# AMD OS / AMDプロトコル 弁理士相談依頼文面ドラフト（内部版）

- 作成日: 2026-06-01
- 位置づけ: まさ / 特許出願司令塔レビュー用の内部ドラフト
- 共有制限: 外部送付禁止。弁理士送付禁止。このままメール、フォーム、DM、紹介文として送らない。
- 目的: 弁理士候補へ初回相談を打診する前に、短い相談依頼文面と聞くべき項目を整理する。

## 0. 使い方

この文面は、外部送付用の最終文面ではない。

実際に送る前に、送付先、宛名、初回相談形式、添付資料の有無、NDA又は守秘義務の扱いを確認し、必要な箇所だけを短く整える。

この文面には、実案件名、顧客名、個人名、未公開技術詳細、実source、prompt、score条件、実DB行、契約条件、価格、connector運用情報を書かない。

## 1. 初回メール / フォーム用の短い文面案

件名候補:

> 研究シーズ事業化判断OSに関する国内特許出願の初回相談

本文案:

> はじめまして。ディープテック研究シーズの事業化判断を支援する社内OSについて、国内特許出願の初回相談が可能か伺いたくご連絡しました。
>
> 対象は、スコア式そのものではなく、複数の業務データ源から証拠付き候補を生成し、人間承認を経て正本化し、却下・コメントを後続処理へ反映し、判断プロトコルや結果観測につなげるワークフロー / データ構造です。
>
> こちらでは、明細書・請求項のたたき台、図面案、発明者・出願人整理、公開済み資料の棚卸しメモを内部ドラフトとして用意しています。ただし、営業秘密や未公開情報を出しすぎない範囲で相談したいため、事前送付資料はまず短縮版に絞りたいです。
>
> 初回相談の可否、料金目安、守秘義務又はNDAの扱い、国内出願までの進め方、見積もりに必要な資料範囲を教えていただけますでしょうか。

## 2. 問い合わせフォーム用のさらに短い版

> ディープテック研究シーズの事業化判断を支援する社内OSについて、国内特許出願の初回相談を希望しています。明細書・請求項たたき台、図面案、発明者・出願人整理、公開済み資料棚卸しの内部ドラフトはあります。営業秘密を出しすぎない範囲で、請求項の広狭、明細書の出し方、初回相談料金、NDA/守秘義務、国内出願までの進め方、見積もり条件を相談したいです。

## 3. 紹介DM用の短い版

> 研究シーズの事業化判断OSについて、国内特許出願に強い弁理士さんへ初回相談したいです。明細書・請求項のたたき台はあるので、ゼロから発明を作る相談ではなく、出願可能化、請求項レビュー、営業秘密の出しすぎ防止、費用感の確認が目的です。候補の方へつないでもらえる場合、まず短い概要だけで打診したいです。

## 4. 初回打診で聞くこと

初回連絡では、以下だけ聞く。

1. 国内特許出願の初回相談が可能か。
2. 初回相談の料金、時間、形式。
3. 守秘義務又はNDAの扱い。事前送付前にNDAが必要か、通常の相談受付で足りるか。
4. 見積もりに必要な資料範囲。概要だけでよいか、請求項案や明細書案が必要か。
5. 国内出願までの標準的な進め方、期間、概算費用。

## 5. 初回打診では書かないこと

以下は初回メール、フォーム、DMに書かない。

- 実案件名、顧客名、研究機関名、個人名。
- 未公開技術、未公開知財、個別プロジェクトの判断材料。
- 実メール、議事録、チャット、クラウド文書、月次レポート本文。
- 実source所在、source permalink、内部source id、長いsnippet。
- prompt全文、few-shot、negative examples、comment-to-guidance変換ロジック。
- score weight、threshold、calibration、正解ラベル、教師データ。
- production DB行、実ログ、connector認証、監視、復旧、watch path。
- 契約条件、価格、商談ログ、導入先別運用ルール。

## 6. 事前送付する場合の添付文

短縮版資料を送る場合だけ、本文末尾へ以下を足す。

> 事前資料としては、営業秘密を除いた1〜2ページの概要と、請求項案の要約、公開済み資料の確認候補だけを送付する想定です。詳細な明細書案や内部運用メモは、初回相談で必要性を確認してから、追加で削除版を作成します。

資料を送らない場合は、以下にする。

> 初回は資料送付なしで、守秘義務又はNDAの扱いと相談範囲を確認したうえで、必要な短縮版資料を後日送付する想定です。

## 7. まさ判断事項

1. 初回打診時点で資料を添付するか、まず資料なしで相談可否と守秘義務/NDAだけ確認するか。
2. 初回相談の予算上限を15〜30万円に置くか、30〜50万円まで許容するか。
3. 送付資料を、1〜2ページ概要 + 請求項要約 + 公開済み資料棚卸し要約に絞るか。
4. 初回文面に会社名を出すか、まずは紹介経由で抽象概要だけ伝えるか。
5. 弁理士候補の実名調査を別workerとして切るか。

## 8. 残課題

- この文面は内部ドラフトであり、外部送付前に最終版へ短縮する。
- 弁理士候補の実名リストはこの文書では作らない。必要なら候補調査workerへ分ける。
- 別workerで批判的弁理士レビューが進んでいる場合、その結果に応じて、打診文面、添付資料、質問項目を再調整する。
