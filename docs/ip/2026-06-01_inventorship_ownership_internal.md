# AMD OS / AMDプロトコル 発明者・権利帰属整理（内部版）

- 作成日: 2026-06-01
- 位置づけ: 弁理士相談前の内部整理。外部送付用ではない。
- 注意: 法的判断の確定ではなく、弁理士へ確認するための事実関係メモ。

## 1. 結論

現時点の内部整理は以下。

- 発明者: まさ
- 出願人: 株式会社チームアルマダ（AMD）
- AI/Codexの位置づけ: 発明者ではなく、発明整理・文書化・批判的検討・ドラフト補助のためのツール
- 共同発明者候補: 現時点ではなし
- 外部送付: なし

まさ判断:

> おれ単独発明で全く問題なし。
> AIの寄与については、おれに聞かれてもなんとも答えようがない。
> AMD名義で出願できる前提で考えている。

この判断を前提に、弁理士へは「発明者=まさ、出願人=AMD」で進めたいと伝える。

## 2. AI/Codexの扱い

AI/Codexは、以下の補助を行った。

- 発明提案書の整理
- 先行技術スクリーニングの補助
- A/B/C/D workerによる批判的検証
- 請求項見直し案の作成補助
- 弁理士相談パックの作成補助

ただし、AI/Codexは権利主体として扱わない。

内部整理:

- 発明の事業課題、対象ドメイン、AMD OS/AMDプロトコルの方向性は、まさが提示した。
- AI/Codexは、まさの指示・判断・既存AMD OS資料に基づいて整理、比較、ドラフト化を行った。
- 発明者欄にAI/Codexは記載しない。
- 弁理士へは、AI/Codexを「発明整理と文書作成を補助したツール」と説明する。

弁理士確認事項:

- AI/Codexを使って発明提案書や請求項案を整理した場合でも、発明者=まさ、出願人=AMDで問題ないか。
- 出願書類にAI利用の経緯を明記する必要があるか。通常は不要と思われるが、念のため確認する。

## 3. AMD名義出願の考え方

まさの前提は、AMD名義で出願できる。

内部整理:

- AMD OS / AMDプロトコルは、AMDの事業として開発・運用している。
- 出願目的も、NIMS/研究機関導入、投資家/提携先説明、外部開示前の防御、後出し出願リスク低減など、AMD事業上の目的。
- よって、出願人はAMDとするのが自然。

弁理士確認事項:

- 発明者まさ、出願人AMDで国内出願する場合、まさからAMDへの「特許を受ける権利」の承継書面が必要か。
- 代表者本人が発明者で、代表者が支配する会社を出願人にする場合、どの書類を用意すればよいか。
- 職務発明規程がない場合でも、個別譲渡書または出願時書類で足りるか。
- 今後、共同研究先や外部協力者が入る場合に備えて、契約書へどの条項を入れるべきか。

## 4. 共同発明者の暫定整理

現時点では、共同発明者候補は置かない。

理由:

- 本件の中心は、AMD OS / AMDプロトコルのワークフロー・データ構造・Before-Zero適用に関する発明。
- まさが、発明の課題、適用先、出願戦略、スコアロジック除外、WS-1〜WS-5主軸、Before-Zero補強という判断を行っている。
- AI/Codexは補助ツール。
- 一般的なレビュー、実装補助、資料整理、営業上の議論だけでは、通常は共同発明者とは限らない。

ただし、以下に該当する人がいる場合は、弁理士へ確認する。

- WS-1〜WS-5の具体的構成を共同で着想した人
- Before-Zero / 設立タイミング推奨の具体的構成を共同で着想した人
- 単なる実装ではなく、請求項の中核構成を具体化した人
- 外部共同研究先が、請求項の中核に入る技術的アイデアを提供した場合

## 5. 弁理士に伝える短文

初回相談では、以下のように伝える。

> 本件は、まさがAMDの事業として着想・具体化したAMD OS / AMDプロトコルに関する発明です。AI/Codexは、発明整理、先行技術スクリーニング、請求項案、相談資料作成の補助ツールとして使いましたが、発明者ではない前提です。出願人は株式会社チームアルマダ、発明者はまさ単独で進めたいです。必要な承継書面や社内書類があれば教えてください。

## 6. まさ判断事項

現時点で追加判断は少ない。

1. 発明者はまさ単独で進める。
2. 出願人はAMDで進める。
3. AI/Codexは補助ツールとして扱い、発明者には入れない。
4. 弁理士へ、必要な承継書面や職務発明整理を確認する。

## 7. 出願書類に書かないこと

- AI/Codexとの全会話ログ
- prompt全文
- worker報告の全文
- 実PJ事例本文
- 実データ、production DB行、source permalink

弁理士へ必要に応じて口頭で説明するだけで足りる可能性が高い。
