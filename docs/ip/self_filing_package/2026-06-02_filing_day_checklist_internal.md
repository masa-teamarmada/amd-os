# AMD OS / AMDプロトコル filing day checklist（内部版）

- 作成日: 2026-06-02
- 位置づけ: 完全セルフ出願の当日に、提出前 / 提出時 / 提出後のMustを落とさないための内部チェックリスト。法的助言ではない。

## 0. 当日方針

- 正ルート: AMD名義の電子出願。
- repoには個人情報 / 会社実値を戻さない。
