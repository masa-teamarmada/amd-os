# 特許請求の範囲候補（内部提出形式候補版）

- 作成日: 2026-06-02
- 位置づけ: 完全セルフ出願に向けた特許請求の範囲候補。実提出版ではない。
- 重要: 外部送付禁止。JPO提出禁止。弁理士問い合わせ禁止。
- 方針: 独立A/B二段構え案を基本とする。WS-5 / WS-6は従属項又は分割候補として未判断を明記する。

## 0. 公式形式メモ

JPO「特許請求の範囲: 特許」では、書類名を `特許請求の範囲` とし、項目名は `請求項○` だけが使用でき、請求項を少なくとも1つ記録する形式が示されている。

## 1. 請求項構成のcurrent truth

- 独立候補A: HITL正本化ループ。複数業務データ源、候補生成、証拠メタデータ、人間承認、approved-only正本反映、reject/comment feedbackを主軸にする。
- 独立候補B: protocol / outcome閉ループ。承認済み正本レコードからprotocolを生成し、1:N事例、multi-horizon outcome、矛盾観測、異種evidence refsまでを主軸にする。
- WS-5: system parameter governance。今回の従属項に残すか、分割候補へ下げるか未判断。
- WS-6: Before-Zero / 法人設立時期推奨。今回の従属項に残すか、分割候補へ下げるか未判断。
- 装置 / プログラム請求項: 方法請求項を支える定型展開として残す。

## 3. 未判断の整理

| 論点 | この候補での扱い | まさ判断 |
|---|---|---|
| 独立A/B | 請求項1と請求項6を独立候補として記載 | 独立2本で出すか、請求項6を従属化するか |
| WS-5 | 請求項11〜12として従属項に残す | 今回残すか、分割候補へ下げるか |
| WS-6 | 請求項13〜14として従属項に残す | 今回残すか、分割候補へ下げるか |
| UI項 | 請求項10として関連画面群の表示態様にする | 侵害検出用に残すか |
| 請求項数 | 16項 | 審査請求料に影響。出願時は16項で厚く、審査請求前に削る選択肢あり |
