# 特許願候補（内部提出形式候補版）

- 作成日: 2026-06-02
- 位置づけ: 完全セルフ出願に向けた願書候補。実提出版ではない。
- 重要: 外部送付禁止。JPO提出禁止。弁理士問い合わせ禁止。
- 方針: 出願人は株式会社チームアルマダ、発明者はまさ単独、代理人なし前提。住所、識別番号、電子証明書、電話番号等は未確認プレースホルダーにする。

## 0. 公式形式メモ

JPO「特許出願」では、願書に `書類名 特許願`、発明者、特許出願人、手数料の表示、提出物件の目録を記録し、その後に明細書、特許請求の範囲、要約書、図面を続けて記録する形式が示されている。

JPO「特許出願人」欄では、識別番号が付与されている場合は識別番号を記録し、識別番号を記録したときは住所又は居所を省略可能とされている。法人が代理人によらずオンライン手続する場合は代表者欄を設ける。

【あて先】特許庁長官殿

【発明者】
    【住所又は居所】【発明者住所プレースホルダー。個人住所は本内部版に記載しない】
    【氏名】【まさの戸籍上又は出願上の正式氏名プレースホルダー】

【特許出願人】

    【代表者】【代表者正式氏名プレースホルダー】
    【電話番号】【AMD連絡先電話番号プレースホルダー】

【代理人】
    【代理人なし】

【手数料の表示】
    【予納台帳番号】【予納を使う場合の番号プレースホルダー】

【提出物件の目録】

    【物件名】特許請求の範囲 1

## 2. 願書未確認欄

| 欄 | 現状 | 出願前確認 |
|---|---|---|
| 提出日 | 未記入 | 実出願日を令和表記で入力 |
| 発明者住所 | 未記入 | 個人住所を本repoに残さず、出願ソフト上でのみ入力する運用を推奨 |
| 発明者氏名 | まさ単独方針のみ | 出願上の正式氏名を確認 |
| 出願人住所 | 未記入 | AMDの登記住所又は識別番号による省略可否を確認 |
| 出願人識別番号 | 未確認 | 9桁識別番号の有無を確認。未取得なら申請人情報・証明書管理ツールで取得 |
| 代表者 | 未記入 | 法人代表者の正式氏名を確認 |
| 電話番号 | 未記入 | 代理人なしなら記録推奨。公開・管理上問題ない連絡先を選ぶ |
| 手数料納付 | 未確認 | 予納、電子現金納付等の方法を決める |
| 電子証明書 | 未確認 | AMD名義又は手続者名義の電子証明書と申請人利用登録を確認 |
| 代理人 | なし前提 | 弁理士を使う場合も、この内部版では代理人なし前提。実提出時は要再作成 |

## 3. 出願人 / 発明者 / 承継メモ

- 発明者: まさ単独。
- 出願人: 株式会社チームアルマダ。
- AI / Codex / worker: 発明者ではなく、資料整理・ドラフト作成の補助ツール。
- 承継: 発明者まさからAMDへ特許を受ける権利を承継したことを示す社内メモ又は決裁メモを、出願前に別途作成する。

## 4. 営業秘密scan

- 願書候補に、個人住所、法人住所、電話番号、識別番号は実値で記載していない。
- 実案件名、顧客名、契約条件、prompt、score、DB行、source permalinkは記載していない。
- 実提出時は出願ソフト上に個人情報を入力する必要があるため、repo内には戻さない。
