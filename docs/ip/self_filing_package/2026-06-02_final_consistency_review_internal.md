2. **願書候補が未確認欄のまま**
   - 個人住所や識別番号をrepoへ入れない方針は正しい。

3. **正式提出図面ではない**
   - SVG候補は内部レビュー用としてusable。
   - JPO提出用には、最新方式、画像形式、余白、線幅、モノクロ2値化、符号視認性、図中テキストを確認する必要がある。

4. **承継メモ未作成**
   - 発明者=まさ、出願人=AMDの内部整理はある。
   - まさからAMDへの特許を受ける権利の承継又は社内決裁メモが未作成。

   - 現パックは請求項1と請求項6の独立候補で整合している。
