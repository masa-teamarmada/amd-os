# 要約書候補（内部提出形式候補版）

- 作成日: 2026-06-02
- 位置づけ: 完全セルフ出願に向けた要約書候補。実提出版ではない。
- 重要: 外部送付禁止。JPO提出禁止。弁理士問い合わせ禁止。
- 公式形式メモ: 特許庁「要約書の概要」は、要約を400字以内、好ましくは200〜400字、課題・解決手段等に分けて記載し、選択図を1つ選ぶことを示している。

## 1. 要約書候補

```text
【書類名】要約書

【要約】
【課題】複数業務データ源に分散した研究シーズの事業化判断材料を、誤抽出を正本へ混入させず、後続判断へ再利用可能に管理する。
【解決手段】情報処理装置は、複数業務データ源から候補データを生成し、元データ全文を正本へ保存せず証拠メタデータを付与し、候補及び証拠を確認インターフェースへ提示する。承認済み候補のみを正本データベースへ反映し、却下又はコメントを後続候補生成へ反映する。さらに承認済み正本レコードから抽象化された事業化判断プロトコルを生成し、複数事例、結果観測及び異種証拠参照を関連付けて保存する。

【選択図】図1
```

## 2. 字数確認

- 要約本文（課題 + 解決手段）: 約260字。
- 400字以内。
- 選択図候補: 図1。
- 代替選択図: 図8。ただし全体構成を速やかに把握できる点では図1を優先。

## 3. 営業秘密scan

- 実案件名、顧客名、個人名、契約条件は記載なし。
- prompt全文、few-shot、score weight / threshold / calibrationは記載なし。
- production DB row、source permalink、実URLは記載なし。
- 効果は過度に断定せず、課題と解決手段中心。
