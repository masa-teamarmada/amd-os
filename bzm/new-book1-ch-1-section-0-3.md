# §1.0.3 測らない自由はない — 共通言語・判断の構造化・再現可能性

> Ch 1「状態空間と観測量 — Before Zero を測るとはどういうことか」(30p) の §1.0 章頭フックの第 3 サブセクション v2。まさレビュー 3 点指摘 (研究者リアリズム / ナラティブ補完 / 批判 panel) を受けて、3 persona → 3 critics (現役研究者リアリズム / 初読読者 / 文献+引用適切性) → synth v1 → adversarial reviewer → synth final で再起草。冒頭は翌週月曜朝の地方合同庁舎三階の給湯室、C 氏 (= 公設試陸上養殖研究員) と D 氏 (新キャラ、同じ公設試の食品加工チームの先輩) の対話。セリフ全て具体的目的語付き、4 件新規引用、adversarial reviewer の 9 must_fix 全反映。

> 翌週の月曜の朝、地方都市の合同庁舎の三階の小さな給湯室で、C 氏は、隣の食品加工チームの先輩研究員 D 氏に金曜の話をしていた。
>
> 「結局、担当官の方に『で、C さんとしてはどう思います』って逆に振られて、何も言えなかったんですよ」と C 氏は言った。「写真と稼働日数だけ持っていって、自分から聞いた話なのに」
> 「で、課長は何て言ってたの」と D 氏が言った。「来週の課内、結論出すんでしょ」
> 「課長にはまだ、先月の問い合わせ三件のうち二件は既存取引先だった、ってとこまでしか話せてなくて」
> 「ふうん。うちでも去年、似た養液循環の案件あったよ。誰も引き取らなくて、結局流れた」
> C 氏はカップを止めて、少し天井を見た。「来年俺が異動になったら、養液の循環、なんで今のやり方に変えたか、たぶん誰も説明できなくなるんですよ。三年前にうちでやり方変えた話、いま俺以外に説明できる人いないんですよ」。D 氏は何も言わずに、おしぼりで手を拭いた。

C 氏 (= 前々節で陸上養殖の試作プラントの写真を持ち込んだ、地方公設試 (= 地方自治体が設置する試験研究機関) の主任研究員) が給湯室で言葉にしようとしたのは、Before Zero (= 会社を設立する瞬間より前の時間) で何かを測ることをめぐる、ある根本的な問いです。D 氏 (= C 氏より一回り上の、同じ公設試の食品加工チームの先輩研究員) はそれを横で受けとめながら、自分のチームでも似た流れがあったことを思い出していました。前節 §1.0.2 では、状態 s_t (= 直接見えない真値) と観測量 y_t (= 外に漏れ出た代理指標) のずれが、写像 g のつぶれ、観測ノイズ ε、自選バイアスの三層によって、他のどの段階よりも大きくなることを見ました。ずれがそれほど大きいなら、いっそ測らず、面談の手応えと経験だけで判断したほうが、数字に引きずられた偽の確信は生まれないのではないか——これは怠惰な逃げではなく、現場でくり返し聞かれる真面目な問いです。本節では、それでも私たちが Before Zero で何かを測ろうとする理由を、三つの実務的責務として立てます。**共通言語**、**判断の構造化**、**再現可能性**。三つは独立した目的ではなく、互いに支え合う三脚であり、一本でも欠ければ残り二本も倒れます。観測の手続きは、当たり外れの精度を競う道具である以前に、この三脚を立てる役目を背負わされています。

第一の責務は、共通言語です。C 氏は来週、課内ミーティングで「あの案件は今投資すべきか、それともまだ早いか」を改めて議論することになります。同席するのは、係長、課長、隣チームの主任、そして来年度から赴任予定の後任の研究員です。五人がそれぞれの頭の中の「早い」「妥当」「機が熟した」を持ち寄っても、議論は噛み合いません。同じ事情は、産学連携本部の URA (= 大学に置かれた産学連携を担う専門職員) と材料系の若い准教授のあいだ、ベンチャーキャピタル (= 未上場企業に出資する投資ファンド) のパートナーと創薬を準備中の若手ポスドク (= 博士号取得後の任期付き研究員) のあいだにも生じていました。「会社にしたほうがいいか」「valuation (= 企業価値評価額) はいくらか」という問いの背後で、各人の頭の中の単語帳がそれぞれ違うのです。F. ハイエクは 1945 年の論文「The Use of Knowledge in Society」(Hayek 1945, AER 35(4)) で、社会の知識は本質的に分散していて誰一人として全体像を持たない、だからこそ薄い共通基盤——彼の例では市場価格を典型例とする調整機構——が要ると論じました。Before Zero の現場には市場価格に相当する信号がまだないので、観測量 y_t に出てくる言葉——「試作プラントの稼働日数」「先月の問い合わせ三件のうち二件は既存取引先」「共同研究の引き合いの本数」——そのものが、関係者の盤面合わせを担います。「先月の問い合わせは三件で、うち二件は既存取引先だった」と言えるようになって初めて、五人は同じ盤面の同じ場所を指していることを確かめられます。観測量は、真値の代用品である前に、辞書です。

第二の責務は、判断の構造化です。三つの場面で当事者が立ち尽くしたのは、それぞれが無能だったからではなく、「いま、何を入力として、何を出力する判断をしようとしているのか」の枠組みが手元になかったからです。H. サイモンは 1955 年の論文「A Behavioral Model of Rational Choice」(Simon 1955, QJE 69(1)) で、人間の合理性は限定的であり、全ての選択肢と全ての帰結を頭の中で同時に評価することはできず、何らかの簡略化された決定枠組みを通してしか判断できないことを示しました。Simon が直接示したのはここまで——限定合理性という事実認識——です。そこから先、入力 (= 何を見るか)・評価関数 (= 何を良いと判断するか)・出力 (= 何を決めるか) に明示的に分けるという扱いは、本書がこの事実認識から引き出す操作的な帰結にすぎません。形式的には、観測 y を見たあとの状態 s の事後分布を p(s|y) と書き、ある決定 d を取ったときの期待損失を、

$$E[L(d, s)\mid y] \;=\; \int L(d, s)\, p(s\mid y)\, ds$$

と書きます。ここで L(d, s) は決定 d と真の状態 s に対する損失、積分は状態空間全体にわたります。これは「あり得る真値 s ごとに、その損失 L(d,s) を、観測後の確からしさ p(s|y) で重み付けして足し合わせる」という意味です。計算の細部は Ch 3 で扱うので、ここでは形だけ覚えておけば十分です。重要なのは、観測量を見るというのが、事前の信念 p(s) を、観測 y を取り込んだあとの信念 p(s|y) に少しだけ更新する手続きにあたる、ということです。それは真値を当てる行為ではなく、判断の構造に入力を流し込む行為であり、サッカーの監督がホワイトボードに描くフォーメーション図のように、誰がどこに立ち、ボールが来たら次にどう動くかを、薄くでも明示する記号として働きます。

第三の責務は、再現可能性です。C 氏が給湯室で漏らした「来年俺が異動になったら、養液の循環、なんで今のやり方に変えたか、たぶん誰も説明できなくなるんですよ」は、過去の判断を未来の担当者が学び直せるかどうかの問題に触れています。K. ポパーは 1959 年の『The Logic of Scientific Discovery』(Popper 1959, Hutchinson; 原著 *Logik der Forschung*, Springer 1934) で、科学的言明の条件として反証可能性——同じ条件を揃えれば、誰がやっても原理的に反証を試みられること——を立てました。この「誰がやっても」の部分、Popper 自身の言葉では intersubjective testability (= 主観を超えた検証可能性) を、本書は実務に翻訳して、組織が判断を蓄積するための条件である再現可能性——同じ観測量と同じ手続きを揃えれば、別の担当者でも近い結論にたどり着けること——として読み替えます。F. ナイトが 1921 年の『Risk, Uncertainty, and Profit』(Knight 1921, Houghton Mifflin) で区別したように、Before Zero に立ち上がっているのはリスク (= 確率分布が既知の世界) ではなく不確実性 (= 確率分布そのものが定まらない世界) です。本書は Knight の不確実性に対し、主観確率 (= 観測者が暫定的に置く信念分布) を明示的に置き、その更新の手続きを可視化することで対処します。不確実性下では、結果による正誤判定は何年も先まで間に合わず、当たり外れで判断の質を測ることはできません。だからこそ、観測量 y_t と判断 d_t の対応を、現場ノートに観測日時と数値を残すように記録しておくことに意味が出ます。「問い合わせ三件、うち二件は既存取引先」という議事録の一行が、半年後に「あのとき何を見ていたか」を後任の研究員に渡すための、最小の申し送り書になります。

共通言語、判断の構造化、再現可能性——この三つは、§1.0.2 で見たずれの大きさをゼロにする手続きではありません。ずれは大きいまま残ります。それでも、五人が同じ単語で議論できること、入力と出力が分離された薄い枠組みを共有できること、半年後に判断の根拠を辿り直せること、この三脚さえ立っていれば、組織はずれの大きい観測量からでも学び続けられます。ただし、§1.0.2 で見た三層のうち、自選バイアス——誰が何を観測対象に選び、誰を観測の場に呼ぶかという偏り——だけは、三脚を立てるだけでは取り除けません。これは §1.2 以降で改めて扱います。逆に言えば、Before Zero の観測設計は、代理指標としての精度だけで評価してはなりません。同じ y_t が、共通言語としては機能するが判断の構造化には組み込めていない、再現可能性は確保されているが共通言語として通じていない——そうした片足の長短は現場で日常的に起こります。次の §1.0.4 では、この三脚を本書がどう実装していくかの道筋を、状態空間 s_t = (P_t, R_t, S_t) と観測方程式 y_t = g(s_t) + ε_t を出発点に、SPS (= P × R × S を一つの数として束ねる尺度、Ch 6 で本格展開) と ECR (= 起業準備度の重み付き合成、Ch 9 で本格展開) という二層の観測枠組みへ向けて、地図の縮尺を引いて予告します。測らない自由はない。だからこそ、どう測るかを決める手前で、何のために測るのかを先に決める必要があります。
