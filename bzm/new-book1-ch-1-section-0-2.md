# §1.0.2 ずれの肥大 — 状態と観測量の差が Before Zero で開く理由

> Ch 1「状態空間と観測量 — Before Zero を測るとはどういうことか」(30p) の §1.0 章頭フックの第 2 サブセクション v2。まさレビュー 3 点指摘 (研究者リアリズム / ナラティブ補完 / 批判 panel) を受けて、3 persona → 3 critics → synth v1 → adversarial reviewer → synth final で再起草。冒頭は翌週月曜の A 氏 + URA 小部屋場面、まさが提供した具体的セリフ案 (「引用してくれるのが身内ばっかり」「サンプル提供のお問い合わせ件数、去年の三分の一」「指標は伸びてるのに、引き合いだけが落ちてる」) をそのまま採用。観測ギャップ概念 + 四つの圧力 (g のつぶれ / ノイズ / 選抜 / 観測本数の少なさ) に整理、新規 4 引用 (Polanyi 1966 / Heckman 1979 / Goodhart 1975 / Cover-Thomas 2006)。

> §1.0.1 月曜の A 氏——ペロブスカイトを持つ材料系の若い准教授——は、翌週の月曜、自分の研究室の隣の小部屋で、同じ URA (= University Research Administrator、産学連携本部の専門職) ともう一度向き合っていた。テーブルの上には、研究室の三年分のサマリーシートが広げられている。論文数、被引用数、IF (= Impact Factor、学術誌の影響度指標)、特許出願件数、共同研究の契約金額——どの列も、棒グラフの先が右上に伸びている。「数字だけ見れば、悪くはないんですよ」と A 氏は言った。「IF も上がってる。被引用も増えてる。ただ、引用してくれるのが、ほとんど同じ研究室の出身者か、同じ学会の旧知の先生方ばっかりなんです。三年前は、応用側の人——デバイス屋さんとか、企業の研究所の人——からの引用がぽつぽつ入っていて、サンプル送ってくれと言われたりしていた。今年に入って、それがほぼ止まりました。共同研究の打診メールも、半年前と比べて明らかに少ない」。URA はうなずいて、「企業からのサンプル提供のお問い合わせ件数、私のほうでも数えてみたんですけど、去年の同じ時期の三分の一くらいでした」と返した。A 氏はしばらく黙ってから、「指標は伸びてるのに、引き合いだけが落ちてる。理屈が合わないんですよ」と続けた。紙の上に並んだ数字と、A 氏自身が現場で感じている肌触りは、明らかに別の方向を向いていた。

A 氏が直面しているのは、曇りガラス越しに人影を読み取ろうとするような作業です。ガラス = 観測量 y_t (= 論文数、被引用数、IF、特許出願件数、企業からの問い合わせ件数といった、研究室の外に漏れ出る代理指標) は手元にあり、それは確かに何かを映しています。けれども、その向こうにいる本当の人物 = 状態 s_t = (P_t, R_t, S_t) (= §1.0.1 で導入した、事業としての到達可能性・研究としての成熟度・社会との接続度の真値) は、ガラス越しにしか見えません。§1.0.1 の観測方程式 y_t = g(s_t) + ε_t を、ここで角度を変えて読み直してみます。本当に知りたいのは状態 s_t のほうです。観測量 y_t は、その状態を覗くための窓にすぎません。ところがその窓は、(i) g という写像によって状態の一部しか写さず、(ii) ノイズ ε_t によって写された像が揺らぎ、(iii) そもそも窓の枚数自体が少ない。A 氏が「指標は伸びているのに、共同研究の引き合いがかからない」と語ったとき、彼は、窓の像の動きと、向こう側にいる人物の動きが、自分のなかで一致しなくなっていることに気づいています。状態と観測量のずれ——本書では以降、これを「観測ギャップ (observation gap)」と呼びます。

問題は、観測ギャップが Before Zero では他のどの段階よりも大きくなる、という構造的な事情にあります。本書ではその構造を、四つの圧力に分解して捉えます。第一の圧力は、写像 g(·) のつぶれです。s_t のうち、研究ノートの細かな記述、装置の癖、未公表の歩留まり、まだ言葉になっていない違和感——これらをすべて含んだ状態は数百次元の厚みを持ちますが、外に出てくる y_t は出願件数・被引用数・問い合わせ件数といった一桁から二桁の指標にしか圧縮されません。Polanyi (1966) が、知識には言葉にできる部分と、本人にすら言葉にできない暗黙の部分 (tacit knowledge = 暗黙知) があると指摘したことは、厳密には写像 g のつぶれそのものではありませんが、状態 s_t のうち外に出ない層という共通点で、本書はこの語彙を借ります。A 氏のサマリーシートの「右上がりの棒グラフ」と、A 氏自身がもらしていた「引用してくれるのが身内ばっかり」という肌触りのあいだの溝は、まさにこの g のつぶれを通り抜けて漏れ出るものと、漏れ出ないもののあいだの溝です。

第二の圧力は、ノイズに対する信号の比の低さです。一本の論文が通るかどうかは査読者の当たり外れに左右され、一件の共同研究契約が成立するかどうかは相手企業の年度予算のタイミングに依存します。同じ研究の質に対して、観測されるシグナルは大きく上下に揺れる。いま ε_t が状態 s_t と独立に振る舞うノイズだと仮定し、Var(·) を「ばらつき (= 分散)」を表す記号としたとき、観測量のばらつきは

$$ \mathrm{Var}(y_t) = \mathrm{Var}(g(s_t)) + \mathrm{Var}(\varepsilon_t) $$

と分解されます。右辺の第一項は状態の真の動きが観測量にもたらしている信号、第二項は状態とは無関係に観測量を揺らしているノイズです。この分解は ε_t と g(s_t) の独立性を仮定したうえでの標準的なもので、Before Zero において第二項が第一項を覆い隠す比率で混入してくる、というのは式から自動的に導かれる帰結ではなく、現場の経験から繰り返し報告される観察事実として本書は受け取ります。

第三の圧力は、観測される量がそもそも「すでに選抜を通過した」ものに偏っているという、選抜の歪みです。論文として外に出ているのは書かれた草稿のごく一部であり、出願された特許は構想された発明のさらに一部です。これを正面から扱った古典として、計量経済学における Heckman (1979) があります。Heckman が労働市場の賃金データの解析で指摘したのは、観測されたサンプルが母集団からランダムに引かれているのではなく、本人自身の自選 (self-selection) と、ゲートキーパーによる他選 (selection by gatekeepers) の二重の網を通過した結果だけが残っているという構造でした。本書ではこの構造を、Before Zero の観測量に転用します。外に出ている論文・特許・共同研究契約は、すでに「外に出す」と研究者自身が判断したもの、あるいは査読・審査を通り抜けたものに限られます。出さなかったもの、出すかどうか迷ったまま手元に残ったものは、観測量 y_t には現れません。観測量を集める側 (URA、TLO、支援機関) もまた、自分たちの実績として残すべき件数を意識して指標を設計しますから、観測量はいわば二重に選抜された像になります。同じ歪みは、§1.0.1 の B 氏 (= 水曜午後、都内のあるベンチャーキャピタルの会議室で valuation (= 企業価値評価額) の問いに沈黙していた、創薬準備中のポスドク) が VC (= ベンチャーキャピタル、未公開企業に投資する金融主体) の面談にたどり着けたこと自体にも乗っています。彼がその会議室にいるのは、紹介者の網と、相手側の社内会議という二重の選抜を生き残った結果だからです。さらに Goodhart (1975) が金融政策の文脈で観察した現象——後に「Goodhart の法則」として広く知られる定式——は、ある統計が政策目的のために圧力をかけられた瞬間、その統計と元の状態との対応関係は崩れていく、という現象でした。本書ではこれを、Before Zero における指標の内生的書き換えとして転用します。本部が「特許件数を伸ばす」という運用目標を掲げた瞬間、現場は出しやすい案件から先に出すように行動を変えます。三年前の特許件数と今年の特許件数は、同じ単位で並んでいても、もう同じ意味を持ちません。A 氏のサマリーシートが「悪くない」のは、悪くない部分だけが計上される設計に向かって、現場と本部が共同で進んできたからでもあります。

第四の圧力は、観測量の絶対数の少なさそのものです。情報理論の標準的な整理 (Cover & Thomas 2006) には、観測量 y が状態 s について運ぶ情報の量を測る「相互情報量 (= 観測量 y を見ることで状態 s についての不確かさがどれだけ減るかの目安)」という量があり、観測が互いに独立であれば、この情報量は本数 n に比例して線形に蓄積していくと整理されています。ところが Before Zero では、論文は年に一本か二本、特許は数年に一件、政策の文脈で動く C 氏 (= 金曜夕方、地方都市の合同庁舎で陸上養殖の試作プラントの写真を広げていた、公設試 (= 公設試験研究機関、地方自治体が運営する研究所) の主任研究員) のような領域では、関連する公募の流れが年に一周しかしません。観測本数 n がもともと小さいうえに、同一研究室の連続論文や同一テーマの連続出願のように観測どうしが強く相関しているため、観測本数を増やしても情報量が線形には増えていきません。結果として、状態 s_t を観測量から逆向きに読み取る作業——観測量を経由した状態の推定——は、極端に裾の広い、つまり「どの状態でもありうる」という分布に着地します。ずれが大きいということは、A 氏や B 氏や C 氏が個人として鈍感だからではなく、観測の構造がそうなっているからずれている、ということを意味します。それでも私たちは、見える観測量から状態を読み取ろうとし続けなければなりません。なぜ続けるのか、続けるための実務的な要請は何か。次の §1.0.3 では、ずれが大きいと知ってなお Before Zero を測ろうとする三つの理由——当事者と支援者のあいだに共通言語をつくる、判断の構造を可視化する、議論を後から再現できる形に残す——を、もう一度三人の現場に戻って描いていきます。
