# BZM 3.0教科書 付録 — 記号一覧、用語、参考文献

第8章の継続価値の式で $h$ に出会った読者は、第9章の到達曲線でもう一度 $h$ に出会う。

同じ文字だが、前者は評価期間の終わりからの経過月、後者は評価日からの経過月である。

$\mu$ も二度現れる。

第2章ではバーンレートの記号であり、第8章では消費の限界効用の弾力性である。

$\phi$ は、第6章では公募の採択関数、第8章では用途の年額のうち案件系が国内で発生させられる割合を指す。

本書の記号は、第1章から第9章と第11章の記号表で定義されており、各章の表は、その章の式に要るものだけを載せている。

式の途中で記号を見失ったとき、どの章のどの表へ戻ればよいか。

同じ文字が別の量を指す箇所は、どこにあるか。

> **状態**：`textbook v0.1`（2026-10-03）
>
> **位置づけ**：BZM 3.0（2026年8月24日採用、9月2日改訂）の教科書章。モデルの定義、式、係数を追加も変更もしない。
>
> **主張の地位**：`design-choice`＋`unvalidated`。前向き検証0件。係数の値は、規約と確定済みのものを除いて較正前の初期値であり、根拠の水準（A：公開統計または実測から直接引ける／B：制度や文献から水準が導出されている／C：暫定の置き）を添える。規約と確定済みの値には、その地位を添える。
>
> **対象読者**：経営学、経済学系の大学院生と、研究成果の事業化を支援する実務者。確率、期待値、条件付き確率、割引現在価値の初歩を前提にする。
>
> **使わない用途**：本書の数値を、案件間の順位づけ、投資額の決定、支援の採択、資源配分、撤退や継続の自動判断、報酬や個人評価の単独条件に使わない。投資判定は本モデルの出力と投資層の判断の二階建てである。
>
> **前後**：[前の章](./bzm-3-0-textbook-limits)。次の章は無い

**到達目標**

この付録を使う読者が、次の三つをできることを目標にする。

1. 本文の式に現れる記号から、その記号を定義した章と、同じ文字が別の量を指す箇所を引ける。
2. 本書が定義した用語について、定義の文と初出の章を確認できる。
3. 本文の角括弧の番号から書誌へたどり、係数の水準に外部の裏づけがある文献（[55]〜[59]）と、本モデルの構造だけを支える文献を区別して読める。

## 1. 記号一覧

初出の欄には、その記号が最初に現れる章を書く。

定義の本体が別の章にある記号には、括弧で定義の章を添える（$\eta_t$ は第4章の前進の式に初めて現れ、定義は第5章にある）。

係数の値は第11章第8節の総覧に、根拠の水準の判定規則は第11章第3節にある。

第14章の反証条件の表が「記号の閉包表」と呼ぶのは、この一覧である。

添字 $u$ は用途、$g$ はゲート、$f$ は機能、$k$ は申し出の形（ライセンス、M&A、知財売却）、$i$ は権利と承認の残件、$o$ は九つの区分、$j$ は制度クラス、$w$ は資金調達の機会を指す。

## 4. 演習

**演習1**

第8章の継続価値の式の $h$ と、第9章の到達曲線 $Q(h)$ の $h$ について、それぞれ $h = 0$ がどの時点かを答えよ。

評価期間が $T$ か月の案件で、第8章の $h$ が 6 の月は、第9章の $h$ ではいくつに当たるか。

方針：第8章の $h$ は評価期間 $T$ の終わりを 0 とする経過月で、第9章の $h$ は評価日を 0 とする経過月である。

したがって評価日からの経過月は $T + 6$ になる。

採点観点：二つの原点を取り違えていないか。

$T + 6$ と答えているか。

第8章の $h$ を第9章の $h$ として読むと、時点が $T$ か月ずれることに気づいているか。

**演習2**

承継者の到達確率 $q_k$（第6章）と、永久年金係数 $\mathrm{Ann}(d,\ \lambda^{\mathrm{obs}})$ の中の $q = (1 - \lambda^{\mathrm{obs}}/12)(1+d)^{-1/12}$（第8章）は、どちらも 0 と 1 のあいだの値をとる。

値の範囲で区別できない二つを、式の中での働きで区別して述べよ。

方針：$q_k$ は承継者が残りの市場ゲートを越える確率であり、申し出で決着したシナリオの価値に乗る確率として働く。

$q$ は月ごとの残存率と割引の積であり、$q/(1-q)$ の形で永久年金係数の中にだけ現れる。

採点観点：範囲が同じでも量が別であることを、添字と式の位置から説明しているか。

1.9 の表の $q$ の行を引いているか。

**演習3**

参考文献 [46]（Wright）と [55]（BIO ほか）は、本モデルの何を支えているか。

構造を支えるのか、係数の水準を支えるのかを分けて答えよ。

方針：[46] は量産で原価が下がる関数の形という構造を支える（第3章、第8章）。

[55] は治験の相別の通過確率という水準を支え、第11章の総覧では根拠レベル B が付く。

採点観点：[46] に水準を、[55] に構造を割り当てていないか。

第11章の総覧で値と根拠レベルを確かめているか。
