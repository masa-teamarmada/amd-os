# BZM 3.0教科書 第3章 — 案件パラメータと事前分布

同じ公的資金を同じ額だけ受け取った二つの研究室があるとしよう。

三年後、一方には出願が二件と再現できる形のデータが残り、他方には研究者本人の論文が増えただけで、案件に残るものはほとんど無い。

二件とも次に越えるゲートは同じで、残高も同じだとする。

第2章の観測状態で見比べても、差は書かれていない。

差があるのは、投じた資源がどれだけ速く次の一手を打つ力に変わったかという、一か月の記録には現れない速さである。

本モデルはこの速さを変換能力と呼び、観測状態ではなく案件パラメータの側に置く。

案件パラメータは、直接には測れない。

測れないものを式に入れるには、分からなさの持ち方を決めなければならない。

評価日に手元にあるのは値ではなく、証拠から置いた分布である。

**到達目標**

この章を読み終えた読者が、次の三つを自分の言葉で説明できることを目標にする。

1. 案件パラメータ $\theta$ の十一の成分について、それぞれ何を表す量であり、月次の計算のどの式に効くかを述べられる。
2. 変換能力 $c$ の測り方（費用と戦略余力の増分の比率の移動平均）と、記録の無い案件で無風期間の目盛りから概算する場合の使い分けを、二重計上を防ぐ規則とともに説明できる。
3. 事前分布 $B_0$ の置き方（四点方式、幾何平均と乗法的ばらつき、同じ源の変数の共有）と、基本設定の既定値がどの成分に置かれ、どの成分には置かれないかを述べられる。

---

## 1. 観測状態と対になる量

第2章の観測状態 $x_t$ は、九つの成分がどれも観測できる量で、推定を挟まない。

本章の案件パラメータ $\theta$ は、その逆の性質を持つ。

直接には測れず、証拠から推定するしかない。

そして、月ごとの計算のあいだは変わらないと置く。

計画の規則は $\theta$ に条件づけず、観測できる状態にだけ条件づける（第7章）。

$\theta$ を一つの値に固定すると、各過程がシナリオの確率をすべて定め、計算が閉じる。

証拠が増えて推定を変えたいときは、評価の版を更新して計算をやり直す（第10章）。

月次の中では、案件パラメータは「変わらず、分かっていないだけ」の量である。

$$
\theta = \big(c,\ e,\ \sigma,\ \tau_{\mathrm{proc}},\ \psi,\ \kappa_{\mathrm{IP}},\ \{w_u\},\ \{\bar P_u\},\ \{\delta_u\},\ \{\underline{c}_u\},\ r\big)
$$

| 記号 | 意味 |
|---|---|
| $c$ | 変換能力。投入資源あたりに前進を生む速さの乗数 |
| $e$ | エバンジェリスト機能が、この案件で埋まる見込み（機能の定義は第3節） |
| $\sigma$ | 産官学モメンタム。その分野に学、産、官の勢いが吹いているか |
| $\tau_{\mathrm{proc}}$ | 工程の型（プロセス型／組立型、特殊インフラ依存。作るものの物理で決まる区分で、四つの型 F1〜F4 としての定義は第4章） |
| $\psi$ | 技術の核の成立（再現性と、規模を上げたときの性能） |
| $\kappa_{\mathrm{IP}}$ | 専有可能性 |
| $w_u$ | 用途 $u$ の支払上限。証拠の階級つき |
| $\bar P_u$ | 用途 $u$ で国内で発生しうる産業の付加価値の年額 |
| $\delta_u$ | うち国内の既存事業からの置き換え分 |
| $\underline{c}_u$ | 用途 $u$ の量産原価の下限 |
| $r$ | 自走力（円／月） |

十一の成分は、付き方で三つに分かれる。

$c$、$e$、$\sigma$、$\tau_{\mathrm{proc}}$、$\psi$、$\kappa_{\mathrm{IP}}$ の六つは、案件に一つずつ付く。

$w_u$、$\bar P_u$、$\delta_u$、$\underline{c}_u$ の四つは、用途 $u$ ごとに付く。

波括弧はそのことを示しており、用途が三つある案件では、この四種で 12 個の成分になる。

本書の計算を実装したプログラム（以下、参照実装）は、当面は主たる用途 1 本で計算し、他の用途は参考として別に併記する近似を置いている（第14章）。

$r$ は案件に一つ付き、第2章の資金の遷移式に $\rho_t\, r$ として現れていた量である。

十一の成分が、月次の計算のどこに入るかを先に一覧にしておく。

式の形はそれぞれの章に置く。

| 成分 | 入る式または過程 | 章 |
|---|---|---|
| $c$ | ステージゲートの前進確率 $p^{\mathrm{adv}}_t$。規制と認証のゲートの準備段 | 第4章 |
| $e$ | エバンジェリスト機能の空席が埋まる探索過程の成功確率 | 第5章 |
| $\sigma$ | 採択関数 $\phi$、申し出到来率 $\nu_k$、受託の到来率 $\nu_c$、競合消失率 $\lambda^{\mathrm{comp}}$、資金調達の機会の新設率 $\nu^{\mathrm{win}}$（参照実装では未実装）に掛かる乗数 | 第6章、第7章、第14章（乗数の値は第11章） |
| $\tau_{\mathrm{proc}}$ | 基準速度 $\kappa_g$ の表の列。必要支出列 $\mu_t$。$\underline{c}_u$ の事前分布 | 第4章、第11章 |
| $\psi$ | 技術系のゲートの前進確率。用途が $A_t$ に入る共有の前提 | 第4章、第8章 |
| $\kappa_{\mathrm{IP}}$ | 国内で発生させられる割合 $\phi_u$、競合消失率 $\lambda^{\mathrm{comp}}$、申し出到来率 $\nu_k$ | 第8章、第7章、第6章 |
| $w_u$、$\underline{c}_u$ | 単位採算 $m_u(\theta) = w_u - \underline{c}_u$ の判定 | 第8章 |
| $\bar P_u$、$\delta_u$ | シナリオの価値 $\Pi(\omega)$ の年額 $\bar P_u - \delta_u$。経済性の乗数 $m_\theta$ | 第8章、第6章 |
| $r$ | 資金の遷移式の $\rho_t\, r$。資本自立の判定。受託の到来率 $\nu_c$。会社化の条件の「資金の目処」 | 第2章、第7章、第6章 |

以下、成分ごとに、何を表す量か、評価日にどう推定するかを見ていく。

## 2. 変換能力

変換能力 $c$ は、投入資源あたりに前進を生む速さの乗数である。

資源そのものと、資源が生む働きを分けて考える系譜 [6] と、その働きを感知、捕捉、再構成の三つへ分解する系譜 [8] に対応する。

研究室に同じ装置と同じ人数と同じ資金があっても、そこから出てくる前進の速さは案件によって違う。

その違いを、分野ごとの基準の速さに掛かる一つの乗数として持つのが $c$ である。

基準の速さは第4章の $\kappa_g$ が受け持ち、$c$ はそれに掛かる。

$c = 1$ の案件は、その分野の基準どおりの速さで進む。

$c = 2$ なら、同じ資源で基準の二倍の率でゲートを越え、$c = 0.5$ なら半分の率である。

### 費用と戦略余力の増分の比率

$c$ は、何かアクションをするたびに、そこに掛かった費用と、それによって得られた戦略余力の増分を推定し、その比率を分野の基準値と比べて測る。

戦略余力は第1章で定義した量で、次の行動を起こすための余力であり、現金だけでなく現金以外の成分も含む。

その増分として数えるのは、獲得した資金、越えたゲート（証拠水準の上昇）、知財、需要家との関係、人の五つである。

費用の側は、そのアクションに実際に掛かった額である。

比率は、直近に重みを置いた移動平均で持つ。

累積の一括比にすると、過去に速かった案件の失速が薄まって見えなくなる。

初年度に大きく前進した案件が、その後の二年間ほとんど動いていないとしても、三年分を一括で割れば平均は高いままである。

直近に重みを置けば、止まっていることが数字に出る。

実務では、評価の版の期間ごとに区切って更新し、記帳は登録簿の様式で行う（第10章）。

費用とアクションの記録が取れない案件では、この測り方が使えない。

その場合は、外から見えるポジティブな動きの公開情報と、無風期間 $t_q$（外から見えるポジティブな動きが最後に観測されてからの月数。定義と目盛りは第11節）から概算する。

### 設立前に獲得した資金の扱い

ただし、設立前に獲得した資金（科研費、GAPファンドなど）は、額をそのまま戦略余力に数えない。

その資金がどれだけ案件の資産へ変わったかで $c$ を推し量る。

資産とは、知財（出願と登録と帰属）、試作と実証（越えたゲート）、データ（再現できる形）、人（案件に残る人）の四つである。

冒頭の二つの研究室は、受け取った額では区別できない。

出願と再現できるデータへ変わった側と、案件に残らない成果へ使われた側とで、$c$ の推定値が分かれる。

資金の額を直接数えると、この区別が消える。

## 3. エバンジェリスト機能の充足見込み

$e$ は、エバンジェリスト機能がこの案件で埋まる見込みである。

エバンジェリスト機能とは、技術の意義と到達点を説明して、需要家、投資家、審査側の判断を動かす機能を指す。

経営チームが持つべき機能を分解したときの一番目に当たり、分解の全体は第5章に置く（機能への分解は [41]、担い手の構成が資金調達の成否に効くことの実証は [44][45]）。

$e$ は専任の担当者を指す量ではなく、機能が誰かによって担われるかどうかを表す。

研究者本人が担ってもよく、他の機能と兼ねてもよい。

測定の手続きは、関係者の棚卸しである。

研究室出身者、長期の共同研究者、初期からの伴走者、共同出願者を列挙し、接触実績を確認する。

未探索なら広い範囲（中立）に置き、探索して担い手が見つからないと分かったときだけ下げる。

まだ探していないことと、探して見つからなかったことは、別の情報である。

前者は分からなさの幅として残し、後者だけが推定値を動かす。

更新は実働の記録（会議、意思決定、対外説明）だけで行う。

肩書、名義、研究者本人の起業意思は入力にしない。

この規律の理由は第1章第8節で述べた。

$e$ が効く先は、第5章の探索過程である。

エバンジェリスト機能の空席は、成功確率が $e$ に依存する探索によって埋まる。

第12節で見る八機能の充足の入力口では、$e$ は機能1の充足 $f_1$ と同じ量として扱われる。

## 4. 産官学モメンタム

$\sigma$ は産官学モメンタム、すなわちその分野に学、産、官の勢いが吹いているかを表す [21][22]。

追い風が無ければ公募に採択されにくく、民間からの出資も付きにくい。

案件の側の努力では動かせない、分野の環境の量である。

冒頭の二つの研究室が同じ分野にいれば、$\sigma$ は二件で同じ値を取る。

二件を分けるのは $c$ であって $\sigma$ ではない。

観測の手続きは、分野別に三つの系列を記録することである。

(i) 公的公募の採択率と予算額の変化 [25]。

(ii) 民間投資額の変化。

(iii) 正統性の二種 [23]。認知的正統性（規格、標準、審議会での位置づけ）と、社会政治的正統性（規制整備、業界団体の形成）である。

一つめは官の側の、二つめは産の側の勢いを、三つめは分野が制度と業界の中で居場所を得つつあるかを捉える。

三系列から、$\sigma$ を逆風、無風、追い風の三値 $\{-1, 0, +1\}$ のどれかに置く。

置かれた値は、採択関数 $\phi$ と申し出到来率 $\nu$ の乗数に写される。

乗数の値と、三系列から三値へ置く判定規則、判定の単位は第11章に置く。

## 5. 工程の型と量産原価の下限

$\tau_{\mathrm{proc}}$ は工程の型である。

作るものの物理で決まる区分で、F1 プロセス型、F2 組立とデバイス型、F3 ソフトウェアとデータ型、F4 サービスと手法型の四つとして第4章で定義する（F3 と F4 を分ける線が物理の線か事業モデルの線かは、本モデルが表現していないことの一つに挙げられている。第14章）。

規制の有無は型とは別の属性として持ち、$\tau_{\mathrm{proc}}$ には含まれない（第4章）。

$\tau_{\mathrm{proc}}$ は評価者が型を選んで置く。

それでも案件パラメータに入れるのは、他の量の事前分布がここから引かれるからである。

必要支出列 $\mu_t$ をここから導き、量産原価の下限 $\underline{c}_u$ の事前分布もここから引く。

型から引いた必要支出列は、案件が申告した支出の列と突き合わせる基準にもなる（第10章）。

二つの量を同じ型から引くことで、同源の共有が保たれる。

プロセス型の案件は、支出の列も原価の下限も、規模を上げると挙動が変わるという同じ物理から決まる。

別々に置くと、支出は重いのに原価は軽いという、物理として両立しない組み合わせが事前分布に入り込む。

$\underline{c}_u$ は、用途 $u$ の量産原価の下限である [48]。

事前分布は工程の型から引き、観測（原価実測、設備見積、歩留まり）が入ったときに評価の版の更新で置き換える（第10章）。

$\underline{c}_u$ が効く先は、単位採算の判定である。

案件パラメータを固定すれば $m_u(\theta) = w_u - \underline{c}_u$ は一つの数で、計画の規則はこれが正の用途だけを稼働している用途の集合 $A_t$ に入れる（第8章）。

全用途でこの差が正でない案件パラメータでは、価値が立たない。

参照実装はこの単位採算のゲートをまだ実装しておらず、天井を 1 に正規化する近似の下で常に通ると仮定している（第14章）。

## 6. 技術の核と専有可能性

$\psi$ は技術の核の成立、すなわち再現性と規模を上げたときの性能である。

使用先は二つある。

第一に、技術系のステージゲートの前進確率に乗る（第4章）。

第二に、技術系のゲートを通らない限り、どの用途も $A_t$ に入れないという共有の前提である。

二つめは、用途が複数ある案件で効く。

用途ごとに需要家も価格も違うが、技術の核は一つしかない。

技術が立たない案件パラメータでは、全用途が同時に立たない。

用途ごとに独立に成否を引くと、技術が立たないのに一部の用途だけ稼働するシナリオが生まれる。

$\psi$ を用途をまたいで共有することで、そのシナリオを除く。

$\kappa_{\mathrm{IP}}$ は専有可能性である [53]。

請求範囲の広さ、他者特許との抵触（実施の自由、FTO）、代替経路の塞がり具合から推定する。

権利の不確かさが技術の取引の成否と速さに効くことの実証は [20] にある。

効き先は三つある。

国内で発生させられる割合 $\phi_u$（第8章）、競合消失率 $\lambda^{\mathrm{comp}}$（第7章）、申し出到来率 $\nu$（第6章）である。

権利が強ければ、作った価値のうち取れる分が増え、競合に先を越される率が下がり、ライセンスや買収の引き合いが来やすくなる。

三つの効き先は同じ一つの推定値から引かれる。

## 7. 用途ごとに置く三つの量

$w_u$、$\bar P_u$、$\delta_u$ は用途 $u$ ごとに置く。

### 支払上限と証拠の階級

$w_u$ は用途 $u$ の支払上限、すなわち需要家がその用途に対して支払う価格の上限である。

この量には証拠の階級が付く。

階級は、関心、有償の概念実証（PoC）の支払い、量産条件の提示、量産契約の四段である。

有償PoCの支払いだけでは、量産の階級に上げない。

評価のために対価を払うことと、量産時の価格と数量を約束することは、別の証拠である。

階級のうち関心は、需要家の関心表明の文書という登録簿の観測で付く。

有償PoC以降の三段は、市場系のゲート M2、M3、M4 の通過で上がる（第4章）。

階級の失効と降格は登録簿の規則で行う（第10章）。

### 天井は一つの数で置く

$\bar P_u$ は、用途 $u$ で国内で発生しうる産業の付加価値の年額である。

第1章で定義した付加価値、すなわち売上から原材料と外注の購入分を引いた額を、年額で置く [38]。

売上ではない。

用途ごとに一つの数で置き、幅を持たせない。

天井 $\bar P_u$ に幅を持たせないのはなぜか。

第8章の価値の式は、市場規模、稼働するか、取り分 $\phi_u$ の三つに分けてあるので、到達の不確かさはすでに別の項が持っている。

その用途がいつ稼働するか、稼働し続けるかは、シナリオの確率と $A_t$ の遷移が担う。

$\bar P_u$ にも幅を置くと、同じ不確かさを二回数える。

市場規模は年額の単位で観測される量なので、割引現在価値のような別の単位から割り戻す換算の手続きも要らない。

推定の手続きは、案件ごとに用途を洗い出すことから始まる。

既存の市場がある用途は、産業統計から国内の年額を引く。

新しく作る用途は、その用途が成立したときの年額を条件つきで置く。

「成立したとき」の条件は、シナリオの側が稼働の有無として受け持つ。

### 置き換え分

$\delta_u$ は、$\bar P_u$ のうち国内の既存事業からの置き換え分である。

他所から移しただけで日本全体では増えていないため、価値の式では $\bar P_u - \delta_u$ の形で差し引く。

他者が同じ用途を実現していたかどうかによる差し引きは置かない（第1章第2節）。

$w_u$、$\bar P_u$、$\delta_u$ と $\underline{c}_u$ には、基本設定の既定値が無い（第10節）。

案件ごとの調査でしか置けない量だからである。

## 8. 自走力

$r$ は自走力である。

外の資金が止まっても、自分の力で稼いで走り続けられる力を指す。

研究成果の事業化がうまくいかなくても、稼げる産業を作れるなら産業創出効果がある、という考え方がこの成分の背景にある。

外部資金に頼らない行動の類型 [13] に対応する。

$r$ の単位は円／月で、工数を全部割いたときに案件へ残る額、すなわち直接費を引いた後の粗利である。

売上ではない。

売上のまま扱うと、受託の遂行に要る工数が支出側に現れず、資本自立が自明に成立してしまう（第2章）。

### 案件ごとに受託の中身を書く

$r$ は、案件ごとに、その案件が実際に何を受託するのかを書いたうえで額を置く。

受託の中身は案件によって違う。

ソフトウェアの案件ならシステム開発の受託、素材の案件なら他素材との複合化の開発受託、競合他社の製品を商社的に販売する事業の請負、といった具合である。

工程の型から引く一律の値は、案件ごとの調査より前に置く初期値であり、推定が入ったら上書きする。

案件ごとの推定を入れれば、会社化後の上限は億単位まで届く。

大学の研究室として受託できる額と、会社として受託やサンプル販売ができる額は別の量であり、$r$ は会社化の前後で水準を分けて持つ。

### 効く先

$r$ は第2章の遷移式に $\rho_t\, r$ として入り、受託に割く工数の割合 $\rho_t$ を掛けた分が月々の稼ぎになる。

資本自立の判定では、反復可能な稼ぎとして売上 $y_t$ とともに数えられる（第7章）。

受託の申し出の到来率 $\nu_c$ にも効く（第6章）。

稼げる型を持っている案件には、受託の話が来やすい。

会社化の条件の一つである資金の目処には、受託の契約も数えられる（第7章）。

## 9. 事前分布の置き方

評価日に持っているのは、$\theta$ の値ではなく事前分布 $B_0(\theta)$ である。

$B_0$ は、出所の印（文書、面談、第三者証言、公開情報）を付けた証拠から、個別推定、根拠交換、再推定、集約の手順で置く。

複数の評価者がまず別々に推定し、互いの根拠を交換し、もう一度推定し、それを集約する。

専門家の判断を確率に写す手続きの系譜 [29] に対応する。

推定は、下限、上限、最良値、確信度の四点方式で受け取る。

一つの数を答えさせると、答える側は自分の不確かさを表せない。

四点で答えさせることで、分からなさの幅が入力に残る。

推定値の幅は「幾何平均×乗法的ばらつき」で持つ。

中央の値を幾何平均で、幅を倍率で持つ形であり、$c$ の既定（第10節）がその例になる。

### 同じ源の変数の共有

相関する成分は、同じ源の変数を共有する。

第5節の $\tau_{\mathrm{proc}}$ と第6節の $\psi$ がその源である。

支出の列と原価の下限は工程の型から、全用途の稼働の可否は技術の核から引く。

成分ごとに独立の分布を置くと、現実には同時に起きない組み合わせがシナリオに入る。

源を共有すれば、その源に由来する不整合は、相関を別に推定しなくても入らない。

### 版の更新と登録簿

月次の中では $\theta$ は固定である。

証拠が増えたときの事前分布の更新は、評価の版の更新として行う（第10章）。

版が変われば $B_0$ が変わり、スコアも再計算される。

どの証拠がどの成分を動かすかは、登録簿の出来事の種類ごとに決まっている。

第10章の24種のうち、案件パラメータの推定値に効くものを成分の側から並べると次のようになる。

| 成分 | 推定値に効く登録簿の出来事 |
|---|---|
| $c$ | 研究室と組織の体制変化。評価版の更新時の経過報告（各ゲートの滞留月数と投入） |
| $\psi$ | ステージゲートの通過。検証の試行の不成立。経過報告 |
| $e$ | 人の実働の記録（機能が空席のときに限る。第5章） |
| $\sigma$ | 分野環境の観測（公募の採択率と予算額、民間投資額、正統性の事象） |
| $\kappa_{\mathrm{IP}}$ | 競合の出願、参入、撤退、実用化 |
| $w_u$ の階級 | 需要家の関心表明。市場系ゲートの通過。需要と証拠の撤回と失効 |
| $\bar P_u$、$\delta_u$ | 天井と置き換えの再推定（市場調査、産業統計） |
| $\underline{c}_u$ | 工程と原価の情報（原価実測、設備見積、歩留まり） |

$r$ を直接動かす出来事は 24 種の中に無く、$r$ は案件ごとの調査で置く（較正のデータ源は受託契約の記録）。

同じ一件の出来事で事前分布を二回更新しないという規則が、この表の上に乗る（第10章）。

スコアの報告に出す下側、中央、上側の三つの数（第9章）は、$B_0$ の下で $v(\theta)$ が取る値の 10%点、50%点、90%点である。

この幅は、案件パラメータがまだ分かっていないことから生じる幅であり、本章で置いた各成分の分布がその源である。

参照実装は、この幅を $c$、$\psi$、$\sigma$、$r$ の格子で出す近似を置いている（第14章）。

**基本設定**（計画の規則を登録していない案件に置く既定の一式。既定の計画の規則、代表案件の前提、案件パラメータの事前分布の既定からなる。以下、基本設定）のうち、本節に置くのは案件パラメータの事前分布の既定、すなわち案件ごとの調査が入る前の $B_0$ である。

既定の計画の規則は第7章、代表案件の前提は第11章に置く。

| 成分 | 既定 | 根拠レベル |
|---|---|---|
| $c$ 変換能力 | 案件ごとの調査より前に置く初期値。対数正規、中央値 1.0、幾何標準偏差 1.65（10%点 0.53、90%点 1.90）。案件ごとの推定が入ったら、分布の中心をその値へ置き換える。幅は幾何標準偏差 1.65 のまま。母集団の中央値 1.0 は識別のための規約 | 規約＋C |

| $\kappa_{\mathrm{IP}}$ 専有可能性 | 権利の内容だけで条件づける：出願なし 0.15、単独出願済み 0.55、登録済みかつ FTO 確認済み 0.75、請求範囲が狭い 0.35。幅 $\pm0.15$ | C |
| $\sigma$ | 観測できていない案件は $\Pr(-1)=0.25$、$\Pr(0)=0.50$、$\Pr(+1)=0.25$ | C |

$c$ の欄の「規約」は、識別のために本モデルが定めた母集団の中央値を指し、データから較正する対象ではない（下の説明）。

### 変換能力の既定

$c$ の既定は対数正規分布で、中央値 1.0 の上下に、幾何標準偏差 1.65 の幅を持つ。

正の値を取り、倍率として効く量なので、幅も倍率で置く。

中央値を 1.0、ばらつきを 1.65 倍とすれば、10%点は 1.0 を 1.65 の 1.28 乗（1.28 は標準正規分布の 90%点）で割った 0.53、90%点は同じ倍率を掛けた 1.90 になる。

足し引きの幅で持つと、幅が中央値を超えた時点で下側がゼロや負に届き、倍率として意味を失う（中央値 1.0 に $\pm1.2$ の幅なら、下側は $-0.2$ になる）。

乗法で持てば、下側はゼロに近づくだけで負にならない。

この幅がどれほどの差かは、第4章の前進の式に入れると見える。

基準速度 $\kappa_g = 1/17$ のゲート（F1 の T3）で、最短準備期間の 11 か月が過ぎたあと、他の因子を 1 として $c$ だけを動かすと、月ごとの通過確率は 10%点の $c = 0.53$ で約 0.031、中央値で約 0.057、90%点の $c = 1.90$ で約 0.106 である（いずれも較正前の初期値の下での計算例）。

同じ分野の同じゲートでも、変換能力の分からなさだけで、月ごとの通過確率が三倍以上の幅を持つ。

案件ごとの推定が入っても、幅は保つ。

中心だけを推定値へ置き換え、幾何標準偏差 1.65 はそのまま残す。

点推定にすると $c$ についての不確かさが消え、第1章の外側の平均（$B_0$ についての積分）が $c$ の幅を含まなくなる。

母集団の中央値を 1.0 と置くのは、識別のための規約である。

ゲートの所要月数、空席の遅延、$c$ は別々には識別できず、同時に推定する（第12章）。

どれかを固定しなければ、他が決まらない。

### 技術の核の既定

$\psi$ の既定は到達段階で条件づける。

**到達段階**は証拠水準の段階で、T1 前を 0、T1 通過を 1、T2 通過を 2、T3 通過を 3 と数える（全段階の定義は第11章）。

越えたゲートが多い案件ほど、技術の核が立っている事前確率を高く置く。

幅 $\pm0.15$ は段階によらず同じである。

### 自走力の既定

$r$ の既定は三点の離散分布で、上側の裾を持つ。

F1 の会社化前なら、確率 0.25 で 0、0.55 で 60万円、0.20 で 150万円であり、期待値は 63万円／月になる。

会社化後は各値が 4.0 倍で、0、240万円、600万円、期待値 252万円／月である。

確率 0.20 で中央値の 2.5 倍を置くのは、$r$ を中央値の一点で持つと自走力が事実上の上限として働き、会社として製品売上や大型の受託が立つ案件をモデルが一度も生成できなくなるからである。

表の末尾にある年 6240 万円は、F4 の中央値 130 万円に会社化後の 4.0 倍と 12 か月を掛けた額である。

確率 0.20 で置く 2.5 倍の裾まで含めれば年 1 億 5600 万円になるが、いずれも案件ごとの推定で上書きする前提の初期値であり、実際に大きい受託が届く水準は案件ごとに置く。

### 既定の無い成分

$\tau_{\mathrm{proc}}$ は評価者が型を選んで置くので、既定を要しない。

$w_u$、$\bar P_u$、$\delta_u$、$\underline{c}_u$ には既定が無く、案件ごとの調査でしか置けない。

$r$ の案件ごとの値も同様で、表の値は調査より前の初期値にすぎない。

基本設定だけで計算した案件は、天井の値を持たないので、円建てのスコアを出せない。

冒頭の二つの研究室は、基本設定だけで置けば $c$ の分布が同じになり、スコアも同じになる。

差が分布の中心に現れるのは、案件ごとの推定が入ったときである。

## 11. 無風期間の目盛り

費用とアクションの記録が無い案件でも、外から見える動きは観測できる。

第2節の概算はこの動きを材料にする。

**無風期間** $t_q$ は、外から見えるポジティブな動きが最後に観測されてからの月数である。

ポジティブな動きとは、資金調達の成立、製品化、提携、受賞、大型の採択などの公開情報を指す。

登録簿の事象でいえば、ゲート通過、公的資金の採択、民間調達の成立、受託契約、用途の拡張がこれに当たる（第10章）。

ライセンス、M&A、知財売却の申し出の話を取れるかどうかは戦略余力の役割であり、$t_q$ はその鮮度の観測量である。

動きが見えない案件には、引き合いも来にくい。

| 無風期間 $t_q$ | $c$ の概算、$m_q$ |
|---|---:|
| 0か月（直近にポジティブな動きあり） | 1.00 |
| 12か月 | 0.50 |
| 24か月 | 0.10 |
| 36か月以上 | 0.05（下限） |

あいだは区分線形で補間する。

根拠レベルは C である。

区分線形の補間を区間ごとに書き下すと、次のようになる。

| 区間 | 値 | 1か月あたりの減り |
|---|---|---|
| 0〜12か月 | $1.00 - 0.50 \cdot t_q / 12$ | 約 0.042 |
| 12〜24か月 | $0.50 - 0.40 \cdot (t_q - 12) / 12$ | 約 0.033 |
| 24〜36か月 | $0.10 - 0.05 \cdot (t_q - 24) / 12$ | 約 0.004 |
| 36か月以上 | 0.05 | 0 |

最初の一年で半分、二年目でさらに 0.10 まで落ち、そこから先はほとんど動かない。

二年間ポジティブな動きが無い案件は、乗数の上ではほぼ止まった案件として扱われる。

### 二つの用途に同じ線を使う

同じ一本の線を、二つの用途に使う。

一つは、記録の無い案件の $c$ の概算である。

もう一つは、申し出到来率に掛かる乗数 $m_q(t_q)$ である。

価値の多くは申し出の経路から立つので、$c$ を下げるだけでは、伸びが止まった案件の価値は十分に落ちない。

そこで同じ目盛りを、申し出の側にも使う。

$m_q$ が効く先は、申し出到来率 $\nu_k$（第6章）と、自走が続かなくなったときの撤退の四経路のうち、出口クラスの転換（会社化済みかつ証拠水準 4 以上で立つ）とライセンスへの畳み込み（証拠水準 3 以上で立つ）の立ちやすさである（四経路の②と③。第8章）。

動きが見えない案件には、買い手もライセンスの相手も現れにくい。

無風期間が申し出の到来に効く過程そのものは第6章に置く。

### 二重計上の防止

二つの経路に効かせるので、同じ無進捗を $c$ の側で二度数えない規則が要る。

第2節の測り方（移動平均）で $c$ を推定できる案件では、無風期間は乗数 $m_q$ にだけ使い、$c$ の概算には使わない。

無風期間から $c$ を概算した案件では、同じ無進捗を登録簿の経過報告からもう一度 $c$ に効かせない。

経過報告は、評価版の更新時に各ゲートの滞留月数を記録する事象で、通常は $c$ と $\psi$ の推定値の情報になる（第10章）。

無風期間ですでに $c$ を下げた案件で、滞留月数からも $c$ を下げると、同じ止まっている事実を二度数える。

## 12. 八機能の充足の入力口

案件パラメータの表には入っていないが、評価日に案件ごとに受け取る入力がもう一組ある。

担い手の八機能のうち、拡張枠の機能8を除く七つの充足 $f_1$ から $f_7$ である。

八機能の定義と、充足が計算のどこに効くかは第5章に置く。

評価日の充足を、機能ごとに 0 から 1 の値で受け取る。

- $f_1$ は、エバンジェリスト機能が埋まる見込み $e$ の別名である。既存の入力と同じ量を、機能の番号で呼び直したにすぎない。
- $f_2$（技術の核）は既定 1（充足）である。担い手が失われた観測がある案件だけ下げる。指定した案件では、技術の核の担い手の恒久喪失を表す消失率 $\lambda^{\mathrm{core}}$（第7章）を外し、空席は供給過程で埋まらない。同じ喪失を率と状態で二回数えないためである。
- $f_3$ から $f_7$ は、指定した案件では「評価日に確率 $f$ で充足済み、残り $1-f$ が供給過程で埋まる」と読む。供給過程の速さは第5章の $\kappa_{\mathrm{sup}}$ である。
- 省略した機能は、評価日に空席であり供給過程で埋まる、という扱いになる。

充足を判定する本則は、実働の記録を二時点以上要求する（第5章）。

記録の無い案件には本則を適用できないので、明確な観測がある案件と機能だけを指定し、根拠を一件ずつ記録する。

残りは既定のままにし、実働の記録が二時点以上そろった案件から本則へ切り替える。

## 13. 演習

演習では、基本設定と、次の合成事例の値だけを使う。

合成事例（複数の実例を組み合わせて一般化した架空の案件。数値はすべて例示である）：

特殊結晶の育成技術。

工程の型はプロセス型（F1）、規制属性は規制なし。

評価日の観測状態は、T2 通過済みで次は用途α（レーザー部品）の T3。

権利と承認の残件は2件（共同出願の同意が審議中、発明者の兼業承認が未提出）。

会社化前。

大学経由の共同研究1件（月額 60万円、工数 0.2）。

稼働用途なし。

評価日の3か月前に公的資金の採択（2年、使途制限）。

研究者が需要家への技術説明の主体として登壇した記録が、評価日の6か月前と1か月前の二時点にあり、相手方の議事が残っている。

**演習1**

次の五つの量を、観測状態 $x_t$ の成分、案件パラメータ $\theta$ の成分、どちらでもない量に分類せよ。

(a) 自由資金の残高。(b) 変換能力。(c) 用途αの支払上限の証拠の階級。(d) 審査の残り月数。(e) 工程の型。

分類の基準を一文で書いてから答えよ。

方針：観測できる量か、推定で置く量かを基準にする。

(a) は $s^{\mathrm{f}}_t$、(d) は審査の残り月数 $\varsigma_t$ で、どちらも観測状態の成分である（資金の残り月数は導出量であり、(d) とは別の量）。

(b) は $\theta$ の成分 $c$ である。

(c) は階級が登録簿の事象で動くが、支払上限 $w_u$ そのものは $\theta$ の成分である。

(e) は型を選んで置く $\theta$ の成分である。

「どちらでもない量」に当たるものは、この五つの中には無い。

採点観点：「観測できるか、推定で置くか」を基準に置いているか。

(c) について、階級と支払上限の値を分けて述べているか。

(e) について、分類で置く成分が $\theta$ に入る理由（他の量の事前分布の源になる）に触れているか。

**演習2**

ある案件の最後のポジティブな動きが、評価日の 18 か月前であった。

無風期間の目盛りから $m_q$ を求めよ。

次に、6 か月前、30 か月前、40 か月前であった場合の $m_q$ を求めよ。

最後に、この案件に費用とアクションの記録があり、第2節の移動平均で $c$ を推定できるとき、無風期間は $c$ と $m_q$ のどちらに使うかを述べよ。

方針：12 か月の 0.50 と 24 か月の 0.10 を区分線形で補間すると、18 か月では 0.30 になる。

6 か月では 0.75、30 か月では 0.075、40 か月では下限の 0.05 である。

記録がある案件では、無風期間は $m_q$ にだけ使う。

採点観点：区間ごとの補間を正しく行い、36 か月以上で下限に張り付くことを述べているか。

二重計上の防止の規則を、「同じ無進捗を $c$ の側で二度数えない」という理由とともに述べているか。

**演習3**

基本設定の下で、プロセス型（F1）の会社化前の自走力 $r$ の三点分布を書き出し、その期待値を求めよ。

次に、会社化後の三点分布と期待値を求めよ。

最後に、この三点分布を中央値の一点に置き換えたとき、モデルが生成できなくなるシナリオを述べよ。

会社化後は各値が 4.0 倍で、0、240万円、600万円。

期待値は 252万円／月である。

一点に置き換えると上側の裾が消え、会社として製品売上や大型の受託が立つ案件を、モデルが一度も生成できなくなる。

採点観点：三点分布の値と確率を正しく対応づけているか。

一点化で失われるシナリオを、「自走力が事実上の上限として働く」という性質から説明しているか。

**演習4**

次に、$\kappa_{\mathrm{IP}}$ の既定の表の四区分（出願なし、単独出願済み、登録済みかつ FTO 確認済み、請求範囲が狭い）のうち、合成事例の権利の状態（共同出願の同意が審議中）に当たる区分があるかを検討し、当たる区分が無いなら何が定義されていないかを述べよ。

**演習5**

二つの案件がある。

案件Aは最初の一年で大きく前進し、その後の二年間は止まっている。

案件Bは三年間ゆっくり前進を続けている。

設立前に獲得した資金を額のまま数えていないか。

**演習6**

**演習7**

第10節の $c$ の既定を使い、$c$ の 10%点、中央値、90%点のそれぞれで、第4章の F1 の T3（基準速度 $1/17$）の、最短準備期間が過ぎたあとの月ごとの通過確率を求めよ。
