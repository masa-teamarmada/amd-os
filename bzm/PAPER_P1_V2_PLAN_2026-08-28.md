## 1. 旗艦主張（一撃）

法人設立前（Before Zero）のディープテック案件の選別を、私的リターン（企業価値・投資収益）ではなく
**産業創出価値**——その案件が国内に生む付加価値の**純増**の割引現在価値——で行う。
純増は二つを差し引いた量である。(1) 国内の既存事業が置き換えられて消える分、
(2) この案件が無くても他者が実現していた分（反実仮想の控除。前倒し期間と国内立地差だけが貢献に残る）。

これは、プログラム評価（公的R&Dの社会便益計算）の作法——純増・反実仮想・社会的割引率——を、
**事後のプログラム単位の評価から、案件単位の事前選別へ**移すことを意味する。

## 2. 新規性主張（監査対象。どれが立つかの判定を監査に求める）

- **N1**: 社会的価値（国内付加価値の純増、反実仮想控除つき）を**案件単位の事前選別**の目的関数に置いた
  体系的枠組みは、本枠組みが最初である。近傍: Link & Scott 2011（プログラム評価）、
  DOE 系 prospective benefits analysis（プログラム単位）、費用便益分析のプロジェクト選択応用。
  「最初」が立たない場合は「法人設立前・案件単位・EXIT非依存・反実仮想控除の組み合わせ」で新規性を主張する。
- **N2**: 法人格・財務諸表・確定した経営チーム・生存標本のいずれも欠く対象を、
  **月次の観測状態**（ゲート位置・円建て二勘定の資金・権利残件・受託拘束・稼働用途・履歴）として表現し、
  **登録された計画規則**（観測できる出来事だけに条件づけた分岐。案件パラメータには条件づけない）の下で
  評価する観測系は新しい。評価対象は案件そのものではなく「登録された計画」である。
- **N3**: EXIT 形態非依存の測定。9区分（期限内資本自立／期限後資本自立／ライセンス／M&A／知財売却／
  ピボット／撤退／清算／未決着）を同じ物差し（産業創出価値）で測ることで、
  ユニコーン型 EXIT だけを成功と数える選別からの転換を可能にする。

## 3. 貢献3点（論文の構成上の宣言）

1. **N1「最初」は棄却**（3体一致）。反例: 開発経済学の社会的費用便益分析（Little–Mirrlees 1974、UNIDO 1972、世銀）、
   米ATPの but-for 条件つき案件選定、医療技術評価の EVPI/EVSI（V=∫E[Π|θ]dB_0 と数学的に同型）、
   SROI の forecast モード（deadweight=α・displacement=δ・attribution=φ・drop-off=λ と控除構造が同型）、
   Mansfield et al. 1977（案件単位・小標本・社会的収益）。この分野の確立語は **additionality（追加性）**。
   → 主張文は最初から「移す」で書く: *事後・プログラム単位の追加性評価の作法を、法人が存在しない案件単位の事前選別へ移す*。
2. **新規性の重心は N2 へ**（3体一致）。ただし N2 の新しさは形式（動学構造推定・段階投資と同型）ではなく
   **「評価対象を案件ではなく〈登録された計画〉に置き換える」という宣言の側**に絞る（経営学者）。
   N3 は独立の貢献から外し、枠組みが可能にすることとして書く（政策的訴求は最強なので §8 の主役にする）。
3. **§7 の標本矛盾**（経営・戦略が独立指摘）: 21件中 **15件が会社化済み**で、「Before Zero＝法人化まで」の
   領域宣言と標本が矛盾。→ 層別（未会社化6件＝Before Zero 適用例／会社化済みは評価日を過去に固定した遡及評価に
   組み直すか、落とす）＋**入力の凍結日を明記**（天井が 8/26 TAM→SOM、8/28 SOM→SAM と動いた事実も感度の主結果として開示）。

   「記録は進んだことを記録し、進まない理由を記録しない」——較正前係数と無関係に成立する検証可能な発見。
   §7 の核をモデルの妥当性からこの**情報の十分性**へ移し、可能なら21件×2回（記録のみ／記録＋聞き取り）の比の分布を出す。

### 10.3 対立点と解消

- **呼称**: 経済学者は「社会的価値（social value）」の語自体を棄却（消費者余剰を測らない量を social value と
  呼べば category error。Nordhaus 2004）。戦略は「社会的価値ベースの一撃は保ってよい（『最初』さえ書かなければ）」。
  → 解消: 日本語は従来どおり**産業創出価値**、英語は *industrial value creation / net domestic value added* を主語にし、
  *social value / welfare* を名乗らない。厚生指標ではなく**産業政策の目的関数**と自己規定する（経済学者の修正案1）。
  加速分（世界でも純増）と立地分（他国からの移転）の2数併記で beggar-thy-neighbor 批判も受ける。
- **N2 の評価**: 戦略「査読者が新しいと認めやすい」vs 経営「形式は標準形で新しくない」。
  → 解消: 主張文を「宣言の側」（評価対象の定義の変更）に絞る（10.1-2 のとおり）。

### 10.4 まさ判断点（4つ）

1. **旗艦の言い換えの承認**: 「最初」を降ろし「追加性評価の作法を Before Zero の案件単位事前選別へ移す」＋
   重心を N2（登録された計画を評価対象にする）へ。英語で social value を名乗らない。
2. **モデル本体への反例 M-1（φ_u）・M-2（費用項）の扱い**: (a) モデル改訂提案を起こす（承認手続き＋再計算が要る）
   か、(b) モデルは変えず論文は限定定義＋両建て報告で書くか。M-1 は「産業創出価値の定義の意図」
   （案件系の実現分か、模倣者を含む誘発産業全体か）というまさの価値判断に依存する。
3. **匿名化**: 方式の記述で案件が同定可能（type×規制属性では匿名化にならない）。
   (a) 関係者の書面同意を取る、(b) 方式・工程の記述を落とし分布＋統計のみにする、の二択。
4. **投稿先**: 第1候補 **Journal of Technology Transfer**（Link & Scott 2011 を明示的土台に、additionality の語彙で書く）、
   第2 Research Evaluation、第3 Science and Public Policy。**Research Policy は前向き登録簿が走った後の第2報へ温存**。
   旧 PF-013 の「RP 旗艦」戦略の変更に当たるため、まさの確認が要る。
