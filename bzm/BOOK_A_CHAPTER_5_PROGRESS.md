**5.1 成熟度を段階で測る——TRL から五つの視点へ** (1,400字)
礼法宣言 (第1-3章と同作法 — 批判でなく、それぞれの射程を敬意をもって確認する) から入る。(1) NASA が宇宙技術の成熟度管理のため 1990年代に体系化した TRL (Mankins 1995): 0〜9 の段階、いまや世界の研究開発の共通言語。骨格を prose で提示 (詳細な段階の意味は 5.3 の表5-3 に集約し、ここは表を置かず身軽に)。(2) 内閣府 SIP が研究開発の成熟度を測る「5つの視点」として TRL/BRL/GRL/SRL/HRL を並列に立てた枠組み: 本書の五軸の直接の源であり、**本書はこれに準拠する** — 五軸は本書の発明ではなく、公的な研究開発評価の現場で実際に使われる物差し = 読者が支援機関・行政と話すときの共通言語 (SRL は欧州 Horizon Europe でも使われる軸、と一言)。(3) KTH Innovation Readiness Level: 技術以外の複数 readiness を束ねて測る系譜。(4) Blank の顧客開発・Ries の MVP 検証: 事業側の準備を「作って測って学ぶ」で刻む発想 (第1章 1.1 の地図の回収、のちの BRL の系譜)。表5-1 = 標準 readiness 指標の射程 (指標 / 測るもの / 前提とする存在・データ / 射程) — 第3章表3-1 と同型。締め: どの指標も射程の内側では最良。面談の三者の問いは、実はこの五つの視点に対応していた、と軽く示唆。ただし現場では、この五枚が「TRL は 5 です」という一枚の数字に畳まれてしまう——次節へ。

**5.2 「TRL は 5 です」が隠すもの——単一の数字は律速を語らない** (1,200字)
単一スカラー運用が二つの情報を潰すことを示す短い蝶番節 (図表なし・意図的に薄く)。**第一の圧縮 = どの視点 (軸) の 5 か**: 技術が 7 でも事業は 2 という凸凹が一つの数字に丸められる。冒頭の准教授の「できています」は技術の軸 (それも研究室の) だけを語り、残る四枚 (事業・制度・社会受容・人材) について何も言っていなかった。**第二の圧縮 = どの応用 × どの組織の 5 か**: 「研究室で作れる」と「自社で作れる」は別の TRL なのに、単一の数字はこの差を消す (暗黙知・場所・人が変われば動かなくなるのは技術移転の標準的な初期条件、と一言だけ先取り)。第3章 3.3 の壁③「単一の値は、律速を隠す」の到達度における具体形だと明示的にコールバック (律速の語は第3章 3.3 で定義済み・第1章 1.4 の「弱い因子が全体を強く引きずり下げる」と接続)。単一化は悪意ではなく構造の罠 — 准教授は自分の物差しでの正直な評価だった。therefore の二方向を予告: 軸へ割る (5.3)、セルへ割る (5.4)、そして主張ではなく観測で刻む。

**5.3 主張ではなく観測で刻む——五軸 XRL と Yes/No の物差し** (1,900字)
R の位置づけを冒頭1文で固定: 第1章 1.4 の PRS_t = P_t × R_t × S_t の R_t の中身を本章で開く (五軸を一つの数字へ束ねる統合は第9章、本章は R の構造 = 五軸プロファイルと律速の読みを作る)。R の最重要性質 = **不可逆な達成のストック** だと予告 (正面から扱うのは 5.7)。直感: 「できている」を五枚の独立した物差しに割る。式(i): 五軸ベクトル **R = (TRL, BRL, GRL, SRL, HRL)**、各軸 0〜9。XRL の語は「五軸の総称」の記法として一度だけ導入し、**prose 基調は「五軸」「五つの物差し」** (頭字語の連呼で第1-3章の語りの温度を下げない)。表5-2 (五軸対応表: 軸 / 名前 / 測るもの / 面談での問い — 作れるか・売れるか・通るか・受け入れられるか・担えるか)、図5-1 (五枚に割れる図)、表5-3 (0〜9 の共通4帯: 0 不在 / 1-3 初期 / 4-6 中期 / 7-9 成熟。**BRL 以下の 9 段階は TRL ほど正準化されていないため、共通4帯 + 観測項目で運用すると正直に一言**)。式(ii): rubric 分解。段階評価は評定者間でブレる (同じ対象に楽観は 6・慎重は 3、自己評価は高く・外部審査は低く出る)。各段階を **Yes/No で答えられる観測項目** に分解する: 例リスト (ラボで原理検証ができている / 再現手順が発明者以外でも実行できる水準で文書化されている / 事業主体が自らの設備と人員で再現製造した実績がある / 顧客から対価を得た検証がある / 該当する規制の関門を特定し当局・認証機関との対話を開始している)。XRL_k = 観測項目の Yes がどこまで付いたかから機械的に決める (段階ごとに何本の Yes が要るかの閾値は校正の手続きの話として採用値非公開 = PF-010 準拠の設計)。worked example: 分離膜の TRL を准教授は 6、技術者は 3 と読んだ対立が、「事業主体が自社設備で再現製造した実績があるか——No」の一項目で機械的に決着する様 (架空)。二つの効用: ①ブレを潰す (証拠 = 契約・請求・報告書を示せる Yes だけを数える) ②**No の項目がそのまま次の一手のリストになる** (「TRL は 4」は行動を教えないが「文書化が No」は来月の仕事を指す)。演習5-1 の二段設計 (素採点 → rubric 再採点) がこの節の実地版だと一文予告。橋: 五枚のうち最も古く、最も事故が多い TRL を、次節で応用×組織に開く。

**5.4 研究室で作れる≠自社で作れる——応用×組織のマトリクスと有効 TRL** (2,150字)
5.2 の第二の圧縮を正面から解く章の心臓 (最厚)。直感: 同じ技術でも、どの応用 × どの組織で作るかで TRL は別物。応用側 — 実験用の小型モジュールとプラント用の大型モジュールでは要求条件 (耐久性・寸法・品質保証) が違う。ある応用で 6 でも本命の応用では 3 は普通に起きる。組織側 (本章でいちばん強調する点) — 研究室には、その技術と一緒に育った装置があり、論文に書かれない調整の勘どころがあり、「彼がやると歩留まりがいい」学生がいる。暗黙知の上で動く技術は、場所と人を変えた瞬間に動かなくなる——研究室での TRL が 5 でも、事業主体にとっての TRL は 0 から始まるのが技術移転の標準的な初期条件。式: 行 = 応用 (本命用途・隣接用途…)、列 = 組織 (発明者の研究室・事業主体・製造委託先…) のマトリクス。**二段導入**: まず (a, o) の二次元でマトリクスを導入 → 「各セルの値は時点 t とともに動くスナップショット (第1章の R_t と同じ)」と一文で t 添字を付し TRL(a, o, t) と書く (三添字を最初から見せない)。事業として意味のある TRL は**事業計画が依存するセルの最小値**:
$$\mathrm{TRL}_{\text{有効}}(t) = \min_{(a,\,o)\ \in\ \text{事業計画が依存するセル}} \mathrm{TRL}(a, o, t)$$
「鎖の強さは一番弱い輪で決まる」。記法注記: 「有効」は「事業が実際に直面する値」の意 (申し送り論点1)。図5-2 (マトリクス図: 研究室列だけ高く事業主体列がほぼゼロの非対称を濃淡で)、表5-4 (分離膜の worked example: 本命×研究室 = 5、本命×自社 = 1、本命×委託先 = 2 などすべて架空値。依存セル = 本命×自社 → TRL_有効 = 1)。読み: 論文・受賞・ピッチ資料の TRL はたいてい研究室セルの値で書かれる (嘘ではない)。しかし本命用途を自社製造して売る計画なら、見るべきセルは本命×自社。**研究室セルと自社セルのギャップの放置は、研究開発型プロジェクトの長期停滞の最も典型的な原因** (「書面上の成熟度は悪くないから資金調達は通るのに、顧客のサンプル請求ひとつ満たせない」型 — 一般型として1〜2文、独立ケース化しない [引き継ぎ規律参照])。希望の側面: TRL は五軸の中で外から借りやすい軸 (製造委託・技術導入・共同開発で他組織のセルを借りる設計はあり得る)。ただし依存セルが委託先列に移るだけで min の原則は不変。委託への依存が生む交渉上の弱みは、戦略余力の話として第8章へ (一言)。締め: 到達目標の「研究室で作れる≠自社で作れるを定量的に区別できる」は、研究室セルと自社セルの二つの値の差として、これで言えるようになった。

**5.5 残る四枚の勘どころ——検証・遅効・受容・担い手** (1,800字)
前置き1文: TRL と同じ深さで四枚を開く紙幅はないが、各軸「現場でまず見る一点」を押さえれば採点は始められる (詳細は表5-5 と演習の観測項目へ)。**BRL**: TRL と独立に動く (TRL 7 で BRL 2 も、その逆もある — 面談で技術者と VC が別々の質問をしたのは、この二軸が別物だから)。検証段階で最も重い観測項目 = 「顧客から対価を得た検証があるか」——無償と有償では情報の質が違う (相手の社内で誰かが稟議を書き、予算を確保し、評価の責任を持ったという事実を映す)。有償の検証が余力の補充でもある面は第8章に一言前方参照 (本節では達成 = R の側面に留める)。**GRL**: 効果が遅効的 (動き始めてから効くまで年単位)。初期の核心は「該当する規制を特定したか」——多くのプロジェクトは規制対応が遅れているのではなく、どの規制が該当するかを調べ始めていない。特定は金でなく注意のコスト (面談で URA が一人気にしていた保安認証と化学物質届出は、この「特定」の問いだった)。**SRL**: マクロの追い風と社会受容は別物。追い風 = 作り手と出し手 (政策・産業・研究) の側の話、受容 = 使い手と世論の側の話。1990年代欧州の遺伝子組換え食品 (追い風は強かったが消費者が受け入れず、市場から拒絶される形で事業化が失敗) を 2〜3 文の例で。初期の観測点 = 想定される反対の構図を言語化できているか。追い風そのものの測り方は第7章の主題と前方参照。**HRL**: 見るのは肩書きの揃いではなくチームの補完性と属人性の解消。「彼がやると歩留まりがいい」という状態は、外から見れば模倣されにくさ = 参入障壁、内から見れば事業の継続性が一人の進路に依存する低さ——**両義性の一般論としてここに置く (学生修了の事実はまだ出さない)**。創業者個人の資質・リーダーシップは HRL に含めない = 生存を扱う第6章の領土 (「チームは揃っているが創業者が決められない」と「創業者は傑出しているがチームがいない」は別の病気、の一文)。Box 5-1: GRL と SRL の両義性——到達度の蓄積であると同時に、外部環境への働きかけでもある (規制対応 = 環境を事業が通れる形に変えていく活動 / 受容 = 待つのではなく形成する活動。働きかけの履歴は消えない達成として積む)。表5-5 (四軸の初期チェック観測項目)。橋: 五枚が出揃った。ではこの五枚を、どう読み合わせるか。

**5.6 平均は凹みを隠す——ボトルネックギャップ G と律速の発見** (1,550字)
直感: 五枚は平均で読んではいけない。四枚が立派でも一枚がゼロに近ければ、事業はその一枚のところで止まる (到達度は事業の成立に掛け算的に効く——第1章 1.4・第3章 3.6 の乗法の読みと同じ構造)。**平均は凹みを隠す統計量**。前処理の明示: 各軸をまず有効値に還元する (TRL は TRL_有効、他の軸も事業が依存する範囲で読む)——この五つの値を並べたものが、その案件の到達度プロファイル。式 (本章の新規定式化 = 数式アイテム4):
$$\text{律速軸} = \operatorname*{argmin}_k \mathrm{XRL}_k(t), \qquad G(t) = \max_k \mathrm{XRL}_k(t) - \min_k \mathrm{XRL}_k(t)$$
**混同回避の注記を必置**: 5.4 の min (マトリクスのセル間 = 一つの軸の中) と本節の min (五軸の間) は別の演算。セルの min がその軸の実力 (有効値) を決め、軸間の min が次に手を打つ軸を指す。worked example (架空・有効値): TRL_有効 = 1、BRL = 2、GRL = 1、SRL = 5、HRL = 2 → 律速 = TRL と GRL、max = SRL、G = 4。図5-3 (新規・本章の看板図版: 五軸の棒 + min/max + G のブラケット + 誤導的な平均線)。読み: G 大 = プロファイルが凸凹 = 最も高い軸への過投資と律速軸の放置の警告 (研究室発の典型型 — 「技術をさらに磨きましょう」はいちばん高い軸をさらに伸ばす提案)。G 小・全軸低 = まんべんなく未成熟という別の診断。平均はどちらも同じに見せる。二つの補正 (定性、r-readiness の記述を踏襲): ①重要度の差 — 人材の不在は他のすべての軸の進行を止めるため重く、社会受容は事業領域により軽い (SRL = 5 は高いが、軽い軸の高さが G を見かけ上大きくすることもある、と正直に) ②時定数の差 — TRL/BRL は月・四半期で動くが GRL は年単位 = 「まだ低くていい」ではなく「いま動かないと、他の軸が揃った頃に間に合わない」。重みを使って律速を機械的に導く手続きは第9章で式になる。本章は定性補正 + G(t) まで、と明示的に線引き (後章記号の越境なし)。橋: 律速が見えた。ではこの「達成」は、使えば減る手元の資源と、何が違うのか。

**5.7 減らない達成と、使えば減る資源——R と戦略余力の線引き** (1,500字)
5.3 で予告した R の不可逆性を正面から扱う。この先の章で、プロジェクトの状態を「到達度 × 戦略余力」の平面で読む道具が登場する (第8章)——その地図が機能するためには、どの資産を R 側に数え、どれを余力側に数えるかが曖昧であってはならない。原則を一文で: **一度獲得したら消費されないものが R、使えば減る資源が戦略余力 y**。式 (単調性): R の各成分は時間と使用について非減少 — t₂ > t₁ ならば R(t₂) ≥ R(t₁) (各軸・各セル)。取得済みの実験データ・登録された特許・完了した検証・取得した承認は、使っても十年後もそこにある。y は増減する (現金・交渉の選択肢・時間的な先行)。分類基準の一問: 「使うと、あるいは時が経つと、減るか」—— No → R、Yes → y。同じ資産が両方の顔を持つ場合が面白い: 表5-6 (特許 / 実験データ / 認証・承認 / 顧客との関係 × R 側面・y 側面)。特許は「登録という達成 = 存在」が R、「残存する独占期間と抑止力」が y。図5-4 (一件の特許を左右に分解: 左 = 減らない階段、右 = 減っていくゲージ)。読み: 「うちには特許がある」の一言が達成の報告か余力の主張か判別できないと、議論が噛み合わない — 登録から年数の経った特許を「資産がある」と数え続けながら、独占期間が尽きかけていることを誰も口にしない、という自己欺瞞への簡単な防御。線引きの意義2点: ①二重計上を防ぐ (R でも y でも満額で数えると、事業は実際より頑健に見える) ②地図の軸の独立性を保つ (横軸 = 不可逆で右に進む一方、縦軸 = 増減する。混ぜると地図が濁る)。Box 5-2: 境界事例——チームに蓄積した経験は、不可逆な達成 (人は学んだことを忘れない) のようでいて、人が辞めれば失われる資源でもある。分析の単位で見え方が変わる: 個人の単位では R 的、組織の単位では y 的。**文書化・移転とは、一人の頭の中の y 的な知識を、組織の R 的なストックへ変換する操作**——5.4 の自社セルの空白・5.5 の HRL の属人性と、同じ一つの結び目。原則を固定し、境界は実際の案件で磨く (モデルの限界の扱いは第15章)。y の消費・補充・交換レートの勘定は第8章の主題と前方参照 (τ 等の後章記号は本文に出さない)。橋: 道具が出そろった。切ったままの面談に戻る。

**5.8 数日後に返ってきた言葉——面談は、どのセルで止まっていたか** (1,450字)
章頭で切った面談の B面。数日後、URA が各者に感触を聞いて回ると、返ってきた言葉は静かだった: 技術者「技術は面白いです。ただ、うちのラインで作れるかどうかは、まったく別の問題ですから」。VC「研究としては素晴らしいと思います。事業としては、これからですね」。誰も嘘をつかず、面談は成功のように終わり、しかし何も動かない。**温存事実の開示**: URA の頭に残っていた「彼がやると歩留まりがいい」——その学生は、来年の春に修了する。本章の道具で面談を読み直す: 五枚で見れば、技術の軸だけが高く (それも研究室セルの値)、BRL は仮説段階、GRL は未着手 (URA だけが「特定」の問いを立てていた)、HRL は実質一人。TRL_有効 = 本命×自社セル ≈ 0。G 大の典型的な研究室発プロファイル。学生の修了は、暗黙知 (失われうる y 的な知識) が文書化 (R 化) される前に去るという時限——HRL と自社セルが同時に落ちる。**第3章との縦接続**: 第3章の配分会議で「大きいが、未成熟」= P 高・R 低と読んだあの断熱素材——あのとき「R 低」としか言えなかった内訳を、いまなら五枚とセルで名指しできる (「自分たちの手で作れる技術への翻訳」とは、自社セルを埋める作業のこと)。討議課題A の答え合わせ: ①評価メモに書くべきは、単一の数字ではなく五枚のプロファイル + 依存セル + No の観測項目 ②誰も嘘をついていない——三人は別々の枚を正しく測っていた。「できています」は研究室セルの技術一枚のことだった ③評価を最も変える一つの事実 = 学生の修了 (暗黙知の行き先)——これが分かった瞬間、次の一手 (文書化・後任への移転・本人の事業参画のどれか) に期限が付く。助言の型: 「技術をさらに磨きましょう」はいちばん高い軸をさらに伸ばす提案であり、ほとんどの場合、的を外している。律速セル (自社での再現製造) を最優先マイルストーンに据えること。教室で評価が割れること自体が教材、の一言。橋: その律速を、演習で自分の手で名指しする。

## 申し送り (ステージ2 の判断論点)

1. **有効 TRL の記法 (3 persona 一致で flag)**: min 演算の結果を「TRL_有効」(日本語添字、r-readiness 原文踏襲) と書くか、「TRL_SU」等のラテン添字にするか。**推奨 = TRL_有効**。理由: (a) 「有効」は「事業が実際に直面する値」という min 演算の意味を直接名指す (b) SU 添字は意味的に不正確 — 律速セルは自社でなく委託先列のこともある (理論家) (c) σ_SU (第7章) は実体 (主体) を指す添字、「有効」は操作結果 (性質) を指す添字で種類が違うため、混在は記法規律違反にならない。全書ラテン統一が後で必要になれば TRL_eff を次善とし、glossary に対応を書く
2. **章頭ケースとシーズカード No.1 の関係 (persona 間で対立)**: 章頭の面談のシーズ (ガス分離膜) を演習カード No.1 (多孔質セラミック分離膜) と同一化するか、別シーズのまま保つか。**推奨 = 別シーズ維持 + 混同回避の一文** (「演習で使うシーズカード No.1 とも別のシーズ」を composite 宣言に追加)。理由: (a) 第1-3章で「章頭ケースは互いに、また演習素材と、別の合成事例」という宣言型が確立済み (b) 同一化すると B面の帰結 (自社セル≈0・学生修了) が演習5-1 の「正解」を先に与え、評定者間ブレの計測が汚染される (c) 両者とも分離膜で紛らわしいため、宣言の一文だけ強化する
3. **節数 10節 (5.0〜5.9)**: 第1章 8節・第2章 9節・第3章 9節に対し本章は 10節。**推奨 = 10節のまま**。理由: 数式アイテム 4点 + 五軸の情報量は第I部より多く、「一節 = 一概念」の分割が 90分授業の消化可能性を保つ (教員)。帯域は 16,300字設計で守られており、節数が増えても分量は増えていない
4. **G(t) の定義水位**: 有効値上・無重みの max−min + 律速軸 argmin 併記、重要度・時定数は定性補正に留め、重み付き律速診断は第9章送り。**推奨 = この水位** (worked example に「軽い軸 SRL の高さが G を見かけ上大きくする」罠を一例入れ、重みの必要性を第9章への布石にする)
5. **討議5-3 (R と戦略余力の棚卸し) の追加**: L1 の演習仕様 (2段階採点 + 90日計画) にない第3の演習。**推奨 = 追加する**。理由: 数式アイテム3 (R vs y) に対応する演習がないと、第3章型の「道具と演習の一対一対応」が崩れる。教室内 15〜20分の軽い討議で、第8章への布石を兼ねる
