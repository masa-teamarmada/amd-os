## 案A「締切の十七時」 — 公募様式が三つの判断を先に決めていた (推奨)

**一行定義: 誰も「いつやるか」を選んでいない——公募のカレンダーが選んでいた、ことに誰も気づかない話。**

### あらすじ

六月最後の金曜、午後二時。産学連携本部の小会議室。実証支援事業の公募締切が、今日の十七時 (電子申請) に迫っている。URA二年目の深津にとって、三週間かけた初の単独案件の申請書 — 十二枚の力作である。先週の企業面談の手応えで「連携見込み」も書き足せた。残るのは機関承認の最終確認だけ、のはずだった。

出席は四人: 深津 (URA)、研究者 (材料系の准教授)、知財担当の大隅 (機関承認の確認で同席)、産学連携本部の係長 (承認手続きの担当)。確認は形式的に、なごやかに始まる — 全員が「出す」前提でいる。

大隅の指が、三つの欄で順に止まる:

1. **「技術の優位性」欄** — 投稿準備中の論文の中核データ (いちばんきれいに出たグラフ)。大隅「この様式、採択されると概要が公表されますが——この図のもとになった出願は、もう済んでいますか」。研究者「……投稿と一緒に、と思って、まだ」。出願前の核心が、外部有識者の審査と採択時公表に向かって開こうとしている (**開示**)。
2. **「連携企業・顧客候補」欄** — 「A社より検証の打診あり」。先週の面談の、深津の解釈が混ざった一行。大隅「これは、先方が言ったことですか。それとも、こちらの解釈ですか」(現行台詞をこの欄の上で発話 — 一文テストの由来を保存)。
3. **「事業化体制」欄** — 「今年度中に法人設立予定 (代表者: 研究代表者が就任予定)」。研究者が、初めてその行に気づく。「私が、代表に?」— 誰も決めていない。係長は善意で言う: 例年この欄は具体的に書く、空欄では審査に乗らない (**設立とCEO**)。

直せば、審査に通らないかもしれない。出さなければ、次の公募は来年度 — 来月のA社の検討会に「採択」を持っていけない。全員の理由が正しく、誰の悪意もない。**この申請を今日出すと、誰がいつ決めたのか——誰も決めていない。締切が決めていた。**

幕: 修正して間に合うのは、一枚か二枚。壁の時計は十六時前。提出画面を開いたまま、深津は三人を見る — **未決**。

### 設計

- **装置 (一章一装置)**: 一枚の様式と三つの欄 — 開示・設立・CEO という三つの「いつ」が、他人のカレンダーの上で同じ一枚に圧縮されている。§8 備考「三つの判断はタイミング問題の三つの現れとして束ねる」を紙一枚の絵で実装。
- **季節・主調音・幕**: 六月・雨 (六月末締切は現実整合) / 緊迫 (締切まで三時間→一時間のカウントダウン) / 未決 — 設計表 Ch2 行の骨は維持。
- **橋1→2**: 「誰も止めなかった四十分」→「止まった午後」。止めたのは大隅の一問。
- **読者誘導**: 前半 =「力作がついに出る日」の達成感 (語り手のヒントゼロ) → 大隅の一問から一枚ずつ傾く → 「紙が三つのことを先に決めていた」は最後まで誰も言語化しない (読者だけに見える)。討議課題で「様式のどの欄が、本来いつ決めるべきことを、いつに引き寄せていたか」に読者自身が気づく。
- **理論との響き**: 理論 2.7 は既に「第1章の会社は τ_B を外部の時計——公募の締切——に明け渡した」と書いている。案Aは同じモチーフを章頭に立てるため、Ch1 (助成金締切から逆算した設立日程) → Ch2 章頭 → 2.7 回収が同一線上に乗る。2.3 効き所③「締切に合わせて動くとは、自分の計画の時計を外部のカレンダーに預けること」の直接の物語化。
- **実話の根**: EP-027 (制度が先生を起業家に仕立てる — 二次審査で先生本人にプレゼンさせる局所最適の合成) の紙版 = 「代表者: 研究代表者」を様式が強制する。EP-006 (追い風と締切に押された設立)。変装 L0〜L1。
- **移植できる現行台詞**: 「これは、相手が言ったことですか。それとも、こちらの解釈ですか」(一字不変で生存) / 「どうせなら、いちばんきれいなのを」(中間報告の回想で生存可) / 「作るなら、作る日に結んでおく紙が〜」(設立予定欄の流れで大隅の独り言として生存可) — 理論が直接引用する台詞は新場面でも生きる。
- **人物**: 深津 (ふかつ、URA二年目) / 大隅 (おおすみ、知財) / 研究者 / 係長 — 既存キャストと重複なし。湯浅・桐山は現行骨格 (案C) と共に降格。

## 案D「動いた時計」 — 相手の予算が前倒しになった週

**一行定義: 相手の時計が一つ動いただけで、こちらの計画の順序が全部玉突きされる話。**

- **あらすじ概要**: 六月の雨の週。連携候補の企業から連絡 — 「予算編成が前倒しになり、新規テーマの検討会が来週に繰り上がった。技術資料を今週中にいただけないか」。願ってもない好機、ただし当初の計画では出願 → 開示の順だった。会議で「間に合わせるために何を飛ばすか」が並ぶ — 出願を待たずに送るか / NDAを大急ぎで結んで済ませるか / いっそ登記を先にして会社名義で受けるか。飛ばす候補が、ぜんぶ取り返しのつかない類のものである。幕: 未決。
- **装置**: 動いた時計 (他人の時計の変針が、自分の計画を玉突きする)。
- **命題カバー**: 開示・設立は正面、CEO は乗らない。「誰の時計で」は直撃。
- **理論側改修**: 討議課題A・2.7 は全面書き換え (高)。2.4 の三色の印・一文テストの由来場面をどう作るかに一工夫要る (中〜高)。2.2 四人の対応 (中)。
- **評価**: 命題直撃度は案Aに並ぶが、三判断のうちCEOが乗らない分、§8 備考「三つの現れとして束ねる」への応答は案Aに劣る。

## 案B「一年後の六月」 — 遅すぎた側から (参考・相性低)

- **あらすじ概要**: 一年前に「もう少し様子を見ましょう」— 条件を何も決めない待ち — で閉じた案件を、支援者が一年ぶりに訪ねる六月。企業の担当者は異動し、翌年度予算のテーマは他に決まり、学生は修了し、教授の熱は次のテーマに移っている。何も壊れていないのに、去年たしかにあった機会だけが、部屋のどこにもない。
- **命題カバー**: 「遅すぎても取り返しがつかない」を唯一正面から撃てる。条件なきWAITの帰結 = 2.6 WAIT三部品の必要性を裏から照らす。
- **評価 (正直に)**: 開示素材がゼロで理論 2.4 (本章理論の最大の節) への場面供給を失い、主調音も緊迫→喪失に変わる — 理論・設計表の改修コストが最大なのにカバー範囲が狭い。この素材の適所はむしろ 2.6 の WAIT 挿話か演習2-4 の注記側。**新案としては非推奨**だが、「遅すぎ側」を検討した記録として残す。

## 案C 現行骨格「送信予約まで十七分」 — 降格済みの候補

- 現行場面 (湯浅・桐山・17分・シール・登記提案) のまま、地の文全文書き下ろし + 時間構造再設計 (「いま」起点・回想を十七分内へ・時刻刻印4点) をした版 = 旧v3 稿。理論側改修コストほぼゼロ。
- **弱点 (命題から見て)**: 三判断のうち開示しか正面になく (登記は脇、CEOは一句のみ)、場面で鳴る他人の時計も「月初の検討会」一つ。命題「三つの現れ」「誰の時計で」のカバー率が新案より低い。
- 本文стは旧v3稿として保存済み (このファイルの git 履歴 `2026-07-13` 参照)。
