# BZM 3.0教科書 第5章 — 担い手の八機能と充足係数

「この案件には CEO がいない」。

研究室の案件を前にして、投資家や支援者がまず口にする評価はこれである。

研究者が一人で研究も説明も交渉もしている案件は、経営陣が揃った案件より弱いのだろうか。

本モデルは、この問いに肩書の有無で答えない。

経営チームが持つべき働きを八つの機能に分け、それぞれが誰かによって実際に担われているかを、実働の記録で判定する。

名刺に CEO と書いてあっても、対外説明の主体になった記録が無ければ、その機能は空席である。

研究者が需要家の前で、直近12か月に三か月以上あけて二度説明の主体に立ち、相手側の議事録が残っていれば、肩書が無くてもその機能は埋まっている。

そして空席は、スコアから一定の点を引く減点ではなく、前へ進む速さを落とす遅延として式に入る。

評価日に席が空いていても、点を引くことはしない。

空席は、ゲートを越える速さを落とし、採択と申し出の確率を下げる因子として効く。

## 1. 肩書ではなく機能で数える

本モデルは担い手を、経営チーム（CEO、COO、CTO）が持つべき機能に分解して数える。

要件は、そのすべての機能が経営チーム内の誰かの責任になっていることである。

エバンジェリスト機能は、その機能の一つに必ず含まれる。

CEO だからといって、CEO が持つべき機能をすべて自分で持つ必要はない。

経営のスキルが無くても、エバンジェリスト機能を十分に担う人がいてよい。

その機能が埋まっているかは、第8節の四条件で判定する。

機能への分解は、チームのリーダーシップを機能の束として捉える系譜 [41] に対応し、分解の限界を突く万能型の仮説 [43] と対をなす。

肩書で数えないことには、第1章で述べた帰結がある。

評価時点で担い手が未定でよく、肩書、名義、研究者本人の起業意思は入力にならない。

移せる機能の空席は支援者の供給過程で埋まる前提であり、評価日に見るのは「誰がいるか」ではなく「どの機能が担われているか」である。

## 2. 八機能

経営チームが持つべき機能の分解表を $\mathcal F$ と書き、八つの機能で固定する。

| # | 機能 $f$ | 中身 | 移せるか | 空席の埋まり方 |
|---|---|---|---|---|
| 1 | エバンジェリスト機能 | 技術の意義と到達点を説明して、需要家、投資家、審査側の判断を動かす。機能であって職名ではない。誰が担ってもよく、他の機能と兼ねてよい | 移せない | 探索過程（成功確率は案件パラメータ $e$） |
| 2 | 技術の核 | どこまで確かで、どこから先が未知か。再現条件の感覚（書き出せない経験に根ざすため移せない [9]） | 移せない | 原則、研究者本人。恒久喪失（異動、定年で戻らない場合）は遅延ではなく、確定した期限と消失の側で扱う |
| 3 | 用途と需要家の開拓 | 用途仮説の設計、需要家の選定と開拓、単位採算と価格条件の判断 | 移せる | 支援者の供給過程 |
| 4 | 最終意思決定と説明責任 | 進む、待つ、止めるを決め、結果を引き受ける | 移せる | 支援者の供給過程 |
| 5 | 資金調達の実行 | 資料を作り、面談を回し、条件を詰める | 移せる | 支援者の供給過程 |
| 6 | 対外交渉と契約 | 企業、投資家、機関との条件交渉、契約実務 | 移せる | 支援者の供給過程 |
| 7 | 組織の構築と運営 | 採用、労務、社内の仕組みづくり（会社化前は空席が既定で、罰しない）と、研究組織と共同研究先の運営管理 | 移せる | 支援者の供給過程、または産学連携部門や第三の担い手 |
| 8 | （拡張枠） | 量産段階の供給、品質など、次の段で必要になったら拡張手続きで足す | — | — |

### 移せる機能と移せない機能

表の四列目は、その機能を外から来た人に渡せるかどうかである。

分ける基準は、言葉にして渡せるかにある。

需要家の選定、資金調達の実務、契約の交渉は、手順と判断の基準を言葉にして渡せる。

支援者が外から人を供給すれば埋まる。

技術の核は移せない。

どこまで確かで、どこから先が未知かという再現条件の感覚は、書き出せない経験に根ざしており、移せない [9]。

だから機能2は原則として研究者本人が担い、本人が異動や定年で戻らなくなれば、それは遅延ではなく確定した期限と消失の側の出来事になる（第7章）。

エバンジェリスト機能も移せない機能に分類される。

その空席は供給過程ではなく探索過程で埋まり、成功確率は第3章の $e$ に依存する。

### 粒度の固定

$\mathcal F$ の粒度は、この表で固定する。

充足係数 $\eta_t$（第3節）は空席の機能にわたる積なので、分解の粒度そのものが値を動かす。

各機能の遅延係数を変えずに、同じ空席を二つの機能に分けて数えれば、積は小さくなる。

細分と統合は、係数の再較正を伴う版の更新として行う。

分けた後に係数を較正し直せば向きは決まらないので、粒度の違う版のスコアを比較しない。

機能8 の拡張枠は、量産段階で供給や品質の機能が要るようになったときの受け口であり、拡張手続きで足される。

COO に相当する中核は機能7 に置いている。

機能7 のうち会社側の運営は、会社化前は空席が既定であり、罰しない。

「罰しない」は、機能7 の空席を理由に評価日のスコアから点を引いたり評価を止めたりしないことを指すと本書は読む。

$\eta_t$ の計算では、他の空席と同じく 0.05 を掛ける（第6節の下限の表がこの数え方である）。

八機能は、チームのリーダーシップの15機能 [41] を参照して置いたものであり、15機能との一対一の対応は本書では与えない。

## 3. 充足係数

ゲートの前進を遅らせる因子としての担い手の空席を、次の一つの係数にまとめる。

$$
\eta_t = \prod_{f \in \mathcal F} \big(1 - d_f \cdot \mathbb 1[\text{機能 } f \text{ が } t \text{ で空席}]\big)
$$

| 記号 | 意味 |
|---|---|
| $\eta_t$ | 月 $t$ の担い手の充足係数。前進の式（第4章）の率に掛かる |
| $\mathcal F$ | 経営チームが持つべき機能の分解表（前節の八機能）[41][43] |
| $d_f$ | 機能 $f$ の空席がもたらす遅延係数（0〜1）。ゲートごとに添字づける（$d_{f,g}$。第6節） |
| $d_e$ | 機能1（エバンジェリスト）の遅延係数 $d_{1,g}$ の略記 |
| $\mathbb 1[\cdot]$ | 中身が真なら1、偽なら0 |

空席の機能ごとに $(1 - d_f)$ を掛け、埋まっている機能は 1 を掛ける。

全機能が埋まっていれば $\eta_t = 1$ で、前進の式の率は落ちない。

空席があれば、その分だけ率が落ち、ゲートを越えるまでの待ち時間が延びる。

これが「空席は減点ではなく遅延」の式の形である。

確率から一定値を引くのではなく、率に掛けるので、空席は前進の速さを落とす遅延として現れる。

第4章の前進の式で、F1 の T3（基準速度 $1/17$、$\psi = 0.80$、$c = 1$、受託なしで $(1 - \gamma\rho_t) = 1$）を例に取ると、最短準備期間の 11 か月が過ぎたあとの月ごとの通過確率は、$\eta_t = 1$ なら約 0.046 である。

$\eta_t = 0.774$（第9節の合成事例の空席の組を当てた T3 の値）なら、率が 0.774 倍になり、通過確率は約 0.036 に下がる。

これは一般の F1 の T3 の値であり、合成事例そのものの通過確率ではない（事例には共同研究の工数 0.2 があり、その近さの区分に応じた $\gamma$ が別に効く。第4章）。

越える確率がゼロになるのではなく、越えるまでに待たされる月数が延びる。

遅延係数には一つの制約がある。

エバンジェリスト機能の遅延係数 $d_e$（$= d_{1,g}$）は、機能1 が主担当になるゲートの中で最大である。

T1 から T3 では技術の核が空席なら前進しないので、機能2 に 1.00 が入り、$d_e$ を上回る（第6節の表）。

T4-* の準備と治験では、機能2 の値は 0.35 で $d_e$ と同じである。

$d_f$ は較正できる量である。

空席期間とゲート通過の遅れの観測から推定し、予測した遅れと実測を突き合わせて反証できる。

## 4. 担い手の空席が効く三つの先

担い手の空席は、ステージゲートの前進確率 $p^{\mathrm{adv}}$（第4章）だけでなく、採択関数 $\phi$ と申し出到来率 $\nu_k$（第6章）にも効く。

前進確率には $\eta_t$ が掛かり、後の二つには $\eta_t$ と同じ形で機能を絞った担い手乗数（第7節）が掛かる。

前進の式にだけ乗せると、担い手の空席はゲートを越える速さだけを変えることになる。

しかし機能1 の定義は、需要家だけでなく投資家と審査側の判断を動かす機能である。

担い手が埋まっていれば、採択される確率も上がるのであって、前進の速さだけが変わるのではない。

定義と式を一致させるには、採択と申し出の側にも乗せなければならない。

担い手の構成が資金調達の成否に効くことの実証は [44][45] にある。

$e$ は第3章のとおり「機能が誰かによって担われるかどうか」であり、肩書も名義も、特定の支援者が入っているかどうかも入力にならない。

機能1 を担う記録があれば、それが誰であっても採択の確率は上がる。

## 5. 空席の埋まり方

評価日に空席だった機能は、どれだけの速さで埋まるのか。

移せる機能は支援者の供給過程で、エバンジェリスト機能は探索過程で埋まる。

評価時点の空席そのものは罰せず、埋まるまでの月数の見込みを持つ。

速さの初期値は次の表のとおり置く。

| 機能 | 過程 | 初期値 | 根拠レベル |
|---|---|---|---|
| 移せる機能（3〜7） | 支援者の供給過程 | $\kappa_{\mathrm{sup}} = 1/12$ | C |
| エバンジェリスト機能（1） | 探索過程（$e$ が乗る） | $\kappa_e = 1/18$ | C |
| 技術の核（2） | 研究者本人（空席にしない） | — | 規約 |

$\kappa_{\mathrm{sup}}$ と $\kappa_e$ は空席が埋まる速さの初期値である（率と読めば、値が小さいほど埋まりにくい）。

探索過程には $e$ が乗るので、エバンジェリスト機能が埋まる速さは案件によって違う。

$\kappa_e < \kappa_{\mathrm{sup}}$ を順序の制約として宣言する。

順序の制約とは、二つの値の大小関係を較正の前に固定することを指す。

本モデルが定めるのは順序だけであり、外から供給できる機能より探索しなければ見つからない機能のほうが埋まりにくい、という見立てはこの順序の本書の読みである。

値そのものは較正前の初期値（C）である。

充足の確率は、評価日からの経過月だけで決まる。

したがって観測状態の成分としては持たず、空席のパターンにわたる厳密な期待値として、毎月、ゲートごとに前計算する。

空席になりうる機能は 1 と 3 から 7 の六つなので、パターンは $2^6 = 64$ 通りである。

64 通りの $\eta_t$ をそれぞれの確率で重み付けた期待値を取るので、これは近似ではない。

第3章第12節の入力口 $f_1$ から $f_7$ は、この前計算の初期条件である。

$f_3$ から $f_7$ は、指定した案件では評価日に確率 $f$ で充足済み、残り $1 - f$ が供給過程で埋まる。

省略した機能は評価日に空席で、供給過程で埋まる。

$f_1$ は $e$ の別名であり、$f_2$ は既定 1 で、指定した充足は評価期間中変わらない（第6節）。

## 6. ゲートで添字づけた遅延係数

同じ空席でも、ゲートによって遅れの大きさは違うはずである。

需要家を開拓する機能の空席は、有償PoCを取るゲートでは重く効き、再現性を確かめるゲートではほとんど効かない。

どのゲートでどの機能の空席が効くのかは、第4章のゲート表の主担当機能の列で先に決めてある。

$d_f$ はゲートごとに添字づけ、$d_{f,g}$ とする。

非ゼロの大きな値は、ゲート表の主担当機能のマスだけに置く。

それ以外は一律 $d_{\mathrm{other}} = 0.05$ である。

根拠レベルはすべて C である。

| ゲート | 主担当の空席の遅延 | それ以外 |
|---|---|---|
| T1、T2、T3 | 機能2（技術の核）＝ 1.00（前進しない） | 0.05 |
| T4-* の準備 | 機能6（対外交渉）0.25、機能2 0.35 | 0.05 |
| T4-治験 | 機能6 0.30、機能2 0.35 | 0.05 |
| M2 | 機能3（用途と需要家）0.30、機能1（エバンジェリスト）0.35 | 0.05 |
| M3 | 機能3 0.30、機能6 0.25 | 0.05 |
| M4 | 機能6 0.30、機能4（意思決定）0.20 | 0.05 |

基準値 $d_{\mathrm{other}} = 0.05$ を超えるマスが少ないのは、どの機能の空席がどのゲートの遅れとして観測されるはずかを、ゲート表の機能列で先に宣言しているからである。

この意味で、表を疎行列と呼ぶ。

技術系の T1、T2、T3 で機能2 の遅延が 1.00 なのは、技術の核が空席なら前進しないことを表す。

第3節の「$d_e$ が最大」をこの表で読むと、機能1 が主担当になる M2 では $d_e = 0.35$ が最大であり、T1 から T3 では 1.00 がそれを上回る。

### 機能2 の規約

機能2 は、既定では空席にならない。

研究者本人が担い、一時的な不在は扱わない。

ただし、評価日に技術の核の担い手が案件から失われていることが観測された場合は、案件ごとの入力として空席（充足 $f_2 < 1$）を指定できる。

指定した案件では、技術の核の担い手の恒久喪失を表す消失率 $\lambda^{\mathrm{core}}$（第7章）を重ねて適用しない。

同じ喪失を率と状態で二回数えないためである。

機能2 の空席は供給過程では埋まらない（移せない機能）ので、指定した充足は評価期間中変わらない。

まだ失われていない案件の将来のリスクは、$\lambda^{\mathrm{core}}$ で扱う。

$d_{2,g} = 1.00$ は、空席を指定した案件でだけ効く。

そうした案件が出てから、実測で較正する。

**基本設定**（計画の規則を登録していない案件に置く既定の一式。既定の計画の規則、代表案件の前提、案件パラメータの事前分布の既定からなる。以下、基本設定）の計算では効かない。

### 充足係数の下限

機能2 の空席を指定しない案件では、$\eta_t$ に下限がつく。

下限はゲートごとに違い、主担当が空席になりうるゲートほど低い。

| ゲート | $\eta_t$ の下限 |
|---|---|
| T1、T2、T3（主担当は機能2 で空席にしない） | 0.735 |
| T4-* の準備 | 0.580 |
| T4-治験 | 0.542 |
| M2 | 0.371 |
| M3 | 0.428 |
| M4 | 0.456 |

この表の値は、空席になりうる六つの機能（1 と 3 から 7）をすべて空席として、疎行列の値を掛け合わせたものである。

T1 から T3 の 0.735 は、六つの機能がすべて 0.05 で $0.95^6$ である。

M2 の 0.371 は、機能3 の 0.30 と機能1 の 0.35 と、残り四つの 0.05 で $0.70 \times 0.65 \times 0.95^4$ である。

T1 から T3 では、機能2 以外のどの機能が空席でも、率は 0.735 倍までしか落ちない。

市場系の M2 では 0.371 倍まで落ちる。

主担当が空席になりうるゲートほど下限が低い、というのがこの差である。

### 積の形が含意すること

$\prod(1 - d_f)$ は、空席が増えるほど追加の空席の害が小さくなる形をしており、空席どうしを代替的に扱う。

M2 で機能1 だけが空席なら率は 0.65 倍で、害は 0.35 である。

そこに機能3 の空席が加わると 0.455 倍で、機能3 を加えた分の害は 0.195 にとどまる（機能3 単独なら 0.30）。

創業チームの研究が示すのは逆の補完性である。

この形は補完性を表現できない。

本モデルはこれを、モデルが表現していないことの一つとして宣言している（第14章）。

## 7. 担い手乗数

採択関数 $\phi$ と申し出到来率 $\nu_k$ に乗る因子は、$\eta_t$ と同じ形で、効く機能を絞って置く。

$$
m^{\phi}_\eta = \prod_{f \in \{1, 5\}} \big(1 - d^{\phi}_f\, \mathbb 1[\text{空席}]\big), \qquad
m^{\nu}_\eta = \prod_{f \in \{1, 6\}} \big(1 - d^{\nu}_f\, \mathbb 1[\text{空席}]\big)
$$

| 記号 | 意味 | 値 | 根拠レベル |
|---|---|---|---|
| $m^{\phi}_\eta$ | 採択関数に乗る担い手乗数。機能1（エバンジェリスト）と機能5（資金調達の実行）の空席で決まる | — | — |
| $m^{\nu}_\eta$ | 申し出到来率に乗る担い手乗数。機能1 と機能6（対外交渉と契約）の空席で決まる | — | — |
| $d^{\phi}_1$ | 機能1 の空席が採択に与える遅延 | 0.30 | C |
| $d^{\phi}_5$ | 機能5 の空席が採択に与える遅延 | 0.25 | C |
| $d^{\nu}_1$ | 機能1 の空席が申し出に与える遅延 | 0.35 | C |
| $d^{\nu}_6$ | 機能6 の空席が申し出に与える遅延 | 0.15 | C |

採択に効くのは、審査側の判断を動かす機能1 と、資料を作り面談を回す機能5 である。

申し出に効くのは、相手の判断を動かす機能1 と、条件交渉と契約実務を担う機能6 である。

どちらにも機能1 が入るのは、機能1 が需要家、投資家、審査側の判断を動かす機能と定義されており、その判断が採択と申し出の両方に関わるからである。

二つの機能の空席の組み合わせで、乗数は四つの値のどれかを取る。

| 機能1 | 機能5 | $m^{\phi}_\eta$ |
|---|---|---|
| 充足 | 充足 | 1.00 |
| 空席 | 充足 | 0.70 |
| 充足 | 空席 | 0.75 |
| 空席 | 空席 | 0.525 |

| 機能1 | 機能6 | $m^{\nu}_\eta$ |
|---|---|---|
| 充足 | 充足 | 1.00 |
| 空席 | 充足 | 0.65 |
| 充足 | 空席 | 0.85 |
| 空席 | 空席 | 0.553 |

担い手乗数の側の下限は、$\phi$ で 0.525、$\nu_k$ で 0.553 である。

採択関数と申し出到来率の式の中で、この乗数がどの位置に掛かるかは第6章に置く。

## 8. 充足の判定

では、何を見れば機能が埋まっていると数えるのか。

名刺の肩書では足りないのなら、記録のどこまでを充足とするのか。

機能 $f$ が月 $t$ に「充足」なのは、次のすべてを満たすときだけである。

1. **直近性**：直近12か月以内に、その機能の実働の記録（登録簿の人の着任、退任、実働の記録のうち、実働の記録。着任と退任は別に記録するが、実働としては数えない。第10章）があること。12か月途切れたら空席へ戻る（失効）。不作為は事象にならないので、失効の判定は評価版（評価を確定する単位。第10章）の更新時に機械的に行う。
2. **複数時点**：すべての機能で、3か月以上離れた2時点以上の実働の記録を要する。評価直前の駆け込み記帳1件では充足にならない。単発の記録しか無い機能は「充足見込み」として表示し、評価版の確定では空席として扱う。
3. **証拠の下限**：機能ごとに次の実働を要する。
   - エバンジェリスト機能：本人が説明の主体となった対外説明の記録（同席、紹介は不可）。
   - 技術の核：実験、技術判断、再現指導の実働。
   - 用途と需要家の開拓：需要家の発掘、条件設計の実働。
   - 最終意思決定：会議体での決定と結果の引き受けの記録。
   - 資金調達：申請、面談、条件交渉の実働。
   - 対外交渉：交渉、締結実務の実働。
   - 組織の構築と運営：採用、労務、体制づくり、または研究組織運営の実働。
4. **出所**：エバンジェリストは第三者証言または相手方の記録（面談相手側の文書、議事）を必須とする。他の機能は推奨とし、自己申告のみの記録は確信度を下げて扱う。

四条件は、担い手の充足を実働の記録だけで判定するというゲーム耐性の規律（第10章）の中身である。

肩書、名義、意思表明では充足にしない。

第3章の $e$ と同じ規律である。

冒頭の二つの場面に戻る。

名刺に CEO と書いてある人物は、条件3 の証拠の下限を満たす実働の記録が無ければ、どの機能も充足していない。

研究者が需要家の前で、直近12か月以内に、3か月以上離れて二度説明の主体に立ち、相手側の議事録が残っている場合は、条件1 から条件4 のすべてを満たし、機能1 は充足である。

着任と退任は、実働とは別の事象として独立に記録する。

空席期間の始点と終点が記録に残っていなければ、$d_f$ の較正ができない。

実働の記録の効き先は、条件つきである。

機能が空席のときは、案件パラメータ（$e$ など）と充足の両方へ効く。

既に充足のときは、充足の維持にだけ効く。

充足を確定した時点で遅延 $d_e$ はすでに解除されており、同じ一件の実働で $e$ の推定値まで上げると、一件の実働が二重に効くためである。

記録が薄い案件では、充足の失効判定を保留し、評価版の確定前に現況確認の記帳を必須にする（第10章）。

記録を怠っただけの案件が、実態と無関係に空席扱いになるのを防ぐ。

四条件は充足の判定の本則である。

記録の無い案件には適用できないので、明確な観測がある機能だけ充足 $f_1$ から $f_7$ を入力し、残りは既定のままにする（第3章第12節）。

実働の記録が二時点以上そろった案件から、四条件へ切り替える。

## 9. 合成事例で追う

特殊結晶の育成技術（F1、REG-0）の評価日の充足を、次のとおりとしよう。

機能1（エバンジェリスト）は研究者が充足している。

本人が説明の主体となった対外説明の記録が、評価日の6か月前と1か月前の二時点にあり、相手方の議事が残っている。

機能2（技術の核）は研究者が充足している。

機能3、4、5、6 は空席で、支援者の供給過程で探索中である。

機能7 は産学連携部門の教員が研究組織側のみ充足し、会社側は会社化前の既定の空席である。

空席の機能を 3、4、5、6、7 の五つとして、第6節の表から各ゲートの $\eta_t$ を計算すると次のようになる。

| ゲート | 空席の因子 | $\eta_t$ |
|---|---|---|
| T1、T2、T3 | $0.95^5$ | 0.774 |
| T4-* の準備 | $0.75 \times 0.95^4$（REG-0 の本事例には無いゲート。規制のある案件に置いたときの参考値） | 0.611 |
| T4-治験 | $0.70 \times 0.95^4$（同上） | 0.570 |
| M2 | $0.70 \times 0.95^4$（機能3 が主担当。機能1 は充足） | 0.570 |
| M3 | $0.70 \times 0.75 \times 0.95^3$ | 0.450 |
| M4 | $0.70 \times 0.80 \times 0.95^3$ | 0.480 |

次のゲートが T3 なので、評価日の前進の率は 0.774 倍である。

同じ空席の組でも、M3 や M4 に進んだときには率が半分近くまで落ちる。

需要家を開拓し（機能3）、条件を交渉して契約を結び（機能6）、進む、待つ、止めるを決める（機能4）機能が空席のままでは、市場系のゲートで遅れが大きくなる。

担い手乗数は、機能1 が充足で機能5 が空席なので $m^{\phi}_\eta = 0.75$、機能6 が空席なので $m^{\nu}_\eta = 0.85$ である。

この値は評価日のものであり、空席の機能は供給過程で月を追って埋まっていく。

前計算では、どの機能がいつ埋まるかの 64 通りのパターンを確率で重ねた $\eta_t$ の期待値を、毎月、ゲートごとに持つ（第5節）。

## 10. 演習

演習では、基本設定と、第9節の合成事例の値だけを使う。

**演習1**

合成事例の評価日の $\eta_t$ を、次のゲートが T3 である場合と、仮に M2 であった場合について求めよ。

機能7 は会社側が空席として数え、他の空席と同じく 0.05 を掛ける。

方針：T3 では主担当の機能2 が充足なので、空席の 3、4、5、6、7 がそれぞれ 0.05 で、$\eta_t = 0.95^5 \approx 0.774$。

M2 では機能3 が主担当で 0.30、機能1 は充足、残りの 4、5、6、7 が 0.05 で、$\eta_t = 0.70 \times 0.95^4 \approx 0.570$。

採点観点：疎行列の主担当のマスとそれ以外の 0.05 を正しく読み分けているか。

同じ空席の組でも、ゲートによって $\eta_t$ が変わる理由（主担当機能がゲートで違う）を述べているか。

**演習2**

第6節の下限の表のうち、T4-* の準備の 0.580 と M4 の 0.456 を、疎行列の値から導け。

導いたうえで、下限がゲートごとに違う理由を一文で述べよ。

方針：T4-* の準備は、機能6 の 0.25 と、機能2 を除く残り五つ（1、3、4、5、7）の 0.05 で、$0.75 \times 0.95^5 \approx 0.580$。

M4 は、機能6 の 0.30 と機能4 の 0.20 と残り四つの 0.05 で、$0.70 \times 0.80 \times 0.95^4 \approx 0.456$。

採点観点：機能2 を空席に数えていないか。

主担当が空席になりうるゲートほど下限が低い、という性質を述べているか。

**演習3**

合成事例について、採択関数に乗る担い手乗数 $m^{\phi}_\eta$ と、申し出到来率に乗る担い手乗数 $m^{\nu}_\eta$ を求めよ。

次に、支援者が機能5 と機能6 を供給して埋めたとき、二つの乗数がどう変わるかを述べよ。

方針：機能1 は充足、機能5 は空席なので $m^{\phi}_\eta = 0.75$。

機能6 は空席なので $m^{\nu}_\eta = 0.85$。

機能5 と 6 が埋まれば両方 1 になる。

採点観点：二つの乗数がそれぞれどの機能で決まるかを正しく引いているか。

機能1 が両方に入る理由をエバンジェリスト機能の定義から述べているか。

**演習4**

次の四つの記録について、エバンジェリスト機能の充足の判定を行え。

(a) 名刺に CEO と書かれた人物が着任した記録。

(b) 投資家との面談に研究者が同席し、説明は支援者が行った記録。

(c) 11か月前に一度だけ、研究者が説明の主体となった記録（相手方の議事あり）。

(d) 20か月前と 14か月前の二件、研究者が説明の主体となった記録（相手方の議事あり）。

方針：(a) は肩書であり充足にしない。

(b) は同席なので証拠の下限を満たさない。

(c) は直近性と出所は満たすが単発なので「充足見込み」で、評価版の確定では空席。

(d) は3か月以上離れた二時点で出所も満たすが、どちらも直近12か月より前なので直近性を満たさず、失効して空席。

採点観点：四条件（直近性、複数時点、証拠の下限、出所）のどれで判定が決まるかを、記録ごとに特定しているか。

(c) と (d) で、不足している条件が違う（複数時点と直近性）ことを区別しているか。

**演習5**

M2 において、機能1 だけが空席の案件と、機能1 と機能3 の両方が空席の案件を比べ、機能1 の空席の害と、そこに機能3 の空席が加わった分の害を、率の低下分で求めよ。

機能3 だけが空席の場合の害とも比べよ。

そのうえで、この結果が創業チームの研究の示す補完性とどう食い違うか、本モデルがそれをどう扱っているかを述べよ。

方針：機能1 だけの空席で率は 1.00 から 0.65 へ落ち、害は 0.35。

そこに機能3 の空席が加わると 0.455 へ落ち、加わった分の害は 0.195。

機能3 だけなら害は 0.30 なので、先に別の空席があると、同じ機能の空席の害が小さくなる。

積の形は空席どうしを代替的に扱う。

補完性は、モデルが表現していないことの一つとして宣言されている（第14章）。

採点観点：代替性の意味（空席が増えるほど追加の害が小さい）を、同じ機能の害の比較で数値から示しているか。

モデルの限界を、第14章で宣言された非表現の一つとして位置づけているか。

**演習6**

合成事例について、第9節の表の M3 と M4 の $\eta_t$ を、疎行列の値から自分で導け。

そのうえで、支援者が機能6 だけを供給して埋めたとき、T3、M3、M4 の $\eta_t$ がそれぞれどう変わるかを求めよ。

方針：M3 は機能3 の 0.30 と機能6 の 0.25 と、残りの 4、5、7 の 0.05 で $0.70 \times 0.75 \times 0.95^3 \approx 0.450$。

M4 は機能6 の 0.30 と機能4 の 0.20 と、残りの 3、5、7 の 0.05 で $0.70 \times 0.80 \times 0.95^3 \approx 0.480$。

機能6 が埋まると、T3 は $0.95^4 \approx 0.815$、M3 は $0.70 \times 0.95^3 \approx 0.600$、M4 は $0.80 \times 0.95^3 \approx 0.686$ になる。

採点観点：ゲートごとに主担当のマスを正しく選んでいるか。

一つの機能が埋まることの効きが、その機能を主担当とするゲートで大きいことを数値で示しているか。

**演習7**

機能2 の空席を指定した案件と、指定しない案件で、T1 から T3 の $\eta_t$ と、消失率 $\lambda^{\mathrm{core}}$ の扱いがどう違うかを述べよ。

方針：$f_2 = 0$ と指定した案件では $d_{2,g} = 1.00$ が効き、T1 から T3 の率は 0 になる。

$0 < f_2 < 1$ なら、空席の確率 $1 - f_2$ の分だけ率が下がる。

同時に $\lambda^{\mathrm{core}}$ を外す。

指定しない案件では機能2 は充足として計算し、将来の喪失は $\lambda^{\mathrm{core}}$ で扱う。

採点観点：同じ喪失を率と状態で二回数えない、という理由を述べているか。

機能2 の空席は供給過程で埋まらないので、指定した充足が評価期間中変わらないことに触れているか。

$f_2$ が 0 から 1 の値であることを述べているか。
