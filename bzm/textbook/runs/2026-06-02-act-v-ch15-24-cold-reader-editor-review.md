## Where theory still leaks

Theory no longer leads the chapter engine, but it still announces itself too formally.

Ch15 still says the book is moving to theory and that BZM can now be placed in the meeting. The scene has earned the name; the narrator does not need to declare the reveal so heavily.

Ch16 repeatedly says terms will be named "later." This is correct as draft architecture, but in a trade book it reminds the reader of a syllabus behind the story.

Ch17 is the densest notation leak. `mu_A`, `mu_G`, `mu_I`, and `sigma_SU` arrive in a compact explanatory cluster after a strong email-clock scene. The reader can understand misaligned waves without variable notation in the main body.

Ch18 repeats the same issue with FRL, F_character, and F_capability. The repeat-back test is strong enough; the definition block cools it.

Ch20 and Ch21 are lighter, but `retrofit`, `validation`, and `ERS` still appear as theory labels near the end. Ch21's line that lists "準備度。統合地図。retrofit。validation。ERS..." is useful as internal orientation but too meta for the public close.

## Where toolkit residue remains

The toolkit residue is no longer markdown tables. It is hidden-list prose.

Ch20 has the most visible list-shaped teaching: five old evidence-rule sentences followed by five new rules. This is good content, but it reads like a training artifact inside the main body. The next pass should keep one or two rules in-scene and move the full old/new rule set into Toolkit A or a methodology appendix.

Ch21's responsibility pipeline is conceptually right, but the seven-step pipeline reads like a process manual. It can stay as a physical whiteboard artifact if compressed; the full pipeline belongs in Toolkit C.

Ch22-Ch24 are correctly toolkit chapters, so the issue is not that they contain tools. The issue is density. Ch23's four-paper sequence and Ch24's pilot charter are useful, but publication layout should separate them as Field Toolkit after Ch21. Ch24's final question is strong enough to close the book after the tools, but Ch21 remains the narrative ending.

Earlier chapters also still carry residue that should be swept in the same pass: Ch07 judgment labels, Ch08 responsibility allocation, Ch10 learning log, Ch12 readiness axes, Ch13/18 role papers, and Ch14/21 institution pipeline.
