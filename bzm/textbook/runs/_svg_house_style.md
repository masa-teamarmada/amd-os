# BZM教科書 構造図 SVG ハウススタイル (g01-g25 共通)

承認済みサンプル g01_two_layer.svg / g02_clock_rings.svg と完全に揃える。

## 必須ルール

- **白背景・印刷可・日本語ラベル**。Web でも紙でも崩れない。
- 1ファイル = 1つの自己完結 SVG。外部フォント/画像/JS 依存なし。
- 冒頭 `<svg xmlns viewBox font-family role="img" aria-labelledby="t d">` + `<title id="t">` + `<desc id="d">` を必ず付ける (a11y)。
- 直後に `<rect width height fill="#ffffff"/>` で白地を敷く。
- フォントスタック: `'Hiragino Sans','Hiragino Kaku Gothic ProN',sans-serif`
- viewBox は内容に合わせる。横長は `0 0 820 520` 前後を基準、縦長・年表は適宜。

## カラーパレット (2色ランプ 青/緑 + オレンジ差し色)

| 用途 | 色 |
|---|---|
| 青・主役/判定系 文字・枠 | `#2a4d8f` / 濃 `#1a2a52` / 中 `#5b73b0` |
| 青 面塗り (淡) | `#eef2fb` |
| 緑・動学/プロセス系 文字・枠 | `#3a7a4a` / 濃 `#2c6038` |
| 緑 面塗り (淡) | `#eef7f0` |
| オレンジ 差し色 (矢印・強調・警告) | `#e07a5f` / 濃 `#c0563c` |
| グレー 補助テキスト | `#555` / 薄 `#888` |
| 罫線・区切り | `#444` / 淡 `#e2e2e8` |

## レイアウト作法

- 角丸 `rx="7"`〜`8`、枠線 `stroke-width="1.6"`〜`2.2`。
- 箱の見出しは `font-weight="700"`、本文 11.5〜12、見出し 13.5〜18。
- **文字と矢印・線を絶対に重ねない**。矢印は箱の端から端へ引き、ラベルは線の脇に置く。
- 矢印は `<defs><marker id="...">` を定義して `marker-end` で付ける。
- `text-anchor="middle"` で箱の中央寄せ。複数行は `<text>` を y でずらして積む (tspan より明示的に)。
- 丸数字の実文字は禁止。番号は `(1) (2)` を使う。

## 禁止

- 丸数字、絵文字の多用、外部依存、座標被り・文字溢れ。
- 固有名詞・社名・人名・チーム名を入れない (匿名の一般例にする)。
