# §1.0.4 本章の道筋 — 二項関係を二層に開く

> Ch 1「状態空間と観測量 — Before Zero を測るとはどういうことか」(30p) の §1.0 章頭フックの第 4 サブセクション (= 最終、§1.0 全体を閉じるロードマップ章) v2。まさレビュー 3 点指摘 (研究者リアリズム / ナラティブ補完 / 批判 panel) を受けて、3 persona → 3 critics (現役研究者リアリズム / 初読読者 / 文献+引用適切性) → synth v1 → adversarial reviewer → synth final で再起草。三人 (A/B/C 氏) を thin に再導入、まさ提供の具体セリフを採用、Ch 1 全体 § 1.1〜§1.7 + 二層観測 PRS/ERS の予告。

§1.0 はここまで三つのサブセクションを並べてきました。§1.0.1 で、ある一週間に三つの面談 — 月曜の午前、国立大学の産学連携本部で URA と向き合ったペロブスカイト太陽電池の若い准教授 A 氏。水曜の午後、都内 VC のオフィスで起業準備を進める創薬ポスドク B 氏。金曜の夕方、地方合同庁舎で地域経済産業局担当官と並んだ陸上養殖の公設試主任研究員 C 氏 — を並べ、三人が別々の机の前で同じ表情で立ち尽くす場面を描きました。§1.0.2 で、その立ち尽くしの正体を、状態 s (= 案件がいまどこに立っているかという目に見えない実体) と観測量 y (= その実体に被さって我々が手にする数字) のあいだのずれとして整理しました。§1.0.3 で、そのずれが大きいとわかってなお測ろうとする三つの実務的要請 — 共通言語・判断の構造化・再現可能性 — を立てました。残るのは、本書がそのずれをどの順で開いていくのか、その道のり地図 (roadmap = この先どこをどの順で通るかを一枚にした地図) を、§1.0 を閉じるにあたって読者に手渡しておくことです。

本章の残り五本の柱を、§1.0 で立てた「状態と観測量の二項関係」を少しずつ解きほぐす作業として並べます。§1.1 では、その二項関係を「測る人」を加えた三項関係 (triadic relation = 状態・観測量・観測者の三者がそろってはじめて意味を持つ関係) として開き直します。何を測っているつもりの数字なのか、その尺度 (scale = ものさしの目盛りの種類) は名義・順序・間隔・比率のどれなのか — Before Zero で飛び交う TRL や有望度ランクのいくつかが実は順序情報しか持っていない、という事実を含めて、尺度水準論を補助線にして整理します (出典は §1.1 本体で示します)。§1.2 では、状態 s をこれまで仮置きしてきた s_t = (P_t, R_t, S_t) という三つ組として開き、(天井 P = Potential、その案件が技術的に届きうる最大高度 / 到達度 R = Reach、いまそのうちどこまで現実に近づいたか / 生存確率 S = Survival、そこへ辿り着くまで案件が組織的に生き延びうる見込み) の三軸からなる状態空間 P × R × S を一枚の地図として描きます。§1.3 ではその状態に被さる観測量 y = g(s) + ε を、特許出願件数や IF (impact factor = 学術誌の引用密度指標)、共同研究件数、面談ログといった具体的な代理指標 (proxy = 直接測れない量の代わりに測る量) に展開し、§1.4 で Before Zero (= 量産投資判断より前の、観測量がそもそも少ない領域) に特有のシグナル・ノイズ・自選 (self-selection = 観測対象が観測されに来る／来ないを自分で選んでしまうこと) の問題を扱います。§1.5 で本書独自の二層観測へと開き、§1.6 で校正と失敗パターン、§1.7 で Book II の機構層 (= 案件の背後で動く制度・仕組みの層) への橋を予告します。

その §1.5 で開かれる「二層」が、本書全体の背骨です。§1.0.1 の三人が別々の場所で同じ表情を見せていたのは、案件一本だけを見ていても、機関一個だけを見ていても、どちらか片方では話が閉じないからでした。本書ではこれを、案件層 PRS (Project Readiness State = 案件準備状態) と機関層 ERS (Entity Readiness State = 機関準備状態) の二階建ての観測装置として組み直します。案件層は、状態空間 P × R × S の上で、その案件がいま投資判断の前のどこに立っているかを、

$$
\mathrm{PRS}_t = P_t \times R_t \times S_t
$$

という乗法 (multiplicative = 掛け算による合成) の形でとらえます。三因子はいずれも、§1.2 で詳しく組み立てますが、ここでは [0,1] に正規化された値として読んでください。掛け算にする意味は単純で、天井が低くても、現在地が出ていなくても、生き延びる見込みが薄くても、どれか一つがゼロに近づけば案件全体としてはゼロに近づくからです。C 氏の陸上養殖で言えば、技術的な天井 P が高くても、地域の運転体制が薄くて生存確率 S が下がっていれば、案件は止まる。案件は、強い軸で弱い軸を補えない。この乗法の意味は Ch 2 で本格的に展開します。

一方、機関層はその案件たちを抱える側 — 大学・公設試・スタートアップ・VC・地域経済産業局といった主体 — がどれだけ案件を抱え運ぶ準備が整っているかを、

$$
\mathrm{ERS} = 100 \cdot \frac{\sum_{k} w_{k} A_{k}}{\sum_{k} w_{k}}
$$

の加重和 (weighted sum = 重みつきの足し算) でとらえます (A_k = 機関能力の k 番目の側面のスコア、w_k = その側面の重み)。係数 100 は、ERS を 0–100 のパーセント表現として読めるようにするための正規化で、A_k は [0,1] 正規化済みスコアとして入ります。機関は案件と違って、産学連携本部が薄くても TLO が厚ければ、研究 IR が弱くても URA 体制が強ければ、別の費目で全体を保ち得ます。家計簿の発想に近い。組織のなかで違う情報源を違う重みで集約する、という考え方そのものは経営学・組織論の系譜にも繋がりますが、出典と接続は Ch 3 で示します。ERS は Ch 3 で本格展開し、Book II の機構層でさらに拡張します。乗法と加重和の対比 — 案件は一つでも欠ければ落ち、機関は弱い所を強い所で補える — これが二層を二層たらしめている要点です。ここで重要なのは、便利だからといってこの二つを掛け合わせて一本の指標にしてしまうこと — PRS × ERS のような一本化 — を本書は禁じる、という規律です。PRS は無次元の連続値、ERS は 0–100 スケール — この尺度そのものの違いも、両者を直接掛け算してはいけない理由の一端です。決定の宛先 (= 誰が何を決めるための数字か) も、時間スケールも違うため、無理に一本化すると両層の意味が同時に壊れます。この結合禁止の理由と帰結は Book II の後続章で改めて立て、層の取り違え、尺度水準の混線、加重の暴走、といった典型は Ch 4 の失敗パターンで並べます。Book II では Ch 5 以降で Triple Helix SSM (= 大学・産業・公共三主体の状態空間モデル) と σ_SU (= スタートアップ層の生存確率パラメータ) を導入し、機構層へと議論を開いていきます。

§1.0.1 の冒頭で立ち尽くしていた三人を、最後にもう一度だけ呼び戻させてください。月曜の午前、産学連携本部の机で、ペロブスカイトの准教授 A 氏が「論文は通るけど、共同研究の声がかからない」と漏らしたとき。水曜の午後、VC の会議室で、創薬のポスドク B 氏が「データは出てるんだけど、製薬企業からの引き合いが続かない」と言葉を選んだとき。金曜の夕方、合同庁舎の会議室で、陸上養殖の公設試主任研究員 C 氏が「指標は良くなってるんだけど、社会実装のスジが見えない」と低く言ったとき。三人はそれぞれ、案件の側の話と、機関の側の話を、同じ一つの口の中で混ぜたまま吐き出していたのでした。あの言葉が、案件層の P か R か S の話だったのか、機関層 ERS のどの軸の話だったのか、あるいはその両方が同じ夕方の机の上で重なっていたのか — その分解は、ここで予告した二階建ての観測装置を一階分ずつ組み立てた先、Ch 2 以降ではじめて構造を持って読めるようになります。あの違和感に答える章が、ここから始まります。
