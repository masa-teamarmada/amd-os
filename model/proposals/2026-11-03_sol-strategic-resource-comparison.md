# 戦略余力の比較基準とSOL投資検証

状態: proposal / 未承認

2026年11月3日。戦略余力の資源評価理論の補足案。比較基準、資源を使い続ける条件、投資方針の感度を具体化する。
対象は設立前のSOL事業化PJと、シード成立後に実行する開発案。年10%を比較用に固定する。

## 1. 検証結果

**現在の入力では、SOLの投資判断が条件を変えても安定するとは確認できない。**
開発の価値や成功確率を実額として推定する情報が不足している。
今回できたことは、金額の測定基準に対する不変性の確認と、実際の計画費用を用いた判断の反転条件の計算である。

| 検証対象 | 結果 | 判断への意味 |
|---|---|---|
| 全案に共通する金額基準 | 基準額を変えても案の差額は不変 | 数式上の性質。事業の採算が実証されたこととは区別 |
| 開発実行と保留・代替利用 | 開発便益、代替機会、遅延、追加費用で判定が変化 | 全額実行の採否は未確定 |
| 10L装置4台と2台 | 同じ完了日・独立な装置残存価値ゼロなら、2台案が現在価値約463万円有利。4か月延長して3名を維持すると約128万円不利 | 名目の475万円削減だけでは採否を決められない |
| 1,100万円の装置の段階発注 | 不良な状態を見て発注を止める便益と、遅延・判定費用・残る装置価値の条件で優劣が反転 | 段階発注にも具体的な停止条件と日程・見積が必要 |

上記の463万円・128万円は、購入月等を仮定した条件比較。予測損益ではない。
試算は全額実行1,944条件、2台案1,296条件、段階発注648条件で実施した。
条件は意図的に並べた感度の格子であり、発生確率・信頼区間・将来の出現頻度を表さない。

## 2. 比較基準の定義

### 2.1 Yの金額を測る基準PJ

主基準は「同じ用途・同じ評価日に、SOL固有資源をまだ持たない新規参入PJ」とする。
対象用途は、現在登録している排水処理、金属回収、燃料関連の開発・利用機会で固定する。
市場、一般的な購入先、公開情報、法規制、割引条件はSOLと共通とする。

| 資源 | 基準PJの扱い |
|---|---|
| 自由現金 | 基準額ゼロ。追加する自由現金はFで円額を保持 |
| 公開された知識・一般機器・外注 | 一般に利用できる条件で取得可能。必要な購入・人件費・期間を計上 |
| SOLの菌株、原データ、試作機、非公開手順 | 初期保有なし。取得できる場合だけ、相手の承諾・対価・期間を伴う行動として登録 |
| GAP研究費と学内利用枠 | 自動付与なし。基準PJに実際の取得条件がある場合に個別登録 |
| SOLの顧客実績・NDA・現場許諾 | 初期保有なし。公開可能な情報と実際の取得権を区別 |
| 人材・大学・投資家との関係 | SOL固有の協力を初期保有しない。標準的な人員確保にも経済的費用と時間を置く |

追加の比較基準として、大学から利用権を有償取得する経路、代替技術を調達する経路を持てる。
その価格・取得時間・成功見込みは現時点で未取得であり、基準PJ自体の価値は未評価である。
現在のSOLの絶対額Yを確定するには、SOL側の資源価値に加えて、この基準の入力も必要になる。

同じ基準額Kを全案から差し引く場合、案Iと案Hの差は次のとおり。

```text
YI − YH = (FI + GI − K) − (FH + GH − K)
        = (FI − FH) + (GI − GH)
```

Kを0円・1,000万円・3,000万円とする数値上の検査でも、差額は完全に一致する。
この三つの額は基準PJの査定値ではなく、不変性を確認する入力である。
比較案ごとに異なるKを引く、対象市場・権利・利用可能な行動まで変える場合は、同じ基準の変更とは区別する。

### 2.2 経営判断の比較方針

| 方針 | 現在の資源と追加行動 |
|---|---|
| H：追加開発を保留 | 実際に残る研究資源を維持し、期限に従って利用。ライセンス提供、別用途、後日の着手など、具体的に成立する代替機会を評価 |
| I4：4台による開発 | 全体概要v4.24の開発費71,421,779〜81,421,779円。初期顧客・供給・燃料/金属の成果取得を目指す |
| I2：2台で順次試験 | 同じ判定に必要な独立試験を順次実施。装置2台分を減らし、追加作業・日数・費用と取得資源の差を評価 |
| IS：段階発注 | 小型試験・候補の成立を確認し、条件を満たす場合に10L装置を発注。判定後に継続・中止を選ぶ |

Hでも既存の株やデータを保持できる範囲を評価する。開発を保留したことだけで、その価値をゼロにしない。
維持費や利用許諾の失効は実条件を使う。先に支出した研究費は新規投資費用へ再計上しない。
Hの代替利用で得る価値をOHとして、開発方針が失わせる部分だけを比較へ入れる。
開発と代替利用を同時に行えるなら、両方を実行する方針を比較案へ追加する。

## 3. 継続条件と資金調達

### 3.1 主条件

**評価上は資源の利用主体が存続すると置き、実際の権利期限・必要費用・技術失敗・受注・調達審査は元の条件を保持する。**
当座の現金不足による強制終了を、資源束の価値へ一括で掛ける処理は用いない。

| 対象 | 主条件 |
|---|---|
| 評価日 | 2026年11月3日。月次計算では2026年11月を0月とする |
| 設立前の資源利用主体 | SOL事業化PJ。大学等が持つ資源のうち、現在使える研究用途・期間を評価 |
| GAP研究費 | 計画期間は2027年3月まで。研究費の使途・残額・発注済額を確認し、未使用枠を期間後の会社現金へ持ち越さない |
| 株・データ・設備 | 現在の利用範囲と保持条件を継承。研究費終了後の保管・人員・権利の条件は未確認として残す |
| 商用利用 | 大学ライセンスの合意・取得を条件とし、現金対価1,000万/2,000万円の計画案を比較。SO対価は別条件で再評価 |
| 開発採否の測定時点 | シード、商用利用権、必要な実施体制が整い、着手できる条件付き状態を比較 |
| 資本の機会費用 | 年10%へ固定。資本金や借入元本を営業上の便益に足さない |
| 維持・追加費用 | 実際に追加される研究・雇用・保管・設備・契約費用を控除。両案で共通する費用は差額で相殺 |
| 後続の成長資金 | シリーズA等の資金獲得は保証しない。成立条件と、その資金で開く具体的な成長投資を評価 |

ここで計算する開発採否の条件付き差額は、現在のYの確定額とは異なる。
設立前の現在価値に戻すときは、PJが存続している条件でのシード成立見込みと、着手前に追加で使う資源を別途評価する。

```text
現在持つ着手機会の増分価値の単純形
  = シード等の着手条件が成立する見込み × 条件付きの投資案差額
    − 着手前に必要な追加支出
```

比較方針で成立見込みが変わる場合や複数の成立状態がある場合は、共同の分岐で計算する。
同じシードを成立済みと置く評価では、そのシードの成立率が上がる便益をさらに足さない。
資源評価に含める調達機会の成立見込みと、その時点まで現金が持つかは別の入力として保持する。

### 3.2 変化させる条件

| 条件 | 感度の設定 | 入力の位置づけ |
|---|---|---|
| 支払時点 | 2027年4月一括、13か月均等、2028年4月一括 | 実支払月が未定のための比較 |
| 全体の完了遅延 | 0・2・4か月 | 試験日数から完了日への波及を検査 |
| 遅延で追加する3名の人件費 | 計画月額1,725,000円の0・50・100% | 計画単価を延長した費用。実際の雇用延長契約は未取得 |
| 追加取引実費 | 開発費の0・2% | 見積ではないストレス。通常の資本コストとは区別 |
| 遅れる便益の割合 | 0・50・100% | 初期顧客と燃料等の成果時期を分けるための条件 |
| 収益期間 | 同じ60か月を後ろ倒し、または終了時期を固定 | 権利・市場の期限が延長できるかの検査。実際の寿命の推定ではない |
| 競合する保留案の価値 | 完了基準時点で0・1,000万・3,000万円 | 成立済みの契約額ではなく、代替機会の影響を検査 |

追加の120試験日と、開発全体の4か月遅延は別である。
計画内の空き期間に収まれば、追加人件費を発生させずに完了日を維持できる場合がある。
契約期間を延ばす場合は、その追加月数で計上する。98.5時間の追加工数を、既存の3名給与へ機械的に再加算しない。

通常の借入利息等を年10%の割引に重ねて引く方式は、本試算では採らない。
営業・投資の入出金と割引条件をそろえ、追加の手続・取引実費だけを独立した支出にする。
参考はAASB 136の§50–51とDamodaranの企業全体の資金収入による評価である。本案の戦略余力を会計上の使用価値と同一とする趣旨ではない。

## 4. 費用の対象範囲

開発のみを比較する場合、取得資源の便益Bは、その実現に追加で必要な販売・供給・会社運営等の費用を控除した価値として入力する。
顧客利益を生むために必要な製造・供給整備が比較案だけで発生する場合は、その費用も一度計上する。
全体概要v4.24の販売機1〜3号機の製造・標準据付1,800万円、供給整備1,000万円は、開発以外70,825,000円に含まれる。

| 費用の範囲 | 名目額 | 計算した現在価値 |
|---|---:|---:|
| 開発のみ・現金ライセンス1,000万円 | 71,421,779円 | 65,475,546円 |
| 開発のみ・現金ライセンス2,000万円 | 81,421,779円 | 74,642,994円 |
| 開発と販売・供給・会社運営・1,000万円案 | 142,246,779円 | 129,153,407円 |
| 開発と販売・供給・会社運営・2,000万円案 | 152,246,779円 | 138,320,855円 |

開発は2027年4月〜2028年4月の13か月均等、その他は同年4月から18か月均等の仮定。
実際の月次支払計画ではない。18か月配分の事業継続予備資金10,203,221円は、支出として控除しない。
再試験・改修7,000,000円は、全部使う場合と使わない場合を分ける。
一式比較の必要便益を2028年4月へ換算すると147,824,189〜158,316,909円。再試験費を同月に全額使う場合は154,824,189〜165,316,909円。

同じ入出金を使うなら、便益からその他費用を控除する方法と、支出側でその他費用を控除する方法の結果は一致する。
この一致を検算した。開発のみの必要便益と一式比較の必要便益は、それぞれ費用控除の位置が異なるため、同じ便益の見積額として比較しない。

## 5. 全額開発の反転条件

### 5.1 追加費用・代替機会がない基準条件

2028年4月時点で得る追加資源価値Bが、次の金額を超えることが必要になる。
Bは、開発支出以外の追加費用を控除した、期待正味の資源価値である。

| 支払時点 | ライセンス1,000万円案 | ライセンス2,000万円案 |
|---|---:|---:|
| 全額2027年4月 | 78,563,957円 | 89,563,957円 |
| 13か月均等 | 74,940,876円 | 85,433,597円 |
| 全額2028年4月 | 71,421,779円 | 81,421,779円 |

保留中の資源価値は両案で共通する分を保持する。
保留案でしか得られない追加の代替便益、遅延による利益減少、延長人件費、追加取引費を含めると必要額は上がる。

### 5.2 登録した全条件での比較

図：比較条件別の投資増分

| 追加資源価値Bの仮定 | 投資差額の最小値・現在価値 | 最大値・現在価値 |
|---|---:|---:|
| 50,000,000円 | −71,856,615円 | −18,716,123円 |
| 75,000,000円 | −51,816,023円 | 3,126,277円 |
| 100,000,000円 | −31,775,430円 | 24,968,678円 |
| 125,000,000円 | −11,734,837円 | 46,811,079円 |
| 150,000,000円 | 8,305,755円 | 68,653,480円 |

今回の格子内で必要Bが最も低い条件は71,421,779円、最も高い条件は139,638,835円。
高い条件は、ライセンス2,000万円・全額初月支払・4か月延長・3名維持・代替機会3,000万円・追加取引費2%・全便益が遅延・収益期限固定を組み合わせたもの。
低い条件は、ライセンス1,000万円・全額最終月支払・追加費用と競合する代替便益ゼロ。

Bが1億5,000万円あるという見積が裏付けられれば、この格子内では正の差額を保つ。
一方、SOLのBを1億5,000万円と査定する証拠はまだない。Bが1億円という仮定では判定が反転する。
したがって、条件幅を並べたことだけで投資採用や成功確率を確定しない。

### 5.3 収益期限による違い

同じ60か月の月次利益を全額後ろへずらせる場合、4か月遅延後の価値は元の96.87%になる。
収益終了時点を固定して稼働できる月数が60か月から56か月になる場合は91.75%になる。
この計算は一定の月次利益を置いた形状の感度。契約・権利・市場機会の期限によって、単なる4か月の割引以上の損失が生じることを示す。
研究費の期限や実際の契約期限を、主体の継続を理由に延長する処理は行わない。

## 6. 10L装置2台案の比較

v0.7の10L装置4台は税込11,000,000円の計画価格。
2台を減らす購入支出削減は5,500,000円、追加分析・洗浄・光熱・調整等の仮額は500,000〜1,000,000円で、中央値750,000円なら名目4,750,000円減になる。
追加750,000円の場合の開発費は66,671,779〜76,671,779円となり、完了日の延長による追加支出は別途評価する。
独立試験の受入条件、納期、追加実費は未確認であり、台数削減案は未採用。

次の比較例では、回避する装置支払を2027年4月、追加750,000円を2028年4月に置く。
延長人件費は2028年5月以降に発生する仮定。
残存する2台分の独立な価値は、遅延の対象となる収益へ含めていない売却・別用途等の価値とする。

| 比較条件 | 2台案−4台案の現在価値 |
|---|---:|
| 同じ完了日、失う独立な装置価値ゼロ | 4,630,589円 |
| 4か月延長、3名を全額維持、他の損失ゼロ | −1,279,624円 |
| 同じ完了日、失う装置価値を購入額5,500,000円と仮定 | −174,739円 |
| 4か月延長、人件費50%、遅れる便益1億円・期間後ろ倒し | −1,056,625円 |
| 同上、収益終了時点固定 | −5,531,750円 |

装置価値5,500,000円と便益1億円は査定値ではなく反転条件を示す仮定。
工数では、必須と不調時を含む4,009.48時間に98.5時間を加えると4,107.98時間で、計画上の実用能力5,200時間内に収まる。
集計した工数が収まることと、必要な技能・学内枠・休日当番・日程が同時に成立することは別に確認する。

台数を減らす案の採用には、独立反復を満たせること、全体完了日の変化、契約期間が延びる費用、失う装置・並列試験能力の価値が必要になる。

## 7. 段階発注の比較

対象は10L装置1,100万円の発注時点とする。
比較用に、一括案は2027年4月、段階案は小型での判定後の2027年7月に発注すると置く。これは納期・試験工程が確定した予定ではない。
判定は中止すべき状態を識別でき、追加設備で救済できる候補を誤って中止することはない、という条件付きの例である。

| 比較条件の仮定 | 段階案−一括案の現在価値 |
|---|---:|
| 中止すべき状態25%、遅延なし、判定追加費50万円、中止時の装置価値ゼロ | 2,360,403円 |
| 中止すべき状態10%、成果4か月遅延、継続時便益1億円、追加費50万円 | −1,646,915円 |
| 中止すべき状態25%、成果4か月遅延、継続時便益1億円、中止時装置価値550万円、追加費50万円 | −890,010円 |

中止の割合は実験成功率の推定ではない。10・25%等を置いた感度である。
上表の遅延便益は、同じ収益期間を後ろへずらせる仮定。終了時期が固定なら損失はさらに大きくなる。
共通の他費用は維持しており、中止で回避できる他の支出を含める場合は入出金を追加して再計算する。
追加の延長人件費は上表には含めていない。

学習前は同じ行動を選び、判定後だけ分岐して計算した。
情報が無料で日程・成果・発注価格を変えず、使わずに元の案も選べる場合は、情報を得る方針が不利になることはない。
実際の段階発注では判定費用、装置納期、見積の変化、誤判定、停止後の資源があるため、それらを確認する。

Bの評価には、顧客別の入出金と具体的な後続機会を一度ずつ登録する作業が残る。

## 9. 安定性の判定規則

評価条件は、確認済みの範囲と、提案したストレスの範囲を分けて保存する。
同じ便益・費用を使う比較では、共通する基準と共通費用の変更に対して差額が不変になることを検査する。
実際に費用・利用可能性・成果日・代替機会が変わる条件では、全案を再評価する。

| 判定 | 条件 |
|---|---|
| 範囲内で採用判断が安定 | 裏付けのある入力範囲の全条件で、比較案に対する増分価値が正 |
| 範囲内で見送り判断が安定 | 同範囲の全条件で、増分価値が負 |
| 条件に依存 | 同範囲の条件間で正負が反転 |
| 未識別 | 便益・費用・権利・選択肢の入力不足により、現実に対応する範囲を定められない |

今回のSOLの採否は「未識別」。登録した感度内では条件による反転も観測した。
これは、SOLの事業そのものが不安定だという実証結果ではなく、現状の資料だけでは採否を一意に定められないという結果である。
資金繰りはこの採否と並行して月次の実行可能性を確認する。
