## I-1 置き方の規約

### 1-1 速度は「基準の所要月数」で置き、2段で持つ

$\kappa$ は月次のハザードなので数字として読めない。基準の所要月数 $M_g$ を表に書き、**変換規約**

$$
\kappa_g \;\equiv\; \frac{1}{M^{\mathrm{res}}_g}, \qquad M^{\mathrm{min}}_g = \mathrm{round}(0.40\,M_g), \qquad M^{\mathrm{res}}_g = M_g - M^{\mathrm{min}}_g
$$

で使う。**$M^{\mathrm{min}}_g$ は最短準備期間**で、この間はゲートを通過しない（確定）。その後の待ち時間だけが
$p^{\mathrm{adv}} = 1-\exp(-\kappa_g \psi_g c\, \eta_t (1-\gamma\rho_t))$ の形になる。

2段にする理由: 指数分布は最頻値が 0 で、「準備が要る」段階を表現できない。パイロット設備の建設や条件交渉に
最小の所要期間があるという物理を、定数ハザードは原理的に表せない。臨界点を越えるまで進まないという
大学発スピンアウトの実証（Vohora ら 2004）とも整合しない。
なお **T4-* の2段構成は v1 が既に採っていた**ので、これはその一般化である（同じ構造が正しいと認めながら
T3 のスケール試験や M3 の条件交渉に適用しないのは一貫しない）。

**$M_g$ が意味する量の一覧**（混同を避けるため明記する）:

| 量 | 値 |
|---|---|
| 変換規約 | $\kappa_g = 1/M^{\mathrm{res}}_g$ |
| 準備を終えた後の平均待ち月数 | $1/(1-\exp(-\kappa_g)) \approx M^{\mathrm{res}}_g + 0.5$ |
| 準備を終えた後の待ち月数の中央値 | $\ln 2 \cdot M^{\mathrm{res}}_g$ |
| ゲート全体の平均所要月数 | $M^{\mathrm{min}}_g + M^{\mathrm{res}}_g + 0.5$ |

**R2 の滞留の目安**（§6.D-1）は、この2段分布の **85% 点**に置く。中央値の2倍という v1 の読み方では、
指数の下で健全な案件の 25% が、案件の質と無関係に不成立を1回積まれていた（誤警報）。

### 1-2 根拠レベル

| 記号 | 意味 |
|---|---|
| **A** | 公開統計または AMD の実測値から**その数字が直接引ける**（出典の固定ページを示す） |
| **B** | 制度の設計・文献から**水準が導出されている**（数字そのものは出典に無いが、導出の筋道が書ける） |
| **C** | 暫定の置き。較正までは根拠が無いことを明示して使う |

**順位・順序の制約しか満たしていない値を B と呼ばない**（v1 は $d_e$ を「$d_e$ 最大の制約を満たす」ことを理由に B としていたが、
制約が決めるのは順位だけで 0.35 という水準は何からも導かれていない）。
単一観測（$n=1$）は測定ではあるがクラスの既定の根拠にならないので A と呼ばない。

### 1-3 不確かさの持ち方 — 3種を分けて報告する

| 種類 | 何の不確かさか | どう出すか |
|---|---|---|
| スコアの幅 | 案件パラメータ $\theta$ が分かっていないこと | $B_0$ の下での $v(\theta)$ の 10%・50%・90% 点（§5.8。既定の実装は $c$・$\psi$・$\sigma$ の3成分×3点の格子） |
| 係数の不確かさ | モデルがまだ較正されていないこと | **上位5係数の束**（下記）と、**係数ごとの弾力性の表** |
| 規約の選択 | 割引率・申し出の検討開始段階・$\sigma$ の判定 | $d$ の3点（1%・2%・4%）、$g^{*}$ の1段、$\sigma$ の3点 |

**束の作り方**: 係数をスコアに対する符号で揃え、**弾力性の上位5つだけ**を悲観側・楽観側へ振る。
振り方は型で分ける——率型（$\kappa$・$\nu$・$\lambda$・$\beta$）は乗数で $\times 1.4$ / $\div 1.4$、
確率型（$\alpha$・$\phi_{\mathrm{base}}$・$p^{\mathrm{pass}}$・$d$）は**オッズ比**で同じ倍率、上下の打ち切りがある量は打ち切り前で振る。

v1 の設計（根拠レベル C を一括で同方向に $\times 0.7$ / $\times 1.4$）は採らない。**計算で確かめた結果、
スコアを上げる係数と下げる係数が打ち消し合ううえ、確率型が定義域を出て価値が負になった**
（F1×REG-0 で $\times 1.4$ のとき $V = -0.233$）。

### 1-4 乗数の関数形と目盛り

**$\sigma$（産官学モメンタム）**: $\sigma \in \{-1, 0, +1\}$。**$0$ が無風**。指数形をやめ、倍率を直接置く。

| 効き先 | 逆風 $-1$ | 無風 $0$ | 追い風 $+1$ |
|---|---|---|---|
| 採択 $\phi$ | 0.61 | 1.00 | 1.65 |
| 申し出 $\nu_k$ | 0.67 | 1.00 | 1.49 |
| 受託 $\nu_c$ | 0.74 | 1.00 | 1.35 |
| 競合の消失 $\lambda^{\mathrm{comp}}$ | 0.74 | 1.00 | 1.35 |

**判定規則**（v1 には測定窓も閾値も無かった）: **直近24か月**と**その前の24か月**を比べ、
(i) 該当分野の公的公募の採択率または予算額が $\pm 20\%$ 以上動いたか、
(ii) 該当分野の民間投資額が $\pm 20\%$ 以上動いたか、
(iii) 正統性の事象（規格・標準の制定または改定／業界団体の設立／監督官庁の制度整備）が**1件以上あったか**。
このうち**2項目以上が同じ向き**なら $\pm 1$、そうでなければ $0$。

**統治**: $\sigma$ の判定は**案件ごとではなく分野ごとに AMD が中央で四半期に一度**行い、版管理する
（案件の担当者が個別に置けないようにする）。$\sigma$ は5か所を同時に動かす最大級の効きを持ちながら定性判断が混じるので、
$\sigma$ の反転（前回と符号が変わる場合）には §6.D-3 と同型の統治（判定根拠の一次データを登録簿へ添付、
一次担当と別の者が承認）を課す。**$\sigma$ は I-11 の「一方向のレバー」の一覧に入れる。**

計算で確かめた効きの大きさ（F1×REG-0、$\theta$ は中央値）: 逆風 $V=0.046$ / 無風 $0.128$ / 追い風 $0.242$。**5.3 倍**。

**$\kappa_{\mathrm{IP}}$（専有可能性）**: $[0,1]$。乗数は線形 $b_0 + b_1 \kappa_{\mathrm{IP}}$。

**$g_t$（証拠水準）の段階**: 0 = T1 前 / 1 = T1 / 2 = T2 / 3 = T3・治験第I相 / 4 = M2・治験第II相・規格試験 /
5 = M3・治験第III相 / 6 = M4・承認。**T4-* も段階を上げる**——相を越えることは、審査側・需要家・投資家から見て
技術・市場のゲートと同等かそれ以上の証拠である。v1 は T4-* が段階を上げない設計で、
その結果 REG-2 の案件が第II相を通過しても採択率も申し出到来率も上がらず、縮退検査で M4 到達が 0.0% になった。

**$m_n$（履歴）は 1 に固定する。** 「過去の採択が将来の採択率を上げる」は、真の状態依存と、
観測されない案件品質の持続的な異質性とを分離しなければ推定できない。AMD の台帳には不採択が1件も無いので、
現時点で推定は発散する。**推定できないものを初期値で置くと、識別できない構造が値だけ持って残る**ため、
較正可能になるまで置かない。（v1 の $m_n$ は、算術的な帰結として採択率 32% 未満の制度で
「応募するほど将来の採択率が下がる」——$\phi_{\mathrm{base}}$ は学内配分以外すべてこれを下回っていた。）

### 1-5 年率と月次の変換規約

**表に書く年率はすべて連続時間のハザードの年換算値であり、月次ハザード＝年率／12 とする。**
（v1 は同じ表の2行で $0.03/12$ と $-\ln(0.98)/12$ の2つの規約が混在していた。）

### 2-2 T4-* 規制・認証のゲート（改訂 K5）

**準備**（$c$・$\eta_t$・$\psi$ が乗る）と**審査**（乗らない。決定的な期間）を分ける。
**治験は審査ではなく技術系ゲート**として扱う（$\psi$・$c$・$\eta_t$ が乗る）。
乗数を乗じない規約は、監督官庁・認証機関の**審査**（承認・保険収載・規格試験）だけに限定する。

| ゲート | 扱い | 準備 $M$（月） | 審査（確定・月） | 通過確率 | 根拠レベル |
|---|---|---|---|---|---|
| T4-相談（対面助言） | 準備＋審査 | 6 | 2 | 0.95 | C |
| T4-規格試験 | 準備＋審査 | 9 | 3 | 0.85 | C |

| T4-承認（医薬品・通常品目） | 準備＋審査 | 12 | 12 | 0.90 | 準備 C・審査 **A** |

**通過確率を相別にした理由**: v1 の一律 $p^{\mathrm{pass}}=0.85$ は、医薬品の代表順では $0.85^4 = 52\%$ になり、
第I相から承認までの累積成功率（一般に 8〜10% 程度と報告される）と 5〜7 倍ずれていた。
相別にすると $0.60 \times 0.35 \times 0.60 \times 0.90 = 11.3\%$ で、公表される水準の範囲に入る。

プロトコル設計・GCP 対応体制・CRO 契約・治験薬供給に加え、月1回開催で差し戻しも多い倫理審査を通す必要がある）。

**審査期間の採用規則を一本化する**: **総審査期間の実績の中央値に最も近い整数**を採る（v1 は行ごとに実績・目標・中間とばらばらだった）。

「審査は変換能力では縮まない」という規約の前提と食い違う。**申請者側の期間を準備側へ移し、
審査欄は総審査期間からその分を控除した値に置いた**（医薬品: 総審査 12 のうち 12 を審査、準備を 9→12 へ増やして照会対応を吸収）。
80% タイル値は感度検査に併記する。

## I-3 $d_{f,g}$ — 空席の遅延、充足の速さ、担い手乗数

### 3-1 空席の遅延は、ゲートで添字づけた疎行列にする

$\eta_t = \prod_f (1 - d_{f,g_t} \cdot \mathbb 1[f \text{ が空席}])$。
**非ゼロは §6.A-2 が既に宣言している「主担当機能」のマスだけ**にし、それ以外は一律 $d_{\mathrm{other}} = 0.05$ とする。

| ゲート | 主担当の空席の遅延 | それ以外 |
|---|---|---|
| T1・T2・T3 | 機能2（技術の核）＝ **1.00** | 0.05 |
| T4-* の準備 | 機能6（対外交渉）0.25、機能2 0.35 | 0.05 |
| T4-治験 | 機能6 0.30、機能2 0.35 | 0.05 |
| M2 | 機能3（用途と需要家）0.30、機能1（エバンジェリスト）0.35 | 0.05 |
| M3 | 機能3 0.30、機能6 0.25 | 0.05 |
| M4 | 機能6 0.30、機能4（意思決定）0.20 | 0.05 |

根拠レベルはすべて **C**。$d_e$（機能1）が最大という §5.4 の確定は、機能1 が主担当になる M2 で満たす。

三つの直し:
1. **ゲート非依存の単一スカラーをやめた。** §6.A-2 の主担当機能列は「どの機能の空席が、どのゲートの遅れとして
   観測されるはずか」の較正のための対応宣言だと明記されているのに、v1 の $d_f$ はどの空席もどのゲートでも
   同じ比例遅延を予測するので、その対応宣言を検証**不能**にしていた。添字づけると反証可能になり、パラメータも減る。
2. **技術系ゲートで機能2 が空席なら $d = 1.00$**（前進しない）。$\prod(1-d_f)$ の形は $d=1$ を許すので、
   式を変えずに必須性を表現できる。v1 の $d_2 = 0.30$ は「技術の核を担う人がいない案件でも T1 が 30% 遅くなるだけで通過する」だった。
3. **会社化前の機能7** は $d_7 = 0.05$ を据え置き、**充足の判定側**を会社化前は「研究組織・共同研究先の運営の実働」だけで
   満たせるようにする。v1 は $d_7 = 0$ にして、§6.B-1 が機能7 に含めている「研究組織・共同研究先の運営管理」という
   Before Zero でこそ効く半分を捨てていた。

**積の形が含意すること（I-13 にも書く）**: $\prod(1-d_f)$ は空席どうしを**代替的**に扱う（空席が増えるほど、
追加の1つの空席の限界的な害が小さくなる）。創業チーム研究が示すのは逆の補完性なので、
**この形は補完性を表現できない**。様式は承認済みなので変えないが、表現していないことを明記する。

## I-4 $\phi$ — 採択関数と補給

### 4-1 基準化条件（規約）

$$
\phi = \mathrm{clip}\big(\phi_{\mathrm{base}} \cdot m_\sigma \cdot m_g \cdot m^{\phi}_\eta,\ 0.03,\ 0.70\big)
$$

$\phi_{\mathrm{base}}$ は「$m_\sigma = m_g = m^{\phi}_\eta = 1$ の案件」の採択率であって、応募母集団全体の平均ではない。
**基準化条件**を規約として置く:

$$
\phi_{\mathrm{base}}^{(j)} \cdot \overline{m}^{(j)} \;=\; \hat p^{(j)}
$$

$\hat p^{(j)}$ は制度 $j$ の観測採択率、$\overline{m}^{(j)}$ は応募母集団における乗数の加重平均。
**応募母集団の段階分布が未取得なので $\overline{m}$ は推定できず、根拠レベルは A ではなく B とする。**
$\overline{m} \approx 0.5$（大半の応募が段階0〜1で、担い手にも空席がある）と置いて $\phi_{\mathrm{base}} = 0.28$ を採る。

$m_g$（証拠水準の段階0〜6）: 0.60 / 0.85 / 1.00 / 1.15 / 1.35 / 1.35 / 1.35。根拠レベル C。
**基準点は段階2（T2 通過）**であり、暗黙の仮定は「T2 を通過した AMD の案件の採択確率は、その制度の応募者平均に等しい」。
この仮定を感度検査の対象にする（基準段階を1に置く／3に置く）。

### 4-2 制度クラス（$\phi$ と $z$ を同一の母集団から対で取る）

  （v1 は NEDO フロンティア育成 16件→11件・69% を「標本が小さい」として除いていたが規則が無く、結果として既定が下方に偏っていた）。

  該当する案件では、案件ごとの資金調達の機会の一覧に**個別の機会として**置く。

**年度と入金**（v1 の月割りは、承認済みの $\ell_t$（年度末の失効）を黙って無効にしていた）:
公的資金は**年度単位で年度初に一括入金**し、未使用分を年度末に $\ell_t$ で失効させる（繰越可の制度は機会の属性として持つ）。

### 5-2 受託の申し出

$$
\nu_c = 0.05 \cdot \Big(\frac{r}{r_{\mathrm{ref}}}\Big)^{1/2} \cdot m_\sigma \cdot m_g^{c}
$$

$r_{\mathrm{ref}} = 80$万円／月（4型の $r$ 既定の幾何平均）。$m_g^c$（段階0〜6）: 0.5 / 0.5 / 0.8 / 0.8 / 1.3 / 1.3 / 1.3。
契約の満了ハザードは 1/12（平均12か月）。$\rho = \min(\rho_{\max},\ \text{契約月額}/r)$。根拠レベルはすべて C。

- **$\nu_c^{\mathrm{base}}$ を型によらず一本にした**。v1 は F4 だけ 2 倍にしたうえで $r$ の既定も型で分けており、

- **$m_g^c$（証拠水準）を加えた**。$\nu_k$ には入っているのに $\nu_c$ に無かった。外から何をやっているか見えない段階の
  無名の研究室と、業界に知られた研究室が同じ受託打診確率になっていた。
- **$m_n^c$（受託履歴の連鎖）は置かない**。契約の規模を問わないカウントは、バーンレートの数%の小口受託を積み増すだけで
  次の到来率を吊り上げられる。較正で扱うときは M2 の「重要性のある対価」と同じ下限をカウント対象に課す。

### 5-3 資金調達の機会の新設と消滅

**大学規模区分**（知財の専任体制を持つか）で2段階にする。専任体制のない大学は解決確率を 0.7 倍・準備期間を +1 か月。

  v1 は両方を「四半期1回・0.80」に揃えており、**両方向に事実と逆の誤差**が入っていた。

  共同出願は、持分者間の実施同意が未了でも、**第三者に対する排他性は単独出願と変わらない**。
  「ライセンスを設定できない」という別の効果は、$R_t$ が申し出の受諾を塞ぐ形で表現される。
- **$\sigma$ に幅を持たせた。** v1 は一点に固定していたため、5か所を同時に動かす最大級の効きを持ちながら
  スコアの幅に一切現れず、要件7 の「次に集めるべき情報」に永久に挙がらなかった。
- **$\psi$ の条件づけを版の開始時点に限った。** $\theta$ は期間中固定なので、段階で条件づけたまま
  シナリオを進めると、モデルが生成する段階3 の案件の $\psi$ は 0.45 付近に集まり、表が主張する 0.92 と矛盾する。
  版の途中のゲート通過は推定値の更新（登録簿の種類9）としてのみ効かせる。
- **$r$ の水準を下げ、0 を許した。** 国内の共同研究の1件あたり受入額は年200〜300万円台なので、
  v1 の F4 月200万（年2,400万）を工数全部で達成するには常時8〜10件が要る。上位数%の研究室の像だった。
  対数正規のままでは「受託を売れない研究室が存在しない」設計にもなっていた。

### 9-2 バーンレート $\mu$ の境界と値

**境界を明文化する**: **案件が自ら調達した資金で賄う支出だけを $\mu$ に数える**。
大学が負担している既存の人件費・設備・間接費は数えない（数えるなら対応する負担を資金の側にも計上しないと、
吸収がほぼ全案件で早期に発火する）。会社化は増分ではなく**負担の付け替え**（大学が持っていた人件費が会社へ移る）を
伴うので、会社化後は増分ではなく**絶対値**で置く。

| 型 | 会社化前（万円／月） | 会社化後（万円／月） | 根拠レベル |
|---|---|---|---|
| F1 プロセス型 | 110 | 400 | C |
| F2 組立・デバイス型 | 95 | 360 | C |
| F3 ソフト・データ型 | 60 | 300 | C |
| F4 サービス・手法型 | 50 | 260 | C |

会社化後の水準は、ビジネス側1〜2名（フルコストで月60〜100万円／人）と、家賃・社会保険・顧問料（月30〜50万円）を
含む標準ケースとして置いた。**AMD の月次損益の記録は4件（うち2件は将来の計画値）なので、実測では置けない。**
較正の優先度は最上位（資金切れの判定を直接動かす）。

**使途制限で充当できない割合**: 0.15（$\mu^{\mathrm{f}}$ と $\mu^{\mathrm{r}}$ の割り付けの既定。根拠レベル C）。
**大学経由の契約収入の間接経費率**: 30%。

**会社化前の $\rho_t r$ の行き先**: 改訂1-3 に従い使途制限側へ入れる。したがって **Before Zero のあいだ
自走力は自由資金の残高に効かない**。これは要件3 の実装の帰結として明示する——自走力が効くのは、
§6.D-1 R3 の「資金の目処＝受託の契約（月額で判定）」を通じた**会社化の成立**と、$\nu_c$ を通じた受託の連鎖である。

## I-10 価値の側の係数（v1 に無かった。**弾力性が最大**）

$\Pi$ の被加算項は $\phi_u \frac{\bar P_u - \delta_u}{12}(1-\alpha_u(t))$ である。$\phi_u$ と $\alpha_u$ は
スコアに**直接比例**し、v1 はどちらにも値を置いていなかった（そのうえ「値が未定だったものはすべて埋まった」と書いていた）。

| 係数 | 既定 | 根拠レベル |
|---|---|---|
| $\phi_u = \phi_0 + \phi_1 \kappa_{\mathrm{IP}}$ | $\phi_0 = 0.25$・$\phi_1 = 0.55$（$\kappa_{\mathrm{IP}}=0$ で 0.25、$=1$ で 0.80） | C |
| $\alpha_u$ の**立地差水準**（前倒し期間 $L_u$ 以降） | 0.85（貢献として残るのは 15%） | C |
| $\alpha_u$ の**評価日の控除率**（$L_u$ まで） | **案件ごとの調査項目**。Tier 0 の暫定は 0.30 | C |
| $L_u$ 前倒し期間 | 36か月（§6.E-3 の確定値のうち「競合が活発」側を Tier 0 既定にする） | 確定済み |

$\phi_0$ が 0 でない理由: $\phi_u$ は承継者（ライセンス先・買収後の主体）を含めて国内で発生する分なので、
自社実施でなくても国内に残る割合がある。

**計算で確かめたこと**: $\alpha_u$ の立地差水準は、$1-\alpha$ が小さいために弾力性が大きい。
F1×REG-0 で $-0.78$、$\phi_u$ の傾きが $0.52$ で、**$\kappa_g$（$-0.46$）や空席の遅延（$-0.03$）より効く**。
したがって**較正の最優先は $\alpha_u$ と $\phi_u$**であり、v1 が最優先に挙げていた $M_g$ ではない。

## I-13 モデルが表現していないこと

承認前に明示する。これらは「値を置けば直る」ものではない。

1. **空席どうしの補完性**。$\eta_t = \prod(1-d_f)$ は代替性を含意する（空席が増えるほど追加の空席の害が小さくなる）。
   創業チーム研究が示すのは逆で、中核機能の欠落は他の充足で埋め合わない。様式は承認済みなので変えず、表現していないことを記す。
2. **新しさの不利・ハネムーン**。$\lambda$ は定数で、会社化からの経過月に依存しない。失敗ハザードが山形になるという実証は入っていない。
3. **補完資産の支配**（既存企業の製造設備・販路・規制上の後ろ盾へのアクセス）。専有可能性は $\kappa_{\mathrm{IP}}$ で入っているが、
   もう一つの軸が無い。F2 の M3・M4 が遅い理由も F1 の T3 が重い理由も実質はここにある。次の版で第3の軸として検討する。
4. **受託由来のサービス用途の価値**。参照実装では M4 到達後の解析的な裾でのみ価値を立てており、
   受託がサービス用途として $A_t$ に入る経路（§5.4）は価値側に反映していない。要件3 の後半が計算に乗っていない。
5. **$\delta_u$（国内の既存事業の置き換え分）の時間形**と、**権利の残存期間を超える月の $\phi_u$ の逓減**。
   どちらも §6.E-3 が「裾を過大に見る向きの単純化」として申し送ったまま。
6. **F3 と F4 の線**は事業モデルの線であり、§6.A-3 が宣言する「工程の型は作るものの物理で決める」と食い違う。

| A4 | 権利・承認の残件を「残件数」だけで持ち、種類別の会議暦を平均の解決率へ畳む | 中立（弾力性がほぼゼロなので影響は小さい） |
| A5 | 滞留の自動分岐を、ハザード位置での付加ハザード（比 0.15）で近似する | 中立 |
| A6 | 天井を1に正規化する。出力は「年額の国内純増1円あたりの現在価値」 | 規約 |
| A7 | スコアの幅を $c$・$\psi$・$\sigma$ の3成分×3点の格子で出す（他の成分は中央値に固定） | 幅を小さく見る |

担い手の充足は評価日からの経過月だけで決まるので状態に持たず、空席パターン64通りにわたる**厳密な期待値**として
毎月・ゲートごとに前計算している（これは近似ではない）。
