## A. 標準関門表

### A-1 関門と観測の区別

BZM 3.0 で「関門」と呼ぶのは、**盤面の位置 $g_t$ を前へ進める、外部から検証可能なイベント**だけである。
体質の帯を狭めるだけの出来事（関心表明の文書、競合の動き、工程情報）は関門ではなく**観測**であり、登録簿（C）を通じて体質へ効く。
この区別で、「証拠が増えた」ことと「案件が前へ進んだ」ことを混ぜない。

### A-2 関門種の定義（7種）

技術系（技術の核 $\psi$ が前進確率に乗る）:

| 記号 | 関門 | 通過の定義（外部から検証可能な形） | 通過が動かすもの |
|---|---|---|---|
| T1 | 原理実証 | 主張する機能が、統制された条件で成立したことが、第三者に検証可能な記録（査読論文・公開データ・日付のある実験記録）になっている | $g_t$ 前進。入口用途の候補が立つ |
| T2 | 再現性 | 手順書化され、実験者または装置を変えて再現が確認されている。第三者再現が最上位の証拠 | $g_t$ 前進 |
| T3 | 実環境・実規模の検証 | 実使用条件(現場・連続運転・実試料)または規模を上げた条件(ベンチ・パイロット)で性能が確認されている | $g_t$ 前進。入口用途が $A_t$ に入る（§7 の稼働開始） |
| T4 | 規格・認証試験の通過 | 該当分野の規格試験・認証・監督官庁の承認を通過している | $g_t$ 前進（規制型では支配的） |

市場系（$\psi$ は乗らない）:

| 記号 | 関門 | 通過の定義 | 通過が動かすもの |
|---|---|---|---|
| M2 | 有償評価の完了 | 需要家が対価を払って評価を完了した（請求と入金の記録） | $g_t$ 前進。支払上限 $w_u$ の証拠階級が「有償評価」へ |
| M3 | 量産条件の提示 | 需要家から量産時の価格・数量・品質の条件が文書で出た | $g_t$ 前進。$w_u$ の階級が「量産条件」へ |
| M4 | 採用決定・量産契約 | 需要家の採用決定または量産契約の締結 | $g_t$ 前進。$w_u$ の階級が最上位へ |

- 関心表明の文書（購入意向書など、支払いを伴わないもの）は関門にしない。登録簿の観測（種類8）として $w_u$ の階級「関心」に効くだけである。
- 番号 M1 を欠番にしてあるのは、この「関心は関門ではない」という線を表の中に残すためである。
- 量産原価の実証はそれ自体を関門にしない。工程の型 $\tau_{\mathrm{proc}}$ と原価下限 $\underline{c}_u$ の観測（登録簿の種類2・16の証拠）として体質へ効く。T3 の通過に原価データが伴うことは多いが、事象としては1件で記録し、効き先を型で分ける（C-3）。

### A-3 工程の型（5型）— 分野の一次分類

関門の重さ（基準速度 $\kappa_g$、第二便）と必要支出列 $\mu_t$ をここから引く。案件は主たる型を1つ選び、複合する場合は重い方に寄せて逸脱欄に書く。

| 型 | 名前 | 特徴 | 重い関門 |
|---|---|---|---|
| F1 | プロセス型 | 素材・化学・バイオ生産。規模を上げると挙動が非線形に変わる。特殊設備・プラント依存 | T3（スケール） |
| F2 | 組立・デバイス型 | 部品統合と歩留まり。試作から量産設計への谷 | T3（量産試作）・M3 |
| F3 | 規制型 | 医療機器・診断・再生医療・食品機能性など。監督官庁の承認が律速 | T4（期間が制度で決まる） |
| F4 | ソフトウェア・データ型 | 軽資本で検証が速い。技術関門より市場関門が律速 | M2〜M4 |
| F5 | サービス・手法型 | 計測・解析・受託の型。受託の稼ぎと一体で立ち上がる | M2（早期に来る） |

### A-4 記入規則と逸脱表示

1. 案件の関門列は、この表の関門種から選んで並べる（同じ種を用途別に複数置いてよい。例: 用途αの T3 と用途βの T3）。
2. **細切れの禁止**: 一つの関門種を「準備・実施・報告」のような下位段階に割って通過数を稼ぐ操作は、標準表からの逸脱として関門表の逸脱欄に表示する（本文 §9 のゲーム耐性）。
3. 表に無い関門が必要な場合は、外部検証可能性の定義（A-2 の書式）を満たす形で逸脱欄に起案し、承認後に標準表へ足す（状態表の拡張手続きと同じ）。
4. 権利・学内承認は関門表に載せない（盤面の $R_t$、本文 §4 の解決過程）。資金の採択も載せない（窓、補給であって前進ではない）。

## B. 機能分解表 — 要件9 の $\mathcal F$

### B-1 七機能を正典として採用する

経営チーム（CEO・COO・CTO）が持つべき機能の分解は、教科書 第5章 表5-4（CEO・CTO という肩書の機能分解）の**七機能**を正典として採用する。
CEO・COO・CTO の3肩書が持つべき機能はこの7つで覆う（COO の中核は「組織の構築と管理」。量産段階で機能が増える場合は拡張手続きで受ける）。

| # | 機能 $f$ | 中身 | 移せるか | 空席の埋まり方 | 空席の遅延 $d_f$ の相対順位（値は第二便） |
|---|---|---|---|---|---|
| 1 | 技術と物語の顔（エバンジェリスト） | その技術をなぜ・どこまで信じられるかを語り、聞き手の態度を変える | 移せない | 探索過程（成功確率は体質 $e$。来歴の棚卸しから） | **最大**（$d_e$。本文 §4） |
| 2 | 技術の核 | どこまで確かで、どこから先が未知か。再現条件の感覚 | 移せない | 原則、研究者本人。異動・定年は壁として盤面へ | 2位 |
| 3 | 最終意思決定と説明責任 | 進む・待つ・止めるを決め、結果を引き受ける | 移せる | AMD の供給過程（埋まるまでの月数の帯） | 3位 |
| 4 | 資金調達の実行 | 資料を作り、面談を回し、条件を詰める | 移せる | AMD の供給過程 | 4位 |
| 5 | 対外交渉と契約 | 企業・投資家・機関との条件交渉、契約実務 | 移せる | AMD の供給過程 | 5位 |
| 6 | 研究組織の運営 | 研究室・学生・共同研究先の運営管理 | 移せる | AMD の供給過程または産連・第三の担い手 | 6位 |
| 7 | 組織の構築と管理 | 採用・労務・社内の仕組みづくり | 移せる | AMD の供給過程（会社化前は空席が既定で、罰しない） | 7位（Before Zero では最小） |

- **評価時点の空席そのものは罰しない**（本文 §4）。空席は前進の遅延 $\eta_t$ として効き、埋まり方の過程を持つ。
- 会社化前に機能7が空席なのは正常な状態である。$d_f$ の効かせ方は「その機能を要する関門・過程が来ている月にだけ乗せる」を既定とする（例: 資金調達の実行の空席は、窓へ申請する月の採択・準備に効き、実験だけの月には効かない）。この「機能と関門の対応」は関門表の行に機能列として書く。

### B-2 充足の判定 — 実働の証拠

機能 $f$ が「充足」なのは、**その機能の実働の記録**が登録簿にあるときだけ（肩書・名義・意思表明では充足にしない。本文 §3 の $e$ と同じ規律）。

| 機能 | 実働の証拠の例 |
|---|---|
| エバンジェリスト | 需要家・投資家・審査への対外説明の実働（面談記録・登壇・質疑対応） |
| 技術の核 | 実験・技術判断・再現指導の実働 |
| 最終意思決定 | 会議体での決定と結果の引き受けの記録 |
| 資金調達の実行 | 申請書の作成・面談・条件交渉の実働 |
| 対外交渉と契約 | 契約交渉・締結実務の実働 |
| 研究組織の運営 | 研究室・共同研究先の運営の実働 |
| 組織の構築と管理 | 採用・労務・体制づくりの実働 |

### B-3 学術的裏付けとの対応（参照）

七機能は Morgeson ら 2010 の15機能（移行局面7＋行動局面8）を Before Zero の粒度へ束ねたものとして位置づける（対応表は付録として第二便で精査する。手順3 付録E に15機能の名称を確認済み）。移せる／移せないの線は教科書 5.5節（言葉にして渡せるか）を採る。

### C-1 様式 — 事象1件が1行

| 列 | 中身 |
|---|---|
| 事象ID | 一意の番号（案件ID＋連番） |
| 日付 | 出来事の日付（記録日と別） |
| 種類 | C-2 の16種から選択 |
| 要旨 | 1〜2文。固有名詞を含む事実 |
| 出所タグ | 文書／面談／第三者証言／公開情報（本文 §3 の証拠手順と同じ4分類） |
| 効き先の型 | 盤面（$g_t$ 前進・$R_t$ 解決/追加・$\chi_t$ 契約・$A_t$ 稼働・壁の設定）／体質（どの成分の帯）／地図（窓の追加・消滅）／規則（計画の版更新） |
| 効き方 | 前進の確定／帯の上限・下限・確信度の変化／階級の昇格（昇格は一方向） |
| 記録者と評価版 | 誰が記録し、どの評価の版に反映したか |

### C-2 出来事の種類（初期リスト16種）

| # | 種類 | 主な効き先 |
|---|---|---|
| 1 | 検証関門の通過（T1〜T4・M2〜M4） | 盤面 $g_t$・履歴 $n_t$。T3 は $A_t$ に入口用途を追加 |
| 2 | 検証の不成立（試行の失敗） | 履歴 $n_t$（計画規則の失敗分岐の入力）・体質 $\psi$ の帯 |
| 3 | 公的資金の採択通知 | 補給 $z^{\mathrm{r}}$・履歴 $n_t$ |
| 4 | 公的資金の不採択通知 | 履歴 $n_t$（$\phi$ の較正入力） |

| 6 | 権利・承認の解決（帰属確定・共同出願同意・ライセンス条件合意・利益相反承認） | 盤面 $R_t$ |
| 7 | 権利・承認の残件の新規判明 | 盤面 $R_t$（追加） |
| 8 | 需要家の関心表明の文書（購入意向書・共同評価の合意） | 体質 $w_u$ の階級「関心」（関門ではない） |

| 11 | 受託・共同研究契約の締結・満了 | 盤面 $\chi_t$・サービス用途の $A_t$ 追加（実績が立ったとき） |
| 12 | 会社化 | 盤面 $\iota_t$・燃焼 $\mu^{\mathrm{f}}$ の固定費増 |
| 13 | 人の実働の記録 | 機能分解表の充足（$\eta_t$）・体質 $e$ の更新（エバンジェリスト実働のみ） |
| 14 | 人の異動・定年・離脱の判明 | 壁の設定・機能の空席化 |
| 15 | 競合の出願・参入・撤退・実用化 | 体質 $\kappa_{\mathrm{IP}}$・$\alpha_u$・消失率 $\lambda^{\mathrm{comp}}$ |
| 16 | 用途の拡張の証拠（第三者データ・単位採算・天井への経路の三点） | $A_t$ への拡張用途の追加（三点が揃った事象だけ。本文 §9） |

### C-3 二重更新の防止規則

1. 一つの出来事は事象1件。効き先が複数あるときは同じ行に列挙し、**同じ成分へ二回効かせない**。
2. 証拠階級（$w_u$ の関心→有償評価→量産条件→量産契約）は昇格のみの一方向。同じ階級内で件数を重ねても帯の確信度が上がるだけで、階級は上がらない。
3. 一つの事象を複数の評価版で使ってよいが、同じ版の中で同じ成分へは一度だけ。
4. 記録の粒度に迷ったら「その出来事を外部の第三者に一つの事実として説明できる単位」で切る。

## D. 計画規則テンプレート

### D-1 選択式の分岐（6項目）

計画の規則 $\pi^{\mathrm{plan}}$ は次の6項目の選択で登録する。**登録者は AMD（評価者）**。案件側の自己申告ではない（本文 §6）。
すべての条件は盤面 $x_t$（履歴 $n_t$ を含む）だけに条件づける。

| 項目 | 選択肢 | Tier 0 既定（較正前の初期値） |
|---|---|---|
| R1 関門の順序 | 関門表から選んで並べる | 工程の型の標準順（F1/F2: T1→T2→T3→M2→M3→M4、F3: T1→T2→T4→T3→M2→M3→M4、F4/F5: T1→T2→M2→T3→M3→M4） |
| R2 失敗の分岐 | 関門 $g$ の不成立が $k$ 回続いたら { 再試行 ／ 用途を変えて再挑戦（ピボット）／ 撤退 } | $k=2$ で用途変更を検討、$k=3$ で撤退 |
| R3 会社化の条件 | (a) 量産条件の提示 かつ 権利残件ゼロ ／ (b) 有償評価完了 かつ 公的採択 ／ (c) 民間調達の条件成立 ／ (d) 受託の稼ぎが想定固定費の一定割合を賄う | (a)（M3 通過 ∧ $R_t = \varnothing$） |
| R4 実現の申し出への応じ方 | { 関門 $g^*$ 以降なら検討 ／ 常に検討 ／ 受けない } | T3 以降なら検討 |
| R5 受託の方針 | 工数上限 $\rho_{\max}$ と、受ける条件（月あたりの稼ぎの下限） | $\rho_{\max}=0.3$。稼ぎの下限は燃焼 $\mu_t$ の1割 |
| R6 撤退の条件 | 燃料の残りが $x$ か月分を切り、地図上に届く窓が無いとき撤退 | $x=6$ |

- 既定と違う選択をした項目は、登録時に**既定との差**として表示する（本文 §6）。
- 規則の変更は評価の版の更新として記録する（登録簿の種類「規則」）。遡って書き換えない。

### D-2 Tier 0（未登録の案件）

登録が無い案件は、工程の型 F1〜F5 を選ぶだけで D-1 の既定列がそのまま計画規則になる。これで**全案件にスコアが定義される**（本文 §6）。

### D-3 診断との関係

最適規則 $\pi^{*}$ との差の診断（会社化の早すぎ・遅すぎ、撤退条件の甘さ・厳しさ、受託の過不足）は、R1〜R6 と同じ6項目の上で表示する。診断のための方針探索の格子は、R2 の $k \in \{1,2,3,4\}$、R3 の (a)〜(d)、R4 の $g^*$ 全候補、R5 の $\rho_{\max} \in \{0, 0.15, 0.3, 0.5\}$、R6 の $x \in \{3, 6, 9, 12\}$ を既定とする。

## E. 値3つ

### E-1 社会的割引率 $d = 2.0\%$（年）

**採る値**: 中心 2.0%。感度検査に 1.0% と 4.0% を必ず併記する。

理由:
1. BZM 3.0 の $d$ は「失敗の可能性を含まない、社会の時間選好」である（本文 §7: リスクの上乗せをしない——失敗は道筋の確率で数えている）。リスクを含む資本コスト（VC の期待収益率など）を使ってはならない。
2. 日本の公共事業評価の現行運用 4% は、2000年頃の長期国債の実質利回りを参考に設定されて以来据え置かれており、その後の金利実勢と乖離している。国側でも見直しの検討が始まっている（2026年、経済財政諮問会議での国土交通大臣の表明）。
3. 近年の各国の水準は、米国 2.0%（2023年の連邦規則改定）、オランダ 2.5%、英国 3.5%（長期は逓減）であり、2.0% はこの帯の下側・米国の現行値に一致する。
4. 感度の 4.0% は日本の現行運用との突き合わせ用、1.0% は長期の産業価値を重く見る立場との突き合わせ用。スコアの帯とは別に、$d$ を動かした3本を並べて報告する（$d$ の選択がスコアを支配していないかを毎回見えるようにする）。

### E-2 経済評価地平 $T = 240$ か月（20年）

**採る値**: 評価日から 240 か月。

理由: 特許の存続期間（出願から20年）と同じ長さで、専有可能性 $\kappa_{\mathrm{IP}}$ が価値に効く期間を自然に覆う。Before Zero（数年）→ 量産立ち上げ → 普及、の時間スケールを含み、それより先は継続価値 $C$ が受ける。$T$ を長くしすぎると遠い将来の仮定がスコアを支配し、短くしすぎると $C$ の比重が上がる——240 か月はその釣り合いの初期値であり、較正の対象ではなく**規約**（全案件共通の物差し。本文 §2 の $T$ は全案件共通、の実装）。

### E-3 継続価値 $C$ の恒久形 — 既定規則での延長・一段打ち切り

**恒久形**: 地平 $T$ で未決着の盤面 $x_T$ に置く値は、「そこから先を Tier 0 の既定規則で延長して回した価値」とする。

$$
C(x_T) \;=\; \mathbb{E}\Big[\ \sum_{h=1}^{H_C} \frac{1}{(1+d)^{h/12}} \sum_{u \in A_{T+h}} \phi_u\, \frac{\bar P_u - \delta_u}{12}\,\big(1 - \alpha_u\big)\ \Big|\ x_T,\ \pi^{0}\Big], \qquad H_C = 120
$$

| 記号 | 意味 |
|---|---|
| $C(x_T)$ | 地平の月にまだ決着していない盤面へ置く継続価値（円） |
| $h$ | 地平 $T$ からの経過月（割引は $T$ からの相対時間。$\Pi$ の側で $1/(1+d)^{T/12}$ が掛かるので、合わせると絶対時刻の割引に一致する） |
| $H_C$ | 延長の長さ。120 か月（10年）で打ち切り、打ち切り時点でまだ未決着の分は 0 と数える（保守側） |
| $\pi^{0}$ | Tier 0 の既定の計画規則（D-2）。登録された規則ではなく既定で延長する——地平の先の計画は誰も登録していないため |
| その他 | $A$・$\phi_u$・$\bar P_u$・$\delta_u$・$\alpha_u$・$d$ は本文 §7 と同じ |

- 計算は本文 §8 と同じ前向きの畳み込みの続きであり、新しい計算法は要らない。**再帰は一段で打ち切る**（$T + H_C$ の先に再び $C$ を置かない）。
- 簡略形（延長計算を省く場合の下側の値): $C_0(x_T) = \sum_{u \in A_T} \phi_u\, \frac{\bar P_u - \delta_u}{12}\,(1-\alpha_u) \cdot \sum_{h=1}^{H_C} (1+d)^{-h/12}$（$T$ 時点で既に稼働している用途だけの年金価値。延長中の新規稼働を 0 と置く）。報告にはどちらを使ったかを明記する。
- 本文 §7 の「初期形」（残り関門数・燃料・権利残件に単調な線形の帯）は、この恒久形が実装されるまでの間の暫定としてのみ使い、実装後は廃止する。
