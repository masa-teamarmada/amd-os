# 戦略余力の円換算設計案

状態: proposal / 未承認

2026年11月2日。対象はSOLから試行する経営判断用の資源評価。実額の評価、本番の計算変更、SOL DDの更新は含まない。
年10%は、この会話でまさが認めた投資比較の暫定割引率。本書の換算規則・内訳・評価期間まで承認済みという意味ではない。

## 1. 定義案

戦略余力Yは、評価日時点で保有・利用できる資金、契約、技術、顧客実績、権利、人材・設備の利用権、資金獲得機会を組み合わせた、経営資源の円換算価値とする。
評価単位は会社・PJ全体の資源とし、既存株主の持分価値や産業創出価値とは別に算出する。
事業化への前進Xは、登録された事業化条件の達成状態で表す。
次の調達までの資金繰りは、現実の入出金による実行制約として別に計算する。
現在の資金繰りを原因とする存続確率をY全体へ掛けない。
Yの円換算には、特定の資源が生む受注・収益・コスト削減・資金取得の不確実性を含める。
同じ出来事がXとYの両方を変える場合は、それぞれの変化理由を記録する。

## 2. 計算単位と評価条件

全ての資源を、所有者、用途、利用期間、利用条件、利用可能量、裏付け資料を持つ一件として登録する。
大学の知財、研究設備、人材は、SOLが利用できる契約上・実務上の範囲を登録する。
将来取得する予定の知財・性能・人材は、必要な追加支出、期間、成立条件を持つ将来の行動として扱う。

Yは、資源を活用して案件を継続する共通の評価条件で測る。
継続運営・供給・開発などの経済的なコストは差し引くが、手元現金が途中で不足することによる強制終了は、資金繰り側で判定する。
評価上の継続条件は、実際に使える資金や確保済みの融資として記録しない。
追加の成長投資に必要な資金獲得機会は、その投資案を開く条件として個別に評価する。
このため、会社の資金切れ確率による一括減額と、ある投資機会に必要な調達の成立確率を区別する。

割引率は年10%、月単位では金額÷1.10^(経過月/12)とする。
金額は円で保持し、入力が名目額なら割引率も名目額に対する値として使う。
受注・継続・技術成立の確率は分岐で表し、同じ不確実性を割引率で再度調整しない。
評価期間は契約期間、商談の有効期間、技術の経済寿命などから資源ごとに登録する。
異なる案の比較では評価日・対象顧客群・期間・税とコストの範囲をそろえる。
期間の根拠が薄い資源は複数の期間で感度を示す。年10%はリスクを十分反映する実証済み係数という位置づけではない。

## 3. 資源別の換算方法

| 資源 | 必要な入力 | 円換算の方法 |
|---|---|---|
| 現金・確定した受取権・支払義務 | 残高、権利の主体、入出金月、使途制限、回収条件、返済条件 | 現金と受取権の現在価値から、既に負っている支払義務の現在価値を控除する |
| 既存顧客・契約 | 契約金額、残期間、解約・更新条件、供給・保守・営業・運転資金・追加設備の支出 | 契約から生じる将来の正味資金増減を現在価値にする。売上をそのまま価値にしない |
| 顧客実績・販路・需要家との関係 | 実績の利用許諾、対象用途、実在する顧客候補、実績の有無で変わる受注率・期間・支出 | 同じ候補群について、実績がある場合とない場合の正味資金増減の差を測る |
| 技術・知財・データ・製造ノウハウ | 利用権、再現性、生産性、処理コスト、適用範囲、残る開発、設備・品質の条件 | 生産・導入コストの低下、追加用途の収益、ライセンス収入、代替技術の取得回避コストを同じ事業案の中で評価する |
| 人材・組織・設備の利用権 | 実際に確保した工数・期間・設備枠、継続条件、代替手段、利用対価、引継ぎ可能な手順 | 外注・採用・再訓練・設備調達の回避コスト、納期短縮、実行可能になる案件の効果を評価する。給与や人数を資産額にしない |
| 資金獲得機会 | 相手、審査段階、成立条件、金額、着金月、使途、返済・持分条件、必要な準備コスト | 助成等の純受取、調達コストの改善、またはその資金で初めて開く具体的な成長投資の正味価値の差を評価する |

使途制限のある資金は、対象支出へ充当できる額・時期を確定し、自由資金と内訳を分ける。
充当先や利用条件が未確定なら条件付きの評価幅に残す。
使途制限資金・助成金を受取権として計上した場合は、同じ入金または同じ支出削減を他の計算へ重ねない。
既存の貸借に伴う債務は金融資源の控除に入れ、同じ返済を事業側で再控除しない。
未着金の融資・出資は、その額を現在の現金へ足さない。
会社の資源評価と、既存株主の希薄化・持分評価を別の計算結果として保持する。

収益の根拠が得られない初期資源には、同等の利用可能な資源を今から取得・再構築するコストを暫定代替値として使える。
過去に払った開発額は取得経緯として保持する。
再構築コストは自動的な最低価値ではなく、有用性・陳腐化・利用権を確認した別方式の推定値とする。
収益方式と再構築コスト方式を同じ資源に加算しない。方式を変えた差は、資源の獲得とは分けて表示する。

## 4. 合計額と重複の処理

### 4.1 合計額

Y = 金融資源の純額F + 非金融資源を組み合わせた価値W(R)

Fは、現在の現金・受取権・既存支払義務の純額。
Rは、現在利用できる非金融資源と、現在保有する条件付き機会の集合。
W(R)は、登録した利用・販売・ライセンス・段階投資案のうち、経済的な利用条件を満たす案について、将来の正味資金増減を評価した値。
Yの対象範囲外にある一般的な新規起業機会や、裏付けのない市場全体の利益は含めない。

W(R)は、資源・人・設備・契約を同時にどう使うかを、組み合わせて計算する。
同じ設備の売却と継続利用、同じ独占権の二重許諾、同じ工数の重複利用は同時実行できる案として扱わない。
同時に実行できない案は比較して選び、将来の結果が判明した時点で選び直す方針を登録する。
実行前に将来の成功・失敗を知っている前提で、都合のよい案だけを選ばない。
登録した案の範囲での評価であることと、未評価の資源・用途を表示する。

全ての入金・支出には一意の識別子を付け、FまたはWのどちらで評価するかを一つに決める。
売掛金をFで評価したら、その回収はWから外す。
現金化したら受取権を外して現金へ移す。
資源が生む利益・コスト削減は一つの資金増減表に一度だけ記録する。

### 4.2 内訳の配分

個別資源の価値を別々に計算して足すと、同じ後続受注を技術・実績・人材で重ねて数える。
合計Wを先に求め、内訳は資源の組み合わせに対する寄与を配分する。
初期実装では非金融資源を最大6群にまとめ、最大64通りの有無の組み合わせを評価する。

配分額は、資源群を追加する全ての順番について「追加前後のWの差」を平均する方式（シャープレイ配分）とする。
これは重複・相乗効果を内訳へ配る規約であり、各資源の因果効果が実証されたことを意味しない。
資源を外す比較では、代替取得が可能なら、その追加コスト・所要時間・条件を入れる。
内訳の配分額の合計が、配分対象のWの増分に一致することを検査する。
全体に共通する基礎資源の価値がある場合は、基礎資源を独立した内訳として残す。

## 5. 資金獲得機会の評価

助成金は、資源として使用できる純額を対象支出・入金時期・条件つきで評価する。
融資・出資は、調達額そのものを利益として計上しない。
融資条件の改善は、利息・手数料等の差として評価できる。
出資条件の改善は株主別評価へ反映し、会社全体の資源額に希薄化の金額を混ぜない。

成長投資を開く資金獲得機会は、次の比較で評価する。

機会の増分価値 = その機会がある場合のW − その機会がない場合のW

同じ投資案・同じ条件付き正味価値で、成立見込みだけが変わる簡単な例では、確率の差×当該投資案の正味現在価値になる。
当該投資案の追加開発・設備・運転・資金調達の実務コストは、既にその正味価値へ含める。
借入で賄う場合は返済義務を含む金融資源との対応を一意にする。
会社の既存運営の資金切れ確率は、この成立見込みとは別に保持する。
後続顧客の利益を既にWへ入れている場合は、同じ顧客群を調達の効果としてもう一度足さない。
技術と実績が同じ投資家・顧客の判断へ効く場合は、独立した確率として機械的に掛けない。

## 6. 5,000万円の顧客獲得例

### 6.1 入力

以下は計算方法の確認用の合成事例。SOLの実績・予測・評価額ではない。
評価日直後に初回の開発・顧客獲得へ5,000万円を支出し、技術改善と利用可能な顧客実績を取得した場合を比較する。
支出前の現金は1億円。既存のその他の資源・負債は比較の両側で同じとする。
過去の支出額を技術や実績の評価額として転記しない。

| 入力 | 改善前 | 改善後 |
|---|---:|---:|
| 顧客1件の年間売上 | 200万円 | 200万円 |
| 供給・保守等を差し引いた年間の正味入金 | 100万円 | 100万円 |
| 契約が続く期間（例の仮定） | 5年 | 5年 |
| 後続の顧客候補 | 40社 | 同じ40社 |
| 後続受注率（例の仮定） | 10% | 30% |
| 後続1件の獲得・導入支出 | 200万円 | 100万円 |
| 後続の契約・導入時点 | 12か月後 | 12か月後 |

初回契約の年間正味入金は12・24・36・48・60か月後。
後続契約の獲得・導入支出は12か月後、年間正味入金は24・36・48・60・72か月後。
年10%で全て評価日へ割り引く。
候補群の集計はこの例では線形とし、必要な供給工数と能力が同時に確保される条件を置く。
実入力では、共有の技術失敗・供給制約・顧客集中を共同分岐へ入れる。

### 6.2 計算結果

| 項目 | 改善前 | 改善後 | 差 |
|---|---:|---:|---:|
| 現金 | 10,000万円 | 5,000万円 | −5,000万円 |
| 初回契約と後続候補群の価値 | 651万円 | 3,424万円 | ＋2,772万円 |
| 比較対象の戦略余力Y | 10,651万円 | 8,424万円 | −2,228万円 |

内部計算は円の丸め前で行う。表は各セルを万円単位に丸めるため、表示差に1万円程度の差が生じうる。
この仮定では、技術・実績が約2,772万円の資源価値を増やしても、5,000万円の現金消費を埋めない。
同じ条件の対象候補が約78社以上ある場合に、この比較の差がゼロ以上になる。
候補数・受注率・契約期間は実際の裏付けを必要とする。

約2,772万円の増分は、技術改善（後続導入コストの低下）に約727万円、顧客実績（初回契約と後続受注率の上昇）に約2,045万円と配分できる。
これは二群の全ての追加順序を平均した配分で、初回支出の会計的な按分ではない。

### 6.3 調達への波及

仮に、上の40社とは重複しない別用途の成長投資があり、その投資の追加支出を全て引いた正味現在価値を1億円とする。
その投資を開く資金獲得の成立見込みが20%から60%へ変わるなら、他の条件が同じ場合の増分は4,000万円になる。
この独立した増分まで裏付けられれば、上の比較差は約＋1,772万円に変わる。
この例では改善前の成長機会2,000万円と改善後6,000万円も、それぞれのYに含めて比較する。
比較差だけを示す場合も、改善前に既に持っていた機会の価値を落とさない。
実際の計算では資金・工数を同時に使えるかを確認し、競合する場合は両方の満額を合算しない。

## 7. 更新と増減の説明

| 出来事 | Yの扱い | 資金繰り・Xの扱い |
|---|---|---|
| 開発費を支払う | 現金を減らす。取得した利用可能な成果は、その時点の証拠で再評価する | 支払月の現金を更新し、達成した事業化条件だけXへ反映する |
| 顧客と契約する | 既存の商談機会を契約へ移し、価値の差だけ反映する | 供給・請求・回収予定を更新する |
| 売掛金を回収する | 売掛金から現金へ振り替える。回収額を新しい価値として再加算しない | 実際の着金を反映する |
| 調達条件を満たす | 資金機会・成長機会の条件と価値を更新する | 現金への加算は実着金時点。未達時の日程も保持する |
| 出資金が着金する | 現金と残る機会を再評価し、外部からの資源流入額を分けて表示する | 支払可能額・持分の記録を更新する |
| 融資が着金する | 現金と返済義務を同時に登録し、未実行枠・機会を更新する | 流動性は改善する。借入額を純資源の無条件の増加にしない |
| 実績が横展開に使えないと判明する | 影響する顧客群・機会の評価を修正する | 事業化条件と営業計画を更新する |
| 人材・利用権・契約を失う | 利用可能な資源と代替取得コストを再評価する | 担当・期限・供給計画を更新する |

資源の実取得、外部資金の流入、分配、予測の見直し、時間経過、方式変更を別々の増減要因として記録する。
実績の取得前に既に見込んだ価値を、取得後にもう一度全額加算しない。
取得前に具体的な取得権・投資機会の価値を既に計上している場合は、その機会を取り崩して取得資源へ振り替え、差だけを増減にする。
現在保有する資源・具体的な選択権の評価と、投資案が将来取得する資源の予測を別の状態として保存する。
本書の顧客獲得例の基本比較は、初回契約・実績をまだ計上していない状態と取得後の状態の比較であり、取得権が既に評価済みならその取崩しも必要になる。
投資前後の効果比較は、同じ評価日・同じ評価条件へそろえた二つの状態で行う。
受注や調達の前進が失敗した場合の線も残し、成功時の線と確率を織り込んだ線を区別する。

## 8. OSの表示と記録

### 8.1 表示

主表示は戦略余力Yの円額・推定幅・評価日時とする。
内訳は金融資源、契約、技術、顧客実績、人材・設備、資金獲得機会などに分け、合計との一致を保証する。
横軸Xは登録済みの事業化条件の達成状態とし、段階を恣意的な百分率へ変換しない。
X・Yの図では各投資前後の点を結び、支出額と獲得資源を付記する。
計画の経過時間は各点の日付として持ち、資金繰りは同じ日付の別欄に現金残高・着金予定・不足月を表示する。
未評価資源、古い入力、評価方式、条件付きの機会を、金額の根拠から確認できるようにする。

### 8.2 記録項目

| 記録 | 必須項目 |
|---|---|
| 資源 | 識別子、区分、所有・利用主体、用途、量・期間、制限、権利・契約、取得日、根拠 |
| 顧客・資金機会 | 相手、対象用途、現在の段階、金額、条件、期限、成立見込みと幅、比較する条件 |
| 資金増減 | 一意の識別子、入出金月、金額、必要資源、分岐条件、F/Wの評価先、既存計上先 |
| 評価条件 | 評価日、年10%、期間、対象範囲、継続条件、税・コスト範囲、比較群、推定規則、版 |
| 評価結果 | Y・F・W、内訳、下位・基準・上位の条件別結果、未評価、入力の照合値、変更理由 |
| 実行計画 | 投資、完了条件、獲得資源、Xの変化、支払・着金月、必要資金、不足時の対応 |

記録の証拠段階は実測、観測から計算、推定、条件付き、未取得を分ける。
未取得をゼロとして保存しない。既知部分の小計と未評価範囲を表示する。
範囲が統計的に較正されていない場合は信頼区間と呼ばず、入力条件を変えた評価幅と呼ぶ。

### 8.3 更新処理

会計・契約・実験・営業・資金調達の確認済み記録の変更を起点に、影響する資源と資金増減だけを再計算する。
抽出された候補は根拠と比較対象を持ち、人が確認してから評価入力へ採用する。
受注率などの推定は、同用途・同規模の候補群と成功・失注・保留をそろえて更新する。
単純な実績取得前後の差だけで、その実績の因果効果が確定したと扱わない。
推定に使った資料、仮定、期間、採用者を保存し、後から実績と照合する。
単純な現金・受取権は確認後すぐ更新し、組み合わせ評価は変更対象をまとめて再計算する。
完了するまでは前回値と再計算中の表示を保ち、新旧の内訳を混在させない。
資料が古いだけで一律に金額を減らす係数を付けず、契約期限・技術陳腐化・候補失効など、資源の変化または推定の幅へ反映する。

## 9. 検証と導入範囲

初回はSOLの現金・支払義務、初回顧客契約、再利用する技術、同用途の後続顧客群、具体的な資金獲得機会を対象にする。
本書の合成数値を実データへ転記しない。
既存の獲得台帳の根拠・取得事象・消費資源を利用し、評価条件・資金増減・重複配分の記録を追加設計する。
新旧モデルの数値を同じ既存スコアとして置き換えず、提案の試算として照合する。

必須検証は、資金繰りの前提だけを変えた場合のYの不変、Xの表示段階だけを変えた場合の不変、資源取得・喪失時の再評価、受取権の現金化、借入と債務、同一資金増減の二重計上拒否、相乗効果の内訳合計、相互排他案と共有資源、同じ日付への割引、未取得の保持とする。
同じ資源がXの達成条件の証拠でもあることは認めるが、Xの数値を掛けてYを増減させない。

この変更は、現行モデルの戦略余力定義・計算対象・入力契約の改訂提案にあたる。
現時点の成果物は設計案と合成例の検算であり、確定モデル、既存スコア、DB、本番の算出処理には反映しない。
承認後の実装では、モデルページ本体・承認記録・ロック、利用者向け説明、実装仕様、各層の変更履歴を同時に更新する。
PWA以外の利用者にも同じ資源評価・資金繰りの区別を渡す。今回の設計作成時点のプラットフォーム実装差分はない。
