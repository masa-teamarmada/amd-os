## 経済学者（全文）

### 解消判定

- **経済 P0-1（価値の発生時点／売上経路）: 部分的** — 発生時点は A-2 で M4 へ移り、稼働用途の離脱も改訂提案1-2 と登録簿の種類12 で入った。ここは解けている。しかし売上経路は閉じていない。改訂提案1-1 が新設した会社の月次売上（y_t）を記録する種類が、C-2 の23種のどこにもない（種類13 は受託契約の月額＝χ_t 側、種類9 は M4 での稼働開始のみ）。改訂提案1-1 自身が「実績は登録簿で更新し」と書いている以上、その更新経路の欠落は閉包の穴である。
- **経済 P0-2（打ち切り）: 部分的** — 一律ゼロ打ち切りの廃止・ハザード付き永久価値・C の一本化・比率併記・C(x_T,θ) への引数訂正は達成。しかし陳腐化率（λ^obs）が地平＋延長（T+H_C＝360か月）以降にしか効かない構成のため、水準は打ち切り版より真値から遠くなっており（N-1 の試算で約2倍過大）、地平依存も残っている。P0-2 が壊れていると指摘した三つ（水準・順位・感度）のうち、直っているのは「感度検査が裾を切らない」ことだけである。
- **経済 P0-3（条件づけ／格子）: 部分的** — R3(d)・R5 は契約月額へ、R6 は地図上の窓の到達性へ書き換えられ、6項目すべてが有限選択肢になり、格子＝直積・R1 固定が明記された。計画が構成上格子に入るという形式的閉包は達成している。ただし R2 に新設された滞留自動分岐が、期待所要月数という体質（ψ・c・κ_g）の関数を閾値に持ち込んだ。「中央値」が何の分布上の中央値かが書かれておらず、書かれていない限り実装は各体質ごとの期待所要月数（＝明白な違反）にも落ちうる。

### 新規 P0 相当

- **[N-1] E-3（陳腐化ハザードの適用区間）**: λ^obs は「実現した産業の陳腐化・代替の年率」と定義されているなら用途が稼働に入った月から効くはずだが、式では終端の永久項にしか入っていない。t=60 で月額 y の用途が稼働する例（d=2.0%、λ^obs=5%）で、第2案の C は 309.5y、稼働開始から陳腐化を効かせた値は 155.9y、第1案の360か月ゼロ打ち切りは 215.0y——**第2案は打ち切り版より真値から遠い**。さらに T+H_C を240／360／480か月と振ると 257.0／309.5／352.6y と 2〜4割動くので、E-2 の「C を E-3 の形で置けば T の選び方は水準をほとんど動かさない」は成立していない。修正: 陳腐化を稼働開始時点から全区間に効かせる（生存確率を掛ける）。あわせて本文 §5 の λ^dem と λ^obs の関係を書く。
- **[N-2] A-2 注記（M4 参入と立ち上がりの織り込み先）**: 「立ち上がりの遅れは φ_u の帯に織り込む」は、本文 §3・§7 が時間不変の割合として宣言した φ_u の無断拡張。(a) 終端の永久価値にも割引かれた φ_u が掛かり30年後の定常にまで立ち上がり期の過小が残る、(b) κ_IP の較正が立ち上がり情報で汚染される、(c) 第二便の「残存期間逓減」と合わせると φ_u が三役になり識別できない。第1ラウンド経営学 P0-2（η の局所化）と同型の違反を「撤回した」と書いた直後に別の記号で繰り返している。修正: 立ち上がりは A_t 側の遷移として本文改訂提案へ。
- **[N-3] C-2（23種）**: 改訂提案1-1 が新設した y_t の観測経路が無い。y_t は遷移式と資本自立判定を通じて q_o を動かす一次の量。M4 翌月から満額の売上が立つ扱いのため資本自立の到達時期が系統的に早まる。修正: 種類を足して効き先を y_t と定義し、立ち上がりを y_t 側にも置く。
- **[N-4] E-3（延長の対象）**: 「地平 T で未決着の盤面から」と限定しているが、本文 §7 の A_t は実現の形を問わず数えるので、ライセンス・M&A・資本自立で決着した道筋も地平以降に国内付加価値を立て続ける——この分を拾う場所が式に無い。早く決着した道筋ほど地平以降の価値を丸ごと失い、早期のライセンスアウト・売却が構造的に過小評価される（VC P0-6 の歪みを価値の側で再生産）。修正: C を終端盤面すべてに適用する関数と定義し直す。

### P1 相当

- **[P1-a]** R2 の期待所要月数の式の誤り: 本文 §4 の前進確率は (1−γρ_t) を含むが式から落ちている（受託に工数を割く案件ほど滞留判定が過剰発火。R5 の型別既定と合わせ型別の偏りになる）。離散月次ハザードの期待値は 1/p^adv であって 1/(κψcη) ではない。「中央値」は「評価日の信念 B_0 の下での中央値」と明記すれば条件づけ規律には抵触しないが、その瞬間、計画規則が B_0 に依存する——閉包表にも §6 にも無い依存であり、版の更新で規則が変わり時間整合検査を汚す。滞留を「不成立1回と同等」に数えると種類23 と種類10 の両方で帯に効き、二重計上に触れる。修正: 式に (1−γρ) を戻し、B_0 中央値と明記し、依存を宣言し、滞留の効き先を n_t に限る。

### 事実確認

- ラムゼー式の合成帯が導出できない: 下限の組合せは 0.5＋1×0.5＝1.0% であって 1.3% は出ない。中央は約1.7%。「中心2.0%」は誇張で、2.0% は帯の上寄り（スコアを控えめに出す側）。
- パラメータ: δ 0.5〜1.0% は標準的。μ 1〜1.5 は実証（1〜2）の下半分のみ。g 0.5〜1.0% は日本の一人あたり実質家計消費の直近実績（年0.3%程度）より上寄り。μ 上限2.0・g 下限0.3% へ広げると帯 0.8〜3.0% になり 2.0% が中央寄りになる。
- 米国: 2023改定・2025撤回の事実関係は正しいが、規制影響分析（A-4）と投資評価（A-94）の区別が付いていない。BZM 3.0 が引くべきは投資評価の側。
- オランダ: 2.25%（2020年・割引率作業部会）はリスクフリー＋リスクプレミアム構成で、リスク別立ての BZM 3.0 とは英国以上に構成が違う——注記が英国だけに付いてオランダに無い。
- 日本: 「国側に見直しの議論がある」は出典が無ければ落とすほうが安全。
- 永久年金係数 q/(1−q) の算術は正しい（陳腐化5%・割引2% で 171.2 か月、連続時間近似と一致。終端割引との合成に重複も隙間も無い）。C-2 の種類数23 も勘定が合う。
