# 戦略余力の資源評価理論

状態: proposal / 未承認

2026年11月3日。BZMへの追加案。11月2日の円換算設計案を、文献・設立前の評価主体・数理的な成立条件から補強する初稿。
対象は研究PJから設立後の事業まで。SOLを検証事例とする。現行モデルの計算・係数・DBは本案の対象外。

## 1. 定義と適用範囲

**戦略余力Yは、あるPJが評価時点で利用できる資源と具体的な選択機会の組み合わせが、共通の評価条件の下で持つ、正味の経済価値を円で表した量とする。**

技術、研究データ、顧客実績、設備、人材へのアクセス、契約、資金獲得機会を対象にできる。
資源の価値は、収益、支出回避、実行可能になる追加投資、学習後の選択に現れる。
評価対象は現在の利用可能性と、その資源に根拠を持つ機会である。将来の市場規模全体は評価条件に置く。

次の三つを区別する。

| 測定対象 | 表すもの | 測定方法 |
|---|---|---|
| 戦略余力Y | 現在の資源・選択機会の経済価値 | 円換算。評価日・条件・推定幅を併記 |
| 事業化の前進X | 登録した事業化条件の達成状態 | 技術、供給、契約等の条件ごとの到達記録 |
| 実行計画の資金繰り | 現実の着金と支払で計画を続けられるか | 月別残高、使途制限、調達条件、不足時点 |

YとXの変化は同じ出来事から起きうる。例えば顧客検収は、事業化条件を満たし、横展開に使える実績も取得する。
Xの表示段階だけを変更した場合はYを変更しない。手元資金不足による強制終了の確率は資金繰り・実行計画で扱う。

Yの円換算は、資源価値を測るために将来の正味資金収入を使う。
したがって、割引現在価値や成長機会の価値はYの測定方法に含まれる。NPVもYも単位は円である。
評価対象・帰属先・継続条件が一致する別のNPVと同じ値になる場合は、同一量として扱う。

## 2. 先行研究と本案の追加範囲

| 文献 | 確認できた主張 | 本案で用いる範囲 |
|---|---|---|
| Bourgeois（1981）[1] | 組織の余剰には適応・戦略行動を支える役割があり、測定方法の設計が必要 | 余力の機能を検討する出発点。今回の円換算式や分類を直接与える文献ではない |
| Barney（1991）[2] | 資源の異質性や模倣・代替の難しさが、競争優位の持続性に関係する | 人・組織・技術・関係を調べる視点。価値が利用者や状況に依存する根拠 |
| Dierickx・Cool（1989）[3] | 重要資源には時間をかけた蓄積、相互依存、減耗などがある | 投資額と資源残高を区別し、実績やノウハウの形成過程を記録 |
| Teece（1986）[4] | 技術から得られる利益の帰属には、権利保護と製造・販売等の補完的資産が効く | 技術単独の金額と、事業で利用できる資源束の金額を区別 |
| Roberts・Weitzman（1981）[5] | 研究開発は情報を得ながら継続・中止を選べる逐次投資である | 実験・初号機の評価に、学習後の行動変更を含める |
| Adner・Levinthal（2004）[6] | 分割投資という形式だけでは、実物投資の選択権は成立しない | 次の行動、選択時点、中止条件、追加費用を具体的に登録 |
| Kerr・Nanda・Rhodes-Kropf（2014）[7] | 起業には、実際に投資して初めて分かる不確実性と実験の制約がある | 初期の確率推定を更新可能な仮説として管理 |
| Bolton・Wang・Yang（2019）[8] | 資金制約は成長・撤退の選択肢と企業価値に影響する | Yから当座の資金繰りによる強制終了を分けるには、共通の評価条件が必要 |
| Bogetoft・Kerstens（2022年オンライン公表）[9] | 同じ生産と余剰をより安く維持できるなら、その追加費用には削減余地がある | 資源や選択肢を維持したまま支出を減らす案を比較 |
| IFRS概念フレームワーク（2018）[10] | 評価主体は必ずしも法人ではなく、経済的資源は便益を生む可能性のある現在の権利 | 法人名より、利用主体・権利・義務・評価範囲を明記 |
| WIPOの技術移転向け評価資料[11] | 初期知財の価値は用途・残存寿命・追加開発等に依存し、収益・市場・コスト・選択権の方法がある | 円換算方法と、その方法で答えられる範囲を記録 |

本案はこれらを組み合わせた経営用の測定設計である。
「六つの資源項目で必要十分」「固定した重みで合算できる」「円換算が実証済み」という結論は、確認した文献からは得られない。
また、従来の組織の余剰は、必要量に対する余剰・未配賦資源を論じることが多い。
本案のYは、事業に投入中の技術や実績も含む資源価値であり、既存用語より対象が広い。
理論上の追加範囲は、研究PJ単位の利用可能性、円換算の比較条件、資源の変換記録、X・資金繰りとの区別にある。
学術上の独創性や実証的妥当性は、今後の検証課題である。

## 3. 設立前の評価主体と資源の境界

評価主体は法人に限定せず、目的・関係者・活動範囲を登録したPJとする。
大学、研究者、支援者、設立後の会社が持つ権利について、PJが使える部分を一件ずつ記録する。
対象は事業化活動に利用できる権利の束とし、大学法人や協力企業の財産全体を合算する範囲とは区別する。
大学から将来の商用ライセンスを取得する場合、その対価は当該利用権を得るためのPJ側の費用となる。
大学への便益や社会全体への便益を測る場合は、帰属先を変えた別の評価として計算する。

| 記録する単位 | 必須の内容 |
|---|---|
| 資源の利用可能性 | 資源ID、権利・許可の保有者、利用者、用途、数量・工数・能力、期間 |
| 条件と証拠 | 対価、承諾者、撤回・更新条件、代替手段、根拠資料、確認日 |
| 事業化への引継ぎ | 設立後に利用・譲渡・再許諾できる範囲、追加手続、追加対価、未合意事項 |
| 具体的な選択機会 | 相手・対象、開始期限、次の判断、追加費用、必要資源、継続・中止条件 |

所有、確定した利用許諾、運用上の協力、将来の交渉機会を区別する。
協力関係も評価対象になりうるが、継続性や利用範囲の不確実性を評価に含める。
独占性は価値を左右する条件の一つであり、すべての資源に求める要件ではない。

研究用途で使える資源と商用で使える資源は、用途ごとの権利を持つ。
設立前後を比較する際は同じPJを追跡し、法人名の変更だけではYを変えない。
ライセンス成立、研究者の参加、設備の利用範囲変更など、実際に変わった権利と対価を増減として扱う。

複数PJが同じ設備や担当者を使う場合は、時間・能力を共有制約として持つ。
PJ別の条件付き評価額には同じ資源の寄与が含まれうるため、スタジオ全体では共有資源を含めて再計算する。

## 4. 円換算の評価条件

同じ資源でも用途、相手、代替手段、時期によって価値が変わる。
比較に先立ち、次の条件の集合をΘとして固定する。

| 条件 | 内容 |
|---|---|
| 主体と帰属 | 対象PJ、含める権利、利益の帰属先、大学・会社・出資者の範囲 |
| 評価日と期間 | 同じ評価日、権利の期限、技術の経済寿命、期間末に残る資源 |
| 用途と代替案 | 対象市場・候補群・行動、代替取得の価格と所要時間、比較の基準となるPJ |
| 資金・コストの範囲 | 税、運転資金、維持・追加開発、通常の資金手当ての経済的負担 |
| 情報と不確実性 | 評価日に得ている証拠、結果の分岐、共同故障、推定幅 |
| 継続の前提 | 資源を利用できる主体の継続を評価上確保し、当座の現金不足による強制終了を分離 |
| 割引 | 暫定年10%。名目・実質の対応、各入出金の時点、感度の範囲 |

継続の前提は、このYを資金制約下の会社売却価値と区別するための測定上の仮定である。
費用は引き続き差し引く。資金手当てを無料の入金として追加せず、実際の確保資金にも登録しない。
この前提を具体化できない場合は、Yの値を比較可能な測定結果として確定しない。

既存活動の当座の資金不足と、追加の成長投資を可能にする調達機会は分ける。
後者では「PJが継続している条件で、現在の技術・実績を示したときの審査成立率・条件」を評価する。
その日まで生き延びる確率は実行計画で計算する。この二つの確率を別の入力として保持する。
両者が分離できるという仮定が弱い案件では、複数の継続・資金手当て条件による評価幅を示す。

成功確率は将来の入出金の期待値に、資本の機会費用等は割引条件に対応する。
期待キャッシュフローを使うことと、リスクを含む割引率を使うこと自体は両立する。
同じ危険をどこで評価したかを記録し、年10%を全リスクの実証済み換算率とは扱わない。

## 5. 資源束の評価式

本節は測定方法の提案であり、現行BZMの確定式ではない。

評価時点の資源を、自由に利用できる現金・無条件の金銭請求権・既存債務の純額Fと、それ以外の利用権・条件付き資金・具体的機会の集合Rに分ける。
使途制限付き研究費はRに含め、対象支出に利用できる条件を持たせる。
既存債務はFで一度控除し、将来の入出金でも同じ債務を再控除しない。

```text
Y(t; Θ) = F(t) + WΘ(R(t))

WΘ(R) = GΘ(R) − GΘ(基準PJ)

GΘ(R) = 実行条件を満たす行動方針ごとの期待正味現在価値の最大値
```

正味現在価値には、将来の売上入金、助成の純利用便益、運営・開発・設備・営業等の支出、期間末の残存価値を含む。
未取得の資源を必要とする行動は、取得費用・所要時間・成立条件を伴う。
行動方針は、その時点までに得られた情報だけで次の行動を選ぶ規則とする。
設備・人の工数・供給能力・用途制限による同時実行の制約を満たす。
当座の現金残高を原因とする終了だけは、§4の共通条件に従って分離する。

基準PJは、登録した固有資源をまだ持たず、同じ市場・一般的な取得手段を利用する比較対象とする。
その目的・初期権利・取得可能な代替資源を明記し、評価期間中は同じ基準を使う。
基準PJ自身に正の機会価値がある場合は、それを差し引く。これは単位を円にそろえるための評価基準であり、既存BZMの産業価値から反実仮想を控除する変更ではない。

これにより、Yは「登録した現在資源の、共通条件・共通基準に対する価値」として定まる。
基準の選定には判断が必要であり、目的や比較対象から独立した唯一の円額は主張しない。
比較条件と基準が同じなら、投資案の差額では共通する基準項が相殺される。

### 5.1 収益・市場・コストの方法

基本の計算は、同じ資源束を使う行動方針の正味入出金から求める。
市場取引や再取得見積は、売却・再取得の行動や評価入力として組み込む。
同じ設備について使用による利益と売却による利益が相互排他なら、選べる方針の中で評価する。

再構築費用しか分からない段階では、その金額を代替的な参考値として表示できる。
収益による評価と再構築費用は答える問いが異なるため、参考値と主評価を区別する。
実際の投資支出額は資源取得の記録とし、取得資源の価値は利用条件・将来便益から測る。

### 5.2 相乗効果と選択肢

技術単独では売れず、実績単独でも売れないが、両方あると受注できることがある。
この場合、合計を先に評価する。個別資源を単独で値付けして合算する方式では、相乗効果が落ちる。
一方、同じ設備で同時に選べない二用途は、排他条件を持たせる。
行動名を増やすだけで同じ成果が増えることはない。

学習は、実験結果を見て継続・中止・用途変更を選べることで価値を持つ。
情報を得る権利があり、追加費用なしで無視でき、選択の柔軟性を保てるなら、情報取得前の期待価値は低下しない。
有料の実験は情報の価値から実験費用を引いて判断する。取得後に失敗が判明した状態のYは下がりうる。

## 6. 分類と二重計上の防止

資金、技術、顧客、権利、人材・設備、資金獲得機会という分類は、資源を探すためのタグとする。
必要十分性は、分類名ではなく、定義した行動の入力をどこまで記録できたかで検討する。

| 層 | 完全性・重複の扱い |
|---|---|
| 資源・利用権 | 同一の権利を一つのIDで管理。用途・期間・能力の異なる部分を必要に応じて分割 |
| 分類タグ | 複数付与。技術と資金調達等の重なりを保持 |
| 入出金 | 一つの経済的な入出金を一つのIDで管理し、FかWの評価先を一つに決定 |
| 行動方針 | 共通資源、排他条件、同じ売上・成果の重複を検査 |
| 金額内訳 | 資源束の合計を配分し、内訳合計との一致を検査 |

内訳には、資源を追加する順番ごとの限界寄与を平均するシャープレイ配分を使える。
例えば技術と実績の二つを組み合わせた価値だけが1,000万円なら、対称な条件では各500万円となる。
配分額は他の資源との組み合わせに依存し、個別の売却価格や実証済み因果効果とは区別する。
グループの分け方によって配分が変わりうるため、評価時の単位を保存する。

必要資源の記録については、登録した用途・期間・行動を実行できるか、根拠をたどって点検する。
その範囲内での計算の完全性と、未知の用途も含む事業機会の網羅性を区別する。
未発見の将来用途には任意の上乗せを付けず、用途を探索する具体的な行動と費用を登録する。
未確認・未評価はそのまま残し、小計の対象範囲を示す。

## 7. 投資と資源の増減

開発投資による効果は、同じ評価日・同じ外部条件で、投資する方針と比較方針の差として計算する。

```text
投資案の増分価値
  = 将来の正味入出金と残存資源価値の差の現在価値

終了時点で、追加の資源価値ΔWを得る単純な比較
  = ΔWの現在価値 − 追加支出の現在価値
```

途中で得た利益や残る権利は一度ずつ計算する。
取得前に既に評価した投資機会・受取権は、取得・現金化時に取り崩して新しい資源へ移す。
購入や検収のたびに、取得資源の満額が新たな利益になるとは限らない。

例えば、同じ評価日で現金1億円と、5,000万円を払えば現在価値1億円の資源を確実に得る権利を持つ場合を考える。
ほかの資源と代替案をゼロとする合成事例では、投資前のYは現金1億円と投資機会5,000万円の計1億5,000万円。
実行後は現金5,000万円と取得資源1億円の計1億5,000万円になる。
行使する価値がある権利の資源化であり、既知の権利を新しく発見した増加とは区別する。
このため、投資する方針と権利を失効させる方針の価値差、権利行使前後の資源残高、成果が予想と異なったことによる再評価を別々に表示する。
将来機会を現在Yへ含める設計では、予想どおりの進捗による価値が先に含まれることがある。

Yの時系列では、外部からの資源流入、開発・営業等による資源の変換、消費・喪失、情報による再評価、時間経過、評価条件の変更を区別する。
外部出資の着金は資源流入、借入の着金は現金と返済義務の増加として記録する。
株主別の希薄化は、その持分を評価する際に計算する。

将来の資金調達については、元本そのものと、その機会が開く事業の正味価値を区別する。
成長投資の費用を全て差し引いた価値が8,000万円で、その投資を可能にする調達の成立見込みが20%から60%になる単純な条件では、機会価値の増分は3,200万円である。
投資家向けの準備費用や同じ顧客群の利益を既に計算した場合は、その入出金を共有して計算する。
この確率は、PJの継続を条件とする個別調達機会の推定である。

### 7.1 判断基準としての使い方

経営判断の比較対象は、直後のYだけでなく、各時点のYと、外部資金・消費・取得資源の変化である。
初期の一括投資や実験では、一時的にYが減ることがある。実行可能な方針の期待増分を、代替案・延期・中止と比較する。
評価期間末だけを大きくするための先送りを避けるには、同じ期間と期間末価値を使う。
法令・契約・資源制約と、資金繰りを満たす案の中で比較する。
このため「Yを増やす」という基準は、評価時点・比較方針・資源流入の範囲まで定めて運用する。

## 8. SOLの設立前事例

2026年11月3日のまさの確認では、SOLは設立前で、現在の確保資金はGAPファンドの研究費である。
新会社について現在の残高・既存支払義務を求める対象は存在しない。
PJの研究費利用枠と、大学側で執行する費用、研究から得た資源を評価対象にする。

申請書と資金計画書による全期間の金額は次のとおり。

| 区分 | 2025年度 | 2026年度 | 合計 |
|---|---:|---:|---:|
| 直接経費 | 21,482,000円 | 38,516,000円 | 59,998,000円 |
| 間接経費 | 6,444,600円 | 11,554,800円 | 17,999,400円 |
| 総額 | 27,926,600円 | 50,070,800円 | 77,997,400円 |

直接経費は使途・期間に沿って研究活動へ使える枠であり、現在の残額には執行済額と発注等の記録が必要になる。
間接経費は大学側の管理・研究環境等の負担分として確認し、PJの自由現金とは分ける。
研究費で取得した設備やデータは、現在の利用権と価値を評価する。
現在残る利用枠と取得資源を計算することで、採択時の総額から現在の資源への変換を追跡できる。

資金計画上の直接経費59,998,000円は、現時点のYの確定額ではない。
現時点の試算に必要な不足情報は、直接経費の執行済・発注済・利用可能残額、株・原データ・設備の利用範囲、商用ライセンス条件、現在と開発後の正味収益・取得機会の差である。
会社の事業利用権が未成立でも、研究PJが現在使える研究資源はその用途で評価できる。

設立後の開発案は、2027年4月〜2028年4月に現金71,421,779〜81,421,779円を使うライセンス対価の比較案である。
年10%、13か月均等支払の仮定では、2026年11月時点の投資現在価値は65,475,546〜74,642,994円となる。
他の条件が同じなら、その現在価値を上回る追加資源価値が必要になる。
2028年4月の終了時点にそろえた必要追加資源価値は74,940,876〜85,433,597円となる。
この逆算値は、投資する案と比較方針の差を評価する条件であり、現在のYや開発成果の査定額ではない。
研究費の現在残額と、設立後の調達・投資案は、異なる時点の資源と行動として保持する。

## 9. 成立条件と検証

### 9.1 数理的な整合条件

| 条件 | 反証する事例 |
|---|---|
| 現金の基準 | 自由現金を1円増やしただけで、同じ評価条件下のYが1円以外の量だけ増える |
| 名称と主体の一貫性 | 利用条件が同じまま、法人設立や資源名の変更だけでYが変わる |
| 二重計上の排除 | 受取権の回収、借入、助成の執行、同じ売上で根拠のない増加が起きる |
| 資源の組み合わせ | 相乗効果が消える、同時実行できない案の利益が重なる |
| 情報の時間順序 | 結果を見る前に、結果に合わせて行動を選べる計算になる |
| 資金繰りとの分離 | 同じ資源・費用・評価条件で、実行計画の当座の資金切れ確率だけを変えてWが変わる |
| 期間と基準の統一 | 評価日・基準PJ・残存価値を変えた差を、資源取得による改善として報告する |
| 不明値の保持 | 未確認の資源・確率・費用をゼロとして総額を確定する |

無償で追加され、使う義務も維持費もない資源は、無視する行動も選べる限り価値を下げない。
利用に義務・維持費が付く資源、古くなる資源、競合が使えるようになる資源には、この単調性を無条件には課さない。

### 9.2 経済学上の検証

Yは評価条件付きの資源価値であり、手元資金制約を織り込んだ企業価値とは異なる場合がある。
これを明示した上で、共通条件の資金手当てコスト、基準PJ、期間、確率と割引率を変えて、投資案の順位が安定するかを検査する。
個別の調達機会と継続条件が分離しにくい場合は、両者を動かした感度を残す。
既存BZMのVと同一の帰属・資金収入を評価する場合は、同じ価値の二重加算を防ぐ。

### 9.3 経営学上の検証

資源台帳は、使える主体、担当者、継続条件、共有する能力を証拠で確認する。
実績による受注率の変化には、顧客の質や営業条件の変化も効くため、単純な取得前後の差と因果効果を分ける。
既存資源を用いた案と代替調達案、学習による方針変更、同じ成果をより安く得る案を比較する。
価値が高いと評価した資源が実際に使われたか、予想した費用・受注・追加調達につながったかを追跡する。

合成事例の検算は数理的一貫性の確認である。実額の妥当性には、予測を凍結した後の実績との照合が必要になる。
現時点では数値の網羅性・因果効果・予測精度は検証途上である。

## 10. BZMとOSへの追加案

現行モデルページ§5.11は、非資金資源を金額換算する規則が未較正であることを明記している。
今回のYは、その測定課題に対する追加案として扱う。
既存のVは産業創出効果を含む評価目的・帰属を持つため、Yと同じ円単位でも対象を照合して区別する。
既存の到達見込みや資金枯渇の計算は、実行可能性を評価する側で使う。

OSでは、Yの金額・評価幅・評価日とともに、対象資源、選べる行動、未評価項目、前回からの増減理由を示す。
Xは事業化条件の到達状況、資金繰りは月別の実行条件として同じ日付で参照する。
新しい記録で資源・権利・分岐・費用が変わったときに再評価し、実測値の更新と推定の変更を分ける。

理論をさらに確定する作業は、SOLの利用権・研究費執行を用いた境界の検証、基準PJと継続条件を変えた投資順位の検査、予測と実績の照合である。
その結果を含む完成案を提示した後、採用された文面をモデルページへ統合する。
