## I-1 置き方の規約

### 1-1 速度は2段で持つ

$$
\kappa_g \;\equiv\; \frac{1}{M^{\mathrm{res}}_g}, \qquad M^{\mathrm{min}}_g = \mathrm{round}(0.40\,M_g), \qquad M^{\mathrm{res}}_g = M_g - M^{\mathrm{min}}_g
$$

$M^{\mathrm{min}}_g$ は**最短準備期間**（この間は通過しない）。その後の待ち時間だけがハザードの形になる。
**名目 $M_g \le 2$ のゲートは待ち時間を持たせない**（準備＋審査だけにする）。判定は**共通倍率 $\mathrm{scale}$ を掛ける前の名目値**で行う——掛けた後で判定すると、較正パラメータを振る操作が規約の適用可否を不連続に変えてしまう。

| 量 | 値 |
|---|---|
| 変換規約 | $\kappa_g = 1/M^{\mathrm{res}}_g$ |
| 準備の後の平均待ち月数 | $1/(1-\exp(-\kappa_g)) \approx M^{\mathrm{res}}_g + 0.5$ |
| 準備の後の待ち月数の中央値 | $\ln 2 \cdot M^{\mathrm{res}}_g$ |
| ゲート全体の平均所要月数 | $M_g + 0.5$（$M_g \ge 3$ のとき） |

**R2 の滞留の目安は 2段分布の 85% 点**（改訂 K6）。

### 1-2 根拠レベル

**A** = 公開統計または AMD の実測値から**その数字が直接引ける**（出典の固定ページを示す）／
**B** = 制度の設計・文献から**水準が導出されている**／**C** = 暫定の置き。
順位・順序の制約しか満たさない値を B と呼ばない。単一観測（$n=1$）はクラスの既定の根拠にならないので A と呼ばない。

### 1-3 不確かさの持ち方

| 種類 | 何の不確かさか | どう出すか |
|---|---|---|
| スコアの幅 | $\theta$ が分かっていないこと | $B_0$ の下での 10%・50%・90% 点（$c$・$\psi$・$\sigma$・$r$ の格子） |
| 係数の不確かさ | 較正されていないこと | 上位5係数の符号つき束と、**全係数を同じ定義で測った弾力性の表** |
| 規約の選択 | 割引率・$g^{*}$・$\sigma$ | $d$ の3点（1%・2%・4%）、$g^{*}$ の1段、$\sigma$ の3点 |
| **数値計算の誤差** | 状態の束ね方 | **格子の収束検査**（刻みを 1/2・1/4・1/8 と変えたときの $V$ の差） |

**弾力性は全係数を同じ定義（水準の $\times1.1$ / $\div 1.1$）で測る。**
ただし**控除率 $\alpha_u$ は 1 に近いので、意味を持つ量（貢献として残る割合 $1-\alpha$）の側を振る**——
$\alpha$ 自体に乗数を掛けると定義域を出て価値がゼロに潰れ、幅の表示が壊れる。
（v2 は確率型だけオッズ比で振りながら同じ分母で割って「弾力性」と呼んでいたため、$\alpha$ の報告値が真の値の約 1/6.7 になり、
較正の優先順位の結論が実際と違っていた。）

### 1-4 乗数の関数形と目盛り

**$\sigma$（産官学モメンタム）**: $\sigma \in \{-1,0,+1\}$、$0$ が無風。倍率を直接置く。

| 効き先 | 逆風 | 無風 | 追い風 |
|---|---|---|---|
| 採択 $\phi$ | 0.61 | 1.00 | 1.65 |
| 申し出 $\nu_k$ | 0.67 | 1.00 | 1.49 |
| 受託 $\nu_c$ | 0.74 | 1.00 | 1.35 |
| 競合の消失 $\lambda^{\mathrm{comp}}$ | 0.74 | 1.00 | 1.35 |

**判定規則**: **直近24か月**と**その前の24か月**を比べ、(i) 公的公募の採択率または予算額が $\pm20\%$ 以上動いたか、
(ii) 民間投資額が $\pm20\%$ 以上動いたか、(iii) 正統性の事象（規格・標準の制定または改定／業界団体の設立／
監督官庁の制度整備）が1件以上あったか。**2項目以上が同じ向き**なら $\pm1$、そうでなければ $0$。

**判定の単位**: **工程の型4 × 規制属性3 の12区分を固定単位**とする（v2 は「分野ごと」としか書いておらず、
対象集団の選び方で閾値超過の有無が変わりえた）。判定は AMD が中央で四半期に一度行い、版管理する。
$\sigma$ の反転には §6.D-3 と同型の統治（判定根拠の一次データを登録簿へ添付、一次担当と別の者が承認）を課す。

**$g_t$（証拠水準）の段階**: 0 = T1 前 / 1 = T1 / 2 = T2 / 3 = T3・治験第I相 / 4 = M2・治験第II相・規格試験 /
5 = M3・治験第III相 / 6 = M4・承認。**T4-* も段階を上げる**——相を越えることは、審査側・需要家・投資家から見て
技術・市場のゲートと同等かそれ以上の証拠だからである。
（v2 はこの変更の根拠に「上げないと REG-2 が退化する」という計算結果を掲げていたが、
**その数値は再現しなかったので撤回する**。中間状態の実装で観測したものだった。根拠は制度の意味に置き直す。）

**$m_n$（履歴）は 1 に固定する。** 状態依存と観測されない異質性を分離しなければ推定できず、
AMD の台帳には不採択が1件も無いので推定は発散する。推定できないものを初期値で置くと、
識別できない構造が値だけ持って残る。

### 1-5 年率と月次

**表の年率は連続時間のハザードの年換算値であり、月次ハザード＝年率／12。**

## I-3 $d_{f,g}$ — 空席の遅延、充足の速さ、担い手乗数

### 3-1 ゲートで添字づけた疎行列

非ゼロは §6.A-2 の「主担当機能」のマスだけ。それ以外は一律 $d_{\mathrm{other}} = 0.05$。根拠レベルはすべて **C**。

| ゲート | 主担当の空席の遅延 | それ以外 |
|---|---|---|
| T1・T2・T3 | 機能2（技術の核）＝ **1.00**（前進しない） | 0.05 |
| T4-* の準備 | 機能6（対外交渉）0.25、機能2 0.35 | 0.05 |
| T4-治験 | 機能6 0.30、機能2 0.35 | 0.05 |
| M2 | 機能3（用途と需要家）0.30、機能1（エバンジェリスト）0.35 | 0.05 |
| M3 | 機能3 0.30、機能6 0.25 | 0.05 |
| M4 | 機能6 0.30、機能4（意思決定）0.20 | 0.05 |

**機能2 は空席にならないと置く（規約）。** 研究者本人が担い、一時的な不在は扱わない。
**恒久喪失（異動・定年で戻らない）は $\lambda^{\mathrm{core}}$（I-7）で扱う。**
この規約の帰結として、$d_{2,g}=1.00$ は Tier 0 の計算では発火せず、**較正の対象から外す**
（推定できないものを表に残さない、という本提案自身の規律を適用する）。
規約の副次的な帰結として $\eta_t$ に下限がつく。**下限はゲートごとに違う**（主担当が空席になりうるゲートほど低い）:

| ゲート | $\eta_t$ の下限 |
|---|---|
| T1・T2・T3（主担当は機能2 で空席にしない） | 0.735 |
| T4-* の準備 | 0.580 |
| T4-治験 | 0.542 |
| M2 | **0.371** |
| M3 | 0.428 |
| M4 | 0.456 |

担い手乗数の側の下限は $\phi$ で 0.525、$\nu_k$ で 0.553。

**積の形が含意すること**: $\prod(1-d_f)$ は空席どうしを**代替的**に扱う（空席が増えるほど追加の空席の害が小さくなる）。
創業チーム研究が示すのは逆の補完性なので、**この形は補完性を表現できない**（I-13）。

### 3-2 空席が埋まる速さ

| 機能 | 過程 | 初期値 | 根拠レベル |
|---|---|---|---|
| 移せる機能（3〜7） | AMD の供給過程 | $\kappa_{\mathrm{sup}} = 1/12$ | C |
| エバンジェリスト機能（1） | 探索過程（$e$ が乗る） | $\kappa_e = 1/18$ | C |
| 技術の核（2） | 研究者本人（空席にしない） | — | 規約 |

充足の確率は評価日からの経過月だけで決まるので状態に持たず、空席パターン64通りにわたる**厳密な期待値**として

   このためライセンス到来率の弾力性が負に出る。

6. **$y_t$（売上）**。§5.2 の自由資金の遷移式と §5.5 の資本自立判定に入る量。参照実装は M4 到達を吸収として扱い、

7. **単位採算のゲート**（$m_u > 0$ の用途だけ $A_t$ に入れる）。天井を1に正規化する近似が、このゲートを常に通ると仮定している。
