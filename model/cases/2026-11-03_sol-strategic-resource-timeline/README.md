# SOL戦略余力の表示用登録試算

2026-11-03にまさが確認したv0.2のグラフを、3スペース共通の表示データへ変換した控え。理論の新しい確定版を定義する文書ではなく、評価日を持つ条件付きのケース試算。

入力・計算結果の指紋と15チェックはsource-manifest.json。page-data.jsonは同じ26時点、強弱3条件×利用対価2条件、見込み更新前の比較2条件を保持する。成果の確認条件と情報係数・根拠・仮定を同梱する。元の絶対パスや個人情報、別PJ情報は表示データに入れない。

初期表示の現在値282,333,205.65円、シリーズA着金後1,447,783,605.09円。成果4件の増分は89,878,540.56円、260,531,922.90円、151,616,575.32円、89,936,008.31円。資金調達は2億円/3億円を保有資金へ一度計上する。開発は達成まで追加投資し最終達成100%。長期事業の成立見込みは現在5%から良い成果により更新する試算仮定。

アプリはproject_configのPJ限定strategic_resources_v1を読む。登録用スクリプトは既存別版を上書きせず停止し、初回登録後にSHAを読戻す。将来の更新は実績・仮定・版を確認して行う。表示形式と権限の正本はpwa/spec/3-24。
