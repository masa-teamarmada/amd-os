## 2026-08-28: 天井を TAM → SOM → **SAM** へ置き直した

まさ 2026-08-26「TAMなんて全くあてにならないよ」「ちゃんとSOMで比較してる？」で、まずSOM（工程・用途の絞り × この案件が取るシェア）へ置き直した。
その直後にまさ 2026-08-28「それならSOMじゃなくてSAMにすればいいだけでは？」で**SAM**へ直した。

**シェアを天井に入れるのは二重計上になる。** モデルの側には取り分 $\phi_u$（専有可能性 $\kappa_{\mathrm{IP}}$ が動かす）が既にあって、
それが「この案件が何%取るか」を担っている。天井にもシェアを掛けると同じことを二回数える。
**天井に入れるのは SAM の絞りだけ**——工程・方式・用途・代替手段。

| 絞りの種類 | 天井に入れる | 例 |
|---|---|---|
| 担う工程 | **入れる** | 送受信デバイスしか作れないなら、システム全体ではなくデバイスの分 |
| 方式・用途 | **入れる** | 量子コンピュータのうち光量子方式／シリコン負極のうちプレドープ方式 |
| 代替手段があること | **入れる** | 空間伝送給電は「電池でいい」用途が多いのでその分を除く |
| 複数市場の足し合わせ | **入れる** | 磁気冷凍は水素だけに限定せず、量子・月面・クーラーボックス・核融合の冷凍機部分を足す |
| その案件が取るシェア | **入れない** | モデルの取り分 $\phi_u$ が担う |

## 組織の状態は、モデルにどこまで入るか

まさ 2026-08-28「組織の評価はどのように入ってるの？」。参照実装を読んで確かめた結果を書く。

**案件ごとに受け取る組織の入力は、担い手 $e$ の1つだけ。**

| 機能（§6.B-1 の八機能） | モデルの扱い | 案件ごとに入れられるか |
|---|---|---|
| 1 エバンジェリスト | $e$（探索過程・$\kappa_e = 1/18$ が乗る） | **入れられる** |
| 2 技術の核 | **「空席にならない」と規約で固定**（§6.I-3-1） | **入れられない** |
| 3 用途と需要家 / 4 意思決定 / 5 資金調達 / 6 対外交渉 / 7 組織 | AMD の供給過程で月 $1/12$ の率で埋まる、という全案件共通の係数 | **入れられない** |

空席の期待値は機能 1・3・4・5・6・7 の**64通り**にわたって計算されるが、機能2 は常に充足として数えられる。
技術の核の恒久喪失は $\lambda^{\mathrm{core}} = 0.008$（年率0.8%）という**全案件共通の係数**で、案件ごとに受け取る口が無い。

**だから「技術の担い手が消えた」という状態を、モデルは直接には表現できない。**
p16 ORLIB がその案件——誰も電池を作れず、リベラウェアからの納品要求に応えられずに引き伸ばしている。
$e$ を 0.20（範囲の下端）まで下げても、$v$ は 0.507 → 0.281 にしか落ちなかった。
**評価日に主張できる証拠水準を段階3から段階1へ下げて初めて $v$ が 0.023 まで落ちた。**
これは「越えたゲート」ではなく「評価日に外部から検証できる水準」として証拠水準を読み直したもので、
やり方としては正しいが、**本来は機能2の空席として入るべきものを証拠水準で代用している。**

### 担い手を下げても順位が落ちない案件がある

$e$ を下げても数字が動かない案件が複数あった。**共通しているのは手元資金が空欄なこと。**

| PJ | $e$ を下げた | $v$ の変化 | 手元資金 |
|---|---|---|---|
| p01 OPTMASS | 既定0.50 → 0.30 | 0.373 → 0.355（ほぼ動かない） | **空欄**（既定 = 会社化後バーンの18か月分） |
| p03 ティエムファクトリ | 既定0.50 → 0.25 | 1.135 → 1.135（動かない） | 当時**空欄** |

**資金に余裕がある前提だと、採択と申し出の機会が何度も来るので、担い手の弱さが吸収されてしまう。**
資金の余裕が消えて初めて担い手の効きが跳ね上がる。
**手元資金が空欄の案件は、組織がどれだけ悪くても順位が落ちない**——これがいまのモデルのいちばん大きな穴。
残高が空欄なのは p01・p16・p26・p29・p31・熱電 の6件。

## モデルが出す数字と、実態から見た「あるべき額」の差

p03 ティエムファクトリで確かめた。実数（残高3,000万円・バーン月300万円・売上年2,000万円）を入れたうえで:

| | 額 |
|---|---:|
| モデルの出力 | **12.3億円** |
| 実態からの積み上げ（売上年2,000万円 × 付加価値率0.35 = 年700万円を20年・割引率2%） | **1.14億円** |
| 同（恒久・永久年金） | **3.50億円** |

**3.5〜11倍のずれ。** 原因は天井66.5億円／年に対して $v = 0.185$ が高いこと。
実際の売上は年2,000万円で、天井の**0.3%**しか取れていない。
**「量産条件は通過したのに市場に受け入れられず、規模が出ないまま止まっている」という状態を表す入力がモデルに無い。**
証拠水準は段階4（有償の顧客がいる）までしか下げられず、そこから先は取り分 $\phi_u$ が担うが、
$\phi_u$ を動かすのは専有可能性 $\kappa_{\mathrm{IP}}$ だけで、市場の受容は入らない。

なお年700万円の付加価値は、日本のGDP（約620兆円）の**約1億分の1**にあたる。

## 気をつけて読むところ

**1. 産官学モメンタム $\sigma$ は、いまチャレナジーの1件だけに入っている。**
残り20件は事前分布（逆風25%・無風50%・追い風25%）のまま。
モデルページ §6.I-1-4 は $\sigma$ を工程の型4×規制属性3の12区分を単位に中央で四半期に一度判定すると定めているが、
その区分では風力とワイヤレス給電が同じマスに入るので、案件の実態に合わない。
チャレナジーだけは逆風がはっきりしている（海外メーカーの日本撤退、FIT区分の廃止、洋上での三菱商事・Equinorの撤退）ので、
案件の観測として $-1$ を置いた。**区分の粒度はモデル側の宿題。**

## 次に効くこと

1. **案件ごとのバーンレートを参照実装が受け取れるようにする**（モデル側。実績が既定の2〜9倍ずれている）
2. **$\sigma$ の判定の粒度を決める。** 12区分では風力とワイヤレス給電が同じマスに入る
3. **天井の絞りと取り分 $\phi_u$ の役割分担をモデル側で整理する**（二重計上の恐れ）
4. **CryoX の天井を経済産業省の部品別データで積み直す**（いま順位2位で、比率の根拠がいちばん薄い）
5. **置き換え分の割合を確定する**（p21 7割・p02 8割・p05 5割はいずれも暫定）
6. **付加価値率 0.35 を分野ごとに引き直す**（いまは全件同じ暫定値）
