# model/cases/ — BZM 3.0 の案件ごとの入力

モデルの定義・式・値は**モデルページ本体**（`model/MODEL_VERSION_LEDGER.md`）にある。
ここに置くのは**案件ごとの入力**（用途の洗い出し、用途ごとの市場規模、観測状態、受託の中身）で、定義は持たない。

規約: `model/APPROVALS.md` #2026-08-26-1 の M1〜M3。

- 用途は**市場が別かどうか**で切る。原料や作り方が違っても売り先の市場が同じなら同じ用途
  （同じ市場を二つの用途として立てると、価値の式が同じ天井を二回数える）。
- 市場規模は**用途ごとに年額の一つの数**で置く。幅を持たせない。
- 旧 SPS の $P^{\mathrm{ind}}$ 帯は入力に使わない（$V$ と同じ次元の量）。$V$ の上限としての検算にだけ使う。
- 受託の売上は、その案件が実際に何を受託するのかを書いたうえで置く。
