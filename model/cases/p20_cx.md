# p20 CX（磁気冷凍による低温冷却）— BZM 3.0 の案件ごとの入力

状態: **調査中 v0.1**（2026-08-26）。承認済みの入力ではない。規約: #2026-08-26-1 の M1〜M3。

- 対象: 物質・材料研究機構（NIMS）発。磁気冷凍による低温冷却。**会社は未設立**。
- 型 × 規制: **F2 × REG-0**（装置。事前承認の制度は無い）。
- 到達段階: TRL3 / BRL5 / HRL5（2026-07 観測）。**技術は早いが事業側は進んでいる**という珍しい形。

## 1. 用途の切り方（改訂 M1）

| 用途 | 何の市場か | 状態 |
|---|---|---|
| **A. 水素の液化** | 液化水素のサプライチェーンのうち液化の工程 | 下記（**確度は低い**） |
| B. 液体ヘリウムの代替（MRI・超伝導・研究用の低温） | 別の市場 | 未調査 |
| C. 一般の冷凍・空調 | 別の市場 | 未調査。ダイキン工業が商業規模の試作を進めている |

**本命は A。** 水素は約20ケルビン（−253℃）でしか液化せず、既存の気体式冷凍機の液化効率は最大25%程度で、
**液化価格が水素製造価格の3分の1を占める**ことが水素の供給価格を下げる障壁になっている。
磁気冷凍はここを直接ねらう（金沢大学のチームは磁気冷凍による水素液化に成功している）。

## 2. 用途 A — 水素の液化

### 2.1 天井 $\bar P_A$（年額）— **推定の連鎖が長い。確度は低い**

| 段 | 値 | 出典・操作 |
|---|---|---|
| 2030年の水素導入目標 | **300 万トン** | 水素基本戦略（2023-06） |
| 供給コストの目標 | **30 円／Nm³**（2030年） | 同上 |
| 水素の体積換算 | 1kg ≒ 11.2 Nm³ → 300万トン ≒ **336 億 Nm³** | 換算 |
| 供給額 | 30円 × 336億Nm³ = **1兆 80 億円／年** | 積 |
| 供給額に占める液化の比率 | **約 20%**（液化価格が製造価格の1/3、製造価格が供給価格の6割として） | **推定。ここが最も弱い** |
| 液化の年額（売上） | **約 2,016 億円／年** | 積 |
| 付加価値率 0.35 | **$\bar P_A$ ≒ 706 億円／年** | — |

**弱いところを明示する**: (i) 300万トンのうち**液化水素が占める比率**が公開資料から取れない
（液化水素・MCH・アンモニアの内訳が水素基本戦略に無い）。ここでは液化が主流になった場合を採っている
（天井は「最大限うまくいったときの年額」なので、この採り方は規約に沿う）。
(ii) 供給価格に占める液化の比率 20% は「液化価格が製造価格の1/3」からの推定で、直接の出典が無い。

**採らなかった置き方**: 世界の磁気冷凍市場（2024年 $3.24億 → 2030年 $232億）は**6年で70倍**の予測で、
そのままは採れない。日本の水素インフラ市場（2030年 約6兆円）は液化以外の工程を大量に含むので広すぎる。

### 2.2 置き換え分 $\delta_A$

既存の気体式冷凍機による液化を置き換える。**未確定**。ただし液化水素の産業自体がこれから立ち上がるので、
奪う相手が小さい（p21 SX とは違い、既存産業がまだ大きくない）。
