## 2. 要件 {#requirements}

> **状態**: 承認済み（[APPROVALS](/model/APPROVALS) #2026-08-24-10。改訂9点 #2026-08-24-11 を反映済み）。

> 改訂9点の内訳は [改訂1 の記録](/model/2026-08-24_bzm30-amendment-1)。

**モデルの要点** [根拠](#evidence "えいみの要約提示に、まさ 2026-08-24「今のところ違和感なし。進めて。」→ APPROVALS #2026-08-24-10"):

- 一件の案件を、**月ごとに更新する観測状態**として表す。観測状態の中身は、次に越えるステージゲートの位置／資金の残高（自由に使える資金と、使途が限定された資金の2勘定。単位は円）／権利と学内承認の未解決件数／会社化の有無／受託契約の拘束／稼働している用途／これまでの成否の履歴
- **案件パラメータ**（変換能力、技術の成立、専有可能性、支払上限、産官学モメンタム、エバンジェリスト機能の充足見込みなど）は直接測れないので、評価日の証拠から推定する
- 観測状態は**登録された計画の規則**（観測できる出来事だけを条件にした分岐。登録が無い案件には分野別の既定の規則を使う）に従って更新され、シナリオは最後に正本の9区分のいずれかで終わる
- 会社化は「何月に実施する」ではなく「この条件を満たしたら実施する」という規則で持つ。価値を最大にする規則と、登録された規則との差が、**会社化が早すぎるか遅すぎるかの診断**になる（要件4 タイミングの窓の測り方）
- 価値は、シナリオの上で発生する**国内付加価値の純増**（国内の既存事業を置き換える分と、この案件が無くても他者が実現していた分を差し引いたもの）を、社会的割引率で現在価値に直した金額。実現が遅いシナリオほど、割引によって金額が小さくなる

**最上段の式（スコア）** [根拠](#evidence "まさ 2026-08-24「めちゃくちゃわかりやすかった！ うん、最上段の式はこの式で違和感ない」→ APPROVALS #2026-08-24-8"):

$$
V = \int \mathbb{E}\big[\Pi(\omega) \mid \theta\big]\, dB_0(\theta)
$$

| 記号 | 意味 |
|---|---|
| $V$ | 案件のスコア。単位は円 |
| $\theta$ | 案件パラメータ。直接は測れず、期間中は変わらないと置く量（変換能力、技術の成立、専有可能性、支払上限、天井、工程の型、産官学モメンタム、エバンジェリスト機能の充足見込み、自走力）。定義は §5.3 |
| $\omega$ | 1本のシナリオ。評価日から評価期間の終わりまで、毎月どの事象が起きて観測状態がどう変わったかを並べた1つの系列 |
| $\Pi(\omega)$ | そのシナリオで発生する産業創出価値の現在価値（円）。定義は §5.7 |
| $\mathbb{E}[\Pi \mid \theta]$ | 案件パラメータを $\theta$ に固定したときの、起こりうるシナリオを発生確率で加重平均した価値 |
| $\int \cdots dB_0(\theta)$ | $\theta$ の推定の不確かさ（事前分布 $B_0$）についてさらに平均する。平均は二段階——内側はシナリオの分岐による不確かさ（情報を集めても消えない）、外側は $\theta$ が分かっていないことによる不確かさ（情報を集めると小さくなる） |

（この式の内側の平均に $v(\theta)$ という名前を付けて分けて書いたものが §5.8。同じ一つの定義であって、別の式ではない。）

### 5.1 設計の答え（先に一枚で）

一件の案件を**月ごとに進む観測状態**として表す。観測状態には、ゲートの位置、円建ての資金（自由資金と使途制限資金の二勘定）、
権利・承認の残件、会社化の有無、受託契約の拘束、これまでの成否の履歴が載る。案件の**案件パラメータ**（変換能力、追い風、技術の核、
専有可能性、支払上限、天井、工程の型、エバンジェリスト機能の充足見込み）は直接測れないので、評価日の証拠から推定する。

観測状態は**登録された計画の規則**——「この検証に成功したら次へ、2回失敗したら撤退」「量産条件の提示と権利の整理が済んだら会社化」
のような、**観測できる出来事だけに条件づけた規則**——に従って進む。毎月、前進・補給（資金調達・受託の稼ぎ）・バーンレート・
確定した期限・確率的な消失・実現の申し出（ライセンス・M&A・知財売却）の到来が起き、シナリオはやがて
正本の9区分（期限内資本自立／期限後資本自立／ライセンス／M&A／知財売却／ピボット／撤退／清算／未決着の継続）のどれかに落ちる。

**スコア $V$** は、シナリオの上で**実現した月ごとに**発生する国内付加価値の**純増**（既存事業の置き換えと、この案件が無くても
他者が実現していた分を差し引く）を社会的割引率で現在価値にした量を、案件パラメータの幅とシナリオの確率の両方で重ね合わせた期待値
——円である。あわせて、共通の経過時間での到達曲線と、計画規則と最適規則の差（会社化の早すぎ・遅すぎの診断）を出す。

### 5.2 時間・観測状態・資金の遷移

$$
t = 0, 1, \dots, T
$$

| 記号 | 意味 |
|---|---|
| $t$ | 評価日を 0 とした経過月数 |
| $T$ | **評価期間**。評価日から何か月先までを計算に入れるかの月数。全案件で同じ値を使う（値は 240 か月＝20年。§6.E-2）。$T$ より先は継続価値 $C$ が受け持つ |

日付が確定している制約（最終公募・定年・任期・権利の期限・年度末）は、**確定した期限**として、その月に効く形で観測状態に置く。

**観測状態（観測できる状態）**:

$$
x_t = \big(g_t,\ s^{\mathrm{f}}_t,\ s^{\mathrm{r}}_t,\ R_t,\ \iota_t,\ \chi_t,\ A_t,\ n_t\big)
$$

| 記号 | 意味 |
|---|---|
| $g_t$ | ステージゲートの位置（標準ゲート表 §4 の中で、次に越えるゲート） |
| $s^{\mathrm{f}}_t$ | 自由資金の残高（円）。使途の縛りがない資金 |
| $s^{\mathrm{r}}_t$ | 使途制限資金の残高（円）。公的資金など。充てられる支出が限定され、年度末で失効しうる |
| $R_t$ | 権利・承認の残件の集合（職務発明の帰属、共同出願の同意、ライセンス条件、利益相反・兼業承認）と各件の進み具合 |
| $\iota_t$ | 会社化したか（0/1） |
| $\chi_t$ | 受託契約の状態（契約中か、残り拘束月数、拘束される工数の割合 $\rho$、**契約の月額（円／月）、契約主体（大学／会社）、本業との近さ（同源／隣接／無関係）**。改訂1-3・1-9）。**受託は契約イベントでだけ増減する**（月ごとに自由に変えない） |
| $A_t$ | **稼働している用途の集合**。入口の用途は該当する市場ゲート（採用決定・量産契約）の通過で入り、**稼働度**（0→1 の立ち上がり。既定12か月線形）を経て満額に達する。拡張の用途は拡張の証拠イベントで入り、受託の実績はサービス用途として入る（ピボットの種）。**離脱が二つある**——需要の消失・契約終了・証拠の撤回の事象による離脱と、陳腐化・代替の率 $\lambda^{\mathrm{obs}}$（年率。§5 の $\lambda^{\mathrm{dem}}$＝案件全体の需要側の死とは別の量）による確率的な離脱。価値（§7）と売上 $y_t$ はこの集合の上でだけ発生する（改訂1-2） |
| $n_t$ | 成否の履歴の要約（各ゲートの試行回数と成否、採択・不採択の回数）。計画の規則はこれに条件づけられる |

**資金の遷移式**（円のストック。「残り月数」は表示用の導出量 $s_t / \mu_t$ であって状態ではない）:

$$
s^{\mathrm{f}}_{t+1} = s^{\mathrm{f}}_t - \mu^{\mathrm{f}}_t + \rho_t\, r + y_t + z^{\mathrm{f}}_t
\qquad
s^{\mathrm{r}}_{t+1} = s^{\mathrm{r}}_t - \mu^{\mathrm{r}}_t + z^{\mathrm{r}}_t - \ell_t
$$

| 記号 | 意味 |
|---|---|
| $\mu^{\mathrm{f}}_t, \mu^{\mathrm{r}}_t$ | その月のバーンレート（円／月）。計画の支出列から。会社化後は固定費で $\mu^{\mathrm{f}}$ が増える。使途制限資金で賄える支出は先に $\mu^{\mathrm{r}}$ へ割り付ける |
| $\rho_t$ | 受託に割く工数の割合（$\chi_t$ が決める。0〜1） |
| $r$ | 自走力: 工数を全部割いたときの受託・有償PoCなどの稼ぎ（円／月）。案件パラメータ §3。**大学経由の契約収入は間接経費控除後を使途制限側として扱い、$s^{\mathrm{f}}$ に入れない**（会社経由の分だけが自由資金へ。改訂1-3） |
| $y_t$ | 稼働している用途（$A_t$ の自社実施分と、ライセンス実施分のロイヤルティ）から、その月に会社へ入る売上（円／月）。稼働度を掛ける。実績は登録簿で更新する（改訂1-1）。産業の付加価値 $\bar P_u$ とは別の量で、混ぜない |
| $z^{\mathrm{f}}_t, z^{\mathrm{r}}_t$ | その月の補給（民間調達→自由資金、公的採択→使途制限資金）。資金調達の機会（§5.4）の結果 |
| $\ell_t$ | 年度末の期限による使途制限資金の失効（繰越できない分） |

**吸収（資金切れ）**: $s^{\mathrm{f}}_t < 0$ になり、充当可能な $s^{\mathrm{r}}_t$ でも埋められない月に、シナリオは終わる（撤退または清算へ分類）。
残高が状態なので、「いつ尽きるか」は履歴に依存する（ゼロ到達＝資金枯渇による終了）。

### 5.3 案件パラメータ — 評価日の証拠から推定する量

$$
\theta = \big(c,\ e,\ \sigma,\ \tau_{\mathrm{proc}},\ \psi,\ \kappa_{\mathrm{IP}},\ \{w_u\},\ \{\bar P_u\},\ \{\delta_u\},\ \{\alpha_u(\cdot)\},\ \{L_u\},\ \{\underline{c}_u\},\ r\big)
$$

| 記号 | 意味と、評価日の置き方 |
|---|---|
| $c$ | 変換能力。投入資源あたりに前進を生む速さの乗数。**履歴から置く**: これまでの（投入した資金・月数）対（越えたゲート）の比を、分野の基準（§4 の $\kappa_g$）と比べる |
| $e$ | エバンジェリスト機能（機能1。技術の意義と到達点を説明して、需要家・投資家・審査側の判断を動かす機能）が、この案件で埋まる見込み。専任の担当者を指す量ではなく、**機能が誰かによって担われるかどうか**を表す。**測定手続き**: 関係者の棚卸し（研究室出身者・長期の共同研究者・初期からの伴走者・共同出願者を列挙し、接触実績を確認）。**未探索なら広い範囲（中立）**に置き、探索して担い手が見つからないと分かったときだけ下げる。更新は実働の記録（会議・意思決定・対外説明）のみ。肩書・名義・研究者本人の起業意思は入力にしない |
| $\sigma$ | 産官学モメンタム。**観測手続き**: 分野別に (i) 公的公募の採択率と予算額の変化、(ii) 民間投資額の変化、(iii) 正統性の二種（認知的＝規格・標準・審議会での位置づけ、社会政治的＝規制整備・業界団体の形成）を記録し、採択関数 $\phi$ と申し出到来率 $\nu$ の乗数に写像する |
| $\tau_{\mathrm{proc}}$ | 工程の型（プロセス型／組立型、特殊インフラ依存）。**必要支出列 $\mu_t$ をここから導き、量産原価の下限 $\underline{c}_u$ の事前分布もここから引く**（同源の共有は事前を型から引くことで保つ） |
| $\underline{c}_u$ | 用途 $u$ の量産原価の下限。工程の型を事前分布とし、観測（原価実測・設備見積・歩留まり）で更新される案件パラメータ成分（改訂1-7） |
| $\psi$ | 技術の核の成立（再現性・スケール時の性能）。**使用先は二つ**: 技術系のステージゲートの前進確率の乗数（§4）と、そのゲートを通らない限りどの用途も $A_t$ に入れないという共有の前提。技術が立たない案件パラメータでは全用途が同時に立たない |
| $\kappa_{\mathrm{IP}}$ | 専有可能性。請求範囲の広さ・他者特許との抵触（FTO）・代替経路の塞がり具合から推定する。効き先は三つ: 国内で発生させられる割合 $\phi_u$、競合消失率 $\lambda^{\mathrm{comp}}$、申し出到来率 $\nu$ |
| $w_u$ | 用途 $u$ の支払上限。**証拠の階級つき**（関心／有償PoCの支払い／量産条件の提示／量産契約）。有償PoCの支払いだけでは量産の階級に上げない |
| $\bar P_u$ | 用途 $u$ で国内で発生しうる産業の付加価値（年額の桁） |
| $\delta_u$ | うち国内の既存事業からの置き換え分 |
| $\alpha_u(t)$・$L_u$ | **反実仮想の控除（時間形。改訂1-6）**: この案件が無くても、他者が用途 $u$ をいつ・どれだけ実現していたか。評価日から**前倒し期間 $L_u$**（競合の状況から下限〜上限で推定する）までは評価日の控除率、それ以降は国内立地差だけが貢献に残る水準へ上がる。$L_u$ の起点は評価日——実現が遅いシナリオほど貢献を過大に見る向きの近似（明示して較正で監視する） |
| $r$ | 自走力（円／月）。§2 |

評価日の事前分布 $B_0(\theta)$: 出所タグつきの証拠から、個別推定→根拠交換→再推定→集約の手順で置く
（下限・上限・最良値・確信度の4点方式）。推定値の幅は「幾何平均×乗法的ばらつき」で持ち、相関する成分は同じ源の変数
（$\tau_{\mathrm{proc}}$、$\psi$）を共有する。**モデルの中の月次では $\theta$ は固定**（案件パラメータは変わらず、分かっていないだけ）。
証拠が増えたときの事前分布の更新は、評価の**版**の更新として行う（§9）。

### 5.4 過程 — ゲート・資金調達・申し出・受託

**標準ゲート表**（ゲートの切り方の規律）: ステージゲートは分野別の標準表から選ぶ。ゲートは**外部から検証可能なイベント**
（第三者の再現、規格試験の通過、有償PoCの完了、量産条件の合意）だけで定義し、細切れにして通過確率を稼ぐ操作は
標準表からの逸脱として表示する。

**ステージゲートの前進**:

$$
p^{\mathrm{adv}}_t = 1 - \exp\!\big(-\,\kappa_{g_t} \cdot \psi_{g_t} \cdot c \cdot \eta_t \cdot (1 - \gamma \rho_t)\big)
$$

| 記号 | 意味 |
|---|---|
| $\kappa_{g_t}$ | ゲート $g_t$ の基準速度（分野×ゲートの種類の初期値表。工程の型 $\tau_{\mathrm{proc}}$ から引く） |
| $\psi_{g_t}$ | 技術系のゲートでは $\psi$（技術の核）、それ以外のゲートでは 1 |
| $\eta_t$ | 担い手の充足係数（下で定義） |
| $\gamma$ | 受託がゲート通過を遅らせる度合い。**受託の本業との近さの区分別**——同源（本業技術の検証を兼ねる。初期値 0＝食わない。成果データは別の事象として証拠側へ）≦ 隣接 ≦ 無関係（較正パラメータ。改訂1-9） |

**担い手の充足係数（関数形を与える。空席は減点ではなく遅延）**:

$$
\eta_t = \prod_{f \in \mathcal F} \big(1 - d_f \cdot \mathbb 1[\text{機能 } f \text{ が } t \text{ で空席}]\big)
$$

| 記号 | 意味 |
|---|---|
| $\mathcal F$ | 経営チームが持つべき機能の分解表（要件9。CEO・COO・CTO の機能をすべて列挙） |
| $d_f$ | 機能 $f$ の空席がもたらす遅延係数（0〜1）。エバンジェリスト機能の $d_e$ が最大。**較正**: 空席期間とゲート通過の遅れの観測から推定し、予測した遅れと実測を突き合わせて反証できる |
| $\mathbb 1[\cdot]$ | 中身が真なら1、偽なら0 |

空席の埋まり方: 移せる機能は AMD の供給過程（埋まるまでの月数の見込み）で埋まる——**評価時点の空席そのものは罰しない**。
エバンジェリスト機能は探索過程（成功確率が $e$ に依存）で埋まる。

**資金調達の機会**: 日付と金額が分かっているもの（公募要領・調達計画）は一覧に載せる。**一覧は固定ではない**——先の期間には、
新しい機会が到来率 $\nu^{\mathrm{win}}(\sigma)$ で現れる（分野の追い風が強いほど新設が多い。較正は公募の新設実績から）。
機会 $w$ での採択確率は

$$
p^{\mathrm{award}}_w = \phi\big(\sigma,\ n_t,\ g_t\big)
$$

| 記号 | 意味 |
|---|---|
| $\phi$ | 採択関数。追い風と、それまでの成否の履歴・ゲートの位置（＝審査側から見える証拠水準）で決まる。採択は補給であって前進ではない |

**実現の申し出**（ライセンス・M&A・知財売却が起きる過程）:

$$
p^{\mathrm{offer}}_{k,t} = 1 - \exp\!\big(-\,\nu_k(\kappa_{\mathrm{IP}},\ g_t,\ \sigma)\big), \qquad k \in \{\text{ライセンス},\ \text{M\&A},\ \text{知財売却}\}
$$

| 記号 | 意味 |
|---|---|
| $p^{\mathrm{offer}}_{k,t}$ | その月に形 $k$ の申し出（引き合いの成立）が来る確率 |
| $\nu_k$ | 申し出の到来率。専有可能性・越えたゲート（証拠水準）・追い風で決まる。受けるかどうかは計画の規則（§6）が決める |

**受託契約（入口・拘束・出口）**: 受託の話は申し出として到来する——

$$
p^{\mathrm{offer}}_{c,t} = 1 - \exp\!\big(-\,\nu_c(r,\ \sigma,\ n_t)\big)
$$

| 記号 | 意味 |
|---|---|
| $p^{\mathrm{offer}}_{c,t}$ | その月に受託・有償PoCの引き合いが成立する確率 |
| $\nu_c$ | 受託申し出の到来率。自走力 $r$（稼げる型を持っているか）・追い風 $\sigma$・実績 $n_t$ で決まる |

受けるかどうかは計画の規則（§6）が決める。受けると契約イベントで $\chi_t$（残り拘束月数と工数割合 $\rho$）が立ち、
契約中は $\rho$ を勝手に下げられない。**受託の実績は、サービス用途を $A_t$ へ追加する遷移**（ピボットの種）を持つ——
受託で立った稼ぎが、そのまま「稼げる産業」への道になりうる（要件3 の後半。受託からピボットへの接続）。

**権利・承認の解決過程**: 残件 $i \in R_t$ ごとに、
着手→審査→解決の所要期間の見込み（下限〜上限）と、大学側の会議暦（委員会の開催月）を確定した期限として持つ。

$$
p^{\mathrm{res}}_{i,t} = 1 - \exp\!\big(-\,\beta_i\big) \quad (\text{ただし委員会の開催月にのみ判定が出る種類は、その月にだけ解決しうる})
$$

| 記号 | 意味 |
|---|---|
| $p^{\mathrm{res}}_{i,t}$ | 残件 $i$ がその月に解決する確率 |
| $\beta_i$ | 残件の種類別の解決率（帰属確定・共同出願同意・COI 承認などの標準所要期間から。較正は台帳の実績） |

未解決の残件は、紐づくステージゲート・資金調達・会社化・申し出の受諾を塞ぐ。

### 5.5 一か月の遷移（順序）

1. **確定した期限**: その月に来た期限を適用（最終公募・定年・任期・権利期限・年度末の失効 $\ell_t$）。
2. **確率的な消失**: $\lambda_t = \lambda^{\mathrm{comp}}(\kappa_{\mathrm{IP}}, \sigma) + \lambda^{\mathrm{dem}}$ で外からの死
   （競合の先取り・需要側の消失。真に確率的なものだけ）。
3. **過程の判定**: ステージゲートの前進、資金調達の採択、申し出の到来、権利・承認の解決、受託契約の開始・満了。
4. **規則の適用**（§6）: 計画の規則が、次の行動（会社化する／申し出を受ける／ピボットする／撤退する／続ける）を決める。
5. **資金の更新**: §2 の遷移式。
6. **吸収の判定**: 資金切れ→撤退・清算へ。資本自立の判定（反復可能な稼ぎ——受託 $\rho_t r$ と売上 $y_t$ の両方を含む——が必要支出を12か月賄う。改訂1-1）→資本自立へ。
7. **履歴の更新**: $n_t$ に今月の成否を積む。

### 5.6 行動規則 — 誰の行動を、どう予測するか（第2ラウンド監査の核心への回答）

**モデルが予測するのは「登録された計画」の帰結**である。計画の規則 $\pi^{\mathrm{plan}}$ は、
評価時点で登録される「観測できる出来事に条件づけた行動規則」の集合——
ゲートの順序、失敗時の分岐（再試行・ピボット・撤退の条件）、会社化の条件、申し出への応じ方、受託の方針。
**規則は時点 $t$ で観測可能な情報——観測状態 $x_t$（履歴の要約 $n_t$ を含む）・資金調達の機会の一覧・契約の条件——にだけ条件づけ、案件パラメータ $\theta$ には条件づけない**（当事者にも $\theta$ は見えないから。改訂1-5）。
これで、案件パラメータを固定した各 $\theta$ に対してシナリオの確率がすべて定まり、計算が閉じる。

**計画の様式と既定**: 計画の規則は自由記述ではなく、**標準テンプレート（分岐条件の選択式）から AMD（評価者）が登録**する。
案件側の自己申告ではない（規則をゲームの対象にしない）。登録が無い段階（Tier 0）は、分野×段階の**既定の計画規則**を使う——
これで全案件にスコアが定義される。登録された計画が既定とどこで違うかは表示する。

**規範の基準**: 参考として、同じ規則クラスの中で $V$ を最大にする規則 $\pi^{*}$ を、**方針探索**——宣言した有限の
規則クラス（閾値の組の格子）を前向き評価で総当たりして最良を選ぶ——で求め、**計画との差**を診断として併記する。
会社化の早すぎ・遅すぎ（要件4 の測定）、撤退条件の甘さ・厳しさ、受託の過不足。案件パラメータが未知のまま観測状態にだけ条件づけた
規則の最適化は動的計画では分解しないので、後ろ向き帰納は主張しない（閉包検証の指摘）。
**スコアは計画規則の下の値**であり、最適規則の値をスコアにしない（最適を仮定するとタイミングのずれという測りたい差が消える）。

| 記号 | 意味 |
|---|---|
| $\pi^{\mathrm{plan}}$ | 登録された計画の規則。版管理される |
| $\pi^{*}$ | 同じ規則クラスの中で $V$ を最大化する規則（診断用の基準。最大化の目的関数は $V$＝産業創出価値の期待値） |

### 5.7 シナリオの価値 — 純増・反実仮想・割引・継続価値

シナリオ $\omega$（案件パラメータ $\theta$ と規則 $\pi^{\mathrm{plan}}$ の下で、観測状態が 0 か月目から評価期間の終わりまでに辿った 1 つの系列）の価値は、実現した月ごとに割り引いて足し上げる:

$$
\Pi(\omega) \;=\; \sum_{t=1}^{T} \frac{1}{(1+d)^{t/12}} \sum_{u \in A_t(\omega)} \phi_u\, \frac{\bar P_u - \delta_u}{12}\,\big(1 - \alpha_u(t)\big)\; +\; \frac{1}{(1+d)^{T/12}}\, C\!\big(x_T(\omega),\ \theta\big)
$$

| 記号 | 意味 |
|---|---|
| $\Pi(\omega)$ | シナリオ $\omega$ の価値（円）。**遅く実現したシナリオは自動的に軽くなる**（割引がシナリオの中にあるため） |
| $d$ | 社会的割引率（一本。公共投資の社会的割引率の系譜から較正。リスクの上乗せをしない——失敗はシナリオの確率で数えている） |
| $A_t(\omega)$ | その月に稼働している用途の集合（観測状態の状態 §2。参入は市場ゲート・稼働度の立ち上がり・二種の離脱——事象と陳腐化——を含む。実現の形——自社・ライセンス先・買収後の主体——を問わず、国内で発生する分を数える） |
| $\frac{\bar P_u - \delta_u}{12}$ | 年額の純増を**月額**に直した量（月次の和と単位を揃える。閉包検証で年額のまま12倍になっていた誤りを訂正） |
| $\phi_u$ | 用途 $u$ の年額のうち、この案件系（承継者を含む）が国内で発生させられる割合（専有可能性 $\kappa_{\mathrm{IP}}$ に依存） |
| $\bar P_u - \delta_u$ | 年額の天井から国内の既存事業の置き換え分を引いた純増 |
| $1 - \alpha_u(t)$ | 反実仮想の控除（時間形。§3・改訂1-6）。前倒し期間 $L_u$ までは評価日の控除率、それ以降は国内立地差だけを貢献に数える（目的3 の帰属。査読で最初に突かれる箇所への先回り） |
| $C(x_T, \theta)$ | **継続価値関数**: 評価期間 $T$ の終端観測状態（決着・未決着を問わない）に置く価値。終端の観測状態と案件パラメータの関数として定義し、版管理する（改訂1-4）。後ろ向き帰納の終端条件でもある |

**単位採算のゲート（要件11）**: 案件パラメータ $\theta$ を固定すれば $m_u(\theta) = w_u - \underline{c}_u$ は一つの数で、
計画の規則は $m_u(\theta) > 0$ の用途だけを $A_t$ に入れる。全用途で $m_u(\theta) \le 0$ の案件パラメータでは価値が立たない。
スコアの上下の幅は、この判定が案件パラメータの事前分布 $B_0$ の上で混ざった結果として現れる——採算が成り立つ用途が一つも見えていない案件は、
スコアの下限が下がる。**このゲートはモデルの中の規則**であり、GO／NO_GO の判定（二階の仕事）とは別物。

**継続価値関数の恒久形**: §6（このページ） E-3 で確定——Tier 0 の既定規則で
$H_C = 120$ か月延長し（陳腐化・離脱は延長中も効く。延長中に決着したシナリオは9区分の実区分へ再分類）、延長終端で生き残っている
稼働用途に陳腐化込みの残存の永久価値を置く。決着済みの終端観測状態にも適用する（稼働分の生存過程だけが効く）。
旧の「残りゲート数・資金・権利残件に単調な線形の式」（初期形）は廃止した。

### 5.8 スコアと報告様式

**案件パラメータを固定した条件付き価値**と**スコア**:

$$
v(\theta) \;=\; \mathbb E\big[\ \Pi(\omega)\ \big|\ \theta,\ \pi^{\mathrm{plan}}\big]
\qquad\qquad
V \;=\; \int v(\theta)\, dB_0(\theta)
$$

| 記号 | 意味 |
|---|---|
| $v(\theta)$ | 案件パラメータが $\theta$ だったときの、シナリオの確率で重ねた価値の期待値。観測状態（$A_t$ を含む）の上の前向きの積み上げ計算で計算する。状態の数が粗い離散化で収まらない場合は、状態の束ね方（資金の刻み・$A_t$ の代表集合）を明示して近似し、近似誤差を表示する |
| $V$ | スコアの中心値。案件パラメータの事前分布で重ねた期待値（確率と価値の相関は $v(\theta)$ の中で保存される） |

**スコアの報告**: スコアは三つの数で報告する——
$B_0$ の下で $v(\theta)$ が取る値の下側（10%点）・中央（50%点）・上側（90%点）。中心値 $V$ は参考に併記。
この上下の幅は、案件パラメータがまだ分かっていないことから生じる、どの案件パラメータを絞り込むと幅が最も縮むか（＝次に集めるべき情報）を
同時に出す（要件7 の運用）。

**導出量（すべて同じ計算から出る報告用の量）**:

- $q_o(\theta)$: シナリオが正本の9区分（期限内資本自立／期限後資本自立／ライセンス／M&A／知財売却／ピボット／撤退／清算／未決着の継続）
  のどれに落ちるかの確率。分類は計算前に固定した規則で行い、$\sum_o q_o(\theta) = 1$ が構成上成り立つ。
- $P_o(\theta) = \mathbb E[\Pi \mid \theta, o]$: 区分ごとの条件付き価値（報告用。原始的な定義は $\Pi$ の側）。
- $Q(h)$: 経過月 $h$ までに資本自立へ届く累積確率（共通の経過時間での案件比較に使う）。
- 計画規則と $\pi^{*}$ の差（会社化・撤退・受託の診断）。

- **観測→状態の登録簿**: 一つの出来事は事象一件で記録し、効き先（状態・案件パラメータ成分・資金調達の機会の一覧・確定した期限）を型で宣言。

### 6.A 標準ゲート表

#### 6.A-1 ゲートと観測

#### 6.A-4 記入規則と計算規則

1. 案件のゲートの列は、この表のゲートの種類から選んで並べる。同じゲートの種類を**実質的に区別できる用途**（市場・顧客・仕様のどれかで区別できること）ごとに置いてよい。区別の実質が無い用途の複製は、細切れと同じ逸脱として扱う。
2. **細切れの計算規則**: 標準表に無い下位段階への分割（「準備・実施・報告」等）は、逸脱欄への表示に加えて、**計算上は同一ゲートの種類につき1回の通過としてのみ $g_t$ へ算入する**。未承認の逸脱が残る案件は、評価版を確定できない。制度が定める区分（T4-* の列）に沿った分割は細切れではない。
3. 表に無いゲートが必要な場合は、外部検証可能性の定義（A-2 の書式）を満たす形で逸脱欄に起案し、承認後に標準表へ足す。承認までの暫定の基準速度は、最も近い標準ゲートの値を使い、その旨を表示する。
4. 権利・学内承認はゲート表に載せない（観測状態の $R_t$、§5.4 の解決過程）。資金の採択も載せない（資金調達は補給であって前進ではない）。
5. **担い手の機能との対応**: ゲート表の各行に、そのゲートの前進を主に担う機能（B の機能番号）を「機能列」として書く。これは較正の対応宣言（どの機能の空席が、どのゲートの遅れとして観測されるはずか）であり、充足係数 $\eta_t$ の計算は §5.4 のとおり毎月・全機能の積で行う。

#### 6.B-2 充足の判定 — 直近性・証拠の下限・失効

機能 $f$ が月 $t$ に「充足」なのは、次の**すべて**を満たすときだけ:

1. **直近性**: 直近12か月以内に、その機能の実働の記録（登録簿の種類15）があること。12か月途切れたら空席へ戻る（失効。不作為は事象にならないので、失効の判定は評価版の更新時に機械的に行う）。
2. **複数時点**: **すべての機能**で、3か月以上離れた**2時点以上**の実働の記録を要する（評価直前の駆け込み記帳1件では充足にならない）。単発の記録しか無い機能は「充足見込み」として表示し、評価版の確定では空席として扱う。
3. **証拠の下限**（機能ごと）: エバンジェリスト機能＝**本人が説明の主体**となった対外説明の記録（同席・紹介は不可）。技術の核＝実験・技術判断・再現指導の実働。用途と需要家の開拓＝需要家の発掘・条件設計の実働。最終意思決定＝会議体での決定と結果の引き受けの記録。資金調達＝申請・面談・条件交渉の実働。対外交渉＝交渉・締結実務の実働。組織の構築と運営＝採用・労務・体制づくりまたは研究組織運営の実働。
4. **出所**: エバンジェリストは第三者証言または相手方の記録（面談相手側の文書・議事）を**必須**とする。他の機能は推奨とし、自己申告のみの記録は確信度を下げて扱う。

肩書・名義・意思表明では充足にしない（§5.3 の $e$ と同じ規律）。着任・退任は種類15 の事象として独立に記録する（空席期間の始点・終点の較正のため）。
種類15 の効き先は条件つき: **機能が空席のときは案件パラメータ（$e$ など）と充足の両方へ、既に充足のときは充足の維持のみ**（同じ実働で $d_e$ 解除と $e$ の推定値上げを二重に効かせない）。

#### 6.C-3 横串の規則

1. **一事象一件**: 効き先が複数あるときは同じ行に列挙し、同じ成分へ二回効かせない。導出量（$\lambda^{\mathrm{comp}}$ 等）は効き先に書かない。
2. **証拠階級**: 昇格が既定だが、種類12 の明示的な撤回・失効の事象で当該用途・当該需要家に限り**降格する**。量産条件（M3）は12か月無進捗で自動失効。同一階級内の独立な複数需要家の証拠は、階級は変えずに $w_u$ の水準・確信度へ効かせる（需要の広がりの情報を捨てない）。
3. **記録の運用**: 逐次記帳が原則だが、評価版の更新の節目に契約書・面談メモ・メールからまとめて起票する簡略記法を認める（日付は出来事の日付で記録する）。**記録密度**（直近6か月の件数）が薄い案件は「記録薄」フラグを評価に併記し、記録の薄さを案件の悪材料と混同しない。**記録薄の案件では充足の失効判定（B-2）を保留し、評価版の確定前に現況確認の記帳（種類15・23）を必須にする**——記録を怠っただけの案件が、実態と無関係に空席・失速扱いになるのを防ぐ。
4. 記録の粒度に迷ったら「その出来事を外部の第三者に一つの事実として説明できる単位」で切る。

#### 6.D-2 Tier 0（未登録の案件）

#### 6.D-3 診断の格子と登録のガバナンス

- **格子＝D-1 の選択肢の直積**（R1 は固定）。$\pi^{\mathrm{plan}}$ は構成上つねに格子の中にあるので、$V(\pi^{*}) \ge V(\pi^{\mathrm{plan}})$ が保証され、「計画と最適の差」は非負になる。
- **$\pi^{*}$ は、R1 に加えて R2（失敗閾値）と R6（撤退条件）を計画と同じ値に固定した、R3・R4・R5 上の条件つき最適**とする——シナリオの価値 $\Pi$ には支出が入っていないため、撤退のレバーを探索に含めると最適規則は必ず最も粘る側に張り付き、診断が情報を失う（閉包検証）。要件4 の測定の主目的である会社化・申し出・受託のタイミング（R3・R4・R5）の診断はこれで生きる。
- **職務分掌**: 計画規則の登録は AMD が行うが、案件の一次担当者とは**別の者が承認**する。既定外の選択は理由の記録を必須にする。
- $\pi^{\mathrm{plan}}$ と $\pi^{*}$ の乖離が大きい案件（差の絶対値がスコアの上下の幅を超える等、基準は第二便）は、スコア確定前のレビュー対象にする。
- 撤退条件 $\underline h$ や失敗閾値 $k$ は「緩めるほどスコアが上がる」一方向のレバーなので、既定より緩い登録は理由と承認を必須にする。

### 6.E 値3つ

**価格の規約（E 全体の前提）**: 金額はすべて**評価日の実質円**で置く（バーンレート・支払上限・天井・売上・割引率のすべて）。
$\bar P_u$ の実質成長率は既定 0%。0% 以外を置く場合は、割引率の導出（E-1 のラムゼー式）の成長率 $g$ と整合させる。

#### 6.E-1 社会的割引率 $d = 2.0\%$（年・実質）

**採る値**: 中心 2.0%。感度検査に 1.0% と 4.0% を必ず併記し、**感度で9区分の順位（資本自立か撤退か等）や案件の順位が入れ替わる場合は機械的にフラグを立てて個別レビューへ回す**。

導出（ラムゼー式による自立の根拠。他国の値の横並びではない）:

$$
d \;=\; \delta + \mu \cdot g
$$

| 記号 | 意味と置いた値 |
|---|---|
| $\delta$ | 純粋な時間選好（今を将来より好む度合い）: 0.5〜1.0% |
| $\mu$ | 消費の限界効用の弾力性（豊かになるほど追加の1円の価値が下がる度合い）: 1〜2 |
| $g$ | 日本の一人あたり実質消費成長の長期見込み: 0.3〜1.0%（直近実績は年 0.3% 程度） |
| $d$ | 合成: 0.8〜3.0%（中央はおよそ 1.7%）。**2.0% を採る**——中央よりやや高め、つまり将来を強めに割り引いてスコアを控えめに出す側の丸め |

補足:
- BZM 3.0 の $d$ は「失敗の可能性を含まない、社会の時間選好」である（§5.7: リスクの上乗せをしない——失敗はシナリオの確率で数えている）。リスクを含む資本コスト（VC の期待収益率など）を使ってはならない。
- 参照（いずれも構成が違う量なので、根拠ではなく参照）: 日本の公共事業評価の運用は 4%（長期国債の実質利回りを参考に設定されて以来据え置き。設定当時と金利実勢が乖離しており、見直しの検討が報じられている）。英国は 3.5%（ラムゼー式によるが、内訳に社会の存続に関する危険率 約1% を含む——リスクを別立てにする BZM 3.0 とは構成が違う）。オランダは 2.25%（2020年の割引率作業部会の勧告。リスクフリー率にリスクの上乗せを重ねる構成で、これも BZM 3.0 とは構成が違う）。米国は連邦の指針（規制影響分析 Circular A-4・投資評価 Circular A-94）が 2023年に約 2% へ改定されたが、**2025年に撤回された経緯があり、現行の参照点にはしない**。
- 4.0% の感度は日本の現行運用との突き合わせ、1.0% は長期の産業価値を重く見る立場との突き合わせ。30年超を見る評価なので、長期で逓減する割引スケジュール（英国型）は第二便の検討項目とする（逓減も「一本」であり§5.7 に反しない）。

#### 6.E-2 評価期間 $T = 240$ か月（20年）

**採る値**: 評価日から 240 か月。**性質は規約**（全案件で同じ値を使う。案件ごとの事情から導かない）。

理由: 登録された計画の規則が意味を持つ範囲——Before Zero（数年）→ 量産立ち上げ → 普及——の時間スケールを覆う共通の期間として置く。
それより先は、個別の観測状態情報の予測力が薄れるため、継続価値 $C$（E-3）が受ける。**価値の裾の減衰は、評価期間の位置ではなく「割引＋陳腐化」（改訂1-2 の $\lambda^{\mathrm{obs}}$ が稼働の全期間に効く）で決まるため、$T$・$H_C$ の選び方はスコアの水準をほとんど動かさない**——これが「規約」と呼べる条件であり、毎回の報告で $T$ 前後の価値の内訳（$T$ までの実現分と $C$ の比率）を併記して確かめる。
特許の存続期間（出願日から20年）は $T$ の根拠にしない——時計の原点が違う（評価日起算と出願日起算）。権利の残存期間は専有可能性 $\kappa_{\mathrm{IP}}$・取り分 $\phi_u$ の推定値の側で扱い、残存期間を超える裾で $\phi_u$ を下げる時間形は第二便へ申し送る（現状は裾を過大に見る向きの単純化であることを明記する）。

#### 6.E-3 継続価値 $C$ の恒久形 — 既定規則で延長し、生き残った稼働分に残存の永久価値を置く

**前提（改訂1-2）**: 陳腐化・代替のハザード $\lambda^{\mathrm{obs}}$ は**稼働の全期間**に効く（稼働中の用途は、評価期間の前も後も毎月同じ率で $A_t$ から確率的に離脱する）。だから価値の裾は評価期間の位置ではなく「割引＋陳腐化」の速さで自然に減衰し、$C$ は「その続きを終端の観測状態から引き継ぐ」だけの量になる——終端にだけハザードを置くと稼働期間の長短で水準が歪む（閉包検証 N-1）ため、この前提が要る。

**構成**: $C$ は**決着・未決着を問わず、すべての終端観測状態**に適用する（閉包検証 N-4——ライセンス・M&A・資本自立で決着したシナリオも、稼働中の用途は評価期間以降も国内付加価値を立て続ける。ここを落とすと早く決着したシナリオほど裾を失い、早期の実現が構造的に過小評価される）。
(i) 未決着の観測状態は Tier 0 の既定規則で $H_C = 120$ か月延長する（この間も稼働度・離脱・事象の判定が動く。延長中に決着したシナリオは**9区分の実区分へ再分類**——「未決着の継続」は $T+H_C$ でも未決着のものだけ）。決着済みの観測状態は延長を回さず、稼働用途の生存過程だけを続ける。
(ii) 延長の終端で**生き残っている**用途に、残存の永久年金を置く。

$$
C(x_T, \theta) \;=\; \mathbb{E}\Big[\ \sum_{h=1}^{H_C} \frac{Y_{T+h}}{(1+d)^{h/12}} \;+\; \frac{1}{(1+d)^{H_C/12}} \sum_{u \in A_{T+H_C}} \bar y_u \cdot \mathrm{Ann}(d, \lambda^{\mathrm{obs}}) \ \Big|\ x_T,\ \theta,\ \pi^{0}\Big]
$$

| 記号 | 意味 |
|---|---|
| $Y_t = \sum_{u \in A_t} \phi_u \frac{\bar P_u - \delta_u}{12} \big(1-\alpha_u(t)\big)$ | 月 $t$ の純増の月額（§5.7 と同じ。稼働度＝立ち上がり 0→1 と陳腐化離脱は $A_t$ の遷移の側にある——改訂1-2） |
| $\alpha_u(t)$ | 反実仮想の控除の時間形（改訂1-6）: 評価日から前倒し期間 $L_u$ までは評価日の控除率、それ以降は「国内立地差だけが貢献に残る」水準へ上がる。**$L_u$ の起点は評価日でありシナリオ上の実現時期ではない**——実現が遅いシナリオほど貢献を過大に見る向きの近似（状態を膨らませない妥協。明示して較正で監視する） |
| $L_u$ | 用途 $u$ の前倒し期間（この案件が他者の実現をどれだけ前倒すか）。競合の状況から下限〜上限で推定する。較正前の初期値: 競合が活発な用途 36 か月・競合が見えない用途 120 か月（第二便で較正） |
| $h$ | 評価期間 $T$ からの経過月（$\Pi$ 側の $1/(1+d)^{T/12}$ と合成すると絶対時刻の割引に一致する） |
| $H_C$ | 既定規則で観測状態を延長する長さ: 120 か月。理由: 観測状態の個別情報（ゲート・権利・資金）に予測力が残る時間スケール。それより先は稼働の定常近似（永久価値）へ引き継ぐ。**裾の減衰はハザードが担うので、$H_C$ の選択は水準をほとんど動かさない（計算の切替点にすぎない）** |
| $\pi^{0}$ | Tier 0 の既定規則（評価期間の先の計画は誰も登録していないため） |
| $\bar y_u$ | 延長終端で**生き残っている**用途 $u$ の純増の月額（$Y$ の $u$ 成分。控除は立地差水準） |
| $\mathrm{Ann}(d, \lambda^{\mathrm{obs}})$ | 残存の月次永久年金係数: $q/(1-q)$、$q = (1 - \lambda^{\mathrm{obs}}/12)\,(1+d)^{-1/12}$。延長中と同じハザードの続きなので、二重計上も隙間も無い |
| $\lambda^{\mathrm{obs}}$ | 稼働した用途の陳腐化・代替の年率（改訂1-2 で $A_t$ の離脱ハザードとして定義）。初期値: 5%（範囲 3〜7%。産業の技術代替のおおまかな周期 15〜30 年に対応）。第二便で較正。§5.5 の $\lambda^{\mathrm{dem}}$（案件全体の需要側の死）とは別の量 |

運用の規則:
- 本番の報告は**この $C$ 一本**。簡略形（稼働分のみの年金）は実装途中の内部確認用とし、比較や報告に使わない（簡略形は稼働が途切れない仮定を含むため、$C$ より大きく出ることもある）。
- **継続価値がスコア全体に占める比率を毎回併記する**。比率が過半の案件は個別レビュー対象（最も検証しにくい仮定が値を支配しているため)。
- §5.7 の「初期形」（線形の式）は、この恒久形の実装までの暫定としてのみ使い、実装後は廃止する。
- **第二便への申し送り（裾を過大に見る向きの単純化2つ）**: $\delta_u$（国内の既存事業の置き換え分）は時間不変のままで、数十年の裾では硬直する。権利の残存期間（出願日起算）を超える月の $\phi_u$ の逓減も未実装。どちらも向きを明示して運用し、第二便で時間形を検討する。
