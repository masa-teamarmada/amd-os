残る次の段（第二便）: 係数の分野別初期値（κ・d_f・φ・ν・β・λ・L・失効期間）、735件の判断帯からの移行手順、較正計画の実施順。

**模型の芯** [根拠](#evidence "えいみの要約提示に、まさ 2026-08-24「今のところ違和感なし。進めて。」→ APPROVALS #2026-08-24-10"):

- 一件の案件を**月ごとに進む盤面**として表す。盤面に載るのは、次に越える関門の位置／燃料の残高（自由資金と使途制限資金の二勘定、円建て）／権利と学内承認の残件／会社化したか／受託契約の拘束／稼働している用途／これまでの成否
- 案件の**体質**（変換能力・技術の核・専有可能性・支払上限・追い風・エバンジェリスト候補の実在など）は直接見えないので、評価日の証拠から幅（帯）で置く
- 盤面は**登録された計画の規則**（観測できる出来事だけに条件づけた分岐。登録が無い案件は分野別の既定規則）で進み、道筋はやがて正本の9区分のどれかに落ちる
- 会社化は「何月」ではなく「この条件になったら」の規則として持ち、価値を最大にする規則との差が**会社化の早すぎ・遅すぎの診断**になる（タイミングの窓の測り方）
- 価値は、道筋の上で立つ**国内付加価値の純増**（置き換えと、この案件が無くても起きていた分を差し引き）を社会的割引率で現在価値にしたもの。遅く実現した道筋は自動的に軽くなる

**最上段の式（スコア）** [根拠](#evidence "まさ 2026-08-24「めちゃくちゃわかりやすかった！ うん、最上段の式はこの式で違和感ない」→ APPROVALS #2026-08-24-8"):

$$
V = \int \mathbb{E}\big[\Pi(\omega) \mid \theta\big]\, dB_0(\theta)
$$

| 記号 | 意味 |
|---|---|
| $V$ | 案件のスコア。円建ての帯 |
| $\theta$ | 案件の体質（直接は見えない部分）。証拠から幅で置く |
| $\omega$ | 一つの道筋（毎月の成り行きの一つの歴史） |
| $\Pi(\omega)$ | その道筋で立つ産業創出価値の現在価値 |
| $\mathbb{E}[\Pi \mid \theta]$ | 体質を固定したとしたら、起こりうる道筋を起こりやすさで均した価値の平均 |
| $\int \cdots dB_0(\theta)$ | 体質がまだ分かっていない幅の上で、さらに平均する（二段階の平均。内側の運は情報で消えないが、外側の幅は情報で狭められる） |

**二段目の式（一つの道筋の価値。確定済みの差し引き2点はここに入る）** [根拠](#evidence "まさ 2026-08-24「さっき確定させた『差し引き』の件が、まだモデルの式の中に表現されてないのでそれも一緒に入れてほしい」→ 式の提示に「今のところ違和感なし。進めて。」→ APPROVALS #2026-08-24-10。差し引き2点の確定は #2026-08-24-9"):

$$
\Pi(\omega) \;=\; \sum_{t=1}^{T} \frac{1}{(1+d)^{t/12}} \sum_{u \in A_t(\omega)} \phi_u\, \frac{\bar P_u - \delta_u}{12}\,\big(1 - \alpha_u(t)\big) \;+\; \frac{1}{(1+d)^{T/12}}\, C\!\big(x_T(\omega),\ \theta\big)
$$

| 記号 | 意味 |
|---|---|
| $\Pi(\omega)$ | 一つの道筋 $\omega$ の価値（円）。遅く実現した道筋は自動的に軽くなる（割引が道筋の中にあるため） |
| $t, T$ | 月。$T$ は全案件共通の経済評価地平 |
| $d$ | 社会的割引率（一本。公共投資の社会的割引率の系譜から較正。リスクの上乗せをしない——失敗は道筋の確率で数えている） |
| $A_t(\omega)$ | その月に稼働している用途の集合。用途は**採用決定・量産契約**で入り、稼働度（0→1 の立ち上がり。既定12か月）を経て満額に達する。抜けるのは二通り——需要の消失・契約終了・証拠の撤回という**出来事**と、陳腐化・代替の率 $\lambda^{\mathrm{obs}}$ による**確率的な離脱**。実現の形（自社・ライセンス先・買収後の主体）を問わず、国内に立つ分を数える |
| $\phi_u$ | 用途 $u$ の年額のうち、この案件の系統（承継者を含む）が国内に立てる割合（専有可能性に依存） |
| $\bar P_u$ | 用途 $u$ の天井（国内に立ちうる付加価値の年額） |
| $\delta_u$ | うち国内の既存事業が置き換えられて消える分 — **差し引き(1)**。$(\bar P_u - \delta_u)/12$ が純増の月額 |
| $1 - \alpha_u(t)$ | この案件が無くても他者が実現していた分の控除 — **差し引き(2)**。貢献は前倒しの期間と国内立地の差に限る。競合がいなければ控除ゼロで全額が貢献。**時間の関数**——前倒し期間 $L_u$ を過ぎたら、国内立地差だけが貢献に残る水準へ上がる |
| $C(x_T,\theta)$ | 地平の月の盤面から先に置く継続価値。既定の規則で120か月延長し、生き残った稼働分に陳腐化込みの残存価値を置く（決着済みの道筋にも適用する） |

**三段目の式（盤面がどう進むか。道筋 $\omega$ はこの規則で生まれる）** [根拠](#evidence "承認済みの BZM 3.0 本文 §2・§4 からの転記であり、新しい主張はない。まさ 2026-08-24「ptadvとかηtの式って、正本にまだ書かれてなくない？ ここまでの確定事項がすべて正本に書かれているか、再度確認して」→ APPROVALS #2026-08-24-10・#2026-08-24-11"):

一つは**関門を越える確率**。案件がその月に次の関門を越えられるかを決める。

$$
p^{\mathrm{adv}}_t \;=\; 1 - \exp\!\big(-\,\kappa_{g_t} \cdot \psi_{g_t} \cdot c \cdot \eta_t \cdot (1 - \gamma \rho_t)\big)
$$

| 記号 | 意味 |
|---|---|
| $p^{\mathrm{adv}}_t$ | その月に関門を越える確率 |
| $\kappa_{g_t}$ | いま前にある関門の基準速度（分野×関門種。標準関門表から引く。値は第二便） |
| $\psi_{g_t}$ | 技術系の関門では技術の核 $\psi$、それ以外の関門では 1 |
| $c$ | 変換能力（投入した資源あたりに前進を生む速さ） |
| $\eta_t$ | 担い手の充足係数（下の式） |
| $\gamma \rho_t$ | 受託が前進を食う分。$\rho_t$ は受託に割く工数の割合、$\gamma$ は**本業との近さの区分別**（同源＝0 で食わない／隣接／無関係） |

もう一つは**担い手の充足係数**。経営チームの空席が前進をどれだけ遅らせるかを決める（空席は減点ではなく遅延）。

$$
\eta_t \;=\; \prod_{f \in \mathcal F} \big(1 - d_f \cdot \mathbb 1[\,\text{機能 } f \text{ が } t \text{ で空席}\,]\big)
$$

| 記号 | 意味 |
|---|---|
| $\mathcal F$ | 経営チームが持つべき機能（機能分解表の八機能。要件9） |
| $d_f$ | 機能 $f$ の空席がもたらす遅延（0〜1）。エバンジェリスト機能が最大。値は第二便 |
| $\mathbb 1[\cdot]$ | 空席なら 1、埋まっていれば 0（充足の判定は直近12か月・2時点以上の実働の記録） |

三つめは**燃料の増減**。ゼロと交差した月に道筋は終わる（撤退・清算）。

$$
s^{\mathrm{f}}_{t+1} = s^{\mathrm{f}}_t - \mu^{\mathrm{f}}_t + \rho_t\, r + y_t + z^{\mathrm{f}}_t
\qquad
s^{\mathrm{r}}_{t+1} = s^{\mathrm{r}}_t - \mu^{\mathrm{r}}_t + z^{\mathrm{r}}_t - \ell_t
$$

| 記号 | 意味 |
|---|---|
| $s^{\mathrm{f}}_t,\ s^{\mathrm{r}}_t$ | 自由資金と使途制限資金の残高（円）。大学経由の契約収入は間接経費控除後を使途制限側で扱う |
| $\mu^{\mathrm{f}}_t,\ \mu^{\mathrm{r}}_t$ | その月の燃焼（円／月）。会社化後は固定費が増える |
| $\rho_t r$ | 受託の稼ぎ（$r$＝工数を全部割いたときの稼ぎ＝自走力） |
| $y_t$ | 稼働している用途からの売上（稼働度を掛ける）。産業の付加価値 $\bar P_u$ とは別の量 |
| $z^{\mathrm{f}}_t,\ z^{\mathrm{r}}_t$ | その月の補給（民間調達→自由資金、公的採択→使途制限資金） |
| $\ell_t$ | 年度の壁による使途制限資金の失効 |

残りの過程——資金の窓と採択、実現の申し出（ライセンス・M&A・知財売却）、権利と学内承認の解決、確率的な消失、月の中の順序、報告の様式、較正とゲーム耐性——の式と定義は [BZM 3.0 本文](/model/2026-08-24_step4_scoring-model-v3) にある（この台帳と同じく承認済みでロック済み）。

横断の結論: 既存理論はどれも「会社がある・財務諸表がある・担い手が決まっている・標本に残っている」ところから始まる。Before Zero にはどれも無いので、使えるのは概念の区分と関数の形で、測定の手続きは作る必要がある。手順4 は、まずこの共通の穴（Before Zero 固有の観測単位）を定義してから、個別の式へ降りる。

要件は独立ではない。外部の実証で相関が確認できている組は 要件11⇄12（学習によるコスト低下は累積投資の関数でもある）と 要件9⇄12（担い手の交代は資金ラウンドで起きる）。構造上、要件2⇄12（いま持っている燃料と、要る燃料の総量）と 要件1⇄2（変換能力を余力の増分で測ると同じ量）は二重計上になりうる。相関のある組を独立と仮定して掛け算しない。
