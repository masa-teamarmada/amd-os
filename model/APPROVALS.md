# APPROVALS.md — まさ承認の記録台帳

このファイルは `model/` 配下のモデル正本（および `model/LOCK.json` にロック対象として
列挙されたファイル）を変更してよいという、まさの承認だけを記録する。

## 運用

- エントリ形式は次の通り、日付が変わった同日内の複数件は連番で区別する。

  ```
  ## YYYY-MM-DD-N

  日付: YYYY-MM-DD

  引用:
  > (まさの発言をそのまま引用する。要約や言い換えをしない)

  対象ファイル:
  - path/to/file1.md
  - path/to/file2.md

  反映commit: (未反映なら「(未反映)」、反映後に司令塔がハッシュを追記)
  ```

- 「対象ファイル」に列挙したパスが、そのままロック対象（`model/LOCK.json` の `files[]`）に
  入る。`node pwa/scripts/model_lock.cjs relock --approval <id>` はこのセクションのパス一覧を
  読み取って `LOCK.json` を再生成する。パスはリポジトリルート（`amd-os/`）からの相対パスで書く。
- 承認の引用を要約・翻訳・創作しない。まさが実際に書いた／言った言葉をそのまま貼る。
- このファイルへの追記は、まさの承認が実際にあった場合だけ行う。提案段階では書かない。

内容:

### 1. 反実仮想の控除 $\alpha_u(t)$ と前倒し期間 $L_u$ を、モデルから外す

スコアは案件ごとに出すもので、案件をまたいで足さない。足さないなら、同じ産業を二重に数える心配は起きない。
同じシーズの2社がそれぞれ国内に 100 億円の産業を立てるなら、それぞれのスコアは 100 億円でよい。
差し引きは「足したときに二重にならないように」という配慮から入っていたので、足さない前提では要らない。

あわせて、この控除は §7.1 Q4 が自ら「反実仮想で原理的に観測できない。較正しない」と書いている量でありながら、
弾力性 +0.96（4位）でスコアの水準を 6.67 分の1に潰す最大級の係数だった。観測できない量が水準を支配する構造を解く。

削除する量: $\alpha_u(t)$（反実仮想の控除の時間形）、$\alpha^{\mathrm{loc}}$ の本体適用、
$\alpha_u^{\mathrm{now}}$（評価日の控除率。Tier 0 暫定 0.30）、$L_u$（前倒し期間。競合が活発 36 か月／見えない 120 か月）。

### 2. 置き換え分 $\delta_u$ は残す

既存の国内事業から奪った分は、その案件が日本に新しく立てた付加価値ではなく、他所から移しただけである。
「個社ごとの日本経済へのインパクト」で測っても、移転は増分にならない。$(\bar P_u - \delta_u)$ の形は変えない。

### 3. 追加的貢献の数字は、換算として残す

対外的に「他者がやっていた分を差し引いた追加的な貢献はいくらか」を問われたときのために、
$V^{\mathrm{add}} = (1 - \alpha^{\mathrm{loc}})\,V = 0.15\,V$ を併記できるようにする。
$\alpha^{\mathrm{loc}} = 0.85$（国内立地差だけが貢献に残る水準）は係数として残すが、**モデル本体の計算には入らない**。
全案件一律の定数倍なので順位も比も動かさず、**案件の比較には使えない**ことを正本に明記する。

### 4. 帰結

- スコアの水準が全案件で 6.67 倍になる。全案件に同じ係数が掛かっていたので、**順位は動かない**。
- 2026-09-01 の提案 `model/proposals/2026-09-01_counterfactual-lead-time.md`（前倒し期間を案件ごとに置く案）は、
  前倒し期間そのものが無くなるため撤回し、`model/withdrawn/` へ移す。
- §6.I-11-2 の縮退検査、§6.I-11-4 の弾力性、§6.I-11-5 の報告の幅は、控除を外した実装で取り直す。
