## ティエムファクトリ (tiem)

| 項目 | 値 |
|---|---|
| ID | `tiem` |
| 設立 | 2012-11 |
| 終了 | 2022 |
| レーン | materials (透明断熱素材) |
| アウトカム | burnout |
| XRL ボトルネック | HRL — 市場形成が致命的に低かった |

### 背景
- 京都大学 山地正洋先生発の透明断熱素材スタートアップ
- 透明断熱 = 窓ガラス等に塗布すると断熱性能が上がる先端素材
- **設立時 TRL3** — 理論実証のみ。商業化への道が見えていない状態で立ち上げた最初のケース
- AMD スタジオモデル初期、まだ「TRL最低ラインを設けるべき」という教訓がなかった

### 軌跡（XRL 視点）
```
2012: TRL3 / BRL1 / HRL2  設立（理論実証のみ）
2015: TRL4 / BRL2 / HRL2  ラボ試作 / 特許出願
2017: TRL4 / BRL3 / HRL2  シリーズB資金調達
2019: TRL5 / BRL3 / HRL2  オフサイトPoC成功（断熱性能の実証）
2021: TRL5 / BRL3 / HRL2  オンサイトPoC → 大手建材メーカーの要求スペック未達
2022: TRL5 / BRL3 / HRL2  資金切れ → 退任・終了
```

### なぜ燃え尽きたか（AMD 教訓）
- TRL5 まで到達したのに終了した = 技術的失敗ではない
- **HRL2 が致命的**: 建材メーカーが「これを採用する理由」＝市場の準備ができていなかった
  - 断熱規制（省エネ基準）が強化される前 → 義務化の圧力がなかった
  - ユーザー（施工業者・建材メーカー）が「今あるもので十分」と感じていた
- BRL は中程度（3）あったが、ビジネス化の出口（チャネル・購買意思決定者）が固まらなかった
- **AMD OS の出発点**: "なぜあのタイミングで立てたのか" を定量的に振り返るためのシステムが欲しかった

### デモでの使い方
> View A でティエムのピンを指して「2012年、材料レーンのマクロ指数が低い時期に立てた。
> TRL だけあって、HRL（市場）が追いついていなかった。
> これが 10年後に分かるのが AMD OS の意義。」

## JOYCLE / JC (jc)

| 項目 | 値 |
|---|---|
| ID | `jc` |
| 設立 | 2023-07 |
| 終了 | 2026-03 |
| レーン | gx_circular (廃棄物・熱分解リサイクル) |
| アウトカム | deep_pivot |
| XRL ボトルネック | BRL (事業化構造) |

### 背景
- 群馬大学 小柳裕太郎先生主導で AMD がサポート
- **設立時のコア技術**: IRS（インクリメンタルリフォーミングシステム）プリミティブ熱分解
  - プラスチック廃棄物 → 熱分解 → 可燃性ガス・オイル
  - TRL3 程度の比較的初期技術で立ち上げた
- **後付け deep 化**: 設立後に群馬大学 野田先生（流動層熱分解の専門家）が合流
  - 流動層熱分解 = スケールアップしやすく、産廃処理業者向けのビジネスモデルに合致
  - 技術の根本から re-architecture した「珍しいケース」

### 軌跡（XRL 視点）
```
2023-07: TRL3 / BRL2 / HRL2  設立（IRS熱分解、TRL3）
2024-01: TRL4 / BRL2 / HRL3  野田先生合流 / 流動層熱分解でdeep化開始
2024-07: TRL5 / BRL3 / HRL3  流動層プロセス実証実験成功
2025-03: TRL6 / BRL3 / HRL4  パイロット装置設計 / 産廃ビジネスモデル確立
2026-03: TRL6 / BRL3 / HRL4  終了（AMD関与終結）
```

### deep_pivot のメカニズム
- 「IRS 熱分解」という shallow な技術で始まり、途中で「流動層熱分解」という深い技術に乗り換えた
- このリアーキテクチャは通常のピボット（ビジネスモデル変更）ではなく、**技術コアの deep 化**
- AMD が関与したことで野田先生との接続が生まれた（AMD のネットワーク価値）
- BRL3 止まりで終了 → 産廃処理業者との大型契約に至る前に AMD 関与が終結

### AMD OS における位置づけ
- AMD 史上最長プロジェクト（JC が 2022-2026 の約4年、ティエムが10年だが AMD 関与期間は異なる）
  ※ まさ談: "JCとかでもいいかも、AMD最長？のPJ"
- deep_pivot パターンの典型例。SU 個別ビューで「後付け deep 化」の時系列を見せられる
- GX サーキュラーレーンが 2022-2024 で最も政策的に盛り上がった時期に BRL3 止まりだった点が示唆的

### デモでの使い方
> "JC は珍しいケースで、最初の技術（IRS）が浅かったんですが、
> 途中で野田先生が来て技術の根幹から入れ替えた。
> このタイムラインを XRL で見ると、2024年1月に TRL が跳ね上がって BRL が追いついてくるのが分かります。"

## 2社から学べる AMD 投入原則

| 原則 | ティエム | JC |
|---|---|---|
| 設立時 TRL | 3（低すぎ） | 3（同様に低い） |
| BRL | 最後まで3 | 3で終了 |
| HRL | 2のまま燃え尽き | 4まで上昇したが未完 |
| マクロ指数 (設立時) | 低（0.18前後） | 高（0.65超 / GX法後） |
| 結論 | **マクロが来る前の TRL3 立上は BRL/HRL 追いつかず燃える** | **マクロが来た後でも BRL 不足で終わる** |

→ 投入シグナル σ_SU が高くても、XRL の三角形（TRL/BRL/HRL のバランス）が整っていなければ結果は出ない。
これが AMD OS の「マクロ × XRL の複合評価」への移行動機。
