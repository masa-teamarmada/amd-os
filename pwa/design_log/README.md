# design_log — 運用ルール

PWA セッションの作業ログ置き場。

## 月次ログの肥大対策 (2026-05-30 確立)

- 各月のログは `sessions_YYYY-MM.md` に追記する（書き込み先のファイル名はこれで固定。他 md からの参照が多数あるため改名しない）。
- **本体が ~3000 行 / ~300KB を超えたら、古い分を `sessions_YYYY-MM_partN.md` に切り出して本体を縮める。**
  - 理由: 1 ファイルが巨大化すると、Edit / Read 時に巨大文字列がツール呼び出しの JSON に乗って壊れ、`The model's tool call could not be parsed (retry also failed)` エラーを **全セッションで多発**させる。2026-05 に 835KB / 1 万行まで肥大し、並行していた複数セッションが同時に停止する実害が出た。
  - これは「気をつける」ではなく、肥大したら必ず実施する**構造ルール**。
- 切り出しは Edit ではなく `sed` / `cat` で機械的にやる（巨大文字列を Edit に渡すこと自体がエラー源なので、分割作業でエラーを誘発しないため）。
- 本体冒頭に過去ログ索引（範囲 → part ファイル）を置く。
- 参照は **ファイル名 + セクション見出し（`#NN` や日付）** で行う。**行番号直指定（`L1234` 形式）は追記でズレるので禁止。**

## ファイル

- `sessions_YYYY-MM.md` — その月の最新分 + 過去ログ索引
- `sessions_YYYY-MM_partN.md` — 切り出した過去分（古い順に part1, part2, ...）
