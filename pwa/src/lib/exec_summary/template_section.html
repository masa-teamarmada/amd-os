CHALLENERGY 2014年設立 / 垂直軸型風力発電
Challenergy
台風や強風でも発電できる、自治体・離島・公共施設向けの小型風力発電機（販売中）。
30-SEC OVERVIEW
一般的なプロペラ風車が苦手な台風 / 強風 / 乱流環境でも発電できる、独自の垂直軸型小型風力発電機。すでに「Type D」を販売中で、定格100W / 最大250W、耐風速40m/s。自治体の防災電源、離島・公共施設の脱炭素、企業版ふるさと納税との組み合わせなど、即・地域に提案可能な唯一の販売プロダクト。
