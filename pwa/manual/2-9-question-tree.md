# 論点・仮説の使い方

PJワークスペースの「実行 → 論点・仮説」タブ。分からないことを分解して、確かめる手をぶら下げ、答えが出たものから閉じていく。

これまでこのタブにあった一覧（4つの列に分かれたカードと、手で並べ替える表）は、この形へ置き換わった。

## 何が置いてあるか

置けるものは3つだけ。

**問い**は、答えが出れば閉じるもの。「バイオディーゼル事業は成立するか」「この株は作れるか」「誰がいつ確認するか」。今まで論点・仮説・決めること・目的・成立条件と呼んで別々に置いていたものは、全部これ。

**やること**は、実行すれば終わるもの。測る、調べる、見積もる、相手に聞く、資料を作る。問いの下にぶら下がる。

**分かったこと**は、事実と出どころ。測定結果でも、相手の発言でも、論文でも、出どころを必ず持つ。

## 詳細を開く

行を押すと、画面の手前にカードが開く。背景・答え・ぶら下がっているやること・分かったこと・その問いから生まれたものが1枚に入っている。見出しの上に、その問いがどの問いの下にあるのかが小さく並ぶ。押すとそちらへ移れる。

**それぞれの値は押すとその場で直せる。** 担当、期限、確からしさ、種類、親との関係、見出し、背景。点線の下線が付いているものが直せる印。`（自動）` と書いてあるものは画面が計算して出しているので触れない。

閉じるのは右上の × か Esc か、外側をクリック。閉じても木の位置は動かない。

## 下にぶら下げる

開いて「子を追加」。種類を選ぶ。

| 種類 | いつ使うか |
|---|---|
| 論点 | これが解けないと親が解けないもの。「事業が成立するか」の下の「原料が取れるか」「収支が合うか」「必要な量を作れるか」は3つとも論点で、1つでも崩れたら親は成立しない |
| 仮説 | どれか1つ立てば足りる答えの候補。「油の量を増やせるか」に対する「強化株を作る」「別の株を探す」は仮説で、どちらかが立てばいい |
| 決めること | 事実ではなく意思で決まるもの |
| やること・確かめる | 測る、調べる、見積もる、相手に聞く |
| やること・作業 | 決まったことを実行する |

**仮説が全部つぶれた瞬間に「枝が死んだ」と画面が言う。** 逆に論点が1つ取り下げられても同じ。文章で書いていると気づけないことが、木にすると自動で出る。

**確かめるやることが1つもぶら下がっていないものは、「手が止まっている」と出る。** 増えるだけで前に進まない状態を、人が気づく前に見つけるため。

ひとつのやることは複数のところにぶら下げられる。1回の測定で2つに同時に答えが出るとき、片方だけにぶら下げると、もう片方が永久に未確認のまま残る。

## 閉じる

問いを開いて「答えを書いて閉じる」。**答えは1行でいい。** 仮説・根拠・検証・判断を全部埋めろとは言わない。厚く残したい問いだけ、分かったことを足していけばいい。

答えが書かれていない問いは閉じられない。追わないと決めた枝も、理由を書かないと捨てられない。あとから「なぜこれをやめたのか」が分からなくなるのを防ぐため。

**子が全部片付いても、親は自動で閉じない。** 「判断できる」と表示が変わって、その行に青が付く。答えを書くのは人。

## どこから手を付けるか

**手を打つべき問いは、木の中でその行に色が付く。** 青は「判断できる」、黄は「手が止まっている」、赤は「枝が死んだ」。左端の縦線が赤いものは期限を過ぎている。

上に別枠で抜き出すことはしない。抜き出すと、それがどの大きな問いの下にあるのかが分からなくなるため。色が付いた行を木の中で見れば、親をたどって文脈のまま拾える。

色が付いた問いは、画面を開いたときに最初から見えるところまで枝が開いている。

## 順番を変える・別の親へ移す

行の左のつまみを掴んで動かす。掴んでいるあいだは、その行の複製がマウスと一緒に動く。

**同じ親の中で順番を変えるなら、行と行のあいだ（上下の縁）へ落とす。** 青い線が入るので、そこへ挿さる。先に解決できるものや重要なものを上にしておける。

**別の問いの子にするなら、その問いの真ん中へ落とす。** 行が青い枠で囲まれるので、その下に入る。

自分の下にある問いへは動かせない（輪になってしまうため）。途中でやめたいときは Esc。

## 数字の読み方

| 表示 | 意味 |
|---|---|
| 判断できる | 下がすべて片付いた。答えを書けば閉じる |
| 手が止まっている | 子もやることも無い。前に進む手が置かれていない |
| 枝が死んだ | 代替が全滅した、または必須の枝が捨てられた。親の答えが出せない |
| 期限超過 | 自分か子孫の期限が過ぎている |
| 確認N | この問いの下に残っている、未完了の確かめる行為がN件 |

## どの問いにもつながっていないやること

画面の一番下に出る。実行するだけで答えを出さない作業（登記する、契約書を送る）ならそれでいい。そうでないなら、つなぎ忘れ。
