# ゴールツリーの使い方

PJワークスペースの「実行 → ゴールツリー」タブ（2026-09-11 まで「論点・仮説」という名前だった）。**シーズンの終わりにこうなっている、という到達点を一番上に置き**、そこから分からないことを分解して、確かめる手をぶら下げ、答えが出たものから閉じていく。この木のことを**ゴールツリー**と呼ぶ。

これまでこのタブにあった一覧（4つの列に分かれたカードと、手で並べ替える表）は、この形へ置き換わった。

## 木のかたち

上から4段。

**到達点**は、シーズンの終わりにこうなっている、という状態。「2027年4月1日にNewCoを設立し事業を開始している」のように書く。1つのPJに1本から数本。木の一番上にある「到達点を追加」から作る。

**MS**は、その到達点が成り立つための条件。到達点のすぐ下にだけ置ける。「出資の確約」「愛媛大との諸手続き完了」のようなもの。シーズンのマイルストーン（お金の配分の単位）と対応する。

その下が**論点**で、さらに下に**やること**がぶら下がる。

到達点の行で「子を追加」を押したときだけ、種類に「MS」が出る。他の場所では出ない。

## 何が置いてあるか

置けるものは3つだけ。

**問い**は、答えが出れば閉じるもの。「バイオディーゼル事業は成立するか」「この株は作れるか」「誰がいつ確認するか」。今まで論点・仮説・決めること・目的・成立条件と呼んで別々に置いていたものは、全部これ。

**やること**は、実行すれば終わるもの。測る、調べる、見積もる、相手に聞く、資料を作る。問いの下にぶら下がる。

**分かったこと**は、事実と出どころ。測定結果でも、相手の発言でも、論文でも、出どころを必ず持つ。

## 詳細を開く

行を押すと、画面の手前にカードが開く。背景・答え・ぶら下がっているやること・分かったこと・その問いから生まれたものが1枚に入っている。見出しの上に、その問いがどの問いの下にあるのかが小さく並ぶ。押すとそちらへ移れる。

**それぞれの値は押すとその場で直せる。** 四角く囲まれているものが直せる印。`（自動）` と書いてあるものは画面が計算して出しているので触れない。

**やることの行も同じように押せる。** 開くと、状態・担当・期限・着手予定・完了日・見積pt・方法・完了条件・完了の証跡・詰まっていることが出る。確かめる行為なら目標値と実測値も。一番下に「これが答えを出す論点」が出るので、押せばそちらへ移れる。

**担当は名前を押して付ける。** 複数人でもいい。押した瞬間に保存される。付けた瞬間が「その人に頼んだ」ことになるので、保存ボタンは置いていない。

名前が並ぶのは、AMDのメンバーだけ。相手先の人（こたさんなど）や「研究側」のような書き方は、その下の「担当メモ」に文章で残す。

閉じるのは右上の × か Esc か、外側をクリック。閉じても木の位置は動かない。

## 下にぶら下げる

開いて「子を追加」。種類を選ぶ。

| 種類 | いつ使うか |
|---|---|
| 論点 | これが解けないと親が解けないもの。「事業が成立するか」の下の「原料が取れるか」「収支が合うか」「必要な量を作れるか」は3つとも論点で、1つでも崩れたら親は成立しない |
| 仮説 | どれか1つ立てば足りる答えの候補。「油の量を増やせるか」に対する「強化株を作る」「別の株を探す」は仮説で、どちらかが立てばいい |
| 決めること | 事実ではなく意思で決まるもの |
| やること・確かめる | 測る、調べる、見積もる、相手に聞く |
| やること・作業 | 決まったことを実行する |

**仮説が全部つぶれた瞬間に「枝が死んだ」と画面が言う。** 逆に論点が1つ取り下げられても同じ。文章で書いていると気づけないことが、木にすると自動で出る。

**確かめるやることが1つもぶら下がっていないものは、「手が止まっている」と出る。** 増えるだけで前に進まない状態を、人が気づく前に見つけるため。

ひとつのやることは複数のところにぶら下げられる。1回の測定で2つに同時に答えが出るとき、片方だけにぶら下げると、もう片方が永久に未確認のまま残る。

## 閉じる

問いを開いて「答えを書いて閉じる」。**答えは1行でいい。** 仮説・根拠・検証・判断を全部埋めろとは言わない。厚く残したい問いだけ、分かったことを足していけばいい。

答えが書かれていない問いは閉じられない。追わないと決めた枝も、理由を書かないと捨てられない。あとから「なぜこれをやめたのか」が分からなくなるのを防ぐため。

**子が全部片付いても、親は自動で閉じない。** 「判断できる」と表示が変わって、その行に青が付く。答えを書くのは人。

## どこから手を付けるか

**手を打つべき問いは、木の中でその行に色が付く。** 青は「判断できる」、黄は「手が止まっている」、赤は「枝が死んだ」。左端の縦線が赤いものは期限を過ぎている。

上に別枠で抜き出すことはしない。抜き出すと、それがどの大きな問いの下にあるのかが分からなくなるため。色が付いた行を木の中で見れば、親をたどって文脈のまま拾える。

色が付いた問いは、画面を開いたときに最初から見えるところまで枝が開いている。

## 順番を変える・別の親へ移す

行の左のつまみを掴んで動かす。掴んでいるあいだは、その行の複製がマウスと一緒に動く。

**同じ親の中で順番を変えるなら、行と行のあいだ（上下の縁）へ落とす。** 青い線が入るので、そこへ挿さる。先に解決できるものや重要なものを上にしておける。

**別の問いの子にするなら、その問いの真ん中へ落とす。** 行が青い枠で囲まれるので、その下に入る。

自分の下にある問いへは動かせない（輪になってしまうため）。途中でやめたいときは Esc。

## 数字の読み方

| 表示 | 意味 |
|---|---|
| 判断できる | 下がすべて片付いた。答えを書けば閉じる |
| 手が止まっている | 子もやることも無い。前に進む手が置かれていない |
| 枝が死んだ | 代替が全滅した、または必須の枝が捨てられた。親の答えが出せない |
| 期限超過 | 自分か子孫の期限が過ぎている |
| 確認N | この問いの下に残っている、未完了の確かめる行為がN件 |
| 未アサイン | やることの行に付く。担当か期限のどちらかが決まっていない |
| TODO 7（未7） | 到達点とMSの行に付く。その下にぶら下がっているやることの数と、そのうち担当か期限が空の数 |

**上の「未アサイン ○件」は押せる。** 押すと、畳まれているところが開いて、いちばん上の該当する行まで画面が動く。

## 会議のときと、そのあと

**会議中は、種類と内容だけ入れて足していく。** 担当も期限も空のままでいい。その場で「誰がやる?」を詰めると会議が止まるため。

**担当・期限・見積ptは、会議のあとに決める。** まさかPMが Codex / Claude を開いて、えいみと話しながら「このやることは誰に、いつまでに、何pt」を決め、えいみがOSに書き込む。ひとつずつ手で入力する運用にはしない。全PJぶんを手作業で回すのは無理だから。

決まったあとに直したくなったら、この画面のやることを開いて、担当と期限をその場で直せる。

**ptはこの画面には出ない。** ゴールツリーとガントは社外のメンバーも開く画面なので、報酬につながる数字は置いていない。**ptを見るのは「MS・月次」タブの「TODOのpt」**（社内だけが開く画面）。MSごとにまとまって、大きい順に並び、棒の長さでそのPJの中での重さを比べられる。

## つくよみが拾った、まだ木に無いもの

画面の上に出る。**会議の記録に出ていたのに、このタブへ登録されていないもの**をつくよみが毎日拾ってくる。

毎朝04:35に、前日以降の開催済み議事録を確認する。対象は問いとやることだけで、議事録のTODOを全部写す処理ではない。すでに木にあるもの、提案中のもの、以前「いらない」としたものは、言い方が違っても同じ意味なら出さない。1つのPJにつき1日最大5件。

会議中に自分で書き足すのが基本で、つくよみは書き漏らしを拾うだけ。だから件数は多くならない。

各行に「どの論点の下に付きそうか」と「なぜそう考えたか」が出る。**「木に入れる」を押すとその場所に入り、「いらない」を押すと消える。** 押すまで木には入らないので、間違った推測がそのまま台帳に混ざることはない。

## どの問いにもつながっていないやること

画面の一番下に出る。実行するだけで答えを出さない作業（登記する、契約書を送る）ならそれでいい。そうでないなら、つなぎ忘れ。

## ガントは同じ木の別の見え方

「実行 → ガント」タブを開くと、**左側にこの木がそのまま並び、右側にやることの日程が棒で出る**。問いの行には、その下のやることが動いている期間が細い線で出る。赤い縦線が今日。

棒はつまんで動かせる。真ん中を掴むと期間ごと移動、左端で開始日、右端で期限が変わる。

棒の右に出る「＋」を押してから別の棒を押すと、**前後関係**がつながる（先に終わる方から押す）。やめたいときは Esc。つないだ関係は、やることを開けば外せる。

**日程が決まっていないやることは、ガントの下に「日程未設定」としてまとめて出る。** ここで日付を入れると、上の棒に並ぶ。担当はここでは付けない。ゴールツリータブの木で付ける。ptはそもそもこの2つの画面に出ない（下の「数字の読み方」）。

どちらのタブで直しても、同じ1行が変わる。
