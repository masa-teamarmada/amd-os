# はじめて使う人向け — ざっくり使い方

AMD OS をまだよく分かっていないメンバーが、最初に迷わないための章。細かい仕様は後半の「全体設計・細かい仕様」へ回し、ここでは **どの画面で何を見るか** だけを掴む。

サイトトップ `/` は共通ポータル。ログイン前は「ログイン」から招待されたメールアドレスを入力する。社内メンバーの入口は社内ログインが済んだ人だけに表示する。外部ログインが完了すると、閲覧を許可されたワークスペースとDDの一覧へ進む。共有資料のリンクから入る場合は、その資料へ進む。研究機関全体を選んでも、PJだけを許可された人は自分の閲覧できる一覧へ案内される。

ログイン画面は全員共通。メールアドレスを入力して「続ける」を押す。`team-armada.jp`のメールはGoogleログインへ進み、それ以外はメールでログインコードを受け取る。社内・PJ・外部の選択は不要。招待されたメールアドレスを使い、届いたメールの数字をログイン画面の「メールのログインコード」に入力して「ログインする」を押す。共有URLから入った場合は、ログイン後もその行き先を引き継ぐ。

ログインメールは「チームアルマダ OS」から日本語で届く。メール内にはコードと入力の案内だけがあり、ログインボタンはない。最新のコードを使い、使用済み・期限切れの場合は「新しいログインメールを受け取る」から申し込み直す。メールを読むブラウザとログイン画面のブラウザが異なってもコードを入力できる。外部の人にGoogle Workspaceのアカウントは求めない。閲覧許可の確認を求められた場合は管理者が設定を確認する。

研究機関・PJ関係者は、同じブラウザでは30日間ログイン状態を保つため、アクセスのたびにメール認証する必要はない。30日経過、ログアウト、Cookie削除、別ブラウザ・別端末では再認証する。管理者がアカウント・所属・PJ権限を停止した場合は、30日を待たず次のアクセスから見られなくなる。

DDのリンクを開くときにログイン状態が切れていたら、メール入力の画面へ戻る。招待されたメールでログインすると、開こうとしたDDのページへ進む。

ログインメールの送信操作は、同じ登録アカウントについて60秒に1回、15分に5回までに制限する。

制限中や未登録メールでも画面の応答は同じにし、登録有無を第三者へ知らせない。

### 研究機関・PJ関係者が見る場所

外部利用者は`/workspaces`で、自分に明示付与された研究機関workspaceとPJだけを選ぶ。

研究機関への所属だけで、その機関に関係する全PJを見られるわけではない。

PJの進捗が未登録なら「未登録」と表示し、0%とは表示しない。

参加PJの読み込みに失敗した場合も「参加PJなし」とは表示せず、参加状況は変わっていないことと再読込を案内する。

## 複数タブの見分け方

開いているタブの名前には先頭に「▶」が付く。タブを切り替えると印も移る。

PJのタブ名は「SOL｜コックピット｜ゴールツリー」「SolvioraX｜DD｜資本政策表」のように、PJ・スペース・表示中の内容で見分けられる。コックピットやワークスペースのメニューでページを変えると、タブ名も変わる。

更新前から開いているタブは再読み込みすると新しい名前になる。

## まず見る順番

```text
ログイン
  ↓
/dashboard
  ↓
自分に関係ある PJ を開く
  ↓
/project/{project_id}/cockpit
  ↓
必要に応じて /mypage / notifications / reimburse
```

| やりたいこと | 開く場所 | 見るもの |
|---|---|---|
| 自分の担当 PJ を確認したい | `/dashboard` | 研究機関・シーズの優先候補、PJ 一覧、各 PJ cockpit への入口 |
| 自分の今週の活動・報酬予定を見たい | `/mypage` | 参加 PJ、今週やったこと、月次報酬予定、月初合意 |
| PJ の状況を見たい | `/project/{project_id}/cockpit` | AMD Score、MS、経営ハイライト、月次カード、MTG サマリ |
| OS からの確認依頼に答えたい | `/notifications` | L2 候補 (= OS が抽出した構造化データの未確認候補)、MS差分、台帳差分、XRL根拠、修正依頼 |
| 立替を申請したい | `/reimburse` | 領収書添付、金額、用途、PJ 紐付け |
| 請求・支払・PJ台帳を触りたい | `/admin/*` | admin 権限が必要 |

ホームとコックピットでは、左上の「≡」を押すと全体メニューが開く。全体メニューは「PJポートフォリオ」グループが最上位にあり、**ホーム**（= `/dashboard`）・**研究機関**・**シーズ**・**PJ運用** の4つを切り替えられる。ホームにマウスを重ねると、いまアクティブなPJが右側に一覧で開く。さらに目的のPJへマウスを重ねると、Chromeのブックマークフォルダのように右側へ移動先が開く。**コックピット**はAMDメンバー限定の判断・経営情報を見る面、**ワークスペース**はAMD外を含む当該PJメンバー限定の共有面。入口と利用者区分は別のまま、「PJ運用」はホーム下段の全PJ一覧へ直接移動する。

### ホーム（`/dashboard`）の見方

PJポートフォリオのPJカードを押すと、そのPJのコックピットが別タブで開き、ホームは元のタブに残る。研究機関PJ・シーズPJ・事業会社PJと、下段のPJ運用一覧も同じ。まだPJに紐づいていない候補は、研究機関またはシーズの詳細を開く。

画面上部の左矢印「戻る」で、直前に見ていたページへ戻れる。右矢印「進む」で、戻る前のページをもう一度開ける。Chromeでは行き先がない矢印は薄く表示され、押せない。ワークスペース・DDにも同じ矢印があり、ブラウザの戻る・進むと同じ履歴を使う。

上から順に、**先手TODO**（判断・着手が要る件数）→ **PJポートフォリオ**（稼働中PJとPJ化検討中の候補を、研究機関PJ / シーズPJ / 事業会社PJ の3つに分けた一覧）→ **PJ運用**（全PJの台帳。稼働中・商談準備中は開いた状態、終了停止中は折り畳み）→ **要対応**（期日順）→ **経営指標・接続状況**（折り畳み）→ **会社の記録**。

- **PJポートフォリオの3列**は出自で分かれる。研究機関から生まれたPJ、シーズから生まれたPJ、どちらにも紐づかない事業会社とのPJ。行は「PJ番号 + PJ名」が主役で、下に小さく相手先が出る。まだPJになっていないシーズだけシーズ名が主役になる。
- **右カラム**はマイページの埋め込み（画面幅が広いときだけ）。当月報酬と月初合意は畳んであり、押すと開く。常に見えているのは「来週やること / 今週やったこと」。
- **会社の記録**（一番下）は、写真を横いっぱいに並べた段と、メンバー / 沿革 / メディア掲載の3列。既定は直近だけ（写真12件、リスト20件）で、各列見出しの「全部見る」で広がる。全件は左メニューの「資料 → 会社の記録」（`/company`）。
- 共有Driveの写真をここへ入れるときは `node pwa/scripts/import_drive_company_photos.mjs --dir <日付フォルダ> --title <表示名> --date YYYY-MM-DD --group <slug> --project <pid>`。

## 日常の使い方

### 自分の仕事を見る

1. `/mypage` を開く
2. 今週の活動ログを確認する
3. 月初合意カードが出ていたら、当月の遂行内容と報酬条件を確認する
4. 参加 PJ の cockpit へ移動する

`/mypage` は「自分のための OS 入口」。全社の管理画面ではなく、自分の参加 PJ と月次報酬・月初合意を確認する場所。

### 左ナビでページを選ぶ

コックピット・ワークスペース・DDパッケージの左ナビは、PCでは上下余白を詰めた一覧になっている。上のスペース3入口と、下の分類・ページの高さをそろえる。項目にマウスを乗せると行全体が青灰色へ変わる。いま開いている項目は青い左線と太字で示し、その行にマウスを乗せると背景が濃くなる。

### PJ を見る

1. `/dashboard` から PJ cockpit を開く
2. 上段で AMD Score / XRL / PJ メタを確認する
3. 左カラムで年間 MS と月次サマリを見る
4. 中央カラムで経営ハイライトと MTG サマリを見る
5. 下段の月次カードと MTG サマリを見る

細かい見方は [2-3 章 PJ コックピット](2-3-pj-cockpit.md)。

### 月次カードを見る

PM 向けの月次 step / TODO は出さない。月次の状況は PJ cockpit の月次カードから開き、進捗・報酬・月次報告書を同じモーダルで確認する。

報告書確認の軽い連絡は Slack 側で扱う。OS には PM 向けの月次 step / TODO / nudge を出さない。

### 通知に答える

`/notifications` は、OS が「これを正本に入れていい?」と聞いてくる場所。

| ボタン | 意味 |
|---|---|
| はい・反映 | 候補を正本に昇格する |
| いいえ・不採用 | 候補を rejected / invalid にする |
| コメント | つくよみに修正依頼として残す |

通知は事後報告ではなく、**正本反映前の確認ゲート**。迷ったらコメントだけ送る。

### アプリ版でタブを並べる

Chrome で「インストール」した AMD OS のアプリ窓は、Chrome と同じようにタブを並べて使える。

| やりたいこと | やり方 |
|---|---|
| 新しいタブを開く | 窓の上のタブ列の「＋」。ホーム（`/dashboard`）が開く |
| タブを閉じる | タブの「×」 |

Mac・Windows の Chrome では、この機能が標準で切ってある。最初に1回だけ次の設定を入れる。

1. Chrome のアドレス欄に `chrome://flags/#enable-desktop-pwas-tab-strip` と入れて開く
2. 黄色く光る「Desktop PWA tab strips」を `Enabled` にする
3. 右下の「Relaunch」で Chrome を再起動する
4. AMD OS のアプリを開き、一度閉じてからもう一度開く

設定を入れない端末では、これまでどおりタブ列のない1画面の窓で動く。

## これはやらない

- OS が勝手に経営判断を決めるわけではない
- 通知の候補は、人間が確認するまで正本ではない
- Slack / Gmail / 議事録の全文を OS に丸ごと見せる画面ではない。必要な snippet / evidence / hash だけを扱う
- admin 権限のないメンバーが、全社の請求・支払・台帳を自由に変更する場所ではない

### PJポートフォリオの表示（2026-10-06）

ダッシュボード上部のPJポートフォリオは、請求状況や経営指標より先に読み込む。初回は研究機関PJ・シーズPJ・事業会社PJの枠を表示し、必要なデータがそろったら候補を表示する。同じ画面へ短時間で戻ったときは取得済みの結果を再利用する。登録・評価の変更は短い保持期間を過ぎた次の読み込みで反映する。

2026-10-06: コックピット・ワークスペース・DDパッケージのページは、選んだ本文から読み込む。初回は本文の枠と「ページを読み込み中…」を表示し、読み込み後に従来と同じ本文を出す。ページの名称・操作・編集権限は変わらない。

2026-10-06: コックピット内のページ選択は画面全体の再読み込みを待たず切り替わる。表示ページはURLに残り、共有・再読み込みで復元する。

### 組織図を見る

コックピット・ワークスペースでは左の「会社情報」→「組織図」、DDパッケージでは資料一覧の「組織図」を開く。会議体・役員から部門、部署・チームへ縦につながる同じ形式で表示する。組織情報が未登録の間は「ひな形」と各欄の「未登録」を表示する。狭い画面では図を左右にスクロールして確認する。

組織図が登録されているPJでは、登録した会議体・部署・協業先と箇条書きの役割を表示する。「組織案」は設立・参画・契約の合意前の案で、正式な所属の確定ではない。協業先とは両矢印でつながる。登録が無いPJはこれまでどおり「ひな形」を表示する。表示内容の変更は確認済みの組織案を登録して反映する。

## この画面を見ている人を確認する

画面上部の右側に、同じ画面を開いている人の丸い頭文字と人数が出る。押すと名前を確認できる。PJ・コックピット／ワークスペース／DD・選択中のページごとに分かれ、別タブへ移ると表示から外れる。更新は約1分ごと。画面を開く・戻る・切り替える操作と退出はその時点で伝える。通信断の場合は3分で表示から外れる。

同じボタンの「閲覧履歴」で、その画面を誰がいつ開いたか、新しい順に50件まで確認できる。外部の参加者は自分の履歴だけ。履歴はこの機能の公開後から蓄積し、過去分は補わない。閲覧中はブラウザで表示しているタブを表し、読了や実作業時間は表さない。
