# 6-11 きよ お金の流れ

## 目的

きよが月次経理の作業（立替精算・請求書・メンバー支払）に入る前に、AMDに「どこからいくらお金が入り、何に使われたか」の全体像を会計知識なしで理解できるようにする。B/Sや試算表の再現ではない。1円単位の正確な帳簿はfreeeが正本で、この画面は構造を掴むためのざっくり全体図と位置づける（画面上にもこの旨を明記する）。

まさ確定（2026-08-27）: A案（流れ図）+ B案（3ステップの数字リスト）のハイブリッド。行クリックのドリルダウンあり。

## 画面

`/admin/kiyo` の先頭タブ **「00 お金の流れ」**。既定で開くタブは立替精算のまま。

1. **期間切替**: 直近6か月の月ボタン + 「今シーズン」「ぜんぶ」。既定は当月。**月単位で見られることが必須**（3か月まとめだと、役員報酬が載る月と期間がズレて実態が見えない）。
2. **流れ図**: 損益を見せる。左=売上の相手先、中央=売上合計、右=費用の4分類と「残ったお金」。縮尺（円→px）は全列共通で帯幅=ノード高さを厳密一致させる。実寸固定（幅720px）で拡大しない。
3. **口座のお金カード**: 入り・出・増減・残高と、参考として事業のもうけ。**両者がずれる理由を必ず本文で書く**。
4. **売上カード / 費用カード**: 相手先別・分類別の内訳。費用は行クリックで勘定科目まで展開。
5. **月ごとの推移表**: 期間が2か月以上のとき。売上・費用・もうけ・口座の増減を月別に並べ、役員報酬未計上の月に印を付ける。

## データの出どころ（freee会計だけ）

**OSの請求台帳（`billing_cycles`）は使わない。** 手入力で進める前提のテーブルなので、入力が止まると画面が実態とズレる（2026-08-28 まさ指摘）。すべて `company_actual_monthly`（= freee試算表と取引履歴の同期先）から取る。

| 画面の項目 | category | 出どころ |
|---|---|---|
| 売上（相手先別） | `revenue_partner` | freee収入取引を取引先別に集計（`/api/cron/freee-revenue-by-partner`）。税抜 |
| 受取利息・雑収入 | `revenue` | freee試算表。「どこから」には混ぜず合計にだけ足す |
| 役員報酬 | `fixed_cost` の `役員報酬` `法定福利費` | freee試算表 |
| メンバーへの報酬 | `cost_member` | freee試算表 |
| 会社の運営費 | `fixed_cost` の残り | freee試算表 |
| 税金 | `fixed_cost` の `租税公課` | freee試算表。法人税の納付そのものは費用でないので入らない |
| 口座の入り・出 | `cash_inflow` 系 / `cash_outflow` 系 | freee取引履歴 |
| 残高 | `cash_balance` | freee取引履歴 |

## 損益と現金を分ける（この画面の核）

同じ月でも「事業のもうけ」と「口座の増減」は一致しない。理由は3つで、これを画面に明記する。

1. **入金が遅れて来る**。8月にやった仕事の入金は10月ごろ
2. **口座から出るが費用でないものがある**。前年の法人税の納付、立替精算の返済、カードの引き落とし
3. **費用だがまだ口座から出ていないものがある**。翌月25日払いの役員報酬

**役員報酬の未計上を検知する**: その月に試算表の行はあるのに `役員報酬` が無ければ、給与の会計連携がまだ。警告に月を並べ「それまでこの月のもうけは実際より大きく出ます」と出す。

## 売上が立つ条件

freeeで請求書を発行するか、入金を売上として登録するまで、その月の売上は立たない。**請求書を出していない月は売上0のまま**で、もうけが実際より小さく出る。これは画面のバグではなく記帳の状態なので、数字を補完せずそのまま出す。

## API・性能

- `GET /api/admin/kiyo/money-flow?period=month|season|all&ym=YYYYMM`。admin専用。プロセス内キャッシュ TTL 5分、`?fresh=1` で強制再読込。
- freeeからの取り込みは `GET /api/cron/management-score-raw-data?includeFreee=1&ym=YYYYMM`（試算表・入出金・残高）と `GET /api/cron/freee-revenue-by-partner?ym=YYYYMM`（取引先別売上）の2本。どちらも `CRON_SECRET`。
