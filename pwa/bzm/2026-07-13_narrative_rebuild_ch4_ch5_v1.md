## 1. 現行診断 — なぜ的を外しているか

### 1.1 Ch4 (診断 △・×寄り)

現行 4.0 (野々村・宮原・水処理膜) の運動は「盛った1兆円が投資家に砕かれる → コンテストでは同じ数字が表彰される (皮肉) → 二度目の面談で**縮めて誠実になる**」。4.5 の到達点は「正直に刻んだ天井は、むしろ1兆円よりずっと小さいものだった」— **運動の向きが中心命題と逆**である。命題は「砕かれても高く掲げ直す」で、掲げ直し (U(t) の書き換え) の物語的回収は現行章頭に存在せず、演習4-2 (不整地ロボット) へ外注されている。理論側も 4.8 到達目標に価値の反転 (掲げ続ける強さ) が未宣言。さらに統一世界の確定により、野々村・宮原は退場・水処理膜は背景在庫へ降格が決まっており、**現行場面は人物・案件のレベルで統一世界と両立しない**。

### 1.2 Ch5 (診断 △)

現行 5.0 (藤野・青柳・ガス分離膜) のクライマックスは「同じ『できています』が、作れるか・売れるか・通るかの**三つの部屋**に分かれて聞こえた」— これは**軸の複数性** (五軸) であり、中心命題が「もう常識」と切り捨てた側を撃っている。命題の新しい核 — TRL が応用×担い手のマス目ごとに違う値を持ち、事業が通るマス目の min が本当の到達度 — は、章頭では「彼がやると歩留まりがいい」の一言と主任の走り書きに伏線として埋まるだけで、読者の章頭体験は「聞き手によって物差しが違う」に留まる。マス目と min を読者が**体験する場面**が存在しない。藤野・青柳の退場も確定済み。

### 1.3 連結章としての追加要件

STORY_WORLD §4-C・§7-D により、Ch4/Ch5 は断熱素材を P → R の順で連続して測る連結章になった。旧 Ch4/5 の病歴「部屋比喩の章間重複」は、同一案件の設計意図に置き換えて根治する。橋 3→4 は「『市場の大きさで言えば一件目でしょう』と言われた案件の、その市場が一円にもならない現場、そして掲げ直し」。橋 4→5 は「掲げ直した天井の『いま、どこまで来ているか』—『研究室でしか作れない』(Ch3 で技術担当が刺した点) がマス目の問題として開かれる」。

## 2. Ch4 白紙構想 — 新場面3案 + 現行降格

### 2.1 本命案 A「数字は、小さいほど信じてもらえますよ」— 下ろさなかった看板

**一行定義: 巨大市場のまん真ん中 (展示会場) に三日間立って一円にもならず、「数字を小さくしろ」という善意の助言まで浴びた発明者が、その日の帰りの電車で、前より大きい数字を — ただし今度は根拠の行を従えて — 書き始める話。**

**何を撃つか**
- 「一兆円が一円にもならない」を、会議室の面談ではなく**市場そのものの物理空間** (端から端まで十五分の展示会場) で起こす。市場の大きさが目に見える場所でこそ、「大きさは証拠ではない」が痛烈になる。
- 「縮めろ」という圧力は、悪意ではなく**善意と実務の顔**で来る (大手技術者の親切な助言「数字は、小さいほど信じてもらえますよ」)。読者も初読では、この助言を「もっともだ」と読む — 現行常識 (盛るな) の側に読者を立たせておいて、幕で裏切る (読者誘導、Ch1 v5 型)。
- 掲げ直しの中身は根性ではなく**作業**である — 幕で書かれる大きな数字の下に、会社名・実額・確かめることが一行ずつ生えていく。「盛りを本物にしていく工程表」の絵。
- 転回の契機は U(t) の拡張 — 建材の目 (安く・厚く・大量に) には無価値だった性能が、炉の目 (熱く・薄く・過酷に) には本丸の性能である。**同じ一枚の板が、見る目によって価値を変える**。

**あらすじ (単一場面・最終日の一日+帰路、台詞は創作ドラフト)**

十月、海沿いの大きな展示場。建材と住宅設備の見本市の最終日。八月の配分会議のあと、「市場が大きいの一言で推した自分が、その市場を資料の外で見たことがない」ことが引っかかった戸倉が、検証予算で小間を取った。いちばん奥のホールの二間の小間。パネルには素材の名前と、兆の字が入った市場規模。

発明者・磐井 (命名確定済み — §5) の実演は三日間一度も外れていない。火気が使えないので黒い加熱台で板を熱し (表示器は四百十二度)、素手を裏に当てる。人垣、歓声、名刺 — 二日間で百六十枚。そして商談はゼロ。「面白いですね」の先が無い。質問は判で押したように、実績は・規格は・坪いくら。

昼、大手建材メーカーの技術部門の人が来る。実演を最後まで黙って見て、厚みの公差・切断・吸湿・施工・防火認定・供給量・価格をひとつずつ確かめ、半分も答えられない磐井に、心底感心した顔で言う——「素晴らしい技術です。うちでは、使えませんが」。去り際、パネルを見上げて「兆のつく数字は、下ろした方がいい。数字は、小さいほど信じてもらえますから」。

午後、磐井がはじめて実演を休む。角地の大手小間からは商談席の笑い声。戸倉は名刺の束をそろえながら八月の会議を思い出す——市場の大きさで言えば一件目でしょう、と言われた案件の市場のまん真ん中で、三日間、一円も動かなかった。「数字を少し小さくしませんか」— 喉もとまで出かかった言葉を、なぜだか飲み込む (理由は自分でも分からない — 言語化しない)。

閉場一時間前、人波の薄い通路をまっすぐ来る一人。名札は建材ではなく**工業炉の会社**。第一声が「これ、続けて使える上限は、何度ですか」。厚みは薄くできるか、熱で反るか、急加熱と急冷を繰り返すと何回で割れるか——質問の向きが逆で、そして磐井が三年間研究室で測り続けてきたのは、こちら側の問いだった。答えのひとつひとつに実験の数字が付いてくる。「うちは炉の内側の断熱材を年に何度も張り替える。止めている間も剥がした古い方も、ぜんぶ金です」——「一度、うちの試験設備を見に来ませんか」。

幕: 帰りの電車。膝に板のケース。磐井が手帳に数字を書く——桁の多い数字。戸倉はパネルの兆の字を思い出してひやりとする。だがペンは止まらず、数字の下に小さな字が一行ずつ増えていく。今日の会社名。張り替えの頻度。炉の台数を調べること。来月持っていく試験片の寸法。三年前この素材に会った日、帰りの電車で企画書を一気に書いたのは戸倉だった。今日は隣で、磐井が書いている。ペンの音。

**設計整合 (要点)**
- **装置 (一章一装置)**: 一枚の板 — 同じ一枚が、見る目によって見世物にも、無価値にも、本丸にもなる。旧装置「同じ数字の旅 (場所で価値が変わる)」の後継を、数字ではなく物に宿す。
- **幕引きの音**: 書く手 (掲げ直しの運動で閉じる)。Ch15 の幕「稟議書の上のペンが止まる」との**意図した対** (走るペンと止まるペン)。
- **主調音**: 歓声とゼロの皮肉。幕に掲げ直しの熱。旧「唯一笑える章」の笑いは、見世物の可笑しみ (「熱くないんですか」「熱くないんです」・名刺だけが厚くなる) として維持しつつ、皮肉の笑いから頼もしさの熱へ転調する。
- **橋 3→4**: Ch3 の幕 (基準ばらばらの表・比べる地図の宿題) を受け、「会議室で言い合っても仕方ない、市場の実体を売り場で確かめる」が出展の動機 — 幕の人 (戸倉) がそのまま動き出す入口。
- **主体の通奏 (Ch1→CEO章の長弓)**: 三年前は支援者 (戸倉) が企画書を書いた。今日は本人 (磐井) が天井を書き直している — 主体が書く側へ移る絵を、幕に沈黙配置。
- **読者誘導**: 初読では「盛るからだ」「小さくしろは正論」と読ませ、幕の「もっと大きい数字」で「え、また?」を起こし、討議課題で「小さくしろ、に頷いた自分」ごと裏返す。答え (掲げたまま証拠で本物にする) は理論 4.4/4.7 が与える。
- **問いを認識する人物を置かない**: 戸倉の違和感は「言いかけて飲み込む」「ひやりとする」の絵まで。磐井は理論を知らず、本能で U(t) の書き換えをやる。

### 2.2 対案 B「三十件の断り状」

十月、市場検証の中間報告の夜。想定顧客への打診三十件・全滅のリストを、戸倉と磐井が読み直す。断りの理由は価格・規格・実績とばらばらで、その列の中に一件だけ毛色の違う断り——「うちの用途には過剰性能」——が混ざっている。過剰は、別の市場では適正である。リストの読み直しから天井の書き換えが始まる。
- 強み: 「断りの理由の列」が証拠の質の教材そのもの。弱み: 書類を読む静的な場面で、市場の物理が立たない。Ch8 (書類と保留の半年) と質感が近接。幕を「掲げ直す運動」で閉じる絵が作りにくい。**非推奨**。

### 2.3 対案 C「値札のない板」

初の顧客面談の前夜と当日。市場は兆で語れるのに、明日の一社に言う「一枚いくら」が決められない——天井と足元の絶望的な距離。当日砕かれ、帰路に掲げ直しの種を拾う。
- 強み: 「一兆円が一円にもならない」の最短の物語化。弱み: 面談室の器が Ch2 (面談)・Ch5 と連続し、会議室一色の病 (俯瞰診断①) に逆戻り。二場面型で時間構造も割れる。**非推奨**。

### 2.4 現行 (降格候補 D): 野々村・宮原の投資家面談+コンテスト

理論改修コストはゼロ。ただし①運動の向きが命題と逆 (§1.1)、②野々村・宮原の退場・水処理膜の在庫降格が確定済みで、**統一世界と人物・案件レベルで両立しない**。ゼロから考え直しても採用に戻る道がない。**不採用を推奨**。

## 3. Ch5 白紙構想 — 新場面3案 + 現行降格

### 3.1 本命案 a「うちで、できるかどうか」— 二枚の板

**一行定義: 「研究室では何百枚も焼けている」板が、同じ原料・同じ手順書・同じ型の炉を揃えた相手先の試験棟で、一枚も同じにならない一日 — 「できています」が嘘ではないまま、場所と手が変わると別の値になることを、視点人物が目撃する話。**

**何を撃つか**
- 「研究室で作れる≠自社で作れる」を、比喩でも評価メモでもなく、**実際に作ってみて失敗する一日**として体験させる。同じ技術の到達度が、担い手のマス目ごとに別の値を持つことが、白く濁った板という物理で現れる。
- **min が本当の到達度**であることを、相手企業の判断の言葉として立てる——「研究室でできていることは、もう疑っていません。うちが知りたいのは、うちで、できるかどうか。それだけなんです。稟議は、そこにしか付きませんので」。事業が通るかどうかは、いちばん進んだマス目ではなく、**事業が依存するマス目**の値で決まる。
- 暗黙知の物語化——手順書を書いた本人 (学生) の体にしか宿っていない判断基準 (昇温の音) が、移転の現場で初めて「発見」される。属人性 (HRL) と自社セルの空白が同じ結び目であることの種。
- 「できなかった一日」が No の一覧 (=次にやることの一覧) を生む——観測項目の思想 (5.3) を、先方の若手の「何がわかってないかは、今日、ぜんぶわかりましたね」に落とす。

**あらすじ (単一場面・試験の一日+帰路、台詞は創作ドラフト)**

十一月の晴れた寒い朝、工業炉の会社の試験棟。先月の展示会のあと話は早く、先方の電話の最後の一言が「うちの設備で、同じものができるかどうか。まず、それを見せてもらえますか」だった。配分を決める戸倉のチームから日々の窓口が瀬戸へ引き継がれ、今日が三度目の同行。同じ型の電気炉が先方にある——それがこの日のそもそもの始まりで、瀬戸は「確認だけの気楽な一日」だと思っている。

研究室からは原料の箱と道具と、飴色に透きとおった見本の板が一枚。磐井と、研究室の大学院生がひとり——研究室でこの板を焼くのはもっぱらこの学生で、手順書もこの学生が書いた。

昼前、一枚目が炉から出る。**白く濁っている**。見本と並べると誰の目にも別物。「温度プログラムは同じですよね」「同じです。手順書のとおりです」——「同じ」が繰り返される午後になる。原料は同じロット、炉は同じ型番、温度も時間も手順書のとおり。二枚目も白濁、三枚目はひびが走る。先方の技術部四人は嫌な顔ひとつせず、一枚ごとに質問が細かく熱っぽくなる。原料の含水は——計ってません、研究室では計ったことがなくて。部屋の湿度は——研究室は地下で一年じゅう変わらないんです。

四枚目の支度のとき、学生が小さな声を出す。「うちの炉、昇温の途中で音が変わるんです。ジー、が、コー、に。いつも、その音を聞いてから次に進めてて」——音、と誰かが言い、手帳を出す音がする。この試験棟の炉は、防音の函に入っている。

夕方までに六枚。最後の一枚は端のほうだけ見本と同じ飴色に透ける。全部が駄目なのではない。決定的な一つが欠けているのでもない。**書かれていない小さな条件が数えきれないほどあって、そのすべての上で、研究室の板は焼けていた**。

片付けの前、製造の責任者が磐井に向き直る——「先生。研究室でできていることは、私たちはもう、疑っていません。うちが知りたいのは、うちで、できるかどうか。それだけなんです。稟議は、そこにしか付きませんので」。責める調子はどこにもない。先方の若手がホワイトボードに今日の「わからなかったこと」を書き出し、なぜだか少し嬉しそうに言う。「何がわかってないかは、今日、ぜんぶわかりましたね」。

帰り支度のあいだに日が落ちる。搬入口の外で先方が学生をつかまえて立ち話——来年も来てもらえるんですか。**春に、修了なので**。そうですか、と誰かが言って、それきり誰もその話を続けない。

幕: 学生が白濁の六枚を一枚ずつ緩衝材にくるみ、箱に収める。捨てていくのかと思って見ていた瀬戸に、蓋を閉めながら言う——「持って帰ります。うちの窯で焼いたのと、並べて比べるので」。車の荷台に来たときと同じ数の箱。増えたのは白い板が六枚。暮れていく試験棟の窓の中で、先方の若手がまだホワイトボードに何かを書き足している。

**設計整合 (要点)**
- **装置 (一章一装置)**: 二枚の板 — 研究室の飴色の一枚と、試験棟の白い一枚。同じ技術の到達度が、マス目 (場所と手) で別の値を持つことの物象化。
- **Ch4 との対 (連結章の設計)**: Ch4 の板は「見る目で価値が変わる」(P — 何を約束するか)、Ch5 の板は「作る手で出来が変わる」(R — どこまで来たか)。**同じ素材の二枚の板が、二章の理論レンズの対になる**。通奏低音② (手の中の小さな物) の鎖は「…冷めた茶 (Ch3) → 実演の板 (Ch4) → 白い板 (Ch5) → 評価シート (Ch6) …」と更新。
- **幕引きの音**: 物と台詞で切る (箱に収められる白い板・「比べるので」)。未決だが、失敗が「データ」に変わる前向きの手つき — Ch2 の幕 (閉じられるメモ帳・答えの氾濫の未決) とは質を分ける。
- **主調音**: 白い息と白い板 — 遠さの発見と、静かな収穫。
- **橋 4→5**: Ch4 の幕で手帳に書かれた「来月持っていく試験片の寸法」が、この日の荷になっている。掲げ直した天井 (書く) の翌月に、そこまでの距離 (作る) が物理で試される — P→R の理論の順序が物語の因果として繋がる。
- **視点交代の意味**: 戸倉 = 配分を決める人 (Ch3/4) → 瀬戸 = 日々伴走する人 (Ch5)。機関の二層 (決める/伴走する) が案件の続報の中で見える。瀬戸の Ch9 への人物アーク — 「できています」という状態の言葉が場所で別の値を持つのを見た人が、二年後、「進行中」という自分の報告の言葉に苦しむ (Ch9)。
- **読者誘導**: 初読では読者も「同じ型の炉なら、できるだろう」と朝を迎える (見本の板は本物なのだから)。一枚目の白濁で読者も「え?」——誰も嘘をついていないのに、できない。討議課題で「できていた/できなかったの境界線」を自分で引かせ、理論 (5.4 のマトリクスと min) が言葉を与える。
- **問いを認識する人物を置かない**: 瀬戸の違和感は「捨てていくのかと思って見ていた」の絵まで。言語化は理論 5.1 以降の仕事。

### 3.2 対案 b「十枚の算数」

相手企業から「評価用に A4 サイズで十枚」と言われる打合せ。研究室の月産 (手のひら数枚・実験の合間・焼けるのは一人) で数えると、十枚に一年半かかると判明する——「できています」と「十枚出せます」の間の距離が、算数だけで露呈する。
- 強み: 最小の場面で「研究室で作れる≠事業で作れる」が立つ。弱み: 会議室の算数で終わり、マス目の物理 (場所と手が変わると動かない) が体験されない。min の一撃 (稟議の言葉) を置く相手側の切実さも立ちにくい。**非推奨**。

### 3.3 対案 c「三つの引き合い」

展示会のあと、三つの業種から引き合いが来て、求められる「できている」がそれぞれ別のもの (寸法・形状・耐性・量) を指す——応用軸のマス目の複数性が主役。
- 強み: マトリクスの応用軸 (行) を先に見せられる。弱み: 場面が散り、「三つ」という数が理論由来 (五軸・三因子) でないのに装置化してしまう (統一方針・数の装置は理論由来のみ、に抵触)。組織軸 (研究室≠相手) の核が薄まる。**非推奨**。

## 5.0 うちで、できるかどうか——ある試験棟の一日

## 10. 推奨

- **Ch4 = 本命案 A「数字は、小さいほど信じてもらえますよ」(展示会・下ろさなかった看板) を推奨。** 市場の大きさが物理空間として現前する唯一の器で、「一円にもならない」と「掲げ直す」を同じ場所で起こせる。中心命題の対立構造 (縮めて信じてもらう vs 掲げたまま証拠で本物にする) が、善意の助言という形で場面に内蔵される。
- **Ch5 = 本命案 a「うちで、できるかどうか」(移転実験・二枚の板) を推奨。** 「研究室で作れる≠自社で作れる」を読者が追体験する唯一の器 (実際に作って、失敗する)。min の一撃が相手企業の稟議の言葉として立ち、理論 5.4 のマトリクスが章頭の実測データそのものになる。
- **命名 = 磐井で確定済み** (§5 — 並行の命名セッションが第四弾で確定、台帳記帳済み。本セッションでの命名タスクは消滅)。
- 承認後の手順: ①本文稿を `book-a-ch-4.md` / `book-a-ch-5.md` の x.0 節へ反映 ②§8 改修パッケージを司令塔ゲートへ ③設計表・STORY_WORLD の該当行更新。
