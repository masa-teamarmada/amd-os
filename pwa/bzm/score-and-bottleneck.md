# 計算式と律速診断 — 9つの軸をひとつの判断へ

---

その支援チームが四半期の計画会議を開いたのは、桜が散ったあとの月曜日だった。議題は、伴走して一年になる吸着材のプロジェクト——工場排水から特定の金属イオンを選択的に回収する多孔質材料で、研究室レベルの性能実証は済み、特許は一件出願済み、企業からの引き合いも二件来ていた。会社はまだない。研究者は学内の業務に追われながら、それでもこのテーマに本気だった。

ホワイトボードには、前の週から各メンバーが持ち寄った「やるべきこと」が並んでいた。量産スケールでの性能検証。引き合いのあった二社への深いヒアリング。周辺特許の追加出願。排水処理に関わる規制と認証の調査。事業側を担う人材の探索。次の公募が迫る助成金の申請書。研究室の学生に頼り切りの実験体制の補強。広報記事の準備。そして、まだ誰も真面目に考えたことのない価格設定。

「どれも大事ですね」と誰かが言い、誰も反対しなかった。実際、どれも大事だったのだ。技術担当は量産検証を落とせないと言い、知財に明るいメンバーは出願の時間切れを警告し、資金担当は助成金の締切は待ってくれないと念を押した。議論は丁寧で、抜け漏れのチェックは行き届いていた。会議の終わりに、九つの項目すべてに担当者と期限が割り振られた計画書が完成した。全員が、穴のない良い計画ができたと感じて散会した。

三か月後のレビュー会議で、その計画書は別の顔をしていた。

九つの項目には、九つの「進行中」が並んでいた。量産検証は装置の手配が遅れ、見積もりを取り直している段階。顧客ヒアリングは二社のうち一社と一度だけ面談し、議事録が共有フォルダに眠っていた。追加出願は明細書の草稿が三割。規制調査は資料を集めたところ。助成金の申請書は書きかけ。採用は求人票の文面を作った段階。広報記事は取材日程の調整中。価格設定は、手つかず。どの項目も止まってはいない。しかし、どの項目も、何かが決まる水準——閾値を越えていなかった。

そして、目に見えない損失が進行していた。研究者の時間が九つの項目に細切れに吸われ、肝心の実験が遅れ始めていた。引き合いのあった二社のうち一社は、二か月前のメールを最後に返信が途絶えていた。

その日のレビューには、チームが顧問として迎えていた年配の支援者が同席していた。彼は配られた進捗表を黙って眺めたあと、顔を上げて静かに尋ねた。

「次の四半期、もし一つのことしかできないとしたら、どれをやりますか」

沈黙が落ちた。技術担当が「量産検証、ですかね……」と言いかけ、語尾が消えた。資金担当が「でも、助成金を逃すと検証の予算自体が」と続け、これも途中で止まった。リーダーが正直に答えた。「全部つながっているので、一つには絞れません」

顧問は頷いてから、言った。「絞れない、のではないでしょう。絞るための物差しを持っていない、ということです。物差しがないから、計画が九項目になる。九項目の計画は、優先順位を決める痛みを九回先送りしているだけです。——そしてその痛みは、消えたわけではない。研究者の時間と、返信が来なくなった一社が、代わりに払っています」

リーダーは反論できなかった。チームには地図があったはずだった。天井、到達、生存という三つの因子。それを構成する九つの軸。どの軸が弱いかも、おおよそ見えていた。足りなかったのは、九つの「大事」を一列に並べ、先頭の一つを指させる物差しだった。

この章では、その物差しを組み立てます。前の章まで一つずつ見てきた九つの軸を、一つの数に統合する計算式を作り、その式から「次の一手」を機械的に取り出す方法——律速診断——を導きます。章の後半では、冒頭のプロジェクトを実際に手で計算し、九項目の計画がどう一つに絞られるかを確かめます。

## 計算は9本の軸で行う — P・R・S は概念のラベル

まず、計算の全体像を確認します。前の章まで、本書のモデルは「天井 $P$ × 到達 $R$ × 生存 $S$」の三因子で価値を読む、と説明してきました。ここで大事な整理があります。**$P$・$R$・$S$ は計算上の別グループではなく、概念のラベルです。** 実際の計算は、三つの因子を別々に計算して掛けるのではなく、その中身である 9 本の軸を、同格に並べた一つの積で行います。

9 本の軸とは、次のものです。各軸は、それぞれの章で見たとおり、観測項目のチェックリスト (採点基準) によって 0〜9 の段階で評価されます。

| 概念ラベル | 軸 | 何を測るか |
|---|---|---|
| $P$ (天井) | $P$ | 潜在規模。最大限うまくいったときの経済的インパクトの天井を、証拠の質で刻む |
| $R$ (到達) | $TRL$ | 技術成熟度 |
| | $BRL$ | 事業モデル成熟度 |
| | $GRL$ | 規制・標準化への適合 |
| | $SRL$ | 社会受容性 |
| | $HRL$ | チーム成熟度 |
| $S$ (生存) | $\sigma_{SU}$ | マクロの追い風。その分野に流れ込む資金と関心 |
| | $R_{\text{net}}$ | 収益化指数。事業が生む純キャッシュ貢献 |
| | $F$ | 創業者要因。資質と経営実行力の合成 |

統合の式は、次の一行です。

$$\text{統合スコア} = K \cdot \prod_{i=1}^{9} (X_i + 1)^{\alpha_i}$$

記号を順に読み下します。$X_i$ は 9 本の軸それぞれの値 (0〜9)。$\prod$ は「すべて掛け合わせる」という記号で、足し合わせる $\sum$ の掛け算版です。各軸は $+1$ してから、軸ごとに決められた重み $\alpha_i$ で べき乗 (その数だけ累乗) され、9 個の因子がすべて掛け合わされて、最後に物差し合わせの定数 $K$ が掛かります。

つまりこの式には、設計上の選択が三つ埋め込まれています。**なぜ足し算ではなく掛け算なのか。なぜ $+1$ するのか。重み $\alpha$ と定数 $K$ はどう決めるのか。** 以下、一つずつ開いていきます。

## なぜ掛け算か — Cobb-Douglas という選択

複数の因子を一つの数に統合する方法は、無数にあるように見えて、性質で分類すると実は数種類しかありません。候補は大きく三つです。

| 統合方式 | 性質 | 一軸がゼロのとき | 律速の表現 |
|---|---|---|---|
| 加重和 (重み付き足し算) | 完全代替 — 弱い軸を他の軸の高さで埋め合わせられる | 他が高ければ高得点が出る | できない |
| min (最小値) | 完全補完 — 最も弱い軸がすべてを決める | 全体がゼロ | 強すぎる |
| Cobb-Douglas (重み付き掛け算) | 中間 — 弱い軸は全体を大きく沈めるが、消しはしない | 沈むが消えない ($+1$ シフト併用時) | できる。しかも重み付きで |

違いを体感するために、極端な案件を一つ考えます。**技術だけがまだ存在しない案件**——$TRL = 0$ で、残り 8 軸はすべて 9、という状態です。

第一の候補、**加重和**で採点するとどうなるか。仮に等しい重みなら、9 軸中 8 軸が満点なので、100 点満点換算でおよそ 89 点。ほぼ満点です。技術がまだ存在しないのに、です。これが加重和の構造的な欠陥で、足し算の世界では、**一つの軸の致命的な欠落を、他の軸の高得点が覆い隠せてしまう**。前の章で見た「準備度だけの評価表が、自社で作れない素材のプロジェクトを高く評価してしまった」失敗は、まさにこの構造から生まれます。事業化は鎖のようなもので、技術・顧客・制度・人のどれか一つが切れていれば全体が機能しません。最も弱い輪が全体を縛る——この**律速**の感覚を、足し算は原理的に表現できないのです。

では第二の候補、**min** (9 軸の最小値を全体の値とする方式) ならどうか。先ほどの案件は 0 点になります。律速の感覚には忠実ですが、今度は忠実すぎます。8 軸分の蓄積が、評価上は存在しないことになる。本書のモデルは、会社になる前——それこそ $TRL = 0$ の、研究室にシーズの気配があるだけの段階——から評価を始めるためのものでした。min を採ると、その段階のプロジェクトはすべて一律にゼロと評価され、シーズどうしの区別がつきません。**初期のシーズを捉えるという目的そのものと矛盾する**のです。

第三の候補が、この中間に立つ **Cobb-Douglas (コブ・ダグラス) 型**、すなわち重み付きの掛け算です。1928 年に経済学者コブと数学者ダグラスが、労働と資本の投入量から生産量を説明する関数として提案して以来、百年にわたって経済学の生産関数の標準であり続けてきた形です。掛け算なので、弱い軸は全体を大きく沈めます (律速が効く)。しかし後述の $+1$ シフトと組み合わせれば、ゼロの軸があっても全体は消えません (初期シーズを捉えられる)。そしてもう一つ、加重和にも min にもない利点として、**軸ごとの重要度の違いを、指数の重みで直接表現できます**。

この重み $\alpha_i$ は、経済学で**弾力性**と呼ばれる量です。意味は単純で、「その軸の値 (正確にはシフト後の値) が 1% 増えたとき、スコア全体が約何 % 増えるか」。$\alpha = 1.5$ の軸の 1% 改善は、$\alpha = 0.3$ の軸の 1% 改善の 5 倍、スコアを動かします。軸はどれも大事だが、同じだけ大事なわけではない——この当たり前を、式の中に明示する仕組みが弾力性です。

> 図版 TODO (統合方式の比較曲線): 横軸にある一つの軸の値 (0→9)、縦軸に統合スコア (相対値)。他の 8 軸を中位に固定したまま、その軸だけを動かしたときのスコアの変化を、加重和 (直線的にしか落ちない)・min (途中までは平坦で、最小値になった瞬間に支配される)・Cobb-Douglas (低い領域で急峻に沈み、ゼロでも消えない) の 3 本で重ね描きする。「足し算は鈍く、min は極端で、積はその間」が一目で分かる図。

なお、Cobb-Douglas は万能ではありません。これは「弱い軸を他の軸で**ある程度**補える」という代替性を仮定した形であり、「両方が揃わなければ成立しない」という強い補完性は表現できません。$S$ の章で見たとおり、創業者要因 $F$ の内部 (資質と経営実行力) はまさにその強い補完性を持つため、そこだけは CES という別の関数で合成してから、この積に載せています。**軸のあいだは代替的に、軸の内部で補完が必要な場所は CES で**——という二段構えです。

## +1 シフトの2つの役割

式の中の $(X_i + 1)$ という小さな細工には、二つの役割があります。

**第一の役割は、ゼロの軸があってもスコアが消えないようにすることです。** 掛け算の宿命として、どれか一つでも因子がゼロなら全体がゼロになります。$TRL = 0$ をそのまま掛ければ、他の 8 軸が何点であろうとスコアは 0。これでは min と同じ欠陥を抱え込みます。そこで、すべての軸を $X_i + 1$、つまり 1〜10 の範囲にずらしてから掛け合わせます。値がゼロの軸は因子 $1^{\alpha} = 1$ となり、掛け算の中で「何も寄与しないが、消しもしない」中立な存在になります。研究室にシーズの気配があるだけの段階——多くの軸がゼロの段階——から評価を始められるのは、このシフトのおかげです。

**第二の役割は、対数スケールでの読みやすさです。** シフト後の各軸は 1〜10、つまり最小から最大までちょうど一桁に収まります。すると、軸が一つゼロであることの意味を、桁数で簡潔に言えるようになります。重み $\alpha$ の軸がゼロなら、その因子は本来の $10^{\alpha}$ ではなく 1 なので、**スコアは $\alpha$ 桁沈む**。たとえば $\alpha = 1.0$ の $TRL$ がゼロなら、スコアは一桁 (10 分の 1に) 沈みます。先ほどの「$TRL$ だけゼロ」の案件は、全軸満点なら 100,000 のところ、10,000 になる——一桁沈むが、消えはしない。加重和の 89 点とも、min の 0 点とも違う、ちょうどよい痛みです。ちなみに「1 を足してから対数的に扱う」という形は、金融実務で企業価値の対数を扱うときの標準的な変換とも同型で、奇抜な発明ではありません。

## 重み α — 専門家判断の事前値と、過去ケースでの校正

では、肝心の重み $\alpha_i$ はどう決めるのでしょうか。本書のモデルが現在置いている値は、次のとおりです。

| 軸 | $\alpha_i$ | 置いた理由の要点 |
|---|---|---|
| $F$ (創業者要因) | **1.5** | 創業チームの質が投資判断の最大の要因であるという実証研究。他の軸を引き上げる間接効果も持つ |
| $\sigma_{SU}$ (マクロの追い風) | **1.3** | 追い風に乗っていない案件の生存は構造的に苦しい |
| $HRL$ (人材) | **1.1** | 公的な readiness 体系でも、チームは技術・事業より重く扱われる |
| $TRL$ (技術) | **1.0** | 中核。ただし外部連携や人材獲得で補完できる余地もある |
| $P$ (潜在規模) | **1.0** | 天井は価値の上限を決める。ただし最も「盛られやすい」軸であることを考慮して中位 |
| $R_{\text{net}}$ (収益化指数) | **0.8** | 自走できる体質は生存に直結する |
| $BRL$ (事業) | **0.6** | 検証の方法論が確立しており、後からの改善が比較的効きやすい |
| $GRL$ (制度) | **0.3** | 重要だが、効き方が遅い |
| $SRL$ (社会受容) | **0.2** | $\sigma_{SU}$ と一部連動するため、重複分を抑えて小さく置く |

合計は $\sum \alpha_i = 7.8$ です。

この表でまず目を引くのは、$F$ と $\sigma_{SU}$ の重みが突出していることでしょう (二つで 2.8、全体の 3 分の 1 以上)。これは偶然ではなく、一つの思想の表現です。**「マクロの追い風に乗っているか、創業者が抜きん出ているか——どちらかが必要だ」**。長い時間と大きな検証を要するディープテックでは、平凡な環境で平凡なチームが完走することは、構造的にほとんど期待できません。分野に資金と関心が流れ込んでいるか、さもなければ、逆風でも資金と人を引き寄せられる傑出した創業者がいるか。少なくとも片方が立っていることを、モデルは重みの形で要求しています。$F$ の重みには実証的な裏付けもあります。投資家の意思決定を実験的に分析した研究では、事業アイデアや市場よりも創業チームの質が判断を最も大きく左右することが示されており、この知見が $\alpha_F$ を最大に置く根拠になっています。

> 出典注 TODO: 創業チームの質が投資判断の最大要因であることを示した実験研究 (Bernstein, Korteweg & Laws 2017, Journal of Finance) と、内閣府 SIP の readiness 体系における HRL の位置づけを、巻末参考文献で確定する。

逆に、$GRL$ や $SRL$ の重みが小さいのは「規制や社会受容がどうでもよい」という意味ではありません。$GRL$ は効き方が遅く、$SRL$ は追い風 $\sigma_{SU}$ と動きが重なる部分が大きいため、**スコアを動かす力としての**割り当てが小さい、ということです。重みが小さい軸でも律速にはなりうる——これは後の練習問題で実際に確かめます。

もう一つ、この表について正直に言っておくべきことがあります。**これらの値は、観測データから統計的に推定された値ではまだありません。** 専門家判断と先行研究を総合して置いた「事前値」です。統計学の言葉を借りれば、事前分布にあたるものを専門家の判断で与え、過去の実プロジェクトへの当てはめ (この作業は検証の章で扱います) で結果と突き合わせ、ずれていれば修正していく——という運用です。重みは固定された真理ではなく、**明示された仮説**です。

そして、ここに評価モデルの効用の核心があります。冒頭の会議を思い出してください。前の章で見たとおり、会議が空転するのは、各メンバーが**暗黙の重み付け**で殴り合うからです。技術担当の頭の中では $TRL$ の重みが大きく、資金担当の頭の中では $\sigma_{SU}$ が大きい。誰の重みも表に出ないまま、結論だけがぶつかる。重みを紙に書いて晒すことの価値は、値が正しいことではなく、**議論の対象になること**です。「$\alpha_{TRL}$ は 1.0 では小さすぎる」という反論は、暗黙の直感の殴り合いより、はるかに生産的です。

## K の校正 — 全軸最高で 100,000 という物差し合わせ

最後の定数 $K$ は、スコアの目盛りを合わせるためだけの数です。決め方は一つの約束で尽きています。**全軸が最高値 (すべて 9、シフト後 10) のとき、スコアがちょうど 100,000 になる**ように $K$ を取る、という約束です。

$$K \cdot 10^{\sum \alpha_i} = 100{,}000 \quad \Rightarrow \quad K = \frac{100{,}000}{10^{7.8}} \approx 0.00158$$

100,000 という数自体に深い意味はありません。全軸最高の案件——あらゆる軸が証拠で満たされ、株式公開に届く水準まで来た案件——を上限の目盛りに固定した、物差し合わせです。重みの合計 $\sum \alpha_i$ を変えれば、$K$ もそれに合わせて再校正します (練習問題で扱います)。

この物差しの上で、スコアは**対数スケールの順位指標**として読みます。注意点は二つです。第一に、意味を持つのは大小関係と**桁**であって、差や比そのものではありません。スコア 45 の案件と 450 の案件の違いは「10 倍の価値」ではなく、「一桁違う段階にいる」と読みます。シフト後の各軸が一桁に収まる設計なので、スコアの桁の違いは、おおよそ「重み付きで数えた軸の成熟が、どれだけ積み上がったか」の違いに対応します。第二に、スコアの絶対値は金額ではありません。ただし対数の目盛りとしては企業価値の対数と同じ単位で読めるように設計されており、スコアと市場の値付けの食い違い——スコアが高いのに安く扱われている案件、低いのに高く値付けされた案件——を探す物差しとしても使えます。

## 例題 — 手を動かして一度計算する

> 式の意味は、自分の手で一度動かすと一気に腑に落ちます。冒頭の吸着材プロジェクトを、9 軸で評価して計算してみましょう。電卓 (べき乗キーのあるもの、または表計算ソフト) があれば追えます。

支援チームが研究者と議論して置いた評価は、次のとおりだったとします。

$$P=6,\quad TRL=2,\quad BRL=1,\quad GRL=4,\quad SRL=4,\quad HRL=2,\quad \sigma_{SU}=7,\quad R_{\text{net}}=0,\quad F=3$$

読み下すと——天井は中規模より上 (産業横展開の証拠が出始めた段階)、技術はラボ実証どまり、事業モデルは仮説の段階、規制と社会受容は中程度、チームは研究者と学生のみ、分野への追い風は強い、売上に類するものはゼロ、創業者要因は研究者の資質は高いが経営実行力が薄い——という案件です。

**手順 1: 全軸を +1 シフトします。**

$$\widetilde{P}=7,\ \widetilde{TRL}=3,\ \widetilde{BRL}=2,\ \widetilde{GRL}=5,\ \widetilde{SRL}=5,\ \widetilde{HRL}=3,\ \widetilde{\sigma}_{SU}=8,\ \widetilde{R}_{\text{net}}=1,\ \widetilde{F}=4$$

**手順 2: 各軸をそれぞれの重み $\alpha$ でべき乗します。**

| 軸 | $\widetilde{X}$ | $\alpha$ | $\widetilde{X}^{\alpha}$ |
|---|---|---|---|
| $P$ | 7 | 1.0 | $7.00$ |
| $TRL$ | 3 | 1.0 | $3.00$ |
| $BRL$ | 2 | 0.6 | $2^{0.6} \approx 1.52$ |
| $GRL$ | 5 | 0.3 | $5^{0.3} \approx 1.62$ |
| $SRL$ | 5 | 0.2 | $5^{0.2} \approx 1.38$ |
| $HRL$ | 3 | 1.1 | $3^{1.1} \approx 3.35$ |
| $\sigma_{SU}$ | 8 | 1.3 | $8^{1.3} \approx 14.93$ |
| $R_{\text{net}}$ | 1 | 0.8 | $1^{0.8} = 1.00$ |
| $F$ | 4 | 1.5 | $4^{1.5} = 8.00$ |

**手順 3: 9 個の因子をすべて掛け合わせ、$K \approx 0.00158$ を掛けます。**

$$
\begin{aligned}
\text{統合スコア} &= 0.00158 \times 7.00 \times 3.00 \times 1.52 \times 1.62 \times 1.38 \times 3.35 \times 14.93 \times 1.00 \times 8.00 \\
&\approx 0.00158 \times 28{,}500 \approx \boxed{45}
\end{aligned}
$$

スコアは約 45。対数の物差しの上では、シーズが顕在化して支援の本格検討に乗る段階——会社にするにはまだ数桁の積み上げが要る位置です。

> **読みどころ**: 因子の表を眺めると、スコアを支えているのは $\sigma_{SU}$ (約 14.9) と $F$ (8.0) の二つで、ここに「追い風か、創業者か」という重み設計がそのまま現れています。一方、$R_{\text{net}}$ の因子は $1^{0.8} = 1$。**掛け算の中で「1 を掛ける」とは、何も寄与していないということです。** ゼロの軸は、スコアを消しはしないが、完全に沈黙する——この沈黙が、次の律速診断で浮かび上がります。

## 実用の核心 — 律速診断

統合スコアの絶対値は、案件どうしを比べ、投資や支援の優先順位を決める場面で使います。しかしこの式の実用上の核心は、実はスコアそのものではありません。**式を微分すると、「次の一手」が機械的に出てくる**ことです。

問いはこうです。9 本の軸のうち、どれか一つを 1 段階上げられるとしたら、どの軸を上げるとスコアが最も伸びるか。これは数学の言葉では、スコアを各軸で**偏微分**して比べることに当たります。偏微分とは、他の軸をすべて止めたまま、その軸だけをわずかに動かしたときの変化率のことです。Cobb-Douglas 型の式は、この計算が驚くほど綺麗に解けます。スコア $\text{Score} = K \prod_i (X_i+1)^{\alpha_i}$ を軸 $X_i$ で偏微分すると、

$$\frac{\partial\, \text{Score}}{\partial X_i} = \frac{\alpha_i}{X_i + 1} \times \text{Score}$$

となります (べき乗の微分を一度施すだけで、興味のある方は手を動かしてみてください)。右辺を見ると、**どの軸についても「スコアそのもの」が共通の因子として現れる**ことが分かります。共通部分は軸の比較に影響しないので、軸どうしの優劣は、残った $\alpha_i / (X_i + 1)$ という単純な比だけで決まります。そこで、律速軸——いま手当てすべき軸——を次で定義します。

$$\text{bottleneck} = \arg\max_i\; \frac{\alpha_i}{X_i + 1}$$

($\arg\max_i$ は「右の量を最大にする $i$ を選ぶ」という記号です。)

この比の意味を、経営の言葉に訳します。分子の $\alpha_i$ は、その軸の本質的な重要度。分母の $X_i + 1$ は、その軸がすでにどれだけ育っているか。つまりこの比は、**重要度と伸びしろの積**です。重みが大きい (本質的に効く) のに、値がまだ低い (伸びしろが大きい) 軸ほど、この比は大きくなる。経済学の言葉で言えば、そこへの投入の**限界収益**——同じ一単位の努力から得られる成果の増分——が最も高い軸です。律速診断とは、限界収益の最も高い場所を指す診断にほかなりません。

ありがちな誤読を一つ潰しておきます。「スコアへの寄与が最も小さい軸が律速だ」という読み方は、一見もっともらしいのですが、誤りです。寄与の小ささで選ぶと、重み $\alpha$ が小さい軸が常に選ばれてしまい、診断が「いちばん軽い軸を指し続ける」だけの壊れた羅針盤になります。律速の定義はあくまで**上げたときの増分**の最大、すなわち $\alpha_i/(X_i+1)$ の最大です。

### 例題のつづき — 九項目の計画を一つに絞る

> 冒頭のプロジェクトに、この診断を当ててみます。各軸について $\alpha_i / (X_i + 1)$ を計算するだけです (分母はシフト後の値、つまり生の値 $+1$ であることに注意)。

| 軸 | $\alpha_i$ | $X_i$ | $\alpha_i/(X_i+1)$ |
|---|---|---|---|
| $R_{\text{net}}$ | 0.8 | 0 | **0.800** ← 最大 |
| $F$ | 1.5 | 3 | 0.375 |
| $HRL$ | 1.1 | 2 | 0.367 |
| $TRL$ | 1.0 | 2 | 0.333 |
| $BRL$ | 0.6 | 1 | 0.300 |
| $\sigma_{SU}$ | 1.3 | 7 | 0.163 |
| $P$ | 1.0 | 6 | 0.143 |
| $GRL$ | 0.3 | 4 | 0.060 |
| $SRL$ | 0.2 | 4 | 0.040 |

律速は $R_{\text{net}}$、それも 2 位にほぼ倍の差をつけての首位です。診断の答えはこうなります——**次の一手は、対価を得る検証である。** 引き合いのある企業との検証を、無償の試料提供ではなく、費用負担つきの評価契約として組み直すこと。九項目の計画の中で、これに直結するのは「顧客ヒアリング」と「価格設定」——奇しくも、最も止まっていた二項目です。

この診断の意味を取り違えないでください。「小さく稼ぐこと自体が目的」なのではありません。ゼロ円の検証と一円でも対価のある検証とでは、得られる情報の質が違うのです。相手が費用を負担した瞬間に、その検証は相手の社内で「誰かが予算を取った案件」になり、顧客の本気度、評価の合格条件、予算の通り道、継続利用の可能性が、一気に観測できるようになります。$R_{\text{net}}$ を上げる一手は、同時に $BRL$ の検証を兼ね、相手のコミットメントを引き出す交渉の一手でもある——だからこそ、この軸の沈黙 (因子 1.00) は放置できないのです。

そして表は、二手目以降も示しています。$F$ (0.375) と $HRL$ (0.367) が僅差で続く——事業を背負う体制の組成が次の山です。一方、技術担当が最優先を主張した量産検証 ($TRL$、0.333) は四番手。重要でないのではなく、**今の限界収益で見ると先頭ではない**、ということです。九項目の計画は、こうして「対価を得る検証に主力を張り、体制づくりを仕込み、残りは止めるか最低限の維持に落とす」という形に絞られます。顧問の問い——「一つしかできないとしたら、どれをやりますか」——に、チームは初めて答えを持ちました。

> 図版 TODO (律速診断の棒グラフ): 例題の 9 軸について $\alpha_i/(X_i+1)$ を降順の横棒グラフで描く。$R_{\text{net}}$ の棒が突出し、$F$ と $HRL$ が僅差で続く形。各棒に「重み $\alpha$」と「伸びしろ $1/(X+1)$」の内訳を色分けで併記し、「重要度 × 伸びしろで次の一手が決まる」ことを視覚化する。

### 律速診断の読み方 — 三つの注意

機械的に出てくる診断だからこそ、読み方には注意が要ります。

第一に、**この診断は「効き目」の順位であって、「上げやすさ」の順位ではありません。** 式の中に、各軸を 1 段階上げるためのコストは入っていません。同じ 1 段階でも、規制対応の 1 段階と顧客面談の 1 段階では、必要な時間も資金も桁が違うことがあります。実務では、診断が指した軸とその次点について「1 段階上げる打ち手は何か、コストはどれほどか」を並べてから決める——診断は意思決定の入力であって、出力ではありません。

第二に、**構造的にゼロが続く軸は、読み替えが要ります。** たとえば創薬のように、製品の承認まで売上が立たないことが分野の構造として決まっている場合、$R_{\text{net}}$ は「上げるべき軸」ではなく「別の手段で代替する軸」です。この読み替えの根拠——補充の経路が確かなら、収益ゼロのまま走っても生存は損なわれにくいこと——は、次の章の戦略余力の枠組みで与えます。

第三に、スコアと診断は**使う場面が違います**。スコアの絶対値は、案件をまたいだ比較と投資判断のための、ゆっくり動く物差し。律速診断は、一つの案件の中で次の打ち手を選ぶ、日々の支援判断の道具。月次の支援会議で毎回見るべきは、スコアの上下よりも律速軸の移り変わりです。手当てした軸が育って律速が次の軸へ移っていく——その移り変わりこそ、支援が効いている証拠です。

## 軸どうしは独立ではない — 共線性の扱い

最後に、この式に向けられる、もっともな疑問に答えておきます。「9 本の軸は、互いに独立ではないのではないか」——そのとおりです。マクロの追い風が強い分野では、政策も予算も投資家も連動して動きます。$\sigma_{SU}$ が高い案件は $GRL$ や $SRL$ も高めに出やすく、チームが厚い案件は事業検証も進みやすい。統計学でいう**共線性** (説明変数どうしが連動して動くこと) が、この 9 軸にもあります。

共線性は、足し算のモデルでは深刻な問題を起こしますが、**積の構造では事情が違います**。Cobb-Douglas の積の中では、連動して動く軸の群は、その共通因子に対して弾力性の**和**として効きます。たとえば $\sigma_{SU}$ と $SRL$ が完全に連動するなら、二軸は実質的に $\alpha_\sigma + \alpha_{SRL} = 1.5$ の重みを持つ一つの軸として振る舞う。すると、個々の重みの割り振りが多少ズレていても——$\sigma$ に 1.3、$SRL$ に 0.2 と置くか、1.2 と 0.3 と置くか——**合計が過去ケースとの校正で合っていれば、スコアの値は正しく出ます**。共線性をすべて事前に解きほぐさなくても、校正しながら使い始められる。これがこの構造の実務的な強みです。

ただし、運用上の注意が二つあります。第一に、連動する軸どうしの**個々の**重みは、データからは合計しか決められません (識別が弱い、と言います)。したがって、律速診断が連動ペアの一方を指したときは、断定を一段弱めて「この群のどこかが律速」と読むのが誠実です。第二に——こちらが大事なのですが——**連動が崩れた事例こそ、情報量が最大です**。たとえば、追い風 $\sigma_{SU}$ は強いのに社会受容 $SRL$ が低い案件。政府と産業は前のめりなのに、消費者と世論が拒んでいる——1990 年代の欧州における遺伝子組換え食品が、まさにこの形で躓きました。連動が前提なら起きないはずの乖離が観測されたとき、それはモデルのノイズではなく、その案件の固有のリスクが顔を出した瞬間です。乖離が出た箇所に限って軸を分解して精査し、乖離が出るまでは分解しない——これが共線性との付き合い方です。

### 練習問題

> 手順は例題と同じです。べき乗の計算には電卓か表計算ソフトを使ってください。解答の方針は問題の下にあります。

1. **【計算】** ある案件の評価が $P=5,\ TRL=3,\ BRL=2,\ GRL=4,\ SRL=4,\ HRL=3,\ \sigma_{SU}=6,\ R_{\text{net}}=2,\ F=4$ だとします。例題の手順 (シフト → $\alpha$ 乗 → 積 → $\times K$) で統合スコアを求めてください。
2. **【律速】** 同じ案件の律速軸を $\arg\max_i\, \alpha_i/(X_i+1)$ で求めてください。首位と二番手以下が僅差の塊になることを確認し、「重要度と伸びしろの綱引き」という観点で解釈してください。
3. **【概念】** ある案件で $SRL$ だけが 0、残りの 8 軸はすべて 9 だとします。$SRL$ の重みは $\alpha_{SRL} = 0.2$ と全軸中の最小です。それでも $SRL$ は律速になるでしょうか。$\alpha_i/(X_i+1)$ を計算して判定し、「重みが小さい軸でも律速になりうる」ことを説明してください。あわせて、重みを変更した場合 (たとえば $\alpha_P$ を 1.0 から 1.3 に上げた場合) に、全軸最高 = 100,000 を保つための $K$ がどう変わるかも求めてください。

> 解答の方針: 問 1 は因子が $6 \times 4 \times 3^{0.6} \times 5^{0.3} \times 5^{0.2} \times 4^{1.1} \times 7^{1.3} \times 3^{0.8} \times 5^{1.5} \approx 161{,}000$、$\times K \approx 0.00158$ で**約 255**。問 2 は $F = 1.5/5 = 0.300$ が首位、次点が $HRL = 1.1/4 = 0.275$、$R_{\text{net}} = 0.8/3 \approx 0.267$、$TRL = 1.0/4 = 0.250$ と僅差の塊。重みの大きい $F$ は値 4 まで育っても首位に残る一方、すぐ後ろに性格の違う三軸が並ぶため、ここでは「上げやすさ (コスト)」の比較が決め手になる。問 3 は $SRL$ の比が $0.2/1 = 0.200$ で、値 9 の他軸の比 (最大でも $F$ の $1.5/10 = 0.150$) をすべて上回るため、**$SRL$ が律速になる**。ゼロ近傍の軸は伸びしろ $1/(X+1)$ が最大化するため、重み最小でも先頭に立ちうる。$K$ の再校正は $\sum\alpha = 8.1$ となるので $K = 100{,}000/10^{8.1} \approx 0.00079$。

## 実例 — 律速診断が、見たくない軸を指したとき

章の締めくくりに、実際の場面を一つ読み解きます。以下は、筆者らが見聞きした複数の事例を組み合わせ、特定を避ける形に再構成したものです。

ある研究機関発の機能性材料プロジェクトに、支援チームが伴走していました。技術は筋がよく、性能データは学会で注目され、複数の企業が説明を聞きに来る。ところが、そこから先に進まない。面談は和やかに終わり、「興味深いですね、続報をぜひ」で止まる。この状態が一年続いていました。

チームの診立ては一致していました。「企業がまだ乗ってこないのは、性能データが足りないからだ。実環境に近い条件での実証をもう一段積めば、動く」。研究者も同意見でした。もともと技術者気質の集団であり、データを磨くことは全員の得意分野でもあったのです。次の半年の計画は、追加実証の装置と人手に資源を寄せる方向で固まりかけていました。

念のため、と 9 軸の評価とスコア計算が行われました。評価は $P=6,\ TRL=5,\ BRL=2,\ GRL=3,\ SRL=4,\ HRL=2,\ \sigma_{SU}=6,\ R_{\text{net}}=1,\ F=1$。律速診断の上位はこうなりました。

| 軸 | $\alpha_i/(X_i+1)$ |
|---|---|
| $F$ | $1.5/2 = $ **0.750** ← 最大 |
| $R_{\text{net}}$ | $0.8/2 = 0.400$ |
| $HRL$ | $1.1/3 \approx 0.367$ |
| …… | …… |
| $TRL$ | $1.0/6 \approx 0.167$ (九軸中の六番手) |

チームが最優先しようとしていた $TRL$ は、六番手でした。技術はすでに 5 まで育っていて、伸びしろが小さい。診断が指したのは $F$——事業を背負う主体の不在——で、しかも二番手にほぼ倍の差をつけていました。

会議室の空気は、正直に言えば、白けたものでした。「経営人材がいないのは分かっている。でも、この段階の案件に来てくれる人などいない。だから技術を磨いて魅力を上げるしかないのではないか」。もっともな反論です。しかし議論を重ねるうちに、チームは一つのことを認めました——**技術を磨く計画は、全員にとって「できること」だった。経営機能の組成は、誰にとっても「やり方の分からないこと」だった。** 計画が技術に寄っていたのは、診断の結果ではなく、得意分野への重力の結果だったのです。

チームは半信半疑のまま、資源の張り方を変えました。追加実証は最小限の構成に縮め、浮いた時間で創業者機能の分解に取り組んだのです。研究・検証運営・資金調達・事業開発という機能に分け、研究者が背負うのは技術だけと定義し直し、事業開発を担える人を、いきなり「外部から来る経営トップ」としてではなく、まず週一日の関与から始められる形で探しました。数か月後、大手企業の新規事業部門を出た人物が、この形なら、と参画します。

動き出したのは、そこからでした。その人物が最初にやったのは、技術を磨くことではなく、一年分の企業面談の記録を読み直して、二社に「御社の評価条件を教えてほしい、それに合わせた有償の評価プログラムを組みたい」と持ちかけることでした。一社が応じ、費用負担つきの評価が始まり、皮肉なことに、そこで初めて「企業が本当に必要としている性能項目」が判明します。追加実証の計画は、その項目に絞って組み直されました。**企業が一年動かなかった理由は、データの不足ではなく、「組む相手」の不在だった**——面談に来ていた企業側の担当者たちは、技術にはとうに納得していて、しかし「この研究室と、誰を窓口に、どういう座組みで組めばいいのか」が見えないために、稟議を書けなかったのです。

律速診断が直感と違う軸を指したとき、可能性は二つあります。モデルの側が間違っている (評価値や重みがズレている) 可能性と、**チームの直感の側が、見たくないものを避けている**可能性です。どちらであるかは、議論しなければ分かりません。しかしその議論は、「全部大事」の会議とはまったく別物です。診断という第三者の声が、得意分野への重力に逆らう問いをテーブルに載せる——それが、この式が日々の現場で果たす仕事です。

## 章末の問い — 現場で使うチェック

いま手元にあるプロジェクトの支援計画を開いて、確かめてください。

1. その計画は何項目ありますか。「次の一手を一つだけ選べ」と問われて、あなたのチームは答えられますか。答えられないとしたら、足りないのは情報ですか、物差しですか。
2. あなたの組織の評価表は、足し算になっていませんか。一つの軸の致命的な欠落が、他の軸の高得点で覆い隠されていないか、最近の評価結果で確かめましたか。
3. 9 本の軸それぞれについて、いまの値を 0〜9 で言えますか。言えない軸があるなら、それは「評価が難しい軸」ではなく「誰も観測していない軸」ではありませんか。
4. 律速軸はどれですか。次の四半期の資源は、その軸に張られていますか。それとも、チームの得意な軸——いちばん楽に進められる軸——に流れていませんか。
5. 律速軸を 1 段階上げる打ち手と、そのコストを言えますか。「効き目の順位」と「楽さの順位」を混同していませんか。
6. 評価の重み付けは、紙に書かれていますか。誰かの頭の中の暗黙の重みのまま、会議で殴り合っていませんか。書かれた重みは、過去の案件の結末と突き合わせて見直されていますか。
7. 連動して動くはずの軸——追い風と社会受容、追い風と制度——のあいだに、乖離が出ていませんか。その乖離を、評価の誤差として丸めずに、案件固有のリスクとして読みましたか。
8. スコアの絶対値と律速診断を、別の判断に使い分けていますか。投資や採択の判断にスコアを、日々の支援の判断に律速を——逆になっていませんか。
