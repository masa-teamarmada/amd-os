**10.1 待つことに値段をつける——実物オプションと参入タイミングの理論** (1,450字)
was。冒頭に転調部 = 第9章の橋を受ける: 第9章末尾「優先順位の物差しはできた。しかし、スコアが高い案件に『いま』踏み込むべきかは、まだ別の問いである。順位と時機は違う」のパラフレーズ + 章頭の海辺 (順位なら高い案件だったはず、なのに二人は「やめる」と言った——本章はこの判断を数理にする) で理論へ入る。礼法は射程の確認 (「この道具は、何の存在と、どんなデータを前提に働くか」)。4系統: ①**実物オプション (主役、最も温かく)** — McDonald & Siegel (1986)、Dixit & Pindyck (1994)。不確実性の下で投資をいつ実行するかを最適停止として解き、「待つこと自体に価値がある」を初めて価格にした系譜。不可逆な投資 × 不確実性 × タイミングの自由、の三点が揃うとき「いま投資する」は「待つ価値を放棄する」ことと同義になる、という転回。本章の骨格になる、と相続を宣言 ②ステージゲート法 (Cooper 1990) — 第2章で判断の器として確認済みの再訪。関門ごとの Go/Kill。Kill してもプロジェクトが閉じるだけで会社は残る、という器の前提をここで再確認 (伏線) ③先行者優位論争 (Lieberman & Montgomery 1988) — 「早く出た者が勝つ」は半分だけ正しい。先行の利得 (学習・資源先取り・切替費用) と後発の利得 (ただ乗り・不確実性の解消を待てる) の両建てで、「早さは常に正義ではない」ことを学術の言葉にした論争 ④Klepper (1996) — 産業の齢と参入時期が生存を分ける実証系譜 (名前まで。ハザードの式・産業ライフサイクルの中身は第15章の領土、立ち入らない)。共通の前提を締めに: 四つとも、意思決定の主体 (法人・事業部) が既に存在し、待っているあいだも主体は無傷で残ることを暗黙に置いている。数式なし (式は 10.3 から)。

**10.2 登記は、NO_GO を消してしまう——標準理論が扱わない非対称** (1,250字)
but。一点集中: 実物オプションの「待つ/行使する」は**対称な選択肢**として設計されている——待てば選択肢は開いたまま残り、行使すれば投資額を失うが主体は残る。Before Zero の設立判断はこの対称が壊れている。第2章の法人化境界 τ_B (扉のたとえ) を受ける: 扉のこちら側では NO_GO (この形では進めない) がまだ生きた選択肢だが、扉を越えた瞬間から毎月の持ち出しが走り出し、清算の重さが NO_GO を事実上選べなくする——「NO_GO という言葉が生きているのは、この境界の手前だけ」(第2章)。つまり設立判断は「いつ投資するか」ではなく「**不可逆点をいつ越えるか**」の判断であり、越えた後に間違いに気づいても、標準理論が前提にする「撤退して主体は残る」道がない。ステージゲートの器の不在も同型 (判定を下す主体も、Kill してなお残る器も、法人前には無い——第2章 2.6 の確認の再訪)。だからこそ、第2章はこう約束していた——「判断が不可逆であるからこそ、待って情報を得ることには価値が生まれます。その価値がどれほどの大きさで、いつ待つのをやめるべきかを数として解くのは、第10章の最適停止の数理です」(2.6 の逐語を趣旨で受ける)。本章がその約束の受け取り手である、と宣言して therefore へ。「鬼門」の語は使わない (全面禁止 — 第2章の三つの判断は「不可逆点」の語で受ける)。

**10.3 追い風と、足場と——GO を立てる二重の錠前** (1,700字)
therefore① (数式アイテム1)。教育順 = 直感→式。直感: GO とは何が揃ったときに出せる判断か。二つの問いに分かれる——外の風は吹いているか (マクロ)、自分の足場はできているか (ミクロ)。どちらか片方では進めない。追い風だけで足場のない案件は、走り出した瞬間に自重で沈む。足場があっても風のない案件は、立ち上げても資金と関心の流れに乗れない。**両方が揃って初めて GO**——掛け算 (AND) の構造。式: $$\mathrm{GO}(t, i) = \mathbb{1}\left[\, \sigma_{SU}(t) \geq \theta_\sigma^* \,\right] \cdot g_{\mathrm{TRL}}(t)$$ 記号の読み下し: 𝟙[…] は中身が成り立てば 1、成り立たなければ 0 を返す指示関数。マクロ項 = 第7章で組み立てた投入シグナル σ_SU (学・産・官の揃いを測る観測量。σ_SU > 0 = 追い風) が、閾値 θ_σ* 以上か。ミクロ項 = $g_{\mathrm{TRL}}(t) = \mathbb{1}\left[\, \mathrm{TRL}_{\text{有効}}(t) \geq \theta_{\mathrm{TRL}} \,\right]$ — 第5章 5.4節の有効値 (事業計画が依存するセルの最小値。「鎖の強さは一番弱い輪で決まる」) が、立ち上げに足る段階 θ_TRL に届いているか。両方 1 のときだけ GO = 1。二つの閾値 θ_σ*・θ_TRL の具体の値は書かない——値は案件の集合と機関の実績から校正する手続きの話であり (第9章の重みと同じ扱い)、本章で大事なのは値ではなく**構造**である。σ_SU の生成過程 (観測系列・状態の推定) は第7章に委ね再展開しない。TRL マトリクスも第5章に委ね再展開しない。章頭への当て込みを一段落: 海辺の案件はどうだったか——試作機は動いた。だが事業計画が依存するセル (量産・実装・保守) の足場はまだ薄く、そして何より、この案件が引っかかったのはこの式のどちらの項でもなかった (伏線——答えは 10.7 末尾と 10.8)。「活動の量は GO の根拠にならない」(第2章) をゲートの言葉で言い直す: 面談の数も紹介の数も、σ_SU にも TRL_有効 にも入っていない。

**10.4 いま決めるか、待って決めるか——二時点の最適停止を数で解く** (2,100字)
therefore② (数式アイテム2、**章の数理の峰**)。第2章の約束をここで果たす、と一文で宣言してから、教育順 = 直感→数値→式の言葉。直感: なぜ「待つ」に価値があるのか——判断が不可逆で、時間が情報を運んでくるからである。待てば、いま見えない不確実性の一部が解けてから決められる。worked example (**全て架空の数値と明記**、図10-2 の決定木): ある案件をいま設立する (GO) か、一期 (たとえば半年) 待って追い風の行方を見てから決めるか。いま GO したときの価値 = 追い風が本物なら 60、外れなら −20 (登記後は毎月の持ち出しが走り、外れと分かっても止まりにくい——第2章の非対称がこの −20 の中身)。どちらに転ぶかは五分五分とする。いま GO の期待値 = 0.5×60 + 0.5×(−20) = **20**。一期待つと: 追い風の行方が見えてから決められる——本物なら GO して 60、外れなら**登記していないので NO_GO を選べて 0** (これが τ_B の手前に立っていることの価値。失うものは待機の費用だけ)。待つ場合の期待値 = 0.5×60 + 0.5×0 = 30 から、待機費用 c を引いたもの。c = 5 なら 25 > 20——**待つほうが良い (WAIT)**。数値が示すこと: 待つ価値の正体は「外れの枝で 0 で止まれること」= 悪い実現のときに −20 を回避できる保険 (0.5 × 20 = 10) であり、待機費用 c がこの保険料 10 を下回るかぎり WAIT が勝つ。**c = 10 でちょうど無差別**——この「待つ価値といま決める価値が一致する境界」を、最適停止の言葉で value matching (価値の一致) と呼ぶ。連続時間の完全な理論では、境界では価値の水準だけでなく傾きまで滑らかに接する (smooth pasting、滑らかな接合) ことが知られており、この二条件が「いつ待つのをやめるか」の一次条件になる——本書は二時点の算数で骨格だけを見せた。完全な導出は本書の理論的基盤を与える学術書 (刊行準備中) に委ねる (一文)。追い風の確からしさ p を動かす読み: いま GO が勝つ条件は 80p − 20 ≥ 60p − c、整理して **p ≥ (20 − c)/20**。c = 5 なら p が 3/4 を超えたとき初めて「いま GO」が最適になる——**この境界の p こそ、前節の閾値 θ_σ* の正体** (σ_SU が高い = 追い風が確からしい、の対応)。閾値は式の外から与える恣意的な線ではなく、待つ価値といま動く価値の競り合いが決める内生的な線である、と次節へ渡す。「待つことは無料ではない」の中身 (c に何が入るか) も次節へ一言で送る。

**10.5 待つ価値は、案件ごとに違う——閾値 θ_σ* の内生性** (1,500字)
therefore③ (数式アイテム3)。前節の worked example のパラメータを現実の案件の顔に翻訳する (表10-2): **P (天井、第4章) が大きい** → 賭け金が大きく、成功の 60 も失敗の −20 も桁が上がる。誤った判断の代償が大きいほど、待って情報を得る価値は大きい → **θ_σ* は上がる** (より強い追い風が確かめられるまで待つべき案件になる)。**B (狙う規模ゆえの毎月の持ち出し、第6章) が重い** → 扉を越えた後の不可逆な流出が深い (worked example の −20 が −40 になる) → 誤 GO の代償が大きい → **θ_σ* は上がる**。**待機の機会費用が高い** (関係者の時計が冷える・公募の窓が閉じる・競合が先に動く——第2章の「遅すぎる会社化も別の形で壊れる」) → 待機費用 c が大きい → **θ_σ* は下がる** (早めの判断に傾く)。レジーム遷移の不可逆の重さ (登記で消える選択肢の多さ) が大きい → θ_σ* は上がる。まとめの一文: **閾値は案件ごとに違う**——「待つ価値」が案件ごとに違うことの形式化であり、第2章の「いつ扉を開けるか自体が、Before Zero でもっとも重い判断の一つ」「τ_B は、向こうからやって来るのではありません。こちらが選ぶものです」が、ここで数理の裏付けを得て完結する。F (創業者機能、第6章) の効き方は他と違う——F は閾値を動かすというより、**待ち方を変える**: F の厚いチームは待機中作業で不確実性を自分から潰しにいける (追い風を確かめるのではなく、確からしさを作りにいく)。「待つ」が受け身の時間ではなくなる——この能動的な待ち方の形式が次々節 (10.7) の主題である、と予告。B の二面性への注記 (誤読封じ): B は「登記後に走る持ち出し」なので閾値を**上げる**側に効く。「待機そのものの費用」は B ではない (登記前に B は走らない——第2章・第6章の教え)。待機費用の中身は時計と窓 (と、第8章の言葉で言えば、待つあいだにも目減りする戦略の余力) である。

**10.6 優先順位とゲートは、別の演算である——SPS≠GO の一枚図** (1,600字)
therefore④ (数式アイテム5、**SPS≠GO 図解の正本**)。第9章 9.7 の予告 (「本章のスコアは優先順位であって『進む・待つ・やめる』の判定ではない——作法は第10章」) をここで回収する、と明示。核心 = 二つは**数学的に別の演算**: SPS ($\mathrm{SPS} = K \cdot \prod_{i=1}^{9} (X_i+1)^{\alpha_i}$、第9章。再掲はこの対比の1回のみ) は案件の**集合**を入力に取り、並べて順位を返す——**相対**の演算 (どの案件が有望か)。GO ($\mathrm{GO} = \mathbb{1}[\sigma_{SU} \geq \theta_\sigma^*] \cdot g_{\mathrm{TRL}}$) は**単一案件**の状態を閾値と照合し、通す/通さないの 0/1 を返す——**絶対**の演算 (この案件を、いま、通してよいか)。入力も出力も違う二つを、一つの数に畳んではならない。図10-1 (正本): 縦軸 = SPS の順位、横軸 = GO ゲートの充足。右上だけが GO。**左上 = SPS 最上位なのにゲート未達 = WAIT**——これが実務で最も誤りやすい象限であり、本章の必須演習の舞台である。「SPS が高いから GO」は、順位表を通行証と取り違える誤読——順位が高いことは、資源配分の列の先頭に立つ理由にはなるが、いま不可逆点を越えてよい理由にはならない。逆 (ゲートは開いているが SPS が低い) は「通れるが、通る価値の順位が回ってこない」案件。NO_GO はこの図のどの象限でもない——σ_SU の低さでも TRL の未達でもなく、**天井 P が原理の水準で立たない**案件は、ゲート判定の手前で評価から降ろすべきである (次節末尾で扱う)、の一文で伏線。UI や資料で SPS と GO を掛け合わせた「総合判定スコア」を作らない、という運用禁止則を一言 (理由の深掘りは第12章の領土、立ち入らない)。章頭への当て込み: 海辺の案件は、順位 (SPS) なら決して低くなかった——追い風は吹き、到達も進んでいた。それでも二人は「やめる」と言えた。その根拠が次節から B面の主題になる。

**10.7 戻る条件から、復帰条件へ——WAIT は待ちながら動く** (1,500字)
therefore⑤ (数式アイテム4)。冒頭で glossary §5 の橋を受ける: **第2章の現場の言葉「戻る条件」を、本章はここで「復帰条件」として形式化する** (第2章 2.6「ここで書く『戻る条件』という現場の言葉は、第10章では復帰条件として形式化されます」の明示回収)。WAIT の形式: $$\mathrm{WAIT} = \left(\, \mathcal{C},\ T,\ W \,\right)$$ — 復帰条件の集合 𝒞、見直し日と担当 T、待機中作業 W の三つ組。第2章の WAIT 3部品 (戻る条件・見直しの日付と担当・待っている間に進める作業) と一対一に対応する (一字も矛盾させない)。𝒞 の中身は**測れる述語**で書く——「σ_SU が θ_σ* を上回る」「事業計画が依存するセルの TRL_有効 が θ_TRL に届く」「予算を持つ人に会い、支払いの条件を聞けている」(第2章の具体化規律の例をゲートの言葉で言い直したもの)。運用: T の日に 𝒞 を検査し、満たされていれば GO ゲート (10.3) の再判定へ、満たされていなければ WAIT 継続か NO_GO かを再び選ぶ。「何が変わったから GO なんですか」(第2章) は、この検査を一言で言ったものである——変わったのが 𝒞 の中身なら復帰、増えたのが活動の量なら復帰ではない。W が本章で新しく持つ意味: 前々節で見たとおり、F の厚いチームの W は「待って様子を見る」ではなく「復帰条件を自分から満たしにいく」——追い風を待つのではなく、顧客の支払い意思という時計を自分で鳴らしにいく (第7章 B面と同じ所作)。待機は無料ではない (W は時間と余力を消費する——第8章の言葉で言えば y の目減り) からこそ、𝒞 のない WAIT は「ただの先送り」に劣化する (第2章の再確認)。表10-1 (判断語彙×判定に使う量: GO = 二重の錠前 / WAIT = 𝒞・T・W / NO_GO = 原理に根ざす天井の欠陥ほか / HOLD = 材料不足・週単位)。Box 10-B (復帰条件付き WAIT 判定書の型)。**末尾に NO_GO の理論的位置** (B面への渡し): 四つの語彙のうち NO_GO だけは、この章のゲートの式では出てこない。σ_SU が低いなら待てばよい。TRL_有効 が足りないなら作ればよい。だが**天井 P が原理の水準で成立しない案件は、待っても作っても変わらない**——ゲートの手前、第4章の物差しで落とすべき案件である。章頭の海辺で世良の計算が突き当たったのは、まさにこれだった。

**10.8 言えた NO_GO、言えなかった NO_GO——決断のあとに要るもの** (1,800字)
B面回収 + 実例2件。第一段 (海辺のその後): 決断の翌週、世良が書いた文書——判断 (この公募には出さない。事業化は見送る)、評価に使った物差し (第4章の三つ: 第三者データ・採算の式・最初の顧客)、そして根拠の核心 = **原理に根ざすコストの下限** (装置のコスト構造の分解。材料の量と構造の力学が決める下限は、量産でも改良でも動かない部分であり、競合する電源の価格水準に、最大限に譲っても届かない)。この文書があることで、NO_GO は「あの支援者が悲観的だったから」ではなく「誰が読み直しても同じ結論に至る評価」になる——**落とす判断の根拠を原理の言葉で文書化できたなら、それは冷酷な切り捨てではなく、評価として誠実な仕事である** (p-potential 実例の核フレーズの回収)。生存 S をどれだけ支えても届く先の天井が低いままなら結末は変わらない——**S 以前に、P で落とすべき案件は存在する**。そして甲斐のその後 (晴れの根拠): 発電の事業はやめた。だが装置の技術は死んでいない——海の観測・防災系の計測という別の用途の相談が研究室に来ている。NO_GO とは「この形では進めない」であって、シーズの死ではない (第2章 表2-4 の定義の実演: 用途を変える、時機を待って研究に戻る)。チームの時間は、より天井の高い何かに使える時間として返ってきた。第二段 (実例2件、匿名化 composite 宣言を各末尾で): **実例その一 (言えなかった NO_GO)** — ある支援者は、伴走していた案件の用途が近い将来、別の技術の進歩に呑まれて消えることを、内心では確信していた。それでも、頼まれるままに資金調達へ協力した——長い付き合い、支援者としての立場、いまさら言い出す気まずさ。調達の直後、予見していたとおり代替技術が跳ね、用途は市場ごと消えた。NO_GO を言うべき立場の人間には、言わないほうへ向かう力学 (関係・報酬・惰性) がいつも働いている。根拠が文書になっていない NO_GO は、個人の勇気の問題にすり替わる——だから判定書という**形式**が要る。**実例その二 (止められなかった NO_GO)** — 別の支援者は、経営の方向がこの形では立ち行かないと判断し、方向転換を求めた。だが説得は届かず、最後に判断を決めたのは議決権の数だった——方向を変えさせるだけの持ち分を、集められなかった。NO_GO は判断だけでは完結しない。**誰が・どの権限で止められるか**という実行の設計が、Before Zero のうちに要る (第2章の判断の器の話が、権限の器の話としてもう一度現れる。CEO と経営機能の配置の議論は第14章へ一言)。締め: 討議課題Aの答え合わせ——①決断の妥当性は「覆る条件」が言えるかで検査できる (原理の下限の再計算を覆す新事実だけが覆せる——それは復帰条件の形をしている) ②機械が動くことと事業が動くことのあいだに挟まっていたのは、採算の式・顧客・そして時計だった ③宛先と形式 = Box 10-A。世良と甲斐が「言えた」ことの条件も一言——計算が紙になっていたこと、そして**まだ扉のこちら側にいたこと** (τ_B の手前では、NO_GO はまだ生きた言葉だった)。
