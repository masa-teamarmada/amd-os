## 2. 設計思想 (4つ)

1. **読者の成長譚**: 視点の高度が段階的に上がる — I部「現場の隣」(伴走者が言葉を持たない) → II部後半「判断の当事者」(Ch9 絞る痛み、Ch10 やめる決断) → III部「機関・経営層」(Ch11 担当者 → Ch12 学長室) → IV部「組成の設計者」→ Ch15「理論を作った本人」が批判の矢面に立つ。章の主役は毎回変わっても、読者の中で一人の支援者が育つ。前半の「支援者一色」はこの助走として意図に変わる。
2. **季節の巡りと時間スケールの拡大**: 三月 (Ch1 祝賀会) に始まり三月 (Ch15 研究会) に終わる円環。1年目 = Ch1〜7 で支援現場の一年度が巡る。2年目 = Ch8 が四月→十二月を一章で走る (理論側の節題「春に決まっていた十二月」と癒着済み)。最終巡り = Ch13 春 → 新章 夏 → Ch14 晩秋 → Ch15 三月で四季が一周して閉じる。並行して章頭の物語内時間が十七分 → 一晩 → 一週間 → 半年 → 数年と伸び、理論のスケールアップ (点の判断 → 線の軌跡 → 機関 → エコシステム) と同期する。**最初の絵が祝辞、最後の絵が批判** — どちらも年度末の会場。祝われて始まり、疑われて終わる (=「モデルを疑いながら使う」の構造化)。
3. **数の装置は理論由来だけ**: 「三」は Ch3 (三因子)・Ch7 (産官学)・Ch15 (三批判)、「九」は Ch9 (九軸) のみ。Ch3 と Ch15 は呼応させる — 始まりは「三つの正しさが噛み合わない」、終わりは「三つの批判をすべて正しいと認める」。
4. **幕引きの音は同型を連続させない**: 未決 (2・8、質は別物) / 言い切り (3・6) / 台詞 (5) / 風景 (7) / 音 (4) / 光 (8) / 決断 (10 — 16話で唯一「決めて終わる」、NO_GO を誠実な仕事として描く唯一の晴れ) / 問いの手渡し (11) / 円環 (15)。

## 2.5 全体のストーリー (まさ確定 2026-07-12)

**一行定義: 言葉を持たない伴走者が、言葉を作る側になるまでの物語。** 各話の主役は別人 (別の合成事例) だが、読者の中では一人の人物として積み上がる。Ch1 の柏木 (通しで見届けたのに何も言えなかった男) が原型、以降の視点人物は「柏木のその後の顔」、最終話の発表者 (自分の言葉を批判に晒す人) が到達点。本書の理論の目的 (現場に共通言語を与える) を物語の形で言ったものになる。

**三幕**: 第一幕「言葉がない」(Ch1〜3、三月→夏) — 違和感はあるのに言葉がない(1) / 止める言葉を得る(2) / 比べる言葉はまだ無い(3)。第二幕「言葉を、ひとつずつ」(Ch4〜10、秋→翌年) — 各話が「言葉が無いことで起きた失敗」から始まり言葉を得て終わる。**Ch10 で初めて「晴れ」** — 冬の海で「やめる」と言えた日、16話で最初に誰かがちゃんと言えた瞬間。第三幕「言葉の先へ」(Ch11〜16、冬→春→再びの三月) — 視座が案件から機関へ(11・12)、観測から行動へ(13・CEO章)、成功の定義へ(14)、言葉そのものへの疑いへ(15)。幕切れは三月の研究会 — 批判を全部認めて、それでも歩き出す。Ch1 と同じ三月。

**話から話への受け渡し (15の橋)** — 前話の幕の残像が次話の開幕に形を変えて現れる:

| 橋 | 受け渡すもの |
|---|---|
| 1→2 | 「誰も止めなかった四十分」の直後に「止まった十七分」。読者はここで初めて「止まる」の見た目を知る |
| 2→3 | 一件を止める語彙は得た。三件並んだら? — 判断の言葉は比較の言葉ではなかった |
| 3→4 | 三つの物差しの一本目「市場」が、なぜ一円にもならないかの解剖へ |
| 4→5 | 外の数字から内の言葉へ。「数字は本当なのに信じられない」の次は「言葉は嘘じゃないのに通じない」 |
| 5→6 | 和やかに終わった面談の次に、満点の案件への「死なないんですか」。問いが一段沈む |
| 6→7 | 内側の設計 (生存) の沈黙を受けて、外側の力 (風) へ |
| 7→8 | 長机の三本の矢印の紙の、その後。風に乗ることと走り切ることは別 |

**通奏低音 (3本)**: ①時計 (Ch1 で逆回転した時計が全話でそれぞれの形で鳴る — 本書理論の中心語) ②手の中の小さな物 (グラス→シール→冷めた茶→トロフィー→評価メモ→評価シート→公募要領→名刺→付箋→… 各話の感情を一つの小さな物に宿らせ、章が閉じるときその物が最後にもう一度映る) ③「言えなかったこと」の変奏 (おおむね(1)→送信前の逡巡(2)→比べる言葉の不在(3)→出せない助け舟(4)→返せない言葉(5)→沈黙(6)→宙に浮く問い(7)→書けない返信(8)→言えない秘密(9)→**10で初めて「言う」**→第三幕では「言う」が仕事になる)。

## 3. 全章共通の統一方針

- **開幕は全章「Ch9型」**: 物語の一行目から (Ch9「瀬戸が…立ったのは、桜が散ったあとの月曜日だった」が模範)。Ch2〜8 の頭の講義接続段落 (「第N章は〜でした。本章は〜です」) は x.0 末尾の転調部か x.1 冒頭へ移す。前章との橋の機能は失わない (置き場所を変えるだけ)。
- **技法反復の管理** (まさ指摘1の一般化): 「一瞬・わずかな間」系の心理描写は同一場面内 1回まで。同じ比喩 (部屋・物差し等) を章をまたいで使い回さない。「言葉にできない」系の幕引きは設計表指定の章のみ。
- 討議課題 A・ケース注記文・図注・台詞「」内・数式・A/B 分割 (判断直前で切る構造) は不変。
- 理論側の回収節 (2.7 / 3.7 / 4.5 / 5.8 / 6.9 / 7.7 / 8.8 / 9.5・9.8) が参照する場面要素は削除・改変しない (動かせない釘)。

## 4. 実話エピソードの器 (まさ確定 2026-07-12)

**原則: 理論との結びつきはエピソード採用の条件にしない。結びつきの濃度は「どの器に置くか」を決める変数。** 回収されない実話は、現実が理論より大きいことを本自体が認める証拠 (= Ch15 の姿勢と同じ) であり、削らない。

- **器A — 章頭の中の「重り」** (理論と半分結びつく話): 作法 4つ — (a) 理論の釘の列 (番号付き違和感等) に並べず転調で区切る、(b) 討議課題で触れない、(c) 理論パートの回収節でも触れない (触れないことを意図する)、(d) 一章に重りは一つまで。
- **器B — 部扉の幕間** (理論と結びつかない話): I→II→III→IV→終章の継ぎ目 4箇所に 1p 弱の一人称断章。序章 (EP-015/030) + あとがき (EP-003 家族の問い) と合わせ「著者の物語」が本の外周を走る。**承認済み・着手は後日** (まさ 2026-07-12「着手は後からにしよう」)。
- **器C — 序章・あとがき**: 配置マップ B群のまま維持。
- **Ch1 の訴訟 (EP-031) の処置 (2026-07-12 v3 で更新・まさ確定)**: **Ch1 では不採用** (まさ「入れるべきではないのは明確」)。Ch1 のテーマは「死因は設立前に生まれる」で、逆年表は設立前へ根を辿る運動 — 訴訟だけが設立後の出来事で設立前に根を持たず、構造的に浮くのは必然だった (v2 の【受賞の年】ラベル格上げ案は対症療法で不採用)。実体験としての価値は **Ch7 新 Box「追い風は、無償ではない」** (Box7-2「追い風は群れでやってくる」の対) へ全量移管 — 「賞が人質になる (受賞したせいで争えない)」は追い風理論の影の面として理論と半分結びつく (器A の正しい適用先)。官庁ビート込みの完全版を用いる。変装 L1 維持 (省庁は「所管官庁」等)。Box は理論パート側への追加のため、Ch7 改稿時に併せて提案し正本反映は司令塔ゲート経由。
