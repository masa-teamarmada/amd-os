## 2. 設計思想 (4つ)

1. **読者の成長譚**: 視点の高度が段階的に上がる — I部「現場の隣」(伴走者が言葉を持たない) → II部後半「判断の当事者」(Ch9 絞る痛み、Ch10 やめる決断) → III部「機関・経営層」(Ch11 担当者 → Ch12 学長室) → IV部「組成の設計者」→ Ch15「理論を作った本人」が批判の矢面に立つ。視点人物は章ごとに替わるが、**読者の同伴者は柏木である** (2026-07-14 改訂 — 旧「章の主役は毎回変わっても、読者の中で一人の支援者が育つ」を廃止): 読者は各章の当事者の目で判断の痛みをくぐりながら、章をまたいで「また、いる」柏木を見つけ、柏木と一緒に機関の九年を歩く。前半の「支援者一色」はこの助走として意図に変わる。
2. **季節の巡りと時間スケールの拡大**: 三月 (Ch1 祝賀会) に始まり三月 (Ch15 研究会) に終わる円環。1年目 = Ch1〜7 で支援現場の一年度が巡る。2年目 = Ch8 が四月→十二月を一章で走る (理論側の節題「春に決まっていた十二月」と癒着済み)。最終巡り = Ch13 春 → 新章 夏 → Ch14 晩秋 → Ch15 三月で四季が一周して閉じる。並行して章頭の物語内時間が十七分 → 一晩 → 一週間 → 半年 → 数年と伸び、理論のスケールアップ (点の判断 → 線の軌跡 → 機関 → エコシステム) と同期する。**Ch1 の幕の絵が祝辞、Ch15 の幕の絵が批判** — どちらも年度末の会場。祝われて閉じる第1話と、疑われて閉じる最終話 (=「モデルを疑いながら使う」の構造化)。※2026-07-13 v5 で Ch1 の開幕は会議室になったため「最初の絵が祝辞」から言い換え — 祝辞と批判の対比自体は不変。
3. **数の装置は理論由来だけ**: 「三」は Ch3 (三因子)・Ch7 (産官学)・Ch15 (三批判)、「九」は Ch9 (九軸) のみ。Ch3 と Ch15 は呼応させる — 始まりは「三つの正しさが噛み合わない」、終わりは「三つの批判をすべて正しいと認める」。
4. **幕引きの音は同型を連続させない**: 未決 (2・8、質は別物) / 言い切り (3・6) / 台詞 (5) / 風景 (7) / 音 (4) / 光 (8) / 決断 (10 — 16話で唯一「決めて終わる」、NO_GO を誠実な仕事として描く唯一の晴れ) / 問いの手渡し (11) / 円環 (15)。

## 2.5 全体のストーリー (まさ確定 2026-07-12 → 2026-07-14 柏木中心の通しドラマへ改訂)

**一行定義 (二重らせん、2026-07-14 まさ確定・案1): 一つの機関の九年を、意思だけで通しに見届けようとした男の物語。個人の意思の限界が露わになるほど「席」の必要が立ち上がり、その傍らで、言葉を作る側になる伴走者が育つ。** 柏木 = 見届けの弧 (物語の主人公・読者の同伴者)、志野 = 言葉の弧 (旧一行定義「言葉を持たない伴走者が、言葉を作る側になるまでの物語」の物理化 — Ch2 → Ch16 発表者として不変)。二本の弧は Ch16 の同じ会場で交差して閉じる — 志野の発表 (言葉の到達) に、柏木の遅れない拍手 (見届けの円環)。物語の主人公は柏木であり、各話の視点人物は柏木の九年を映す相手役。最終話の発表者は志野のまま — 柏木が言葉の側へ渡ると「個人の努力で解決できた」ことになり、Ch1 1.2 の釘 (通しで見届けて責任を負う席が制度側に無い) が折れる。本書の理論の目的 (現場に共通言語を与える) を物語の形で言ったものになる。※旧定義の「各話の主役は別人 (別の合成事例) だが、読者の中では一人の人物として積み上がる」は 2026-07-14 に廃止 — 精神的連続 (読者の中の合成) ではなく、柏木自身が全話に現れる物理的連続で通しのドラマを立てる (経緯は本節末尾の 2026-07-14 訂正)。

**三幕**: 第一幕「言葉がない」(Ch1〜3、三月→夏) — 違和感はあるのに言葉がない(1) / 止める言葉を得る(2) / 比べる言葉はまだ無い(3)。第二幕「言葉を、ひとつずつ」(Ch4〜10、秋→翌年) — 各話が「言葉が無いことで起きた失敗」から始まり言葉を得て終わる。**Ch10 で初めて「晴れ」** — 雪の源泉で「やめる」と言えた日、16話で最初に誰かがちゃんと言えた瞬間。第三幕「言葉の先へ」(Ch11〜16、冬→春→再びの三月) — 視座が案件から機関へ(11・12)、観測から行動へ(13・CEO章)、成功の定義へ(14)、言葉そのものへの疑いへ(15)。幕切れは三月の研究会 — 批判を全部認めて、それでも歩き出す。Ch1 と同じ三月。

**話から話への受け渡し (15の橋)** — 前話の幕の残像が次話の開幕に形を変えて現れる:
