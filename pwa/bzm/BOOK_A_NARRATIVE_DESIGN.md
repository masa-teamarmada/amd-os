## 0. 出発点 — なぜ通し設計か (まさ差し戻し 2026-07-12)

場面単位の Before/After 推敲 (旧 PF-021 方式) は「木を見て森を見ない」とまさが差し戻し。全章を並べた俯瞰診断で以下が判明した:

1. 8話ぜんぶが「支援者が室内でかすかな違和感を覚え、言葉にできないまま幕」の同型 (最大の問題)
2. Ch2〜8 の開幕が全て「前章要約+本章予告」の講義接続で始まり、没入を毎回削ぐ
3. 「三つの◯◯」骨格が 5章で反復、Ch4/Ch5 は「部屋」比喩まで章間重複
4. 幕引きが 6/8章で「言葉にできない」系の同型
5. 季節描写が Ch1/2/8 のみ (和の美意識方針と不整合)
6. 理論側は章間参照で繋がっている (5.8→Ch3、8.5→Box7-2、2.7→Ch1) のにナラティブだけ孤立

**大原則 (タスク定義より不変)**: 事実関係・データ・数値・登場人物の設定・プロットの骨格は変更しない。変えてよいのは表現・構成・見せ方 (場面の順序、視点の移し方、エピソードの取捨選択や配置、比喩・レトリック)。文体は「である」調 (PF-020、N ストリームと1パス統合)。

## 2. 設計思想 (4つ)

1. **読者の成長譚**: 視点の高度が段階的に上がる — I部「現場の隣」(伴走者が言葉を持たない) → II部後半「判断の当事者」(Ch9 絞る痛み、Ch10 やめる決断) → III部「機関・経営層」(Ch11 担当者 → Ch12 学長室) → IV部「組成の設計者」→ Ch15「理論を作った本人」が批判の矢面に立つ。章の主役は毎回変わっても、読者の中で一人の支援者が育つ。前半の「支援者一色」はこの助走として意図に変わる。
2. **季節の巡りと時間スケールの拡大**: 三月 (Ch1 祝賀会) に始まり三月 (Ch15 研究会) に終わる円環。1年目 = Ch1〜7 で支援現場の一年度が巡る。2年目 = Ch8 が四月→十二月を一章で走る (理論側の節題「春に決まっていた十二月」と癒着済み)。最終巡り = Ch13 春 → 新章 夏 → Ch14 晩秋 → Ch15 三月で四季が一周して閉じる。並行して章頭の物語内時間が十七分 → 一晩 → 一週間 → 半年 → 数年と伸び、理論のスケールアップ (点の判断 → 線の軌跡 → 機関 → エコシステム) と同期する。**最初の絵が祝辞、最後の絵が批判** — どちらも年度末の会場。祝われて始まり、疑われて終わる (=「モデルを疑いながら使う」の構造化)。
3. **数の装置は理論由来だけ**: 「三」は Ch3 (三因子)・Ch7 (産官学)・Ch15 (三批判)、「九」は Ch9 (九軸) のみ。Ch3 と Ch15 は呼応させる — 始まりは「三つの正しさが噛み合わない」、終わりは「三つの批判をすべて正しいと認める」。
4. **幕引きの音は同型を連続させない**: 未決 (2・8、質は別物) / 言い切り (3・6) / 台詞 (5) / 風景 (7) / 音 (4) / 光 (8) / 決断 (10 — 16話で唯一「決めて終わる」、NO_GO を誠実な仕事として描く唯一の晴れ) / 問いの手渡し (11) / 円環 (15)。

## 3. 全章共通の統一方針

- **開幕は全章「Ch9型」**: 物語の一行目から (Ch9「瀬戸が…立ったのは、桜が散ったあとの月曜日だった」が模範)。Ch2〜8 の頭の講義接続段落 (「第N章は〜でした。本章は〜です」) は x.0 末尾の転調部か x.1 冒頭へ移す。前章との橋の機能は失わない (置き場所を変えるだけ)。
- **技法反復の管理** (まさ指摘1の一般化): 「一瞬・わずかな間」系の心理描写は同一場面内 1回まで。同じ比喩 (部屋・物差し等) を章をまたいで使い回さない。「言葉にできない」系の幕引きは設計表指定の章のみ。
- 討議課題 A・ケース注記文・図注・台詞「」内・数式・A/B 分割 (判断直前で切る構造) は不変。
- 理論側の回収節 (2.7 / 3.7 / 4.5 / 5.8 / 6.9 / 7.7 / 8.8 / 9.5・9.8) が参照する場面要素は削除・改変しない (動かせない釘)。

## 4. 実話エピソードの器 (まさ確定 2026-07-12)

**原則: 理論との結びつきはエピソード採用の条件にしない。結びつきの濃度は「どの器に置くか」を決める変数。** 回収されない実話は、現実が理論より大きいことを本自体が認める証拠 (= Ch15 の姿勢と同じ) であり、削らない。

- **器A — 章頭の中の「重り」** (理論と半分結びつく話): 作法 4つ — (a) 理論の釘の列 (番号付き違和感等) に並べず転調で区切る、(b) 討議課題で触れない、(c) 理論パートの回収節でも触れない (触れないことを意図する)、(d) 一章に重りは一つまで。
- **器B — 部扉の幕間** (理論と結びつかない話): I→II→III→IV→終章の継ぎ目 4箇所に 1p 弱の一人称断章。序章 (EP-015/030) + あとがき (EP-003 家族の問い) と合わせ「著者の物語」が本の外周を走る。**承認済み・着手は後日** (まさ 2026-07-12「着手は後からにしよう」)。
- **器C — 序章・あとがき**: 配置マップ B群のまま維持。
- **Ch1 の訴訟 (EP-031) の処置 (まさ指摘2への回答)**: 削除しない。(i) 遡行の正式な一段に格上げ — 現状も時系列は正しい遡行なのに太字ラベル (【設立三周年】等) がこの段にだけ無いのが唐突さの正体。**【受賞の年】等のラベルを与えて逆年表の一段にする** + 観察 (違和感①②③) から記憶 (訴訟) へ移る瞬間に柏木が輪を離れる身体動作を挟む。(ii) 理論側 (1.5節・図1-1 死因欄) は最後まで触れない — 「誰も触れない一件」の共犯に本の構造自体がなる、意図した作法。(iii) 完全版 (官庁ビート強め、EPISODE_BANK 温存分) は Ch7 新 Box「追い風は、無償ではない」(Box7-2 の対) 候補。

## 5. 新章「CEO という難問」(仮題) — まさ確定 2026-07-12

- **動機**: FRL/CEO を正面から論じる章が Book A に不在 (全章 grep 確認済み。近いのは Ch5 HRL 軸と Ch6 F-CES のみ)。CEO 問題の実話が 10件級 (EP-003/009/016/017/018/019/025/026/027/037) 宙に浮いていた。
- **位置**: Ch13 (円卓) の直後 — 「円卓を組んだ。では、誰が背負うのか」。**章番号の最終付番・Ch14/15 起草ワーカーとの調整・PF-014 (TOC v1) の改定記帳は司令塔マター。**
- **型**: 標準型 (章頭+was→therefore) ではなく「**問いの連なり×実話**」の変奏章。本の中で最もエピソード密度が高く、最も人間の話をする章。骨子案: ①CEO に求められるものは時期で変わる (Before Zero→ゼロイチの通時変化) ②制度は先生を起業家に仕立て、市場はそれを否定する (支援の局所最適化) ③CEO は機能の束として分割できる (Ch6 6.7 の式を実務へ) ④ただし分割できない一枚がある — エバンジェリスト機能 (愛情の総量は外注できない) ⑤CEO は育てられるか (三年条項の消滅=育った実例 / 早すぎた返却=失敗例の対) ⑥肩書だけの CEO — 権限なき責任という最悪の配置 ⑦解: Before Zero からゼロイチまで一気通貫の経営機能供給。
- **AMD の価値の書き方 = a案 (まさ確定)**: 本文では「一気通貫の経営機能供給」を理論の帰結 (Ch1 1.2「通しで見届ける席が制度側にない」への解) として**一般形**で立て、スタートアップスタジオ / EIR / 経営人材プールと比較して論じる。業務委託型支援の構造的弱点 (EP-018/019/026) も正直に書く。筆者の実践は序章・あとがき・Ch15 著者性 Box で種明かし。固有名は本文に出さない。
- **Ch6 との棲み分け**: Ch6 = 式 (F-CES の静学。6.5〜6.7 は動かさない)、新章 = 人 (変数を現実にどう埋めるかの問答)。相互参照で結ぶ。

## 6. Ch1〜9 の再推敲タスク

- **Ch1** (サンプル先行): ①訴訟の遡行ラベル化+転調の身体化 (§4)。②「三つの違和感」を「三つの違和感+**違和感と数えられなかった四つ目** (白衣の代表 = F)」に組み直し、1.5節の四変数回収 (S₀/ι/I/F) と照応を締める。③「一瞬・間」系 3連発の解消 (「半拍おくれた拍手」は正用として残し、相づちの硬直・視線の泳ぎは別の技法で書き分ける)。④開幕・幕引き・逆年表・図1-1 は現行構造を維持。
- **Ch2〜8** (共通): 開幕統一 (§3) / 設計表の装置・幕引き・季節への整合 (Ch3 幕引き移動・Ch4 部屋比喩の整理・Ch5 メモ装置化・Ch7 風景幕引き、Ch3〜7 への季節の書き込み) / である調変換 (PF-020、N と1パス統合)。
- **Ch9** (正本化済み、局所推敲 3点): (a) 顧問の「年配者の一撃」が Ch6 委員と同型 — 瀬戸の秘密 (返信の途絶を知っていて言えない) を主役化し顧問を一段引かせる。(b) 「それが何なのかを確かめる前に、議論はもう次へ進んでいた」が Ch1 とほぼ同文 — Ch9 側を変える。(c) 幕引き「答えを持っていなかった」が同型 — 秘密の絵で閉じる。
