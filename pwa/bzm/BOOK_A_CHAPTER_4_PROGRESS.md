**4.0 一兆円が、一円の価値も持たなかった——大きすぎる市場と、小さすぎる市場** (1,800字)

**4.1 天井という考え方——P は何を測るか** (1,500字)
第3章で組んだ地図 $E[V] \approx P \times R \times S$ を recap として一度だけ示し (再導出しない)、三因子のうち本章は最初の $P$ に集中すると宣言。第II部の行程表を一段落 (天井 P = 本章 / 到達 R = 第5章 / 生存 S = 第6〜8章 / 統合と律速診断 = 第9章 / 進む・待つ・止めるの判定 = 第10章)。P の定義 = 潜在規模: このシーズが最大限うまくいったときに到達しうる経済的インパクトの天井。中身は三つの要素——**狙う市場の規模** (その課題に世の中が支払っているお金の総量) × **その市場で到達可能なポジション** (競合・代替手段・価格の中で現実に取りうる位置) × **波及市場までの射程** (最初の用途の先に同じ技術が展開しうる隣の市場)——の言葉の積 (概念構成、形式式にしない)。第三要素「波及射程」が章後半の主役になる、と伏線。第3章 3.5「DCF が測っていたのは、天井だけ」の回収: 設立前のシーズについて DCF・精緻な事業計画が測ろうとしていたものの正体は P そのもの——本書はこれを否定でなく役割分担として引き受ける。**P は大風呂敷の大きさを測る。その大風呂敷が実現するかどうかは、R と S が測る**。1兆円スライドが機能しなかったのは数字が嘘だったからではない——P の話しかしておらず、しかも P の話としてさえ証拠が足りなかったから (章の主題宣言)。本章の二運動の予告: 前半で天井の測り方 (証拠の質) を作り、後半で天井そのものを動かす打ち手 (書き換え) を扱う。

**4.2 市場規模はどう測られてきたか——TAM・SAM・SOM と推定の二方向** (1,450字)
礼法 (第1〜3章と同型——批判でなく射程の確認「この道具は、何の存在と、どんなデータを前提に働くか」)。市場規模の議論の三層の用語: 表4-1 = TAM (狙う市場の総規模) / SAM (自分の製品・チャネルで現実に届きうる範囲) / SOM (競合・価格・生産能力を踏まえて現実に取れる規模)——1兆円スライドの例で言うと、の列つき (p-potential の表を再構成)。推定の二方向: トップダウン (大きな市場統計に比率を掛けて絞り込む) / ボトムアップ (想定顧客の数 × 一顧客あたりの支払額を積み上げる)。新製品が市場に浸透していく時間経路を描く道具として拡散モデル (Bass 1969) を名指し + S字カーブの直感一文のみ (式は出さない)。礼法の締め: これらの道具は、市場と製品カテゴリが既に存在し、参照点 (類似製品の実績・顧客の現行支出) がある場面では今も最良。冒頭の投資家の問いも、実はこの標準語彙の要求だった——「TAM ではなく、SAM と SOM を示せ」(読み替えの先出し。何が欠けていたかのフル回収は 4.4)。問題は、会社になる前のディープテックでは、参照点の側がまだ薄いこと——次節へ。

**4.3 TAM は最も盛られやすい数字——安くて、見栄えがして、反証が遅い** (1,650字)
but 節。結論先出し: 市場規模は、スタートアップ評価の中で最も「盛られやすい」数字。構造的理由が三つ——第一に**安いから** (調査会社のレポートから大きな数字を引用するのは数時間の作業で、出典が立派なので反論されにくい。SOM を示すには顧客の特定・支払額・競合・価格の分析で何か月もかかる)。第二に**大きいほど見栄えがするから** (ピッチの場では市場の大きさが野心の証明のように扱われ、小さい数字を出す動機が誰にもない)。第三に**検証が遅れて来るから** (市場規模の主張の正否は事業化の何年も先にしか分からない。その場で反証されない数字は膨らみ続ける)。ディープテック特有の増幅を一段: 用途がまだ確定していないシーズは「原理的には、あらゆる〜に使える」と言えてしまう——章頭の「原理的には、この市場の全体が対象になりえます」という答えは、この構造の実演だった。帰結: 評価の現場で案件を並べると、大半の案件の市場規模が「中〜大」に張り付き、**数字としての判別力を失う**。どのピッチ資料にも数千億円から兆円の市場が書いてある——書いてあるという点では全案件が同じで、差がつかない。主張された市場規模の大きさは、P の観測値としてほとんど機能しない。締め: 大きさを主張する競争では差がつかないなら、必要なのは大きさではない別の軸——評価の発想を切り替える (4.4 へ)。

**4.4 大きさではなく、証拠の質で刻む——三つの物差し** (2,200字)
therefore①・本章の核心 rubric。発想の切り替え宣言: 主張された市場規模の「大きさ」ではなく、天井の「証拠の質」で刻む。**第一の物差し = 第三者データの裏付け**: 市場規模の主張が独立した情報源で裏付けられているか。効くのはトップダウンとボトムアップの**両方を作って突き合わせる**こと——トップダウンだけの数字は掛ける比率しだいでいくらでも作れる。ボトムアップが同じ桁に着地して、はじめて天井の輪郭が信用に足る。**第二の物差し = スケール時のユニットエコノミクス**: 1単位あたりの採算。研究シーズ特有の罠 = **ラボで作るコストと、量産したときのコストは別物**。実験室で一平米数十万円かかる膜は、量産でいくらまで下がるのか、その根拠は何か (材料費の下限・工程の簡略化・歩留まりの見込み)。顧客の支払上限の根拠と両方揃うか。スケール時に採算が成立する根拠を示せない市場規模は、原理的に到達できない天井を語っている。**第三の物差し = 天井に至る経路の具体性**: 最初の用途はどれか、最初の顧客は誰で、その購買を決める評価条件は何か、規制・認証は絡むか、二番目・三番目の用途への接続は説明できるか。経路のない天井は、対岸の蜃気楼と同じ。表4-2 = 三つの物差しの弱い主張・強い主張の対比 (素材の表を再構成: 「調査レポートのトップダウン数字を引用するのみ」vs「トップダウンとボトムアップが同じ桁で突き合う」等)。図4-1 = TAM/SAM/SOM の同心円に証拠の質の階段を重ねる (外側ほど数字は大きいが証拠が薄く、内側ほど数字は小さいが証拠が濃い——1兆円スライドは最外周だけを指していた、の視覚回収。本章の看板図版)。規律の明記: 三つの物差しは**順序尺度** (弱い・中間・強い、の順序だけを持つ物差し)——数値の点数化や閾値はここでは導入しない (三因子を共通の物差しに載せる作業は第9章)。この物差しで章頭の面談を読み直す (小さな worked example): 1兆円という数字 (第一の物差しの半分) はあった。しかしボトムアップの突き合わせがなく、量産時コストの根拠がなく、最初の顧客への経路がなかった。投資家の無表情は、技術への失望ではなく、**天井の証拠がゼロであることの確認**だった。処方もはっきりする: 1兆円のスライドを捨てる必要はない。その内側に、SAM と SOM を、三つの物差しの証拠つきで刻み込むこと。では、実際にそれをやるとどうなるか——面談室に戻ります (4.5 へ)。

**4.5 二度目の面談——変わったのは、数字ではなく証拠** (1,350字)
B面回収 (中盤・物語の谷・数式ゼロ)。p-potential 原文に「その後」の場面はないため、控えめな新規設計とする。担当者と研究者が次の面談までに用意したもの: 1兆円スライドは捨てない——その内側に、対象の工程・地域・規制区分で絞った範囲 (SAM) / 想定顧客の数と現行支払額から積んだボトムアップとの突き合わせ / ラボ一平米のコストと、量産時の下限の根拠 (材料費・工程・歩留まり——まだ粗い見込みは「見込み」と明記) / 最初の顧客候補と、その購買を決める評価条件・認証の有無。二度目の面談: 投資家の四つの問いに、分からない点は分からないと言いながら、経路のある答えが返る。会話は前回と違って具体的に進む。**数字は大きくなっていない——正直に刻んだ天井は、むしろ1兆円よりずっと小さい。変わったのは、証拠**。討議課題Aの答え合わせ: ①用意すべきだったのは、より大きな数字ではなく、三つの物差しの証拠 ②投資家の四つの問いは、三つの物差しそのものだった (最初の顧客と支払 = 経路とボトムアップの種 / ラボと量産のコスト = ユニットエコノミクス)。トーン規律: 成功譚にしない——出資や契約の成立は書かず、「話が具体的になった」水位で止める。末尾に二つの問いを立てて後半へ: 証拠の揃った天井も、掛け算の一因子にすぎないのではないか (→4.6)。そして——そもそも天井は、固定の量なのか (→4.7)。

**4.6 天井は、掛け算の一因子である——止まる天井と、落とすべき天井** (2,000字)
therefore②・積の両側の押さえ。**一方の側: 天井が大きくても、事業は止まる**。$E[V] \approx P \times R \times S$ は積——どれかが低ければ全体が低い (第3章 3.6「弱い軸が全体を強く引きずり下げる」の読みを一文で再演。「ゼロなら全滅」とは書かない)。第3章の断熱素材案件 (P高・R低) を**同一の合成事例の継続**として一段落で回収: 天井の証拠がどれだけ揃っていても、自分たちの手で作れる技術への翻訳 (R) が動かなければ、天井には届かない。評価の場で「市場は巨大です」に頷きそうになったら、同じ熱量で「で、いまどこまで来ていますか」と問う——「研究室で作れる」と「自社で作れる」の区別と R の測り方は第5章、走り切る力 S は第6〜8章。P の大きさに見とれて R と S の議論を飛ばすのは、宝の地図だけ眺めて船の点検をしないのと同じ。**もう一方の側: 天井そのものが低い案件は、生存以前の問題**。評価の現場では「やる気のあるチームをどう支援するか」に意識が向き、「この案件は天井で落とすべきだ」という判断は心理的に下しにくい。しかし P には、努力や生存とは独立に案件を止めるべき場合が存在する。典型は**原理的にコストが市場価格に合わない**場合——物理法則や材料のコスト構造に根ざした下限が、顧客の支払える価格を上回っているなら、その天井は努力では持ち上がらない (抽象類型として叙述し、特定の事例は描かない)。チームがどれだけ長く生き延びても (S が高くても)、届く先の天井が低いままなら、掛け算の答えは小さいまま。落とす判断の根拠を「原理に根ざすコスト下限」という形で文書化できたなら、それは冷酷な切り捨てではなく、評価として誠実な仕事 (判定の運用 = 第10章)。**但し書き = 低さの二種類** (表4-3): 原理に根ざす低さ (熱力学的な効率の上限・材料そのもののコスト下限・物理的に縮まらない距離——戦略では動かない) / **用途の選び方に根ざす低さ (動く)**。そして実際の現場で出会う「市場が小さい」の多くは後者——章頭の二つ目の相談を思い出してください、の一文。2読み方式の先出し (数文のみ・式や表にしない): 支援会議で「あの案件は頑張っているのに評価が低い」という声が出たら、それは運用の巧拙 (その案件が自分の天井に対してどこまでやれているか) と、配分の優先順位 (天井の絶対の大きさ) の混同——この二つの読みは別々の仕事をする。使い分けの正本は第14章 (シーズごとに正しいサイズの成功を扱う章)。締め: 動く低さなら、どう動かすか——次節。

**4.7 天井は動く——P は戦略の関数である** (2,250字)
therefore③・数式フル節 (直感→式→worked example)。学術的異論から入る: ここまで P を、あたかもシーズに備わった固定の量のように扱ってきた——この扱い自体に、アントレプレナーシップ研究から強い異論がある。機会というものは、地面に埋まった金塊のように最初からそこに在って「発見」されるのを待っているのか、それとも起業家が手持ちの手段から「創造」するものなのか (機会発見観 vs 機会創造観、Alvarez & Barney 2007——第3章 3.1・3.8 で「一文の名指し」に留めて預けた立場問題を、ここで回収)。熟達した起業家の行動研究が示すのは、固定された市場の期待値を計算して動くのではなく、手持ちの技術・人脈・知識から出発して市場そのものを作り出していく姿——用途転換やピボットによって、天井は事後的に書き換わる。本書の立場: この批判を**部分的に正しいものとして受け入れ、P の定義を一段階拡張する** (創造観の全面採用ではない——「書き換えとは証拠を作り直す作業」という規律で創造観を律する)。直感: いま見えている使い道の中で、いちばん大きな天井が、その時点の天井。式: 時点 $t$ に見えている応用候補の集合を $U(t)$、候補 $u$ ごとの天井を $P_u$ として、$$P(t) = \max_{u \in U(t)} P_u$$ 式後の読み下し: max は「最大をとる」——いま**見えている**応用候補のうち、最も大きな天井が、その時点の P (「見えている」の条件付けが本質: まだ誰も言語化していない用途は、天井に入らない)。含意: 応用候補の集合 $U(t)$ を広げる行為——用途の探索、産業文脈の読み替え、隣接市場の調査——は、**それ自体が P を引き上げる経営の打ち手**。P は測るものであると同時に、戦略の関数。4.1 の第三要素「波及射程」が、ここで動かせる量になる (回収)。図4-2 = P(t) の階段グラフ。処方の順序 (現場の定番の行き詰まりへ): 「市場が小さくて、買い手が本気にならない」——単一用途で年間数億円の市場は、大きな事業会社から見れば担当者一人の片手間案件で、その状態で条件交渉に臨んでも本気の交渉が始まらない。交渉のテクニックを磨くのは順序が違う——**交渉の前に、P を書き直すのが先**。天井を、買い手が本気になる大きさまで証拠つきで書き直してから、交渉の土俵に乗る (交渉の力学と「絵を大きくするのが先」の本論は第8章)。worked example = 第3章の計測装置案件 (P低・R高) の継続: 表3-4 が残した「次の問いは『P を書き換えられるか』」の宿題をここで解く——装置の能力を、いまの用途 (特定分野の計測) ではなく機能 (何を・どんな環境で・どれだけ精密に測れるか) の言葉で言い直し、隣接産業の検査・監視・品質管理の支出に当てて候補を書き出し、候補ごとに三つの物差しを粗く当てる (数値は出さず、読みの手順として示す)。Box 4-1 = **書き換えは、言い換えではない** (引用ブロック・読み飛ばし可能な独立設計): 新しい用途を主張するなら、その用途について三つの物差し——第三者データ、ユニットエコノミクス、天井への経路——を最初からやり直す。証拠のない用途を十個並べても U(t) は広がっていない。広がったのはスライドの行数だけ。表4-4 = 天井の三つの顔 (統合): 止まる天井 (断熱素材型 = P高R低、次の一手は R) / 落とすべき天井 (原理起因型 = 文書化して止める) / 書き直せる天井 (計測装置型 = 用途の横展開)——表3-4 の P レンズ継続。締め: 章頭の二つ目の相談 (数億円と言われたロボット) の答えは、この節の道具でもう出せる——ただし本文では解かない。演習4-2 で、あなた自身の手で天井を書き直してもらう (読者に手渡す)。そして天井の次は、そこへの到達——「技術はもうできています」という言葉が会議室で三通りに受け取られるとき、何が起きているのか。第5章 R へ。
