## 2. 先行研究との境界

### 2.1 Hsu–Schwartzが既に解いていること

Hsu and Schwartz（2003）は、研究品質、残り費用、完成時間、需要、段階的な続行・放棄を持つR&D価値モデルを示した。

費用補助と購入保証が会社の継続境界を変え、結果として研究開始、次段階進出、成功率を変える構造も実装している。

条件付き継続価値は、Longstaff and Schwartz（2001）の最小二乗モンテカルロで近似する。

したがって、次をBZM独自理論と主張しない。

- リアルオプション一般。
- 動的計画法またはBellman後退。
- 段階的な続行・放棄。
- 残り費用と完成時間の不確実性。
- 品質情報の更新。
- 最小二乗モンテカルロ。
- 支援契約が継続境界と成功率を変えること。
- 会社価値と公的費用・便益を分けること。

Hsu–SchwartzはHJB方程式または連続時間PDEを解いていない。

三つの期境界における続行・放棄を後ろ向きに解く最適停止モデルである。

### 2.2 Hsu–Schwartzに無いもの

- WAIT、再試行、ピボット、縮小、拡張、ライセンスの多行動。
- 正の撤退・転用・IP売却価値と負の閉鎖費用。
- 現金残高、資金調達、希薄化、資金の崖。
- 行動が速度、品質、需要遷移を変えるintensive margin。
- 単一権限主体が選んだ同一方針を、会社、BZSF、公的基金の三視点から再評価する入力契約。
- 情報締切、証拠、欠測、版、後知恵防止。
- 複数PJの資源競合、相関、共通設備。

ただし、これらもリアルオプション、MDP、VC契約、技術経営の広い先行研究に部分的な先例がある。

BZMの候補貢献は、Before Zeroの共通到達境界、二つの時計、権利、資金、証拠、欠測、版、実行権限を、少数PJで再現できる入力契約へ接続する適用設計に限定する。

世界初という主張は、新規性調査が終わるまで行わない。

## 3. 理論P0監査

### 3.1 閉じた項目

| P0 | 反例または問題 | 2.1での閉じ方 |
|---|---|---|
| 評価視点と権限 | BZSFや基金が会社行動を単独で選べない | 視点$r$と権限主体$d$を分離 |
| 公的目的 | 財政費用と社会厚生を一つへ合成できない | 財政価値と社会厚生ベクトルを分離 |
| Bellman契約 | 固定方針と選択方針の次期価値が曖昧 | $V^\pi$と$V^*$、終端境界を別に定義 |
| 価格測度 | 実世界確率と価値評価確率が混ざる | 到達用$p^{\mathbb P}$と価値重み$w_r$を分離 |
| 到達時計 | 終端ラベルだけでは到達後M&Aを落とす | $T_C$のfirst-passageを履歴に保存 |
| 未到達時計 | $+\infty\le+\infty$で初期状態が失敗になる | $T_Y$有限条件と同着規則を明示 |
| 固定方針 | 2.0計画がoff-pathを定めない | 完全方針でなければ$V^{\pi_0}$と柔軟性価値を停止 |
| 同率解 | 同価値でも$q$が違う | 事前tie-breakまたは$q$範囲 |
| 推定誤差 | point maxが上振れ誤差を選ぶ | 感度で入替なら`decision_indeterminate` |
| 行動集合 | 8動詞が同時実行を表せない | 基本型と実行可能行動束を分離 |
| 資金調達・交渉 | ライセンス・調達を一方的終端にできない | 交渉、提案、受諾を行動・遷移化 |
| WAIT | 情報価値だけ置くと常に有利になる | 燃焼、期限、信用、機会損失を同時計上 |
| 費用 | 2.0価値と2.1価値で二重控除しうる | event IDつき単一CF台帳 |
| サンクコスト | 過去支出が続行判断を歪める | 履歴表示だけにし将来比較へ再投入しない |
| 支援 | 観測差を因果効果と誤認する | `model_implied_contrast`へ限定 |
| 会社価値 | PJ NPV、企業価値、株主価値が混ざる | 最小版を会社保有PJの正味増分価値へ限定 |
| BZSF価値 | 他PJ機会費用を単独PJとportfolioで二重控除 | 単独PJ証券CFとportfolio影価格を分離 |
| 選択肢被覆 | 未知行動を落として最適と呼ぶ | `partial_action_set`と閉じた集合内最適を分離 |
| Goodhart | 配分利用で入力・行動列挙が歪む | shadow運用と採否・逸脱・評価者ログ |

### 3.2 理論判定

**BZM 2.1理論仕様は条件付き通過とする。**

BZM 2.0の固定方針到達見込みを保存したまま、閉じた単一権限主体の行動選択、経路別正味価値、物理確率による到達見込みを同一遷移グラフ上で接続する最小契約は、P0反証監査を通過した。

通過対象は内部整合性と主張境界だけである。

実装、測定、予測、因果、配分の妥当性を含まない。

| T14 | Hsu型の続行・放棄へ縮約すると手計算解に一致 | 通過 |

### 4.2 合成テストの主張境界

合成テストの数値は架空である。

算術と状態遷移の契約だけを確認し、実PJの予測精度、企業価値、投資収益を表さない。

独立コード監査では、近接しているが価値が異なる行動へtie-breakを適用すると、固定方針より価値の低い行動を選び、権限主体の柔軟性価値が負になりうる反例を検出した。

実装を修正し、厳密同値だけをtie-break対象とし、非同値のnear tieは`decision_indeterminate`で停止する回帰テストを追加した。

同じ再監査で、CFの各計算区分は根拠つきeventまたは根拠つき明示0を必須とし、介入IDと遷移確率差分の重複、介入後のWAIT契約違反、範囲外の到達確率、許容差を超える負の柔軟性価値を計算前に停止することも確認した。

この修正後の再監査ではP0を検出しなかったため、最小算術エンジンを`implementation-prototype conditional pass`とする。

## 5. 役割別の残存P1

### 5.1 経済学・金融

- 価格づけ方式を実PJごとに閉じていない。
- 遷移、費用、価値の外部参照クラスが無い。
- 支援あり・なしの差を因果識別していない。
- 未選択行動の反実仮想を単独PJ履歴から識別できない。
- 公的価値は外部で換算済みの単一額を受け取る最小実装であり、財政価値、社会便益、移転相殺を内部計算しない。

### 5.2 経営学

- action availability、遷移、価値の評価者間信頼性が未測定である。
- 組織が数学上の方針を実行できるかを前向きに検証していない。
- 行動列挙数によるoptimizer's curseとunpacking effectを実測していない。
- 同じ経済問題のnode split/merge不変性を実PJで検査していない。

### 5.3 経営者

- 通常の会議・文書から更新できる入力密度か未確認である。
- 必要現金、最悪損失、不可逆点、見直し条件を実PJ画面で運用していない。
- まさ一人へ大量質問せず維持できるか未確認である。
- 資金制約は総必要額と確保額の比較までで、時点別現金残高と資金の崖を内生的に解いていない。

### 5.4 産学連携

- LSTを含む大学由来PJで、帰属連鎖、FTO、field、territory、独占、再許諾、diligence、解除、返還、COI、輸出管理を閉じていない。
- 交渉開始と拘束力ある権利を分けた実データが無い。
- 相手方受諾確率の参照クラスが無い。

### 5.5 VC・BZSF

- 証券別ウォーターフォール、希薄化、支配権、フォローオンを閉じていない。
- 共通予算、人員、相関、集中、ファンド期限を持つportfolio層が未実装である。
- shadow運用前であり、投資額推薦に使えない。

## 7. 2.1で新たに可能になった判断

入力が閉じた場合、次を同じ経路グラフから比較できる。

- 固定計画を続けた場合と、判断時点で方針を変えた場合の正味価値差。
- 続行、WAIT、再試行、ピボット、縮小、拡張、ライセンス、撤退の行動別価値。
- 行動によって変わる資本自立到達見込み。
- 価値は上がるが資本自立到達見込みは下がる早期ライセンス等の経路。
- 必要資金、失敗損失、撤退・転用価値を含む継続境界。
- 同じ選択方針を会社、BZSF、公的視点から別々に評価すること。
- 費用補助、購入保証、資金支援が、費用・必要資金・遷移確率を通じて方針と到達見込みを変える最小モデル内シナリオ。

## 8. まだ計算できないもの

- SXとLSTの動的正味価値。
- 実PJの閉じた行動集合内の選択方針。
- BZSF取得証券の投資価値。
- 公的社会便益を円へ集約した価値。
- 支援による行動集合、所要時間、情報獲得の変化を含む動的価値。
- 時点別資金残高と資金の崖を内生化した動的価値。
- 支援の因果的な$\Delta q$または$\Delta V$。
- PJ間の比較順位。
- BZSFの投資額と資源配分。
- 市場で観測される時価総額。

## 9. 前向き検証が必要な主張

- 行動条件付き遷移確率が校正される。
- BZM 2.1の選択方針が専門家または固定計画より意思決定損失を減らす。
- WAIT、支援、撤退の価値が実績上の選択と成果を改善する。
- PJ間で共通化した値が比較可能である。
- shadow運用で入力誇張または行動列挙の歪みが管理できる。
- BZSFのportfolio制約下で純便益と下方損失を改善する。
