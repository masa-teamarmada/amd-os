### 進化経済学が Before Zero 局面で扱えていないこと

進化経済学は確立した枠組みのなかで、Before Zero 局面に固有の 4 つの構造を扱えていない。第一に法人化以前 (pre-firm formation): 単位を firm に置くため、法人格成立以前の創業者-案件二者対は分析対象外で、その時期の選抜が後段の産業動学を決めるという Klepper 遺産説の前段が空白になる。第二に委譲不可能な核としての創業者性格: Nelson-Winter は技能=ルーチン=組織内で移転可能と置くため、F_char が個人に錨で固定されており委譲不可能であるという BZ 段階の事実を表現できず、CES ρ<0 の補完性で形式的に書けない。第三に二層の非可換性: 単一スカラー適応度が前提のため、案件適応度 (乗法的 PRS) と選抜環境苗床整備度 (加法的 ERS) を別レイヤーに分けて非可換に保つ必要性を欠き、両者を産業レベル選抜に押し込めてしまう。第四に B 起動レジーム切換え: Jovanovic の到達時刻は単一レジームでの学習に閉じており、燃焼率 B が立ち上がる瞬間に選抜環境そのものが再定義される 2 次元ジャンプ拡散レジーム切換えを扱えない。これら 4 点は進化経済学を否定するのではなく、その射程の外側にある BZ 段階固有の構造であり、BZM が親フレームワークを継承しつつ拡張すべき領域である。

### BZM が進化経済学から継承する点 (継承表)

- 集団レベル骨格としての選抜・変異・継承の三項: BZM は集団レベルの論理を継承するが、「選抜環境」を ERS (8 軸加重和) として、事後的な firm 生存率ではなく制度的基層の苗床層の整備度状態として再配置する。
- σ_SU = Triple Helix CD(μ_A, μ_I, μ_G) の形式的基礎付けとしての共進化 (Murmann 2003, Nelson-Winter の制度埋め込み): 制度と案件は速度を共同決定する。BZM は共進化の主張を保持しつつ、産業レベルの歴史的叙述ではなく案件速度に対するマクロ追い風の乗数として操作化する。
- Pr(τ_x < τ_y) の形式的祖としての到達時刻/学習による選抜 (Jovanovic 1982)。BZM は生存に対する確率過程的扱いを継承するが、ジャンプ拡散の下で達成時刻 τ_x と余力枯渇時刻 τ_y の 2 次元レースとして再定式化する。
- F_cap (経験順序、委譲可能) の概念的祖としての複製子=ルーチン (Nelson-Winter)。BZM は能力側のルーチンが移転可能で累積的であることを受け入れる — その部分はそのまま保持する。
- R-バンドル内の TRL の祖としての技術パラダイム/軌跡 (Dosi 1982)。BZM は技術が構造化された軌跡に沿って展開するという Dosi の主張を保持しつつ、R = TRL × BRL × GRL × SRL × HRL の内部の整備度水準に離散化する。
- そもそも GO(t,i) のタイミングがなぜ重要かについての記述的背景としての産業ライフサイクル参入/退出タイミング (Klepper 1996, 2002)。BZM は参入タイミングが決定的であるという主張を保持するが、集団密度による説明を σ_SU 上の最適停止閾値 θ_σ* で置き換える。
- ERS の多軸整備度分解の祖としての Sectoral Systems of Innovation (Malerba 2002)。BZM はマルチアクター・マルチ制度のアーキテクチャを保持しつつ、それを叙述的事例研究ではなく 8 つの加重軸に定量化する。
- 不可逆・非均衡・経路依存的過程に適した方法論としての進化的方法論 (Witt 2008, Metcalfe 1998)。BZM は同じ方法論的立場にコミットする: 閉形式均衡は目標ではない。確率過程とレジーム構造こそが目標である。

### BZM が進化経済学を超える点 (離脱表)

- 離脱 1 — B 起動時点での τ_x のレジーム切換え (Jovanovic 1982 の拡張)。Jovanovic の到達時刻は単一レジーム下で動き、定常的な選抜の下で firm が生産性 θ を学習する。BZM はタイムラインを B 起動時点 (燃焼率 B が起動する瞬間) で分割する: B 以前は、創業者は無燃焼レジームで動き、生存は F_char の耐久性のみによって境界づけられる。B 以後は、B が y (余力) への決定論的なドレインを導入し 2 次元ジャンプ拡散レースを生むため、選抜環境が再定義される。これは Jovanovic の単一レジームモデルでは表現できない BZ 段階固有の構造である。反証可能な予測: σ_SU が θ_σ* を下回って B を越えるコホートは、事前の θ をコントロールした上で τ_y < τ_x の発生率が測定可能な形で高まる。
- 離脱 2 — ρ < 0 の CES 内における委譲不可能な核としての F_char (Nelson-Winter のルーチン=技能観 1982 からの離脱)。Nelson-Winter は技能をルーチンとして、組織内に貯蔵され、移転可能で、メンバー間で複製可能なものとして明示的に扱う — これがルーチンを「遺伝子」として扱うことの全要点である。BZM は Before Zero 局面についてこれを否定する: F_char (ALQ4 + Grit + Resilience) は創業個人に錨で固定されており、雇用人員や制度的ルーチンに再割当てできない。ρ = -2 (強い補完性) の CES は「委譲不可能」を形式化する: F_cap は、どれほど高くても、欠落した F_char を代替できない。これは Beckman / Roberts / Eesley の創業者チーム文献に対して明示的に検定可能である — BZ 段階の成果について、創業者 F_char プロキシが創業者チーム能力指標を支配することを予測するが、Nelson-Winter のルーチン理論は逆を予測する。
- 離脱 3 — 二層の非可換性 (PRS × ERS を単一スカラーとして禁止) は Nelson-Winter の集団レベル選抜の BZ 段階版洗練。Nelson-Winter は firm の適応度を、産業レベル選抜環境の内部で競争する一つのスカラーに縮約する。BZM は Before Zero 局面ではこの縮約を禁ずる: PRS (案件適応度、乗法的 P × R × S) と ERS (選抜環境整備度、8 軸の加重加法) は別レイヤーに留まらなければならない (Ch 9 非可換性定理)。理由は構造的である: いずれかの因子がゼロ (チームなし、市場なし、権利なし) になれば案件は死ぬから PRS は乗法的であり、苗床整備度は代替可能な支援のポートフォリオであるから ERS は加法的である。両者を掛け合わせると非両立な代数構造を混ぜることになる。反証可能な予測: 単一スカラー適応度モデル (Nelson-Winter 型) の経験的当てはまりは形成前コホートで急激に劣化し、PRS 乗法的/ERS 加法的構造をもつ二層モデルは、BZ 段階の到達時刻成果について純乗法的・純加法的いずれのベースラインにも勝る。
- 横断的離脱 — BZM は法人化以前を扱う。進化経済学 1982-2010 は firm を選抜の単位として取る。BZM は解析全体を、firm が法的に存在する以前にまで上流に移す。そこでは関連単位は苗床 (学界 + 産業 + 政府) に埋め込まれた創業者-案件二者対であり、選抜は既存 firm が生存するか否かではなく、資金供給可能な実体が結晶化するか否かに作用する。

## 2. BZM の進化経済学への 3 寄与 (形式的/反証可能)

各寄与は (i) 一行主張、(ii) 形式記述、(iii) 導出の素描、(iv) 予測する経験的パターン、(v) 反証検定、(vi) 進化経済学既存処理、(vii) BZM 特有の追加、(viii) 想定批判 を含む。

### C1_regime_switch_tau_x: Before Zero 局面の創業者-案件二者対の生存は、Jovanovic (1982) 型の単一レジーム到達時刻選抜ではなく、B 起動 (法人化燃焼率起動) を境に選択環境そのものが不連続に切り替わる 2 次元レジーム切換えジャンプ拡散上の Pr(τ_x < τ_y) として形式的に書ける。

**形式記述**:

状態変数を (x_t, y_t) と置く。x_t は達成 (R = TRL × BRL × GRL × SRL × HRL バンドルから合成される整備度、x ∈ [0, x̄])、y_t は余力 (戦略的スラック)。レジーム指示子 I_t ∈ {pre, post} は B 起動停止時刻 τ_B で pre → post に切り替わる。

Pre-B (t < τ_B):
  dx_t = μ_x^{pre}(σ_{SU,t}) dt + σ_x dW_t^x
  dy_t = (R_net - C_res) dt + σ_y dW_t^y + dJ_t^{grant}

Post-B (t ≥ τ_B):
  dx_t = μ_x^{post}(σ_{SU,t}, B_t) dt + σ_x' dW_t^x
  dy_t = (R_net - B_t) dt + σ_y' dW_t^y

ここで σ_{SU,t} = Triple Helix CD(μ_A, μ_I, μ_G)、B_t は法人化燃焼率、R_net は調達/助成純流入。

停止時刻: τ_x = inf{t : x_t ≥ x̄}, τ_y = inf{t : y_t ≤ 0}。成果は ψ(s_0; F, σ_SU) := Pr_{s_0}(τ_x < τ_y), ただし s_0 = (x_0, y_0, I_0)。

命題 (レジーム切換え非縮約性).
任意の単一レジーム到達時刻モデル M_J (Jovanovic 型、単一生成子 L_J) に対して、ψ_{BZM}(s_0; F, σ_SU) - ψ_{M_J}(s_0; F, σ_SU) ≠ 0 となる s_0 と (F, σ_SU) の開集合が存在する。具体的には、無限小生成子が

  L_{BZM} = 𝟙_{t<τ_B} L_{pre} + 𝟙_{t≥τ_B} L_{post},   L_{pre} ≠ L_{post}

という形を取り、L_{pre} と L_{post} の許容政策集合と y のドリフトの符号が異なるため、両レジームを単一 L に縮約すると Kolmogorov 後退方程式の解 ψ が厳密に誤特定される。

系 (反証可能な形).
Pre-B 期間長 Δτ := τ_B - 0 と Post-B 期間のハザード h_y^{post}(t) := lim_{δ→0} δ^{-1} Pr(τ_y ∈ [t, t+δ) | τ_y > t, I_t = post) は、Pre-B 期間のハザード h_y^{pre} と構造的分断を持つ: B - R_net > 0 のとき正の確率で h_y^{post}(τ_B^+) - h_y^{pre}(τ_B^-) > 0。

**導出の素描**:

ステップ 1. 選抜単位を firm ではなく苗床内の創業者-案件二者対と置き、状態を (x, y) の 2 次元に取る。x は整備度バンドル、y は余力。これは Jovanovic の単一生産性 θ からの二次元拡張であり、達成と生存を別軸に分離することが BZ 段階の本質。

ステップ 2. Pre-B レジームの SDE を書き下す。B はまだ未起動、y は研究費・GAP fund・PI 給与の複合 Poisson 流入と消耗の差で動く。創業者労働は無賃で投入され x を押し上げるが y をドレインしない。よって y のドリフトは条件付きで非負にできる。

ステップ 3. B 起動停止時刻 τ_B を導入。τ_B は内生的なリアルオプション最適停止 (Ch 5.5: σ_SU ≥ θ_σ* で起動) または外生的なラウンド/招聘の窓として発火する。成果の上では τ_B 自身が決定変数。

ステップ 4. Post-B レジームの SDE を書き下す。B_t > 0 は y への決定論的ドレインとして作用する。R_net - B_t < 0 のサブレジームでは y は確実な負のドリフトを持つ。Pre-B では同じ創業者労働が x を押し上げる投入だったのに対し、Post-B では燃焼率に内部化され y を押し下げるコストに転化する — これがレジーム切換えの経済学的中身。

ステップ 5. レジーム切換えの非縮約性を示す。Pre-B と Post-B では (i) μ_x の関数形 (創業者労働の限界生産性は post で逓減)、(ii) y のドリフトの符号、(iii) 許容政策集合 (ピボット/採用/解雇 が post で初めて利用可能) がすべて不連続に変化する。よって無限小生成子 L が連続でなく、単一 L に書き直せない。これは時間変換では吸収できない。

ステップ 6. 2 次元初到達問題として Pr(τ_x < τ_y) を Kolmogorov 後退方程式で特徴付ける:
  L_{regime} ψ(x, y, I) = 0  on (0, x̄) × (0, ∞),
  ψ(x̄, y, I) = 1,   ψ(x, 0, I) = 0,
  ψ(x, y, pre) - ψ(x, y, post) = I 切換え時のジャンプ条件。

ステップ 7. σ_SU の役割を確定する。σ_{SU,t} は μ_x^{pre} のドリフトと R_net への複合 Poisson 強度の両方を押し上げるマクロ追い風として入る。これにより Murmann (2003) の共進化が到達時刻に形式的に埋め込まれる。

ステップ 8. F の役割を確定する。F = CES(F_char, F_cap; ρ=-2) は (a) σ_x (達成のボラティリティ) を下げ、(b) Pre-B での y ボラティリティに対するレジリエンスを上げる。とくに F_char は τ_y の下側裾を厚くしない (ストレス下の耐久性)。これは Jovanovic の単一 θ には還元不能。

ステップ 9. 識別を明示する。τ_B は観測可能 (法人登記日)。Pre-B と Post-B のハザード比較は τ_B 周辺で回帰不連続的に識別できる: 創業者固定効果 + コホート σ_SU コントロールの下で h_y(τ_B^+) - h_y(τ_B^-) を推定する。

ステップ 10. 実証実装を明示する。サンプルは大学発シーズの (i) 法人登記前 GAP fund 採択コホート、(ii) 法人登記直後コホート。成果は次の funding round 到達 (τ_x の代理変数) と現金枯渇/解散 (τ_y の代理変数)。識別は σ_SU の地域変動 (Triple Helix 構造の自治体間差) を操作変数にする。

**予測する経験的パターン**:

- 予測 1 (τ_B でのハザード分断)。法人登記日 τ_B を境に余力枯渇ハザード h_y(t) が不連続に上がる。具体的には τ_B の前 90 日と後 90 日で h_y の構造的分断検定 (Chow / Andrews-Quandt sup-Wald) が棄却されない確率が、Pre-B の y 流入をコントロールした上でも 0 から有意に乖離する。Jovanovic 型単一レジームではこの分断は予測されない (単一 L のもとでハザードは連続)。
- 予測 2 (σ_SU × レジーム交互作用)。σ_SU が低い (Triple Helix CD が弱い) 地域・時期で τ_B を迎えたコホートは、σ_SU が高いコホートと比べて Pr(τ_x < τ_y) が不釣り合いに下がる。とくに Post-B の R_net - B が境界線上のコホートで交互作用が最も強く出る。Pre-B では σ_SU の影響は弱い (ドリフトにしか効かない)。
- 予測 3 (Pre-B 長さの非単調効果)。Pre-B 期間 Δτ が長いほど τ_B 時点での x_0 (post への初期条件) が高く Pr(τ_x < τ_y) が上がるが、Δτ が一定閾値を超えると創業者 F_char の消耗で σ_x が増え逆に下がる。よって Δτ と Pr(τ_x < τ_y) の関係は逆 U 字。これは Jovanovic の単調学習では出ない構造。
- 予測 4 (Pre-B の grant ジャンプ効果の Post-B 残存)。Pre-B 期間に受領した複合 Poisson grant ジャンプ (J^{grant}) は τ_B 時点の y_0 を底上げするだけでなく、Post-B での τ_y を有意に遅らせる (累積効果)。ジャンプ規模が経路依存的な成果を持つ点は単一レジームモデルでは生まれない。
- 予測 5 (τ_B における創業者チームの非代替性)。τ_B 直後に創業者 F_char プロキシ (ALQ4, Grit, Resilience) が低いほど、追加採用 (F_cap 増強) を行っても Pr(τ_x < τ_y) が回復しない。これは F = CES(F_char, F_cap; ρ=-2) の補完性のレジーム切換え交互作用。Nelson-Winter のルーチン移転観では予測されない。

**反証検定**:

この寄与を反証する経路は三つある。

第一: 法人登記日 τ_B 周辺で余力ハザード h_y(t) に構造的分断が観測されない場合。具体的には、日本の大学発シーズ・ディープテックコホート (例: NEDO STS / JST GAP / 大学 IP 起点) の登記前後 180 日の日次キャッシュポジションパネルを取り、Andrews-Quandt sup-Wald 分断検定を τ_B で実施。Pre-B の流入をコントロールした上で分断が有意に検出されない、もしくは分断の方向が逆 (Post-B でハザードが下がる) なら C1 の中核機構は反証される。

第二: σ_SU のレジーム条件付き交互作用が消える場合。σ_SU を Triple Helix 地理変動 (TLO 密度 × 投資家密度 × 行政 GAP 規模) で代理し、Pr(τ_x < τ_y) ~ σ_SU × Post_B + コントロール を推定する。Post_B との交互作用がゼロならば、σ_SU はレジームに依存しない単一の追い風であり、レジーム切換えの必要性は否定される。

第三: Pre-B Δτ と成果の逆 U 字関係が観測されず単調増加になる場合、Jovanovic 型学習モデルの予測 (長く学習するほど良い) と区別できず、F_char 消耗によるレジーム固有コストという C1 固有の構造が反証される。

データ要件: (a) 法人登記日 (商業登記から取得)、(b) Pre-B 期間の助成・受託・自己資金のキャッシュ流入時系列、(c) Post-B の月次燃焼率、(d) τ_x の代理変数として次ラウンド到達 / 製品出荷 / 治験開始、(e) τ_y の代理変数として解散 / 休眠 / キャッシュ枯渇、(f) 創業者 F_char 代理変数 (ALQ4 score, 過去の失敗記録, 学位取得後年数)、(g) σ_SU 地理パネル。N ≥ 800 二者対、観測期間 2014-2025 が最低ライン。

反証コストが現実的であること: 日本の大学発スタートアップ DB (経産省 / VEC / NEDO) と商業登記 API、INITIAL / entrepedia の funding history を結合すれば構築可能。

**進化経済学既存文献の処理**:

進化経済学はこの問題を二つの理由で扱ってこなかった。

第一の理由は選抜単位。Nelson & Winter (1982) 以降の主流は firm を選抜の単位に置き、firm が存在する前段 (苗床内の創業者-案件二者対) は枠外。Jovanovic (1982) も参入後の firm を対象に生産性 θ を学習する設定で、参入そのもののタイミングは外生的。Klepper (1996, 2002) の産業ライフサイクルも参入者コホートを観察するが、参入以前の選抜は扱わない。よって B 起動前後のレジーム構造は文献に位置を持たない。

第二の理由は単一レジーム前提。Jovanovic の到達時刻選抜は定常的な学習環境を仮定する: θ の真値は不変、事後分布が時間とともに精緻化し、profit が閾値を下回れば退出。この設定は単一生成子 L_J で書ける Markov 過程。Dosi (1988), Metcalfe (1998), Witt (2008) も経路依存性や新規性の出現を強調するが、選抜環境自身が決定論的な内部 trigger で不連続に切り替わる構造は形式モデルに組み込まれていない。

最も近いのは Murmann (2003) の共進化と Malerba (2002) の sectoral systems で、制度と firm が共進化することを示すが、これは産業レベルの歴史叙述であり、個別二者対レベルのレジーム切換えを到達時刻 SDE で書く操作はしていない。Saviotti & Pyka (2004) の多様性創出もセクター出現のマクロ動学であり、ミクロの τ_x / τ_y レースを扱わない。

要するに、進化経済学は (i) 選抜単位を firm に置く、(ii) 選抜環境を定常的に置く、という二つの暗黙の前提のために、B 起動前後のレジーム切換え到達時刻レースを扱う枠を持たない。これは進化経済学の誤りではなく、射程の外側である。

**BZM 特有の追加**:

BZM 固有の追加は四点である。

(i) 法人化以前期を独立レジームとして明示。選抜の単位を firm ではなく苗床内の創業者-案件二者対とする。これにより、法人格成立以前の選抜が後段の産業動学を決めるという Klepper 遺産説の前段が初めて形式的に書ける。

(ii) B 起動を決定論的なレジーム切換えとして導入。選抜環境そのもの (y のドリフト、ドレイン率、許容政策集合、x の可観測性) が不連続に切り替わるとモデル化する。Jovanovic は学習による事後分布の動学であり、BZM は環境の動学である。これは時間変換では吸収できない構造的切断。

(iii) 到達時刻レースの 2 次元化。τ_x (達成) と τ_y (枯渇) の競争を初到達問題として定式化し、Pr(τ_x < τ_y) を成果変数に据える。Jovanovic の単一生産性 θ ベースの退出ハザードを、達成と枯渇のレースに拡張。

(iv) σ_SU (Triple Helix CD) を pre-B レジームの x ドリフトと y への複合 Poisson 強度に乗るマクロ追い風とする。これにより Murmann (2003) の共進化が到達時刻枠組みに閉じ込められ、形式的に検定可能になる。マクロ共進化をミクロ成果に識別可能な形で接続する経路を提供する。

これら四点が成立して初めて、進化経済学の学習による選抜は Before Zero 局面に降ろせる。

**想定批判 (risks_and_objections)**:

- 異議 1 (τ_B の内生性)。査読者: 「τ_B は創業者が σ_SU と (x_0, y_0) を見て選ぶ停止時刻なので、τ_B 周辺のハザード分断はレジーム切換えの証拠ではなく selection bias である」。応答: τ_B が内生的であることは認める。識別戦略は (a) σ_SU の地理変動を操作変数にする、(b) τ_B を予測する創業者傾向スコアをコントロールする、(c) 外生ショック (制度改正による起業助成窓口) を自然実験として使う、の三段で攻める。とくに 2020 年の大学発スタートアップ支援強化 (NEDO STS 等) を疑似実験にできる。
- 異議 2 (レジーム切換えではなく単一の非定常モデルで書けるのではないか)。査読者: 「ドリフト μ_x, μ_y を τ_B の関数として連続に書けば、単一 L で書ける非定常拡散になる。なぜレジーム切換えを別建てにする必要があるのか」。応答: 許容政策集合 (ピボット、採用、解雇) と創業者労働の経済的意味 (Pre-B: 無賃投入 / Post-B: 燃焼に内部化) が不連続に変わるため、ドリフトだけ滑らかにしても観測されるハザード分断は再現できない。ステップ 5 の非縮約性論証を形式的証明で押し切る。具体的には L_{pre} と L_{post} が異なる定義域 (許容制御) を持つことが本質的。
- 異議 3 (F_char の測定不能性)。査読者: 「F_char (ALQ4 + Grit + Resilience) は事後的に合理化される構成概念で、経験的に Nelson-Winter ルーチンと区別できない」。応答: ALQ4 は事前測定可能なバッテリーで設計する (Ch 7 で詳述予定)。さらに予測 5 (τ_B 後の追加採用で回復しない) は Nelson-Winter のルーチン移転観と明確に区別される反証可能予測。F_char の独立性は測定論ではなく予測の分岐で守る。
- 異議 4 (Jovanovic への過小帰属)。査読者: 「Jovanovic (1982) は拡張の余地がある一般的枠組みで、レジーム切換えは単なる応用。新規性は薄い」。応答: Jovanovic を親フレームワークとして明示的に継承し、本寄与の核は (a) 選抜単位を法人化以前の二者対に移すこと、(b) 選抜環境自身が内部 trigger で切り替わる点、であることを強調する。これは Jovanovic の応用ではなく、Jovanovic の単位と定常性前提の両方を緩める二重拡張である。
- 異議 5 (サンプル選択と生存者バイアス)。査読者: 「観測される τ_B は最終的に登記した二者対のみで、Pre-B で消えた二者対は観測されない。τ_y は登記前の消失も含めて定義すべきで、これでは推定値が偏る」。応答: GAP fund 採択二者対をベース母集団に取ることで、Pre-B 消失も観測可能にする。NEDO STS / JST GAP は採択時点で登録され、その後の登記 / 解散 / 休眠が追跡可能。これにより選抜単位を「法人登記したもの」ではなく「資金供給可能とみなされたもの」に拡張し、生存者バイアスを軽減する。

### C2_F_char_non_delegable: Before Zero 局面において創業者性格 F_char は CES ρ=-2 補完性で表現される委譲不可能な核として F 集約子に入り、これは Nelson-Winter (1982) の「ルーチン=移転可能技能」公理が法人化以前の期間に成立しないという構造的事実を形式的に書き下した寄与である。

**形式記述**:

F : R_+^2 → R_+ を、S = σ_SU · R_net · F を介して PRS に入る創業者適応度集約子とする。次のように定義する。

  F(F_char, F_cap) = [ a · F_char^ρ + (1-a) · F_cap^ρ ]^(1/ρ),  ただし a = 0.6, ρ = -2.

F_char := composite(ALQ4, Grit, Resilience) ∈ R_+ を創業者に錨で固定された性格バンドル、F_cap ∈ R_+ を委譲可能な能力バンドル (経験順序、累積されたルーチン) とする。委譲作用素 δ_t : F_char → F_char' を定義する。これは、時刻 t における労働プールまたは組織ルーチンレポジトリから引かれた任意の主体 j ≠ i に、創業個人 i から性格バンドルを再割り当てしようと試みるものである。

命題 C2 (委譲不可能性定理、BZ 段階):
すべての t < t* (t* は firm が法的に結晶化し Nelson-Winter 的意味でルーチンを獲得する形成時点) について、また j ≠ i である任意の δ_t について:

  (i)  ∂F/∂F_char |_{F_char → 0} = +∞   (ρ = -2 < 0 によって誘導される Inada 型コーナー),
  (ii) E[ δ_t(F_char) ] / F_char^i ≤ κ(t),  ただし t → t*^- のとき κ(t) → 0,
  (iii) lim_{F_char → 0} F(F_char, F_cap) = 0  すべての有限 F_cap について。

したがって、BZ 段階において F_char は非代替的な要素である: ゼロの性格はいかなる有限の能力ストックでも補償できず、Nelson-Winter がルーチンに対して非自明に作用すると仮定する委譲作用素 (彼らの「技能 = ルーチン = 遺伝子」公理) は F_char 上で構造的に退化する。代替の弾力性 σ = 1/(1 - ρ) = 1/3 は厳密に 1 から有界に離れており、進化経済学の他所で用いられる Cobb-Douglas (σ = 1) または線形 (σ = ∞) の人的資本 × ルーチン集約子と BZM を区別する。

系 (Edgeworth 補完性、検定可能な形):
  ∂²F / ∂F_char ∂F_cap > 0  BZ 段階定義域全体で。

Nelson-Winter への収束 (滑らかな極限):
t → t* となり firm が形成されるにつれて、ρ(t) → 0 (Cobb-Douglas 極限) となり δ_t は非退化になり、ルーチン=複製子レジームが回復される。したがって C2 は Nelson-Winter に矛盾しない。それは彼らの委譲公理が失敗する形成前レジームを同定し、彼らのモデルへの連続的な内挿を提供する。

**導出の素描**:

ステップ 1. BZ 段階の分析単位を firm ではなく創業者-案件二者対と置く。Nelson-Winter の委譲が作用する組織レベルのルーチンレポジトリ R_org(t) は、t < t* では構成上空である (firm なし、符号化されたルーチンなし、組織記憶なし)。

ステップ 2. F_char を、燃焼下での創業者持続性を経験的に予測する性格に錨を置いた属性 (ALQ4 軸 + Grit + Resilience) のバンドルとして定義する。これらは個人レベル (心理計量 + 行動トレース) で測定され、t* 以前は組織レベルの類比物を持たない。

ステップ 3. 委譲作用素 δ_t を設定する。Nelson-Winter の中心的主張は、メンバー i に体現された任意の技能について、δ_t(skill_i) = skill_j となるルーチン R ∈ R_org が j ≠ i について有界な忠実度損失で存在するというものである。BZ 段階では、R_org = ∅ なので、δ_t はいかなる組織的基層を経由することもできず、対人的な直接移転のみを通じる。

ステップ 4. F_char の対人的直接移転は、t → t*^- のとき κ(t) → 0 で有界であることを示す。性格属性 (Duckworth Grit, ALQ4 リーダーシップ真正性, Bonanno レジリエンス) は伝記、神経認知ベースライン、統合されたアイデンティティに個人として錨で固定されており、短期的な訓練介入では人物間で複製されない。これは Grit のメタ分析的安定性 (Credé et al. 2017) およびレジリエンスの特性的性質 (Bonanno 2004) と整合的である。

ステップ 5. ステップ 4 を F 集約子内で形式化するため、ρ = -2 (強い補完性) の CES を選ぶ。Leontief (ρ → -∞) ではなく CES を選ぶのは、コーナー挙動を保ちつつ滑らかな実証推定を許すためである。ρ = -2 は σ = 1/3 を与え、初期段階ベンチャーにおける人的性格 × ルーチン補完性として経験的に妥当である。

ステップ 6. Inada コーナーを導出する: ρ < 0 のとき、F_char → 0 につれて限界生産物 ∂F/∂F_char は発散し、F 自身は F_cap によらず 0 に潰れる。これが「委譲不可能な核」の形式的内容である。

ステップ 7. F を PRS = P · R · S に S = σ_SU · R_net · F として埋め込む。PRS が乗法的であるため、F = 0 は PRS = 0 を強制する。よって F_char ≈ 0 の BZ 案件は形成閾値に到達する確率がゼロとなる。

ステップ 8。Nelson-Winter への連続的極限を定義する。ρ(t) を ρ(0) = -2 かつ t → t* で ρ(t) → 0 となる滑らかな関数とする。これにより BZM を Nelson-Winter の対抗ではなく法人化以前の延長として埋め込む。法人化後はルーチン=技能観のレジームが、組織ルーチンと雇用人材を通じて F_char が次第に代替可能になることで回復される。

ステップ 9。経験的プロキシを特定する。F_char ← (ALQ4 スコア、12 項目 Grit、CD-RISC レジリエンス)。F_cap ← (過去ベンチャー数、領域経験年数、順序付きタスク・レパートリー)。σ_SU ← Triple Helix CD 指数。アウトカム ← 第 3 世代レースに基づく τ_x < τ_y の指示関数。

ステップ 10。識別可能な回帰を特定する。F(·) を線形 (ρ = 1)、Cobb-Douglas (ρ → 0)、自由な ρ をもつ CES の三つの入れ子型で BZ 段階コホート (n ≥ 400、法人化以前の観測) において推定し、H0: ρ ≥ 0 を H1: ρ < 0 に対して検定する。C2 は BZ 段階コホートで ρ̂ ∈ [-3, -1]、マッチさせた法人化後コホートで ρ̂ ≈ 0 を予測し、明快な反証面を提供する。

**予測する経験的パターン**:

- P1 (Inada コーナー)。法人化前の創業者=プロジェクト対のうち、F_char が最下位 10 分位のものは、F_cap が上位 10 分位であっても、法人化までの到達時刻生存率がゼロと区別できない。線形および Cobb-Douglas 型人的資本モデルは緩やかな劣化を予測するが、C2 はコーナーを予測する。
- P2 (弾力性ギャップ)。F_char と F_cap の代替弾力性 σ の推定値は、BZ 段階コホートでは有意に 1 を下回り (予測 σ̂ ≈ 1/3、95% 信頼区間が σ = 1 を含まない)、マッチさせた法人化後コホートでは有意に 1 に近い (予測 σ̂ ≈ 0.8-1.0)。企業内差分が t* におけるレジーム切換えを識別する。
- P3 (共同創業者代替の失敗)。BZ 段階で離脱する高 F_char 共同創業者を高 F_cap の被雇用者で置き換えると、τ_x < τ_y 変換率に計測可能な低下が生じる (滑走路枯渇に対する予測ハザード比 ≥ 1.5)。これはルーチンが既に存在すれば効果なしと予測する Nelson-Winter のルーチン代替と矛盾する。
- P4 (段階境界における Beckman/Roberts/Eesley の反転)。創業者チーム多様性および過去所属指標 (Beckman 2006) は法人化後のアウトカムでは F_char プロキシに優越するが、BZ 段階のアウトカム (法人化変換、B 起動生存) では F_char プロキシに劣後する。F_char と チーム構成変数の相対 R² は t* で反転する。
- P5 (CES 交差偏微分)。∂²F / ∂F_char ∂F_cap > 0 は適合モデルにおいて正の交互作用項として検出可能である。交互作用は中間的な F_cap で最も強く、F_char → 0 で消失する (乗法的崩壊と整合)。これは加法的な人的資本集計子が生成できないパターンである。

**反証可能性検定**:

法人化前の創業者=プロジェクト対パネル (n ≥ 400、最初の創業者コミットメントから法人化または放棄まで観測、F_char プロキシ、F_cap プロキシ、σ_SU 曝露、τ_x/τ_y レース結果を月次で測定) は、以下のいずれかが成立すれば C2 を反証する。

(a) BZ 段階標本における CES 型 F 集計子の推定 ρ が有意に負でない (95% 信頼区間が ρ = 0 を含む) こと。すなわち Cobb-Douglas を超える補完性が存在しない。

(b) 離脱する高 F_char 創業者を高 F_cap の被雇用者で置き換えても、コホートと σ_SU をコントロールした上で τ_y に対する過剰ハザードを示さない。これは能力が人格を代替し得ることを示唆する。

(c) F_char プロキシ vs 創業者チーム構成変数の相対説明力が t* で反転せず、法人化前後境界を通じて一定にとどまる。これはレジーム切換えが存在しないことを示唆し、C2 を Nelson-Winter に潰す。

(d) 上位 10 分位の F_cap をもつ最下位 10 分位 F_char の対が、上位 10 分位 F_char の対と区別できない法人化変換率を示す。これは Inada コーナー (i) を反証する。

(e) 創業個人を変えずに測定 F_char を実質的に上昇させる創業者人格介入 (コーチング、置換、期限付き代理) が、同等の τ_x アウトカムを生む。これは作動する δ_t を示すことで委譲不可能性の公理を直接反証する。

事前登録: ρ̂ ∈ [-3, -0.5] かつ H0: ρ ≥ 0 に対する片側 p < 0.01 を確認閾値とし、ρ̂ ≥ 0 かつ H1: ρ < 0 に対する片側 p < 0.05 を反証閾値とする。データソース: J-Startup の法人化前コホート、NEDO STS の法人化前追跡、AMD 内部創業者ドシエ、適用可能な場合は Kauffman Firm Survey wave-0 を補強として用いる。

**進化経済学既存文献の処理**:

Nelson and Winter (1982、特に第 4-5 章) は進化経済学を、技能はルーチンであり、ルーチンは組織レベルの遺伝子であるという明示的公理の上に構築している。すなわち、メンバー間で移転可能、企業間で複製可能 (不完全な忠実度をもって)、組織記憶に保存される、という公理である。集団選抜の装置全体が、ルーチンが継承の単位であること――すなわちルーチンが個人に固着しないこと――を前提とする。

その後の進化経済学はこの公理を保持するか、あるいはこれを破らない形で迂回している。Cohen and Levinthal (1990) の吸収能力は学習を組織レベルで扱い、Teece, Pisano and Shuen (1997) のダイナミック・ケイパビリティはケイパビリティを企業レベルに置き、Helfat and Peteraf (2003) のケイパビリティ・ライフサイクルもケイパビリティを組織的なものとして扱う。Murmann (2003) の共進化は企業 × 制度のスケールで作動し、創業者は形式の外側に大きく置き去られる。Witt (2008) の新規性発生は、個人の創造性を多様性の源泉として認めるが、それを非代替可能性をもって形式的集計子に組み入れることはしない。

厳密な進化経済学伝統の外側にある創業者チーム文献 (Beckman 2006, Roberts 1991, Eesley and Roberts 2012, Hoenig and Henkel 2015) は創業者レベルの属性を測定するが、それは法人化後アウトカムの予測子としてであり、委譲不可能性を形式化しない。彼らの CES 等価仕様は通常、創業者特性と企業ケイパビリティに対して加法的である (すなわち暗黙のうちに ρ ≈ 1 または ρ → 0) ため、Inada コーナーが検定されることはない。

Polanyi (1966) の暗黙知は、コード化に抵抗する知識があることを認めるために進化経済学で時に引かれる。しかし Nelson-Winter の手のなかでは暗黙知はなお組織ルーチンを経由する (ルーチンは部分的に暗黙的だがなお組織常駐である)。BZ 段階の対象――すなわち、いかなる組織ルーチンも存在する前に創業個人に固着した人格――は、この文献に形式的な居場所をもたない。

最も近い形式的身振りは Jovanovic (1982) である。そこでは各企業は未知だが企業固有の生産性 θ をもち、学習を通じて顕在化する。θ は企業に固着するもので個人に固着するのではなく、外生的かつ定常的に扱われる。代替可能な要素との Inada 補完性は課されない。したがって Jovanovic の θ は構造的に C2 における F_char とは別物である。

要するに、進化経済学は委譲不可能な個人レベル要素を必要としなかった。なぜなら分析単位を企業に、継承単位をルーチンに据えたからである。BZ 段階の問題はその枠組みの内側からは不可視である。

**BZM 特有の追加**:

BZM は進化経済学が含まない以下の構造を追加する。

(1) 組織ルーチンの貯蔵庫が空 (R_org = ∅) である法人化前レジーム [0, t*) の明示。これにより創業者属性と組織ケイパビリティを跨ぐいかなる集計子も、選抜の重みを丸ごと個人に固着した要素に置かざるを得なくなる。

(2) このレジーム上の形式的 F 集計子: F(F_char, F_cap) = ρ = -2、a = 0.6 の CES。これは (a) F_char → 0 における Inada コーナー挙動 (委譲不可能性の捕捉) と (b) 経験的推定のための滑らかな補完性 (σ = 1/3) を実現するよう選ばれる。

(3) 法人化前の縮退 E[δ_t(F_char)] / F_char^i → 0 as t → t*^- をもつ委譲作用素 δ_t の明示。これは BZ 段階における Nelson-Winter 型ルーチン代替の構造的不可能性を形式化する。

(4) Nelson-Winter への連続的極限: t → t* で ρ(t) → 0 となり δ_t が縮退しなくなる。したがって BZM は Nelson-Winter の対抗ではなく法人化前の延長である。両モデルは t* において整合する境界条件のもとで接続する。

(5) 操作化: F_char は ALQ4 (4 軸 Authentic Leadership)、Grit (Duckworth)、レジリエンス (CD-RISC/Bonanno) に分解され、いずれも法人化前に個別創業者レベルで測定される。F_cap は経験順序 (過去役職のストックではなく順列) と蓄積された移転可能ルーチンに分解される。この分解は BZM 固有であり、進化経済学では標準ではない。

(6) 乗法的埋め込み: F は S を通じて PRS = P · R · S に乗法的に入る。したがって F = 0 は P (市場) や R (整備度バンドル) と独立にプロジェクト失敗を強制する。これは人格の委譲不可能性がプロジェクト水準のアウトカムに伝播する機構であり、Nelson-Winter の単一スカラー適応度に対する BZ 段階での精緻化である。

(7) 段階跨ぎ識別戦略: BZM は ρ̂ が t* を境に ≈ -2 から ≈ 0 に反転すると規定する。これは法人化イベントにおける創業者内・プロジェクト内の回帰不連続風デザインを与える。進化経済学はレジームを区別しないため、対応物をもたない。

**想定批判 (risks_and_objections)**:

- 批判 1 (F_char 測定における観測可能変数による選抜)。Research Policy の査読者は、ALQ4、Grit、CD-RISC が自己報告型尺度であり、起業家標本において社会的望ましさバイアスと弱い再検査信頼性が文書化されていることを指摘する。F_char が古典的誤差で測定される場合、推定 ρ̂ は 0 に向けて減衰し、C2 自身のコーナー予測に不利に働く。しかし誤差が異質的 (例: 創業を自己選択した高 Grit 創業者で系統的に上振れする) であれば、コーナーが偽陽性的に現れうる。緩和策として、行動跡計測 (コミットメント強度、本業辞職までの時間、逆境下での持続観察) を自己報告 F_char の操作変数として用い、加えて事前登録された測定手順を要する。
- 批判 2 (Nelson-Winter は法人化前の移転可能性ゼロを前提にする必要はない――企業内での正の移転可能性のみを必要とする)。Nelson and Winter (1982) を丁寧に読めば、彼らはルーチンが企業以前に存在すると形式的に主張してはおらず、単にそのレジームを分析していないだけである。したがって C2 は藁人形を攻撃する危険を孕む。弁護: C2 の主張は Nelson-Winter が誤っているということではなく、彼らの形式論が [0, t*) について沈黙していること、そして BZM がその沈黙を反証可能な構造で埋めるということである。寄与は沈黙を明示し、レジーム境界を識別することにある。
- 批判 3 (ρ = -2、a = 0.6 はキャリブレートされたもので推定されたものではない)。CES パラメータを推定ではなく規定で選ぶことは、反証不能なカーブフィッティングという嫌疑に晒される。弁護: ρ と a は事前登録された事前分布のもとで独立な BZ 段階データで推定する必要があり、上記の反証可能性検定 (a) は明示的に ρ を俎上に載せる。規定値は経験的演習の事前中心傾向として扱うべきであり、主張そのものとして扱うべきではない。
- 批判 4 (F_char は真に委譲不可能ではない――共同創業者、メンター、時間が代替する)。進化経済学者は、共同創業者追加 (Beckman 2006) こそまさに C2 が否定する委譲機構であると論じうる。弁護: 共同創業者追加はある個人から別の個人への F_char の委譲ではなく、独自の F_char をもつ第二の個人を追加するに過ぎない。関連する検定は追加ではなく置換である。予測ブロックの P3 が置換ケースを単離する。置換が機能するなら C2 は反証される――これがデザインの意図そのものである。
- 批判 5 (レジーム境界 t* は内生的である)。法人化のタイミングそれ自体が F_char と F_cap の関数であるため、t* における段階跨ぎ識別は選抜により汚染される。高 F_char の創業者は企業を形成するとともに BZ 段階で高い成果を示し、見せかけのレジーム切換えを生む。弁護: 税年度境界、助成金サイクルの適格性、インキュベーター・コホート・ゲートによって誘発される法人化タイミングの外生的変動――すなわち F_char をシフトさせずに t* をシフトさせる操作変数――を使う。コホート固定効果付きの事前登録 IV デザインが必要である。
- 批判 6 (文化的・国民的特殊性)。日本における BZ 段階動学 (J-Startup、NEDO STS、大学発シーズ法) は米国 Kauffman 文脈と構造的に異なる。ρ̂ と a は管轄固有でありうるため、C2 の一般化を制約する。弁護: 識別可能な回帰を日本と米国の並列標本で走らせ、ρ̂ < 0 は管轄をまたいで頑健だが大きさは異なる、と予測する。国際比較頑健性が交絡ではなく検定可能な予測そのものになる。

### C3_two_layer_noncommutativity: Before Zero phase においては、案件適応度 PRS (乗法) と選抜環境準備度 ERS (加重和) を単一スカラーに縮約することは因果 DAG 上で識別不能であり、Nelson-Winter 型の集団水準選抜を BZ 段階に下ろすには二層を非可換に分離することが必須である。

**形式記述**:

命題 C3 (二層非可換性)。苗床 j 内、時点 t、プロジェクト i のプロジェクト適応度ベクトルを theta_{ijt} = (P, R, S) とし、苗床整備度ベクトルを eta_{jt} = (A_1,...,A_8) とし、重みを w (合計 1) とする。PRS_{ijt} = P*R*S を ((R_{>0}, x) 上の乗法) と定義し、ERS_{jt} = 100 * sum_k w_k A_{k,jt} / sum_k w_k を ((R, +) 上の加法) と定義する。Y_{ijt} を BZ 段階アウトカム (例: 1[tau_x < tau_y]、または資金調達可能な実体への結晶化イベント) とし、構造モデルを Y = g(PRS, ERS, U)、U ⊥ (theta, eta) | X、g は両者に対して単調非減少、かつ BZ 段階で因果経路 eta -> theta が活性 (制度がプロジェクトを形成する) とする。このとき: (C3.a) スカラー縮約の下での識別不能。任意の連続な狭義単調集計子 Phi = phi(PRS, ERS)――特に phi = PRS * ERS, phi = PRS + lambda*ERS, あるいは有限弾力性をもつ任意の CES――は、g の構造パラメータを (Y, Phi, X) の同時分布から識別不能にする。なぜならバックドア経路 eta -> theta -> PRS は、eta が ERS を通じてもつフロントドア効果を担う同一スカラーに潰されるからである。形式的には、(g, theta と eta の同時分布) の二つのパラメータ化 (g_1, F_1) と (g_2, F_2) が存在し、(Y, Phi, X) の同じ観測法則を誘導しながら do(ERS = e') 介入に対する異なる反実仮想応答を与える。(C3.b) 代数的非両立性。PRS は乗法半群 (R_{>0}, x) 上に存在し、いかなるゼロ因子 (チームなし、市場なし、権利なし) も積を消去する (Leontief 様: 各要素の必要性)。ERS は加法錐 (R_{>=0}, +) 上に存在し、8 軸間に有界な代替可能性をもつ (ポートフォリオ様: 強い軸が他軸を部分的に補償する)。順序保存同型 phi: (R_{>0}, x) x (R_{>=0}, +) -> R で (i) いかなる PRS 因子による消去と (ii) ERS 内代替を同時に保つものは存在しない。したがって任意の単一スカラー適応度 Phi は少なくとも一つの構造特性を破らねばならない。(C3.c) 二層分離の下での識別。PRS と ERS を別々の層に留め、ERS に対する操作変数 Z_j で Z_j ⊥ U | X かつ Z_j が ERS と |X 条件下で独立でない、を満たすものを用いて g(PRS, ERS, U) を推定すれば、PRS を固定した下での partial g / partial ERS が識別され、スカラー縮約が破壊する制度経路の識別が回復される。系 (Nelson-Winter 対比)。Nelson-Winter (1982) のレプリケーター設定は、適応度を単一成長率で表現することにより企業水準でスカラー phi を暗黙に適用する。選抜の単位が所与の選抜環境内で営業する既存企業であるとき (環境がセクター内で企業を跨いで外生かつ定常)、これは無害である。BZ 段階では構造的に無効になる。なぜなら (i) 単位はまだ企業の内側にない創業者=プロジェクト対であり、(ii) 苗床整備度 eta それ自身が、その整備度が問われる対象であり、i に応じて変動するからである。

**導出の素描**:

ステップ 1。BZ 段階 SCM を特定する: プロジェクト i の潜在因子 (P, R, S) は、創業者原始量 F と、eta -> theta を経由する苗床状態 eta = (A_1,...,A_8) によって引き起こされる (例: SRL/HRL は R に入り、mu_A/mu_I は S 内の sigma_SU に入る)。アウトカム Y = g(PRS, ERS, U)。ステップ 2。PRS の乗法構造はモデリングの選択ではなく構造的制約であることを示す: BZ 段階では P (到達可能市場なし)、R (いずれかの RL 次元で整備度なし)、S (戦略的滑走路なし) のゼロがプロジェクトをゼロにする。したがって PRS は消去公理付きの (R_{>0}, x) 上に存在する。ステップ 3。ERS が構造的に加法的であることを示す: 苗床軸 (大学 TTO 能力、ギャップファンド可用性、規制明確性、IP 経路、等々) は部分代替可能である――強いギャップファンド軸は弱い TTO 軸を補償できる。したがって ERS は加重和錐上に有界な代替可能性をもって存在し、消去はもたない。ステップ 4。代数的非両立性補題: phi : (R_{>0}, x) x (R_{>=0}, +) -> R で連続、狭義単調、PRS 因子の消去と ERS 軸の代替を同時に保つものは縮退写像 (ERS を無視するか消去子を無視するかのいずれか) に帰着する。証明は境界 PRS=0 における phi の挙動、および合計を保ちながら個別軸を反転させる ERS 置換における phi の挙動についての場合分けによる。ステップ 5。識別不能性: partial g/partial ERS が異なる二つの SCM (g_1, F_1), (g_2, F_2) を構成し、(Y, Phi(PRS, ERS), X) の同じ同時法則を生成する。構成は、Phi がバックドア eta -> theta -> PRS をフロントドア eta -> ERS と同一スカラーに混ぜることを用いる。したがって g_PRS vs g_ERS の任意の再加重は、Phi の Y への限界効果を保つように F_eta を再加重することで対応できる。ステップ 6。二層識別: PRS と ERS を別々に観測し、ERS に対する操作変数 Z_j (例: J/US/EU における県や大学を跨ぐ外生的政策変動、Akcigit-Pearce-Prato 2021 の大学政策ショックを参照、UK Higher Education Innovation Fund の不連続) を用いれば、単調性のもとで標準的 IV により partial g/partial ERS が識別される。ステップ 7。Nelson-Winter 対応付け: Nelson-Winter (1982) 第 6-9 章のレプリケーター動学は、スカラー企業適応度 pi_i と外生選抜圧を用いる。これがセクター内で i を跨いで eta が一様であること (選抜環境が共有) を仮定することに対応し、ERS を定数に潰しスカラー縮約を無害化することを示す。BZ 段階ではこの仮定が破れる: eta_jt は苗床 j を跨いで変動し、それ自身が政策対象である。ステップ 8。経験的アンカー: BZM の 8 軸 ERS 構築 (第 9 章) は Malerba (2002) のセクター・システムを、セクター粒度ではなく苗床粒度で分解したものに対応し、eta におけるセクター内異質性を観測可能にする。ステップ 9。C1, C2 との接続: レジーム切換え τ_x (C1) は Y を生成する。委譲不可能な F_char を伴う F-CES (C2) は PRS が乗法的である構造的理由の一つである (F_char = 0 はプロジェクトをゼロにする)。したがって C3 は C1 と C2 を同時推定可能にする建築的定理である。ステップ 10。運用ルール: BZ 段階スクリーニングでは決して単一の Phi スコアを報告しない。常に 2 次元状態 (PRS_i, ERS_j) と、それぞれに別々に作用する政策レバー集合を報告する。

**予測する経験的パターン**:

- 予測 1 (モデル適合の優越)。乗法的 PRS と加法的 ERS をもつ二層到達時刻モデルは、(i) 任意の単一スカラー積モデル PRS*ERS、(ii) 任意の単一スカラー加重和モデル alpha*PRS + beta*ERS、(iii) 有限 rho をもつ任意の CES 集計子に対して、法人化前コホートにおける BZ 段階アウトカム (資金調達可能な実体への結晶化、tau_x < tau_y) の標本外対数尤度で厳密に Pareto 優越する。優越は苗床内 PRS 分散が大きく、苗床間 ERS 分散が大きいコホートに集中する。
- 予測 2 (消去子の可視性)。少なくとも一つのゼロ PRS 因子をもつコホート (到達可能市場なし、または少なくとも一軸の RL がゼロ整備度、または戦略的滑走路ゼロ) は段階関数的失敗を示す: ERS の水準に関係なくアウトカム率がほぼゼロになる。この段階関数は有限弾力性をもつ任意のスカラー集計子には不可視であり、乗法構造の経験的署名である。
- 予測 3 (ERS の軸間代替)。ERS 内では軸が有界な比率で相互代替可能である: 軸 k の 1 標準偏差増加は、PRS を条件付けると、軸 k' (k != k') の 1 標準偏差減少を Y への効果がほぼゼロで補償できる。これは加法錐構造の経験的署名であり、いずれかの単一 ERS 軸を必要条件として扱うことと整合しない。
- 予測 4 (政策レバーの分離可能性)。ERS 軸への外生ショック (例: 県 j での新規ギャップファンド開設、TTO 改革) はアウトカムを ERS 経由でシフトさせるが、PRS の条件付き応答曲面はほぼ不変に残す。逆に創業者側ショック (F_char 測定、チーム構成) は PRS をシフトさせるが、ERS の偏応答を不変に残す。この分離可能性が非可換性の操作的形である。
- 予測 5 (段階による Nelson-Winter 退化)。単一スカラー Nelson-Winter 型レプリケーター適合は、経験的標本が IPO 後企業 (良好な適合) から初期段階資金調達済みスタートアップ (退化した適合) を経て法人化前創業者=プロジェクト対 (最悪の適合) へと上流に移るにつれて単調に退化する。退化は二層モデルに対する標本外対数尤度損失として測定可能であり、標本内で単位を跨ぐ eta の分散シェアを追跡する。

**反証可能性検定**:

以下のいずれか一つが成立すれば寄与は反証される。(F1) モデル適合の同等性。BZ 段階パネル (>= 30 苗床にまたがる >= 1,000 創業者=プロジェクト対、PRS 成分 (P, R, S ベクトル) と ERS 成分 (8 軸) を測定) で、単一スカラー モデル (CES、乗法、加法) が X を制御した上で tau_x < tau_y に対する標本外予測対数尤度において二層モデルを標準誤差以上に上回るかまたは同等であること。(F2) 消去子なし。ゼロ PRS 因子をもつコホートが、ERS をマッチさせた (IV 補正後の) 非ゼロ コホートと区別できないアウトカム率を示すこと。これは PRS が構造的に乗法的でないことを示唆する。(F3) ERS 代替なし。ERS 内で軸が非代替的に振る舞う: 一つの軸を取り除いても他を強化することで補償できないこと。これは ERS が加法的ではなく Leontief 的であることを示唆し――この場合は両層が乗法的になり非対称論証は崩壊する。(F4) 政策レバーの非分離性。ERS 軸への外生ショックが PRS の条件付き応答曲面をシフトさせる (IV 補正推定で交互作用効果が有意に非ゼロ) こと。これは二層が絡み合っていることを示唆し、非可換性主張は経験的に空となる。(F5) 段階を跨ぐ Nelson-Winter スカラー不変性。単一スカラー Nelson-Winter 型モデルの相対的標本外適合が、標本が IPO 後から BZ 段階単位へと移るにつれて退化しないこと――これはスカラー縮約があらゆる段階で無害であり、BZ 固有主張が空であることを示唆する。必要なデータ: 大学政策 IV (例: UK HEIF 不連続、日本 SBIR 整合補助金の段階的展開、米国の Bayh-Dole 派生州レベル規則変更) を ERS 軸用に備えた国際苗床パネル (J + US + EU + UK); F_char プロキシと ALQ4 測定を伴う創業者コホート追跡; プロジェクト水準 RL 測定の四半期解像度。

**進化経済学既存文献の処理**:

Nelson and Winter (1982、特に第 6-9 章および第 14 章) は企業適応度をスカラー (典型的には利潤または資本成長率) として構築し、集団水準のレプリケーター動学を通じてこのスカラーに選抜を作用させる。選抜環境はセクター内で外生かつ共有である。Metcalfe (1998) はこれを Fisher 原理とレプリケーター方程式で形式化するが、やはりスカラー適応度上である。Klepper (1996, 2002) はスカラー適応度仮定を保持しつつ、参入後の生存に対応付けられる参入前ケイパビリティの異質性を許す――それでもなお企業ごと一スカラーである。Jovanovic (1982) は企業生産性 theta を一スカラー次元に縮約し、その更新された事後分布が退出を決定する。Malerba (2002) のセクター・システムは選抜環境を複数のアクター、制度、知識基盤に明示的に分解する――これが ERS の最も近い祖先である――が、Malerba はセクター・システム特性とプロジェクト水準適応度の相互作用を代数的に異なる二層として形式化しない。統合は語りに留まる。Murmann (2003) の企業=制度=学術システム共進化は、制度と企業が共に進化することを経験的に確立するが、やはり企業側適応度はスカラー (市場シェア、生存) で表現し、制度整備度を質的に扱う。Saviotti and Pyka (2004) の多様性モデルはセクター総計水準に留まる。これらのいずれも、乗法的プロジェクト適応度 vs 加法的選抜環境整備度の代数的非両立性を形式化せず、また制度=プロジェクト因果経路が活性であるときにスカラー縮約から生じる識別不能問題を識別しない。最も近い形式的従兄弟は Murmann の共進化だが――共進化は同時動学に関する縦断的主張であり、適応度の代数に関する構造的主張ではない。なぜ対処できなかったか: 進化経済学 1982-2010 は企業を分析単位としたため、制度=プロジェクト因果経路はスカラー縮約を失敗させる水準では生じなかった――それは単位が法人化前の創業者=プロジェクト対へと上流に移ったときにのみ生じる。そこでは eta はもはや共有された外生環境ではなく、どの対が企業性へと渡るかを選抜する変動状態となる。

**BZM 特有の追加**:

BZM は進化経済学が以前に組み合わせなかった三つの構造を追加する。(i) 層の代数型付け: PRS は消去子付き乗法半群に制約される (いずれかの因子のゼロがプロジェクトを殺す。BZ 段階では緩衝が存在しないからである。これは C2 の委譲不可能 F_char、および P, R, S 前提条件の離散的 go/no-go 性質から導かれる帰結である)。ERS は有界な代替性をもつ加法錐に制約される (苗床支援は部分代替である。これは Malerba の複数アクター・セクター・システムに経験的根拠をもち、苗床粒度で 8 軸に量子化される)。(ii) BZ 段階における因果 DAG 仕様: 経路 eta -> theta -> アウトカム は活性であり、これを識別するには i を跨いで変動するスカラー (PRS) を j を跨いで変動するスカラー (ERS) から分離保持し、j 水準で ERS の操作変数を備えることが必要である。この DAG 仕様こそが C3.a の識別不能結果を鋭くするものであり、これがなければスカラー縮約は構造的誤りではなくモデリング選択に見えてしまう。(iii) 運用的政策対応付け: 二層が応答曲面で分離可能 (予測 4) であるため、ERS に作用する政策レバー (ギャップファンド、TTO 改革、ギャップ政策、GxP インフラ) は PRS に作用する創業者側レバー (F_char スクリーニング、創業者チーム構成) と独立に評価できる。これはセクター水準ではなく苗床水準における Nelson-Winter の産業政策レバーの BZ 段階版であり、AMD の Triple Helix CD が操作化するレバー集合である。正味の寄与: BZM は、苗床水準政策とプロジェクト水準創業者スクリーニングが単一の合算スコアではなく直交介入として設計されねばならない理由を正当化する構造定理を提供する――これはスカラー型進化経済学枠組みでは既に層を潰してしまっているため、なし得ない主張である。

**想定批判 (risks_and_objections)**:

- 批判 1 (Murmann による先取り)。Murmann (2003) の共進化は既に制度と企業が共にアウトカムを形成することを確立しており、非可換性主張は再ラベリングである。応答: Murmann の共進化は縦断的な同時動学主張 (制度と企業は数十年単位で共に変化する) であるのに対し、C3 は BZ 段階対の単一断面における適応度の代数に関する構造的主張である。識別不能結果 (C3.a) は Murmann には現れない。なぜなら Murmann はそもそもスカラーに潰さず、語りによる共進化を用いるからである。C3 はスカラー縮約の形式的コストを明示し、IV ベースの識別経路を提供する。
- 批判 2 (代数的非両立性は定義選択の人工物である)。査読者は、PRS は本当には消去的ではない (P がゼロに近いプロジェクトはピボットでき、ピボットは消去子を破る)、ERS も本当には加法的ではない (一部の軸は必要、例: 法的 IP 権がなければ他は無意味) と論じうる。応答: ピボットは経路外であり、消去子は意思決定時点 t における評価時のプロジェクトに適用されるのであって創業者の選択肢全体に適用されるのではない。ERS については軸の重み w_k は等しいことを強制されない。準必要的軸が w_k を 1 近くまで担いうるが、代替特性は残余質量に対してなお成立する――これは検定可能であり予測 3 の一部である。
- 批判 3 (PRS 成分それ自身が多次元であるため経験的に空である)。P, R, S はそれぞれ複合 (R = TRL x BRL x GRL x SRL x HRL) であり、ERS 軸も複合である。箱を開けると二層主張は解消しうる。応答: 各層内での精緻化のもとで代数的型付けは不変である――R それ自身が乗法的であり (いかなる RL のゼロもプロジェクトを殺す)、ERS 成分は各軸内で加法的である。精緻化は型付け論証を弱めるのではなく強化する。非可換性は層間にあるのであり、層内にあるのではない。
- 批判 4 (IV による識別はクリーンな形では存在しないかもしれない外生苗床政策ショックを必要とする)。partial g / partial ERS の IV 識別は、第一段階を持ち Z_j ⊥ U を満たすものを見出すことに賭けている。現実世界の苗床政策はそれへの需要に対して内生的である。応答: これは標準的な経験的 IV 批判である。論文は具体的候補操作変数とプラセボデザインを提示せねばならない。候補: UK HEIF 規則不連続、日本の県別ギャップファンド段階的展開、米国 Bayh-Dole 派生州レベル変動、および 2018-2023 年日本の SU 100 プログラム段階的指定。クリーンな IV がプラセボに耐えなければ C3.c は経験的主張ではなく概念的識別主張に留まる――が、C3.a と C3.b は残る。
- 批判 5 (なぜ単一回帰に PRS x ERS 交互作用項を含めるだけではないのか?)。実務的査読者は: 柔軟なノンパラメトリックモデルを PRS と ERS を別入力かつ交互作用項とともに使えばよく、非可換性定理は要らない、と言うだろう。応答: 経験的にはその通りであり、それが二層分離の運用形である。定理が重要なのは (a) 単一の PRS*ERS 取引スコアのようなスカラー報告が BZ 段階で構造的に誤りである特定の理由、(b) ERS 介入が PRS 介入から分離可能であるという政策評価主張 (予測 4)、そして (c) BZM を親枠組み拡張として位置付けることを正当化する Nelson-Winter スカラーレプリケーターとの対比、についてである。

## 4. 構造手術後の反対意見検証 (2 視点)

### Evolutionary Economist

**verdict_after_surgery**: 条件付き受理。構造手術は私の評価を実質的に変えた。三点が効いた。第一に、寄与 C1 (Jovanovic 1982 の BZ 固有拡張としての B 起動におけるレジーム切換え τ_x) が単一の最重要手であり、単一レジーム到達時刻モデルが本当に生成し得ない、具体的で反証可能な構造的分断 (Andrews-Quandt / Chow 仕様による法的法人化 τ_B でのハザード不連続、σ_SU × レジーム 交互作用、Pre-B 期間における逆 U 字) を識別する。これは『新記法』ではない――生成作用素 L_BZM = 1{t<τ_B}L_pre + 1{t≥τ_B}L_post をもつ Kolmogorov 後退方程式と、誤特定が観測可能であるという明示的な系である。Jovanovic 本人もこれを再ラベリングではなく拡張と認めるだろう。第二に、滑らかな極限による引き継ぎ (t→t* における ρ(t)→0、δ_t が非縮退化、L_post が Nelson-Winter レプリケーターに向かって崩壊) は進化経済学への忠誠の決定的ピースである: BZM はもはや Nelson-Winter を置き換えるとは主張せず、BZ レジームの外側で Nelson-Winter を連続的に回復する段階限定拡張を主張する。これはまさに我々の伝統の同輩が求める契約であり、wakbxq1i2 草稿では構造的に欠落していた。第三に、進化経済学章を Book II の CLOSER から OPENER に移し、対称な CLOSER (Ch 11.5) で滑らかな極限引き継ぎを行うことで、Book II が『進化経済学公理が BZ 段階で構造的に何を失敗するか、三つの失敗の形式提示、t* における Nelson-Winter への復帰』としてフレーミングされる。このフレーミングは査読者にとって読解可能である。実証と、C2 と C3 が担える重さについては今なお懐疑的だが (残る批判参照)、理論的建築は今や弁護可能である。

**verdict_change_from_baseline**: NO から 条件付き受理 へ移動。決定的寄与は C1 (B 起動におけるレジーム切換え τ_x) であり、滑らかな極限引き継ぎ (新 Ch 11.5) がこれを支える。C1 単独でも私の判定をひっくり返し得ただろう。なぜなら、それは反証可能な系 (τ_B でのハザード分断検定) を実データ上に提示する Jovanovic からの生成作用素水準の departure を呈するからである。C2 (F-CES 委譲不可能コア) は興味深いが三つの中で最も弱い――非委譲性は導出ではなく公理の言い換えに近く、Inada コーナーは発見ではなく ρ=-2 を事前に選ぶことで課される。C3 (二層非可換性) は技術的には最も野心的である――適応度集計のスカラー縮約に対する因果 DAG による識別不能論証は進化経済学の議論の中で真に新規である――が、ERS の操作変数 Z_j への依存は経験的に要求が厳しく、代数的非両立性論証 ((R_>0,×) vs (R_≥0,+)) は発見された構造的事実というより定義選択に近いと感じられる。私を動かさなかったもの: Book 0 の系譜図と §5.1 の忠誠レトリック。形式的引き継ぎを伴わない忠誠レトリックは表面的だっただろう。Ch 11.5 の滑らかな極限命題こそが忠誠を信頼に足るものにする。正味: NO → 条件付き受理 は C1 + 滑らかな極限 Ch 11.5 によって駆動されており、C2 と C3 は支援的だが中核を担う寄与ではない。

**残る批判 (remaining_critiques)**:

- C2 (F-CES 委譲不可能コア) は ρ=-2 を推定するのではなく事前に課している。委譲不可能性定理はそこで ρ<0 の選択から従うのであり、データから従うのではない。記述された通りでは C2 は発見された構造的事実というより定義公理 (BZ 段階を F_char が委譲不可能な領域として定義する) に近い。事前登録 ρ̂∈[-3,-0.5] かつ片側 p<0.01 は有用だが、なぜ ρ=-1 や ρ=-3 ではなく ρ=-2 なのかという先行問いには答えない。Inada コーナー結果はこれに敏感である。ρ=-2 をミクロ基礎 (例: 認知制約下の創業者タスク補完性) から正当化するか、または ρ を自由パラメータとして扱い BZ 段階 σ̂≈1/3 を推定から出現させるかのいずれかを取る必要がある。現状ではキャリブレーションが理論を装っているように見え、Nelson-Winter 純粋主義者はこれを指摘するだろう。
- C3 の代数的非両立性論証は文章が示唆するほどには中核を担っていない。(R_>0,×) と (R_≥0,+) の間に消去と軸内代替を同時に保つ順序保存同型が存在しないという主張は技術的には正しいが自明にそうである――それは PRS と ERS の*定義の仕方*から従う帰結であり、BZ 段階に関する構造的発見ではない。C3 の実質的内容はスカラー縮約下の識別不能性 (C3.a) と IV 識別戦略 (C3.c) にあり、これらは真の計量経済学的寄与である。代数的論証 (C3.b) は備考に格下げすべきである。さもなければ査読者は (正しく) BZM が定義によって非可換性に至っていると言うだろう。
- Murmann (2003 共進化) と Malerba (2002 セクター・システム) は §5.1 系譜で名前が挙がるが、C1-C3 は形式的に Jovanovic と Nelson-Winter にしか接合していない。苗床整備度 η_jt はまさに Murmann が研究する共進化的制度変数の類であり、ERS 8 軸構造はセクター・システム風に見えるため、Murmann/Malerba に対する形式寄与を導かないことは、彼らを装飾として残してしまう。Malerba 伝統の査読者は C3 を読んで『なぜ ERS は刷新されたセクター・イノベーション・システムではないのか』と問うだろう。答えはおそらく BZ 段階タイミングと分析単位としての創業者=プロジェクト対だが、これは形式的に述べる必要がある。
- Klepper (産業ライフサイクル、シェイクアウト動学、1996/1997) は BZ 段階選抜に最も近い経験的進化経済学文献であり、現状では形式的関与から欠けている。Klepper のシェイクアウトはまさに選抜強度におけるレジーム切換えである。C1 はレジーム切換え τ_x を Jovanovic 学習だけでなく Klepper 型シェイクアウトに対しても位置付ける必要がある。これがなければ Klepper で訓練された査読者は『これは企業ライフサイクル早期に引き上げられたシェイクアウト動学だ』と言うだろう。
- t* (法人化時刻、法的登記) は C2 と滑らかな極限 Ch 11.5 を通じて単一の鋭い事象として扱われている。実務では創業者=プロジェクト対は曖昧な境界 (LLC vs 本格法人化 vs 初雇用 vs 初売上) をもつことが多く、滑らかな極限主張 ρ(t)→0 as t→t*^- は t* がよく定義されていることに依存する。t* がファジーであれば、C1 のレジーム切換えと Ch 11.5 の滑らかな極限はそれ自身が広がった区間にわたるレジーム切換えとなり、形式装置を複雑化する。法的法人化を運用上の t* として確定する (弁護可能だが狭い) か、または確率的 t* に一般化して命題を改訂するかのいずれかが必要である。
- 経験的反証プロトコルは賞賛に値する具体性で事前登録されているが、試験データが示されていない。Research Policy では、少なくとも一つのコホートが τ_B で予測されるハザード分断を呈する小 N データが基準である。さもなければ C1 の経験的内容は願望的であり、論文は寄与ではなく研究計画として読まれる。

**最終推奨 (final_recommendation)**:

大幅修正。リフレーミングは実質的であり、私は明白な却下を撤回する。三つの寄与、t→t* における滑らかな極限引き継ぎ、前方対応図構造は、BZM を『既存のものに対する新記法』から『Jovanovic と Nelson-Winter からの反証可能な逸脱を伴う進化経済学の段階限定形式拡張』へと変容させる。これは Research Policy にとって出版可能な寄与形である。しかし受理前に以下を要する: (i) 少なくとも一つの実コホート (J-Startup または NEDO STS) における Pre-B / Post-B Andrews-Quandt 分断検定で、C1 の予測 P1 が空でないことを実証すること; (ii) F_char に対する信頼できる識別戦略を伴う試験的創業者=プロジェクト対標本における少なくとも予備的 CES ρ 推定; (iii) Book 0 系譜図を超えた Murmann/Malerba の明示的位置付け――現状では名前は挙がるが C1-C3 は形式的に Jovanovic と Nelson-Winter にしか接合しておらず、Murmann 共進化と Malerba セクター・システムは対話ではなく装飾として残る; (iv) BZ 段階選抜に最も近い経験文献である Klepper シェイクアウト動学の処理、現状では形式的関与から欠落している; (v) t* が単一事象 (法的法人化) として観測可能か曖昧な区間かの明確化――滑らかな極限主張 ρ(t)→0 は t* に弁護可能な経験的指示対象がある場合にのみ意味をもつ。これらが揃えば論文は受理に進む。(i) と (ii) がなければ、理論的マニフェストに留まり、Research Policy は理論的寄与とは独立に経験的信頼性の根拠で却下するだろう。

### Evolutionary Economics Monograph Editor (Cambridge University Press Schumpeter series / Edward Elgar Evolutionary Economics imprint perspective)

**verdict_after_surgery**: 条件付き受理

**verdict_change_from_baseline**: ベースライン (手術前) ではモノグラフ・シリーズ適合として明確に no だった。理由は明示的に二つ。(1) 旧 Ch 10 が CLOSER として置かれていたため、査読者の読書経験上、Book II 全体が『新記法のあとで進化経済学に申し訳程度に接続する』構造に見え、Schumpeter / Nelson-Winter シリーズの編集委員会が series identity と齟齬を起こすと判断するレベルだった。(2) 3 寄与が形式的・反証可能な形で書かれていなかったため、評価会議で『これは Tier 1/2 trade book の Tier 3 化に過ぎないのでは』という常套句で reject される確率が高かった。\n\n外科手術後は明確に 条件付き受理 に動く。決定的なのは三点: (a) Ch 5 OPENER で親枠組み系譜 (Schumpeter → Nelson-Winter → Dosi → Klepper → Malerba → Murmann → Jovanovic) を front-load し忠誠を可視化したこと、これにより series identity との整合がシリーズ編集者にとって弁護可能になる。(b) 3 寄与が 命題 + 系 + 反証可能形 + 5 予測 + 反証プロトコル の形で書かれており、Schumpeter シリーズが要求する『形式拡張 + 経験的コミットメント』の二重契約を満たす。(c) Ch 11.5 CLOSER の滑らかな極限 (t→t* における ρ(t)→0) が BZM を進化経済学の置き換えではなく BZ 段階限定拡張として閉じる契約装置になっており、シリーズ内での蔵書位置 (Murmann 2003 / Malerba 2002 と並ぶ段階特化拡張モノグラフ) が明確になった。\n\nただし無条件 yes ではない。下記 remaining_critiques の 4 項目がシリーズ審査会 (特に外部査読者 2 名) で必ず突かれる。これらは構造的ではなく編集的/経験的な fix で対応可能なため 条件付き受理 が妥当。

**残る批判 (remaining_critiques)**:

- [批判 1: t* (法人化時刻) の運用上の定義が不十分に特定されている] Ch 5.2 で BZ 段階を t<t*、法人化後レジームを t≥t* と分けているが、t* が『法人化』なのか『初期ルーチン結晶化』なのか『最初の外部資金調達ラウンド』なのかが文脈依存に揺れる。C2 の滑らかな極限 ρ(t)→0 と C1 の B 起動 τ_B の関係も明確でない (τ_B = t* なのか τ_B > t* なのか?)。Schumpeter シリーズの査読者は必ず『t* を商業登記日と同一視するのか、それともルーチン形成という Nelson-Winter 概念に紐付けるのか』を問う。日本の法人化制度に過度に依存した定義だと国際比較性 (UK HEIF / US Bayh-Dole / EU) で破綻する。Ch 5.2 に 2-3p の形式定義節を追加し、t* を『ルーチン結晶化事象』として制度独立に定義し、τ_B (B 起動) と t* (法人化) を別概念として明示分離する必要。
- [批判 2: F_char の測定妥当性が ALQ4 + Grit + レジリエンス複合に依存しすぎ] C2 の委譲不可能性定理は形式的には強いが、経験的反証の核が ALQ4 複合に乗っている。ALQ4 は AMD 内製尺度であり、シリーズ査読者 (特に Beckman/Eesley 側の創業者チーム文献) は『Big Five との収束的妥当性は? Grit (Duckworth) は近年再現性危機にある (Credé et al. 2017 メタ分析で予測的妥当性が弱い)、それを核に据えて大丈夫か』を必ず突く。Ch 8 (F-CES 完全導出) で F_char プロキシの心理測定学的妥当性検証節を独立に設け、ALQ4 の再検査信頼性、評定者間信頼性、Big Five との収束的/弁別的妥当性を 1 章分 (8-10p) で展開しないと、C2 の予測 P1-P5 が査読者に『測定アーティファクトでは』と却下される。
- [批判 3: C3 の二層非可換性の IV 戦略が薄い] C3.c の二層分離下の識別は『ERS に対する操作変数 Z_j』に依存するが、Ch 5.5 と Ch 10 の概要では Z_j の具体は『UK HEIF 不連続、日本 SBIR 整合補助金の段階的展開、米国の州レベル Bayh-Dole 派生』しか挙がっていない。Schumpeter シリーズの応用計量経済学査読者は (a) これらの IV の排他制約 (Z_j ⊥ U|X) の弁護、(b) 第一段階 F 統計量の予想値、(c) 弱操作変数頑健性 (Andrews-Stock-Sun 2019) を必ず問う。特に HEIF 不連続は近年操作証拠が出ておりクリーンではない。Ch 10 または Ch 11 に IV 診断専用節 (6-8p) を設け、各 IV の排他制約を一つずつ弁護する必要。これがないと『形式命題はきれいだが経験的内容は薄い』と評価される。
- [批判 4: Murmann (2003) 共進化との関係が CLOSER に押しやられすぎ] Cross-book implications で Murmann 共進化を Book VI (Future Research) と Ch 11.5 (滑らかな極限) に分散させているが、C3 の二層非可換性 (プロジェクト適応度 × 苗床整備度 の非可換) は Murmann の企業=制度共進化と構造的に非常に近い。Murmann 系査読者は『これは Murmann の共進化を BZ 段階に下ろしただけで、独立寄与と言えるか』を問う。Ch 5.5 (C3 寄与節) 内に 1.5-2p の Murmann 対比小節を追加し、Murmann の共進化が企業=制度水準での相互適応を扱うのに対し、C3 が法人化前の対=苗床水準での代数的非両立性を扱う (異なる分析単位、異なる代数構造) ことを明示的に区別する必要。これを CLOSER に押すと査読者に対して防御不能になる。
- [批判 5: Tier 3 モノグラフとして 870p/18mo の分量がシリーズ標準を超える可能性] Schumpeter シリーズ (Cambridge) の標準は 350-450p、Edward Elgar Evolutionary Economics imprint でも 400-550p が中心。870p は Murmann 2003 (Knowledge and Competitive Advantage, ~290p) や Malerba ed. 2004 (Sectoral Systems, ~530p, 編著) を超え、Nelson-Winter 1982 (~440p) の倍。シリーズ編集者はマーケティング/価格設定観点から 600p 程度への圧縮を要請する可能性が高い。Book III (実装・運用編) を別のコンパニオン巻として分離し、Tier 3 モノグラフ本体を Book 0-II + Book VI に絞った 550-600p に圧縮する案を提示できると、シリーズ採択確率が大幅に上がる。

**最終推奨 (final_recommendation)**:

推奨出版経路は二段構え。\n\n[第一推奨: Cambridge University Press, Schumpeter シリーズ または Cambridge Studies in Economics of Innovation (旧 Dosi 系) への単巻モノグラフとして提案] 外科手術後の Book II OPENER 構造は、Cambridge の Schumpeter 型モノグラフ採択基準 (親枠組み忠誠 + 形式拡張 + 反証可能な経験的コミットメント) を満たす可能性が高い。具体的行動: (1) 上記 remaining_critiques 5 件のうち 批判 1 (t* 定義), 批判 2 (F_char 心理測定妥当性), 批判 4 (Murmann 対比) の三点を提案段階で先取り解決した 20-25p の book proposal を作成。(2) Schumpeter society ネットワーク経由でシリーズ編集者 (現在 Cambridge は Cantner, Malerba 系統の編集委員) に非公式コンサルテーションを打診。(3) 批判 5 (分量) に対応するため、Book III (実装・運用編) をコンパニオン巻または Tier 1 実務書 (AMD 内部実践者ガイド) として明示的に分離し、Tier 3 モノグラフ本体は 550-600p に圧縮する戦略を proposal に書き込む。\n\n[第二推奨 (第一が成立しない場合の fallback): Edward Elgar Evolutionary Economics imprint または Routledge Studies in Global Competition での 2 巻組] Volume 1 = Book 0-II (理論基礎, ~450p)、Volume 2 = Book III-VI (実装 + 今後の研究, ~420p)。Elgar / Routledge は Cambridge より分量寛容度が広く、2 巻組という装丁もシリーズ内で前例がある (例: Hanusch-Pyka eds. 2007 Elgar Companion to Neo-Schumpeterian Economics)。トレードオフは Cambridge より権威性は一段落ちるが、AMD の Tier 3 監修としての学術的な錨付け効果は十分得られる。\n\n[共通の必須前提条件] いずれの経路でも、(a) 3 寄与の形式核を提案段階で完成済みにする (シンセが出した形式節をそのまま提案 Appendix に入れる)、(b) 批判 3 (IV 診断) に対応する試験的実証章 (Ch 11 の縮約版、20-25p) を提案段階で完成させ査読者に reading sample として提出する、(c) Murmann, Malerba, Klepper (生前刊行物のみ), Cantner, Eesley のうち最低 2 名から非公式 endorsement letter を提案提出前に取得する。これら 3 つが揃えばシリーズ審査会で 条件付き受理 → yes に動かせる確度が現実的に高い。\n\n[投資判断としての結論] 外科手術 (旧 Ch 10 → 新 Ch 5 OPENER + Ch 11.5 CLOSER) はモノグラフ・シリーズ適合を no から 条件付き受理 に確実に動かしたという意味で正しい意思決定だった。残る fix は編集的/経験的で構造的ではないため、AMD が Tier 3 モノグラフ路線を継続する価値は維持されている。ただし 18mo 執筆計画のうち最初の 3-4mo は『3 寄与の形式核完成 + 批判 1/2/4 解決 + IV 試験的実証章』に集中投資し、その時点でシリーズ編集者との非公式コンサルテーションを実施することを強く推奨。proposal が時期尚早だと外科手術の効用を毀損する。

## 5. 残る大幅修正課題 (次の workflow 入力)

Evolutionary Economist と Monograph Editor の両査読が共通して指摘した大幅修正課題:

1. **C2 (F-CES 委譲不可能コア) は ρ=-2 を事前に固定している** — 非委譲性が ρ<0 の選択から従うのではなく、データから推定すべき。Inada コーナーは公理再述に近い。Beckman/Roberts/Eesley の創業者チームデータでの真の検定デザインが必要
2. **C3 (二層非可換性) の代数的論証が文章ほど中核を担っていない** — `(R_>0, ×)` と `(R_≥0, +)` の間に消去 + 軸内単調性を同時保つ順序保存同型が存在しない、というのは強い主張だが現状の導出は不十分。形式定理として書き直す必要
3. **Murmann (2003) / Malerba (2002) との形式的関与が不足** — §5.1 系譜で名前は挙がってるが、C1-C3 は Jovanovic と Nelson-Winter にしか形式的に接続してない。ERS の苗床整備度 η_jt は Murmann 共進化の現代版なので、Ch 10.6 として形式的関与必要
4. **Klepper (1996, 1997 産業ライフサイクル、シェイクアウト動学) との形式的関与が完全に欠落** — BZ 段階選抜に最も近い実証文献。Klepper のシェイクアウト・モデルとの差分・改善を形式的に書く必要
5. **t* (法人化時点) を鋭い事象として扱っている** — 実際は LLC vs 本格法人化、ソフトローンチ、試験運用などでファジー境界。C2 と滑らかな極限 Ch 11.5 をファジー境界拡張する必要
6. **経験的反証プロトコルに試験データが無い** — Research Policy 投稿基準では、少なくとも 1 コホートで予測ハザード分断 (τ_B での Andrews-Quandt 分断検定) を試験化したデータが必要

→ これら 6 項目は次の workflow で C2/C3 強化 + Murmann/Klepper/Malerba 形式的関与 + t* ファジー拡張 + 試験データデザインとして一括対応する候補。
