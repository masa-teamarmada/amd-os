# 附則（テキストブック変更履歴）

> **この章は何か**: `/bzm` の追加・変更・削除を append-only で記録する変更履歴。BZM は理論・数式・rubric 導出の正本なので、理論変更がいつ・なぜ入ったかを消さない。

## 運用ルール

- `/bzm` の章を追加・変更・削除したら、同じ commit でこの附則へ 1 行追記する。
- 記録項目は `日時 / 対象章 / 種別 / 変更箇所 / 理由 / 変更者`。
- 数式、rubric、出典、用語定義を削除・簡略化する場合は、削除元と移植先を必ず書く。
- この附則は append-only。過去行を書き換えない。
- 実装仕様は `/spec`、使い方は `/manual` に置き、BZM には理論上必要な説明だけ残す。
