## 現行骨格の題材ズレ診断 (降格ではなく全面不採用の根拠)

現行 2.0 (送信予約17分) で場面の中心にある問いは「**この資料を出してよいか**」(内容の適否) であって、「**いつ出すか**」(時機) ではない。
- 送信予約の「十六時」はタイミングの絵に見えるが、桐山が止めた理由は時機ではなく中身 (出願前データ・未了承の一文) — 十六時が二週間後でも同じ会話が成立する = 時計は劇の外にある。
- 登記提案も、応答が「作る日に結んでおく紙」(準備物の話) で、「いつ作るべきか」の判断は誰も扱わないまま流れる。
- CEO のタイミングに至っては場面に存在しない。
- ゆえに、中心命題 v2 (三判断の「いつ」を誰の時計で決めるか) に対し**題材レベルで別の話** — 語り直し・意味層の再定義では回復不能。全面不採用 (まさ裁定)。

**中心命題 (§8 v2、唯一の的)**: Before Zero の大きな判断 (開示・設立・CEO) はどれも「いつやるか」の問題で、早すぎても遅すぎても取り返しがつかない。では「いつ」を**誰の時計で**決めるのか — 関係者の時計を読めるようになり、進む/待つ/止めるを自分の語彙で言えるようになる。

## 本命案「いつがいい、と思いますか」— めいめいの時計

**一行定義: 「いつ」という同じ問いに、正しい答えが人の数だけ返ってくる——そして、それぞれの答えが、それぞれの持ち主の時計から出てきていることには、答えた本人も、聞いた側も、気づかない話。**

### 何を撃つか

- 同じ瞬間が、ある時計の上では「早すぎ」、別の時計の上では「もう遅い」— **早い/遅いは絶対時間ではなく、誰の時計で見るかで反転する**。これが「いつやるか」問題の正体 (理論 2.3「温度差ではなく、時計の差」の物語化)。
- 幕で、観察者のつもりでいた視点人物 (支援者) 自身も、自分の時計 (プログラムの年度) で答えてしまう — **支援者も六者の一人** (表2-2 最終行)。読者は初読でその答えを「現実的で親切」と読み、討議課題で「これも同じ穴だった」に気づく — 読者自身の見落とし体験 (Ch1 v5 型の誘導を、別の型で)。
- 「止める/待つ/進むの語彙が無い」ことが幕の答えられなさとして立ち、理論 2.6 (判断語彙) の必要性へ渡る。

### あらすじ (単一場面・順行、台詞は創作ドラフト)

支援プログラムの中間メンタリングの日。六月の雨の午後、大学のインキュベーション施設。採択チームが面談室で順に、メンター陣の助言を受けていく — 発表十分、助言二十分の流れ作業。視点人物は事務局側の伴走担当、**志野** (このチームの担当)。三つ目の面談、機能性材料の准教授のチーム。発表はうまくいった (完全にポジティブな導入 — 語り手のヒントゼロ)。

助言の時間。四つの声が、順に「いつ」を答える:

1. **キャピタリスト**: 「率直に言って、想定より仕上がっています。会社化、早めに考えませんか。うちのファンドはいまが仕込みどきですし——この領域、ほかにも二チームほど動き始めていますよ」(**早く** — ファンドの時計・競合の時計)
2. **事業会社から来ているメンター**: 「うちの目線だと、逆です。慌てない方がいい。実証の数字が揃う前に会社になられると、正直、付き合い方が難しくなる。数字が出てから来年度の予算に乗せるほうが、結局は早いと思います」(**まだ早い** — 予算編成の時計。「結局は早い」— 早い/遅いが時計ごとに反転する)
3. **知財・産学連携の担当**: 「時期は、どちらでも。ただ、順序だけは守ってください。出願の前に発表や深い開示が挟まると、あとから戻せませんので」(**順序の時計** — 開示・不可逆への一言はここに凝縮、深追いしない)
4. **プログラムの事務局長**: 「プログラムとしましては、年度内に設立の見通しが立つと、次の枠にご推薦しやすいんですが」(**年度の時計**)

全員、善意。全員、根拠がある。誰も他の助言を否定しない — それぞれの持ち場から言っているだけである。研究者はメモを取る — 「早めに」と「慌てない」が、同じページに並んだところで、ペンが止まる (絵だけ。言語化しない)。

面談時間が終わる。メンターたちは次の面談室へ移り、部屋には志野と研究者が残る。片づけの手を止めて、研究者が訊く。

「志野さんは——いつがいい、と思われますか」

志野は、すこし考えて、答える。「三月に最終報告会がありますから、そこまでに『設立準備中』と言える形になっていると、恰好がつくと思います」

「……そうですよね」。研究者は小さく笑って、メモ帳を閉じた。

**幕**。志野の答えもまた「三月 = プログラムの時計」だったことに、志野は気づかない。研究者の「そうですよね」の力なさだけが、それを知っている。

### 転調部 (幕のあと・討議課題の前)

場面を閉じ、読みを裏返す — 「あの部屋で、研究者のメモ帳には四つの『いつ』と一つの『順序』が書き留められた。どれも、間違ってはいなかった。では、なぜ決まらなかったのか——それを考える前に、まず最後の問いに、自分ならどう答えたかを考えてみよう」の趣旨 (2〜3文)。

### 討議課題A (全面差し替え案 — 3問構造は維持)

**討議課題A** この日、研究者の手元には、四つの「いつ」が残りました。

1. 四つの「いつ」と一つの「順序」は、それぞれ誰の、どんな事情から出てきたものでしょうか。
2. 志野の答えは、ほかの四つの助言と、何が同じで何が違うでしょうか。
3. あなたがこの場の伴走担当だとしたら、「いつがいい、と思いますか」に、どう答えますか。

(問1 → 2.3 時計の地図 / 問2 → 支援者も六者の一人 = 表2-2 最終行 / 問3 → 2.6 判断語彙が答えの道具になる、という布石設計)

### 設計整合

- **装置 (一章一装置)**: めいめいの時計 — 同じページに並ぶ「早めに」と「慌てない」。
- **季節**: 六月・雨 (採択年度の初回中間面談が六月 = 現実整合)。**主調音**: 現行「緊迫」から「**めいめいの正しさの、噛み合わない静けさ**」へ変更 (設計表更新)。**幕**: 未決 — 閉じられたメモ帳 (物で閉じる)。
- **通奏低音**: ①時計 = 章の主題そのもの ②手の中の小さな物 = **研究者のメモ帳** (「シール」から変更、設計表更新) — 幕で閉じられて最後にもう一度映る ③「言えなかったこと」= 答えになっていない答え (志野は答えたが、答えていない)。
- **橋1→2 (再設計)**: Ch1 = 「いつ」が誰にも問われないまま設立日程が決まった (問いの不在)。Ch2 = 「いつ」がはっきり問われる — そして正しい答えが多すぎて決まらない (答えの氾濫)。§2.5 橋表の更新: 「問われなかった『いつ』の直後に、四度答えられる『いつ』。問いが生まれても、めいめいの時計で答えるなら、決まらない」。
- **読者誘導**: 初読 = 順調な中間面談・親身な助言たち・志野の現実的な締め、として流れる。討議課題2 で初めて「志野の答えも同じ穴」に気づく — 読者自身も志野の答えを「まとも」と読んでいたことごと裏returnされる。
- **問いを認識する人物を置かない**: 志野は最後まで自分の答えの意味に気づかない。研究者の当惑は「ペンが止まる」「そうですよね」の絵まで。
- **視点人物の名**: 志野 (しの) — 既存キャスト・禁止実名と重複なし。助言者は全員役割名のみ (めいめいの時計の匿名性)。
- **現実考証**: 合同メンタリングデー (VC・事業会社・知財同席) は支援プログラム実務で一般的 / ファンドの仕込み時期・事業会社の「実証前の新会社とは組みにくい」・年度内見通しで後続推薦、いずれも実務整合 / 中間面談が六月 = 年度採択の初回中間として自然。
- **実話の根**: EP-027 (めいめいに局所最適化された支援が研究者一人の上で矛盾する構図) の合成一般化。変装 L0〜L1。
- **Ch3/Ch5 との差別化**: Ch3 = 多案件×一つの物差しの不在 (配分)、本案 = 一案件×多くの時計 (タイミング) — 構図が逆。Ch5 = 一対一面談で「できています」の受信が三様、本案 = 多対一で「いつ」への発信が四様 — 方向が逆。数の装置は立てない (「四つ」を装置名にしない)。

## 対案 (簡潔)

### 対案2「二通の知らせ」
同じ朝に届く二通 — 一年前に急いで設立した案件の苦しい近況と、待ち続けた案件への「今回は見送り」(予算は他テーマへ)。午後には三つ目の案件の「いつ」を決める面談が控えている。幕 = 面談室の扉の前、未決。
- 「早すぎ/遅すぎの両側」を正面から見せる唯一の型。ただし帰結の先出しが討議の判断を誘導する構造リスクと、章頭が回想過多になる弱み。理論 2.4 (開示) への場面供給もゼロ。

### 対案3「研究者の一日」
視点を研究者に移し、一日のうちに浴びる複数の「いつ」(学生の修了相談・VCの電話・出願督促・夜の自問) を並べる。
- 命題カバーは本命と同等だが、視点人物 = 支援者系という全16話の成長譚設計 (§2 思想1) から一章だけ外れる。非推奨。

## 推奨

**本命案「いつがいい、と思いますか」を推奨。** 「いつ」という問いそのものを場面の背骨にでき、早い/遅いの反転 (時計の差)・支援者自身も六者の一人・語彙の不在、という本章理論の三点へまっすぐ橋が架かる。改修パッケージは討議課題A+2.7 が高コストだが、2.2/2.4 はむしろ理論の説明が新場面の方に良く合う。
