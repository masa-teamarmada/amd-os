**7.1 産・学・官の三重らせん——Triple Helix という主役** (1,900字)
was①。礼法は第1〜3章と同型 (批判でなく射程の確認) だが、本章は**主役1・支持2の非対称** (第3章の DCF 主役方式の変奏)。Triple Helix (Etzkowitz & Leydesdorff 2000) を主役として最も温かく: 大学・産業・政府が、それぞれの役割を保ちながら重なり合い、互いの機能を一部引き受け合う——線形モデル (大学→産業→市場) からの転換。なぜ主役か: 「追い風」を漠然と一つの量として測るのではなく、**三つの担い手に分けて測る**という発想の源であり、本章の σ_SU が三つの軸を持つのはこの理論の直接の遺産 (相続の宣言)。Leydesdorff が三者の絡み合いを情報量で測る定式化を進めた系譜は**名前だけ**紹介し、詳細は 7.4 末の Box 7-1 へ送る。キーフレーズ: 「三つの担い手に分けて数える」「線形ではなく、絡み合い」。表7-1 は 7.2 末でまとめて提示 (本節は言及のみ)。

**7.3 どの理論も、案件の「いつ」には降りてこない——射程の縁** (1,100字)
but。最短節・一点集中 (第3章の「四つの壁」のような多点分析はしない。L1 指示 = 簡潔)。三系統に共通する縁: いずれも「その領域に、いま、追い風があるか」は描けるが、「**この一件が、いま出るべきか**」という案件単位のタイミング判断には降りてこない。設立前の現場で必要なのは、まさにこの一件・この週の判断。第2章の言葉で言い直す——理論は「場の時計」を描くが、確認すべきは「自分の時計のうち、どれが鳴り、どれが黙っているか」。加えて、期待の波 (ハイプ) の存在は描けても、「いま自分の目の前の風は本物か、言及だけか」を**内訳で**分ける道具ではない。therefore への渡し: 「そこで、追い風を雰囲気ではなく、一件ごとに構成できる一つの観測量に落とします」。キーフレーズ: 「場の風は描けても、この一件の"いつ"には降りてこない」。

**7.4 追い風を、雰囲気ではなく観測量にする——投入シグナル σ_SU の構成** (2,050字)
therefore①判定層 (数式アイテム1)。教育順 = 直感→式→式後の日本語。直感: 追い風とは、学・産・官の三つの勢いが**揃って**動いている状態。どれか一つだけ強くても風にはならない (公募だけ出ても産業が動いていなければ)。三者の"揃い"を一つの数にする。式: σ_SU = ∛[(μ_A+1)(μ_I+1)(μ_G+1)] − 1。μ_A = 学の勢い、μ_I = 産の勢い、μ_G = 官の勢い (基準からの相対的な高まりを表す無次元量。表7-2 で観測源と対応: μ_A↔論文・研究の動き/μ_I↔投資・企業の探索/μ_G↔政策・公募——演習の三系列と一対一)。式後の読み下し3点: ①**なぜ立方根**——三つを掛けたままでは尺度が膨らむので、立方根で個々の μ と同じ土俵に戻す。三つが等しく μ なら σ_SU = μ (スケールの直感) ②**なぜ +1**——勢いは冷え込むとゼロ近傍にもなり、素の掛け算はそこで壊れる。+1 の下駄 (第3章 3.6 で名前だけ出た「小さな下駄」のここでの具体例——一般原理は再解説しない、数値手続きは第9章) を履かせると、一つが冷えても全体が破綻せず、三つとも動いていない「無風」がちょうど σ_SU = 0 に対応する。末尾の −1 は無風を 0 に合わせる操作 ③**符号が読める**——σ_SU > 0 は追い風、< 0 は向かい風、0 は無風 (一文のみ。極端な負値には立ち入らない)。**乗法の読み分け (整合の要)**: 同じ掛け算でも階層で読み方が違う——第1章 1.4 の P×R×S の乗法は「互いに代替しにくい」掛け算 (弱い因子が全体を強く引きずり下げる)、いま作った σ_SU の内部は +1 の下駄のぶん「代替的」な掛け算 (一つの弱さを他の二つがある程度まで補える。生存を支える要素どうしの補い合い——第3章 表3-3 の第2行——の一例)。インライン数値例: (0.6, 0.6, 0.6) → σ_SU = 0.60 / (1.5, 0.15, 0.15) → σ_SU ≈ 0.49——合計は同じ 1.8 でも、偏ると低く出る (揃いを測る数であることの実演)。基準のとり方 (正規化・校正) は第9章へ送る一句。末尾に Box 7-1 (読み飛ばし可を明示)。キーフレーズ: 「三者の"揃い"を一つの数に」「揃って動くと大きく、偏ると割り引かれる」。

**7.5 一つの数値の裏側——判定層と動学層、そして状態空間モデル** (2,200字・最重量)
therefore②動学層 (数式アイテム2 = **本書初の状態空間モデル**)。**冒頭に橋渡し段落 (必須・本章の成否を分ける)**: 数式へ入る前にケースの体感へ戻る——「σ_SU という一つの数を手にしても、まだ足りません。あの会議で本当に知りたかったのは、"いま高いか"ではなく、"これから上がるのか、それとももう天井なのか"でした。一枚の写真の裏に、動いている実体があるのです」。第3章 3.6 の二層予告 (判定層 = 写真/動学層) をパラフレーズで明示回収。本体: ①**判定層**——σ_SU はある時点の追い風を写し取った一枚の写真 ②**なぜ観測からそのまま計算して終わりにしないのか (二層アーキテクチャの核心)**——真の勢い (μ_A, μ_I, μ_G) は直接は見えない。見えるのは、公募の公示・投資のニュース・論文といった、**ノイズを含み、遅れて届き、部分的にしか映さない観測**。ある週の派手な調達ニュース一本が、本物の勢いか一過性の跳ねかは、その一本だけでは分からない。だから「隠れた真の勢い」と「それを映す観測」を分けて置く ③**状態空間モデルの標準形 (2本)**——真の勢いを束ねて z_t と書く。状態方程式: z_{t+1} = A z_t + (状態の変動)——真の勢いが時間の中で動く。A の対角 = 各らせんの慣性 (今期の勢いは来期にある程度残る)、非対角 = 一方が他方を引っ張る**相互の牽引** (7.1 の「役割の引き受け合い」が数式の形でここに現れる——was の相続を therefore で受ける縦糸)。観測方程式: y_t = z_t + (観測のノイズ)——観測は真の勢いの曇った窓。行列 A は枠とラベルのみ、数値・推定には立ち入らない。ノイズは記号を置かず括弧書きの言葉で ④**Kalman filter の直感 (式なし・1点集中)**——「これまでの動きから推した予測」と「新しく届いた観測」を、**それぞれの確からしさで重みづけて混ぜる**。観測が信頼できるときは観測寄りに、ノイズが多いときは予測寄りに。この"賢い混ぜ方"を繰り返すことで、曇った窓の向こうの真の勢いを推定し続けられる——σ_SU は生の観測からではなく、この推定された勢いから作る ⑤まとめ——判定層の一つの数値の裏に、状態方程式・観測方程式からなる動学層がある。これが本書の二層アーキテクチャの最初の実演であり、第8章は生存 S について同じ構図を別の形で開く (一句の前方参照)。図7-2 (看板図版)。キーフレーズ: 「観測は曇った窓」「予測と観測を、確からしさで混ぜる」「一つの数値の裏に、動学層がある」。

therefore③内訳の読み (数式アイテム3)。冒頭で 7.4・7.5 を束ねる総括: σ_SU がハイプに強いのは**二重の仕掛け**——偏りは掛け算 (相乗平均) が割り引き (7.4 の静学)、一過性の跳ねはフィルタが割り引く (7.5 の動学)。それでも読み方の規律が二つ要る。①**ハイプ (言及だけ高い) の識別**——内訳を見ると μ_A (論文・言及) だけが跳ね、μ_I・μ_G が動いていない場合がある。三者が揃って持続的に動いてはじめて真の進展。**σ_SU の値だけでなく内訳を読む** (7.2 で受け渡した「期待の波」の語彙をここで回収)。図7-3 ②**社会受容との混同禁止**——追い風 (σ_SU) と、その技術が社会や顧客に受け入れられている度合い (社会受容) は別物。「風が吹いていること」と「顧客が受け入れ、対価を払うこと」は違う。社会受容の測り方は第5章の領土 (本文は平易語「社会受容」のみ、軸略号は出さない。論点7)。表7-3 ③**λ(t)——半外生的なブレークスルー**——追い風はなめらかに変わるだけでなく、大型調達や画期的成果という**跳び**として届くことがある。跳びの起きやすさを λ(t) と書く。「半外生的」= 外の出来事だが、その領域の蓄積 (研究の積み上がり) にも依存する、という意味。章頭ケースの「海外競合の大型調達」はこの跳びの一例 ④**前方参照 (一句のみ)**——この跳びの強さが、案件の到達の跳びを駆動する形——λ_x(σ_SU, ERS)——として第8章で再登場する (式展開・ジャンプ拡散・平面図は一切先取りしない。ERS は「苗床の整備度 (第1章で頭出しした第二のレンズ)」の語で受ける)。キーフレーズ: 「値ではなく内訳を読む」「風が強いことと、迎え入れられることは、別の時計」「なめらかな変化と、段差の跳び」。
