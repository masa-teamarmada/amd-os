## 3. 論点詳細と相場観

数字は 2026-07-13 時点の初期相場観。KDP / ISBN / 納本の制度値は公式ページで一次確認済み。印刷所外注・校正外注・表紙外注の相場は、R1 確定後に候補先別の見積りへ落とす。

### 3.0 2026-07-13 公式確認メモ (R1 判断用)

- **KDP の実体**: Amazon が用意している「自分で本を登録し、Amazon で売れるようにする出版窓口」。紙の本は注文が入るたび Amazon 側で印刷・発送されるため、発行者が在庫を持たずに紙書籍を売れる。Book A で使う場合、KDP は「一般販売の棚」兼「注文ごとの印刷所」と考えるのが一番近い。
- **KDP は電子書籍 + ペーパーバックを無料で出版可能**。Amazon 商品ページを作れる。電子書籍を KDP セレクトに入れた場合だけ、電子版の他チャネル配布が制限される。
  - source: https://kdp.amazon.co.jp/help?topicId=GHKDSCW2KQ3K4UU4
- **KDP ペーパーバック印刷原価 (Amazon.co.jp、A5=標準判、白/クリーム黒インク、110〜828p)** は `206円 + ページ数×2円`。砕木パルプ紙は `206円 + ページ数×1.9円`。標準カラーは `206円 + ページ数×3.5円` (72〜600p)。
  - source: https://kdp.amazon.co.jp/ja_JP/help/topic/G201834340
- **KDP ペーパーバックのロイヤリティ**は Amazon.co.jp では税抜希望小売価格 1,000円以上で 60%、999円以下で 50%。計算式は `(ロイヤリティ率×税抜希望小売価格) - 印刷コスト`。日本の紙書籍は税抜価格を入れ、Amazon 側で消費税が足される。
  - source: https://kdp.amazon.co.jp/ja_JP/help/topic/G201834330 / https://kdp.amazon.co.jp/ja_JP/help/topic/G201849770
- **Kindle 電子書籍の日本向け価格帯**は 35% ロイヤリティなら税込 99〜20,000円、70% ロイヤリティなら税込 250〜1,650円。2,000円超の専門書価格にするなら実質 35% 側。
  - source: https://kdp.amazon.co.jp/ja_JP/help/topic/G201849770
- **KDP 無料 ISBN はペーパーバックで利用可能**。ただし KDP でのみ使え、出版社表示は「個人出版」になる。独自の出版社名 (Team Armada 等) を出すには自己取得 ISBN が必要。
  - source: https://kdp.amazon.co.jp/ja_JP/help/topic/G201834170 / https://kdp.amazon.co.jp/ja_JP/help/topic/GTJ8LBXL6Z4WV5QX
- **日本図書コード管理センターの ISBN 出版者記号**は新規 7桁10点 = 22,000円+税、8桁シングルコード1点 = 11,000円+税、6桁100点 = 40,320円+税。書籍 JAN (2段バーコード) は別料金で、出版物売上1億円未満なら3年 10,000円+税。
  - source: https://isbn.jpo.or.jp/index.php/fix__about_8/
- **納本**は発行者義務。企業・団体・個人の自費出版物も、頒布目的で相当部数を刊行した国内出版物は対象。ISBN/JAN なしでも対象になり得る。民間出版物は原則1部、発行日から30日以内。KDP POD / 少部数直販の厳密な扱いは、発行直前に国会図書館へ確認する。
  - source: https://www.ndl.go.jp/collect/deposit/about/outline / https://www.ndl.go.jp/collect/deposit/request/qa05

### 3.1 出版経路 (R1-1)

候補は実質3案だったが、D-PUB-003 により紙の KDP ペーパーバック主戦場案は採らない。現方針は **B案: Kindle = KDP + 紙 = 高品質印刷所**。

- **A案: KDP 一本 (不採用)** — Kindle + KDP ペーパーバック (POD)。直販・献本用の在庫は KDP の「著者用コピー」(印刷原価のみで購入可) で調達。
  - 初期費用ゼロ・在庫リスクゼロ・絶版なし (注文ごと印刷)。Amazon 商品ページが紙/電子で1つにまとまる。
  - 印刷品質は POD 水準 (モノクロは十分実用、カラーはやや割高)。紙質・製本の選択肢は少ない (クリーム/白、光沢/マット表紙程度)。
  - 480〜550p モノクロ A5 の印刷原価: **1,166〜1,306円/冊** (白/クリーム黒インク、Amazon.co.jp 公式式)。60% ロイヤリティから印刷費が引かれるため、最低定価が印刷費に連動して決まる (概算: 税込 2,140〜2,400円台が下限)。専門書としては下限より高い 3,500〜5,500円帯が自然。
- **B案: Kindle = KDP + 紙 = 高品質印刷所 (採用)** — 紙質・カバー加工・製本方式の自由度が高く「見せる本」としての質感を作り込める。在庫・発送は自前。Amazon では Kindle を売り、紙は直販・献本・個別販売を主導線にする。
  - 印刷仕様の検討軸: A5 / モノクロ本文 / 480〜550p / 厚め本文紙 / PUR 無線綴じ候補 / 表紙マットPPまたは質感紙 / 背幅 25〜30mm級 / 50〜100部の初回少部数。
  - 費用は KDP より高くてよい前提。次に複数印刷所で概算見積りを取り、紙質・背幅・1冊単価・増刷単価を比較する。
- **C案: 両建て (保留・初期不採用)** — 一般販売用 = KDP ペーパーバック、直販・献本用 = 印刷所の上質版。Amazon に紙の商品ページが存在する利点はあるが、紙の品質イメージが割れるため初期方針からは外す。将来「Amazonで紙も買える状態」が必要になったら再検討。
- **観点**: 目的が「本を出せるレベルを見せる」なら、手に取る人の大半は直販・献本先 = 質感が効く相手。Amazon 上の紙商品ページより、渡した時の手触り・重み・背表紙・表紙加工の信用効果を優先する。
- **書店流通 (取次) は引き続き対象外**。必要になったら少部数取次サービスを別途検討するが、初版は Team Armada 直販・献本を前提にする。

### 3.2 名義・発行元・ISBN (R1-2 / R1-3)

- **名義・発行元は法人 Team Armada で確定 (D-PUB-002)**。奥付は「発行: Team Armada」、著者は個人名を基本形にする。製作費 (校正・表紙外注・ISBN) と売上処理は法人側に寄せて検討する。
- **ISBN 要否**: Amazon だけなら ISBN 無しでも販売可能 (ASIN)。ただし:
  - ISBN は「この紙の本はこの出版者が出した、この版のこの本である」と世界で識別するための番号。読者向けの飾りではなく、書店・図書館・取次・データベースが本を特定するためのコード。
  - ISBN + 奥付 + 発行元が揃うと「出版物」としての体裁が立つ — 目的 (信用形成) に照らすと取得推奨。
  - 取得先 = 日本図書コード管理センター。出版者記号の新規取得: **7桁10点 = 22,000円+税 / 8桁シングルコード1点 = 11,000円+税 / 6桁100点 = 40,320円+税**。名義 (個人/法人) をここで使う。
  - KDP 無料 ISBN は日本語ペーパーバックでも利用可能。ただし KDP 専用で、出版社表示が「個人出版」になるため信用形成には弱い。
  - 書籍 JAN コード (2段バーコード) と日本図書コード (Cコード・価格表記) は紙表4に載せる場合に追加手配。出版物売上1億円未満なら **3年 10,000円+税**。直販+Amazon のみなら必須ではないが、上質版・献本版の見た目を「商業書」に寄せるなら取得候補。
- **奥付の必須記載** (慣行): 書名 / 著者名 / 監修者名 / 発行日 / 版・刷 / 発行者・発行元 / 連絡先 / ISBN / © 表記 / 「落丁・乱丁」文言 / 印刷所名 (印刷所ルートの場合)。

### 3.3 判型・仕様 (R2-1)

- A5 (148×210mm) は PF-016 で確定済み。KDP 対応判型内。
- **モノクロ本文が既定路線** (数式・図版中心の専門書、カラー必須の図は現状ない認識)。KDP 標準カラーにすると 480〜550p で印刷原価は **1,886〜2,131円/冊** まで上がるため、最低価格と定価設計が重くなる。matplotlib 図のカラー設計も別途必要。
- **重要な派生論点**: 本文モノクロ確定なら、matplotlib 図版は**モノクロ最適化設計** (色分け→線種・マーカー・ハッチング分け) が必要。図版ストリーム (G) への申し送り事項。
- 550p 級の紙厚: 背幅 **概算 25〜30mm (要検証、用紙依存)**。無線綴じ (PUR) が現実的。

### 3.4 組版パイプライン (R2-3、技術検証マター)

- 入力: `book-a-ch-*.md` (markdown + LaTeX 数式 + 図参照)。
- **紙 (印刷用 PDF)**: pandoc + LuaLaTeX (jlreq / ltjsbook 系の日本語ドキュメントクラス) が本命。A5 版面設計・ノンブル・柱・目次/索引自動生成・フォント埋め込み (PDF/X 相当) まで内製可能な見込み。
- **Kindle**: pandoc → EPUB3 → KDP 入稿。**数式が最大の技術リスク** (→ §3.5)。
- 検証はこのセッション内で実際に1章分を試作して確認する (§4 にログを残す)。
- 組版を外注する選択肢 (組版会社: **概算 1p 500〜1,500円 × 550p = 30〜80万円級, 要検証**) は、内製が破綻した場合の保険として置いておく。

### 3.5 Kindle 形式と数式問題 (R2-2)

- Kindle は公式ガイド上は MathML を扱える (Kindle Publishing Guidelines §11.6、source: https://kindlegen.s3.amazonaws.com/AmazonKindlePublishingGuidelines.pdf) が、Book A は日本語・長文・数式密度・表の組み合わせが重い。**実務検証では MathML 版と数式画像 (SVG/PNG) 版の両方を作り、Kindle Previewer と実機で比較する**。
- 選択肢: (a) リフロー型 + 数式画像 — 文字サイズ変更・検索が生きる。数式の拡大品質と行内数式のベースライン揃えが課題 / (b) 固定レイアウト — 紙 PDF と同じ見た目だが文字拡大不可・ファイル巨大・教科書用途では読書体験が悪い / (c) Print Replica は一般 KDP では使えない認識 (**要検証**)。
- 数式密度が低い章 (Ch2 数式ゼロ、Ch14 ほぼゼロ) と峰 (Ch6-10) で挙動が違うため、検証は Ch6 or Ch8 級の重い章で行う。
- 実機確認: Kindle Previewer + 実機 (iPhone / Kindle 端末) での表示検証を工程に含める。

### 3.6 表紙 (R3-1)

- 紙: 前表紙 + 背 (背幅はページ数×紙厚で確定後) + 裏表紙の一体データ。KDP はテンプレート/計算機を提供。
- Kindle: 表1のみの画像 (推奨 2,560×1,600px 級)。
- デザイン: 外注 (**概算 3〜10万円**、ココナラ/クラウドソーシング〜プロ個人) か、まさが外部ツールで生成 + えいみがレイアウト整備か。**「画像生成ごまかし禁止」ルールにより、えいみが SVG/CSS で「それっぽい表紙」を自作して済ませる進め方はしない** — 本物のデザイン品質が必要な公開物。
- 専門書としての信頼感を出すなら、タイポグラフィ中心のシンプル系が定石 (有斐閣・白桃書房系の意匠)。

### 3.7 校正・校閲 (R3-2)

- 数式検算・用語整合は執筆側 6ステージ pipeline (verify 済) でカバー済み。ここで言う校正は**日本語表記の外部校正** (誤字脱字・表記ゆれ・約物)。
- 相場: **1文字 0.5〜1円 × 総字数 約28〜30万字 = 15〜30万円 (要検証)**。素読み校正のみなら下限側。
- 代替: えいみによる機械校正パス (textlint + 表記ゆれ辞書 + 独立 persona 素読み) で内製し、外部校正は「見せ先が特に重要」と判断した場合のみ発注する二段構え。
- 判断材料: 目的が信用形成である以上、**誤植の多い本は逆効果** — 最低でも内製フルパスは必須工程とする。

### 3.8 権利・法務 (R3-3)

- 本文は匿名化ルール運用済み (実話の変装水準 = PF-017、キャラ名台帳管理)。刊行前に**全章の固有名詞・実在組織残存の最終グリープ**を出版側工程として1回走らせる。

### 3.9 価格・ロイヤリティ (R2-4)

- **紙 (KDP POD の場合)**: ロイヤリティ = 定価×60% − 印刷費。550p 級の専門書相場 = **3,500〜5,500円**。例: 定価 4,400円 → 概算手取り 1,100〜1,300円/冊 (**要検証**)。
- **Kindle**: 70% ロイヤリティは**税込 250〜1,650円の制約付き** — 専門書価格 (2,000円超) を付けるなら **35% 一択**。例: 定価 2,750円 → 手取り約 960円 (概算、配信費等は入稿時確認)。
- **KDP セレクト (Kindle 独占) には入らない想定** — 入ると電子版の他チャネル配布 (PDF 直販含む) が禁止されるため、R2-5 (直販の形) を狭める。Kindle Unlimited 読み放題による発見性と引き換え。
- 直販 (紙): 定価同額か、連携先向け割引価格か。手渡し/郵送の送料・入金方法 (請求書/銀行振込/Square 等) も運用として決める。

### 3.10 税務・経理 (R3-5)

- R1-2 (名義) に従属。法人 (Team Armada) 発行なら: 製作費 (ISBN・表紙外注・校正外注・献本印刷費) = 法人経費、売上 (直販・KDP ロイヤリティ) = 法人売上。
- 個人なら: 雑所得 (または事業所得) として確定申告。KDP の税務情報登録 (源泉徴収まわり) も名義に合わせる。
- KDP ロイヤリティの入金 = Amazon から銀行振込 (月次、最低支払額あり)。受取口座の名義も R1-2 に従属。

### 3.11 納本・献本 (R3-4)

- **国会図書館納本**: 頒布目的で相当部数を刊行する出版物は発行者に納本義務。ISBN/JAN の有無に関わらず対象になり得る。発行者として奥付に載る者が原則1部を発行後30日以内に納入する。KDP POD / 少部数直販の扱いと代償金申請は、発行直前に国会図書館へ確認する。「ちゃんとした出版物」の体裁としても納本実施推奨。
- 献本: 監修者・協力者・連携先 (愛媛大・NIMS 等)・エピソード提供的な関係者。部数は R1 確定後に台帳化 (概算 20〜40部)。

### 3.12 発売後運用 (R3-6)

- 正誤表: PWA 上に正誤表ページを置き、奥付 or 巻末に URL を記載する (自費出版の弱点 = 刷り直しコストを Web 正誤表で補う)。
- 改訂: KDP は入稿データ差し替えで「刷」相当の修正が随時可能 (紙・電子とも)。大改訂 (第2版) は ISBN 別途。
- モノグラフ (Book II) や研修キット (PF-006) への導線を巻末に置くかは、公開物語彙ルールと整合させて別途判断。
