## 1.5 レンズ名の正本 (SPS / ECR — まさ確定 2026-07-11 改称)

案件レンズと苗床レンズの呼称を、以下に改称する。**式・計算は一切変えない (ラベルのみ改称、成分 P/R/S・8軸はすべて不変)**。

| 新名称 (略) | 旧名称 | 日本語正式名 | 中身 (不変) |
|---|---|---|---|
| **SPS** (Seed Prospect Score) | PRS | シーズ有望度 | M × P × R × S の乗法 (M=マクロ追い風 / P=潜在規模 / R=到達度 / S=自走力) |
| **ECR** (Ecosystem Construction Rate) | ERS | エコシステム構築率 | 8軸の加重和 (充足率・ギャップ診断) |

- **改称理由 (まさ確定 2026-07-11)**: 旧 `PRS` は成分の頭字 (P×R×S) で「3文字=積」を表す一方、旧 `ERS` (Ecosystem Readiness Score) はただの頭字語で、両者が非対称だった。3文字略語のままでは、苗床側をどう名付けても隣の PRS に引きずられて「積」と誤読される。両レンズを「呼びやすい和名 → その略称」という同じ作りに統一し、SPS/ECR がともに「和名の略」であって成分の積ではないことを明確にした。ECR は "Score" を "構築率 (Rate)" に替え、中身 (加重和=充足・ギャップ診断) と名前を一致させた。
- **経緯注記**: 旧 ERS についてまさが原設計した「E×R×S (積)」の一次ソースは現存資料から失われており、現行の加重和 (充足率) を正本として確定 (2026-07-11 調査)。SPS の中の積・ECR の中の加重和という**演算の非対称は意図的**で、第12章 (二層非可換性=案件と苗床を掛け合わせない) の土台。
- **張り替え対象マップ**:
  - 張り替える (現役): Book A 各章 (`book-a-ch-*`)・`BOOK_A_MASTER_PLAN`・`BOOKS_PORTFOLIO`・本用語集・理論正本 (`before_zero_theory`・`rt_roundtable_theory`・戦略余力 HTML)・論文 `PAPER_P1` 一式・`knowledge/` 該当ファイル・OS 章一覧 UI (`bzm-chapters.ts`)
  - 据え置く (歴史記録): `legacy/`・`textbook/`・`2026-06-*` 議論ログ・`runs/`・過去 COMMANDER ログ
  - 据え置く (実装): コード変数・DB 列 (案件スコアは DB では `amd_score` 系で PRS/ERS 列は不使用) は内部識別子として不変、表示テキストのみ改称
- **移行中の読み替え規律**: アーカイブ内の `PRS`/`ERS` は「= 現 SPS/ECR」と読む。以後の全新規執筆は SPS/ECR を使う。RT 理論の派生記号 `ERS₋ᵢ` は `ECR₋ᵢ` に改称 (§3)。

## 1.6 初期資源記号の Book A 限定改称 (S₀ → D₀ — まさ確定 2026-07-18)

状態空間 $x = (\iota, F, S_0, I)$ の初期資源 $S_0$ は、生存 (survival) $S$ / $S_t$ と同じ文字 S を使うため、添字の有無だけで両者を読み分ける負荷が読者にかかる (まさレビュー指摘 2026-07-18)。**Book A に限り**、初期資源の記号を **$D_0$** に改称する。

| 対象 | 初期資源の記号 |
|---|---|
| Book A (`book-a-ch-*.md` / `book-a-frontmatter.md` / `book-a-backmatter.md`) | $D_0$ に改称 (状態空間の初出は Ch1 §1.3) |
| モノグラフ・BZSF 理論正本 (`before_zero_theory` 等) | $S_0$ のまま (不変。Book A 内で閉じた表記変更であり理論正本は触らない) |

- **衝突チェック** (2026-07-18、候補順 W → A₀ → D₀ で検証):
  - **W は不採用** — Ch10 (第9章 GO/WAIT/NO_GO) で $\mathrm{WAIT} = (\mathcal{C}, T, W)$ の $W$=待機中作業として既に形式記号化済み (語源は Ch2)。巻頭の記号一覧にも載る現役記号。
  - **A₀ は不採用** — $A$ は Ch7 (第6章) の Triple Helix 状態遷移行列 $z_{t+1}=Az_t$、$A_k$ は Ch1/Ch10 の ECR 軸充足率として既出。A₀ でも同じ字面の近接を再生産する。
  - **D₀ を採用** — $D$ は Book A 全文で数式記号としての使用例がなく、確立された競合概念もない。初期資源 (endowment/deployable resources) の $D$ として字面衝突が起きない。
- 「同字別量の注意」(初期資源 $S_0$ と生存 $S$ は同じ文字だが別の量、という断り書き) は、この改称により **不要になったため Book A 側で削除**した (Ch1 §1.4 本文・巻頭凡例の該当項目)。$D_0$ (状態の座標) と $S$ (観測レンズの因子) は役割の異なる別量である、という区別自体は本文・記号一覧に残す。
- **モノグラフとの関係**: モノグラフでは初期資源は $S_0$ 表記のまま (Book A では読者の紛れ防止のため $D_0$ に改称)。両者を突き合わせる読者のために、モノグラフ側の $S_0$ = Book A の $D_0$ と読み替える。

## 4. 乗法 / 加重和 / 補完性の4層対応表 (A/B 両書の「式で見る」Box はこの表からのみ引く)

| 層 | 集約形 | 意味 | 教え方の注意 |
|---|---|---|---|
| SPS トップ層 (M × P × R × S) | 乗法 (Cobb-Douglas、+1 シフト実装) | 4因子は互いに代替しづらい。弱い因子が全体を強く引きずり下げる | 「ゼロなら全滅」と教えない (実装は +1 シフトでゼロ落ちしない)。「弱い軸が全体を引きずり下げる」が正 |
| M 内部 (μ_A・μ_I・μ_G) | 代替的 (相乗平均) | 産・学・官の勢いは互いに補い合える。揃うと大きく、偏ると割り引く | ハイプ識別 (μ_A だけ跳ねる) が教材 |
| S 内部 (F・R_net) | Cobb-Douglas (代替的) | 収益化 / 創業者の実行力はどちらかで補える | 自走型 (R_net で生きる) と調達型・創薬型 (F で生きる、CTB) が教材。追い風型 (量子・核融合) は「M 高 × S 低 = 風で延命」のトップ層の教材へ移す |
| F 内部 (F_char × F_cap) | **CES (補完的、ρ<0)** | 資質と経営実行力は両方必要。片方が低いと大きく崩れる | TIEM/BWE チーム対比が教材 |
| ECR (8軸) | 加重和 (充足率) | 欠けている軸を見せる (ギャップ診断)。軸7はゲート的前提条件 | 「44% でも規程ゼロなら他軸は空回り」を必ず教える |
| 層間 (SPS × ECR) | **結合禁止** (二層非可換性) | 「張るのは案件、通うのは苗床」 | UI でも合成単一スコア表示禁止 |

## 6. 領域としての Before Zero / モデルとしての BZM / 予測地平 (まさ確定 2026-08-09)

「Before Zero に特化」という表現には、診断ドメインの特化と予測地平の閉鎖という二つの読みがあり、混同すると「単年度黒字化までモデル化するのは Before Zero 逸脱ではないか」という誤読を生む。次の三分法で読み分ける (正本: `BZM_2_0_REVISION_REQUIREMENTS.md` §3.5)。

| 用語 | 定義 | 出典 |
|---|---|---|
| 領域としての Before Zero | 研究成果が世に出てから法人化に至るまでの時間。診断・介入の主戦場。AMD のコアコンピタンスと BZM の新規性主張はここに固有の測定に限定 | `field-before-zero.md` |
| モデルとしての BZM | Before Zero で観測・診断を始め、到達見込み $q$ の更新は共通到達目標への到達または停止まで続けるゼロ横断の測定体系。法人設立はゴールでも成功結果でもない | `BZM_2_0_REVISION_REQUIREMENTS.md` §3.5 / §4.8 |
| 予測地平 | $q$ が評価する到達事象の地平。第一地平は $G_{\mathrm{self}}(12\mathrm{m})$。回収・出口・投資収益は地平外で、BZSF 投資層 (`/Users/masa/projects/AMD/BZSF/` 配下で別版管理) の管轄 | `sps-2-0-reachability-model.md` §2 |

- 誤読防止: 「Before Zero Model」は「Before Zero で完結するモデル」ではなく「Before Zero という領域で観測・診断・介入し、ゼロ後の到達で検証するモデル」と読む。
- 投資判定は BZM 出力 ($q$、$\mathbf P$) + BZSF 投資層の**二階建て**。BZM 単体で GO、投資額、投入人月を決めない (診断スコア仕様の主張境界と同じ)。

## §1.7 SPSは単一系譜 — 現行版は到達見込みモデルの式（2026-08-15 まさ確定）

> 「SPSはひとつしかない。過去のモデルに欠陥があったからどんどん新しいモデルにバージョンアップしてるのに」「（到達見込みモデル章の式が）正しい式。それ以外のSPSの式は古いバージョンで抹消されるべき情報」— まさ、2026-08-15

1. **現行のSPS**は、到達見込みモデル章の $\mathrm{SPS}_{\mathrm{all},\tau}(H_{\mathrm{econ}})=\sum_o q_{o,\tau}P_{o,\tau}$（全価値実現経路の確率加重持分価値。円建て）とその族（$\mathrm{SPS}_G$ 等）である。
2. **9軸Cobb-Douglas型のスコア（旧運用SPS、$K\cdot M\cdot P\cdot R\cdot S$）は旧版**であり、現役の表示・計算・選別から退役させる。旧版の文書・数値は、結果を見てからの書き換えを排除する監査規律に従い履歴として保存するが、現役文書・画面では旧版と明示し、新しい計算に使わない。旧版UI表示（AMDスコア画面のSPS primary等）の退役は実装タスクとして別途実施する。
3. シーズ一次選別のスコア帯は、旧9軸式でなく現行SPS式による円建て帯へ差し替える（段階→入力対応表のv0.3で実施）。9軸のうちTRL等の指標は、段階仮説と状態の記述子として入力側に残ってよいが、スコアの集約には使わない。
4. 本節の初版（2026-08-15の同日早い時刻）は「SPSの名は9軸系譜に限る」と逆向きに記録した誤りであり、本改訂で置き換える。円建て量をV_all/V_Gへ改名する案も撤回する。
5. **（2026-08-16 まさ確定）価値項の差し替え＝現行版の更新**: SPSの価値項$P_o$は持分価値から**産業創出価値$P^{\mathrm{ind}}_o$**（そのシーズ事業が日本国内に生む付加価値の割引現在価値の桁。外需比率を属性併記。被害回避・効率化の便益も顧客の支払いを通じて含む＝分野除外なし）へ差し替える。$\mathrm{SPS}=\sum_o q_oP^{\mathrm{ind}}_o$が現行版。持分価値版$\sum_o q_oP^{\mathrm{eq}}_o$は$V^{\mathrm{eq}}$（持分価値量）として内部保存し（BZSFフロア型の関門・資本政策用）、SPSとは呼ばない。版統治はmeasure_version方式（DB・画面に版と単位を刻む。旧measureとの歴史比較禁止）。**旧バージョンはOSに表示しない**（持分価値版の帯・旧9軸表示とも）。定義・監査経緯の正本は[SPS_NAT_VALUE_MEASURE_PROPOSAL_2026-08-16.md](./SPS_NAT_VALUE_MEASURE_PROPOSAL_2026-08-16.md)（v0.3, masa-agreed）。
