## 4. 章型・執筆規律

- **章型 (全章統一)**: 章頭ミニケース (意思決定直前で切る A/B 分割 — A面を章頭、B面 (帰結) を章後半で回収) → 標準理論 (was) → deep-tech Before Zero での破綻点 (but) → BZM の拡張 (therefore、数式フル: 直感→式→worked example) → 演習 → 章末 (到達目標の確認 + モノグラフ読書案内)
- **文体 (PF-020、まさ確定 2026-07-12)**: 本書全体で**常体 (「である」調)**。ナラティブパートも常体の地の文で書き、外側から報告する語りではなく視点人物の内側で時間が動いている語りにする (「〜だった / 〜だ / 〜である」)。台詞 (登場人物の発話) 内部の敬語・丁寧語は保持 (人物の声)。読者への指示文 (演習・討議) は「〜してみよう / 〜考えよ / 〜を書け」の常体で統一 (「〜してください」は使わない)。制作プロセス語 (persona / workflow / PF-xxx / D-xxx / 内部ファイル名) を本文に出さない
- **語彙規律**: validation 語彙禁止 (D-033 の書籍適用)。RT は「仮説 + 検証プログラム」と明示 (D-056)。「ゼロなら全滅」と教えない (3層対応表 = glossary §4 正本)
- **数値規律 (PF-010)**: K・α 群・CES a/ρ・σ_SU 閾値 θ_σ*・CRL n₀ の採用値は書かない (校正手続きの話として扱う)。worked example は架空パラメータ。白紙チェックリスト DL 配布なし (CRL は判定演習・❌事例集形式)
- **ケース規律**: 全ケース匿名化 composite 宣言。機関は type 名のみ (D-034)。章頭ストーリーの排他は**モノグラフとの間のみ** — Book B は Book A の平易版として章頭・ケースを共有する (PF-019、2026-07-11。旧「冊子間0%共有」は A・B 間では撤回)。**実話シードと変装水準 (PF-017、まさ確定 2026-07-11)**: 章頭・実例は「実話を種にした合成事例」を既定とし、変装は「全部ぼかすが、関係者が思い当たるレベルまで生々しく」。素材在庫は `/Users/masa/projects/knowledge/EPISODE_BANK.md` (非公開・本文へ転記禁止)
- **章頭ナラティブ水準 (PF-018、まさ確定 2026-07-11)**: 章頭は漫画の1話に耐える独立したストーリー — 視点人物1名に仮名・内面・賭け金 / 台詞と具体物で進める / 起伏を作り意思決定直前か余韻でカット / 分量 2,600〜3,400字 / 理論アンカーは verbatim 保持 / 章ごとに別キャスト・実在関係者名禁止。淡々とした状況説明 (例示) は不合格。水準見本 = 第1・4・5章の章頭 (2026-07-11 正本反映)
