## 0. 最上位合否条件

次の五条件は、Book Aの理論、ナラティブ、章間設計を束ねる最上位の合否条件である。

一つでも欠けた稿は不合格とする。

1. 各章の中心命題と運用判断に直結する理論装置を、人物の選択、損失、次章制約を変える因果にする。wasの比較理論、導出、補助数式、発展BoxもA、B、C PJと美咲の物語世界へ置き、人物が比較、計算、検証、棄却、説明に使う。一項目ごとに独立事件を作る必要はないが、理論を外すと章の理解または判断根拠が欠ける状態にする。
2. 柏木美咲を全15章の主人公とし、手続には能動的だが事業帰結を負わない非主体から、限定権限、自己損失、異論義務、返却期限を引き受け、次の主体と再現可能な制度を生む独立主体へ成長させる。
3. 美咲の明るさ、翻訳、速度、招集力を開始直後から実際の選択肢を救う専門能力として見せ、その同じ強みが未成熟な段階では損失を生み、成長後には条件、損失、返却日と結びついて人と事業の未来を救う構造にする。
4. 各章を前章の帰結から始め、美咲の不可逆な選択を経て、次章でしか回収できない問いを残す。二章または三章にわたって苦痛だけを続けず、五幕それぞれに途中報酬と幕末の解放を置き、最後まで読み進めたくなる一つの職業ドラマにする。
5. 読者が「この仕事を担いたい」と思える職業上の勝利へ到達させる。正式な席、生活を守れる報酬、専用予算、協働者、後進、再依頼、他機関による導入を具体物として置き、AMD型独立主体が現場に欠けていた役割であることを事件の帰結から評価可能にする。

明確な成功は、再依頼、同行、紹介、予算化、採用、顧客との継続、契約の模倣、後進の志望、次の主体による自己署名で測る。

美咲は、前半で現場証拠と試験候補枠を生み、中盤で売上と限定権限を作り、後半で顧客、採用、研究、次の試験、交渉自由、次の主体を残す。

その強みと成長を通じて、AMD型独立主体が事業帰結を動かす経営専門職として必要とされ、職業として再生産されるところまでを最上位の合格条件とする。

理論coverageは二層で判定し、物語側の対応正本は`BOOK_A_SCENARIO_DRAFT_4.md`とする。

第一層では、各章の中心命題と運用判断に直結する理論装置が人物の選択、損失、次章制約を変えるかを見る。

第二層では、本書§9の`was`、`therefore`、数式アイテム、導出、発展Boxを同じA、B、C PJと美咲の物語世界で扱い、人物が比較、計算、検証、棄却、説明に使う。理論を外すと章の理解または判断根拠が欠けることを合格条件とするが、一項目ごとの独立事件は要求しない。

理論名を台詞や説明へ置くだけの処理と、別キャストのミニケースへ逃がす処理は、どちらの層でもcoverageに数えない。

## 4. 章型・執筆規律

- **章型 (全章統一)**: 前章帰結を受ける通しドラマの続き (不可逆な選択の直前で切る A/B 分割 — A面を章頭、B面の帰結を章後半で回収) → 標準理論 (was) → deep-tech Before Zero での破綻点 (but) → BZM の拡張 (therefore、数式フル: 直感→式→worked example) → 演習 → 次章でしか回収できない問いまたは損失を残す章末
- **文体 (PF-020、まさ確定 2026-07-12)**: 本書全体で**常体 (「である」調)**。ナラティブパートも常体の地の文で書き、外側から報告する語りではなく視点人物の内側で時間が動いている語りにする (「〜だった / 〜だ / 〜である」)。台詞 (登場人物の発話) 内部の敬語・丁寧語は保持 (人物の声)。読者への指示文 (演習・討議) は「〜してみよう / 〜考えよ / 〜を書け」の常体で統一 (「〜してください」は使わない)。制作プロセス語 (persona / workflow / PF-xxx / D-xxx / 内部ファイル名) を本文に出さない
- **語彙規律**: validation 語彙禁止 (D-033 の書籍適用)。RT は「仮説 + 検証プログラム」と明示 (D-056)。「ゼロなら全滅」と教えない (3層対応表 = glossary §4 正本)
