# AMD Score — 7 軸を一つの数値に統合する

> **ねらい**：σ_SU・5 XRL・FRL の 7 軸を、Cobb-Douglas 関数で一つの数値 AMD Score に統合する方法を示します。なぜ Cobb-Douglas なのか、シフト方式と対数校正、軸ごとの重み α、そして律速判定までを定義します。
>
> **前提**：第 2〜4 部（σ_SU・XRL・FRL の各軸）。

## 1. 統合方式 — Cobb-Douglas 関数

複数の因子を一つに統合する経済学の標準手法が、**Cobb-Douglas 関数**（Cobb & Douglas 1928）です。生産関数として 100 年間使われてきました。

$$Y = K \cdot \prod_i X_i^{\alpha_i}$$

各 $\alpha_i$ は **弾力性（elasticity）**、すなわち「$X_i$ が 1% 増えたとき $Y$ が何 % 増えるか」を表します。これにより、**軸ごとに異なる重要度を直接表現** できます。

### 1.1 なぜ等重幾何平均ではダメか

すべての軸を $\alpha_i = 1/n$ とする等重幾何平均は、「TRL の 1 増と SRL の 1 増が同じインパクト」と仮定します。これは経済学的に支持されません。Cobb-Douglas の重み $\alpha_i$ によって、軸間の相対重要度を明示します（第 1 部の設計原則 2「軸ごとに相対重要度を明示する」の実装です）。

### 1.2 なぜ min ではないのか

| 統合方式 | 性質 | 適切性 |
|---|---|---|
| 加重和 | 完全代替（一軸ゼロでも他で補える） | ✗ 律速性がない |
| min | 完全補完（一軸ゼロで全体ゼロ） | ✗ 律速が強すぎ、シーズ察知段階で全体ゼロ |
| **Cobb-Douglas** | 弾力性一定（中間） | ✓ 経済学標準、軸間重み付け可 |
| CES | 弾力性可変 | （将来拡張） |

Cobb-Douglas は CES の特殊ケース（$\rho \to 0$）であり、将来 CES 拡張で軸間の補完性をより細かく表現できます。

## 2. 7 軸の統合式

$$\text{AMD Score}_i(t) = K \cdot \prod_{X \in \{\sigma_{SU}, TRL, BRL, GRL, SRL, HRL, FRL\}} (X_i + 1)^{\alpha_X}$$

各軸 $X_i \in [0, 9]$。出てくる軸の出典は次の通りです。

| 軸 | 内容 | 出典 |
|---|---|---|
| σ_SU | マクロ追い風（Triple Helix） | 第 2 部 |
| TRL | Technology Readiness | NASA / 内閣府 SIP |
| BRL | Business Readiness | 内閣府 SIP |
| GRL | Governance Readiness | 内閣府 SIP |
| SRL | Social Readiness | 内閣府 SIP / EU H2020 |
| HRL | Human Resources Readiness | 内閣府 SIP |
| FRL | Founder Readiness | AMD 独自（第 4 部） |

## 3. シフト方式（X + 1）

### 3.1 問題 — ゼロ落ち

Cobb-Douglas は積で計算するため、**一軸でもゼロだと全体がゼロ** になります。ティエム 2012 の TRL=0 を生で扱うと AMD Score=0 となり、他軸の影響をまったく反映できません。これは AMD のスタジオ運営（シーズ察知 → 育成）を否定する設計です。

### 3.2 解決 — 全軸を +1 する

すべての軸を $\widetilde{X}_i = X_i + 1 \in [1, 10]$ にシフトしてから Cobb-Douglas を取ります。

- X=0 でも $\widetilde{X}=1$（中性値）として計算に使える。
- X=9 で $\widetilde{X}=10$。

経済学的にも、VC の log valuation で `log(1 + Y)` 形式が標準であり、Box-Cox 変換とも整合します。これにより、TRL=0 でも μ_A（基礎研究シーズ）が高ければ AMD Score が応答します。中西発明（2007）を捕捉できる設計です。

## 4. スケール校正 — IPO = 100,000

全軸が最大（$X=9$、$\widetilde{X}=10$）のとき、AMD Score が IPO 級（= 100,000）になるよう、定数 $K$ を校正します。

$$\text{AMD Score}_{\max} = K \cdot 10^{\sum \alpha_i} = 100{,}000$$

base case では重み合計 $\sum \alpha_i = 6.0$ なので、

$$K = \frac{100{,}000}{10^{6.0}} = 0.1$$

重み合計が変われば $K$ も再校正されます（UI 内で自動）。

## 5. 重み α — 軸の相対重要度

base case の重みは、まさの経営判断・先行研究・内閣府 SIP を総合して次のように置きます。

| 軸 | $\alpha_i$ | 根拠 |
|---|---|---|
| **FRL** | **1.5** | Bernstein et al.(2017): Founder Quality が VC 意思決定の最大要因。Hsu(2007): 他軸を引き上げる間接効果 |
| **σ_SU** | **1.3** | まさ判断「マクロに乗ってないなら成功確率が低い」 |
| **HRL** | **1.1** | 内閣府 SIP「HRL が TRL/BRL より重要」 |
| **TRL** | **1.0** | ディープテック中核だが「他から取り入れてよい」 |
| **BRL** | **0.6** | Lean Startup 系の事業モデル検証 |
| **GRL** | **0.3** | 規制は重要だがディープテックでは遅効的 |
| **SRL** | **0.2** | 一般受容、σ_SU と一部重複 |
| **計** | **6.0** | $K = 0.1$ で IPO 級 100,000 に校正 |

### 5.1 経済学的解釈

- **FRL / σ_SU が突出**（合計 2.8）＝ AMD のスタジオモデル哲学そのもの。「マクロに乗っているか、CEO が抜きん出ているか、どちらかが必要」。
- **HRL / TRL が中位**（合計 2.1）＝ 経営チームと技術が運用層を支える。
- **BRL / GRL / SRL が低位**（合計 1.1）＝ 重要だが他軸を引き上げる効果は相対的に弱い。

重みは UI 上でスライダー調整でき（レーン依存・フェーズ依存・利用主体依存）、変更時には $K$ が自動で再校正されます。将来的には 9 PJ retrofit から階層ベイズで最尤推定する計画です。

## 6. UI 表示の 3 大要素 — M × X × F

理論層では 7 軸が一つの積ですが、UI では「マクロ M × 会社の XRL X × CEO の FRL F」の **3 大要素** で見せます。

$$S = k \cdot M \cdot X \cdot F$$
$$M = (\sigma_{SU}+1)^{\alpha_\sigma}, \quad X = \prod_{x \in \{TRL,BRL,GRL,SRL,HRL\}}(x+1)^{\alpha_x}, \quad F = (FRL+1)^{\alpha_F}$$

哲学（まさ言語化）：「マクロトレンドの流れがあって、会社の XRL が整っていて、それを FRL の高い CEO が牽引する」。FRL は α_F=1.5 という別格の重みを持つため、XRL の積に呑み込ませず、独立した第 3 要素として表示します。

## 7. 律速判定 — 次に手当てすべき軸

第 1 部の設計原則 4「構成軸が経営アクションに直結する」を実装するのが律速判定です。「1 段階上げたときに AMD Score が最も大きく増える軸」を律速と定義します。Cobb-Douglas の偏微分から、

$$\frac{\partial S}{\partial X_i} = K \cdot \alpha_i \cdot (X_i+1)^{\alpha_i - 1} \cdot \prod_{j \neq i}(X_j+1)^{\alpha_j} = \frac{\alpha_i \cdot S}{X_i + 1}$$

したがって 1 段階あたりのスコア増分は $\alpha_i / (X_i + 1)$ に比例し、律速軸は次で与えられます。

$$\text{bottleneck}(t) = \arg\max_i \frac{\alpha_i}{X_i(t) + 1}$$

**経済的解釈**：重み $\alpha_i$ が大きい（本質的に効く）のに値 $X_i$ が低い軸 ＝ 投入の限界収益が最も高い軸 ＝ 最初に手当てすべき軸。

> **過去の実装バグ（教訓）**：旧実装は $\arg\min$（寄与シェア）で律速判定していましたが、これは「α が小さい軸が常に律速」になる退化したロジックで、α_SRL=0.2 が最小のため SRL が常に律速と表示される回帰がありました。Cobb & Douglas（1928）の偏微分定義に揃えて修正済みです。数学的な定義に忠実であることが、正しい経営示唆を生みます。

## 9. Valuation との関係

AMD Score の対数は、log valuation と同じ単位として読めます。

| Stage | Valuation | AMD Score |
|---|---|---|
| Seed | 〜1 億円 | 〜1,000 |
| Series A | 〜10 億円 | 〜10,000 |
| Series B | 〜50 億円 | 〜30,000 |
| IPO | 〜200 億円 | 〜50,000–100,000 |

これにより、第 1 部で予告した **補完関係** が読めます。

- AMD Score 高 + Valuation 低 ＝ **過小評価**（買い場）
- AMD Score 低 + Valuation 高 ＝ **過大評価**（バブル警戒）
