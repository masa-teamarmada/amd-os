# Chapter 4: 起業家として立つ部屋、CEOを問われる部屋

発表の翌朝、研究者はまだ少し高揚していた。

前日の会場では、いつもより大きな拍手が起きた。研究室の言葉ではなく、社会に出すための言葉で話せた。技術の説明は削り、用途を絞り、企業候補の反応も入れた。最後のスライドには、あの一文が残っていた。

「この技術は、二年以内に産業実装を目指します」

審査員の一人は、研究者に言った。

「すごく起業家らしくなりましたね」

その言葉は、研究者を少し安心させた。前に立ってよかったのだと思えた。研究成果を社会に出す話を、自分の言葉で語ってよかったのだと思えた。

ところが翌朝、別の会議で同じ資料を開くと、空気は変わった。

投資家経験のある人が、資料のチーム欄を見ながら言った。

「いいですね。ただ、誰が会社を経営するんですか」

若い事業化人材が、少し急いで答えた。

「先生には技術と事業の中心に立ってもらいながら、経営人材も探していく想定です」

相手はうなずいた。

「研究者がCEOをやるのは、かなり難しいと思います。早めに外部CEOを連れてきた方がいいかもしれません」

研究者は笑っていた。けれども、資料の端に置いた手が止まった。

昨日は、前に出たことを褒められた。今日は、前に出るには足りないと言われている。自分はこの会社の顔なのか。それとも、会社になる前に脇へ下がるべき人なのか。

誰も研究者を傷つけようとしていない。支援プログラムが研究者に起業家らしい発表を求めるのも、投資家が経営者を問うのも、それぞれ理由がある。研究者本人が語らなければ、技術の中心は伝わらない。資金を入れる側から見れば、会社を毎日動かす人が必要になる。

問題は、二つの部屋がつながっていないことだった。

前日の部屋では、研究者本人の言葉が事業化の証拠になった。翌朝の部屋では、研究者本人だけでは会社が動かないという不安が出た。その落差を、誰も資料の中に書いていなかった。

若い事業化人材は、ホワイトボードに「CEO候補」と書きかけて、手を止めた。

候補者の名前を並べても、研究者の沈黙は消えない気がしたからだ。

代わりに、こう書いた。

「まだ誰も持っていないもの」

そこから会議は、少しだけ別のものになった。

技術の意味を語る人はいる。研究者本人だ。社会に出したい理由を、自分の研究人生の言葉で語れる人もいる。これも研究者本人だ。

でも、企業候補の「面白いですね」を、予算者と導入条件へ戻す人はまだ弱い。資本政策を設計する人もいない。採用候補に、何を任せるのかを決める人もいない。大学との利益相反、知財ライセンス、研究室との距離を毎週調整する人も、まだ名前がない。

外部CEOという言葉は、便利だった。足りないものを一気に埋めてくれるように見えた。

けれども、外部CEOを入れるという言葉の中にも、いくつもの別の機能が混ざっていた。顧客を読む人。資金を集める人。採用する人。契約を進める人。研究者の言葉を守りながら、会社の言葉へ翻訳する人。厳しいときに、研究者を前に出すのではなく、研究者の納得を先に取りに行く人。

その全部を一人で持つ人は、なかなかいない。

研究者は、しばらく黙ってから言った。

「僕がCEOをやるかどうかより、僕がどこから外されるのかが怖いです」

その言葉で、会議の焦点が変わった。

投資家経験のある人は、すぐには反論しなかった。

代わりに、資料の一文を指差した。

「この技術は、二年以内に産業実装を目指します」

「この文を、外部CEO候補が投資家の前で読むとしたら、どこまで弱めて言える必要がありますか」

研究者は少し考えた。

「二年以内に、ではなく、二年以内に何を確かめるか、です。産業実装を約束しているわけではない」

会議室の空気が、もう一段静かになった。

外部CEOが必要かどうかを話す前に、その人が研究者の守る線を強めずに復唱できるかを見る必要があった。さらに、企業や投資家に悪い知らせを伝えるとき、研究者へ戻す前にきれいな言葉へ薄めてしまわないかを見る必要があった。

外部CEO候補のfitは、経歴の強さだけでは測れない。

研究者の弱い文を、弱いまま外へ運べるか。払われなかった理由や予算者不在を、見栄えの悪い事実として先に言えるか。そこが見えなければ、外部CEOという言葉は補完ではなく、研究者を中心から遠ざける言葉になってしまう。

研究者CEOか、外部CEOか。その二択を急ぐ前に、研究者を会社の中心から外してはいけないものがある。技術の真正性。社会に出す理由。まだ言ってよいことと言ってはいけないことの境界。研究者本人が、これは自分の研究の延長だと思える感覚。

一方で、研究者に背負わせてはいけないものもある。資金繰りを毎週見ること。契約と株主と採用を一人で回すこと。投資家、企業、大学、行政の期待を同時に受け止めること。

二つを分けたとき、CEOという肩書きは少しだけ小さくなった。

大事なのは、誰をCEOと呼ぶかだけではない。会社になる前に、どの機能が空いていて、どの機能は研究者本人から切り離してはいけないかを見えるようにすることだった。

会議の最後、若い事業化人材は資料のチーム欄を書き換えなかった。代わりに、次の会議メモに一行だけ追加した。

「未割当の経営機能: 顧客条件、資金調達設計、採用、大学調整、研究者の真正性の保護」

それは、完成した答えではない。

でも、研究者を無理に起業家へ押し込む会話でも、研究者から会社を取り上げる会話でもなかった。

そしてその一行は、すぐに次の問題を呼び込んだ。役割がまだ決まっていないのに、資料はもう外へ出ようとしていた。
