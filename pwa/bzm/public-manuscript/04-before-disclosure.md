# Chapter 4: 起業家として立つ部屋、CEOを問われる部屋

支援プログラムの発表後、研究者は三人から別々の感想をもらう。

一人目は言う。

「すごく起業家らしくなりましたね」

二人目は言う。

「ただ、投資家に見せるならCEOの説明が弱いですね」

三人目は言う。

「外部の経営人材を入れる話も、そろそろ考えた方がいいかもしれません」

研究者は笑ってうなずく。けれども、心の中では引っかかっている。

いま褒められたのは、自分が前に立ったからではなかったのか。次に求められているのは、自分が下がることなのか。

GAPファンドや初期の事業化プログラムでは、研究者が前に立つ。

審査や成果発表では、研究の言葉だけでは足りない。誰の課題を解くのか。市場はどれくらいあるのか。どの企業と検証するのか。将来、会社にする可能性はあるのか。研究者は、研究成果を社会に出す主人公として語ることを求められる。

発表は磨かれていく。

技術の説明は短くなる。社会的意義は伝わりやすくなる。用途仮説も、顧客候補も、資金使途も、少しずつスライドに入る。会場では、研究者の熱意が評価される。研究者本人が語るからこそ、技術の中心が見える。

ところが、資金調達や会社化の議論に近づいた瞬間、別の問いが出る。

「誰が会社を経営するんですか」
「研究者がCEOをやるのは難しいのではないですか」
「外部の経営人材を入れた方がよいのでは」

この問いも、乱暴に出てきたとは限らない。投資家は、資金を入れたあと会社が進むかを見ている。大学や支援者も、研究者一人に過剰な負荷をかけたくない。外部の経営人材を入れることで、会社が進みやすくなることもある。

それでも研究者には、二つの要求が矛盾して聞こえることがある。

ある場では、起業家として前に出ることを求められる。別の場では、起業家としては足りないと言われる。自分はこの会社の中心なのか。それとも、技術を持つ人として脇に下がるべきなのか。

これは Before Zero に繰り返し現れる鬼門の一つである。GAPファンドとVCのあいだだけで起きる特殊な話ではない。研究成果を会社らしく見せる場と、会社として本当に動くかを問う場のあいだで、研究者の役割がねじれるのである。

## 二つの部屋は、どちらも不完全な問いをしている

GAPファンドや支援プログラムが研究者に求めることには意味がある。

研究者が研究の言葉だけでなく、社会実装の言葉を持つことは、事業化の第一歩になる。研究者本人が語るからこそ、技術の意味や社会に出したい理由が伝わる。研究者が自分の研究を会社化の文脈で見直すことで、顧客、用途、知財、チームの不足も見えやすくなる。

しかし、そこで磨かれる発表能力は、会社を経営する能力そのものではない。

市場規模のスライドを作れることと、採用を進められることは違う。顧客候補に会えることと、売上責任を持つことは違う。事業化の夢を語れることと、資金繰り、契約、株主、取締役会、チームの衝突を毎週引き受けることは違う。

一方で、VCやCVCがCEOについて聞くことにも意味がある。

資金を入れたあと、会社が前に進むかを見ている。誰が意思決定するのか。顧客仮説を誰が検証するのか。採用を誰が進めるのか。次の資金調達までに、どの不確実性が下がるのか。研究者と経営者の関係は持続するのか。

ただし、この問いも万能ではない。

研究者の真正性や、大学との関係の繊細さを十分に読まないまま、外部CEOという解を急ぐことがある。経営経験だけを見て、技術の意味を語る力や研究者との信頼を軽く見ることもある。

だから、どちらの部屋の言葉も、そのまま結論にしてはいけない。

研究者を起業家として演じさせるだけでも足りない。外部CEOを入れれば解決する、でも足りない。

先に分解すべきなのは、CEO機能である。

## CEOは一つの肩書きではなく、機能の束である

会社を前に進める機能は、一つの塊ではない。

少なくとも、次のように分けて考えられる。

| 機能 | いま誰が担っているか | 研究者に残すべきか | 補完できるか | 空白なら何が起きるか |
| --- | --- | --- | --- | --- |
| 技術の意味を語る |  |  |  |  |
| 社会に出す理由を語る |  |  |  |  |
| 顧客課題を読み、用途を絞る |  |  |  |  |
| 不確実性の中で決め続ける |  |  |  |  |
| 資金調達と資本政策を設計する |  |  |  |  |
| 採用し、役割を埋める |  |  |  |  |
| 契約、知財、法務、経理を前に進める |  |  |  |  |
| 大学、企業、投資家、行政の期待を調整する |  |  |  |  |

このすべてを一人が持っていることはまれである。特に研究成果の会社化では、技術の真正性と経営実務が別の人に分かれていることが多い。

研究者が担うべき機能がある。外部経営人材が担うべき機能がある。大学や研究機関が守るべき機能がある。支援者が一時的に補える機能がある。そして、まだ誰も担っていない空白がある。

その空白を見ないまま、研究者をCEOにするか、外部CEOを入れるかだけを決めると、あとでどこかに負荷が集中する。

## 研究者の真正性を会社の外に出さない

外部の経営人材を入れる場合に最も大切なのは、研究者の真正性を会社の外に出さないことである。

研究者の真正性とは、その技術をなぜ社会に出したいのかを、自分の人生と研究の言葉で語れる力である。それは単なるストーリーではない。企業候補、採用候補、投資家、大学内の支援者が、「この技術には中心がある」と感じる源泉になる。

外部人材が経営実務を担うとしても、この真正性が会社の中心から消えると、会社は技術を借りた箱になってしまう。研究者は距離を取り、大学との関係は弱まり、採用候補も何を信じればよいか分からなくなる。

逆に、研究者の真正性を中心に置きながら、経営実務を補完できれば、研究者CEOか外部CEOかという二択を超えられる。

問うべきなのは、誰が偉いかではない。

どの機能を誰が担えば、研究成果を壊さず会社が前に進むかである。

## 明日使える問い

GAPファンド、VC面談、CEO候補探しのあいだで迷ったら、次の問いを使ってみる。

- GAPファンドで研究者に求めているのは、どの機能か。
- VCが「CEO」を聞くとき、本当に懸念している不足は何か。
- 研究者本人が必ず担うべき機能は何か。
- 外部CEOやCOOが担った方がよい機能は何か。
- 研究者の真正性は、会社の中心に残る設計になっているか。
- 会社化前に、まだ誰も担っていないCEO機能はどれか。

CEOを決める前に、CEO機能を分ける。これだけで、研究者を無理に起業家へ押し込む会話も、研究者から会社を取り上げる会話も、少しずつ減らせる。

ただし、機能を分けるだけではまだ足りない。ピッチが磨かれ、投資家や企業との会話が始まるほど、研究成果は外へ出ていく。役割が曖昧なまま資料だけが先に走ると、次に壊れるのは知財、論文、信頼、そして研究者の同意である。
