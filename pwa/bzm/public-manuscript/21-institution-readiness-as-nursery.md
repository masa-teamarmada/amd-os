# 21. 研究機関を、苗床として見る

個別シーズは強い。研究者も前向きだ。論文も出ている。企業からの関心もある。

それでも、会社化前の負荷が研究者に流れていくことがある。

知財は誰に相談すればよいのか。外部にどこまで話してよいのか。ギャップ資金はあるのか。経営人材はどこから来るのか。共同研究契約はどのくらいで進むのか。利益相反や兼業はどう扱うのか。投資家や企業との接続は誰が持つのか。

支援メニューはある。担当者もいる。けれど、最後に一枚の判断へ戻す責任の流れが見えない。

このとき見るべきなのは、研究者個人の頑張りだけではない。研究機関そのものが、会社化前の苗床としてどれだけ整っているかである。

## メニュー数ではなく、責任pipeline

研究機関の支援は、数えると多く見えることがある。URA、TLO、産学連携本部、アクセラレーター、起業教育、ギャップファンド、外部メンター、自治体連携。

けれど、メニューが多いことと、苗床が強いことは同じではない。

苗床として見るなら、問いは変わる。

| 支援メニューとして見る | 苗床として見る |
|---|---|
| URAがいるか | 事業化目利きと研究者理解ができるか |
| TLOがあるか | 出願、開示、ライセンスが事業化順序とつながるか |
| 起業講座があるか | 会社化前の判断を伴走できるか |
| VC紹介があるか | DD前の準備と資金使途を整えられるか |
| EIR制度があるか | CEO/CXO機能が研究者の信頼と接続するか |
| 規程があるか | COI、兼業、エクイティ、研究継続を動かせるか |

ERSは、この苗床の整備度を見るための言葉である。研究機関をランキングするためではない。どこが乾いていて、どこに水を入れれば次のシーズが育ちやすくなるかを見るためのものだ。

## unknownとnot_startedを分ける

機関を見るときに、よくある誤りがある。

確認できていないものを、未整備だと決めつけることだ。

たとえば、EIR制度の資料がまだ見つからない。だから「EIR制度なし」と書く。これは危ない。単に未確認なのか、本当に制度がないのかで、次の行動は変わる。

| 状態 | 意味 | 次の行動 |
|---|---|---|
| unknown | まだ確認していない | 資料、担当者、運用実態を確認する |
| not_started | 制度や運用がない | 整備課題として設計する |
| drafting | 草案や試行がある | 運用条件と責任者を詰める |
| established | 制度と実績がある | 個別シーズへ接続する |

unknownをnot_startedとして扱うと、支援者は間違った提案をする。逆にnot_startedをunknownのまま放置すると、研究者に負荷が流れ続ける。

苗床を見るとは、分からないことを分からないままにせず、確認TODOと整備課題を分けることでもある。

## 個体の準備度と、苗床の準備度を混ぜない

個別の研究シーズが強いことと、研究機関の苗床が整っていることは違う。

強い研究者がいても、知財と契約が遅ければ会社化前の開示は詰まる。顧客候補がいても、共同研究の処理が遅ければPoCは進まない。外部CEO候補がいても、大学側の兼業や利益相反の扱いが曖昧なら、関係は不安定になる。

逆に、苗床が整っていても、個別シーズのTRLやBRLが低ければ、会社化を急ぐべきではない。

だから、個体の準備度と苗床の準備度は混ぜない。個体を見るときは、技術、顧客、制度、社会、人材、創業者機能を見る。苗床を見るときは、シーズ発掘、知財、起業支援、産学連携、資金、人材供給、規程、政策接続を見る。

ERSは個別案件の点数に足すものではない。個別案件が生まれ、育ち、戻り、また次が出るための土壌を見るものだ。

## 苗床の自己点検

研究機関や支援者が最初にできる自己点検は、次のようなものになる。

| 苗床の機能 | 問い |
|---|---|
| シーズ発掘 | 誰がどの研究を事業化候補として見ているか |
| 技術評価 | 市場、知財、競合を含めて初期評価できるか |
| 知財・開示 | 出願、論文、共同研究、NDAの順序を守れるか |
| 顧客接続 | 企業の好反応を検証条件へ翻訳できるか |
| ギャップ資金 | 会社設立前の不確実性を下げる資金があるか |
| 経営人材 | CEO/CXO/EIR候補が研究者の信頼と接続できるか |
| 規程 | COI、兼業、エクイティ、研究継続を扱えるか |
| 政策・地域連携 | 公的支援や地域資源が一つの判断へ戻るか |

この表は、研究機関を責めるためのものではない。むしろ、支援者と機関が同じ地図を見て、次に何を整えるかを話すためのものだ。

## 今日の行動、まだ残る不安

今日できることは、研究機関の支援メニューを列挙するのではなく、責任pipelineとして並べ替えることだ。シーズ発掘から会社化判断まで、どこで誰が受け取り、どこで止まり、どこで研究者に負荷が流れているかを見る。

それでも不安は残る。苗床が見えたとしても、実際の現場では毎回、研究者、支援者、企業、投資家、機関の関係を編み直さなければならない。

だから次のパートでは、問い、ケース、チェックリストへ戻る。理論はここで終わらない。現場でまた使われて、また直される。
