# Chapter 18: 創業者機能を、人格評価にしない

地域PoC corridorの地図ができたあと、研究者は少し黙った。

「会社にするなら、私が代表になるんですか」

その問いは、部屋の空気を変えた。

研究者本人は、この技術の意味を深く語れる。なぜこの検査が必要なのか。どこに限界があるのか。何を急いではいけないのか。病院の医師も、研究者本人の説明には信頼を置いている。

一方で、研究者が資金調達、採用、契約、企業交渉、病院PoCの運営、大学手続き、研究室の維持まで全部持つのは無理がある。

そこへ、外部経営候補が紹介された。経歴は強い。事業開発経験もある。資金調達の言葉も知っている。だが、初回面談でその人は、研究者の出願前の慎重さを「スピード感がない」と言った。

その瞬間、研究者の顔が少し硬くなった。

創業者機能は必要である。けれど、それを「研究者が向いているか」「外部経営者が優秀か」という人格評価にしてしまうと、最も大事なものを見落とす。

## 委ねられないもの、補えるもの

作業会では、創業者機能を二つに分けた。

| 機能 | この案件での中身 | 委ねられるか |
|---|---|---|
| 技術の意味を語る | 何を解く技術で、何を約束しない技術か | ほとんど委ねられない |
| 研究として守る線 | 出願、論文、共同研究、患者への説明責任 | ほとんど委ねられない |
| 逆風時の透明性 | 分からないことを分からないと言う | ほとんど委ねられない |
| 顧客・病院ヒアリング | 誰に何を聞き、検証条件へ翻訳する | 補える |
| 資金調達・資本政策 | どの資金で何の不確実性を下げるか | 補える |
| 契約・採用・管理 | 日々の会社運営を回す | 補える |
| 大学との調整 | 兼業、利益相反、研究継続を進める | 一部補える |

後半の理論では、委ねにくい中心をF_character、補える経営実行をF_capabilityと呼ぶ。そして両方を合わせてFRL、創業者準備度として見る。

ただし、この言葉は人を裁くためのものではない。誰に何を背負わせると壊れるかを見つけるためにある。

## 三者の補完可能性を見る

この案件では、少なくとも三者がいた。研究者本人、若い事業化人材、外部経営候補である。

| 見るポイント | 研究者本人 | 若い事業化人材 | 外部経営候補 |
|---|---|---|---|
| 技術の意味を語る | 非常に強い | 学び中 | 表面的 |
| 研究者・病院からの信頼 | 強い | これから作る | まだ弱い |
| 企業への聞き取り | 時間が限られる | 動ける | 経験あり |
| 資金調達の実務 | 未経験 | 未経験 | 経験あり |
| 開示への慎重さ | 強い | 担当者と学べる | 急ぎがち |
| 大学手続きへの理解 | ある | 学び中 | 面倒に見ている |
| 毎週の統合判断 | 持ちすぎると研究が壊れる | 補助なら可能 | 信頼形成なしでは危険 |

この表から出る結論は、「誰が一番優秀か」ではない。

研究者本人を中心から外すと、技術の意味と信頼が壊れる。研究者本人に全部を背負わせると、研究と会社化の両方が壊れる。若い事業化人材は、翻訳者として育つ可能性があるが、まだ単独で責任を持つには弱い。外部経営候補は、実務を補えるかもしれないが、研究者との信頼を軽く扱うなら中心に置けない。

つまり、答えは人選ではなく設計である。

## 外部経営候補を入れる前の条件

外部経営候補を否定する必要はない。むしろ、この案件には経営実務を持つ人が必要である。

ただし、入れ方を間違えると、研究者は「自分の研究が奪われる」と感じる。病院側は「誰の技術なのか分からない」と感じる。産学連携担当者は、開示や契約の順序が崩れることを恐れる。

そこで、次の条件を置いた。

| 条件 | 確認すること |
|---|---|
| 技術への敬意 | 研究者の論文と出願前の線を理解しようとするか |
| 透明性 | 分からないことを分からないと言えるか |
| 補完範囲 | 資金調達、企業交渉、採用など何を持つか |
| 越境禁止線 | 研究者の承認なしに何を約束しないか |
| 時間コミット | 名義ではなく、毎週の実務を持てるか |
| 関係形成 | 研究者、若手人材、産学連携担当者と信頼を作る時間を取るか |

外部経営候補の経歴が強いことは、F_capabilityの一部である。だが、F_characterとの接続を壊すなら、FRL全体は上がらない。

条件を置いたあと、研究者は候補者へ一つだけ頼んだ。

「僕がまだ外に言いたくない線を、あなたの言葉で繰り返してもらえますか」

候補者は最初、少し戸惑った。市場、資金、成長戦略の話ならすぐ答えられる。だが、研究者の守る線を、投資家向けに滑らかにしすぎず、そのまま復唱するのは別の仕事だった。

一度目は、うまくいかなかった。候補者は「まだ検証途中ですが有望です」と言い換えた。研究者は首を振った。

二度目に、候補者はこう言った。

「その図はまだ出さない。用途仮説は話せるが、検証済みとは言わない。病院との会話は協力相談であって、実施合意ではない」

ここで初めて、研究者はうなずいた。

このrepeat-backは、面接の儀式ではない。外部経営候補が研究者の言葉を守ったまま、外の世界へ翻訳できるかを見る小さな実験である。

## 若い事業化人材の位置

この案件で、若い事業化人材は重要だった。

その人は、研究者ほど技術を語れない。外部経営候補ほど経営経験もない。だが、研究者の言葉を聞き、企業の質問を翻訳し、病院の不安を表にし、産学連携担当者の開示線を守りながら、次の問いを作ることはできる。

若い人材が最初に持つべきなのは、肩書きではない。

| 最初の30日で持つこと | 具体的な行動 |
|---|---|
| 聞く役割 | 研究者、病院、企業、知財担当に別々に聞く |
| 翻訳役 | 「面白い」を検証条件に、「不安」を確認TODOに変える |
| 記録役 | 事実、仮説、未確認、約束禁止を分ける |
| 信頼形成 | 研究者の守る線を先に確認する |
| 小さな責任 | 次回会議までに一つの表を埋めて戻る |

この人材は、創業者機能の一部を将来持てるかもしれない。だが、その前に、研究者と現場から信頼される翻訳者になる必要がある。

三十日後、この人材は外部経営候補より先に、一つの重要なことを知っていた。

研究者が絶対に出したくない図。病院側が気にしている作業負荷。企業の探索担当がまだ予算者ではないこと。産学連携担当者が恐れている開示の順番。投資家向け資料で強く書きすぎると壊れる一文。

これは派手な経営経験ではない。けれど、Before Zeroではかなり強い。

創業者機能を見るとき、経歴の強さだけに目が向くと、この種の記憶を軽く見てしまう。だが、研究成果を会社に変える最初の数か月では、「誰が何をまだ言ってはいけないか」を覚えている人の方が、関係を守れることがある。

FRLを読むとは、強い人を探すことではない。委ねられない中心を守りながら、どの実務を誰が育てて持てるかを見ることである。

## 次章へ残す未解決

創業者機能を分けると、人格評価の空気は薄くなった。

しかし、案件全体の判断はまだ出ていない。技術は強い。追い風もある。人の補完設計も見えてきた。だが、顧客条件、開示、社会受容、機関の責任導線にはまだ低さがある。

ここで必要なのは、総合的に高そうかどうかではない。

どの低さが、次の一手を決めるのかである。

次章では、この同じ案件に統合準備度の表を入れる。そして、期待値は高いのに、結論がGOではなくRESOURCE_SHIFTになる場面を見る。
