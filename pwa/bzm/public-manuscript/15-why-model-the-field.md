# 15. 現場をモデルにする理由

助成金の面接が近づくと、研究者の周りに言葉が増える。

「この技術は伸びる」
「政策の流れにも合っている」
「企業も関心を持っている」
「そろそろ会社にした方がいい」

どの言葉も、単独では間違っていない。けれど会議が終わったあと、支援者の手元にはまだ空白が残る。顧客は誰か。研究者はどこまで前に出るのか。外に出してよい情報はどこまでか。会社を作ったあと、最初の半年を誰が持つのか。

現場で怖いのは、誰かが嘘をつくことではない。みんなが正しいことを言いながら、違うものを見ていることだ。

## 点数ではなく、誤読を減らす地図

会社化前の議論では、強い言葉ほど人を動かす。

「社会実装」「大型市場」「政策テーマ」「投資家の関心」「大学発スタートアップ」。これらは前に進む力になる一方で、準備不足を覆い隠すこともある。見栄えのよい資料ができると、顧客検証が進んだように見える。企業面談が入ると、事業が立ち上がったように見える。研究者が堂々と話すと、経営機能まで埋まったように見える。

しかし、会社になる前の現場で本当に知りたいのは、「すごいかどうか」だけではない。

知りたいのは、次に何を確かめればよいかである。

| 現場で聞こえる言葉 | 読み間違えると起きること | 確かめるべきこと |
|---|---|---|
| 技術はすごい | 論文上の成立を、実環境での成立と混同する | 試作、再現性、運用条件 |
| 企業が面白いと言った | 好反応を顧客検証と混同する | 課題、予算、評価条件、意思決定者 |
| 政策テーマに合っている | 官の追い風だけで市場も来たと見る | 産業側、研究側、社会側の位相 |
| CEO候補がいる | 肩書きで創業者機能が埋まったと見る | 信頼、意思決定、経営実行、補完関係 |
| 支援制度が多い | 支援メニュー数を苗床の強さと見る | 責任の流れ、統合者、戻る条件 |

モデルは、この表をきれいにするためにあるのではない。会議の中で混ざってしまう言葉を、もう一度分けるためにある。

## 現場語が先で、理論語はあと

会社化前の判断では、最初から記号を出してもあまり役に立たない。研究者が不安そうにしている部屋で、いきなり数式を見せても、その不安は軽くならない。

必要なのは、まず現場語で分けることだ。

「技術は進んでいるが、顧客の痛みはまだ浅い」

「企業面談は入っているが、開示順序が危ない」

「研究者の真正性は強いが、経営実務を持つ人がいない」

「大学には支援メニューがあるが、最後に判断を束ねる人がいない」

こう言えるようになったあとで、理論語が必要になる。技術の成熟は TRL、事業の成熟は BRL、制度や開示の成熟は GRL、社会受容は SRL、人材・組織は HRL、創業者機能は FRL、研究機関の苗床は ERS と呼べばよい。

名前はあとでいい。先に必要なのは、何を混同していたのかに気づくことだ。

## ひとつの有望さに押し込めない

ある案件は、政策にも合い、論文も強く、企業からの反応もある。支援者は前に進めたくなる。けれどよく見ると、最初の顧客が曖昧で、CEO機能も空いている。知財の出し方も決まっていない。

このとき「有望だから進める」とまとめてしまうと、支援は速く見える。だが、何が未確認なのかが消える。

逆に「まだ弱いから止める」とまとめても、同じように粗い。WAITは停止ではない。戻る条件が書けるなら、それは作業計画である。

モデル化の役割は、GO / WAIT / HOLD / NO_GO / RESOURCE_SHIFT のような判断を、気分ではなく未確認事項から出すことにある。

| 判断 | 現場での意味 | 必ず添えるもの |
|---|---|---|
| GO | リスクを引き受けて前に進む | 引き受ける不確実性 |
| WAIT | 戻る条件を置いて作業する | 30〜90日の確認項目 |
| HOLD | 短い情報不足を埋める | 誰が何を確認するか |
| NO_GO | 会社化しない価値を守る | 研究価値の残し方 |
| RESOURCE_SHIFT | 最も低い条件へ資源を寄せる | 律速軸と担当者 |

地図があると、判断は冷たくなるのではない。むしろ、誰かを責めずに済む。

投資家に断られたとき、それは研究者の否定ではなく、BRLの低さかもしれない。外部経営者が合わなかったとき、それは人柄の問題だけではなく、F_character と F_capability の組み合わせを見誤ったのかもしれない。支援制度が機能しなかったとき、それは担当者の熱意不足ではなく、ERSのどこかが乾いていたのかもしれない。

## 今日の行動、まだ残る不安

今日できることは、いま扱っている案件について「有望さ」という一語を禁止してみることだ。代わりに、技術、顧客、開示、社会受容、人材、創業者機能、苗床のどこが強く、どこが未確認かを書き出す。

それでも不安は残る。軸を分けるだけでは、どの軸から手を入れるべきかはまだ決まらない。

次章では、まず「準備できている」という言葉が現場でどれだけ違う意味で使われているかをほどく。そこで初めて、TRL / BRL / GRL / SRL / HRL という名前が必要になる。
