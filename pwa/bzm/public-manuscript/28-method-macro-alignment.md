# Method Appendix M2 — マクロの追い風を分けて読む

本文では、追い風は何度も案件を急がせた。

公募の締切、企業の関心、投資家の熱、政策上の注目。どれも前へ進む理由になる。しかし、それらが同じ方向を向いているように見えても、研究成果が会社になる条件を満たしたとは限らない。

ここでは、その追い風を三つに分けて読む。

- `mu_A`: 学術側の勢い
- `mu_I`: 産業側の勢い
- `mu_G`: 政策・行政側の勢い

この三つを合わせて、マクロの整合度を `sigma_SU` と呼ぶ。

代表的な形は次のように置ける。

`sigma_SU = (((mu_A + 1)(mu_I + 1)(mu_G + 1))^(1/3)) - 1`

ここで大事なのは、三つのどれか一つだけが高くても、全体がきれいに整ったとは読まないことである。政策の追い風が強くても、企業の予算者がいないことはある。企業の技術部門が熱心でも、学術側の開示順序がまだ整っていないことはある。

マクロの追い風は、GOの許可ではない。

それは、低い条件を急いで見に行く理由である。

もう少し細かく読むなら、各モメンタムは観測量から作る。

`mu_x = sum(c_xp * y_p) / sum(c_xp)`

ここで `y_p` は観測量であり、`c_xp` はその観測量がどのモメンタムにどれくらい効くかを表す重みである。

たとえば、政策予算、研究費、論文、企業発表、投資件数、競合の増え方は、それぞれ違う方向から追い風を見せる。けれど、同じ観測でも、学術側の勢いを示すものと、産業側の勢いを示すものと、政策側の勢いを示すものでは意味が違う。

状態空間モデルのように、時間方向の動きを扱うこともできる。

`x_(t+1) = A x_t + B u_t + e_t`

`y_t = C x_t + D u_t + n_t`

ただし、この本の公開本文で重要なのは、状態方程式そのものではない。

重要なのは、追い風が強いときほど、現場の人が「もう進めてよい」と言いたくなることだ。式は、その前に一度立ち止まり、どの追い風が本当に整っていて、どの追い風がまだ文書や予算者や開示線に落ちていないかを見るために使う。

## 観測量から三つのモメンタムを作る

`mu_A`、`mu_I`、`mu_G` は、会議室で直接見える値ではない。

直接見えるのは、政策文書、公募予算、投資件数、論文、研究費、企業発表、競合の増え方のような観測量である。これらを、どのモメンタムにどれくらい効くかで重みづけして読む。

代表的には、次の七つを使う。

| 記号 | 観測量 | 主に反映するもの |
|---|---|---|
| `P` | 政策密度 | 政策・行政側の勢い |
| `B` | 公募予算 | 政策・行政側の勢い |
| `V` | VC投資・資金流入 | 産業側の勢い |
| `R` | 言及・PR・メディア露出 | 学・産・官にまたがる認知 |
| `I_R` | 研究費 | 学術側と政策側の勢い |
| `N` | 論文・研究成果 | 学術側の勢い |
| `C` | 競合密度 | 産業側の勢い |

観測量 `y_p` は、一定期間のレンジで0から9へ正規化してから使う。ある観測量がどのモメンタムに効くかを `c_xp` と置けば、次の形になる。

`mu_x = sum(c_xp * y_p) / sum(c_xp)`

たとえば、公募予算が増えても、それは主に `mu_G` を上げる。VC投資が増えれば、主に `mu_I` を上げる。論文が増えれば、主に `mu_A` を上げる。

この分解を入れると、「追い風が来ている」という一語を、少なくとも三つに割れる。

政策は来ているが、産業側の予算者がまだいない。

学術は強いが、社会実装の導入負荷がまだ見えていない。

投資家の熱はあるが、開示順序がまだ危ない。

このように読めることが、`M` を独立して置く理由である。

## 状態空間として読む

追い風は一時点の写真ではない。

学術、産業、政策は、互いに遅れて反応する。政策が先に立ち、産業が遅れて動き、学術が別の周期で進むことがある。そこで、時間方向の動きを扱うなら、状態空間モデルとして読む。

`x_(t+1) = A x_t + B u_t + epsilon_t`

`y_t = C x_t + D u_t + eta_t`

ここで `x_t` は隠れ状態、つまり `mu_A`、`mu_I`、`mu_G` のまとまりである。`y_t` は観測量である。`u_t` は外生ショック、たとえば災害、海外政策、地政学、規制変更のようなものを指す。

`A` は、三つの螺旋が互いにどう影響するかを表す。

この `A` の非対称な相互作用があると、単純な直線ではなく、遅れを持った回転、つまり螺旋のような動きが現れる。固有値で書けば、複素ペア `lambda = alpha ± i beta` が出ると、周期 `T = 2pi / beta` と減衰の速さ `tau = -1 / alpha` を読める。

ここで大事なのは、数式の難しさではない。

「政策、産業、学術は同時にそろうとは限らない」という現場の違和感を、時間を含む地図にできることが大事である。

## マクロだけではGOにしない

`sigma_SU` が高いだけでは、会社化GOにはならない。

マクロが整っていても、個別案件の技術、事業、開示、人材、創業者機能が低ければ、進め方は変わる。特に、技術を自分たちの手で次の検証へ進められるかは、別のゲートとして見る。

簡略化して書けば、次のようになる。

`GO(t) = 1[sigma_SU(t) >= theta_sigma] * g_TRL(t)`

`g_TRL(t)` は、技術側のゲートが満たされているかを見る指標である。

この式は、GOを機械的に出すためではない。

追い風が強いときほど、低い技術条件や開示条件を見落としやすい。その見落としを止めるために置く。
