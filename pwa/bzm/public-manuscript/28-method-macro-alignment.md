# Method Appendix M2 — マクロの追い風を分けて読む

本文では、追い風は何度も案件を急がせた。

公募の締切、企業の関心、投資家の熱、政策上の注目。どれも前へ進む理由になる。しかし、それらが同じ方向を向いているように見えても、研究成果が会社になる条件を満たしたとは限らない。

ここでは、その追い風を三つに分けて読む。

- `mu_A`: 学術側の勢い
- `mu_I`: 産業側の勢い
- `mu_G`: 政策・行政側の勢い

この三つを合わせて、マクロの整合度を `sigma_SU` と呼ぶ。

代表的な形は次のように置ける。

`sigma_SU = (((mu_A + 1)(mu_I + 1)(mu_G + 1))^(1/3)) - 1`

ここで大事なのは、三つのどれか一つだけが高くても、全体がきれいに整ったとは読まないことである。政策の追い風が強くても、企業の予算者がいないことはある。企業の技術部門が熱心でも、学術側の開示順序がまだ整っていないことはある。

マクロの追い風は、GOの許可ではない。

それは、低い条件を急いで見に行く理由である。

もう少し細かく読むなら、各モメンタムは観測量から作る。

`mu_x = sum(c_xp * y_p) / sum(c_xp)`

ここで `y_p` は観測量であり、`c_xp` はその観測量がどのモメンタムにどれくらい効くかを表す重みである。

たとえば、政策予算、研究費、論文、企業発表、投資件数、競合の増え方は、それぞれ違う方向から追い風を見せる。けれど、同じ観測でも、学術側の勢いを示すものと、産業側の勢いを示すものと、政策側の勢いを示すものでは意味が違う。

状態空間モデルのように、時間方向の動きを扱うこともできる。

`x_(t+1) = A x_t + B u_t + e_t`

`y_t = C x_t + D u_t + n_t`

ただし、この本の公開本文で重要なのは、状態方程式そのものではない。

重要なのは、追い風が強いときほど、現場の人が「もう進めてよい」と言いたくなることだ。式は、その前に一度立ち止まり、どの追い風が本当に整っていて、どの追い風がまだ文書や予算者や開示線に落ちていないかを見るために使う。
