# §1.0 章頭フック — 三人の起業家、三つの「測れなさ」

本書が扱う時間を、最初にひとことで確定させておきます。**Zero = 会社を設立する瞬間**。世にあふれる「ゼロイチ (0 → 1)」の本が描くのは、設立した会社が製品・顧客・組織を 0 から 1 へ育てていく時期です。本書が立つのはその一段手前——会社になるかどうかさえまだ決まっていない時間、**Before Zero (ビフォア・ゼロ = ゼロより前)** です。Ch 1 はその Before Zero を「測る」とはどういうことかを、状態空間 (state space = プロジェクトの取りうる姿の集合) と観測量 (observable = そこから外に見える代理指標) という二つの言葉で立て直す章です。§1.0 はその章頭フック (chapter-opening hook = 章全体を引き受ける入口) として、まず読者を「同じ問いの前に立ち尽くす三人」の場に連れていきます。

ゼロイチを論じる本は本棚を埋めるほどあるのに、ゼロより前を正面から扱う本はほとんどありません。研究者の頭のなかにだけ仮説がある段階、共同創業者候補が三人いるけれど誰も辞表を出していない段階、特許出願は済んだが事業計画はまだ白紙の段階——こうした「会社未満」の時間にこそ、その後の十年を左右する判断が詰まっています。誰と組むか、どの応用領域を選ぶか、いつ法人化するか、知財をどこに帰属させるか。判断のたびに当事者は「いま、このプロジェクトはどこにいるのか」を測ろうとします。けれど製品はなく、売上はなく、会社自体がまだない。それなのに、産学連携本部の担当者も、ベンチャーキャピタル (venture capital = 未公開株に投資する投資家) のキャピタリストも、地方公設試 (公設試験研究機関 = 都道府県が運営する応用研究・技術支援の拠点) の研究員も、毎週のように同じ問いを突きつけられている。問いは同じ。相手も領域も段階もばらばら。それでも全員が、同じ場所で立ち尽くす。この既視感の正体を言語化することが、Ch 1 全体——ひいては本書 Book I 全体——の出発点になります。難しい数式や定義は §1.1 以降にまわします。§1.0 ではまず、問いの肌触りを読者の手の届く距離まで持ってくることに専念します。

§1.0 は四つのサブセクションで構成されます。§1.0.1 では、2024 年初秋の一週間に開かれた三つの面談——月曜の国立大学 (ペロブスカイト太陽電池)、水曜の都内 VC (創薬ポスドク)、金曜の地方公設試 (陸上養殖) ——を並べ、領域も段階も相手も違う三人が同じ問いの前で立ち尽くす場面を描きます。§1.0.2 では、その共通項を、状態 (state = 見えない真実) と観測量 (observable = 見える代理指標) のずれとして整理し、Before Zero ではこのずれが他のどの段階よりも大きくなる理由を示します。§1.0.3 では、それでも測ろうとする三つの実務的要請——共通言語・判断の構造化・再現可能性——を立てます。§1.0.4 で、§1.1 以降のロードマップと、二層観測 (PRS = Project Readiness State / ERS = Entity Readiness State) という本書独自の道具立てへの橋を予告します。

§1.0 を読み終えたとき、読者の手元には「Before Zero を測ることは原理的に難しいが、それでも測らなければならない」という、本書全体を貫く緊張が残っているはずです。その緊張を抱えたまま、まずは月曜日の朝、国立大学のキャンパスの一室へ——。
