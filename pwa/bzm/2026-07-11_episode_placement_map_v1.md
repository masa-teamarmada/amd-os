# エピソード配置設計マップ v1 — 全エピソードを Book A のどこに置くか

*目的: 「Book A = 全部盛り」(PF-019) の実装。EPISODE_BANK の全エピソードを Book A のどのスロットに置くかを1枚に並べ、まさが1件ずつ判断できるようにする。ここで方向を確定し、以後は章起草・改稿のたびにこのマップに沿って配置する。*

*作成: 2026-07-11 第5セッション / まさ「すべてのエピソードを Book A に入れるなら、どこに入れるかの設計をここでしないと」を受けて。*

---

## 考え方 (まず3つだけ)

1. **エピソードはナラティブ用が既定** (まさルール)。置き先は【章頭】【囲みコラム】【討議・演習のケース】【著者の声=序章/あとがき/章の導入】が基本。**理屈の途中に「実例」として埋めるのは、まさが「これはいい」と言った時だけ**。
2. **章頭は1章に1つ**。すでに埋まっている章に強い実話が来たら、勝手に上書きせず、差し替え / A・B分割 / コラム化 のどれかで「組み替え」を提案する。
3. 下にいったん全部置いた。まず全体像 → そのあと「今決めてほしい要点」を絞ってある。**枠が足りなければ章を組み替える前提**なので、「入らないから捨てる」はしない。

## 今、決めてほしい要点 — ここだけ答えれば動けます

**要点1 — 著者の声3件 (B)**
EP-030 (傷から式を作った)・EP-003 (家族の問い)・EP-015 (スタジオ設立) を、序章とあとがきに置く方向でいい? 3件とも「まさ自身の物語」で、理論の途中ではなく本の入口と出口が似合う。

**要点2 — 理屈に実話を「実例」として埋めるのは避ける、でいい?**
まさルール (エピソードはナラティブ用) に忠実にやると、上の C 群は全部【コラム】か【討議のケース】として置く (理屈の説明文には溶かさない)。それでいい? それとも「この章のこの実話は理屈の実例に使っていい」と個別に開けるものがある?

**要点3 — EP-016 (三年条項) の立て方**
独立コラム (「機能は育てられるか」)  /  Ch10の章頭をA・B二部構成にして主役に  /  のどちらで立てる?

**要点4 — EP-022 (CLG・50億) の扱い**
現役の社外取として知る内部情報。使うなら深い変装＋決着後、が原則。今は「保留 (在庫に置くだけ)」でいい?

**要点5 — 章の組み替えは要るか**
第1版で並べた限り、既存の章頭を差し替える必要は無さそう (強い実話は章頭済み or コラムで足りる)。唯一 EP-023 (2機関の確執) を Ch11 (苗床) と Ch13 (円卓) のどちらの主役にするかだけ、まさの感覚を聞きたい。

## 補足 — 各章のエピソード充足の見通し

- **手厚い**: Ch2 / Ch5 / Ch6 / Ch7 / Ch10 (章頭+コラム候補が複数)
- **章頭済みだが脇が薄い**: Ch3 / Ch4 / Ch8 (コラム候補を足す余地)
- **抽象度が高くエピソードが少ない**: Ch9 (統合スコア) / Ch12 (二層非可換性) / Ch14 (出口ポートフォリオ) / Ch15 (検証) — ここは新規書き下ろしの章頭 (学長室のダッシュボード等) が主で、実話コラムは無理に足さない
