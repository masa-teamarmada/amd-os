## 0. 命名の設計原則

1. **名前を持つのは、視点人物 (支援者側) と、その章で対になる研究者だけ**。助言者・審査員・上長・来賓・投資家は役割名のまま (現行本文の実態の原則化。Ch2 v4「めいめいの時計の匿名性」、Ch6 の無人称設計を壊さない)。
2. **命名理由は「まさが人に聞かれて、自分の言葉で説明できる」水準で言語化**して本台帳に残す。観点: 音の印象 (硬さ/柔らかさ/速度感)、漢字の意味と役割・アークの響き、季節や通奏低音との呼応、姓の地域性・普遍性。
3. **衝突チェック4点** (全命名で必須):
   - ① 禁止実名リスト (§0.5) と一致・類似 (同音・一字違い) しない
   - ② 実在の著名研究者・経営者・事件関係者と紛らわしくない
   - ③ 既存キャスト同士で音・字面が紛れない (頭音・語尾・共有漢字・同系統の並び)
   - ④ 有名フィクションの強い連想を避ける
4. 各章の理論パート・討議課題が人物名を参照している場合、改名は理論側改修パッケージとセットで司令塔ゲートに載せる (NARRATIVE_DESIGN §6 条項③と同じ運用)。

## 0.5 禁止実名リスト

杉浦 / 石原 / 中島 / 中西 / 河尻 / 星野 / 會澤 / 木場 / 山地

— 一致だけでなく類似 (同音・一字違い・同字含み) も避ける。

## 2. 命名台帳 (確定順に追記)

### 2.1 柏木 (かしわぎ) — Ch1 視点人物・全16話の原型

- **役割・アーク**: URA (産学連携本部)。教授から最初の相談を受けて二年、設立前最後の支援会議に同席。五年後の三周年祝賀会で、最初の相談の日を知る人間が学内に自分しか残っていないことに気づく — 通しの見届け人、ただし仕組みの成果ではなく偶然の産物。§2.5 全体ストーリーの原型: 以降の視点人物は「柏木のその後の顔」、Ch16 の発表者が到達点。
- **命名理由 (えいみ提案)**:
  1. **柏は「新しい芽が出るまで、枯れた葉を落とさない木」**。ゆえに「代が途切れない」縁起の木とされ、柏餅の葉に使われる。柏木は、担当替えを二度はさみ、TLO 担当者が他機関へ移り、メンターの派遣が終わったあとも、ただ一人残った見届け人 — **制度の季節 (年度・異動) が何巡りしても、葉を落とさなかった木**。しかも柏の葉が落ちるのは「新芽が出たとき」— 次の世代の言葉 (本書の共通言語) が生まれるまで残る人、という全16話のアークの一行になっている。
  2. **柏手 (かしわで) の呼応**: Ch1 の幕は「柏木の手も、半拍だけおくれて、そこに加わった」— 拍手で閉じる章。柏手は神前で「気づいてもらうために打つ音」。柏木の半拍おくれた拍手は、まだ誰にも聞こえない違和感の最初の音であり、姓の中に「拍」が眠っている。
  3. **音**: かしわぎ、4モーラ。k の硬い立ち上がりに -wagi の柔らかい収まり — 生真面目で物腰のやわらかい URA の人物像。全国に分布する姓で地域色が薄く、特定の大学を連想させない。
- **衝突チェック**: ① 禁止実名 — 該当なし (「木場」と「木」を共有するが別姓・別音)。② 実在 — 著名研究者・経営者に強い柏木なし。③ キャスト内 — 旧・桐山 (Ch2) と「木偏の樹木姓」で並んでいたが、桐山は v4 で退場済み (§4)。④ フィクション — 源氏物語「柏木」帖があるが、現代の読者文脈で強い連想にならない。
- **まさ確定状況**: 維持推奨で提示済み・判断待ち (2026-07-13)。

### 2.2 志野 (しの) — Ch2 視点人物

- **役割・アーク**: 支援プログラム事務局の伴走担当。触媒チームの准教授に三か月伴走し、資料も言葉も一緒に作ってきた。「志野さんは——いつがいい、と思われますか」に、いちばん現実的な答え (= プログラムの時計) を返し、自分の答えも「めいめいの時計」の一つだったことに最後まで気づかない。討議課題A-2 が名指しで参照する (「志野の答えは、四つの助言と、何が同じで、何が違うでしょうか」)。
- **命名理由 (えいみ提案)**:
  1. **篠 (しの) = 篠竹**。細く、しなやかで、風に折れない。ただし一本では立たず、群れて生える — 主体ではなく、寄り添って支える伴走者の性質そのもの。そして Ch2 の発見は「支援者も六者の一人」= 自分も群れの中の一本にすぎなかった、ということ。篠の生態が人物のアークと同じ形をしている。
  2. **篠突く雨**: 激しい雨の慣用句。Ch2 は六月・雨の章 — 章の天候が姓の中に潜んでいる (通奏低音の季節設計との呼応)。
  3. **志野焼**: 美濃の白釉。土物のあたたかさ、飾らない白 — 誠実で腰の低い事務局員の印象。茶陶 = もてなす側・支える側の器。
  4. **字義の二重らせん**: 「志」はある、けれどまだ「野」の内にいる — こころざしを持ちながら、自分のフィールド (プログラムの年度) の外から物を見られていない人。Ch2 の幕の縮図が姓二字に畳まれている。
  5. **音**: しの、2モーラ。s の柔らかさと短さの軽やかさ — 若い伴走者。「志野さんは——」という准教授の台詞のリズムにも収まりがよい。
- **衝突チェック**: ① 該当なし。② 実在の強い連想なし (志野焼は物の名)。③ **「野」が野々村 (Ch4)・藤野 (Ch5) と重複 — §3-1 で横断判断**。④ 強い連想なし。
- **まさ確定状況**: 維持推奨で提示済み・判断待ち (2026-07-13)。

### 2.3 戸倉 (とくら) — Ch3 視点人物

- **役割・アーク**: 支援チームのリーダー・配分責任者。伴走中の有望三件は、三件とも自分が最初に機関へ持ち込んだ。過去に「有望な四件への四等分」で全部死なせた記憶を倉に抱えている (「あのときの四件の名前は、いまでも全部言えます」「動きました」の一行メールを消せない)。「三等分だけは、やめましょう。それは配分ではなくて、決めないことに付ける名前です」と言い切ったあと、比べる言葉を自分が持っていないことに直面する。
- **命名理由 (えいみ提案)**:
  1. **字義 = 役割の直喩**: 戸は開け閉てするもの、倉は蓄えの置き場。配分責任者とは、**限られた予算の倉に、どの案件へ戸を開くかを決める役**。「様式に『重点』と書ける欄は、一つきり」= 開けられる戸は一つ。
  2. **記憶の倉**: 倉は捨てない場所。四件の名前も、「動きました」の一行も、戸倉は消さずに仕舞っている。苦い記憶を保管したまま職務を続ける人の姓。
  3. **音**: とくら、3モーラ。t と k、二つの硬い破裂音 — 「三等分だけは、やめましょう」と言い切る決断の硬さ。短く止まる語感が、会議を締める側の人の口調と合う。
  4. **季節**: Ch3 は八月・熱帯夜。閉め切った蔵にこもる熱 — 三周しても出口のない配分会議の主調音 (疲労と重い記憶) と土着的に響く。
- **衝突チェック**: ① 該当なし。② 実在の強い連想なし。③ キャスト内で頭音・語尾の重複なし。④ 強い連想なし。
- **まさ確定状況**: 維持推奨で提示済み・判断待ち (2026-07-13)。

## 3. キャスト横断の衝突マップ (まさ判断待ちの論点)

固定キャスト連続ドラマ化 (A案) で「名前の重み」が増したため、章単位では成立していた名前に、通しで読むと紛れる並びがある。該当章の番で個別に扱う。

| # | 論点 | 該当 | 内容 |
|---|---|---|---|
| 3-1 | 「野」の三連続 | 志野 (Ch2) / 野々村 (Ch4) / 藤野 (Ch5) | 第一幕〜第二幕序盤に「野」姓が3人。特に志野 (しの) と藤野 (ふじの) は語尾 -の が同韻で、どちらも支援者側の視点人物 — 通し読みで紛れるリスク |
| 3-2 | 「柳」の重複 | 青柳 (Ch5) / 柳井 (Ch8) | 研究者・青柳と支援者・柳井が同じ字を持つ。役柄も章も違うが、固定キャストの人物表に並ぶと字面が近い |
| 3-3 | 実在著名経営者との同姓 | 柳井 (Ch8) | **柳井正氏 (ファーストリテイリング創業者) と同姓**。起業・経営を扱う本で「柳井」は経営者名としての既存連想が強い — 衝突チェック②に抵触の疑い。改名候補の筆頭 |

| 3-5 | 隣接章の頭音重複 | 瀬戸 (Ch9) / 世良 (Ch10) | 連続する二章の視点人物がともに「せ」始まり (せと / せら)。どちらも支援者で、Ch9→10 は「絞れない→やめると言えた」の対になる重要な受け渡し — 音で混線させたくない並び |

## 3.9 命名の通奏低音 (観察 — まさ確定後に §0 へ昇格)

現行キャストには **植物・自然物の姓が多い**: 柏 (柏木)・篠/志野・藤 (藤野)・柳 (青柳・柳井)・柴 (真柴)・笹 (笹本)。研究シーズ (種) が木になるまでを扱う本の人物名として、「支援者・研究者たちが植物の姓を負う」のは通奏低音になり得る。一方で瀬戸・世良・甲斐・戸倉・宮原・野々村は地形・土地系。**「植物系 = 現場で伴走する人 / 地形系 = 場・構造を見る人」のようなゆるい使い分けに整えるか、偶然のまま置くか**は、改名判断とセットでまさに問う。
