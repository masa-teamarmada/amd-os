## 1. ポートフォリオ構造 — 読者のジョブで切る3層

```
[学術層]  940p モノグラフ (Cambridge UP / Before Zero Studies)   ← 領域宣言・定理の初出・実証
    ▲                                          読者: 研究者・査読者
[教育層]  Book A 教科書 = 理論の集大成テキスト (数式全部入り)     ← 講義・研修採用 + 肩書に恥じない書籍
    ▲                                          読者: MBA/MOT院生・学部上級ゼミ・URA/EIR/VC研修
[現場層]  Book B 解説書 (実戦書17章ベース + RT部)                ← 現場のツールと台本
                                               読者: URA/産連/EIR/研究者 (主)、VC/事業会社 (従)
派生資産: 演習パッケージ (シーズカード / RT役割カード / ERS診断シート / 採点ワークシート)
          — 書籍に従属しない研修・AMDイベント商材として先行運用可
共通基盤: terminology_glossary (3冊共通正本) / 冊子横断ケース露出台帳 (§5) / 掲載ゲート (§6)
```

**書き分け原則**: モノグラフ = 宣言と実証 / **A = 体系と演習** / **B = ツールと台本**。
- モノグラフと A の違いは数式の量ではなく**ジョブ**: モノグラフは新領域を宣言し定理を初出させ実証する (Tier A/B 装置・査読対応・940p)。A は完成した理論体系を教育最短経路で学べる構成 + 演習 + 講義パッケージ (定理の初出はしない。導出はモノグラフ参照可、ただし式そのものは全部載せる)。
- カニバリ規律: 概念フレームワーク100%共有 / 散文重複15%未満 / 章頭ストーリー冊子間0%共有 / 主要ケースは主戦場排他 / A と B の刊行12ヶ月以上分離。

## 2. まさ確定事項 (2026-07-02 判例)

### PF-001: Book A は「理論の集大成」— 数式を読者配慮で減らさない
- **judgment**: Book A には必要な数式を**すべて**入れる。σ_SU SSM・GO最適停止・F-CES・first-passage S・ERS加重和・二層非可換性・RT機構/CRL/ICT を本文から排除しない。学術的に高い価値を持つテキストにする。
- **rationale**: まさ「おれの組み立ててきた理論の集大成となるようなテキストにしたい。読者のレベルに配慮して数式を減らすようなテキストは愛用したことがない」。ワークフロー時の「4層規律で first-passage/SSM/不可能性定理は教科書に出さない」裁定はこれにより**破棄**。残る規律は「教育的順序 (直感→式→worked example→演習)」と「校正数値の扱い (§4)」のみ — これは削減ではなく Tier 規律。
- **implications**: 体裁は 380-450p / 専門書価格帯 (4,000-5,000円) を許容。15章=15回対応は維持。

### PF-002: Book A 主対象
- MBA/MOT 大学院1年 (主) + 大学院共通アントレ科目 + 学部3-4年ゼミ + URA/EIR/VC 研修市場。学部1年は捨てる (入口は Book B)。本文の読解水準は学部上級、深さは Box と発展演習で出す。(Q1 おけ)

### PF-003: Book B 骨格 = URA案 (大学側主語・4部16章)
- VC/事業会社向けは「VC評価軸→PRS変換表」「RT参加判断チェックリスト」を章内ツール+巻末付録に圧縮。(Q2 おけ)

### PF-004: 素材リユースは実戦書ドラフト17章のみ
- **judgment**: 既存コーパスのうち**実戦書ドラフト17章だけ**をクオリティ基準・素材として扱う。textbook/ 企画文書・public-manuscript 34章は「見なかったこと」にし、品質・トーンの参照点にしない。
- **rationale**: まさ「そのクオリティに引っ張られてほしくない」(2026-07-02)。
- **implications**: 章頭ストーリーの「public-manuscript 場面バンク」構想は廃止。A/B の章頭ストーリーは実戦書由来 or 新規書き下ろし。

### PF-005: 編集上の看板主張 = 出口ポートフォリオ論
- **judgment**: 両書 (特に A) の看板主張として「**研究機関はユニコーン単願ではなく、ユニコーン〜スモールビジネス〜スモールM&A までの出口ポートフォリオを設計すべき**」を立てる。
- **rationale**: まさ「すべてのシーズをユニコーンに！みたいな風潮には辟易。スモールビジネスだって立派。そこには一石を投じたい」。「起業を止める」ケースは実際にはほとんどない — 本題はタイミング (GO/WAIT) と**サイズ・経路の選択**。
- **theory anchor**: 既確定の「絶対スケール維持 + P に対する達成率の2読み方式」(2026-06-12) がそのまま数理基盤。Book B の旧フレーミング「死なない会社だけ作る」は「シーズごとに正しいサイズの成功を」へ更新。

### PF-006: 演習パッケージに投資する
- シーズカード20枚 / RT役割カード / ERS診断シート / PRS・ERS 採点ワークシート (Excel + OS 教育開放検討)。コストと時間をかける価値あり。AMD のイベントでも使う。書籍に先行して研修・イベント投入可。(まさ「ぜひほしい！」)

### PF-007: 著者体制・チャネル (事実訂正込み)
- まさの現職: **愛媛大・工学院大イノベーションマネージャー就任済み**、香川大は来年度客員教授見込み。「教員ポスト・採用ネットワークゼロ」という市場批判の前提は**事実誤認**。出版動機の一つ = この肩書に恥じない書籍を出すこと。
- 共著: **愛媛大・石原先生** (まさにこのテーマの専門家、共著やぶさかでない反応済み = 筆頭候補)。NIMS 松本さん・香川大 永冨先生も関心を持ちそう (まさ読み、打診未)。(Q8 おけ)
- Book B 監修: 弁護士 (独禁・契約) / 会計士 (take-or-pay) / 現役URA。

### PF-008: RT は BZM の大きな要素として正式に組み込む
- **judgment**: RT を「v1 は pointer のみ」とする最小侵襲案は**破棄**。多くの PJ で組成実績がありポイントは見えている。retrofit 不足は自認した上で、**仮説として一級市民**で BZM 理論と各書に組み込む。PRS・ERS の2つに RT が有機的に絡む三項構造 (観測二層 + 結合機構) を理論として落とし込む。
- **guard**: 「仮説として組み込む」と「検証済みと主張しない」は両立させる (実証主張は Ch 26b 型の事前登録・Tier 規律で担保)。ERS 側接続の設計は `BZSF/rt_roundtable_theory.md` §13.4-13.6 (v0.2) が正本。
- **940p 本への載せ方の構造 (章の位置・ページ) は議論中** — 2026-07-02 えいみ3案提示、まさ判断待ち (Q12)。

### PF-009: 時間軸
- 2026 = ゲート整備 + モノグラフ専念 (A/B 本文着手ゼロ)。B 企画書+サンプル2章は Q4。B 本文 2027 H2 → 刊行 2027年末-2028年初。A は 2028 執筆 → 2029年4月学期。自動フリーズ条項: 2027年6月にモノグラフ Book II 確定率50%未満なら A/B 凍結。(Q5 おけ)
- 英訳工程: まさ「どちらでも。工数というかトークン料金次第。多分そんな時間かからん」→ えいみ/LLM で実施前提、費用は都度見積り。(Q10)

### PF-010: 数値開示ポリシー (3冊共通)
- 公開: ゲート構造 (GO 2軸判定の形)・レベル尺度 (CRL L0-L5 / XRL / ERS 8軸 rubric)・チェックリスト・**式の形はすべて** (PF-001)。
- 非公開: 校正定数 (K、IPO=100,000)・Cobb-Douglas 指数 α 群の採用値・CES の a/ρ 採用値・σ_SU 閾値の具体値 — これらは「校正手続きと事後分布」の話として扱う (D-006/D-032 と整合。読者配慮ではなく Tier 規律)。(Q6 おけ)
- 尺度は事例で教え、白紙チェックリストの DL 配布はしない (CRL は判定演習・❌事例集形式)。

### PF-011: その他確定
- 独禁 §7.3 弁護士確認 = **やる** (Q4)。KENQ・Book B RT部・ERS 2-e rubric の三つが待つクリティカルパス。
- 実名許諾 (P-001) = やってみる (Q7)。設計基準線は全ケース composite 宣言で成立、実名はボーナス。共著体制 (PF-007) が交渉の追い風。
- Web 先行連載 (Book B 第I部限定) = やってみたい (Q11)。制約: 完成済み素材のみ・付録ツールは出さない・学術初出は RP 論文に温存。
- 「BZSF」の混同解消 (Q3): BZSF フォルダはファンド (`before_zero_fund.md`) と**理論正本** (`before_zero_theory.md` / `rt_roundtable_theory.md`) の同居場所。Q3 の実体は「RT 理論正本への ERS 接続追記」であり、ファンドとは無関係 → 2026-07-02 反映済み (v0.2)。

## 3. 各書の設計サマリ

### Book A — 理論の集大成テキスト (仮題: ディープテック起業の経営学)
- 15章 = 半期15回 1:1 / 380-450p / A5 / 専門書価格帯。三部構成の背骨 = **観測二層 (PRS/ERS) + 行動一層 (RT)** + 出口ポートフォリオ論の章。
- 章型: 章頭ミニケース (意思決定直前で切る A/B 分割) → 標準理論 (was) → deep-tech での破綻 (but) → BZM (therefore、**数式フル**: 直感→式→worked example) → 演習。
- 数式方針: PF-001。導出の完全版はモノグラフ参照可、式は全部載せる。記号一覧+日本語読み下し表を巻頭に。
- 差別化: 演習パッケージ (PF-006) + 「やめる/待つ/サイズを選ぶ判断を教えられる教科書」(YD/TIEM/JC ケース)。
- 共著: 石原先生筆頭に体制構築 (PF-007)。刊行 2029年4月学期照準。

### Book B — 現場解説書 (仮題: 会社をつくる前に決まっている)
- 序章+4部16章+付録ツール集 / A5 260-300p。母体 = 実戦書17章 (PF-004)。
- 第I部 物差し (PRS言葉版・GO判定・F分解・ERS診断) / 第II部 機関を整える (規程順序・GAP/URA/EIR 導線・出口ポートフォリオと「ベンチャー数の罠」) / 第III部 RT を組む (目玉、席次表型・大学正門・看板連携の見分け方) / 第IV部 先生が一歩を踏み出すとき (退路・株・学生・COI・創業科学者という選択)。
- 主語 = 研究機関ノード。ただし「RT の主宰者は中心 DTSU であって大学ではない」線引きを第III部冒頭に明記。
- RT 部は v1 = RT lite → 増補二段刊行 (ゲート: 独禁法務確認 ∧ 実地点火の事後観測1件)。

### 940p モノグラフ
- `BOOK_MASTER_PLAN.md` (L1) / `BOOK_DECISIONS.md` (L2) が正本。RT の組み込み構造は Q12 議論で確定後に L2 判例化 → L1 反映。
