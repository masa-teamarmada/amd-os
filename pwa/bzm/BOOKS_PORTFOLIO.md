## 1. ポートフォリオ構造 — 読者のジョブで切る3層

```
[学術層]  940p モノグラフ (Cambridge UP / Before Zero Studies)   ← 領域宣言・定理の初出・実証
    ▲                                          読者: 研究者・査読者
[教育層]  Book A 教科書 = 理論の集大成テキスト (数式全部入り)     ← 講義・研修採用 + 肩書に恥じない書籍
    ▲                                          読者: MBA/MOT院生・学部上級ゼミ・URA/EIR/VC研修
[現場層]  Book B 解説書 (実戦書17章ベース + RT部)                ← 現場のツールと台本
                                               読者: URA/産連/EIR/研究者 (主)、VC/事業会社 (従)
派生資産: 演習パッケージ (シーズカード / RT役割カード / ERS診断シート / 採点ワークシート)
          — 書籍に従属しない研修・AMDイベント商材として先行運用可
共通基盤: terminology_glossary (3冊共通正本) / 冊子横断ケース露出台帳 (§5) / 掲載ゲート (§6)
```

**書き分け原則**: モノグラフ = 宣言と実証 / **A = 体系と演習** / **B = ツールと台本**。
- モノグラフと A の違いは数式の量ではなく**ジョブ**: モノグラフは新領域を宣言し定理を初出させ実証する (Tier A/B 装置・査読対応・940p)。A は完成した理論体系を教育最短経路で学べる構成 + 演習 + 講義パッケージ (定理の初出はしない。導出はモノグラフ参照可、ただし式そのものは全部載せる)。
- カニバリ規律: 概念フレームワーク100%共有 / 散文重複15%未満 / 章頭ストーリー冊子間0%共有 / 主要ケースは主戦場排他 / A と B の刊行12ヶ月以上分離。

- **rationale**: まさ「おれの組み立ててきた理論の集大成となるようなテキストにしたい。読者のレベルに配慮して数式を減らすようなテキストは愛用したことがない」。ワークフロー時の「4層規律で first-passage/SSM/不可能性定理は教科書に出さない」裁定はこれにより**破棄**。残る規律は「教育的順序 (直感→式→worked example→演習)」と「校正数値の扱い (§4)」のみ — これは削減ではなく Tier 規律。

- **rationale**: まさ 2026-07-09「とりあえず出版社使わずに自費出版でもいいかなと思ってる」「まずは本を出せるレベルにあるということを見せるというのが目的」「買いたいと言ってくれる知り合いや連携先に対してのみ販売していければいい。kindle版は売れるだけ売れたら嬉しい」「石原先生は監修でもいいかもしれない。NIMS松本さんとか、それ以外にも監修だったら協力してくれる人は多そう」
