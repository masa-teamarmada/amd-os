### I1_C2_rho_estimation: C2 F-CES 委譲不可能コアの ρ 推定可能化

**一行解決**: F-CES 委譲不可能コアを経験的に推定可能な主張として再鋳造する: ρ は、Beckman/Roberts/Eesley-Roberts コホートで別々に測定された創業者 F_char とチーム F_cap に対する C1 到達時刻の Kmenta 展開された二次モーメント回帰から点識別され、ρ<0 (および Inada コーナー) は公理から反証可能な事後の言明に格下げされる。

**形式的追加**:

定義 (F-CES、推定可能として再述)。創業者-チーム i について、創業者特性複合 F_char,i と委譲可能な能力複合 F_cap,i を持つとき、創業者効果集計子を\n\\[\nF_i \\;=\\; \\Big[\\, \\alpha\\, F_{\\text{char},i}^{\\rho} \\;+\\; (1-\\alpha)\\, F_{\\text{cap},i}^{\\rho} \\,\\Big]^{1/\\rho}, \\qquad \\alpha\\in(0,1),\\ \\rho\\in(-\\infty,1]\\setminus\\{0\\}\n\\]\nと定義する。命題 1 (創業者コホートデータからの ρ の識別)。z_{c,i} = log F_{char,i}, z_{k,i} = log F_{cap,i} とし、y_i を B 起動 τ_x への C1 由来の対数到達時刻と表す。(A1) F_char,i の法人化前測定、(A2) 共通の選抜を吸収するコホート × 産業の固定効果、(A3) (z_c, z_k) における共通支持の下、Kmenta (1967) の二次展開は次を導く\n\\[\n y_i \\;=\\; \\delta_0 + \\delta_1 z_{c,i} + \\delta_2 z_{k,i} + \\delta_3\\, (z_{c,i}-z_{k,i})^2 + \\varepsilon_i,\n\\]\nそして ρ の符号と大きさは次によって識別される\n\\[\n\\operatorname{sign}(\\rho)=\\operatorname{sign}(\\delta_3), \\qquad \\hat\\rho = \\frac{2\\,\\hat\\delta_3}{\\hat\\alpha(1-\\hat\\alpha)}\\quad\\text{with}\\quad \\hat\\alpha = \\hat\\delta_1/(\\hat\\delta_1+\\hat\\delta_2).\n\\]\n系 1 (経験的主張としての委譲不可能性)。事後分布が $P(\\rho<0\\mid \\text{data})\\ge 0.95$ を満たすならば、Inada コーナー $\\lim_{F_{\\text{char}}\\downarrow 0} \\partial F/\\partial F_{\\text{char}} = \\infty$ が成立し、F_char は BZ ステージの意味で委譲不可能となる: F_cap のいかなる有限の再配分も消失する F_char キャリアを補償できない。逆に $P(\\rho\\ge 0\\mid\\text{data})>0.05$ は C2 を反駁し、モデルを Nelson–Winter (1982) のルーチン=完全委譲可能ベンチマークに戻す。\n仮説 H_C2。ρ < 0 (事前登録、片側)。

**導出 / 証明素描**:

ステップ 1 (設定)。F_i = [α F_char,i^ρ + (1-α) F_cap,i^ρ]^{1/ρ} を創業者レベルの F_char,i (ALQ4 + Grit + Resilience 複合、コホート内で標準化) とチームレベルの F_cap,i (焦点創業者を除く共同創業者の領域能力指数の和) で指定する。BZ ステージの結果 Y_i ∈ {B まで生存, B 前失敗} と C1 の到達時刻 τ_x から得られる連続代理変数 y_i = log time-to-B-trigger を定義する。ステップ 2 (線型化)。Kmenta (1967) / Klump et al. ### I2_C3_algebraic_theorem: C3 二層非可換性を Arrow スタイル不可能性定理に

**一行解決**: C3 を Arrow 不可能性スタイルの定理 3 として再鋳造する: PRS 消滅、ERS 単調性、因果チャネル制限を公理化し、いかなる狭義単調なスカラー崩壊 Φ(g(P,R,S), h(A)) も三つすべてを満たさないことを証明する — これにより BZ ステージデータ上で Nelson-Winter のスカラー適合度に対する Hausman 検定可能な反証子が得られる。

**形式的追加**:

定理 3 (BZ ステージにおける二層非可換性)。(P,R,S) ∈ R_{>0}^3 を創業者内部の Purpose-Readiness-Skill の三つ組、A = (A_1,...,A_K) ∈ R_{≥0}^K を K 次元の環境リソース系 (ERS) とする。PRS := P·R·S および ERS := Σ_{k=1}^K w_k A_k, w_k > 0 と定義する。f: R_{>0}^3 × R_{≥0}^K → R_{≥0} を候補となる複合評価関数とする。f が次を満たすならば\n\n(A1) PRS 消滅: min(P,R,S) = 0 のとき f(P,R,S,A) = 0;\n(A2) ERS 単調性: ∂f/∂A_k ≥ 0 ∀k、領域の開部分集合上で狭義;\n(A3) 因果チャネル制限: ∂f/∂A_k = (∂f/∂R)(∂R/∂A_k) + (∂f/∂S)(∂S/∂A_k)、すなわち ERS は (R,S) の時間導関数を介してのみ f に作用する;\n(A4) 領域の内部での連続性、\n\nそのとき f は、Φ が各引数で狭義増加で (g,h) がスカラー値であるような表現 f = Φ(g(P,R,S), h(A)) を持たない。とくに、f は純乗法的 (PRS·ERS) でも純加法的 (PRS + ERS) でも、二つのスカラー集計子の任意の狭義単調合成でもない。∎\n\n系 3.1 (経験的反証子)。定理 3 の下で、BZ ステージのベンチャー結果 y を (PRS, A_1,...,A_K) に対して回帰する任意の線形または対数線形回帰は、少なくとも次のいずれかを示す: (i) プールされた推定値と PRS 層別推定値の間の γ_k の Simpson 型符号反転; (ii) PRS 四分位を横切る γ_k の >2σ 不安定性; (iii) プールされた vs PRS 条件付き GMM の Hausman 棄却。(i)-(iii) の結合的失敗は二層的主張を反証し、BZ ステージにおける Nelson-Winter のスカラー適合度集計子を復権させる。\n\n定義 (二層非可換性)。組 (PRS, ERS) は、定理 3 の公理 (A1)-(A4) が経験的支持上で結合して成立するとき、そしてそのときに限り、二層非可換である。

**導出 / 証明素描**:

ステップ 1 (設定)。P, R, S ∈ R_{>0} を Purpose, Readiness, Skill のスカラーとし、A = (A_1,...,A_K) ∈ R_{≥0}^K を環境リソース軸 (資本、ネットワーク、規制、需要、人材) とする。PRS = P·R·S (乗法的) および ERS = Σ_k w_k A_k, w_k > 0 (加法的) と定義する。評価者は複合的な創業者-ベンチャー存続可能性を表す f: R_{>0}^3 × R_{≥0}^K → R を求める。\nステップ 2 (公理)。次を課す: (A1) 消滅: P=0 ∨ R=0 ∨ S=0 ⇒ f = 0 (C2 の F-CES 委譲不可能コア)。(A2) ERS の軸内単調性: ∂f/∂A_k ≥ 0 ∀k、開集合上で狭義不等式。(A3) 因果方向: ERS は時間導関数 (dR/dt, dS/dt) を介してのみ f に影響する; すなわち ∂f/∂A_k = (∂f/∂R)(∂R/∂A_k) + (∂f/∂S)(∂S/∂A_k)、かつ ∂P/∂A_k = 0 (Purpose は環境ではなく創業者に内生的)。(A4) f の領域上での連続性。\nステップ 3 (加法的崩壊を排除する)。f = g(P,R,S) + h(A) と仮定する。(A1) により、P=0 と置くと: f = g(0,R,S) + h(A) ≡ 0 ∀ R,S,A。これは h ≡ -g(0,R,S) を強制するが、同一性が成立するためには g(0,R,S) が (R,S に独立な) 定数でなければならず、(A2) に矛盾する。ただし h が定数 — これは (A2) の開集合上での狭義単調性節に矛盾する — であれば別である。∎\nステップ 4 (乗法的崩壊を排除する)。f = g(P,R,S)·h(A) と仮定する。(A1) は g(0,·,·)=0 のとき、かつそのときに限り満たされる。(A2) は ∂h/∂A_k ≥ 0 を強制する。しかし (A3) は ∂f/∂A_k = h(A) · [∂g/∂R · ∂R/∂A_k + ∂g/∂S · ∂S/∂A_k]、すなわち ERS が (R,S) を *介してのみ* f に入ることを要求する。すると ∂h/∂A_k は (∂R/∂A_k, ∂S/∂A_k) = (0,0) のときには常にゼロでなければならない。一般的にこの集合は正の測度を持つ (例えば創業者の Readiness や Skill に即時には影響しない規制ショック) ので、そこで (A2) の狭義単調性に矛盾する。∎\nステップ 5 (単調変換崩壊を排除する)。f = Φ(g(P,R,S), h(A)) で Φ が両引数で狭義増加と仮定する。結合測定 (Krantz et al. 1971) は二重キャンセルを要求する。反例を構成する: h(A) < h(A') であるが (R,S) を介して経路付けられて、誘発された動学を伴う g の合成が g(P,R(A'),S(A')) < g(P,R(A),S(A)) を与える (高リソース環境が Christensen 型の既存企業罠で文書化された自己満足を介して Readiness を侵食する) ような A, A' を選ぶ。二重キャンセルは失敗するので、そのような Φ は大域的には存在しない。∎\nステップ 6 (定理)。ステップ 3-5 を結合すれば、(A1)-(A4) を満たす連続な f は、乗法的、加法的、または狭義単調合成のいかなる単一スカラー表現も持たない。f は還元不可能に二層的である。\nステップ 7 (反証可能な系)。BZ ステージデータ上の任意の計量経済学的特定化 y_i = β_0 + β_PRS·(P_i R_i S_i) + Σ_k γ_k A_{ik} + ε_i (Nelson-Winter スタイルのスカラー適合度回帰) は、次のいずれかを示さなければならない: (i) プールされた推定値と PRS 層内推定値の間の γ_k の符号反転 (ステップ 5 が予測する Simpson 型反転); (ii) PRS 分位を横切る γ_k 係数不安定性が 2σ を超える; (iii) プールされた vs PRS 条件付き GMM の Hausman 検定棄却が p<0.05。三つすべての不在は C3 を反証する。

### I3_Murmann_co_evolution: Murmann (2003) 共進化との形式的関与

**一行解決**: Murmann (2003) の企業-制度共進化を双方向 ERS↔PRS 結合として形式化する。そこでは 8 軸 ERS 整備度ベクトル η_jt が遅い制度状態として作用し、速い PRS レジーム遷移ハザードを再スケールする。これにより、それ以前の言語的共進化ナラティブが提供できなかった反証可能な (Granger 因果) リードラグ制約 η_{j,t-1} → ΔPRS_{jt} が得られる。

**形式的追加**:

Ch 10.6 (BZM OPENER の共進化的閉合)。

定義 10.6.1 (ERS 苗床整備度ベクトル)。地域/苗床 j および年 t について、
  η_{jt} = (η^1_{jt}, …, η^8_{jt}) ∈ R^8_+,
を軸 A_k ∈ {capital_depth, talent_thickness, regulatory_clarity, IP_enforcement, anchor_demand, supplier_density, university_linkage, exit_liquidity} で定義する。スカラーの苗床指数を
  E_{jt} := Σ_{k=1}^{8} w_k · A_k(η^k_{jt}),  Σw_k = 1, w_k ≥ 0,
と定義する。これは Ch 10.3 の ERS 層であり (命題 10.4 — C3 参照 — により PRS に崩壊不可)。

定義 10.6.2 (PRS レジーム遷移ハザード)。C1 の法人化後 2 次元状態 (x_t, y_t) において、創業者レベルの PRS を P_{it} × R_{it} × S_{it} とし、企業の段階過程 Z_{it} ∈ {Seed, A, B, …} が年次遷移ハザード
  λ_{it}^{Z→Z+1} = λ_0(Z) · g(P_{it} R_{it} S_{it}) · φ(E_{j(i)t}),
を持つとする。ここで g は創業者品質の乗数、φ: R_+ → R_+ は苗床再スケール、横断平均で φ(Ē) = 1 と正規化される。

命題 10.6.3 (ERS-PRS 結合としての Murmann 共進化)。仮定 (i) η_{jt} が
  η_{j,t+1} = Γ η_{jt} + Ψ · N_{jt} + ε^η_{j,t+1},   (制度ドリフト)
に従って進化する。ここで N_{jt} = #{j 内で t までに B 起動を通過した企業 i} は累積 B 卒業数で、Ψ ≥ 0 は企業→制度フィードバック (アンカー需要、ロビー活動、人材再循環) を捕捉する; (ii) PRS ハザード λ_{it}^{Z→Z+1} は定義 10.6.2 を ∂φ/∂E > 0 で満たす; (iii) ε^η は創業者品質ショック ε^{PRS} に直交する。そのとき結合系 (η_{jt}, {Z_{it}}) は Murray (2002, Ch. 4) の相互因果という形式的意味で Murmann (2003) の共進化的過程である: 制度が企業レベルのハザードに入り、企業が制度の運動方程式に入り、どちらの層も他方に還元不可能である。

系 10.6.4 (反証可能なリードラグ制約)。命題 10.6.3 の下で、w_k > 0 を持つ任意の軸 k について、
  Cov(η^k_{j,t-1}, ΔPRS-realized-transition_{j,t}) > 0   かつ   Cov(ε^{PRS}_{i,t}, η^k_{j,t-1} | controls) = 0,
したがって η^k は同年内で地域の PRS 実現遷移率を Granger 因果的に予測するが、その逆は成立しない。いずれかの不等式が破れれば、BZM の連結における ERS→PRS 方向は反証され、モデルは縮退した単層 Nelson-Winter 選抜過程に帰着する。

定理 10.6.5 (B 起動不連続性による Ψ の識別)。C1 (B におけるレジーム切換え) と Def. 10.6.1 を組み合わせると、firms→institutions 係数 Ψ は、限界企業が B 閾値を跨ぐ年における η_{j,t+1} の不連続ジャンプから識別される。これは B 以前の軌道を条件付けた上でのファジー RD を B 卒業件数に適用すれば、Murmann (2003) の語りによる証拠を打ち破る逆因果の交絡から解放された Ψ̂ が得られることを意味する。

**導出の素描**:

Step 1. Murmann (2003, Ch. 1–2) の語りによる主張から出発する。合成染料の事例において、ドイツ企業群とドイツの化学制度的能力は共に上昇したが、Murmann には「企業が制度を形成した」と「制度が企業を形成した」を分離する形式的装置はなく、共進化を物語として記述している。
Step 2. BZM の二層非可換性 (C3) を埋め込む。PRS は企業-年水準で乗法的構造を持ち、ERS は地域-年水準で加法的な 8 軸構造を持つ。これらは一つのスカラーに畳み込めないため、共進化の主張は二つの異なる状態空間の間の連結でなければならない。これがまさに Murmann が残した欠落である。
Step 3. η_{jt} を緩慢な状態 (地域・年次)、Z_{it} を高速過程 (企業水準、C1 由来の B 起動不連続性つき) として導入する。
Step 4. 高速層を書く。創業者の PRS 質は g(·) の中に乗法的に入り、ERS は再尺度化 φ(E_{jt}) として入る。これにより C2 の F-CES 委譲不可能コアが保たれる。g と φ は積として入り、弾力性 ρ < 0 のため、低質な創業者が厚い苗床によって救済されることはない。これは F_char の委譲不可能性主張と整合する。
Step 5. 緩慢層を VAR(1) として書き、N_{jt} (B 卒業) を firms→institutions のフィードバック経路とする。Ψ > 0 は「成功した B 卒業者が苗床を厚くする」(再循環する人材、アンカー需要、IPO 比較対象) を意味し、Murmann が BASF/Hoechst/Bayer について物語的に記録した機序とまさに一致する。
Step 6. 直交性 (iii) は鍵となる識別制約である。創業者質ショック ε^{PRS} は個人水準 (遺伝、職歴、F_char に基づく性格特性) であり、地域制度的ドリフト ε^η と独立である。これは C1 の到達時刻構造を介して検証可能で、B 以前の創業者の PRS 残差は B 後の地域 η を予測してはならない。
Step 7. リード-ラグ (Cor. 10.6.4): 制度がプロジェクト速度に効くのであれば、前年の η は創業者固定効果を条件付けた上で当年の実現 PRS 遷移を動かすはずである。標準的なパネル Granger 検定である。
Step 8. Ψ の識別 (定理 10.6.5): C1 の B 起動が不連続性を与える。閾値近傍では B の直上と直下の企業は PRS では比較可能だが、N_{jt} への寄与が異なる。B 卒業件数に対するファジー RD で、η^k_{j,t+1} を結果変数とすれば、各軸ごとにクリーンな Ψ̂_k が得られる。
Step 9. この結果は Murmann の語りを形式化する。彼は共進化の存在証拠を提示したが、BZM は方向性・符号制約・識別戦略に裏付けられた係数を備えた構造モデルを生み出す。さらに 8 軸分解は Murmann の一枚岩的な「制度的能力」を、軸ごとに検証可能なチャネル (例: B 後に効くのは university_linkage か anchor_demand か) へと精緻化する。
Step 10. 頑健性: 連結は Ψ → 0 かつ φ ≡ 1 のとき Nelson-Winter (1982) 単層選抜に縮退し、φ を未指定のまま放置すれば純粋な Murmann 語りに縮退する。BZM は双方を極限として包摂する。

識別戦略:

試験データ: 日本のみのサブサンプル (J = 8 の都道府県苗床、T = 2010–2024、N ≈ 600 のディープテック企業) — METI/JST/AMED のオープンデータ + Pitchbook ライセンスで実現可能。2022 年以降の波を抽出する前に (A)–(D) の事前登録を行う。

**残るリスク** (5 件):

- 内生的な重み w_k: ERS スカラー E_{jt} は結果変数によって決まる重み (例: パネルに適合させるために選ばれた重み) に依存する。査読者は w_k の事前登録、もしくは重み事前分布上のベイズモデル平均化を要求するであろう。さもなくば Cor. 10.6.4 は実務上反証不能となる。
- アンカー需要逆経路の汚染: N_{jt} (B 卒業) と η^anchor_demand は、卒業した企業群そのものがアンカー需要 (地元スケールアップによる地元大型調達) となる場合に機械的に連結する。Thm. 10.6.5 のファジー RD はこれを緩和するが除去はしない。査読者は非地元アンカー需要を用いたプラセボを要求する可能性がある。
- 苗床間スピルオーバー: η_{jt} は近隣 j' の η_{j',t-1} に依存する可能性が高い (Bay Area のショックが Boston に届く)。Prop. 10.6.3 の VAR(1) は局所的であり、空間 Γ の非対角成分を無視すれば Ψ̂ は上方バイアスを受ける。査読者は空間 VAR の頑健性を要求するであろう。
- Murmann (2003) の選抜バイアス的再現: Murmann の事例は単一産業 (染料) を 50 年間追ったものだが、BZM のパネルは多産業を 20 年間追う。提案された検定は Murmann の問いとは別の問いに答えている。モノグラフ編集者は、少なくとも一つの深い歴史的事例 (例えば 1990 年代から 2020 年代の日本ディープテック苗床形成) がパネルと並んで語られない限り、BZM は「Murmann を彼自身の土俵で受け止めていない」と論じる可能性がある。
- F-CES (C2) 相互作用の未指定: φ は g に乗じるが、Prop. 10.6.3 は ∂²λ/∂g∂φ > 0 (代替的) か < 0 (補完的) かを定めていない。委譲不可能性主張 (C2、ρ<0) は補完を要請する。データが代替を示せば C2 と Ch 10.6 は内部的に矛盾し、いずれかが譲歩を強いられる。

### I4_Klepper_shakeout: Klepper (1996/1997) シェイクアウトとの形式的接続

**一行解決**: Klepper の形成後シェイクアウト (企業群に対する参入-退出ハザード) を、形成前レジーム (t < τ_B) を BZM の到達時刻問題とする単一の二レジームハザード過程の t > τ_B 継続として埋め込み、τ_B における反証可能なハザード分断を与え、Klepper (1996, 2002) を特殊ケースとして包摂する。

**形式的追加**:

N(t) をコホート人口とする (形成前 = 法人化前の志望者、形成後 = 法人化企業)。統一ハザードを以下で定義する:

  h(t, n; theta) = 1{t < tau_B} * h_pre(t, x_i(t), y_i(t); theta_pre)  +  1{t >= tau_B} * h_post(t - tau_B, n(t); theta_post)

ここで

  h_pre(t, x, y; theta_pre) = lim_{Delta -> 0+} (1/Delta) * Pr( tau_B <= t+Delta | tau_B > t, x_i(t), y_i(t) )
       = phi( B - x_i(t) ) * sigma_x * g( y_i(t) ),                              (形成前、BZM C1)

  h_post(s, n; theta_post) = alpha_0 + alpha_1 * n(s) + alpha_2 * log s,         (Klepper 1996/2002 縮約形)

であり、レジーム切換えを跨ぐ人口の運動則は

  N(tau_B^+) = integral 1{ tau_B,i <= tau_B } * 1{ y_i(tau_B,i) >= y_min } dF(i).

命題 4 (Klepper 包摂)。F_char == 1 (委譲不可能コアなし、C2 が崩壊) かつ起動前異質性が縮退 (Var[x_i(0)] -> 0) であり、B が固定されているならば、h_pre は期待値で消滅し、統一ハザードは Klepper (1996) の参入後シェイクアウトハザード h_post に縮退する。この意味で Klepper (1996, 1997, 2002) は BZM の F_char -> 1 極限である。

命題 5 (τ_B におけるハザード分断)。BZM C1 + C2 のもとで、対数ハザードは τ_B において不連続を示す:

  Delta log h := lim_{eps -> 0+} [ log h_post(eps, N(tau_B^+)) - log h_pre(tau_B - eps, x, y) ]  != 0,

であり、Delta log h の符号は生存コホートにわたる F_char の相対的分散によって識別される。Delta log h < 0 となるのは、Var[F_char | crossed tau_B] * rho_{F-CES} が Klepper の密度依存的混雑 alpha_1 * N(tau_B^+) を上回るとき、かつそのときに限る。

系 (検証可能性)。Klepper シェイクアウトパターン (産業年齢とともに上昇する h) は、真の企業水準死亡曲線を [0, tau_B] 上の h_pre の面積分だけちょうど過小評価する。すなわち、形成前コホートを打ち切ることは産業ライフサイクルハザードの生存解析的推定を下方にバイアスする。

**導出の素描**:

Step 1. BZM C1 から出発: 形成前ダイナミクス (x_i, y_i) は x 上に吸収境界 B を持つ伊藤拡散である。初通過時刻が Jovanovic (1982) の到達時刻機構によりハザード h_pre を持つ τ_B,i を与える。
Step 2. τ_B,i において主体 (i) は法人化人口 N(t) に渡る。これは Cox 過程の薄化であり、y_i(tau_B,i) >= y_min の者だけが入ることで、委譲不可能コア F_char (C2) 上の選抜が生じる。
Step 3. N(t) に入れば、Klepper (1996) の縮約形が適用される。ハザードは密度 n(s) (alpha_1 > 0) と産業年齢 (技術飽和シェイクアウトを捕捉する alpha_2) に対して上昇する。これは Sutton 型の埋没費用スピルオーバーだが、Klepper の経験的特定化を用いる。
Step 4. h_pre と h_post を τ_B で区分的ハザードとして接合する。ハザードの連続性は課されない — それが検証可能な内容である。
Step 5. 極限を取る。F_char == 1 (委譲不可能異質性なし) なら τ_B に到達する主体はすべて同一であり、起動後コホートに対する h_pre の選抜効果は消滅し、h_post が物語の全体となる -> Klepper (1996)。これが命題 4 (Klepper 包摂) を証明する。
Step 6. ρ < 0 (F-CES の強い補完性) を伴う一般的 F_char のもとでは、生存コホートは (F_char, F_cap) 上で打ち切られた分布を持つ。打ち切りの汎関数として起動後ハザードの切片 alpha_0 を計算する。h_pre(tau_B - eps) と比較すると、不連続 Delta log h は生存者選抜差分の関数となる。
Step 7. Delta log h の符号: より重い F_char 選抜 (高い Var[F_char | survived]) は h_post の切片を下げ (生存者がより強健) -> Delta log h < 0。τ_B における高密度混雑は h_post を上げ -> Delta log h > 0。交差点は alpha_1 * N(tau_B^+) = Var[F_char | survived] * |rho_{F-CES}| によって識別される。これが命題 5 である。
Step 8. 系: 産業ライフサイクルに関するいかなる生存解析的研究も、時計を法的参入から始めれば (Klepper の標準的実務、例: Klepper 2002 のデトロイト自動車データ) [0, tau_B] を打ち切る。したがって真の累積ハザード integral_0^infty (h_pre + h_post) ではなく integral_{tau_B}^infty h_post を推定する。バイアスの符号は既知 (下方) であり、形成前コホート規模が登記データから知れていれば限界づけ可能である。
Step 9. 識別: τ_B は法的法人化日として観測可能であり、形成前コホートは創業者追跡登記 (例: 日本の起業準備者パネル、米国 Kauffman Firm Survey の打ち上げ前波、英国 Global Entrepreneurship Monitor の萌芽起業家パネル) から観測可能である。区分的最尤法によって (theta_pre, theta_post) を結合推定し、ハザード分断検定をハザード上の Chow 検定として行う。
Step 10. 反証: 複数の産業にわたって Delta log h が統計的に零であり、かつ τ_B において F_char の分散に打ち切りが見られなければ、BZM C1+C2 は純粋な Klepper を支持する形で棄却される。逆に、予測された符号での Delta log h != 0 と F_char の打ち切りが見出されれば、純粋な Klepper は BZM を支持する形で棄却される。

**Connecting works** (8 件):

- Klepper, S. (1996). Entry, Exit, Growth, and Innovation over the Product Life Cycle. American Economic Review 86(3): 562-583. - 密度依存の退出ハザードを持つ基礎的なシェイクアウトモデル。BZM の h_post はこの論文の特定化である。
- Klepper, S. (1997). Industry Life Cycles. Industrial and Corporate Change 6(1): 145-182. - BZM の t > tau_B レジームが再現すべき様式化事実 (参入ピーク、シェイクアウト、支配的デザイン)。
- Klepper, S. (2002). Firm Survival and the Evolution of Oligopoly. RAND Journal of Economics 33(1): 37-61. - デトロイト自動車産業の生存解析。法的参入で打ち切るため h_pre + h_post ではなく h_post を推定する — 命題 5 の系が予測するまさにそのバイアス。
- Jovanovic, B. (1982). Selection and the Evolution of Industry. Econometrica 50(3): 649-670. - BZM が C1 で拡張するベイズ学習型の到達時刻機構。Klepper のハザードは Jovanovic の個人学習の人口集計版である。
- Sutton, J. (1997). Gibrat's Legacy. Journal of Economic Literature 35(1): 40-59. - 企業規模ダイナミクスと参入-退出を結ぶ。BZ ステージを加えることで BZM が完成させる Jovanovic ミクロと Klepper マクロを橋渡しする。
- Nelson, R. & Winter, S. (1982). An Evolutionary Theory of Economic Change. - 人口水準の選抜ベンチマーク。BZM C3 (二層非可換性) は Nelson-Winter のルーチン=技能観を BZ ステージで精緻化したものであり、Klepper の同質的主体シェイクアウトが見落とす τ_B での生存コホート異質性を予測することが示される。
- Reynolds, P.D. & Curtin, R.T. (2008). Business Creation in the United States: PSED-II Initial Assessment. Foundations and Trends in Entrepreneurship 4(3): 155-307. - 萌芽起業家コホートに関する PSED-II データ。従来は実現不能だった [0, tau_B] 上の h_pre の直接測定を可能にする。
- Cabral, L.M.B. & Mata, J. (2003). On the Evolution of the Firm Size Distribution: Facts and Theory. American Economic Review 93(4): 1075-1090. - 命題 5 の F_char 上の選抜機構と整合的な、参入後の小企業分布の打ち切りを記録する。

**検定・データ設計**:

設計: 区分的ハザード推定 + τ_B におけるハザード上の Chow 検定。

観測変数 (コホート構成員 i ごと):
  - tau_B,i: 法的法人化日 (登記: 例えば日本の法務省商業登記、米国の Secretary of State 申請、英国の Companies House)。
  - t_0,i: 萌芽起業家コホート参入 (PSED-II wave 1、Kauffman Firm Survey の打ち上げ前、JGSS 起業準備者パネル、GEM TEA コホート)。
  - tau_E,i: 退出日 (解散 / 倒産 / 休眠)。
  - x_i(t), y_i(t) プロキシ: x = マイルストーン件数 (MVP、初収益、初採用)、y = 流動性ランウェイ (月数)。
  - F_char,i: t_0 における事前登録された心理測定バッテリ (ALQ4, Grit-S, CD-RISC-10, BRS)。
  - n(s): 暦時点での産業水準の企業密度、SIC-4 または NAICS-6。

識別戦略:
  1. 形成前コホート {i : t_0 <= t < tau_B,i} 上で h_pre を競合リスクハザードとして推定する (成功 = tau_B,i、失敗 = 撤退)。共変量 (x_i, y_i, F_char,i)。
  2. 形成後コホート {i : tau_B,i <= t < tau_E,i} 上で h_post を Klepper (1996) の密度依存ハザードとして推定する。共変量 (s = t - tau_B,i, n(s), 引き継いだ F_char,i)。
  3. τ_B におけるハザード上の Chow 検定で結合 MLE: H_0: Delta log h = 0 (純粋な Klepper)、H_1: Delta log h = beta * Var[F_char | survived] * rho - gamma * alpha_1 * N(tau_B^+) (BZM 命題 5)。
  4. tau_B,i に対する操作変数: 法人化コスト/速度の規制的変動 (例: 1990 年代–2000 年代に州ごとに段階的に採用された米国 LLC 法、2006 年の日本会社法改正、EU の一日会社プログラム)。これらは F_char を動かさずに tau_B を動かし、レジーム切換え効果を識別する。

反証条件:
  - F1 (BZM を棄却): Delta log h が 5 産業以上 × 2 制度的レジーム以上にわたって零と有意に区別されない。
  - F2 (BZM を棄却): F_char 分布が τ_B で打ち切りを示さない (起動前と起動後の F_char 周辺分布に対する Kolmogorov-Smirnov 検定が等しさを棄却しない)。
  - F3 (Klepper を棄却、BZM を支持): Delta log h < 0 で、符号が Var[F_char | survived] * |rho| > alpha_1 * N と整合し、かつ F_char が τ_B で上方打ち切りを受けている。
  - F4 (両者を棄却): ハザードが τ_B に局在しない複数の構造的分断を示す (どちらのモデルも関連レジーム構造を捉えていないことを示唆し、第三のレジーム、例えば支配的デザイン採用、を動機づける)。

試験データ: PSED-II (米国、2005–2013 に追跡された 1,214 名の萌芽起業家、法人化と退出記録に連結) が現存する最もクリーンなデータセット。日本の GEM-成人人口調査を法人番号公表サイトに連結したものが交差検証を提供する。産業固定効果を伴う結合 MLE のサンプル規模は 8 産業以上にわたる約 3,000 名のコホート構成員を要する。

**残るリスク** (5 件):

- R1 (法人化への選抜の内生性): tau_B に対する規制的変動操作変数 (LLC 法のタイミング、会社法改正) は法人化する者の構成を動かす可能性があり、速度だけを動かすとは限らない。もしそうなら異なるレジーム下の tau_B 以後のコホートは比較可能でなくなり、Delta log h 推定は交絡する。緩和策: 改正前 F_char 分布をベンチマークとする限界づけ演習。
- R2 (Klepper の産業特異性弁護): Klepper (2002) は明示的に技術集約型製造業 (自動車、タイヤ、テレビ) を念頭にシェイクアウトをモデル化した。Klepper 学派の査読者は、BZM の包摂主張 (命題 4) は Klepper が決してモデル化を主張しなかった産業 (サービス、プラットフォーム) に対しては空虚であると論じる可能性がある。反論: F_char -> 1 極限は包摂を形式的にしているのであって経験的にしているのではない — 主張はモデル構造に関するものであり、経験的範囲に関するものではない。
- R3 (h_post の関数形): Klepper の alpha_0 + alpha_1 * n + alpha_2 * log s はいくつかの縮約形のうちの一つにすぎない (Sutton のエスカレーション、Cabral-Mata の対数正規打ち切り)。代替的な h_post 特定化に対する命題 5 のハザード分断の頑健性が示されなければならない。さもなくば Delta log h 推定はモデル依存となる。
- R4 (形成前コホートの定義): 萌芽起業家コホート (PSED-II、GEM TEA) は事業立ち上げ意図の自己申告を要するが、これ自体が潜在的 F_char の結果である。打ち切りは既に t_0 で F_char 上に生じており、h_pre を生存者寄りにバイアスする。緩和策: 人口水準調査 (例: 就業構造基本調査) を用いて、Heckman 補正により観測されない t_0 以前のコホートを復元する。
- R5 (ハザード上の Chow 検定の統計的検出力): 予測された符号と大きさで Delta log h を検出するには、大きなコホート N または大きな F_char 分散のいずれかが必要である。検出力不足の検定は BZM が真であっても H_0 を棄却し損ね、BZM を Klepper と観測的に同等と誤分類する可能性がある。サンプル規模と効果量ベンチマークの事前登録が必要である。

### I5_Malerba_sectoral: Malerba (2002) SSI と ERS 8 軸の形式的全射

**一行解決**: ERS 8 軸を、企業形成前のノードにおいて Malerba (2002) の 5 次元的語りを解像する量的測定層として再定式化する。全射 φ: ERS → Malerba を通じてこれを行い、レーンごとに添字付けられた重み w_k(L) が Klevorick-Levin-Nelson-Winter 型の符号制約パネルのもとで Wald 検定可能な反証を生成する。

**形式的追加**:

命題 5.M (ERS の Malerba 埋め込み)。M = (K, A, I, D, T) を Malerba (2002) の産業システム 5 つ組とし、A = (A_1,...,A_8) ∈ [0,1]^8 を地域-レーンノードでの BZM ERS 軸ベクトルとする。構造的対応 φ: {1,...,8} → 2^{{K,A,I,D,T}} を次のように定義する:\n\n  φ(1)={K},  φ(2)={T,I},  φ(3)={I},  φ(4)={A,I},\n  φ(5)={A},  φ(6)={A,D},  φ(7)={I},  φ(8)={K,I}.\n\n(i) [全射的被覆] ∪_{k=1..8} φ(k) = {K,A,I,D,T}; Malerba の各次元は少なくとも一つの ERS 軸で覆われる。\n(ii) [量化層] ERS(A;w) := Σ_{k=1..8} w_k · A_k (w ∈ Δ^7 = {w ≥ 0 : Σw_k = 1}) を定義する。すると ERS は M の可測な精緻化であり、Malerba の語りスコア上で定義された任意の連続汎関数 Ψ: [0,1]^5 → R に対し、ある w ∈ Δ^7 と φ の逆像 φ^{-1} 上の集約規則が存在して、ERS(A;w) が φ 誘導押し出しの像上で Ψ を再現する。\n\n命題 5.L (レーン添字付けされた重みの異質性)。L ∈ L = {Deep-tech, Bio, Material} を産業レーン添字とする。BZM モデルは以下を課す:\n\n  w = w(L) ∈ Δ^7,    H1: ∃ k, L ≠ L' s.t. w_k(L) ≠ w_k(L').\n\n帰無仮説 H0: w(L) = w̄ ∀L (レーン不変性) は棄却可能である。とくに BZM は以下の符号パターンを予測する:\n\n  w_2(Bio) > w_2(Deep-tech), w_2(Bio) > w_2(Material)      [専有性チャネル]\n  w_8(Material) > w_8(Bio), w_8(Material) > w_8(Deep-tech)  [累積性チャネル]\n  w_6(Deep-tech) > w_6(Bio), w_6(Deep-tech) > w_6(Material) [資本集約性チャネル]\n\nこれは Klevorick-Levin-Nelson-Winter (1995) の機会・専有性・累積性の三つ組を BZM 軸に対応させて導出される。\n\n系 5.NW (Nelson-Winter との境界)。企業形成前の BZ ステージでは企業内ルーチンが存在しないため、w(L) における産業的異質性は N-W (1982) 型のルーチン上の人口選抜では生成できず、外生的な環境マッチングでなければならない。したがって ERS は Nelson-Winter 選抜の企業形成前双対である: N-W が産業を所与としてルーチンを選抜するのに対し、BZM はレーンを所与として環境を重み付ける。

**導出の素描**:

Step 1 (Malerba プリミティブ)。Malerba の産業システムを 5 つ組 M = (K, A, I, D, T) と定義する (K=知識基盤、A=アクター/ネットワーク、I=制度、D=需要、T=技術/人工物)。M は語り的であり、各次元は既存企業が住まう産業水準システムの質的記述子である。Step 2 (BZM プリミティブ)。BZM の企業形成前環境は、地域-レーンノードで評価される ERS 軸の 8 ベクトル A = (A1,...,A8) であり、企業はまだ存在しない (N=1、法人化前)。Step 3 (写像構築)。全射 φ: A → M を次のように構築する。φ(A1)=K (シーズ抽出は地域の知識基盤を操作化する)、φ(A2)=T∩I (IP/TT は技術的専有性と制度的規則を結合する)、φ(A3)=I (スタートアップ支援制度)、φ(A4)=A∩I (共同 R&D 契約は制度的規範に統制されるアクターネットワーク手続きである)、φ(A5)=A (人材接続はアクター側を充足する)、φ(A6)=A∩D (資本マッチングは予期される需要正統性を代理するアクターチャネルである)、φ(A7)=I (制度設計)、φ(A8)=K∩I (文化/トラックレコードは知識基盤の緩慢な制度的堆積物である)。Step 4 (被覆と精緻化主張)。φ は全射 (Malerba の各次元が覆われる) だが単射でない (制度 I は A3, A4, A7, A8 から寄与を受ける)。これは ERS が Malerba の I 次元の内部で、まさに企業形成前の摩擦が存在する場所において解像度を加えることを示す。Step 5 (量化層)。M は語り的であるのに対し、BZM は各 A_k に [0,1] 内の可測スカラーを与え、ERS = Σ_{k=1..8} w_k · A_k によって集約する。これが ERS が Malerba の語り骨格に取り付けられた「測定層」である形式的意味である。Step 6 (産業特異性仮説)。L ∈ {Deep-tech, Bio, Material} をレーン添字とし、w_k = w_k(L) (w(L) ∈ Δ^7、7-シンプレックス) と推測する。Step 7 (反転 Malerba 機構による識別)。Klevorick-Levin-Nelson-Winter (1995) は機会・専有性・累積性が産業ごとに異なることを記録する。これらを BZM の重みに対応させる: 高専有性レーン (Bio: 特許保護分子) → 高い w_2 (IP/TT); 暗黙的累積性レーン (Material: プロセスノウハウ) → 高い w_8 (文化/トラックレコード); 高機会高燃焼レーン (Deep-tech: ハードウェア) → 高い w_6 (資本マッチング)。Step 8 (反証可能予測)。H0: 全 L に対し w_k(L) = w_k (産業的変動なし)。H1: 少なくとも一つの k で w_k(L) が標本誤差を超えて L にわたって異質である。パネル推定された重みに対する Wald 検定が BZM をレーン不変な ERS 集約器から区別する。Step 9 (Nelson-Winter との境界)。N-W は既存企業群上で動作し、選抜はルーチンに作用する。BZM の企業形成前レジームには選抜すべきルーチンが存在しないため、産業重み w_k(L) は環境から来なければならず、企業内ダイナミクスからは来ない。これは BZ ステージの精緻化であり、N-W への矛盾ではない。Step 10 (閉合)。写像 φ とレーン添字付けされた重み推測が結合して、BZM を Malerba (2002) の測定層付き企業形成前拡張として位置づける。これは後者の構造を保ちつつ法人化前ノードにおける不足規定を解像する。

### I6_t_star_fuzzy_boundary: t* シャープな事象 → ファジー境界 拡張

**一行解決**: t* を Andrews-Quandt のシャープな事象から、識別された窓 [t*_start, t*_end] 上の滑らかな incorporation 重み B_h(t) に格上げし、C1 のシャープなレジーム切換え (h↓0) と Ch 11.5 の滑らかな極限 (h↑∞) を、Bai-Perron で識別される一つの一パラメータ族の二つの境界事例として入れ子化する。さらに窓幅と PRS 分散を結びつける反証可能な企業横断予測を加える。

**形式記述の追加**:

定義 6.1 (ファジー法人化境界)。[t*_start, t*_end] ⊂ ℝ_+ を *法人化窓* とし、下限は法的に認知しうる最早の創業行為 (LLC 設立、ソフトローンチ、自治体規則による法人化みなし) によって、上限は事業会社としての完全登記日によって与える。*法人化重み* を\n\n    B_h(t) := K((t − t*_mid) / h),   t*_mid := (t*_start + t*_end)/2,   h := (t*_end − t*_start)/2,\n\nと定義する。ここで K は K(−∞)=0, K(+∞)=1, K'>0 を満たす滑らかな CDF カーネル (Gaussian-CDF または logistic) である。\n\n定義 6.2 (平滑化されたレジーム動学)。C1 の pre-B / post-B 2 次元系を次のように一般化する\n\n    dx_t = [(1 − B_h(t)) μ_pre(x_t, y_t) + B_h(t) μ_post(x_t, y_t)] dt + σ(x_t, y_t; B_h(t)) dW_t,\n    dy_t は同様に,\n\nとし、平滑化された到達時刻を τ_x^{(h)} := inf{ t : x_t ≥ x̄ } と定める。\n\n命題 6.1 (シャープ極限/滑らかな極限の埋め込み)。族 {τ_x^{(h)}}_{h ≥ 0} は次を満たす: (i) h ↓ 0 のとき τ_x^{(h)} ⇒ τ_x^{(0)} (C1 の Andrews-Quandt シャープ分断を回復); (ii) h ↑ ∞ のとき τ_x^{(h)} ⇒ τ_x^{(∞)} (Ch 11.5 の滑らかな極限、完全委譲可能コーナーを回復); (iii) Var[τ_x^{(h)}] は h について弱単調増加。\n\n命題 6.2 (h の識別可能性)。企業レベルの PRS および ERS 系列に対する Bai-Perron (1998) 多重分断仕様の下で、構造的分断日に対する 95% 信頼帯は [t*_start, t*_end] の一致推定量となる。その幅 ĥ はカーネル選択を所与として識別される。\n\n反証可能主張 (F6)。i = 1,...,N のベンチャーから成るパネルにわたって、企業固有の窓幅 ĥ_i は、PRS ルーチン遷移率の企業内分散 σ_{ΔPRS,i} と正に相関する:\n\n    H0: corr(ĥ_i, σ_{ΔPRS,i}) ≤ 0,   H1: corr(ĥ_i, σ_{ΔPRS,i}) > 0.\n\nH0 の棄却 (α=0.05 の片側検定) はファジー境界拡張を支持する。非棄却または符号反転は拡張を反証し、モデルをシャープな C1 に戻す。

**導出 / 証明素描**:

ステップ 1 (対象)。シャープな事象 1{t ≥ t*} を滑らかな指示子 B_h(t) := K((t − t*_mid)/h) に置き換える。ここで K は CDF 形のカーネル (logistic または Gaussian-CDF)、t*_mid := (t*_start + t*_end)/2、帯域幅 h := (t*_end − t*_start)/2 である。w(t) := B_h(t) ∈ [0,1] を *法人化重み* と定義する。ステップ 2 (レジーム動学)。C1 の 2 次元動学は凸結合となる: ẋ = (1 − w(t)) f_pre(x, y) + w(t) f_post(x, y)、ẏ も同様。pre/post のドリフト、拡散、到達時刻 τ_x の生成作用素は補間され、切換えではない。ステップ 3 (シャープ極限への入れ子化)。h → 0 のとき B_h(t) → 1{t ≥ t*} がほぼ至るところ各点収束し、(ẋ, ẏ) は C1 のシャープなレジーム切換え系に収束する。第 11.5 章の滑らかな極限は h → ∞ (完全委譲可能、緩慢遷移) コーナーとして回復される。両者の以前の定式化は h で添字付けられた一つの族の *境界事例* である。ステップ 4 (平滑化の下での τ_x の存在)。f_pre, f_post は Lipschitz であり w(t) は単調かつ滑らかなので、補間 SDE は強解とよく定義された到達時刻 τ_x^{(h)} を持つ。Skorokhod 連続性により h → 0 のとき τ_x^{(h)} → τ_x^{(0)} が分布収束する。到達時刻の分散は h について弱単調非減少 (平滑化はレジームラベルに雑音を加える) であり、検定可能な比較静学を与える。ステップ 5 ([t*_start, t*_end] の計量経済学的識別)。法的届出日まわりの候補窓における企業レベルのルーチン指標 (PRS の乗法的スコア、ERS の加法的スコア) に対し Bai-Perron (1998) の m 分断検定を用いて 1 個以上の分断を検出する。シャープ分断という帰無仮説 H0 の下では m̂ = 1 で信頼区間は退化する。ファジー境界という対立仮説 H1 の下では、分断日に対する 95% CI が正の幅を持ち、これが我々の推定量 ĥ となる。ステップ 6 (命題)。命題 6.1 (ファジー境界 t*): 帯域幅 h の下でのレジーム切換え到達時刻を τ_x^{(h)} とする。このとき (i) Var[τ_x^{(h)}] は h について弱単調増加; (ii) PRS レジーム遷移率の企業横断分散 σ_{ΔPRS} は h について単調; (iii) シャープモデル (h=0) と滑らかな極限 (h=∞) は識別された一パラメータ族の両端点である。ステップ 7 (反証)。帰無仮説 H_null: 企業 i 横断で cov(ĥ_i, σ_{ΔPRS,i}) = 0。H_null を *予測された正方向に* 棄却すればファジー境界が支持される。棄却失敗または負共分散の場合は拡張は反証され、シャープ C1 に押し戻される。ステップ 8 (C2, C3 との関係)。w(t) は F-CES の F_cap チャネルのみを変調する (委譲可能能力は法的足場とともに連続的にフェーズインする)。F_char チャネル (委譲不可能) は同一性の意味で階段状にとどまり、C2 の委譲不可能性主張を保つ。二層非可換性 (C3) は w(t) が各層 *内* で作用し層を跨がないため保たれる。

### I7_pilot_data_protocol: 試験データ 設計 (N≈32, Andrews-Quandt sup-Wald)

**一行解決**: AMD-8 + 機関後付け 7 + 国際 17 (MIT Deshpande、EPFL TTO、ETH Pioneer、Karolinska Innovation を含む) からなる N≈32 のマルチコホート試験を事前登録し、観測された法人化日 τ_B における Andrews-Quandt sup-Wald ハザード分断検定を実装する。σ_SU × レジーム交互作用は時間変化係数を持つ Cox モデルで点推定し、試験推定値を Ch 10 第 5.4 節に前倒しして OPENER の経験的足場シグナルとする。

**形式記述の追加**:

命題 7 (C1 レジーム切換えの試験段階反証)。i ∈ {1,...,N} を pre-firm ベンチャーの添字とし、[t_{0,i}, T_i] にわたって連続観測されると仮定する。法人化事象時刻 τ_{B,i} ∈ (t_{0,i}, T_i)、生存事象 τ_{y,i} < τ_{x,i} (到達前の資源枯渇) とする。ハザードを h_i(t | Z_i(t)) = h_0(t) · exp( β_1 · 1{t ≥ τ_{B,i}} + β_2 · σ_{SU,i} + β_3 · σ_{SU,i} · 1{t ≥ τ_{B,i}} + γ' X_i ) と定義する。ここで σ_{SU,i} は構造的不確実性指標 (事前の比較対象に対する Bayesian shrinkage 後の Knight 的残差) であり、X_i は F-CES コントロール (F_char, F_cap プロキシ) である。理論 C1 は同時に検定可能な制約 H0^{C1}: β_1 = β_3 = 0 (τ_B でレジーム分断なし) vs H1^{C1}: β_1 > 0 かつ β_3 > 0 を含意する。OPENER 試験は Andrews-Quandt (1993) sup-Wald 統計量 supW = sup over π ∈ [π_0, 1 − π_0] of W_n(π) を、W_n(π) = n · (β_1_hat(π), β_3_hat(π))' V_hat(π)^{-1} (β_1_hat(π), β_3_hat(π)) として、観測された (探索ではない) 分断点 π_i = (τ_{B,i} − t_{0,i}) / (T_i − t_{0,i}) で評価し、χ^2_2 参照分布を持つ点識別された Wald 統計量 W_n_star を得る。反証ルール: 試験 N≈32 において W_n_star < χ^2_{2,0.90} または β_3_hat ≤ 0 ならば C1 は試験段階で棄却され、Book III 第 26b 章のレジストリは再定式化される。系 7.1 (効果量の事前コミット): 方向性の点推定 β_3_hat はコホート IQR で正規化された σ_SU 単位あたり対数ハザードで [0.4, 1.2] にあり、90% CI がゼロから離れていること、これが試験成功を事前に定義する。

**導出 / 証明素描**:

ステップ 1 (C1 を Cox ハザードに対応付ける)。C1 によれば、2 次元系 (x = 到達、y = 残余余裕) は τ_B で不連続に切り替わる: pre-B のドリフト μ_pre = μ_research(σ_SU)、post-B のドリフト μ_post = μ_firm(σ_SU) であり、法的実体・給与・バーンレートが効いてくるため σ_SU への感応度が厳密に大きい。Jovanovic (1982) の到達時刻ロジックにより、{τ_y < τ_x} の条件付きハザードは |μ - σ_SU^2/2| の単調関数であるので、不連続なドリフトジャンプは不連続なハザードジャンプに対応する → β_1 ≠ 0。post-B での σ_SU へのより大きな感応度は β_3 > 0 に対応する。ステップ 2 (観測された分断点の下での識別)。τ_{B,i} は標本内で探索されるのではなくベンチャー毎に観測されるので、従来の Andrews-Quandt の局外パラメータ問題 (Andrews 1993) は個別レベルでは生じない。観測された π_i における W_n_star を報告し、ロバストネスチェックとして制約なしの sup-Wald も追加で報告する。ステップ 3 (τ_B の内生性への対処)。法人化タイミングは (x, y) に関する創業者の信念に対して内生的である。我々は τ_B の機関 TTO クロック効果による残差変動を操作変数として用いる: (i) 大学の会計年度境界 (日本では 3/31、MIT では 6/30)、(ii) GAP/AMED 助成金支給ゲート、(iii) PCT 30 か月国内移行期限。これらは創業者の根底にある σ_SU を動かさずに τ_B をシフトさせる。試験では第一段階 F > 10 を要求する。ステップ 4 (σ_SU の操作化)。σ_SU は、5 年売上に関するアナリスト予測の残差標準偏差であり、Atlas レジストリ内 k-NN 比較対象 (k=10、距離は TRL × セクター × チームサイズ) から形成される平均 Bayesian shrinkage 予測を partial out した後のものである。これは Bloom (2009) や Jurado-Ludvigson-Ng (2015) に倣い、Knight 的残差を測定可能リスクから分離する。ステップ 5 (フレイルティとクラスタリング)。TTO コホートレベルでフレイルティ項 u_j (j は大学/アクセラレーターを添字付け) を持つ共有フレイルティ Cox は機関の未観測異質性を吸収する。SE は j でクラスタリング。ステップ 6 (検出力計算)。N = 32、各 i について τ_B が観測される、β_3 = 0.7、σ(σ_SU) = 1、平均打切り 35% の下で、シミュレーションは片側 α = 0.05 で β_3 > 0 を検出する検出力を約 0.72 と算出する — 試験シグナルとしては十分だが、確定的ではないと事前にコミットしておく (Book III レジストリでは N≈200 へエスカレートする)。ステップ 7 (分析パスの事前登録)。Cox の仕様、操作変数集合、フレイルティ構造、反証ルールは、コホート締切 (32 ベンチャーのうち 28 以上で τ_B が観測されることと定義) より前に OSF と Book III 第 26b 章でタイムスタンプされる。ステップ 8 (第 10 章第 5.4 節への前倒し)。第 5.4 節では、既に τ_B が観測されている AMD-8 サブセットについて τ_B で分割された記述的 Kaplan-Meier 生存曲線 (視覚的ハザード分断) を報告し、事前登録された試験プロトコルを併載する — これにより、確定的識別を主張せずに、理論論文に経験的足場を求める Research Policy 査読者の要求を満たす。ステップ 9 (C2 と C3 への接続)。F_char と F_cap プロキシは X_i として入る。その非代替可能性 (C2) は F_char × F_cap の交互作用と CES 曲率制約 ρ < 0 を加えることで同時に検定可能となる。PRS-ERS の非可換性 (C3) は F-CES カーネルに対する乗法仕様 vs 加法仕様検定 (Vuong 1989) を加えて検定する。ステップ 10 (Lakatos 的硬化)。反証ルールはハード: 試験不合格はコホート締切から 90 日以内に「C1 は試験 N=32 で棄却された」とする公表ノートを発動する — これは両査読者が提起した深い反証可能性要求を満たす。

- 定理 3 (10.4) の因果チャネル制限 A3 が重い役割を担っており、より多くの擁護を要する。A3 は ERS が f に (∂R/∂A_k, ∂S/∂A_k) を通じてのみ入り、P を通じては入らないと課す。これは Dosi 系譜の査読者によって最も挑戦されやすい公理で、彼らは制度資本 (ERS 軸 1) は正統化チャネル (Aldrich-Fiol 1994) を通じて創業者の Purpose を直接形成すると論じる。著者らは A3 を弱めて P を通じた小さな ε チャネルを許容しつつ定理 3 が成立することを示すか、あるいは経験的擁護 (例: 試験コホートで P が A から独立に load することの因子分析的証拠) を提供すべきである。

- R1 (校正、植字に対してのみブロッカー): §§10.2–10.9 にわたる記号統一は本書横断グロッサリーで約束されているが、OPENER 自体は依然として創業者品質乗数に対して 3 つの近似同義語 (F、g(P·R·S)、Cox の暗黙的 exp(β·X)) を使っている。§10.1 で単一の記号を固定し伝播させる必要がある。φ も二重に使われている — §10.6 の全射 {1..8}→2^{K,A,I,D,T} としてと、§10.7 の苗床リスケーリング φ(E_jt) として。どちらか改名すること。
- R2 (軽微、非ブロッキング): 命題 1 の Kmenta (1967) 経由の ρ 識別は (A1) F_char の pre-formation 測定を仮定する。AMD-8 と機関後付け 7 のコホートではこれは妥当に満たされるが、国際 17 (MIT Deshpande、EPFL TTO、ETH Pioneer、Karolinska) では妥当に満たされない — これらのアーカイブでは F_char 複合 (ALQ4+Grit+Resilience) は典型的に法人化後に収集される。§10.3 に逆生存バイアスと Heckman 型補正を論じる一段落のロバストネス節を追加するか、識別主張を AMD + 後付けサブサンプル (N≈15) に限定すること。
- R3 (軽微): 定理 3 (A3) の因果チャネル制限 (∂f/∂A_k は ∂R/∂A_k と ∂S/∂A_k を通じてのみチャネルし、∂P/∂A_k を通じてはチャネルしない) は暗黙裡に Purpose P が環境不変であることを仮定している。これは BZ 段階では擁護可能だ (P は創業者の内的テレオロジー) が、Witt-Hodgson 系の読者は環境が目的を形成すると反対するだろう。§10.4 に半ページを追加し P 不変性を擁護するか、ゆっくりと動く ∂P/∂A_k チャネルを許容するよう A3 を弱めるか — どちらも受容可能だが、非対称性は明示する必要がある。
- R4 (軽微): Klepper 入れ子 (命題 4、§10.5) は F_char→1 かつ Var[x_i(0)]→0 の同時極限のときにのみ Klepper に崩壊する。第二の条件は強い退化仮定であり、命題の前提に埋もれさせるのではなく独立した仮定として述べるべきである。読者は (正当にも) F_char→1 の極限だけで十分かを尋ねるだろう。
- R5 (軽微、提示): §10.6 命題 5.L はレーン添字付き重みに 3 つの符号制約を事前コミットしているが、検定 (同時 Wald vs. Bonferroni を伴う 3 つの独立した片側検定) を指定していない。多重比較プロトコルなしには事前登録は不完全である。3 行の追補で十分。
- R6 (軽微、スコープ): §10.9 の N≈32 試験は事前コミットされた効果量 β̂_3 ∈ [0.4, 1.2] の下で β_1=β_3=0 を棄却するに十分だが、検出力計算 (下限 0.4 における 1-β) を明示し、設計が下端側対立仮説に対して検出力不足ではないことを査読者が検証できるようにすべきである。一段落と一表で済む。
- R7 (ごく軽微): Murmann のファジー RD 識別 (定理 10.6.5) は限界 B 通過者における η_{j,t+1} の連続性仮定を要する — 標準的だが未記載。McCrary (2008) 密度連続性検定を試験の診断バッテリーに加えること。
- R8 (装飾的): §10.0 は「理論オープナーかつ経験的事前登録ドキュメント」の双方を約束する — この二重役割は §10.9 によって今や真に果たされているが、章タイトルと Book II 前付けでそれを示すべきである。第 10 章を「BZ 段階対象: 理論と事前登録」と改題し、TOC から経験的事前コミットメントが見えるようにすることを検討せよ。これはシリーズ位置付けにとって重要である: Cambridge UP Schumpeter 読者で TOC を流し読みする者は、これがまた一つのデータなし形式モノグラフではないことを確認する必要がある。

## 4. 軽微修正の残課題 (執筆中対応)

進化経済学者が受理前の条件として挙げた 5 件 (軽微修正レベル):

1. **N≈32 における試験検出力計算**: §10.9 で Andrews-Quandt sup-Wald の効果量 β̂_3 ∈ [0.4, 1.2] は妥当だが、N=32 でその範囲を検出できる検出力が示されていない。検出力計算表が必要。
2. **§10.8 におけるカーネル識別の非一意性**: t*_start, t*_end はカーネル選択を所与として識別されるが、F6 (corr(ĥ_i, σ_{ΔPRS,i})>0) は ĥ_i に依存。カーネル ロバストな反証主張が必要。
3. **F_char 複合 (ALQ4 + Grit + Resilience) の測定妥当性**: §10.3 の識別は F_char,i の pre-formation 測定を仮定するが、ALQ4/Grit-S は自己申告で treatment 後の汚染余地がある。測定誤差感度分析が必要。
4. **国際 17 コホート選抜**: MIT Deshpande / EPFL TTO / ETH Pioneer / Karolinska Innovation の 4 プログラムによる初期コホート選定は非ランダムで、コホート × 業種固定効果に吸収されない可能性。選抜補正戦略が必要。
5. **定理 3 (二層非可換性) の因果チャネル制限 A3**: ERS が f に R/S 経由でのみ入り P には入らない、という A3 が重い役割を担う。公理的に擁護するか、A3 違反のケースを検定設計で抑える必要。

これらは執筆中に解消可能。Cambridge UP 投稿前に対応する軽微修正を経て受理見込み。
