**3.1 会社の値段はどう決めるか——Valuation と DCF の射程** (2,000字)
冒頭で数式復帰を宣言 = 第2章 2.3「数式が戻ってくるのは次の第3章から」の約束を回収。同時に三点セットで安心材料: (i) 第1章 1.3 の三約束 (記号は巻頭一覧 / 宣言と計算の区別 / 式は読み飛ばしても筋が通る) は本章でも生きている (ii) 本書の物差しで数値を出す計算 (三因子の採点・統合スコア) は第II部 — 第9章が計算実習 (iii) 本章の演習で行うのは、従来の道具が壊れることを手で確かめる計算 (第1章「計算は第II部から」と矛盾させない区別文言)。次に礼法 (第1章 1.1・第2章 2.1 と同型、批判でなく射程の確認 —「この道具は、何の存在と、どんなデータを前提に働くか」)。Valuation (企業価値評価) の定義から DCF を主役に: 直感 (将来稼ぐ現金を、遠い年のものほど大きく割り引いて足し合わせる) → 式 PV = Σ CF_t/(1+r)^t → 式後の日本語読み下し (why-valuation-fails の DCF 解説を圧縮)。**割引率 r の「三つの仕事」を礼法水準で導入**: ①時間価値の換算 (いまの1円 > 将来の1円) ②事業リスクの織り込み ③予測の不確実性の吸収 — この三つ目が Before Zero で膨張する伏線 (正体は 3.5 の Box で開く)。前提条件 = キャッシュフローの実績があり将来を堅実に外挿できること。**DCF は正しい道具** (成熟事業の M&A・設備投資で標準であり続ける十分な理由) と道具を立てる。表3-1 = 評価手法の射程 (手法 | 測るもの | 前提とする存在・データ | 射程): DCF / VC メソッド・マルチプル法 (Gompers & Lerner; Sahlman — 類似企業の取引相場から逆算) / スコアカード法 (項目別採点の加重和) / リアルオプション評価の実務 (段階投資の柔軟性を評価)。DCF 以外は表 + 各1〜2文の非対称 (本章の壁は DCF の壁として立てる)。機会の手前に「見つけるものか、作るものか」の立場の違いがあること (Alvarez & Barney 2007) は一文の名指しのみ (本書は中立、天井の測り方は第4章)。締め: どの道具も射程内では今も最良。問題は道具の善し悪しではなく適用範囲 — 会社になる前へ持ち込むと、四つの壁に当たる (3.2 の挿話を挟んで 3.3 へ)。

**3.2 三十億円の数字の旅——同じ数字が、場所ごとに顔を変える** (1,200字)
why-valuation-fails 章頭場面の低解像度挿話 (全再現しない・要約的に・場面クレームは Book A の was 挿話として登録済み)。骨子: ある産学連携の現場で、市場調査レポートの市場規模 × 対象セグメント × 想定シェアの掛け算から「5年後売上30億円」が生まれる — 一つひとつの仮定には出典があり、誰も嘘をついていない。ただ、その掛け算の答えを検証した者は世界に一人もいない。その数字が場所を変えるたびに別の顔を持つ: 投資家の前では「正直、小さいですね。100億円の絵が見えないと」(野心の大きさ) / 学内審査会では「本当に達成できるんですか。できなかったら誰が責任を」(約束の重さ) / 資金調達の場では想定時価総額10億円「このステージだと、正直、相場です。いまこの分野が熱いので」(分野の熱気)。結びは原文の核心を圧縮: けれど、プロジェクトが生きるか死ぬかを、どの数字も測っていなかった — 私たちはいったい、何を測っていたのだろう。この問いを 3.3 の四つの壁への転回点に。「30億円という数字は何を測っていたか」は章末の討議でもう一度考えると軽く予告 (3.8 討議3-3 への伏線)。登場人物は役割語のみ (産学連携の担当者・研究者・投資家・審査委員)、この挿話も合成事例である旨を一言 (3.0 の会議とは別案件)。図なし・数式なし (説明の 3.1 と分析の 3.3 の間の物語的小休止)。

**3.3 四つの壁——評価の道具は、設立前のどこで壊れるか** (2,350字)
3.2 の「何を測っていたのだろう」を受け、DCF が Before Zero で壊れる構造を四つの壁として体系化 (why-valuation-fails §2.2-2.5 の圧縮再構成)。**壁① 前提が、全部仮定になる**: 設立前は CF の実績が一切ない → CF_t・成長率・黒字化年のすべてを仮定で埋める / 精緻に見える数表が反映しているのは事業の実体ではなく「どれだけ大きな構想を描けるか」/ 割引率や成長率を数ポイント動かすだけで企業価値が数倍変わる (この壊れ方は演習3-1 で自分の手で確かめる、と伏線) / ベンチャー投資の現場で使われる 30〜70% という極端な割引率は、「この段階で CF 予測は機能していない」という実務からの告白 (3.1 の r の三つ目の仕事に接続)。**壁② 期待 (ハイプ) を測ってしまう**: 将来 CF は誰にも観測できない → Valuation の実体は市場参加者の期待 / 分野が「来ている」とされれば中身が変わらないのに評価額だけが動き、冷えれば下がる / 3.2 の30億円の旅はこの壁の実演だった / 高い評価額が「準備が整っている」と誤読される瞬間が実害 — 周囲の過熱に押されて稼げる体質が整う前に会社を作ってしまう (第2章の早すぎる登記・τ_B と一文で接続)。図3-1 = 期待で揺れる評価額と、積み上がる準備度の対比。**壁③ 単一の値は、律速を隠す**: 律速の語 (第1章 1.4 の「最も弱い軸」既出) を確認 / 同じ「想定時価総額10億円」の二案件でも、内訳を開けば次の一手がまったく違う (技術だけ突出した一本足型 vs 全体バランス型 — readiness の軸名は出さず概念水準で、軸の中身は第5章) / 単一値はこの差を潰し、「何が弱いか」が見えない指標は経営の道具にならない。**壁④ 「死なない力」を測る軸がない (最重要)**: ディープテックの死因第一位は技術の劣後ではなく、本命が整う前に資金と選択肢が尽きること / 資金だけでなく交渉の選択肢が尽きる「主導権の死」もある (第2章の登記後の NO_GO 消失と響く) / 従来手法はこの失敗の可能性を割引率に暗黙に押し込む → 「なぜ死にそうなのか」「どうすれば死ななくなるのか」が二度と読み出せない。評価額の高いプロジェクトと、死なないプロジェクトは、別物 (挿話の彼女が見た二つの結末を型として一文回収)。締め: 四つの壁を裏返すと、必要な物差しの仕様が浮かぶ — 期待ではなく事実を測る / 単一値ではなく内訳が見える / 設立前から連続で測れる / 死なない力を独立の軸として持つ。この仕様を満たす形を、次節で組み立てる。J カーブ一律適用の副作用は一文に留める (正しいサイズの成功は第14章の領土)。

**3.4 では、何を測ればよいのか——期待値分解 E[V] ≈ P × R × S** (1,850字)
3.3 末の仕様を受けて、意思決定理論の標準的な分解から物差しを組み立てる (model-overview「なぜ積なのか」+ why-valuation-fails「では、何を測ればよいのか」の統合降圧)。教育順 = 直感 → 式 → 式後の日本語。直感: 不確実な賞金の期待値は、賞金の大きさ × 当たる確率 (宝くじと同型)。式: E[価値] ≈ 天井の大きさ × そこに到達できる確率。天井が P。次に到達確率を二つに割る: いまどこまで来ているか (R) と、残りの道のりを死なずに走り切れるか (S)。登山のたとえ (八合目の隊と二合目の隊は見込みが違う = R の情報 / 同じ八合目でも食料が十分な隊と残り一日分の隊は見込みがまるで違う = S の情報 / 現在位置と走り切る力は独立に変化するので、混ぜると「八合目だが食料切れ寸前」という最も危険な状態が見えなくなる)。合わせて **E[V] ≈ P × R × S**。図3-2 = 三因子の概念図 (P = 山の高さ / R = 現在位置 / S = 燃料の残量と迂回ルート)。**honest 位置付けの宣言**: この分解は本書の発明ではない — 不確実な物事の価値を測るときの意思決定理論の標準的な分解を、設立前の案件が読める形に翻訳したもの (第1章 1.5「発展途上のフレームワークの現在地」「疑いながら使う」の姿勢と整合)。到達確率 ≈ R × S と「分けて掛ける」ことは近似であり読み方の道具である、の水位に留める (独立性の命題化・相関の細部はしない — 厳密な扱いは「本書の理論的基盤を与える学術書 (刊行準備中)」の一般形言及のみ)。**第1章 1.4 との接続 (再宣言でなく導出)**: PRS_t = P_t × R_t × S_t は第1章で観測レンズとして宣言済み — 本節の仕事は、その宣言を四つの壁への答えとして導き直すこと。あわせて構造と測定のレベル分けを一文: 本章が固めるのは分解の構造で、各因子を共通の物差し ([0,1] の採点) に載せる作業は第II部の各章。使用記号は PV, CF_t, r, E[価値], P, R, S (+ 既出 PRS_t への言及) のみ。末尾: この分解が、これまで使ってきた道具 (DCF) とどう関係するのか — 否定なのか、置き換えなのか — を次節で確かめる、と 3.5 へ橋。

**3.5 DCF が測っていたのは、天井だけ——割引率に隠れていた到達と生存** (1,950字)
honest 位置付けの核 (model-overview「DCF は何を測っていたのか」の降圧 + r 分解 Box)。主張: DCF が精緻に作り込もうとしていたのは、実質的に P だけだった — 事業計画から将来 CF を描く作業は「このシーズが最大限うまくいったときの絵」= 天井の見積もり / その絵が実現するかどうか (R と S) は計画書の数字の中に入っておらず、不確実さは割引率という一つの数字に押し込まれてきた。ここで 3.1 の伏線を回収する **Box 3-1 = 割引率の三つの仕事とその行き先**: r を開くと ①時間価値の換算 (正当な割引 — この仕事は残る) ②事業リスクの織り込み ③失敗して(ゼロになる)確率の埋め合わせ、の三層 / ベンチャー投資の 30〜70% という極端な r の正体の大部分は③ (実務観察として提示、why-valuation-fails 原文準拠) / 本書の物差しでは、③の「死なない力」を生存 S が独立の因子として引き取り、②のうち到達に関わる部分を R が引き取る — これが「S (と R) が肩代わりできる範囲」/ 一つの利率に溶かすと読み出せなかった「なぜ死にそうか」が、因子に開くと読める。図3-3 = 割引率 r に押し込まれていたものが P・R・S へ開かれる対比図 (本章の看板図版)。Box は読み飛ばしても本文の筋が通る独立設計。そのうえで関係を確定: 本書のモデルは DCF の否定ではなく**包含** — E[価値] ≈ P × Pr(到達) に照らせば、DCF は右辺の前半 (P) だけを精緻化し、後半を割引率に丸めていた。本書はその丸められていた部分を開いて、観測できる因子に分けたもの (上位互換の関係)。表3-2 = DCF と本書のモデルの対比 (測っているもの / 会社になる前の評価 / 不確実性の扱い / 弱点の可視性 — 素材2ファイルの対比表の統合版)。文言注意: validation 語彙禁止 — 「実務の観察に支えられている」の水位に留め「検証済み」と断定しない。
