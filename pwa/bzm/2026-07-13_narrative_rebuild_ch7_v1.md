## 1. 現行診断 — なぜ的を外しているか (降格の根拠)

現行 7.0「同じ週に届いた三つの信号」の中心の運動は、**揃った信号への高揚 (真柴) と、信号の独立性への疑い (笹本の問い)** である。撃っているのは「同じ週に並んだ信号は独立か、同じ流れの反響か」= 数え方の規律であり、理論側では Box 7-2 (群れ) と 7.6 の防御規律 (ハイプ識別) に接続する**防御側**の問い。命題 v2 の新しい核「乖離 = 先回りの窓 (攻め)」は場面のどこにも存在しない。

より深い病理は、**乖離の向きが逆**なことである。

- 現行の三信号 = 公募の公示 (官)・海外競合の大型調達 (産)・企業の前向きな返事 (産)。理論 7.1 自身が解剖しているとおり、この週に鳴ったのは**官と産だけで、学の時計は鳴っていない**。
- ところが命題 v2 の窓は「**論文は増えているのに助成金がまだ無い分野**」— つまり**学が先に鳴り、産官がまだ黙っている**乖離である。
- 現行場面の乖離 (産官が先・学が後) は、7.6 の規律で読めば「実体の裏づけが薄いのに外の期待だけが鳴っている」— 警戒すべき乖離の側にしかならない。**現行の座組では、先回りの窓としての乖離は原理的に描けない**。語り直し・意味層の再定義では回復不能で、Ch2 と同じく題材レベルの病である。
- さらに 7.7 が「三つの勢いが同じ方向にそろって強まった結果だった。追い風は本物だった」と**揃いを肯定的に確定**して閉じており、「揃った風はもうみんなの風 (= 揃いの確認が済むころには、もう秘密ではない)」の反転が理論回収の側でも起きていない (7.6 末尾に追記済みの一段落だけが孤立している)。

ゆえに現行は候補 D (降格) とし、学が先行する乖離を場面の背骨に置く新場面をゼロから構想する。

## 2. 本命案「風に名前がつくとき——誰も並ばない窓口」

**一行定義: 風の揃った領域の熱気 (満員の説明会場) と、自分たちの領域の静けさ (誰も並ばない相談窓口) を同じ日に浴びた男が、「風がない」と落ち込んで帰る——学会の中でだけ二年前から増え続けている折れ線が、その静けさの意味を裏返しかけたところで、章が閉じる話。**

### 2.1 何を撃つか

- **揃った風はもうみんなの風**: 追い風の「揃い」を、会場の物理 (廊下まで伸びる列・刷り切れた資料・名刺の飛び交い) として描く。読者は初読でこの熱気を「うらやましい追い風」と読む — 実はそれは「もう混み合っている風」の絵である。反転は場面では言語化せず、討議課題と理論 (7.6〜7.7 改修) で確定させる。
- **乖離は先回りの窓**: チームの領域は、公募の一覧では例示の一語・窓口は閑散 (産官がまだ) なのに、学会の発表だけが二年前から倍増している (学が先行)。命題の実例「論文は増えているのに助成金がまだ無い分野」を、**そのままの向き**で場面に置く。
- **観測の遅れ**: 春一番は「吹いたあとで、名前が付く」風である (気象台の事後発表)。「風に名前が付いたときには、もうみんなが知っている」— 揃いの確認と手遅れの同時性を、季節の装置がそのまま体現する。
- 真柴の既視感 (台帳 §2.7 確定の倒産経験) は新しい断面で使う: 逆風が群れで来るのを見た人は、**風の絶頂の景色**も同じ場所で見ている。会場の唸りに覚えがある — いちばん調子のよかった年の会場と、同じ音がする。「揃った風の眩しさのすぐ裏の静けさ」を知る人物としての既視感 (言語化はさせない — 「いま思い出す話ではない」と自分で棚に上げる)。

### 2.2 あらすじ (二場面・順行)

**場面1 (三月の木曜・都心の貸会議場)**: 来年度の研究開発支援事業の公開説明会。真柴は勤め先に半休を出して午後から参加。重点分野の筆頭の領域 (この一年、新聞で見ない週がなくなった領域 — 固有名は書かない) の相談窓口は廊下まで列が伸び、資料は刷り切れ、会場は唸っている。自分たちの領域の窓口は最奥で、番号札二番は待たずに呼ばれる (一番の誰かは、もう帰ったあと)。一覧では「関連する技術の例」として一語だけ。相談員の答えは「対象に、なりえないことは、ないです」。

**場面2 (土曜の午後・笹本の研究室)**: 月に一度の対面回。真柴の報告は熱気 (速い声) と静けさ (落ちる声) の二色に割れる —「風は、世の中には吹いている。うちの頭の上では、まだ吹いていない」。出すこと自体に迷いはない (試作の次の一台は研究室の手持ちでは作れない — この公募が初めてのまとまった資金の当て)。決めるべきは「どう出すか」。若手の助教が「向こうの言葉で書く手は」と看板の掛け替えを口にし、真柴も内心では申請書を向こうの言葉で書き直しはじめている (そして会場の唸りへの既視感が兆すが、棚に上げる)。笹本が長机に二枚の紙を並べる — 真柴が持ち帰った重点分野の一覧と、自分で刷ってきた学会発表数の折れ線 (この二年でおよそ倍)。「こちらの言葉が新聞に載るようになったのは、この一年です」「——向こうの、二年前は、どう、だったんでしょうね」。問いは宙に浮いたまま、部屋が静かになる。窓の外では朝から南風。誰かの端末がニュースを読み上げる — 気象台が、けさ、春一番が吹いたと**発表した**。幕 = 名前をもらったことも知らないまま並木を撓ませ続ける風の風景。

### 2.3 設計整合 (要点)

- **技術分野 = 電磁波吸収材料** (機器から漏れ出す電波・機器に飛び込む電波を、薄い板で吸いとる機能材料 — 次世代の通信や車載機器の干渉対策へ向かう領域) を確定提案 (v1.1 で「廃熱の熱電変換」から差し替え)。理由: ①「新しい周波数帯の材料研究は、規格の商用化に数年先行して学会で積み上がる」という**学先行・産官遅行の時間差が実在領域の技術史として自然**で、命題の実例 (論文は増えているのに助成金がまだ無い分野) に最適 ②試作のデモ (送信の器具と計器のあいだに板を差し入れると、数字が目に見えて落ちる) が素人にも一目で分かり、真柴の一目惚れ (台帳 §2.7 確定) の絵になる ③材料合成+卓上評価のラボスケールで回り、手弁当の自走チームと整合 ④機関の性格 (材料・化学系に厚い工学系) と整合。**実在案件からの距離 (2026-07-13 司令塔経由まさ確定基準)**: 回避リスト (海洋エネルギー・風力・断熱遮熱・電池/資源回収・廃棄物熱分解・微生物/バイオ・農食・生成AI/SW) のいずれとも技術系統・用途・市場が離れており、既存作中案件 (A 機能性材料 [総称・中身は不特定] / H コーティング材料) とも形態・機能で区別できる。初版の「廃熱の熱電変換」は未利用エネルギー回収という系統が回避リスト (海洋エネ・廃棄物熱分解) と近いため差し替えた。
- **装置 (一章一装置) = 風の名前** (名前のつく風 = もうみんなの風 / まだ名前のない風)。数の装置は立てない — 三 = 産官学は素材として場面に散らす (学会の折れ線 [学]・新聞と会場の列 [産]・重点分野の一覧 [官]) 。理論 7.1 が回収する。
- **読者誘導**: 初読 = 「向こうは追い風、うちは風なし」という真柴の落胆に同調させる。笹本の「向こうの、二年前は」で「あれ?」を起こし、討議課題2で読者自身が「二年前の向こう = いまのうち」に行き着く。反転の確定 (乖離 = 窓) は理論 7.6〜7.7 の仕事。
- **問いを認識する人物を置かない**: 笹本は事実 (二枚の紙・二年と一年の時間差) と問いまで — 「だから今が好機」とは言わない。真柴は繋がりかけて自分で棚に上げる。助教は言いかけてやめる。
- **幕 = 風景** (設計表指定を維持)。**主調音 = 速度と既視感** (維持 — 速度は「もうみんな走っている」会場の速度へ、既視感は「絶頂の景色を知っている」側へ中身を更新)。
- **通奏低音**: ①時計 — 「来年度」「半休」「二年」「この一年」「月に一度」の沈黙配置 (「時計」の語は場面に出さず、理論 7.1 が翻訳する) ②手の中の小さな物 = **番号札の二番** (受付で渡され→返しそびれ→幕直前にポケットで指先に触れる。初読では「誰も並ばない惨めさ」、再読では「まだ誰も来ていない早さ」— 同じ物が二つの読みを持つ) ③言えなかったこと = 宙に浮く問い (笹本の「二年前は」) + 助教の言いかけ + 真柴の「いま思い出す話ではない」。
- **橋 6→7**: 満点の審査 (Ch6・機関の網の中・揃って選ばれる場) の直後に、どの網にも掛からない場所 (誰にも選ばれていない領域の、誰も並ばない窓口) — 対比が命題レベルでも強化される。**橋 7→8**: 「乗ることと走り切ることは別」は維持 — 名のない風に賭けて公募に乗る決断の先の長さを Ch8 (四月始まり・空白の成果欄) が受ける。物理の担い手は「三本の矢印の紙」から「長机の二枚の紙」へ更新 (§7)。
- **現実考証**: 三月に翌年度事業の公開説明会 + 分野別相談窓口は公募実務として一般的 / 重点分野の例示欄と「対象になりえます」型の回答は制度運用の実態 / 電磁波吸収材の卓上デモ (送受信系に板を挟むと計器の数字が落ちる) は展示会の定番形式でラボスケールとして現実的 / 新周波数帯の材料研究が規格の商用化に数年先行する時間差は通信分野の技術史の実態 / 学会の専門部会新設→発表倍増は新興領域の典型 / 春一番は気象台の事後発表 (吹いた後に名前が付く) — 気象の事実。
- **一般化規律**: 事業名・会場名・機関名・流行領域の固有名は書かない。チームの分野 (電磁波吸収材料) は実在領域だが性能値・数値は書かない。人物の経歴の固有性なし。
- **チーム構成**: 真柴・笹本・若手の助教の3人とする (現行の「若手ふたり」は持ち越さない — 人数も構想の結果。より小さく、より手弁当の生活感)。

## 7.0 風に名前がつくとき——誰も並ばない窓口

受付で渡された番号札は、二番だった。

三月の木曜である。都心の貸会議場では、来年度の研究開発支援事業の公開説明会が、朝から開かれていた。午前が制度の全体説明、午後は重点分野ごとに相談の窓口が並ぶ。真柴は勤め先に半休を出して、午後から来た。平日の昼間に外を回れるのは、このチームでは自分だけである。エスカレーターを上がりきるより先に、音が来た。人の声が、天井の高いロビーで一つの唸りになっている。

会場の熱は、想像していたより濃かった。重点分野の筆頭に掲げられた領域——この一年、新聞で見ない週がなくなった領域である——の窓口には、相談待ちの列が廊下まで伸びていた。配布資料の台は、その分野の棚だけが早々に空になり、増刷中、と手書きの紙が貼られている。列には、そろいの上着の企業の一団もいれば、教員らしい年配のひとりもいる。奥のホールの壇上では、投資を扱う会社の人が、この領域への資金の集まり方を数字で語っているところで、聞き手の肩越しに、スライドを写す端末がいくつも持ち上がっていた。壁際では名刺が飛び交い、誰もが少しだけ早口で、誰もが少しだけ前のめりに立っていた。真柴は、その熱を胸のあたりで受け止めた。悪い気はしなかった。風は、世の中に、こんなにもはっきり吹いている。

自分たちの領域の窓口は、いちばん奥の、非常口を背にした長机だった。

機器から漏れ出す電波と、機器に飛び込んでくる電波を、薄い板で吸いとってしまう——笹本の研究室が長く積み上げてきた材料の話である。二年前、公開の技術説明会で、真柴はその試作を初めて見た。送信の器具と計器のあいだに、手のひらほどの黒い薄板が差し入れられると、計器の数字が、目に見えて落ちた。板を抜けば、数字は戻る。仕掛けも、電源も、何もなしにである。これは外へ出るべきだと思い込んで、気づけば名刺を差し出していた。以来、週に一度の画面越しの定例と、月に一度の研究室の長机が、このチームの持ち場である。平日の夜と週末が、真柴の持ち時間だった。

その窓口の前に、列はなかった。

番号札の二番は、待たずに呼ばれた。一番の札の誰かは、もう帰ったあとらしい。相談員は、丁寧だった。丁寧に制度の趣旨を説明し、丁寧に、重点分野の一覧をなぞってくれた。真柴たちの領域の名前は、一覧の終わりに近い行に、関連する技術の例として、一語だけ載っている。対象になるのか、と真柴は訊いた。対象に、なりえないことは、ないです、と相談員は答えた。この欄は、あくまで例示ですので。昨年度、この領域からの応募は、と真柴が重ねて訊くと、相談員は手元の綴りをめくる素振りだけして、多くは、なかったと記憶しています、と言った。それから、声を落として付け加えた。「ただ、審査の場では、取り組みの意義を、丁寧にご説明なさるのがよいかと」。背中の向こうで、ロビーの唸りが続いている。礼を言って立ち上がり、外の風に当たったところで、番号札を返しそびれたことに気づいた。

土曜の午後、三人は笹本の研究室に集まった。月に一度、顔を合わせる回である。実験机の端を片づけて、湯呑みを三つ置いただけの会議だった。窓の外では朝から南風が育っていて、中庭の若い並木を、まとめて撓ませている。

説明会の報告は、自分でも聞き分けられるほど、二色に割れた。向こうの熱気を語るとき、真柴の声は速くなった。廊下まで伸びた列。刷り切れた資料。そろいの上着の一団。それから、自分たちの窓口の静けさに話が及んで、声は落ちた。番号札の、二番。例示の、一語。丁寧な相談員。「風は、ある」と真柴は言った。「世の中には、ちゃんと吹いている。ただ、うちの頭の上では、まだ吹いていない」

出すこと自体に、迷いはなかった。この公募は、チームにとって初めての、まとまった資金の当てである。試作の次の一台は、研究室の手持ちでは作れない——それが去年の秋からの、動かない事実だった。決めるべきは、出すかどうかではなく、どう出すかである。

若手の助教が、遠慮がちに口を開いた。「向こうの言葉で書く手は、ないんでしょうか。電波の漏れや干渉は、あちらの機器でも困りごとだと聞きます。入り口は、向こうのほうが、ずっと広い」

正直なところ、真柴は、その一言を待っていた気がした。同じことを、帰りの電車で考え続けていたからである。向こうには風がある。風のあるところへ、荷物を運び直す。外へつなぐ役目を引き受けた者の、それが正しい仕事のようにも思えた。頭の中では、申請書の一枚目が、もう向こうの分野の言葉で書き直されはじめている。それに——あの熱気には、覚えがあった。前に勤めていた、研究開発型の小さな会社。いちばん調子のよかった年に出入りしていた会場が、ちょうどあんな唸り方をしていた。頼む前に、申し出のほうが列を作った時期である。その列が、その後どうなったかも、真柴は同じ場所で見ている。——いや、あれは自分たちの不運の話だ。いま思い出す話ではない。

笹本は、さっきから黙って、長机に二枚の紙を並べていた。

一枚は、真柴が持ち帰った、重点分野の一覧である。もう一枚は、笹本が自分で刷ってきた折れ線のグラフだった。学会でのこの領域の発表の数は、この二年で、およそ倍になっています、と笹本は言った。国際会議に専門の部会が立ったのが、その始まりです。初回は、顔見知りばかりの小さな部屋でしたが——このごろは、知らない若い発表者のほうが多い。それから、一覧の筆頭の領域を、指の背でそっと示した。「こちらの言葉が新聞に載るようになったのは、たしか、この一年です」

助教が何かを言いかけて、やめた。

「向こうの、二年前は」と、笹本は誰にともなく言った。「どう、だったんでしょうね」

部屋が、静かになった。真柴は、長机の二枚を見た。片方には、もうみんなが知っている風の名前が刷られている。もう片方の折れ線は、まだ、名前を持っていない。上着のポケットに手を入れると、返しそびれた番号札が、指先に触れた。誰も並ばなかった窓口の、二番である。

窓が、ひとつ鳴った。助教が立ちあがって、緩んだ留め具を締め直す。誰かの端末が、短くニュースを読み上げた——気象台は、けさ、この地方に春一番が吹いたと発表した。窓の外では、朝から吹き通しの南風が、名前をもらったことも知らないまま、若い並木を撓ませ続けている。

## 3. 対案B「三度目の要領」— 不採択の講評に記録されていた風

**一行定義: 今年の公募要領の対象分野に、初めて自分たちの領域の言葉が載った——三度目の挑戦に沸くチームの前で、過去二回の不採択通知の講評文面が、風の動き出す音を年輪のように記録していたことに、誰も名前を付けられない話。**

- 場面: 三月、今年の要領の公示日の夜、画面越しの定例。真柴が「今年は風がこっちを向いた」と沸く。笹本が過去二通の不採択通知を映す — 一年目「社会的意義が不明確」、二年目「意義は認めるが時期尚早」、そして今年、対象分野への明記。**官の時計が動き出す音が、落選の紙に記録されていた**。若手「今年は通りますよ」。笹本「載った、ということは——今年から、この分野で出してくるのは、うちだけではなくなります」の手前で言葉を切る。幕 = 三枚の紙 (二通の通知と今年の要領) が机に並ぶ絵 + 窓の外の春一番。
- 強み: 「窓の中にいた二年」(誰にも評価されない時間) の実感 / 講評文面の変化 = 動学層の生データが場面にある / 続報 (今回採択) と滑らかに接続。
- 弱み: ①過去回想が骨格になり、不採択の湿度が Ch8 (空白の成果欄・保留の帳簿) と情緒的に近接 ②「二年前から公募に出し続けていた」ことになり、手弁当チームの「外部にはまだ薄くしか接していない」感より既成の活動歴が前に出る ③「揃った風はもうみんなの風」の側 (会場の熱気のような物理) が場面にない — 命題の片翼 (乖離 = 窓) だけを撃つ。

## 4. 対案C「風下の火曜日」— 看板を掛け替える人々

**一行定義: 流行領域に国の大型事業の発表があった日の夜、画面越しの定例で「隣の研究室が来年度からあちらへ看板を掛け替えるらしい」という知らせを聞きながら、学界ぜんぶが風上へ向き直っていく風景を、網の外のチームが眺めている話。**

- 場面: 火曜夜のオンライン定例。昼に流行領域への大型事業のニュース。助教の報告「隣の研究室、来年度から向こうの分野へ看板を掛け替えるそうです」。学内も学会もざわつき、みんなが風上を向いていく。「うちも、半分だけ寄せませんか」。真柴の動揺。笹本が発表件数の二本の折れ線を画面共有 — 流行領域は頭打ちの兆し、自分たちの領域は増え続けている。幕 = 会議が終わり画面が消えた真柴の自室、窓の外の夜の春一番、机の上の書きかけの申請書。
- 強み: 手弁当の生活感 (自宅・画面越し) が16話中で最も濃い / 「みんなの風」を人の移動 (看板の掛け替え) として描ける / 一場面で締まる。
- 弱み: ①全編が画面越しで、熱気の身体性 (会場の唸りのような物理) が伝聞になる — 「みんなの風」の圧が弱い ②幕の風景が自室の窓で小さい ③頭打ちの折れ線 (流行側の μ_A 下降) まで見せると、理論 7.6 の「揃って続く = 本物」との整合に一段説明が要る。

## 5. 候補D (降格) — 現行「同じ週に届いた三つの信号」

現行場面を候補の一つとして同じ土俵に置く。改修コストは最小 (理論側 7.1/7.5/7.7/Box 7-2 が現行の場面参照で書かれているため無傷)。しかし §1 の診断のとおり、**乖離の向きが構造的に逆** (産官が鳴り、学が沈黙) で、命題 v2 の「論文は増えているのに助成金がまだ無い分野 = 先回りの窓」を場面が原理的に例示できない。7.7 の「揃って強まった = 本物」の肯定確定も命題の反転と正面衝突する。ゼロから構想した結果、現行と同じ答えには帰着しなかった — 不採用を推奨。

## 6. 推奨

**本命案「風に名前がつくとき」を推奨。** 理由: ①命題の両翼 (揃った風 = みんなの風 / 乖離 = 窓) を、会場の熱気と誰も並ばない窓口という一日の身体経験の対比で同時に撃てる唯一の案 ②「春一番 = 吹いたあとで名前が付く風」が季節指定 (三月・春一番) を装置そのものに変える ③番号札の二番が「惨めさ→早さ」の二重の読みを持ち、再読に耐える ④理論側との噛み合いが現行より深くなる — チーム領域の「μ_A だけが高い」形は演習のハイプ型 (レーンB) と同型であり、「ハイプと窓を分けるのは動学層 (二年の持続) と実体」という 7.5〜7.6 の主題が、場面の二枚の紙から直接立ち上がる (§7 の 7.7 改修案参照)。
