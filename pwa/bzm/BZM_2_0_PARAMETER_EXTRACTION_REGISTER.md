# BZM 2.0 SPS パラメータ抽出台帳

> **状態**：`extraction-register v0.1`（2026-08-11）
>
> **主張の地位**：`design-choice`。抽出手続きの正本であり、各PJの値が測定済みであることや、予測精度が確認済みであることを意味しない。
>
> **理論正本**：`pwa/bzm/sps-2-0-reachability-model.md`

## 1. この台帳の目的

この台帳は、BZM 2.0のSPSを構成する全パラメータについて、「どの資料から」「どの手順で」「どの単位へ」抽出するかを固定する。

各値は、値だけでなく、情報締切、出所、根拠状態、抽出規則の版、反映先を同時に保存する。

到達可能性を測る入力と価値を測る入力を分け、同じ事象を複数の場所へ重ねて入れない。

## 2. 最上位式と価値への三経路

到達事象を次のように置く。

$$
A_v=\{T_C<T_Y,\ T_C\le H_v\}
$$

| 記号 | 意味 |
|---|---|
| $A_v$ | 計画版$v$の期限内かつ戦略余力を失う前に共通到達目標へ着く事象 |
| $T_C$ | 共通到達目標へ初めて着くまでの時間 |
| $T_Y$ | 戦略余力を失うまでの時間 |
| $H_v$ | 計画版$v$の判定期限 |

SPSの正本は次の三式である。

$$
q_\tau=\Pr(A_v\mid\mathcal I_\tau)
$$

$$
P_\tau=
\operatorname E\!\left[
M_{\tau,T_C}V^{\mathrm{eq}}_{T_C}
\mid A_v,\mathcal I_\tau
\right]
$$

$$
\mathrm{SPS}_\tau
=q_\tau P_\tau
=\operatorname E\!\left[
M_{\tau,T_C}\mathbf 1_{A_v}V^{\mathrm{eq}}_{T_C}
\mid\mathcal I_\tau
\right]
$$

| 記号 | 意味 | 単位 |
|---|---|---|
| $\tau$ | 情報締切 | 日時 |
| $\mathcal I_\tau$ | 情報締切までに利用できた証拠の集合 | — |
| $q_\tau$ | 到達事象の実世界確率 | 0から1 |
| $V^{\mathrm{eq}}_{T_C}$ | 到達時点における会社全体の理論株主価値 | 円 |
| $M_{\tau,T_C}$ | 時間価値、事業化後リスク、市場の価格づけを現在価値へ写す係数 | 無次元 |
| $P_\tau$ | 到達した場合の、現在時点の条件付き理論時価総額 | 円 |
| $\mathrm{SPS}_\tau$ | 到達前失敗も含めた現在時点の期待時価総額 | 円 |

$P_\tau$はBZSFの持分価値ではない。

会社全体の株主価値であり、投資額、取得持分、契約条件はSPSの下流にあるBZSFポートフォリオ層で扱う。

社会的な要素をSPSへ入れる経路は、次の三つに限る。

1. 売上、補助、公共調達、規制、費用へ影響するなら、将来キャッシュフローを通じて$V^{\mathrm{eq}}_{T_C}$へ入れる。
2. 工程の成功、所要時間、資金接続へ影響するなら、$T_C$、$T_Y$、$q_\tau$へ入れる。
3. 投資家の保有選好、要求収益率、評価倍率へ影響するなら、$M_{\tau,T_C}$または市場倍率へ入れる。

社会的便益が大きいという説明だけでは数値を動かさない。

三経路のどれかを支える観測または事前に固定した推定規則が必要である。

## 3. 共通の抽出規律

| 項目 | 規則 |
|---|---|
| 証拠の優先順位 | 約定・取引・入出金の実績、締結済み契約、確定文書、構造化DB、議事録、構造化ヒアリング、参照クラス補完、単純仮定の順 |
| 情報締切 | 各値に$\tau$を付け、締切後に得た結果で過去入力を上書きしない |
| 時刻 | 事象が起きた時刻と、AMD OSが利用可能になった時刻を分ける |
| 根拠状態 | `observed`、`document`、`hearing`、`proxy`、`imputed`、`missing`を区別する |
| 推測値 | 同じPJ類型の参照クラス中央値など、事前に書ける機械的規則がある場合だけ置く。規則も母集団も無ければ欠測にする |
| 幅 | 一点だけでなく、最短・最頻・悲観、または下位・中央値・上位を保存する |
| 版 | 値、構造、抽出規則のいずれかが変わったら旧版を残して追記する |
| 二重計上 | 一つの証拠について主反映先を一つ決める。別経路にも効く場合は因果経路と重複除外を明記する |

## 4. 測定版と到達境界

| パラメータ | 定義・単位 | 一次ソース | 抽出手順 | 欠測時と更新契機 |
|---|---|---|---|---|
| $\tau$ | 情報締切・日時 | 測定実行記録 | 計算が読んだ最後の証拠日時を固定する | 必須。新しい証拠を採用したら新しい版を作る |
| $v$ | 事業計画版 | 承認済み事業計画、取締役会資料 | 計画名、承認日、対象期間、前版との差を記録する | 版を特定できなければ計算しない |
| $\pi$ | 支援方針 | 契約、支援計画、実行記録 | 現状支援とBZSF支援案を別シナリオとして固定する | 口約束は`hearing`。支援内容変更時に更新する |
| $e$ | 外部環境 | 法令、制度、公募、価格、市況の時点固定資料 | PJが制御できない条件を列挙し、適用地域と有効期間を付ける | 出所不明の追い風は入れない。制度変更時に更新する |
| $G_{\mathrm{self}}(12\mathrm m)$ | 共通到達目標 | 理論正本 | 反復可能な外部対価で12か月の通常運営と既存債務をまかなえる境界を採用する | 定義変更は全PJを再計算する理論改訂 |
| $X_v^*$ | 計画版の到達境界 | 事業計画、契約、技術・供給要件 | 共通目標を満たすために必要な技術、製造、顧客、権利、収支条件を列挙する | 不明条件は欠測。条件追加・削除時に$q$と$P$を同時点検する |
| $R_{\mathrm{rep}}$ | 12か月の反復可能な外部対価・円 | 契約、請求、入金、継続実績 | 一回金を除き、契約または12か月実績がある収入を月別に積む | 根拠のない売上見込みは含めない。契約・解約・単価変更時に更新する |
| $E_{\mathrm{req}}$ | 12か月の必要支出・円 | 支出実績、雇用契約、債務、設備維持計画 | 現在の活動水準を維持する費用、債務履行、必要更新投資を月別に積む | 開発停止による縮小を成功扱いしない。固定費・債務変更時に更新する |
| $C_{0,G}$ | 到達判定時点の利用可能資金・円 | 残高、交付決定、締結済み入金契約 | 現金と受取が確定した未入金だけを月別入金日に置く | 未契約調達を入れない。残高・交付・契約変更時に更新する |

## 5. 到達見込み$q$の入力

| パラメータ | 定義・単位 | 一次ソース | 抽出手順 | 欠測時と更新契機 |
|---|---|---|---|---|
| $X_\tau$ | 情報締切時点のPJ状態 | 完了証跡、契約、試験結果、DB | 各到達条件を完了・未完・失効・不明へ符号化する | 不明は未完と同一視しない。証跡追加時に更新する |
| $\mathbf Z_\tau$ | 複数工程へ作用する共通状態 | 制度文書、契約、議事録、記録 | 状態名、観測根拠、影響する工程・時間・資金を登録する | 独立加点しない。影響先が特定できなければ説明変数のままにする |
| $\mathcal G_v=(N,E)$ | 工程の依存グラフ | 事業計画、工程表、構造化ヒアリング | 各工程について、何と並行し、何の後に来るかを明示して有向辺を引く | グラフが閉じるまで$q$を計算しない。計画順序変更時に更新する |
| $s_i$ | 工程$i$の現在状態 | 完了証跡、試験、契約 | 未着手・進行中・完了・失敗・失効を証拠で判定する | CEOの自己申告だけで完了にしない。新証跡時に更新する |
| $p_i$ | 親工程まで成立した条件付き成功確率 | 参照クラス、観測頻度、構造化複数評価者判断 | 条件と母集団を先に固定し、頻度または評価者分布から推定する | 単独の感覚値は`hearing`。校正資料が無ければ幅を広くするか欠測にする |
| $(a_i,m_i,b_i)$ | 工程$i$の最短・最頻・悲観所要時間・月 | 実績工程表、会議資料、担当者ヒアリング | 並行・直列関係を確認した後、三点を取得してPERT入力へする | 同型工程の参照クラスがあれば補完。無ければ欠測にする |
| $F_i$ | 工程$i$失敗時の停止・迂回・縮小先 | 代替計画、契約、構造化ヒアリング | 失敗が何を止め、何を残すかを工程単位で有向分岐にする | 影響範囲不明なら単純積で全停止にしない |
| $R_i$ | 再試行回数、費用、時間、成功率 | 試験計画、実績、見積 | 再試行の上限と各回の追加時間・費用・条件付き成功率を登録する | 無限再試行を許さない。試験結果時に更新する |
| $C_j$ | フェーズ$j$開始時の利用可能資金・円 | 残高、交付決定、締結済み契約 | 現金と受取確定額を入金時期つきで積む | 累積調達額を使わない。入出金・契約変更時に更新する |
| $b_j$ | フェーズ$j$の月次純燃焼・円/月 | 月次実績、採用計画、設備・外注契約 | 月次支出から反復収入を引き、最小・最頻・最大を作る | 実績不足なら同じ活動計画のボトムアップ見積り。根拠タグを`assumption`にする |
| $L_j$ | 条件付き資金流入・円と時期 | 投資契約、融資、補助金、公募計画 | 確定入金と未確定調達を分け、未確定分は独立の成立ノードにする | 未契約額を$C_j$へ直入れしない。条件変更時に更新する |
| $T_Y^{\mathrm{資金}}$ | 資金切れまでの時間・月 | $C_j$、$b_j$、$L_j$ | 経路ごとに月次残高を更新し、初めて負になる時点を取る | 現行実装の主要な余力時計。資金計画更新時に再計算する |
| $T_Y^{\mathrm{非資金}}$ | 顧客信用、チーム、知財、代替選択肢の余力・月 | 契約期限、退任日、権利期限など | 月数へ変換できる確定イベントだけ時計にする | 再現可能な時刻変換が無いものは欠測のままにする |
| $K_\ell$ | キラー要素$\ell$の発生状態 | SHA、定款、取締役会記録、契約、外部記録 | カタログに照らし、記録・文書で発生を判定し、影響工程を聞き直す | CEO本人の自己申告は発生証拠にしない。発生時に新しい測定版を作る |
| $T_C$ | 共通到達目標への初回到達時間・月 | 工程グラフの計算結果 | 依存、並列、失敗、再試行を含む共同経路ごとに初回到達時刻を取る | 入力欠測のまま一点値を作らない |
| $T_Y$ | 戦略余力の初回喪失時間・月 | 資金時計と実装済み非資金時計 | 各経路で最初に発生した余力喪失時刻を取る | 未実装成分を0か無限へ置き換えず、部分実装と表示する |
| $q_\tau$ | 到達事象の確率・0から1 | 共同シミュレーション結果 | 事前登録した経路を反復生成し、$A_v$を満たす割合と区間を出す | 依存グラフ、主要時間、資金時計が欠ければ数値を出さない |

## 6. 条件付き理論時価総額$P$の入力

| パラメータ | 定義・単位 | 一次ソース | 抽出手順 | 欠測時と更新契機 |
|---|---|---|---|---|
| $d_0$ | 評価基準日 | 測定版 | 情報締切$\tau$と同日を原則とし、通貨と物価基準年を固定する | 必須。評価日が変われば新しい版を作る |
| $c$ | 表示通貨 | 会計通貨、比較目的 | 原則JPYとし、外貨は評価日時点の出所つき為替で換算する | 為替出所が無ければ外貨値を併記し、円換算を欠測にする |
| $S$ | 事業・顧客セグメント集合 | 事業計画、契約、市場資料 | 製品、顧客、地域、収益モデルが異なる単位に分ける | TAMだけで売上を置かない。事業モデル変更時に更新する |
| $u_{s,t}$ | セグメント$s$の単価・円 | 契約、見積、実取引、比較価格 | 実績、契約、顧客見積、外部比較の順で採用し、値引き条件を反映する | 根拠が無ければ参照クラス幅を使い`imputed`表示する |
| $n_{s,t}$ | 販売数量・件数 | 受注、設備能力、顧客計画 | 顧客数×採用率×一社当たり数量と、供給能力の小さい方を使う | TAM比率だけの数量は採用しない。受注・能力変更時に更新する |
| $\rho_{s,t}$ | 継続・反復率 | 更新実績、契約期間、解約率 | コホート実績を優先し、無ければ類似契約の参照クラスを使う | 単発売上は反復率0として分離する |
| $R_t$ | 売上・円 | $u_{s,t}$、$n_{s,t}$、$\rho_{s,t}$ | セグメント別に単価×数量×反復を計算して合算する | 直接売上計画がある場合も三要素へ分解して整合確認する |
| $\mathrm{COGS}_t$ | 売上原価・円 | 原価実績、BOM、製造見積 | 変動費と製造固定費を分け、数量・歩留まり・稼働率へ接続する | 業界粗利率補完は`imputed`として幅を持たせる |
| $\mathrm{OPEX}_t$ | 販管費・研究開発費・円 | 月次数値計画、雇用・外注契約 | 人員、外注、拠点、販売、維持R&Dをボトムアップで積む | 成長停止を前提に過小化しない。計画・契約変更時に更新する |
| $\mathrm{CAPEX}_t$ | 設備投資・円 | 設備見積、建設計画、契約 | 能力増設、更新、立上げ費用を支払時期へ置く | 見積幅を保存し、補助金は別行で相殺する |
| $\Delta\mathrm{NWC}_t$ | 運転資本増減・円 | 回収・支払条件、在庫計画 | 売掛、買掛、在庫の回転日数から計算する | 回転日数不明なら同業参照クラスを`imputed`で使う |
| $\mathrm{Tax}_t$ | 税金・円 | 税率、繰越欠損、法人所在地 | 課税所得、実効税率、欠損金使用限度を反映する | 税務条件が未確定なら幅を置く |
| $\mathrm{FCFF}_t$ / $\mathrm{FCFE}_t$ | 企業または株主への自由キャッシュフロー・円 | 上記財務入力 | 採用したDCF方式に合わせ、同じ方式を全期間で使う | FCFFとFCFEを混在させない |
| $\Omega$、$w_\omega$ | 事業化後シナリオと条件付き確率 | 実績、参照クラス、構造化評価 | 到達後の需要、価格、原価、競争をシナリオ化し、条件付き確率を付ける | 到達前失敗を再び入れない。確率根拠が無ければ等確率にせず欠測にする |
| $g$ または $m_{\mathrm{exit}}$ | 継続成長率または出口倍率 | 長期経済前提、上場比較、M&A取引 | 永続成長法か倍率法のどちらかを主方式にし、もう一方で感度確認する | 高成長を永続させない。比較会社集合変更時に更新する |
| $\mathrm{TV}_N$ | 明示予測期間後の残存価値・円 | $g$または$m_{\mathrm{exit}}$ | 明示期間末の正常化利益またはCFから計算する | 総価値に占める比率が大きい場合は感度を必須表示する |
| $V^{\mathrm{EV}}_{T_C}$ | 到達時点の理論事業価値・円 | 条件付きDCFまたは比較倍率 | 事業化後CFと残存価値を到達時点へ割り引く | 市場倍率を使う場合は比較集合と調整を保存する |
| $\mathrm{Cash}_{T_C}$ | 到達時点の余剰現金・円 | 経路別資金繰り | 事業運営に必要な現金を除く余剰分だけを加える | 現在現金をそのまま加えない |
| $\mathrm{Debt}_{T_C}$ | 到達時点の有利子負債・円 | 借入契約、返済表 | 元本、未払利息、転換条件を到達経路ごとに積む | 転換社債は転換・返済シナリオを分ける |
| $\mathrm{Senior}_{T_C}$ | 優先請求・希薄化調整・円 | 投資契約、優先株条件、SO、転換証券 | 清算優先、参加条項、潜在株式を会社全体株主価値の橋渡しに反映する | BZSF固有持分は入れない。資本政策変更時に更新する |
| $V^{\mathrm{eq}}_{T_C}$ | 到達時点の会社全体株主価値・円 | 事業価値と資本構成 | 事業価値に余剰現金を加え、負債と優先請求を控除する | 企業価値と時価総額を混同しない |
| $M_{\tau,T_C}$ | 現在価値への市場価格づけ係数 | 無リスク金利、比較企業収益率、資金調達・取引価格 | 時間価値、到達後リスク、投資家需要を、DCF割引率または市場倍率として推定する | 到達前失敗リスクを再投入しない。根拠のない社会プレミアムは置かない |
| $D_{\mathrm{soc}}$ | 社会要素の価格反映証拠 | 公共調達、補助、規制、顧客支払意思、資金調達価格、投資家需要 | 各社会要素を$q$、CF、$M$のどこへ効かせるか一つずつ記録し、反実仮想との差を推定する | 経路が確認できなければ説明変数として保存し、Pへ独立加点しない |
| $P_\tau$ | 到達時条件付き理論時価総額・円 | 上記入力の計算結果 | 到達経路だけを取り出し、$M_{\tau,T_C}V^{\mathrm{eq}}_{T_C}$の条件付き平均と分布を出す | 金額の核となる売上・費用・割引入力が欠ければ数値を出さない |

## 7. 派生出力と表示

| 出力 | 算出 | 必須表示 |
|---|---|---|
| $T_C$分布 | 成功・失敗を含む共同経路から初回到達時刻を集計 | 中央値、下位・上位点、到達経路数 |
| $T_Y$分布 | 各経路の最初の余力喪失時刻を集計 | 実装成分、欠測成分、中央値、下位・上位点 |
| $q_\tau$ | $A_v$を満たす経路数を総経路数で割る | 一点、計算上の区間、前向き検証件数、主要死因 |
| $P_\tau$ | 到達経路の現在価値つき株主価値を条件付き集計 | 円、中央値と幅、評価日、通貨、DCF方式、代理・補完率 |
| $\mathrm{SPS}_\tau$ | $q_\tau P_\tau$ | 円、$q$と$P$の代入値、両者の版、二重計上点検 |
| 感度 | 主要入力を一つずつ所定幅で変更 | $q$、$P$、SPSへの変化を分けて表示 |
| 版差 | 旧版と新版の差分分解 | PJ状態、証拠、計画、構造、抽出規則のどれが変わったか |

## 8. 最小保存単位

一つのパラメータ観測は、少なくとも次を持つ。

| フィールド | 内容 |
|---|---|
| `parameter_key` | 変数の一意なキー |
| `symbol` | 画面でLaTeX表示する記号 |
| `value_json` | 値、一点または分布、通貨、単位 |
| `value_status` | 観測、計算、推定、部分実装、欠測 |
| `evidence_kind` | 計算、文書、記録、ヒアリング、仮定、複合 |
| `evidence_ref` | 出所の識別子と該当箇所 |
| `information_cutoff` | 情報締切 |
| `extraction_rule_version` | 抽出規則の版 |
| `affects` | 反映先 |
| `condition_json` | 条件、参照クラス、反実仮想、補完規則 |
| `note` | 限界、反対証拠、二重計上点検 |

この台帳の行を埋めたことと、予測が当たることは別である。

前向き検証は現在0件であり、SXの$q$もLSTの事前登録も、校正済みの投資判断モデルではない。

## 9. 理論上の参照点

- 将来キャッシュフローの金額・時期が不確実なときに確率加重した現在価値を使う考え方は、[FASB Concepts Statement No. 7](https://storage.fasb.org/Concepts_Statement_7_As_Amended.pdf)を参照した。ただし、本台帳の共通到達事象と二重計上防止はBZM固有の設計である。
- 投資家の環境・社会選好が資産価格へ影響しうるという仮説の参照点は、[Pástor, Stambaugh and Taylor, NBER Working Paper 26549](https://www.nber.org/papers/w26549)である。ただし、個別PJの外部便益が自動的に株価へ資本化されることを示す証拠ではない。
