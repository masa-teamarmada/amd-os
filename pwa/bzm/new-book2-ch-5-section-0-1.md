# §5.0.1 対照的な二領域 — 章頭問いと政策密度 P の段階的上昇

> 規律: D-031 Tier A (校正 / illustrative / 強い事前分布下の事後分布要約), D-033 (validation 主張は Ch 11 前向き予測登録簿照合経由のみ), D-034 機関匿名化 type 名運用 (PJ 名 CX/YD は実名 OK), D-045 K=3 pre-commit, D-048 Nelson-Winter 圧縮 (本格展開は Book 0 Ch 0.3 へ逆流), 専門用語日本語化方針 (L1 §10) 適用。

本章は、一枚の図を読者の前に並べて置くところから始めたい。横軸を 2020Q4 から 2023Q4 まで取り、縦軸に四半期ごとの政策密度 P_t、産業投資 B_t、ベンチャー資金 V_t、そして三者を Cobb-Douglas 合成で縮約した σ_SU(t) を載せたパネルを、CX (= カーボンニュートラル / GX 系領域) と YD (= 養殖 / フード系領域) の二領域について並置する (図 5.0.1、4 panel: P / B / V / σ_SU 合成、type 匿名化)。両者は同じ歴史時刻を共有し、同じマクロ環境 — コロナ後の財政膨張、円安、半導体不足 — のもとに置かれていた。にもかかわらず、片方の領域では三本の線がほぼ同位相で立ち上がり、σ_SU が本書で後付け校正の対象とする 8 PJ のなかで観測史上最高水準 (= 本書サンプルが切る四半期断面のなかで、これより上の値が観測されていないという意味での最高、母集団全体に対する主張ではない) まで押し上げられる。もう片方では、同じ時刻に P_t が低位で水平に張り付き、B_t と V_t もそれに引きずられるかたちで σ_SU が床近傍を這う。ここで σ_SU(t) とは、ひとことで言えば「学術 (μ_A)・産業 (μ_I)・政府 (μ_G) の三軸を一本のスカラーに縮約した三レーン合成指標」であり、Triple Helix (= 学術・産業・政府の三レーンが相互に絡みながら一つの技術領域を立ち上げる構造) が同位相で動いているかどうかを四半期単位で量化した量である。同じ歴史時刻が異なる領域では異なる選抜圧として観測される — これが本章を貫く章頭問いである。観察者の語彙で言い換えるなら、歴史時刻はスカラーではなくベクトル場であり、領域ごとにその場の強度が違う、ということになる。

この非対称はどこから来るのか。目を凝らしてみると、CX 系領域の P_t が階段状に跳ね上がる最初の踏み段は、2020 年 10 月 26 日の所信表明演説における「2050 年カーボンニュートラル」宣言 (菅 2020) に同定される。ここでいう政策密度 P_t とは、すなわち「政府レーンが当該領域に向けて投入している圧力強度を四半期単位で量化したスカラー」であり、本書では Atlas signals CX 領域 P/N/R 速報値 (AMD OS TripleHelixMatrix.tsx 集計) に依拠して計上する。CN 宣言以降の四半期階段プロット (図 5.0.2) を辿ると、P_t は連続的に滑らかに上がるのではなく、CN 宣言 (2020Q4) の即時反映、GX 移行債の制度設計確定 (2022Q4–2023Q1)、GX-ETS 段階導入決定 (2023Q2)、SIP 第 3 期 CE 課題立ち上げ (2023Q2–2023Q4) という四つの離散イベントに対応して、明確に段差をつけて持ち上がっていく。ひとことで言えば、CX 領域の政府レーン圧力は連続的に滲み出したのではなく、政治判断の節目ごとに一段ずつ持ち上げられた。同じ窓を YD 系領域について引き直しても、これに匹敵する踏み段は観測されない。言い換えれば、σ_SU を構成する三成分のうち μ_G (= 政府レーンの平均成長率指標、§5.2 で構成法を与える) の入力である P 成分が、外生的政治ショック — つまり領域内部のミクロ動学からは説明されない、上空から落ちてきた離散的イベント — によって離散ジャンプを起こした、という記述的事実が CX 側にだけ刻まれている。

ここで一度立ち止まりたい。この段階性 — 滑らかに上がるのではなく踏み段ごとに体制が切り替わる挙動 — は、連続時間拡散モデル (= 伊藤過程や Ornstein-Uhlenbeck 型平均回帰過程のように、Brown 運動を駆動項とする滑らかな時間発展モデル) を素朴に当てはめる枠組みでは捉えにくい。連続拡散は局所的に滑らかな経路を前提とするが、CN 宣言型のジャンプは経路の左右で μ_G の生成過程そのものが切り替わる構造的不連続であり、平滑な拡散項の分散変化だけにこれを押し込めるのは不自然である。むしろレジーム (= 構造的状況) が確率的に切り替わると考えたほうが、データに対する記述として素直である。加えてこの段階性は、CX 系と YD 系で異なる時刻に異なる回数現れるため、領域横断的な単一拡散モデルでは二領域の非対称を表現しきれない。両者を合わせて読めば、§5.3 で導入する MS-SSM (= マルコフ切換え状態空間モデル = レジームが確率的に切り替わる時系列モデル、K=3 の S₀ stuck / S₁ 中位 / S₂ 三位一体追い風 を pre-commit する、D-045) の必要性は、理論的天下りではなく本サブセクションの観察そのものから要請される、と言える。経済史的観点からは、政策宣言 P と公募予算 B の同位相加速、および両者間のラグが従来推定の 8–12 四半期から 4–6 四半期へと縮減した経緯は、戦後日本の産業政策史のなかでも稀少な事例に属し (Atlas signals 速報、AMD OS TripleHelixMatrix.tsx 集計)、後続の §5.6 横断後付け校正および Ch 11 の K∈{2,3,4} horse-race の核心的素材となる。

最後に、本サブセクションの叙述地位を Tier A 規律 (D-031) に従って自己宣言しておく。ここで提示した CX vs YD の対比、CN 宣言を起点とする P_t の四半期階段、ラグ縮減の経済史的稀少性は、いずれも「強い事前分布下の事後分布要約」および「本書 8 PJ 後付け校正に基づく illustrative な記述」として読まれるべきであり、識別された因果効果の主張ではない。validation の語は本書を通じて Ch 11 の前向き予測登録簿照合 (D-033) に限定して用い、本章本文中では用いない。この規律自己宣言を読者と共有したうえで、続く §5.0.2 では σ_SU を構成する Cobb-Douglas 合成、§5.0.3 では二層非可換性 (σ_SU と Problem-fit P の結合、本格展開は Ch 9)、§5.0.4 では本章全体の地図と Nelson-Winter 圧縮 (D-048) を順に展開する。図 5.0.1 と図 5.0.2 が読者に手渡しているのは、因果ではなくレジーム切換えという記述形式そのものへの招待状である。
