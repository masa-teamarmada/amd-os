## 3. 理論整合の解き方 (最重要論点)

### 3.1 問題

Ch1 の中心命題:「勝負の大半は設立前に決まる。なのにその時間に、主体として入り、**通しで見届けて責任を負う席が制度側に無い** (柏木の偶然は再現しない)」。柏木が全章に登場し通しで見届けてしまうと、「再現しないはずの偶然が再現している」ように見え、この釘と自己矛盾しかねない。

### 3.2 解 — 「見届け」と「席」の分離。柏木の九年は、釘の反証ではなく釘の証明

Ch1 1.2 の釘を精読すると、核心は二つの語の**分離**にある — 「通しで**見届け**、その**責任を負う席**が、制度の側に用意されていない」。見届け (観測) と責任 (決定の主体) は別のものであり、制度に無いのは後者を含んだ席である。ここから解が立つ:

1. **柏木は、偶然の見届け人 (Ch1) から、意思で通しの見届けを試みる人へ変わる**。祝賀会の晩に喉の奥で鳴った小さな骨 — あの晩から柏木は、誰に頼まれたのでもなく、案件の節目に顔を出し、覚えている人になる。偶然を意思で引き継ぐ。
2. **しかし柏木は、毎章、見ているのに決められない**。配分を決めるのは戸倉、審査で問うのは委員、出さないと言うのは灘、保留するのは楢原。柏木が隣にいても、当事者たちは一人で決め続ける。見届けは席ではないからである。個人の意思は (i) 決定に関与できず (ii) 全部には届かず (機関の網の外 = Ch7、機関の外の当事者 = Ch14) (iii) 柏木がいなくなれば消える。
3. **この限界の堆積が、最終幕の CEO 章への長弓になる**。三幕を通じて、機関は柏木の属人的な記憶に頼るようになっていく (「柏木さんに聞けば分かる」) — 便利だが、それは席ではない。属人化した記憶で回っている状態こそが、制度の不在のいちばん静かな可視化である。CEO 章の「一気通貫の経営機能供給」は、柏木が個人で試みて埋めきれなかったもの — 観測と責任を一つの席に束ねる制度解 — として立つ。
4. **柏木は最後まで、言葉を作る側にならない**。Ch16 の発表者は志野のまま (STORY_WORLD 決定B 維持)。柏木が壇上に立ってしまうと「個人の努力で解決できた」ことになり、釘が折れる。柏木は会場で、九年の見届けの終わりに、批判を全部認めた発表へ拍手する — Ch1 の幕「柏木の手も、半拍だけおくれて、そこに加わった」の対として、**今度は、遅れない**。

この整理では Ch1 1.2 の理論本文は**無改修で整合**する。むしろ柏木の九年の弧そのものが、16話かけて釘を証明する装置になる — 理論と乖離するどころか、理論の背骨と癒着する。

### 3.3 一行定義の改訂 (二重らせん)

現行「言葉を持たない伴走者が、言葉を作る側になるまでの物語」は、志野のアーク (Ch2 →Ch16 発表者) として物理化済みで、これは壊さない。柏木の弧を主軸に重ねて二重らせんにする:

> **一つの機関の九年を、意思だけで通しに見届けようとした男の物語。個人の意思の限界が露わになるほど「席」の必要が立ち上がり、その傍らで、言葉を作る側になる伴走者が育つ。**

柏木 = 見届けの弧 (物語の主人公・読者の同伴者)、志野 = 言葉の弧 (理論の目的の物理化)。二本は Ch16 の同じ会場で交差して閉じる。

## 4. 視点設計 — 三案比較

### 案1 (推奨)「通しの見届け」— 主人公 = 柏木、視点は章ごと、柏木は基本毎章登場

**設計**: 物語の主人公は柏木。各章の視点人物は現行割当を維持し (志野・戸倉・瀬戸・楢原・灘・本部長・当事者)、柏木は**毎章、意味を持って現れる** — ただし顔見せではなく、§3.2 の「見届けの運動」の一コマとして。三層で現れる:

- **主役回** (柏木視点): Ch1 / Ch11 / Ch16 (会場・幕の拍手)
- **判断の場への陪席・同席**: Ch3 (配分会議の壁際) / Ch6 (審査会場の事務局側) / Ch9 (四半期レビュー) / Ch13 (円卓の機関側同席) / Ch15 (稟議の周辺)
- **廊下・道すがらの点景**: Ch2 (施設のロビー) / Ch4 (夜の本部) / Ch5 (試験棟への随行) / Ch8 (本部の隣の島) / Ch12 (本部長が学長室へ呼ばれる前後の本部)
- **不在の章** (見届けの届かない場所): Ch7 (機関の網の外) / Ch14 (機関の外の当事者)。Ch10 は選択制 (§6)

**視点は当事者、同伴者は柏木**: 各章の内面 (戸倉の四件の記憶、灘の夜の計算、楢原の保留) は当事者視点でしか書けない — Ch2 v4 の強度はここから来ており、白紙で考え直してもこれを捨てる理由がない。柏木は読者が章をまたいで「また、いる」と見つける存在になる。読者は当事者の目で判断の痛みをくぐり、柏木と一緒に機関の九年を歩く。

**三幕での柏木の弧**:
- 第一幕 (Ch1〜3): 骨が鳴る → 通い始める。なぜ通うのか、本人もまだ言葉にできない (問いを認識する人物を安易に置かない、の原則に整合 — 柏木の違和感は言語化させない)
- 第二幕 (Ch4〜10): 見届けが増え、限界も形を持ち始める。届かない場所 (Ch7) と、隣にいたのに気づけなかった夜 (Ch10・選択制)
- 第三幕 (Ch11〜16): 他機関で初めて自機関が外から見える (Ch11 主役回)。機関が柏木の記憶に頼り始める (属人化 = 制度不在の裏返し)。Ch16、志野の発表に、遅れない拍手

**理論整合**: §3 の解がそのまま実装される。Ch1 の釘は無改修。CEO 章への長弓が「柏木の九年の限界」という物語の実体を得る。

**現実考証**: 柏木の職掌 = 産学連携本部の古参 URA。URA の実務は案件横断の伴走・会議体への陪席・公募説明会や展示会への随行・企業面談の同席を普通に含み、「機関に一人いる、全部の案件に顔を出す古参」は現実の産学連携本部にいる実在型である。個別の検算: 配分会議 (本部の会議・陪席自然 ✓) / プログラムの施設 (本部 URA の出入り自然、ただし面談室の中の助言構造には混ぜない ✓) / 最終審査会 (機関内オブザーバー ✓) / 企業面談・装置見学 (本部同僚 ✓) / 学長室 (職位が違う — 入れない。前後の本部場面で ✓) / 機関の網の外のチーム (立ち会う理由が無い — **不在が制度的に正しい**) / 雪の源泉 (技術窓口 = 灘の職掌。柏木が谷まで行く理由は薄い — 現地不在が正)。つまり「基本毎章、ただし制度的に居られない場所には居ない」— 不在の章そのものが「個人の見届けは全部には届かない」の証明として意味を持つ。

**既存章影響**: §6 参照。承認済み本文への追加は最大でも数文/章、Ch2 v4 は1箇所以内 (または無改修)。

### 案2 (対抗)「全章柏木視点」— 完全通しドラマ

**設計**: 全16話を柏木の視点で貫く。「ひとつの通しのドラマ」の最も文字通りの実装。

**評価**: 三つの壁がある。
1. **現実考証の壁**: Ch7 (機関の網に掛かっていないチームの週末の研究室) と Ch14 (機関外の当事者の内面章) は、柏木が居る理由を作れない — 章の器ごと再設計になる。Ch12 (学長室)・Ch10 (雪の谷) も居られない。「基本全ストーリー」の物理的な網羅は、URA という現実の職掌では作れず、作ろうとすると考証ゲートに落ちる設定 (万能の随行者) を要求する。
2. **物語の質の壁**: 当事者の内面が全部伝聞・観察に変わる。灘の夜の計算の孤独 (Ch10)、楢原の下書きフォルダ (Ch8)、志野の「いちばん現実的な答え」(Ch2) は、当事者の内側からしか書けない。さらに「見ているだけで決められない男」の受動が16話反復する — 通し設計の出発点だった俯瞰診断 (8話ぜんぶが「支援者がかすかな違和感を覚え、言葉にできないまま幕」の同型) と同じ病を、今度は一人の人物で再生産する。
3. **資産の壁**: Ch2 v4 (まさ「何も文句なし」) を含む承認済み5章の全面書き直し + Ch6 の無人称設計 (16話で唯一・意図した設計) の喪失。

**採る条件**: まさの「通しのドラマ」が「カメラを一人に固定すること」まで含むなら、この案が正解になる。その場合、Ch7/Ch14 は章の器の再設計 (柏木が接点を持てる器への差し替え) までセットで動かす必要がある — 影響は理論側 (章頭が撃つ命題の器) に及ぶ。

### 案3 (対抗・現行降格)「現行維持 + 柏木の露出密度だけ増やす」

**設計**: 設計思想 (各話の主役は別人・視点交代の群像劇) はそのまま、柏木の点景を各章に足す。

**評価**: 改修コスト最小 (本文に数文ずつ、正本の思想は不変)。だが「主人公」は生まれない — 挿入は「同じ世界の証拠」(顔見せ) にとどまり、Ch1 の骨から Ch16 の拍手へ向かう弧の上に乗らない。まさの「基本全ストーリーの中心は柏木」「ひとつの通しのドラマ」は設計思想の変更を求めており、露出の増量はそれに応えない。**現行温存への帰着の型であり、推奨しない** — コスト比較のために明示的に並べる。

## 5. Ch16 の到達点との接続

現行「発表者 = 志野が到達点、柏木は会場」は、案1 では**二重の幕**として強化する:

- **志野の幕 (言葉の弧の到達)**: 機関の四年の実践から言葉を組み上げ、三つの批判を全部認めて会場を出る — 現行設計のまま不変。
- **柏木の幕 (見届けの弧の円環)**: Ch1 の幕「柏木の手も、半拍だけおくれて、そこに加わった」に対し、Ch16 の拍手は**遅れない**。祝われて閉じた第1話の会場では、違和感だけが半拍の遅れになった。疑われて閉じる最終話の会場では、批判を全部認めた言葉に、ためらいなく手が鳴る。九年の弧が拍手二つで閉じる。
- 発表者を柏木に変えない理由は §3.2-4 のとおり — 柏木が言葉の側へ渡ってしまうと「個人で解決できた」ことになり、席の不在という釘が折れる。志野という次の世代が言葉を作り、柏木は見届けの人のまま円環を閉じることが、理論の帰結として誠実である。

## 9. 骨抜き防止セルフチェック (自己申告)

- **現行温存への帰着になっていないか**: 本構想は現行設計の核 (「各話の主役は別人」= 視点交代の群像劇) を**廃止**し、主従を逆転する (主人公 = 柏木、各話の視点人物は相手役)。「視点が章ごとに回る」という物理は現行と連続するが、これは白紙で考え直しても当事者の内面 (Ch2 の志野、Ch10 の灘) を捨てる理由がないことの帰結であり、その判断根拠を §4 案2 の評価に明示した。現行そのもの (思想不変の露出増) は案3 として降格・非推奨を明記した。
- **釘を固定して帰着していないか**: Ch1 1.2 の釘は「固定したから現行に戻る」向きには使っていない — 逆に、柏木中心化と釘が両立する解 (§3) を先に立て、釘が本改訂を止めないことを確認した。仮に案2 を採る場合の理論側影響 (Ch7/Ch14 の器の再設計) も明示し、まさがコスト込みで選べる形にした。
- **承認済み本文の価値の扱い**: Ch2 v4 は全捨てせず、挿入 (a) / 無改修 (b) の両論を判断ポイントに上げた。承認済み章への追加は最大数文/章に抑え、一括の編み込みパスでまさが全文面を見てから反映する。
