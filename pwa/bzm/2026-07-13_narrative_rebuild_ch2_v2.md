## 0. 中心命題 (§8 v2 台帳、まさ確定済み)

> Before Zero の大きな判断 (開示・設立・CEO) はどれも「**いつやるか**」の問題で、早すぎても遅すぎても取り返しがつかない。では「いつ」を**誰の時計で**決めるのか — 関係者の時計を読めるようになり、進む/待つ/止めるを自分の語彙で言えるようになる

現行ナラティブ (および v1) がズレていた点: 現行場面の意味の重心は「開示の不可逆性を、興奮の外の目が止める」= 理論 2.4 の挿絵に留まっており、命題の重心「**いつを、誰の時計で決めるのか**」(2.3 時計の地図・2.6 判断語彙) を撃っていない。場面に出てくる時計は「月初の検討会」一つだけで、六者の時計の構造が物語に不在。

## 1. 白紙検討の過程 (棄却案とその理由)

| 案 | 骨子 | 棄却理由 |
|---|---|---|
| η 一日三場面 | 早すぎた案件の報せ (朝)・遅すぎた案件の傷 (昼)・未決の十七分 (夕) を一日に並べ「早すぎても遅すぎても」を正面から見せる | 帰結の先出しが討議課題A1 (止めるべきはどちらか) の判断を誘導して殺す (Ch1 v5 で確立した原則違反)。「早すぎの帰結」は理論 2.7 の反実仮想が既に担っており重複。朝昼夕の三幕が「三」の数装置に見える (§2: 数の装置は理論由来章限定) |
| β 二案件対比 | 早すぎた案件と遅すぎた案件を対で見せてから第三の案件 (十七分) へ | ηと同じ理由 + 複数案件を並べる構図が Ch3 (三案件で三周する配分会議) と章間で被る |
| γ 桐山視点 | 月に一度しか来ない知財担当の目で、月刻みの早送りとして案件を見る | 桐山は「答えを持つ人」— 視点にすると読者が最初から安全地帯に立ち、湯浅の盲目を体験できない。**要素は意味層として吸収** (桐山 = 部屋で一番遅い時計を持つ人が、一番速い時計に最初に気づく) |
| ζ 会議 + 後日談 | 十七分 → 数年後の帰結 (Ch1 v5 と同構造) | 章構造の同型連続。かつ「その後」は理論 2.7 が回収する設計で、ナラティブが先に言うと 2.7 が死ぬ |

**帰着**: Ch2 は Ch1 と違い、理論側の釘が場面の物理骨格をほぼ完全に固定している —
- 討議課題A (不変の釘) が「**この十七分で**」「**メールと登記**」「**残る十七分で誰に何をどの順に**」を明示
- 2.2 が「章頭に登場した**四人**」を一人ずつ回収 (URA/知財担当/研究者/支援プログラム担当の台詞・行動を引用)
- 2.4 が「冒頭の場面で知財担当者が置いた**三色の印**」を Lv1〜4 に一般化、「**一文テスト**」を定義
- 2.6 が「冒頭の会議室で判断を押していたのも〜この**空気**だった」を引く
- 2.7 が「章頭で切ったまま残しておいた、あの十七分に戻る」から顛末 (送信停止・資料再構成・登記は宿題化・紙の一覧に一行) を全部語る
- 演習2-3 が「**八枚目スライド**」を再掲

白紙から立てても「**雨の六月、定例の会議室、未決の十七分**」に帰着する。Ch1 (釘が薄く場面ごと再設計できた) との違いはここ。**ゼロから考えても同じ物理骨格が最良、ただし物語の意味層と語りは全面再設計** — が v2 の結論。

## 2. v2 の設計 — 何の物語に組み替えるか

**一行定義: 「他人の時計を、自分の指で書き写していたことに、本人だけが気づかない話」。**

現行が「開示事故を止めてもらう話」なのに対し、v2 は同じ物理骨格を「いつを誰の時計で決めるのか」の物語として語り直す。

### 意味層の設計 (4つ)

1. **送信予約 = 他人の時計の書き写し**: 予約時刻の十六時は、企業の「月初の検討会」から逆算して、湯浅が今朝**自分の指で**入れたもの。「自分で決めた」ように見えて、実は他人の時計を自分の手で書き写しただけ — これが章の運動の核。幕のカーソル (自分の指で入れた予約を、自分の指で取り消すか) と正確に呼応する。
2. **「報告」と「審議」のすり替え (初読では見えない)**: 予約済み = 決定済み。湯浅にとってこの定例は報告の場であって、決める場ではなかった — 決める場を素通りする設計を、悪意なく自分でしていた。桐山の「この資料、もう送信予約に入っていますか」が刺さる本当の理由 (= まだ会議中なのに、もう決まっている)。初読では「仕事が速い」、再読で「決定が会議より先に済んでいた」に反転する。
3. **部屋じゅうの時計 (沈黙運用)**: 会議で口にされる時間語 — 「月初」(企業)、「今朝」(湯浅)、「月に一度」(桐山の定例)、「冬」(中間報告 = プログラム)、「半年後」(漏洩の発覚 = 帰結の遅延)、「年度の様式」(行政・大学)、「仲が良いうち」(紙の時計) — を全編に編む。壁の時計 (15:43→15:55) だけが機械的に進む。語り手は指差さない。再読で「この部屋は時計だらけだった。なのに議題に載った時計は一つもない」と見えてくる。通奏低音① (Ch1「まだ始まっていない時計」→ Ch2「それぞれの時計」) の受け。
4. **桐山 = 一番遅い時計の人**: 月に一度しか来ない (= 部屋で一番ゆっくりの時計で回っている) 人だけが、一番速い時計 (十七分) に気づく。彼の過去談 (半年後に知った) は「開示の帰結は遅れて届く」= 原因と結果の時間差の体現。

### 語りの統一方針との整合

- **開幕**: 物語一行目から (Ch9 型)。現行冒頭の講義接続段落 (「第1章の支援会議は〜誰の時計だったのか〜舞台を移します」) は削除。**「誰の時計だったのか」の問いは幕のあとの転調部へ移設** (機能は保存、置き場所を変えるだけ)。
- **読者誘導** (Ch1 v5 の原則の Ch2 適用 — ただし Ch1 と同型にしない): Ch1 = 完全ポジティブ→終盤で「あれ?」。Ch2 = 前半だけポジティブ (有能な若手の前進譚)、桐山の一問からは緊迫を隠さない。裏切りの層は別に用意する — 読者が「開示 (資料) の話」と思って読んでいると、「登記だけ先に」で同じ型が二度目に現れ、研究者の「誰の責任で出すんですか」で「資料の話ではなく、時計と責任の話だ」へ一段沈む。
- **問いを認識している人物を置かない**: 湯浅は最後まで「月初に間に合うか」しか考えない。「間に合わない、は誰の時計の上の言葉か」の問いは、本文では言語化せず読者と討議課題に渡す。現行 2.0 にある湯浅の自問 (「いまこの瞬間、この八枚を出す責任は、誰が負っているのか」) は**削除** — 研究者の問いの直後、画面をメールに切り替えると差出人欄に自分の名前がある、という絵だけで因果を通す。
- **「一瞬・間」系**: 場面内 1回まで。比喩の章間使い回しなし (「部屋」「物差し」不使用)。
- **字数**: 2,600〜3,400 (PF-018)。現行系 (v1 約3,900字) から地の文を約 1,000 字絞る。台詞「」は全件不変のまま。
- **現実考証**: 三色の印 = 情報管理実務の TLP (トラフィックライト・プロトコル) の物理版として実在整合 / 送信予約を定例中の時刻に置く行動 = 実務で頻出 (定例を通過儀礼化する設計) / 共同研究先装置のデータは相手方同意が要る = 契約実務と整合。

### あらすじ (場面は一つ、順行)

1. 開幕: 六月の雨の木曜、月に一度の定例。湯浅がメールを壁に映す — 報告として。先週の面談の手応え、「月初に、新規テーマの検討会があります。間に合えば、載せてみますよ」— 企業の口から出た初めての日付。今朝、その日付から逆算して十六時ちょうどの送信予約を自分の指で入れた (ここまで完全ポジティブ、語り手のヒントゼロ)。
2. 桐山の一問「この資料、もう送信予約に入っていますか」。壁の時計 15:43。十七分。
3. 八枚目 → 紙に出す → 三色のシール。一枚の資料の中に「出せる言葉とまだ出せない言葉」が混じっていたことが、色で初めて誰の目にも見える。一文テスト「これは、相手が言ったことですか。それとも、こちらの解釈ですか」。
4. 「誰と誰が知っていますか」→ 数えきれない。桐山の過去談 — 知ったのは半年後 (帰結は遅れて届く)。
5. 「登記だけ先にしておきましょうか」— 挙がる理由がすべて誰かの時計 (成果報告の様式・話しやすさ・器が先なら人も探しやすい)。桐山の独り言「紙には、結べる時期というものがあるんです」。
6. 研究者「会社を作ったら、この資料は誰の責任で出すんですか」。
7. 幕: 湯浅が画面をメールへ切り替える。差出人欄の自分の名前。15:55。取り消しは二回のクリック。取り消せば、月初の検討会には間に合わないかもしれない。「予約を取り消す」の上にカーソルを置いたまま、湯浅は顔を上げる。三人がこちらを見ていた — **未決。カーソルの上の指** (設計表どおり)。
8. 転調部 (罫線後、討議課題の前): 場面を閉じ、読みの向きを渡す — あの部屋で鳴っていた時計は、壁の一つだけだったのか。第1章の四十分では誰も止まらず、この十七分では止まった。止まった分だけ、問いが手元に残っている——という趣旨の 2〜3 文 (橋 1→2 の機能をここが担う)。

### 検討点 (まさに聞く)

- **研究者の時計の一拍**: 議論のどこかに研究者の時計 (例:「投稿は、七月なので」の類の短い新規一言) を一度だけ鳴らすか。理論 2.3 の効き所④「研究者自身の時計だけが議題に載らない」と演習2-1 (発明者は7月に論文投稿) に接続する。ただし場面の密度が上がるため、置かない選択もある (置かない場合、「研究者の時計が一度も鳴らなかったこと」自体を再読の発見として討議課題A3 が拾う)。**えいみの推奨は「置かない」** — 不在こそが 2.3 の論点で、置くと答えの先出しになる。

## 3. 「鬼門」代替語候補 (理論側 15箇所 + MASTER_PLAN 等の改修、まさ確定とセット)

対象概念の定義 (2.4): 「一度通り過ぎると元には戻れず、その後に選べる道のすべてを狭めてしまう地点。①不可逆 ②通り過ぎた瞬間には何も損なわれて見えない」

| 案 | 語 | 根拠 | 難点 |
|---|---|---|---|
| **A (推奨)** | **不可逆点** | **原義と定義が100%一致。しかも新語ではない** — 章題「関係者の時計と不可逆点」、Ch1 1.2「この『不可逆点』の精密な扱いは第2章で行う」、Ch1 1.6 部の案内、Ch2 2.2・読書案内で既に予告語・上位語として本文使用済み。現行は「Ch1 が不可逆点と予告 → Ch2 が鬼門と改名し直す」構造になっており、A案なら予告と本命名が同じ言葉で通る。「三つの不可逆点」「不可逆点その二」も成立 | 情緒はない (ただし本書の理論語彙は τ_B 等の乾いた系で統一されており浮かない) |
| B | 分水嶺 | 和語・地形語。越えると水は別の海へ流れる (不可逆)、歩いていて越えたことに気づかない (通過時に無徴) — 二性質とも原義に含む。「地図」の比喩体系と親和。Book A 内で未使用 (衝突なし) | 原義は嶺 = 線 (尾根) であって「点」ではない。慣用の「勝敗の分水嶺」は「重大な分かれ目」の意が前面で、不可逆の含意が薄まって流通している — 「原義が違う」の再指摘リスクが残る |
| C | 帰還不能点 | 航空用語 point of no return の定訳。残燃料的にもう引き返せない地点 = 「まだ飛べているのに、もう戻れない」— ②の性質 (通過時に無徴) まで原義が含む唯一の既成語 | 翻訳語臭・硬い。「帰還不能点その二」がやや不格好 |

- 番外で検討して外した語: **関門** (Cooper のステージゲート訳語として 2.6/2.8 で使用済み・衝突) / **境界** (τ_B 法人化境界と衝突) / **一線** (「一線を越える」の俗用が強い) / **峠・関所・敷居** (いずれも往復可能な地形・建具で、不可逆の原義がない = 鬼門と同型の不一致)。
- ナラティブ側は白紙構想で用語自体を使わないため、確定した語は理論側 (2.4 命名宣言・2.4/2.5 節題・見出し「その二/その三」・2.7・2.8 演習/到達目標) + `BOOK_A_MASTER_PLAN.md` §9 Ch2/Ch14 + 関連 md へ展開する (正本反映は司令塔ゲート)。
