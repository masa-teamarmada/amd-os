# §1.0.3 測らない自由はない — 共通言語・判断の構造化・再現可能性

> Ch 1「状態空間と観測量 — Before Zero を測るとはどういうことか」(30p) の §1.0 章頭フックの第 3 サブセクション。Ch 5 §5.0.1 v4 と同じ narrative トーン (冒頭ストーリー blockquote + 引用 + 軽い式 + 「読破したくなる」照準) で起草。§1.0.1 の三人のうち C 氏を金曜夜の駅前珈琲店に呼び戻し、「測らない自由はない」を共通言語・判断の構造化・再現可能性の三責務で立てる。

> 同じ週の金曜の夜、地方都市の合同庁舎を出た C 氏は、最終の特急に乗るために駅へ向かう途中、駅前のチェーン喫茶店に立ち寄り、温い珈琲を前にして、ノートを開いたまま十五分ほど動かないでいた。月曜に帰ったら、所長に何と報告するのだろう。「いまは投資すべきタイミングではないと思います」と書くのは易しいが、それを聞いた所長が「なぜ」と問い返したときに、自分は何を根拠として差し出すつもりなのか。来年の自分が同じノートを開き直したとき、今夜のこの判断を辿り直せるのだろうか。C 氏は、結局その晩、ノートに一行も書かないまま改札を抜けた。測らないという選択肢が、もし本当にあるのなら、それはきっとこのような夜には現れてくれないのだろう、と思いながら。

ずれがこれほど大きいのなら、いっそ測ることなど諦めて、当事者の勘と縁に任せたほうがよいのではないか。§1.0.2 の終わりに置いたこの素朴な誘惑は、現場では半ば真剣な選択肢として浮かびます。雨樋とバケツのバケツの位置がそもそも歪んでいるなら、雨量を読み上げることに意味はあるのか。霧の濃い湖面で釣果を数えることに、何の意義があるのか。しかし本書はここで踏みとどまります。Before Zero でも、いや Before Zero でこそ、測ることをやめる自由は実は与えられていません。理由は、観測という手続きが背負わされている三つの実務的責務にあります。本書ではその三つを、共通言語 (common vocabulary、関係者が同じ単語で同じものを指せるための語彙) ・判断の構造化 (structured decision、何を入力にどんな手続きを経て何を出力するかを明示した枠組み) ・再現可能性 (reproducibility、同じ材料が揃えば別の人間が同じ結論に辿り着けること) と呼びます。三つは別個の徳目ではなく、観測という一つの装置の三つの面として、互いを支え合います。

第一の責務、共通言語から始めます。Before Zero の一つの案件には、典型的には、研究者・URA・産学連携本部の管理職・VC のパートナー・公設試の主任・所管省庁の担当者といった、互いに語彙の重ならない人々が同時に関わります。彼らが同じ「有望」という一語を口にしても、A 氏は実験再現性のことを、URA は知財ポートフォリオのことを、本部長は所管省庁への説明可能性のことを指している、ということが日常的に起きます。同じ盤面を並べたつもりで、三人がそれぞれ別の方角からその盤を眺め、別の手筋を語っている。合意も決裂も、実はまだ生じていません。経済学者 Hayek (1945) は "The Use of Knowledge in Society", *American Economic Review* 35(4) で、社会の意思決定にとって決定的なのは、特定の専門家の頭の中に集中している知識ではなく、無数の現場に薄く分散して存在する知識をいかに一つの表記に乗せて突き合わせるかである、と論じました。Before Zero の小部屋は、まさにその縮図です。状態 s_t = (P_t, R_t, S_t) を §1.0.1 がわざわざ記号で固定したのは、命名が好きだからではなく、まず辞書を共有しないことには、ずれの話すら始められないからでした。共通言語とは、関係者全員が同じ盤面を見るための、最小限の辞書のことです。

第二の責務、判断の構造化に移ります。共通言語が揃っても、「で、どう決めるのか」が毎回その場の空気で揺れていたのでは、組織は同じ問題を二度解くことになります。経済学者 Simon (1955) は "A Behavioral Model of Rational Choice", *Quarterly Journal of Economics* 69(1) で、現実の意思決定者は計算能力にも情報にも厳しい上限を持っており (限定合理性、bounded rationality、有限な情報処理資源のもとで満足化により意思決定する様式)、だからこそ「何を入力に、どの基準で、何を出力するか」をあらかじめ枠として固定しておかなければ、判断はその場の気分と弁の立つ者に支配されてしまう、と指摘しました。サッカーのフォーメーション図のようなものです。実際の試合で起きることは図の通りには動きませんが、それでも「誰がどこを担当し、ボールが来たら何を出力するか」が事前に書き出されていることで、はじめて選手は十一人として動けます。本書はこの薄い枠線を、最も簡素な形では次のように書きます。決定 d を、観測 y を手がかりに状態 s について選ぶときの期待損失 (expected loss、決定 d がもたらす損失 L(d, s) を観測 y のもとでの状態の事後分布 p(s|y) で平均した量) です。

$$ \mathbb{E}[L(d,\, s) \mid y] \;=\; \int L(d,\, s)\, p(s \mid y)\, ds $$

式そのものを覚える必要はありません。覚えておいてよいのは、観測することをやめるとは、ここで事後分布 p(s|y) を事前の主観 p(s) に縮退させることだ、という一点です。観測のずれが大きくても、何も観測しない判断より、観測してから判断するほうが期待損失は小さい。判断の構造化とは、Before Zero の関係者が十一人の選手として動くための、薄い枠線のことです。

第三の責務、再現可能性です。Before Zero の判断は、面談一回で完結することは稀で、半年後・一年後・三年後に、後任の担当者や、新しく着任した所長や、出資を検討する次の VC によって、しばしば本人ではない誰かによって辿り直されます。山に入るときに登山者がロガーを持つのは、自慢のためでも告発のためでもなく、来年の自分が同じ尾根をもう一度歩けるようにするためです。科学哲学者 Popper (1959) は *The Logic of Scientific Discovery* (Hutchinson) で、ある主張が知識として扱われるためには、第三者が同じ手続きを踏めば同じ結論に到達できる、という最低限の条件——反証可能性 (falsifiability、ある命題がどのような観測によって覆りうるかを原理的に明示できる性質) ——を満たす必要がある、と論じました。実務家の内省を理論化した Schön (1983) *The Reflective Practitioner: How Professionals Think in Action* (Basic Books) も、専門家の熟達とは、現場での判断 (reflection-in-action) を後から自分で読み返せる形で残しておく習慣の積み重ねだ、と描いています。共通言語が「同じ盤面を見るための辞書」だったとすれば、再現可能性は「同じ盤面をもう一度並べ直すためのロガー」にあたります。あの一週間に、A 氏が語尾を弱め、B 氏が数秒の沈黙を置き、C 氏が語気を揺らしたあの瞬間が、ただ過ぎ去る逸話ではなく、半年後の自分が読み返せる議事録に変わりうるかどうかは、この第三の責務にかかっています。

共通言語が地図を描き、判断の構造化が歩き方を定め、再現可能性が足跡を残す。三つは別個の作法ではなく、地図と歩き方と足跡という関係のように、どれか一つを欠けば残りの二つが崩れます。共通言語が崩れれば、構造化された手続きの入力欄を参加者は同じ意味で埋めることができません。判断の構造化が崩れれば、議事録には結論だけが残って手続きが残りません。再現可能性が崩れれば、共通言語と構造化された手続きで一度たどり着いた結論が、次の機会の学習材料として効かなくなります。あの一週間、A 氏が教授会への翻訳を、B 氏が VC への説明を、C 氏が機関長への報告を、面談のあとで一人ずつ抱え込んでいたのは、観測のずれの問題であると同時に、この三つの責務の問題でした。続く §1.0.4 では、Ch 1 の残り (§1.1 状態・観測・推定の三項関係、§1.2 状態空間 (P, R, S)、§1.3 観測量の構造、§1.4 Before Zero の観測問題、§1.5 案件層 PRS と機関層 ERS の二層観測) を、この三つの責務を順に育てていくロードマップとして並べ直します。五枚の地図を、C 氏が珈琲の前で動けなくなったあの十五分のような夜に、静かに広げ直すための節が、ここから始まります。
